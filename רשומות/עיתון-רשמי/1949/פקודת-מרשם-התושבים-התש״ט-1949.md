|2. יותקן מרשם תושבים בשטח הפקודה ויתנהל על ידי משרדי רישום.                                        |מרשם התושבים          |
|3. תפקידיהם של משרדי הרישום הם:-                                                                   |תפקידים של            |
|(א) לנהל ספר התושבים לפי פרטי הרישום המפורטים בסעיף 4;                                             |משרדי הרישום          |
|(ב) ליתן תעודות זהות, לחדשן ולרשום בהן שינויים:                                                    |                      |
|(ג) להוציא העתקים ותמציות מהרשום בספר התושבים ולמסור ידיעות על                                     |                      |
|שמו של תושב ועל כתובת מעונו ;                                                                      |                      |
|(ד) למלא כל תפקיד אחר לפי פקודה זו או לפי כל חוק אחר.                                              |                      |
|4. ואלה הם פרטי הרישום-                                                                            |פרטי הרישום           |
|(א) שם המשפחה, השם הפרטי ושמות ההורים: ואם שונו השמות לפני                                         |                      |
|הרישום -.גם השמות הקודמים:                                                                         |                      |
|(ב) יום הלידה ומקומה:                                                                              |                      |
|(ג) המין:                                                                                          |                      |
|(ד) המצב המשפחתי;                                                                                  |                      |
|(ה) יום העליה ויום ההתישבות במקום המגורים!                                                         |                      |
|(0 האזרחות, הלאום, הדת;                                                                            |                      |
|(ז) שפת הדיבור:                                                                                    |                      |
|(ח) ידיעת קרוא וכתוב:                                                                              |                      |
|(ט) משלח היד והמקצוע:                                                                              |                      |
|(י) כתובת המעון ומקום העבודה;                                                                      |                      |
|(יא) נשואין וגירושין:                                                                              |                      |
|(יב) לידות:                                                                                        |                      |
|(יג) אימוץ;                                                                                        |                      |
|(יד) אפוטרופסות על גוף;                                                                            |                      |
|(טו) יציאה משטח הפקודה ושיבה אליו:                                                                 |                      |
|(טז) מות.                                                                                          |                      |
|5. (א) כל תושב שמלאו לו 16 שנה חייב להודיע למשרד הרישום את פרטי                                    |חובה להודיע           |
|הרישום המנויים בסעיף 4 (א) עד (י) על עצמו, ואם יש לו ילדים שלא                                     |פרטי רישום            |
|מלאו להם 16 שנה או אם נמצא בדירתו או בחסותו תושב שלא מלאו                                          |                      |
|לו 16 שנה או שאינו מסוגל לקיים בעצמו את חובת ההודעה - גם על                                        |                      |
|ילדיו ועל כל תושב כזה.                                                                             |                      |
