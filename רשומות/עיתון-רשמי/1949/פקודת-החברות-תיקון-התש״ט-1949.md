|1. פקודת החברות תתוקן כך:                                                                      |תיקון פקודת          |
|(א) בסעיף 18 (1), אחרי המלים "המסים שהוזכרו בסעיף הקודם", יווספו                               |החברות               |
|המלים: "במידה שסילוקם לא נדחה אגב שימוש בסמכות לפי צו של                                       |פרק נ''ב             |
|שר המשפטים על פי סעיף 244".                                                                    |                     |
|(ב) בסעיף 244 תיווסף פסקה זו:                                                                  |                     |
|"על אף האמור בפקודה זו, רשאי שר המשפטים, בצו שיפורסם בעתון                                     |                     |
|הרשמי, לקבוע סוגים של חברות אשר לגביהם יהיה הרשם רשאי לדחות                                    |                     |
|את סילוקם של מס רישום, מס הון וכל מם אחר המשתלם לפי פקודה זו,                                  |                     |
|כולו או מקצתו, לתקופה ובתנאים שיקבע הרשם, באישור שר המשפטים,                                   |                     |
|בכל מקרה ומקרה".                                                                               |                     |
|2: (א) לגבי משכנתות ושיעבודים אשר המועד החוקי להגשתם לידי הרשם תם                              |רישום שיעבודים       |
|בין יום ט"ז בכסלו תש"ח (29 בנובמבר 1947) ובין יום י"ב בתשרי תש"ט                               |                     |
|؀ࠂࠆ(15 באוקטובר 1948) תהא הסמכות הנתונה בידי בית המשפט לפי סעיף                                |                     |
|132 לפקודת החברות - גם בידי הרשם, אם הבקשה לפי אותו סעיף                                       |                     |
|הוגשה לרשם תוך שלושים יום מיום היכנס פקודה זו לתקפה.                                           |                     |
|(ב) הודעה על כל בקשה שהוגשה לרשם על פי סעיף זה תפורסם על ידיו                                  |                     |
|בעתון הרשמי, והרשם לא ידון בבקשה אלא אחרי תום שלושים יום מיום                                  |                     |
|פרסום ההודעה ואם לא הוגשה לו התנגדות לבקשה תוך אותה תקופה.                                     |                     |
|(ג) הוגשה לרשם התנגדות לבקשה תוך שלושים יום מיום פרסום ההודעה                                  |                     |
|כאמור, יעביר הרשם את הבקשה לבית המשפט אשר ידון בה כאילו היתה                                   |                     |
|היא בקשה שהוגשה לכתחילה לבית המשפט על פי סעיף 132 לפקודת                                       |                     |
|החברות.                                                                                        |                     |
