|מס' 61 לשנת תש"ט-1949                                                                                 |                  |
|מועצת-המדינה הזמנית מחוקקת בזה לאמור:                                                                 |                  |
|1. (א) בישיבת הפתיחה של האסיפה המכוננת יקרא נשיא מועצת-המדינה                                         |הצהרת הצירים      |
|הזמנית באזני צירי האסיפה את נוסח ההצהרה הזאת:                                                         |בישיבת הפתוחה     |
|"אני מתחייב להיות נאמן למדינת ישראל ולמלא באמונה את                                                   |                  |
|שליחותי באסיפה המכוננת".                                                                              |                  |
|(ב) אחרי קריאת נוסח ההצהרה ייקראו שמות הצירים לפי סדר אלף-בית,                                        |                  |
|וכל אחד, בזה אחר זה, יקום ויגיד: "מתחייב (מתחייבת) אני".                                              |                  |
|2. ציר האסיפה המכוננת שלא נכח בישיבת הפתיחה, בין שהיה ציר מלכתחילה                                    |הצהרת צירים       |
|ובין שהיה לציר אחרי ישיבת הפתיחה בהתאם לסעיף 32 (ב) או לסעיף                                          |נוספים            |
|35 (ג) (2) לפקודת הבחירות לאסיפה המכוננת' תש"ט-1948, יצהיר את                                         |                  |
|ההצהרה המפורשת בסעיף 1 בפני יושב ראש הישיבה הראשונה של האסיפה                                         |                  |
|המכוננת בה הוא משתתף.                                                                                 |                  |
|3. לפקודה זו ייקרא "פקודת האס؀ࠂࠆࠈࠌࠎࠐיפה המכוננת (הצהרת הצירים), תש"ט-1949".                           |שם                |
