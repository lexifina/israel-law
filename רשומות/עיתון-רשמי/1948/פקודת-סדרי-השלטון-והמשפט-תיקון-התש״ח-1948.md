פקודת סדרי השלטון והמשפט (תיקון)
מס' 5 לשנת תש"ח - 1948
מועצת המדינה הזמנית מחוקקת בזה לאמור:

|1. בפקודת סדרי השלטון והמשפט, תש"ח-1948, יצורפו לסעיף 1 שני הסעיפים                                 |תיקון הפקודה          |
|הקטנים הבאים:                                                                                       |העיקרית               |
|"(ג) חבר מועצת המדינה הזמנית שהתפטר או. נתפנה מקומו מטעמים                                          |                      |
|אחרים, רשאית מועצת המדינה הזמנית למנות אדם אחר במקומו. שמו                                          |                      |
|של אדם זה יתפרסם בעתון הרשמי כתיקון לתוספת לפקודה זו.                                               |                      |
|(ד) אם הוכרז על מצב חרום לפי סעיף 9(א) לפקודה זו, ועקב מצב                                          |                      |
|החרום נבצר מחבר מועצת המדינה הזמנית להשתתף בישיבה מסויימת                                           |                      |
|؀ࠂࠌࠎשל המועצה' רשאית מועצת המדינה הזמנית לבחור באדם אחר שימלא                                       |                      |
|את מקום החבר הנעדר. ממלא מקום זה יהנה בישיבה זו מכל הזכויות                                         |                      |
|של חבר מועצת המדינה הזמנית".                                                                        |                      |
|2. תוקפה של פקודה זו הוא מיום כ"ה אייר תש"ח (3 ביוני 1948).                                         |תוקף הפקודה           |
|3. פקודה זו תיקרא בשם "פקודת סדרי השלטון והמשפט (תיקון) תש"ח-1948".                                 |                      |
