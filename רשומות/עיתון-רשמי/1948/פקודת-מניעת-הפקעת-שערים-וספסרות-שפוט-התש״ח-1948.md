|1. (א) יוקמו בתי דין למניעת הפקעת שערים וספסרות.                                                |הקמת בתי דין          |
|(ב) מקום מושבם ואזורי שפוטם של בתי הדין ייקבעו על ידי שר המשפטים                                |למניעת הפקעת          |
|בצו שיפורסם בעתון הרשמי.                                                                        |שערים וספסרות         |
|2. (א) בתי הדין למניעת הפקעת שערים וספסרות יהיו מורכבים משופטים                                 |חברי בתי הדין         |
|ממשלתיים ונציגי ציבור.                                                                          |למניעת הפקעת          |
|(ב) חברי בתי הדין יתמנו על ידי שר המשפטים; נציגי הציבור יתמנו בכל                               |שערים וספסרות         |
|אזור שפוט של בית דין מתוך המועמדים אשר העיריות והמועצות                                         |                      |
|המקומיות של אותו אזור יציעו לשר המשפטים.                                                        |                      |
|(ג) רשימת חברי בתי הדין למניעת הפקעת שערים וספסרות תפורסם בעתון                                 |                      |
|הרשמי.                                                                                          |                      |
|3. (א) בית דין למניעת הפקעת שערים וספסרות מוסמך לדון בכל ענין שיובא                             |כמכות בתי הדיז        |
|לפניו על פי הפקודות, התקנות והצוים הבאים:                                                       |ע"ר 1944 ע' 726       |

|(3) תקנות ההגנה, 1939;                                                                          |מס' 34 לש' 1939       |

|(ב) "תקנות פיקוח" פירושן:                                                                      |                      |
|(1) התקנות וההוראות של הנהלת הועד הלאומי לכנסת ישראל בארץ-                                     |                      |
|ישראל שנתפרסמו ברבים בחוברת בשם "פקוח על המזונות ובתי                                          |                      |
|הדין למניעת ספסרות, תקנות לשעת חרום", מניסן תש''ח -                                            |                      |
|אפריל 1948;                                                                                    |                      |
|(2) הצוים מס' 1 עד 4 של המפקח על המלאי שנתפרסמו ברבים בגליון                                   |                      |
|מנהלת העם, צוים והודעות, מ-10.5.1948 ובתוספת לגליון מנהלת                                      |                      |
|העם, צוים והודעות, מ-31.5.1948;                                                                |                      |
|(3) התקנות לפיקוח של יבוא מזונות של המפקחים על המזונות שנתפרסמו                                |                      |
|ברבים בגליון מנהלת העם, צוים והודעות, מ-10.5.1948.                                             |                      |
|(ג) ענין אשר בית דין למניעת הפקעת שערים וספסרות מוסמך לדון בו                                  |                      |
|על פי סעיף זה' אין להביאו לפני כל בית משפט אחר.                                                |                      |
|4. (א) בית דין למניעת הפקעת שערים וספסרות ישב בהרכב שלשה חברים:                                |הרכב בית הדין         |
|שופט ממשלתי אחד ושני נציגי ציבור.                                                              |למניעת הפקעת          |
|(ב) שר המשפטים ימנה את אב בית הדין.                                                            |שערים וספסרות         |
|(ג) אב בית הדין יקבע את התור לפיו ישבו בדין חברי בית הדין.                                     |                      |
|(ד) בית הדין יחליט פה אחד או ברוב דעות.                                                        |                      |
|5. (א) כתב אשמה בפני בית דין למניעת הפקעת שערים וספסרות יוגש על ידי                            |סדרי דיון             |
|היועץ המשפטי לממשלת ישראל או על ידי בא כוחו.                                                   |                      |
|(ב) בבית דין למניעת הפקעת שערים וספסרות אין נזקקים לכל טענה של פגם                             |                      |
|בהזמנת הנאשם או בכתב האשמה.                                                                    |                      |
|(ג) נמסרה הזמנה לדין כחוק, והנאשם או פרקליטו לא הופיעו, רשאי בית                               |                      |
|הדין לתת צו זמני לסגירת בית העסק של הנאשם.                                                     |                      |
|(ד) בית הדין למניעת הפקעת שערים וספסרות יעריך את העדות וההוכחות                                |                      |
|לפי אומדנא דדיינא, ולא יהא קשור בדיני העדות.                                                   |                      |

|(ר.) חוץ מן הענינים האמורים לעיל בסעיף זה, יחולו בבית הדין למניעת                                  |                     |
|הפקעת שערים וספסרות סדרי הדיון הנוהגים בבית משפט השלום:                                            |                     |
|הסמכות לתת צו מעצר נגד הנאשם וכל הסמכויות האחרות של שופט                                           |                     |
|שלום בקשר למשפט פלילי, חוץ מן הדיון במשפט עצמו, נתונות לאב                                         |                     |
|בית הדין.                                                                                          |                     |
|6. (א) בצאת נאשם חייב בדין בפני בית דין למניעת הפקעת שערים וספסרות,                                |עונשין               |
|יהא צפוי לו מאסר שלא יעלה על חמש שנים או קנס שלא יעלה על                                           |                     |
|2500 לירות, או שני העונשין גם יחד.                                                                 |                     |
|(ב) אם העבירה נעשתה לאחר שהנאשם יצא חייב בדין בשל עבירה קודמת                                      |                     |
|בפני בית דין למניעת הפקעת שערים וספסרות על פי פקודה זו, יוטל                                       |                     |
|עליו מאסר שלא יפחת משבועיים ולא יעלה על שבע שנים, ונוסף על כך                                      |                     |
|יהא צפוי לו؀ࠂࠆࠈࠌࠒࠔ࠘ࠞࠠࠤ࠮࠰࠴࠸ קנס שלא יעלה על 5000 לירות.                                             |                     |
|(ג) נוסף על הטלת עונש לפי הסעיפים הקטנים (א) ו-(ב) רשאי בית דין                                    |                     |
|למניעת הפקעת שערים וספסרות לצוות -                                                                 |                     |
|(1) כי מלאי הסחורות של הנאשם אשר בהן נעשתה העבירה, או הפדיון                                       |                     |
|במכירתן, יוחרם, כולו או מקצתו, לאוצר המדינה:                                                       |                     |
|(2) כי בית העסק של הנאשם ייסגר לתקופה שתיקבע על ידי בית הדין;                                      |                     |
|(3) כי רשיון שניתן לנאשם יבוטל או תקפו יופסק לתקופה שתיקבע על                                      |                     |
|ידי בית הדין:                                                                                      |                     |
|(4) כי דיוח מופרז אשר בא לידי הנאשם יושב לאדם שממנו קבל אותו;                                      |                     |
|(5) כי פסק הדין יפורסם ברבים בצורה ובאופן שייקבע על ידי בית-                                       |                     |
|הדין : הוצאות הפרסום דינן כדין קנס שהוטל בפסק דין.                                                 |                     |
|(ד) סעיף זה בא להוסיף ולא לגרוע מכוחו של בית הדין על פי הפקודות,                                   |                     |
|התקנות והצוים שהוא מוסמך לדון על פיהם.                                                             |                     |
|7. (א) כל פסק דין של בית דין למניעת הפקעת שערים וספסרות נתון לערעור.                               |ערעור                |
|(ב) הערעור הוא לבית המשפט המחוזי אשר באזור שפוטו נמצא בית הדין                                     |                     |
|למניעת הפקעת שערים וספסרות.                                                                        |                     |
|(ג) הטיל בית הדין עונש של קנס, אין מקבלים כתב ערעור על פסק הדין                                    |                     |
|אלא לאחר ששולם הקנס במלואו.                                                                        |                     |
|(ד) כל נמוק הראוי לשמש יסוד לערעורו של נאשם יכול לשמש יסוד גם                                      |                     |
|לערעור התביעה הכללית.                                                                              |                     |
|(ה) אין אחרי פסק דינו של בית המשפט המחוזי ולא כלום.                                                |                     |
|(0 חוץ מן הענינים האמורים לעיל בסעיף זה, הרי ערעור על פסק דין של                                   |                     |
|בית דין למניעת הפקעת שערים וספסרות, יהא דינו כערעור על פסק- דין                                    |                     |
|של שופט שלום.                                                                                      |                     |
