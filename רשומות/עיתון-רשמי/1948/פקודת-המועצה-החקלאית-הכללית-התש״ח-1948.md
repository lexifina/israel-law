|מועצת המדינה הזמנית מחוקקת בזה לאמור-                                                                                     |
|1. תוקם מועצה חקלאית כללית, אשר תיעץ לממשלה בעניני חקלאות, ותקשר                                    |הקמת המועצה          |
|בין הממשלה לבין הציבור החקלאי.                                                                      |ותפקידיה             |
|2. הרכב המועצה יהא -                                                                                |הרכב המועצה          |
|(א) שבעה חברים מטעם הממשלה, והם-                                                                    |                     |
|שר החקלאות ,-                                                                                       |                     |
|המנהל הכללי של משרד החקלאות ושני סגניו:                                                             |                     |
|שלשה נציגים אחרים של הממשלה שימונו על ידה.                                                          |                     |
|(ב) עשרים וחמשה, או יותר, חברים מטעם הציבור שימונו על ידי שר                                        |                     |
|החקלאות, על דעת הממשלה, תוך התיעצות עם ארגונים של חקלאים,                                           |                     |
|מחלקת ההתישבות של הסוכנות היהודית לארץ-ישראל והקרן הקימת                                            |                     |
|לישראל, ועם מוסדות אחרים המטפלים בחקלאות, התישבות, מחקר                                             |                     |
|ופיתוח חקלאי.                                                                                       |                     |
|(ג) הרכב המועצה יפורסם בעתון הרשמי.                                                                 |                     |
|3. שר החקלאות יביא לפני המועצה, לדיון ולחוות דעת, את הענינים הבאים :                                |ענינים המובאים       |
|(א) קוי יסוד של המדיניות החקלאית.                                                                   |5פני המועצה          |
|(ב) תכניות כלליות לפיתוח חקלאי והשקאה.                                                              |                     |
|(ג) הצעות חוקים הנוגעים לבעיות יסוד של החקלאות.                                                     |                     |
|(ד) שאלות עקרוניות בכל אחד מהענינים הבאים:                                                          |                     |
|(1) שמירה ופיקוח על מקורות המים ופיתוחם:                                                            |                     |

|4. המועצה מוסמכת י-                                                                               |סמכויות                   |
|(א) לבחון את דרכי הבצוע של מדיניות הממשלה בעניני החקלאות.                                         |המועצה                    |
|(ב) להציע הצעות להרחבת החקלאות, ארגונה היעיל, הגדלת הייצור החקלאי,                                |                          |
|שיפור מצב החקלאים, העלאת הרמה המקצועית בחקלאות, רבוי חקלאים,                                      |                          |
|קליטת עולים במשק החקלאי ותוספת כפרים ומשקים.                                                      |                          |
|(ג) להמליץ על חקיקת חוקים חדשים הנוגעים לחקלאות ולהציע תיקונים,                                   |                          |
|שנויים והוספות לחוקים הקיימים.                                                                    |                          |
|5. מסקנות המועצה, הצעותיה והמלצותיה תובאנה על ידי שר החקלאות לתשומת                               |מסקנות המועצה             |
|לב הממשלה.                                                                                        |                          |
|6. (א) שר החקלאות יהא יושב ראש המועצה.                                                            |יושב ראש                  |
|(ב) יושב ראש המועצה ימנה את מזכיר המועצה.                                                         |המועצה ומזכיר             |
|7. (א) חבר מטעם הציבור יוכל להתפטר על ידי מתן הודעה בכתב ליושב ראש                                |התפטרות וכו'              |
|המועצה.                                                                                           |של חבר המועצה             |
|(ב) שר החקלאות רשאי להפסיק את חברותו של חבר מטעם הציבור אם                                        |                          |
|החבר נעדר, ללא מתן נימוק המתקבל על דעתו של שר החקלאות, בשתים                                      |                          |
|משלש ישיבות רצופות של המועצה.                                                                     |                          |
|8. כל מועצה תשמש בתפקידה במשך שנתיים מיום מנויה: בתום תקופה זו                                    |זמן כהונה                 |
|תורכב המועצה מחדש, אולם המועצה היוצאת תמשיך בתפקידה גם לאחר                                       |של המועצה                 |
|תקופת השנתיים כל עוד לא הורכבה מועצה חדשה.                                                        |                          |
|9. (א) יושב ראש המועצה יכנס את המועצה לפי הצורך ולפחות אחת לשלשה                                  |ישיבות המועצה             |
|חדשים, ויקבע את זמן הישיבה, מקומה וסדר יומה.                                                      |וסדריהן                   |
|(ב) על פי דרישה חתומה על ידי עשרה חברים מטעם הציבור, אשר תפרט                                     |                          |
|את סדר היום הנדרש, יכנס יושב ראש המועצה ישיבה שלא מן המנין.                                       |                          |
|(ג) הזמנה לכל ישיבה תישלח על ידי מזכיר המועצה לכל חבריה לפחות                                     |                          |
|؀ࠂࠆࠈࠌࠒࠔ࠘ࠞࠠࠤࠪשבעה ימים לפני מועד הישיבה. בהזמנה יש לפרט את סדר יומה של                             |                          |
|הישיבה.                                                                                           |                          |
|(ד) בכל ישיבה ישב ראש שר החקלאות ובהעדרו - המנהל הכללי של משרד                                    |                          |
|החקלאות או אחד מסגניו, ובהעדרם - אחד משאר החברים מטעם                                             |                          |
|הממשלה.                                                                                           |                          |
