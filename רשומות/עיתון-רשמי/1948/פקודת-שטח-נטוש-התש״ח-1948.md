|פקודת שטח נטוש                                                                                    |                  |
|מס' 12 לשנת תש"ח - 1948                                                                           |                  |
|מועצת המדינה הזמנית מחוקקת בזה לאמור:                                                             |                  |
|1. (א) "שטח נטוש" פירושו כל שטח או מקום שנכבש. על ידי כוחות מזויינים,                             |הגדרות            |
|או נכנע להם, או שנעזב על ידי תושביו או חלק מתושביו, ואשר הוכרז עליו                               |                  |
|בצו כשטח נטוש.                                                                                    |                  |
|(ב) "רכוש" פירושו נכסים נדים ונכסים שאינם נדים, וכולל בעלי חי, תבואות,                            |                  |
|פירות וירקות וכל תוצרת חקלאית אחרת, בתי חרושת, תעשיה ומלאכה,                                      |                  |
|מכונות, סחורות ומצרכים לכל סוגיהם, וכן זכות לנכסים נדים ולנכסים שאינם                             |                  |
|נדים וכל זכות אחרת שהיא.                                                                          |                  |
|(ג) "רכוש נטוש" פירושו כל רכוש שנטשוהו בעליו בשטח נטוש.                                           |                  |
|2. (א) רשאית הממשלה להכריז בצו על.כל שטח או מקום שנכבש, נכנע או                                   |סמכותה של         |
|נעזב כמפורש בסעיף 1(א) כשטח נטוש, ומשהכריזה על כך, ייחשב אותו שטח                                 |הממשלה            |
|כשטח נטוש לצרכי פקודה זו וכל תקנה שתותקן לפיה.                                                    |                  |
|(ב) לצרכי פקודה זו רשאית הממשלה להטיל בצו על כל שטח נטוש את                                       |                  |
|החוק הקיים או כל חלק הימנו, תוך שמירה על זכויות י הפולחן והדת של                                  |                  |
|התושבים במידה שאין הדבר פוגע בבטחון ובסדר הציבורי, וכן למלא ידי                                   |                  |
|ראש הממשלה או כל שר אחר להתקין תקנות ככל אשר ייראה לו בעניני הגנת                                 |                  |
|؀ࠂࠆࠈࠌהמדינה, בטחון הצבור' אספקה ושרותים חיוניים, בתי מפר ובתי מרפא, בריאות,                       |                  |
|עבודה, משטרה או משטרת ישובים ערביים, בתי דין ומנוי שופטים בסמכות                                  |                  |
|מוגבלת או מלאה, בתי מוחה בתי כלא ומעצר, הפקעה והחרמה לגבי נכסים                                   |                  |
|נדים ושאינם נדים, בתוך כל שטח נטוש.                                                               |                  |
|(ג) שר שהוסמך להתקין תקנות לביצוע פקודה זו רשאי, באשורו של ראש                                    |                  |
|הממשלה< להתקין תקנות, לקבוע עונשין בתקנות אלו, ולקבוע הוראות לגבי                                 |                  |
|כל רכוש נד ושאינו נד בשטח נטוש.                                                                   |                  |
|3. שר האוצר ממונה על ביצוע פקודה זו.                                                              |ביצוע הפקודה      |
|4. תקפה של פקודה זו הוא למפרע מיום ז' באייר תש"ח (16 במאי 1948);                                  |הוקף הפקודה       |
|5. פקודה זו תיקרא בשם "פקודת שטח נטוש, תש"ח - 1948".                                              |שם                |
