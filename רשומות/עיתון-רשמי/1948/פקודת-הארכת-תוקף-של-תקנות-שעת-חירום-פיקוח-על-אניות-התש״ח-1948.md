|שאחד מחבריו יושב במדינת ישראל.                                                                     |                     |
|3. שר התחבורה רשאי ליתן הוראות לבעליה או לרב החובל של כל אניה השייכת                               |סמכות 5ית1           |
|לתושב ישראל, השכורה לו או המשועבדת לו -                                                            |؀ࠂࠆࠈࠌࠒࠔ࠘ࠞהוראות      |
|(א) הדורשות להסיע את האניה, תוך התקופה ובדרך שתיקבענה בהוראה,                                      |5אניות               |
|אל נמל או מקום אחר שיצויין בהוראה (בין שאותו נמל או מקום נמצא                                      |מסוימות              |
|בתחומי מדינת ישראל ובין שהוא נמצא מחוצה לה);                                                       |                     |
|(ב) הדורשות להטעין על האניה או לפרוק מעליה את הסחורות שתפורטנה.                                    |                     |
|בהוראה, או להעלות על האניה או להוריד מעליה את הנוסעים או את                                        |                     |
|סוג הנוסעים שיפורטו בהוראה, תוך התקופה ובנמל או במקום אחר                                          |                     |
|שיצוינו בהוראה (בין שאותו נמל או מקום נמצא בתחומי מדינת ישראל                                      |                     |
|ובין שהוא נמצא מחוצה לה)-,                                                                         |                     |
|(ג) הקובעות את תנאי ההובלה של מטענים או נוסעים באניה (לרבות מחירי                                  |                     |

|בדרך כלל ובין במקרה מיוחד או סוג מיוחד של מקרים:                                                   |                     |

|4. (א) כל הוראה לפי תקנות אלה, מותר לתתה באופן אשר ייראה לשר התח-                                  |אופן נתינת           |
|בורה, לרבות פרסום בעתון הרשמי או על ידי רם קול או מברק רדיו .                                      |ההוראות              |
|או על ידי הודעה בכתב, והודעה בכתב כזאת מותר -                                                      |*                    |
|(1) למסור ביד לבעלים או לרב החובל של האניה או לאדם העובד                                           |                     |
|אצל הבעלים או רב החובל;                                                                            |                     |
|(2) לשלוח בדואר במכתב רשום למקום המגורים או למקום העסקים                                           |                     |
|של הבעלים או של רב החובל;                                                                          |                     |
|(3) להציג או להדביק במקום בולט על סיפון האניה.                                                     |                     |
|משניתנה הוראה באחד האופנים הקבועים בסעיף זה, הרי כל אדם שההו-                                      |                     |
|ראה נוגעת לו דינו כדין מי שידע את תכנה ובהתאם לכך עליו למלא                                        |                     |
|אחריה.                                                                                             |                     |
|(ב) כל הוראה לפי תקנות אלה, די להפנותה אל בעליה או אל רב החובל                                     |                     |
|של האניה, ולא יהיה צורך לציין בה את שמו של האיש שאליו היא                                          |                     |
