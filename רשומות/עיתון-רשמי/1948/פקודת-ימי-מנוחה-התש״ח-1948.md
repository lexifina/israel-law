|מועצת המדינה מחוקקת בזה לאמור:                                                                                           |
|1. (א) כל אדם אשר היה ביום ה' באייר תש"ח (14 במאי 1948) בשרות ממשלת                          |עובדי ממשלה                |
|ארץ-ישראל ואשר מקום שרותו הרגיל היה אותו יום בשטח המדינה, ישרת                               |                           |
|זמנית על פי הוראות הממשלה הזמנית או אחד משריה, בלתי אם קבל לפני                              |                           |
|פרסום פקודה זו הודעה אחרת. אדם כזה ייקרא להלן "עובד ממשלה".                                  |                           |
|(ב) עובד ממשלה שלא יתיצב לעבודה במקום שרותו הרגיל תוך שבוע ימים                              |                           |
|מיום פרסום פקודה זו, ייראה כאילו פרש מן השרות, חוץ אם תווכח הממשלה                           |                           |
|או אחד משריה כי העובד לא התיצב מסיבות שאין אחריותן עליו.                                     |                           |
|(ג) הממשלה או אחד משריה רשאים, תוך 6 חדשים מיום פרסום פקודה זו,                              |                           |
|לפי ראות עיניהם ובלי מתן נמוקים, להפסיק את שרותו של עובד ממשלה או                            |                           |
|להעבירו למשרה אחרת.                                                                          |                           |
|(ד) סעיף זה אינו חל על שוטרים.                                                               |                           |
|(ר.) הממשלה רשאית ל؀ࠂࠈࠊࠎࠜࠞࠠהתקין תקנות לבצוע סעיף זה, אולם אי-התקנת תקנות                    |                           |
|לא תפגע בהוראות המפורשות לעיל.                                                               |                           |

|2. (א) כל אדם אשר שרת ביום ה' באייר תש"ח (14 במאי 1948) במשטרה                                    |שוטרים            |
|הארצישראלית של ממשלת ארץ-ישראל ואשר מקום שרותו הרגיל היה אותו                                     |                  |
|יום בשטח המדינה, ישרת זמנית על פי הוראות הממשלה הזמנית או שר                                      |                  |
|המשטרה, בלתי אם קבל לפני פרסום פקודה זו הודעה אחרת או לא נשבע                                     |                  |
|שבועת אמונים למדינה תוך חודש ימים מיום פרסום פקודה זו. אדם כזה                                    |                  |
|ייקרא להלן "שוטר".                                                                                |                  |
|(ב) הממשלה או שר המשטרה רשאים, תוך 6 חדשים מיום פרסום פקודה זר,                                   |                  |
|לפי ראות עיניהם ובלי מתן נמוקים, להפסיק את שרותו של שוטר או להעבירו                               |                  |
|לדרגה או משרה אחרת.                                                                               |                  |
|(ג) סעיף זה אינו חל על שוטרים נוספים זמניים ונוטרי כפרים (גפירים).                                |                  |
|(ד) הממשלה או שר המשטרה רשאים להתקין תקנות לבצוע סעיף זה, אולם                                    |                  |
|אי-התקנת תקנות לא תפגע בהוראות המפורשות לעיל.                                                     |                  |
