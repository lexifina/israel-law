|(ג) שופטי בית המשפט העליון יתמנו על פי הצעת שר המשפטים על ידי                                |                      |
|הממשלה הזמנית באשור מועצת המדינה הזמנית. .                                                   |                      |
|2. (א) עד היום בו יתחיל בית המשפט העליון לפעול, יהא בית המשפט המחוזי                         |עניני בית הדי!        |
|בתל-אביב מוסמך לדון בענינים שהם, על פי החוק, בסמכות בית המשפט                                |הגבוה                 |
|העליון כבית דין גבוה לצדק. . .                                                               |                      |
|(ב) בית המשפט המחוזי בתל-אביב' בדונו בענינים אלה, ישב בהרכב שלושה                            |                      |
|שופטים.                                                                                      |                      |
|(ג) בית המשפט המחוזי בתל-אביב ידון בענינים אלה לפי סדרי הדיון הנוהגים                        |                      |
|בבית הדין הגבוה לצדק.                                                                        |                      |
|3. (א) בית המשפט העליון, כבית משפט לערעורים, ישב בהרכב שלושה שופטים.                         |הרכב בחי משפט         |
|(ב) בית המשפט המחוזי, כבית משפט לערעורים, ישב בהרכב שלושה שופטים.                            |                      |
|(ג) הוראות סעיף זה תכנסנה לתוקפן ביום או בימים שייקבעו לכך על ידי שר                         |                      |
|המשפטים.                                                                                     |                      |
|4. כל סמכות משפטית שנתיחדה בחוק לנשיא בית המשפט המחוזי, תהא נתונה                            |השווית סמכויות        |
|מעתה לכל שופט של אותו בית משפט מחוזי.                                                        |                      |
|5. שר המשפטים רשאי, בצו שיפורסם בעתון הרשמי, לקבוע את אזורי השפוט                            |אזורי שפוט של         |
|של בתי המשפט המחוזיים ושל בתי משפט השלום.                                                    |בתי משפט              |

|6. כל סמכות יתר שנתיחדה בחוק לאחד מבתי המשפט המחוזיים, תהא נתונה                               |סמכות בענינים             |

|מעתה לבית המשפט המחוזי.                                                                        |חמורים                    |

|המשפט לפשעים חמורים, ישב בהרכב שלושה שופטים.                                                   |                          |
|8. (א) בית המשפט לקרקעות - בטל.                                                                |בטול בית                  |
|(ב) כל סמכות שהעניק החוק לבית המשפט לקרקעות תהא נתונה מעתה לבית                                |המשפט לקרקעות             |
|המשפט המחוזי, יהא אשר יהא ערך הקרקע או נשוא התביעה.                                            |                          |
|(ג) בית המשפט המחוזי, בדונו בענינים שהיו עד כה בסמכותו של בית המשפט                            |                          |
|לקרקעות, ינהג על פי הוראות החוק אשר נקבעו לגבי בית המשפט לקרקעות.                              |                          |
|(ד) כל؀ࠂࠆࠈࠌࠒࠔ࠘ࠞ ענין אשר ביום הכנס פקודה זו לתוקפה היה תלוי ועומד בפני בית                     |                          |
|משפט לקרקעות, ייראה כתלוי ועומד בפני בית המשפט המחוזי של אותו                                  |                          |
|מקום, והדיון בו יימשך בשלב שאליו הגיע באותו יום.                                               |                          |
|(ה) הוראות סעיף זה אינן פוגעות בענינים אשר ביום הכנס פקודה זו לתוקפה                           |                          |
|היו תלויים ועומדים בפני בית משפט שלום כבית משפט לקרקעות.                                       |                          |
|9. כל הוראה בחוק המצריכה קבלת היתר ממשלתי להגשת תביעות נגד הממשלה                              |תביעות נגד                |
|או אחת ממחלקותיה, וכל הוראה הקשורה בהשגת היתר כזה - בטלה.                                      |הממשלה                    |
|10. כל סמכות שהעניק החוק לזקן השופטים לגבי התקנת תקנות בית דין או אחרות,                       |העברת סמכות               |
|בין לבדו ובין באישורו או שיתופו של הנציב העליון, וכן לגבי ההנהלה                               |לשר המשפטים               |
|האדמיניסטרטיבית של בתי המשפט, תהא נתונה מעתה לשר המשפטים.                                      |                          |
|11. (א) שר המשפטים ממונה על בצוע פקודה זו.                                                     |הממונה על                 |
|(ב) שר המשפטים רשאי להתקין תקנות בכל ענין הנוגע לבצוע פקודה זו,                                |הבצוע ותקנות              |
|והוא יהא רשאי, ללא הגבלה כל שהיא הנובעת מכל חוק -                                              |                          |
|(1) לקבוע בתקנות אלה הוראות ביחס לענינים שהיו תלויים ועומדים                                   |                          |
|ביום הי באייר תש"ח (14 במאי 1948) בפני בית המשפט העליון                                        |                          |
|בירושלים או בתי משפט ובתי דין ארץ-ישראליים אחרים שאינם                                         |                          |
|בשטח המדינה, וביחס להוצאה לפועל של פסקי דין של בתי משפט                                        |                          |
