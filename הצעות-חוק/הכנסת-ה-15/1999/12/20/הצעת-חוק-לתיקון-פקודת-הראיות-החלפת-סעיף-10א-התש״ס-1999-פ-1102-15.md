הצעת חוק לתיקון פקודת הראיות (החלפת סעיף  10א), התש”ס-1999

|בפקודת הראיות [נוסח חדש], התשל"א-1971[1] (להלן – הפקודה) במקום סעיף 10א יבוא:                        |1.    |החלפת סעיף 10א |
|בסעיף זה -                                                           |(א)  |10א.    |"אמרת עד מחוץ   |      |               |
|"אמרה" - אמירה שניתנה מחוץ לבית המשפט, ונתקיים בה אחד מאלה:          |     |        |לבית המשפט      |      |               |
|האמרה נרשמה בידי נותנה:                                     |(1)    |     |        |                |      |               |
|האמרה נרשמה במעמד נתינתה, הוקראה לנותנה בסיום רישומה, ונחתמה|(2)    |     |        |                |      |               |
|על ידו, ואם סרב לחתום דבר הסרוב נרשם, ואם ניתנה סיבה לסרוב, |       |     |        |                |      |               |
|נרשמה אף היא;                                               |       |     |        |                |      |               |
|האמרה נרשמה בידי שומע האמרה בהזדמנות הראשונה לאחר נתינתה    |(3)    |     |        |                |      |               |
|והוקראה לנותנה לאחר רישומה במועד סביר בנסיבות הענין, ונרשמה |       |     |        |                |      |               |
|תגובתו;                                                     |       |     |        |                |      |               |
|האמרה הוקלטה או הוסרטה, והוכחה תקינותה ואמינותה של ההקלטה או|(4)    |     |        |                |      |               |
|ההסרטה;                                                     |       |     |        |                |      |               |
|"עד" - מי שהוזמן להעיד במשפט פלילי וכן נאשם שהואשם באותו כתב אישום עם|     |        |                |      |               |
|אחר, והעיד באותו משפט להגנתו הוא.                                    |     |        |                |      |               |
|אמרה של עד או של מי שאמור להיות עד במשפט תהיה קבילה כראיה במשפט פלילי|(ב)  |        |                |      |               |
|אם נתקיימו אלה:                                                      |     |        |                |      |               |
|מתן האמרה הוכח במשפט;                                       |(1)    |     |        |                |      |               |
|נותן האמרה נוכח כעד במשפט וניתנה לבעלי הדין הזדמנות לחקרו;  |(2)    |     |        |                |      |               |
|העדות שונה לדעת בית-המשפט בפרט מהותי מן האמרה, או העד מכחיש |(3)    |     |        |                |      |               |
|את מתן האמרה, כולה או מקצתה, או את תכנה, או טוען כי אינו    |       |     |        |                |      |               |
|זוכר את תכנה.                                               |       |     |        |                |      |               |
|על אף האמור בסעיף קטן (ב)(2), ו-(3), נוכח עד במשפט אך לא ניתנה לבעלי |(ג)  |        |                |      |               |
|הדין הזדמנות לחוקרו, תהא האמרה קבילה אם שוכנע בית המשפט מנסיבות הענין|     |        |                |      |               |
|או מהתנהגותו של העד, שהדבר נובע מפחדו של העד פן יבולע לו או לאדם     |     |        |                |      |               |
|הקרוב אליו, או נועד לשבש הליכי משפט.                                 |     |        |                |      |               |
|בית המשפט רשאי לקבל אמרה כאמור בסעיף קטן (ב), אף אם נותן האמרה איננו |(ד)  |        |                |      |               |
|נוכח במשפט, בין משום שהוא מסרב להעיד או משום שאינו מסוגל להעיד, ובין |     |        |                |      |               |
|שלא ניתן להביאו לבית המשפט משום שאינו בחיים או משום שלא ניתן למצאו,  |     |        |                |      |               |
|ובלבד ששוכנע בית המשפט מנסיבות הענין כי אמצעי פסול שימש להביא או     |     |        |                |      |               |
|למנוע את נותן האמרה מלתת את העדות.                                   |     |        |                |      |               |
|בית המשפט רשאי לסמוך ממצאיו על אמרה שנתקבלה לפי סעיף זה, או על חלקה, |(ה)  |        |                |      |               |
|והוא רשאי להעדיף את האמרה על עדותו של העד, והכל אם ראה לעשות כן לנוכח|     |        |                |      |               |
|נסיבות הענין, לרבות נסיבות מתן האמרה, הראיות שהובאו במשפט, התנהגות   |     |        |                |      |               |
|העד במשפט ואותות האמת שנתגלו במהלך המשפט, והטעמים יירשמו.            |     |        |                |      |               |
|לא יורשע אדם על סמך אמרה שנתקבלה לפי סעיף זה, אלא אם כן יש לה סיוע   |(ו)  |        |                |      |               |
|בראיה אחרת; נרשמה האמרה בידי העד, או הוקלטה או הוסרטה די אם יש בחומר |     |        |                |      |               |
|הראיות דבר לחיזוקה, ובלבד שהעד אינו נאשם באותו משפט.                 |     |        |                |      |               |
|אין באמור בסעיף קטן (ו), סיפה, כדי לפגוע בהוראת סעיף 11 לחוק לתיקון  |(ז)  |        |                |      |               |
