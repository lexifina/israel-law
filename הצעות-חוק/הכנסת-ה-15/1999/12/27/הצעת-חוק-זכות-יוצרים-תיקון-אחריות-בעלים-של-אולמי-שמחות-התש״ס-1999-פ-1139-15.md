הצעת חוק זכות יוצרים (תיקון - אחריות בעלים של אולמי שמחות),          התש”ס-1999

|בחוק זכות יוצרים, 1911[1] בסעיף 2 פסקה (3) בסופה יבוא:                                             |1.     |תיקון סעיף 2    |
|"למעט בעלים של אולם שמחות, בו הושמעה יצירה מוסיקלית, באמצעות תקליטן או תזמורת, שהתקשרו עם מי שאינו |       |                |
|בעל האולם;                                                                                         |       |                |
|לעניין זה – "אולם שמחות" – מקום בו מתקיימים ארועים חברתיים, משפחתיים וכל סוג אחר של אירועים בהם    |       |                |
|מושמעת מוסיקה."                                                                                    |       |                |

דברי - הסבר

כיום כאשר בעל שמחה מזמין תזמורת או תקליטן אשר אינם מכבדים את חוק זכויות היוצרים, נתבע על ההפרה בעל האולם בו הושמעה המוזיקה, למרות שאינו צד להתקשרות כלל.

חוק זה בא לתקן את המצב, ולהטיל את האחריות על מפרי החוק עצמם.

הצעה דומה הונחה על שולחן הכנסת הארבע-עשרה ע"י ח"כ יונה יהב ומספרה פ/1051.
