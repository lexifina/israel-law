הצעת חוק מקרקעי ישראל (תיקון - איסור אפליה בעסקאות במקרקעין) התש”ס-1999

|בחוק מקרקעי ישראל, התש"ך-1960[1] (להלן – החוק העיקרי), לפני הגדרה "מקרעי ישראל" יבוא:              |1.     |תיקון סעיף 1    |
|"המועצה" – כהגדרתה בחוק מינהל מקרקעי ישראל, התש"ך-1960[2].                                         |       |                |
|בסעיף 2 לחוק העיקרי, בסופו יבוא:                                                                   |2.     |תיקון סעיף 2    |
|"המועצה תתן דעתה בשאלה האם מנעה הקרן הקיימת לישראל את אישורה בניגוד לאמור בסעיף 2א; קבעה המועצה    |       |                |
|בהחלטתה כי מנעה הקרן הקיימת לישראל את אישורה בניגוד לאמור בסעיף 2א, תתן את אישורה תחת אישורה של    |       |                |
|הקרן הקיימת לישראל."                                                                               |       |                |
|אחרי סעיף 2 לחוק העיקרי יבוא:                                                                      |3.     |הוספת סעיף 2א   |
|עסקאות כאמור בסעיף 2 יתקיימו ללא אפליה בין אזרחי ישראל; אין באמור בסעיף זה כדי לשלול      |"2א.   |       |                |
|שיקולים הנובעים מן הצורך לקלוט עליה ולהקים ישובים בעלי אופי קהילתי ייחודי."               |       |       |                |

דברי - הסבר

עיקר המקרקעין בישראל מצוי בשליטתה של המדינה ומנוהל על-ידי מנהל מקרקעי ישראל. בחוק יסוד:  מקרקעי ישראל נקבע איסור על העברת מקרקעי ישראל. לאיסור זה נקבעו סייגים במסגרת היתר העברת מקרקעין לפי סעיף 2 לחוק מקרקעי ישראל, התש"ך-1960. מטרתו של תיקון זה למנוע אפליה כלשהי ביישום סעיף 2 הנ"ל באופן שעסקאות במקרקעין של המדינה יתבצעו משיקולים ענייניים תוך קיום העקרון היסודי מימי הקמת המדינה לשוויון זכויות חברתי ומדיני גמור לכל אזרחי המדינה בלי דת, גזע ומין.
