הכנסת החמש-עשרה

|הצעת חוק של חבר הכנסת איוב קרא                                        |

הצעת חוק נסיגת כוחות צבא הגנה לישראל מלבנון ומתן תנאים בסיסיים לחיילי צד”ל, התש”ס-1999

|בחוק  זה  -                                                                                      |1.        |  הגדרות         |
|"דרום לבנון"-שטח  לבנון  אשר  נמצא  בשליטת  כוחות  צבא  ההגנה  לישראל, או בשליטת  צבא  דרום      |          |                 |
|לבנון;                                                                                           |          |                 |
|"השר" – שר הבטחון.                                                                               |          |                 |

|                                                                                                 |          |                 |
|(2)הבטחת  עתידם   של  הדרוזים  והאזרחים  הלבנונים, שהיו נאמנים       לכוחות  הביטחון  של  ישראל  |          |                 |
|בדרום  לבנון;                                                                                    |          |                 |

דברי  הסבר

עקב  ההצהרות  הגוברות  על  פינוי  אפשרי  בלבנון,  הריני  מציע  לחוקק  חוק  המבטיח  בטחון  לתושבי  הצפון  ולאוהדי  ישראל  ובמיוחד  לאזרחים  הדרוזים  וכוחות  צבא הדרום, וכן אפשרויות  סיוע  בקליטה  בארץ,  לרבות  מקום   מגורים, תעסוקה  ותנאי  מחיה,  בצורה  המכובדת  ביותר, ובתנאים שיומלצו  ע"י  כוחות  הביטחון  של ישראל.
