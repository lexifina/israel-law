הכנסת החמש-עשרה

|הצעת חוק של חבר הכנסת עופר חוגי                                       |

הצעת חוק הבנקאות (שירות ללקוח) (תיקון - ריבית על יתרת זכות), התש”ס-1999

|בחוק הבנקאות (שירות ללקוח) (התשמ"א-1981 [1], האמור בסעיף 8 יסומן "(א)" ואחריו יבוא:                |1.     |תיקון סעיף 8    |
|על אף האמור בסעיף קטן (א), תאגיד בנקאי ישלם ללקוח ריבית על יתרת זכות בחשבון עובר ושב;      |"(ב)   |       |                |
|הנגיד, לאחר התייעצות עם הוועדה המייעצת ובאישור שר האוצר, יקבע את שיעורי הריבית המינימלית   |       |       |                |
|לעניין סעיף קטן זה."                                                                       |       |       |                |

דברי - הסבר

   1. תיקון זה יעודד את לקוחות הבנק לחסל את יתרת החובה כדי לזכות בריבית יתרת זכות.
   2. הואיל והבנק גובה עמלה מהלקוח על כל פעולה לצורך שוויוניות יש לחייב את הבנק לשלם ריבית ביתרת זכות.
   3. בשנים עברו חלק מן הבנקים שילמו ריבית על יתרת זכות; מן הראוי לחדש נוהג זה כיום.
