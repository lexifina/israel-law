|בחוק החברות הממשלתיות, התשל"ה-1975[1] אחרי סעיף 59, יבוא:                                          |1.     |הוספת סעיף 59ז  |

|תשמש אלא לצורך הקטנת חובות החוץ של המדינה, וזאת בנוסף לתשלומים השוטפים   |       |                 |       |                |
|שתשלם המדינה בגין חובות החוץ שלה, באותה שנה."                            |       |                 |       |                |

דברי - הסבר

מכירת החברות הממשלתיות נמצאת בעיצומה, חברות אלו נרכשו והוקמו על ידי המדינה, תוך כניסה להתחיבויות גדולות כלפי גופים ומדינות בחו"ל. מן הראוי שאותן התחייבויות, אליהן נכנסה המדינה לצורך הקמת החברות המפורטות כעת, לא תיהפכנה להתחייבויות לשם מטרה אחרת, באמצעות העברת הכספים שיתקבלו ממכירת החברות הללו לסעיפים תקציביים אחרים.  על כן מוצע להגביל את כוחה של הממשלה לעשות שימוש בתמורת ההפרטה לכל מטרה מלבד הקטנת החוב החיצוני העצום.

הצעת חוק זהה הונחה על שולחן הכנסת הארבע-עשרה ומספרה פ/54.
