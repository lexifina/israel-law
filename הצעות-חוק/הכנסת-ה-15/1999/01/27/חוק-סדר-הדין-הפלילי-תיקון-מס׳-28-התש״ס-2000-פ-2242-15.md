|מתפרסמת בזה הצעת חוק של חבר הבנסת מטעם ועדת החוקה חוק ומשפט של הכנסת:                                  |

|הצעת חוק סדר הדין הפלילי (תיקו מס' 26) (זכות השימוע),                                            |
|התשנ"ט-1999*                                                                                     |

|1. בחוק סדר הדין הפלילי [נוסח משולב], התשמ"ב-1982 1, אחרי סעיף 61 יבוא:                                            |הוספת סעיף 61א        |
|ו6א. (א) רשות תביעה תיידע חשוד בדבר כוונתה להעמידו לדין                                           |"זכות שימוע     |                      |
|בעבירה מסוג עוון או פשע.                                                                          |                |                      |
|(ב) חשוד שהודע לו על כוונה להעמידו לדין בעבירה מסוג פשע                                           |                |                      |
|יהיה זכאי לשימוע בפני פרקליט המחוז או בפני מי שהוסמך על ידו                                       |                |                      |
|במועד שייקבע על ידו.                                                                              |                |                      |
|(ג) לא יוגש כתב אישום בעבירה מסוג פשע נגד חשוד שביקש                                              |                |                      |
|לממש את זכותו לשימוע לפני שניתנה לו הזדמנות נאותה לממש זכות                                       |                |                      |
|-)                                                                                                |                |                      |
|(ד) הוראות החוק לתיקון סדרי המנהל (החלטות והנמקות),                                               |                |                      |
|התשי"ט-21958, לא יחולו על תשובת פרקליט המחוז או מי שהוסמך על                                      |                |                      |
|ידו באשר לתוצאת השימוע.                                                                           |                |                      |
|(ה) אין בהוראות סעיף זה כדי לשנות מהוראות סעיף 74.                                                |                |                      |
|(ו) שר המשפטים, באישור ועדת החוקה חוק ומשפט של הכנסת,                                             |                |                      |
|יקבע בכללים את דרך עריכת השימוע ואת הליכיו, וכן יקבע, באישור                                      |                |                      |
|ועדת החוקה חוק ומשפט של הכנסת, את סוגי העוונות שלגביהם לא                                         |                |                      |
|יחולו הוראות סעיף קטן (א)."                                                                       |                |                      |

|דברי הסבר                  |

|ההחלטה להעמיד אדם לדין, ؀ࠂࠔࠖ࠘ࠦובעיקר לגבי עבירות              |
|חמורות היא החלטה רבת משמעות. בחברה שאנו חיים                  |
|בה, די בכתב אישום, לבטח בעבירות חמורות, כדי לפגוע             |
|פגיעה קשה בנאשם.                                              |

|מסיבה זו מוצע להעניק את זכות השימוע למי                            |
|שמרגע ההכרעה בענינו ישתנה מעמדו בציבור.                            |
|עלות הצעת חוק זו כ-2.6 מיליארד שקלים                               |
|חדשים.                                                             |
