|מתפרסמת בזה הצעת חוק של חברי הכנסת מטעם הועדה לגיל הרך של הכנסת:                                       |

|הצעת חוק מסגרות טיפוליות, התשנ"ט-1999*                                      |

|1. בחוק זה -                                                                                                      |הגדרות             |
|"ילד" - ילד מגיל שנה עד גיל שלוש שנים ואם מלאו לו שלוש שנים במהלך שנת הלימודים                                    |                   |
|עד סיום שנת הלימודים, אשר אובחן כבעל ליקוי התפתחותי חמור או לקות חושית קשה                                        |                   |
|על ידי מכון להתפתחות הילד המוכר על ידי משרד הבריאות ומתקיים אחד מאלה:                                             |                   |
|(ו) זכאים בשלו לגמלת ילד נכה על פי חוק הביטוח הלאומי [נוסח משולב],                                                |                   |
|התשנ"ה-1995 1, או על פי הסכם כאמור בסעיף 9;                                                                       |                   |
|(2) הוא הוכר במפגר על ידי ועדת אבחון כמשמעותה בחוק הסעד (טיפול                                                    |                   |
|במפגרים), התשכ"ט-1969 2;                                                                                          |                   |
|"השרים" - שר העבודה והרווחה ושר הבריאות;                                                                          |                   |
|"מסגרת טיפולית" - מסגרת יומית המספקת לילד שירותי טיפול ושיקום שנקבעו לפי                                          |                   |
|הוראות סעיף 3 ושקיבלה רשיון לפי הוראות סעיף 4.                                                                    |                   |
|2. בל ילד זכאי למסגרת טיפולית באזור מגוריו או קרוב בבל האפשר לאזור מגוריו.                                        |זכאות              |
|3. השרים יקבעו סל של שירותי טיפול ושיקום מסוימים שיינתנו במסגרת הטיפולית.                                         |מערך טיפול         |
|                                                                                                                  |ושיקום             |
|4. (א) לא ינהל אדם מסגרת טיפולית אלא אם כן קיבל רשיון לכך מאת השרים                                               |רשיון              |
|ובהתאם לתנאי הרשיון.                                                                                              |                   |
|(ב) הבקשה לרשיון תוגש לשרים בדרך ؀ࠂࠒࠔࠖࠤועל גבי טפסים כפי שיקבעו.                                                  |                   |
|5. השרים יקבעו את דרכי הפיקוח על המסגרות הטיפוליות ועל נותני הטיפול והשיקום                                       |פיקוח              |
|במסגרות אלה.                                                                                                      |                   |
|6. השרים אחראים- לביצועו של חוק זה, והם רשאים להתקין, באישור ועדת העבודה                                          |ביצוע ותקנות       |
|והרווחה של הכנסת, תקנות לביצועו.                                                                                  |                   |
|7. תחילתו של חוק זה שישה חודשים מיום פרסומו.                                                                      |תחילה              |

|דברי הסבר              |

|מאחר שילדים עם בעיות התפתחות עד גיל 3 אינם                       |
|כלולים בחוק החינוך המיוחד, מוצע בחוק זה כי כל ילד                |
|בגיל שנה עד שלוש עם בעיות התפתחות קשות, כמוגדר                   |
|בחוק יהיה זכאי למסגרת טיפולית.                                   |
