|מתפרסמת בזה הצעת חוק של חבר הכנסת מטעם ועדת העבודה, הרווחה והבריאות של הכנסת:                                             |
|הצעת חוק הסעד (טיפול במפגרים) (תיקון מס' 4) (סידור חוץ ביתי                                                               |
|וסידור יומי), התש"ס-2000*                                                                                                 |
|1. בחוק הסעד (טיפול במפגרים), התשכ"ט-1969 1 (להלן - החוק העיקרי), בסעיף ו -                           |תיקון סעיף 1       |
|(1) במקום ההגדרה "דרך טיפול" יבוא:                                                                    |                   |
|''"דרך טיפול" - לרבות סידור חוץ ביתי וסידור יומי;";                                                   |                   |
|(2) אחרי ההגדרה "מעון נעול" יבוא:                                                                     |                   |
|""סידור חוץ ביתי" - החזקתו של מפגר במעון, במשפחה אומנת, בדיור בקהילה,                                 |                   |
|או במקום אחר מחוץ לביתו כפי שקבע שר העבודה והרווחה;                                                   |                   |
|"סידור יומי" - שהותו של מפגר במרכז יום טיפולי, במסגרת תעסוקה מוגנת או                                 |                   |
|במסגרת יומית-טיפולית אחרת, כפי שקבע שר העבודה והרווחה;".                                              |                   |
|2. אחרי סעיף 7 לחוק העיקרי יבוא:                                                                      |הוספת סעיף 7א      |
|7א. (א) החליטה ועדת אבחון על סידור חוץ ביתי או סידור יומי למפגר                     |"הזכות לסידור    |                   |
|מסוים תקבע גם את סוג הסידור המתאים לו ביותר.                                        |חוץ ביתי         |                   |
|(ב) בקביעת סוג הסידור החוץ ביתי תיתן ועדת האבחון עדיפות,                            |ולסידור יומי     |                   |
|ככל שניתן, לדיורו בקהילה.                                                           |                 |                   |
|(ג) מפגר שועדת האבחון החליטה כי דרך הטיפול בו תהיה סידור                            |                 |                   |
|חוץ ביתי או סידור יומי, זכאי לקבל אותו בכפוף להוראות חוק זה                         |                 |                   |
|ולהוראות חוק שירותי הסעד, התשי"ח-1958 2, מהמדינה או מטעמה,                          |                 |                   |
|במקום, באופן ולפי כללים שקבע שר העבודה והרווחה-, כללים לפי סעיף                     |                 |                   |
|קטן זה יכול שייקבעו לסוגים מסוימים של סידור חוץ ביתי או סידור                       |                 |                   |
|יומי.                                                                               |                 |                   |
|(ר) שר העבודה והרווחה רשאי לקבוע את שיעור השתתפותו של                               |                 |                   |
|מפגר או של מי שחייב במזונותיו לפי סעיף 3 לחוק ؀ࠂࠈלתיקון דיני משפחה                  |                 |                   |
|(מזונות), התשי"ט-1959 3, ובמידת חיובו, בהוצאות הסידור החוץ ביתי או                  |                 |                   |
|הסידור היומי שיינתן לו, הכל על פי כללים ובשיעורים שיקבע שר                          |                 |                   |
|העבודה והרווחה, דרך כלל או לסוגים."                                                 |                 |                   |

|דברי הסבר                                                                                                                |

|מוצע לקבוע בחוק בסעיף 7א(ג) ו-(ד) את זכאותו של              |הממתינים לסידור חוץ ביתי ולסידור יומי למפגרים. חוק          |
|המפגר לסידור חוץ ביתי או לסידור יומי ולהסמיך את             |הסעד (טיפול במפגרים), התשכ"ט-1969 (להלן - החוק),            |

|המפגר או של מי שחייב במזונותיו בסידור.                      |מפגר ואת דרכי הטיפול בו.                                    |
