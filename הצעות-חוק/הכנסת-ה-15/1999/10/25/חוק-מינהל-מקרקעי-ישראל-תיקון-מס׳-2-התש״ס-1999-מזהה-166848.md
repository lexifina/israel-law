|הצעת חוק מינהל מקרקעי ישראל (תיקון מס' 2), התש"ס-1999                                                    |                   |
|1. בחוק מינהל מקרקעי ישראל, התש"ך-1960 1, אחרי סעיף 4יד יבוא:                                            |הוספת סעיף 4טו     |
|4טו. (א) המינהל רשאי לנהל מאגר מידע שיהיה פתוח לעיון הציבור                              |'מאגר מידע     |                   |
|ושבו ייכללו פרטים על התקשרויות חוזיות של המינהל לגבי מקרקעין                             |               |                   |
|שבניהולו, אשר אינם רשומים בפנקסי המקרקעין המתנהלים לפי חוק                               |               |                   |
|המקרקעין, התשכ"ט-1969 2 (להלן - המאגר).                                                  |               |                   |
|(ב) המאגר יכלול את הפרטים האלה:                                                          |               |                   |
|(1) זכויות לגבי המקרקעין;                                                                |               |                   |
|(2) התחייבויות של המינהל לרישום משכנתה בנוגע                                             |               |                   |
|למקרקעין בעת רישומם בפנקסי מרשם המקרקעין כמשמעותם                                        |               |                   |
|בסעיף 123 לחוק המקרקעין, התשכ"ט-1969:,                                                   |               |                   |
|(3) הודעות שהומצאו למינהל בדבר משכון שנרשם על פי דין                                     |               |                   |
|לגבי אותם מקרקעין-,                                                                      |               |                   |
|(4) הודעות שהומצאו למינהל בדבר פסקי דין, החלטות                                          |               |                   |
|וצווים שניתנו על ידי בית המשפט או על ידי רשות אחרת                                       |               |                   |
|המוסמכת לכך על פי דין והנוגעים לזכויות לגבי؀ࠂࠊࠌ המקרקעין.                                |               |                   |
|(ג) השר, בהתייעצות עם שר המשפטים, רשאי לקבוע הוראות                                      |               |                   |
|לביצוע סעיף זה, ובכלל זה הוראות לגבי אופן הצגת המידע במאגר ולגבי                         |               |                   |
|התנאים למסירתו."                                                                         |               |                   |

|דברי הסבר                                                                                                                    |
|ישראל לנהל מאגר מידע, אשר ברומה לפנקסי המקרקעין                |מקרקעין רבים אינם רשומים עדיין בפנקסי                        |
|שבלשכות רישום המקרקעין, יהיה פתוח לעיון הציבור                 |המקרקעין המתנהלים בלשכות רישום המקרקעין,                     |
|וניתן יהיה לקבל ממנו מידע לגבי המקרקעין שבניהול                |והמידע על הזכויות לגביהם נמצא בידי מינהל מקרקעי              |
|מינהל מקרקעי ישראל שאינם רשומים בפנקסי                         |ישראל בלבד. על בן מוצע להסמיך את מינהל מקרקעי                |
|המקרקעין כאמור.                                                |                                                             |
