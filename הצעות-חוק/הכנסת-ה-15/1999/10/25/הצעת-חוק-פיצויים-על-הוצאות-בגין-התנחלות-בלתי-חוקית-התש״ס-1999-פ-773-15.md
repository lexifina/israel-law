הצעת חוק פיצויים על הוצאות בגין התנחלות בלתי חוקית, התש”ס-1999

|מי שהתנחל התנחלות בלתי חוקית, בין בישראל ובין בשטחים המוחזקים בידי צבא הגנה לישראל, ובשל  |(א)    |1.     |פיצויים על הוצאות|
|כך נגרמו למדינה הוצאות לפינויו או לאבטחתו, יהיה חייב בהחזר ההוצאות האמורות למדינה.        |       |       |                 |
|בית משפט השלום יהיה מוסמך לדון בתביעת פיצויים על פי סעיף קטן (א).                         |(ב)    |       |                 |
|בסעיף זה "התנחלות בלתי חוקית" אחת מאלה -                                                  |(ג)    |       |                 |
|תפיסת מבנה או מקרקעין שאינם שייכים לתופס;                                         |(1)    |       |       |                 |
|התיישבות שלא אושרה על ידי הממשלה.                                                 |(2)    |       |       |                 |

דברי - הסבר

הוצאות הפינוי והאבטחה של התנחלויות בלתי חוקיות מגיעות לסכומים גדולים ביותר. על –פי הצעת חוק זו יחויב מי שהתיישב בהתנחלות בלתי חוקיות בהחזר הוצאות פינויו ואבטחתו.

הצעה ברוח זו הונחה על שולחן הכנסת השתים עשרה, ומספרה תתתק"ז.
