|"מוסד" - בית ספר, גן ילדים, גן חיות, גן שעשועים, תנועת נוער, עסק להסעת קטינים,                             |                  |
|קייטנה, פנימיה או מועדון שבו שוהים קטינים, וכן מוסרות המעניקים טיפול לקטינים או                            |                  |
|שירותים המחייבים מגע ישיר עם קטינים-,                                                                      |                  |

|"עבודה" - בין בתמורה ובין בהתנדבות; ולרבות מתן שירותים המחייבים קשר ישיר עם                                |                  |
|קטינים;                                                                                                    |                  |
|"עבירת מין" - עבירה לפי סימן ה' לפרק י' בחוק העונשין, התשל"ז-1977 2 (להלן - חוק                            |                  |
|העונשין);                                                                                                  |                  |
|"קייטנה" - כהגדרתה בחוק הקייטנות (רישוי ופיקוח), התשץ-1990 3.                                              |                  |
|2. (א) מעסיק לא יקבל לעבודה במוסר, בגיר שהורשע בעבירת מין נגד קטין שטרם                                    |איסור עיסוק       |
|מלאו לו 16 שנים, ונידון עליה למאסר בפועל.                                                                  |                  |
|(ב) בגיר שהורשע כאמור בסעיף קטן (א) לא יציע עצמו לעבודה במוסר.                                             |                  |
|3. לא יתקבל בגיר לעבודה במוסד בטרם אישרה משטרת ישראל כי אין הוא פסול לכך                                   |איסור העסקה -     |
|מהטעמים האמורים בסעיף 2(א).                                                                                |                  |
|4. (א) העובר על הוראות סעיף 2؀ࠂࠆࠈࠌ(א), דינו - קנס כאמור בסעיף 61(א)(3) לחוק העונשין-,                      |עונשין            |
|הורשע אדם, בתוך שנתיים, בעבירה נוספת לפי סעיף קטן זה, דינו - מאסר שנה או קנס                               |                  |
|כאמור בסעיף קטן זה.                                                                                        |                  |
|(ב) העובר על הוראות סעיף 2(ב), דינו - מאסר שנה; הורשע אדם, בתוך שנתיים,                                    |                  |
|בעבירה נוספת לפי סעיף קטן זה, דינו - מאסר שנתיים.                                                          |                  |
|5. (א) נושא משרה בתאגיד חייב לפקח ולעשות כל שניתן למניעת עבירה לפי סעיף                                    |נושא משרה         |
|2(א) על ידי התאגיד או על ידי עובד מעובדיו-, המפר הוראה זו, דינו - קנס כאמור בסעיף                          |בתאגיד            |
|61(א)(2) לחוק העונשין-, לענין סעיף זה, "נושא משרה" - מנהל פעיל בתאגיד, שותף, למעט                          |                  |
|שותף מוגבל, או אדם האחראי מטעם התאגיד על קבלת עובד לעבודה.                                                 |                  |
|(ב) נעברה עבירה לפי סעיף 2(א) על ידי תאגיד או על ידי עובד מעובדיו, חזקה היא                                |                  |
|כי נושא משרה בתאגיד הפר את חובתו לפי סעיף קטן (א) אלא אם כן הוכיח כי עשה כל                                |                  |
|שניתן כדי למלא את חובתו.                                                                                   |                  |
|6. היה המוסד עסק טעון רישוי לפי חוק רישוי עסקים, התשכ"ח-1968 4, מותנה רשיון                                |מוסד שהוא         |
