|הצעת חוק המסייעים לנטרול תוצאות אסון צ'רנוביל, התשנ"ט-1999*                                                  |

|הגדרות              |1. בחוק זה -                                                                                             |
|                    |"אסון צ'רנוביל" - דליפת הבור הגרעיני בצ'רנוביל שאירעה בשנת 1986;                                         |
|                    |"הועדה" - הועדה להכרה במנטרלי תוצאות אסון צ'רנוביל שהוקמה לפי סעיף 2;                                    |
|                    |"מנטרל" - מי שנטל בצ'רנוביל חלק פעיל בפעולות לנטרול תוצאות אסון צ'רנוביל והתקיימו                        |
|                    |בו כל אלה:                                                                                               |
|                    |(1) הוא מחזיק בתעודות רשמיות;                                                                            |
|                    |(2) הוא תושב ישראל או אזרח ישראלי ערב פרסומו של חוק זה;                                                  |
|                    |(3) הועדה הכירה בו כמנטרל;                                                                               |
|                    |"תעודות רשמיות" - תעודות רשמיות של ממשלת ברית המועצות לשעבר המוכיחות כי                                  |
|                    |בעליהן נטל חלק בפעולות לנטרול אסון צ'רנוביל;                                                             |
|                    |"השר" - השר לקליטת עליה.                                                                                 |
|ועדה להכרה          |2. השר ימנה ועדה של חמישה חברים לקביעת הברה במנטרלים והם:                                                |
|במנטרלים            |(1) שופט בדימוס, והוא יהיה יושב ראש הועדה;                                                               |
|                    |(2) נציג משרד ראש הממשלה;                                                                                |

|הצעת חוק מס' פ/1090; הועברה לוועדה ביום י''ז באדר ב' התשנ"ז (26 במרס 1997), והצעת חוק מס'                           |
|פ/1378; הועברה לוועדה ביום י"ד באייר התשנ''ז (31 במאי 1997).                                                        |

|(3) נציג משרד החוץ;                                                                                                 |                     |
|(4) נציג המשרד לקליטת עליה;                                                                                         |                     |
|(5) נציג שהוא תושב ישראל או אזרח ישראלי מבין בעלי התעודות שהן לכאורה                                                |                     |
|תעודות רשמיות.                                                                                                      |                     |
|3. תפקידיה של הועדה הם:                                                                                             |תפקידי הועדה         |
|(1) לבדוק את הבקשות להכרה כמנטרל;                                                                                   |                     |
|(2) לקבוע את רשימת הזכאים להכרה כמנטרלים;                                                                           |                     |
|(3) להעניק לזכאים תעודה המעידה על היותם מנטרלים;                                                                    |                     |
|(4) לבצע ולרכז את כל הפעולות הנדרשות לביצוע תפקידיה שבסעיף זה.                                                      |                     |
|4. (א) תושב ישראל או אזרח ישראלי המבקש להיות מוכר כמנטרל יגיש בקשה                                                  |בקשות להכרה          |
|לועדה בתוך מיום פרסומו של חוק זה.**                                                                                 |כמנטרל               |
|(ב) הליך ההכרה בתושב ישראל או אזרח ישראלי כמנטרל, ייעשה בתוך 90 ימים                                                |                     |
|מיום קבלת הבקשה בידי הועדה; יושב ראש הועדה רשאי להאריך את פרק הזמן האמור,                                           |                     |
|לגבי בקשה מסוימת, מטעמים מיוחדים.                                                                                   |                     |
|5. (א) אחד מבתי החולים, לפי קביעת שר הבריאות, ישמש מרכז רפואי למעקב רפואי                                           |טיפול רפואי          |
|אחר המנטרלים וילדיהם (להלן - המרכז הרפואי); המעקב הרפואי ייערך על פי המלצת                                          |                     |
|הרופאים המטפלים במנטרלים במרכז הרפואי.                                                                              |                     |
|(ב) מנטרל זכאי לקבלת שירותים רפואיים, כפי שיקבע שר ؀ࠂࠈࠊࠎࠚࠜࠞהבריאות באישור ועדת                                      |                     |
|העליה והקליטה של הכנסת; שירותים כאמור ותרופות אשר יומלצו על ידי הרופאים                                             |                     |
|המטפלים במרכז הרפואי יינתנו, בלא תשלום, הכל בהיקף וכפי שיקבע שר הבריאות.                                            |                     |
|(ג) שר הבריאות רשאי לקבוע מרכזים רפואיים נוספים שבהם יינתנו למנטרלים                                                |                     |
|שירותים רפואיים.                                                                                                    |                     |
|6. מנטרלים זכאים לעדיפות בהלוואות לדיור או להיכלל בקבוצת הזכאים לדיור                                               |הלוואות לדיור        |
|ציבורי, הכל בהתאם לקביעת שר הבינוי והשיכון בהסכמת השר ובאישור ועדת העליה                                            |                     |
|והקליטה של הכנסת.                                                                                                   |                     |
|7. מנטרל זכאי לקצובת הבראה ונופש פעם אחת בשנה, בעד שמונה ימים, בסכום                                                |קצובת הבראה          |
|ששולם באותה שנה לעובד מדינה, בהתאם לקביעת שר האוצר.                                                                 |                     |
|8. השר ממונה על ביצוע חוק זה והוא רשאי, באישור ועדת העליה והקליטה של                                                |ביצוע ותקנות         |
|הכנסת, להתקין תקנות בכל הנוגע לביצועו, ובין היתר בנושא סדרי הדיון בועדה ותקופת                                      |                     |
|הכהונה של חבריה. דברי הסבר                                                                                          |                     |

|בקרב העולים שהגיעו למדינת ישראל מברית                          |
|המועצות לשעבר, מצויים אנשים אשר כתוצאה                         |
|מעיסוקם בפעולות הקשורות בטיפול בתוצאות התאונה                  |
|שאירעה בכור הגרעיני בצ'רנוביל באפריל 986 ו, נחשפו              |
|לקרינה מזיקה (להלן - מנטרלים).                                 |
|מספר המנטרלים שהם תושבי ישראל מוערך                            |
|במאות. אין כיום יכולת לקבוע באופן מדויק את                     |
|ההשלכות הרפואיות שיהיו לקרינה ביחס אליהם                       |
|ולילדיהם, אולם יש חשש כי אצל רבים מהם תתגלה                    |
|פגיעה בריאותית חמורה.                                          |

|מטרת הצעת החוק לקבוע את דרך ההכרה                               |
|במנטרלים ולסייע בידי מי שהוכרו ככאלה בתחומי                     |
|הבריאות, הדיור וההבראה.                                         |
|העלות התקציבית השנתית של הצעת החוק                              |
|מוערכת בכמיליון ש"ח בשנה, והיא תמומן מסעיף                      |
|הרזרבה הכללית בתקציב המרינה.                                    |

|חברי הכנסת: סופה לנדבר, יוסי כץ,                      |
|יורי שטרן, מיכאל נודלמן                               |
