|'                  |מתפרסמת בזה הצעת חוק של הבר הכנסת מטעם ועדת הכלכלה של הכנסת:                                              |
|                   |הצעת חוק להרחבת מקורות המים בישראל באמצעות הקמת מפעלים.                                                   |
|                   |להתפלת מי ים, התשס"א-2000*                                                                                |
|מטרת החוק          |1. מטרתו של חוק זה; לתת עדיפות לאומית להקמתם המהירה ולהפעלתם של מפעלים                                    |
|                   |להתפלת מי ים במדינת ישראל, אשר ירחיבו את מקורות המים של מדינת ישראל וישפרו                                |
|                   |את איכותם, ובכך יפתרו את הגירעון המתמשך והגובר במשק המים של' המרינה ויתרמו                                |
|                   |ליכולתה של ישראל להשיג שלום ויציבות באזור.                                                                |
|הקמת מפעלים        |2, שר התשתיות הלאומיות (להלן - השר) יפעל להקמתם המהירה של מפעלים                                          |
|להתפלת מי ים       |להתפלת מי ים בישראל, בין השאר, באמצעות גורמים פרטיים בעלי ידע, ניסיון, מומחיות                            |
|                   |ויכולת מוכחת בהקמת מפעלים להתפלת מי ים.                                                                   |
|הקמת מפעל          |3. (א) בתוך שנה מיום תחילתו של חוק זה תבצע הממשלה את כל הפעולות                                           |
|ראשוני             |הנדרשות לצורך תחילת עבודות ההקמה של מפעל להתפלת מי ים אשר יפיק לפחות מאה                                  |
|                   |מיליון מטר מעוקב מים בשנה (להלן - המפעל הראשוני); פעולות כאמור, לרבות הקמת                                |
|                   |המפעל הראשוני, רשאית הממשלה לבצע באמצעות תאגיד שתסמיך לענין זה, באישור                                    |
|                   |ועדת הכלכלה של הכנסת.                                                                                     |
|                   |(ב) החליטה הממשלה להסמיך תאגיד באמור בסעיף קטן (א), תקצה לו, בתוך 60                                      |
|                   |ימים מיום הסמכתו כאמור, את הקרקע הנדרשת לצורך הקמת המפעל הראשוני.                                         |
|                   |(ג) המים אשר יופקו על ידי המפעל הראשוני יירכשו על ידי המרינה, במחיר                                       |
|                   |שישקף את עלות הפקת המים בתוספת רווח סביר בנסיבות הענין.                                                   |
|                   |(ד) השר, באישור ועדת הכלכלה של הכנסת, יתקין תקנות בכל הנוגע לביצוע                                        |
|                   |הוראות סעיף זה, לרבות בדבר אופן קביעת עלות המים שיופקו במפעל הראשוני והרווח                               |
|                   |הסביר המרבי שייכלל במחיר המים, ובדבר אופן המכירה של המים.                                                 |
|                   |(ה) השר, בהתייעצות עם מועצת המים, בהסכמת שר האוצר ובאישור ועדת                                            |
|                   |הכלכלה של הכנסת, רשאי להעלות את תעריפי המים לצרכנים כדי לאפשר את מימון                                    |
|                   |רכישת המים המיוצרים במפעל הראשוני.                                                                        |
