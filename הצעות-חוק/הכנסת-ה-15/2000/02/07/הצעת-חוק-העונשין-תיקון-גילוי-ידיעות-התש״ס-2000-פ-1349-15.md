הצעת חוק העונשין (תיקון - גילוי ידיעות), התש”ס-2000

|בחוק העונשין, התשל"ז-1977[1], בסעיף 117(ד), בפסקה (2), במקום הסיפה המתחילה במילים "ושהידיעה לא     |1.     |תיקון סעיף 117  |
|נגעה" יבוא:                                                                                        |       |                |
|"ובידיעה שעניינה בטחון המדינה או יחסי החוץ שלה – אם חלפו חמש שנים מהיום שחדל מהיות עובד הציבור     |       |                |
|ולאחר קבלת אישור הצנזור הצבאי כי הידיעה איננה פוגעת בבטחון המדינה או ביחסי החוץ שלה."              |       |                |
|                                                                                                                             |
|דברי   הסבר                                                                                                                  |
|                                                                                                                             |
|כיום, חל על עובד ציבור איסור בחוק למסור ולעשות שימוש, ללא סמכות כדין, בידיעה שהגיעה אליו בתוקף תפקידו, לתקופה של חמש שנים.   |
|בנוסף לכך, אם הידיעה קשורה לביטחון המדינה, איסור זה תקף ללא הגבלת זמן.                                                       |
|                                                                                                                             |
|מטרתה של הצעת חוק זו, היא להשוות בין מעמדן של ידיעות שונות לבין מעמדן של ידיעות הנוגעות לביטחון המדינה, כך שבשני סוגי הידיעות|
|יהיה עובד הציבור רשאי לעשות שימוש לאחר חמש שנים ובלבד שמסירת ידיעות הקשורות בביטחון המדינה לא יגרמו נזק לביטחון ויעברו את    |
|אישור הצנזור.                                                                                                                |
