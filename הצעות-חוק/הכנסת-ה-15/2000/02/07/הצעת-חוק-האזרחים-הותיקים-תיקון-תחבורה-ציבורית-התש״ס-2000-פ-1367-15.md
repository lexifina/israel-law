|משרד העבודה והרווחה יתן תעודת אזרח ותיק מיוחדת לכל תושב ישראל בהגיעו לגיל 75   |(1)    |"(ב)   |       |       |                |

|בתחבורה הציבורית."                                                             |       |       |       |       |                |

דברי – הסבר

עם סיומה של שנת הגימלאי ולאחר הסקת המסקנות המתבקשות, עלינו למצוא פתרונות של ממש וליישמם בפועל על מנת לעזור לגימלאים בישראל לחיות את חייהם בשלווה ובכבוד.

התיקון המוצע בא לסייע לאוכלוסייה המבוגרת (החל מגיל 75) בארץ לממש את חופש התנועה על-ידי הענקת הנחה של 100% מדמי הנסיעה בכל סוגי התחבורה הציבורית.
