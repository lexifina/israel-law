|הצעת חוק של חבר הכנסת צחי הנגבי                             |

הצעת חוק הנצחת זכרם ומורשתם של גדולי התרבות הישראלית,

 התש”ס - 2000

|הממשלה תמנה מועצה לענין הנצחת זכרם ומורשתם של מי שמפעל חייהם העלה תרומה נכבדה לתרבות הישראלית (להלן|1.     |המועצה          |
|– המועצה); המועצה תמנה לא יותר מעשרים ואחד חברים; נציגי הממשלה במועצה מקרב עובדי המדינה יהיו: 2    |       |                |
|נציגים לשר החינוך; 2 נציגים לראש הממשלה; 2 נציגים לשר המדע, התרבות והספורט; נציג אחד לשר המשפטים;  |       |                |
|נציג אחד לשר האוצר, ונציג אחד לשר התקשורת; החברים הנוספים יהיו 12 אנשי ציבור שיתמנו על-ידי הממשלה, |       |                |
|ובלבד שלא יהיו עובדי המדינה;  הממשלה תמנה אחד מנציגיה במועצה להיות יושב ראש.                       |       |                |
|תקופת כהונתו של חבר המועצה היא חמש שנים; ניתן למנותו מחדש.                                         |2.     |תקופת כהונה     |
|המועצה תקבע את נוהל דיוניה ככל שלא נקבע בחוק זה או בתקנות לפיו.                                    |3.     |נוהל  דינים     |
|המועצה תציע לממשלה מועמדים להיכלל במסגרת האישים שחוק זה יחול לגביהם.                               |4.     |תכנית הנצחה     |
|המועצה תציע לממשלה תכנית להנצחת זכרם ומורשתם של האישים שהממשלה החילה עליהם חוק זה.                 |       |                |
|התכנית תפרט את פעולות ההנצחה שתבצע הממשלה ואת פעולות ההנצחה שיבצעו גופים ציבוריים בתמיכת הממשלה,   |       |                |
|לרבות תמיכה במפעלים או מוסדות הנושאים את שמו של הנפטר, הכל כפי שהמועצה תראה כהולם את הנצחת זכרו    |       |                |
|ומורשתו של הנפטר, בשים לב לאישיותו, לפועלו ולשאר שיקולים הנוגעים לענין; התכנית תכלול אומדן של      |       |                |
|ההוצאות הכרוכות בביצועה והצעת מקורות לכיסויין.                                                     |       |                |
|תכנית הנצחה טעונה אישור הממשלה.                                                                    |       |                |
|ניתן לשנות תכנית הנצחה בדרך האמורה בסעיף זה לענין הכנתה ואישורה.                                   |       |                |
|במסגרת הפעולות להנצחת זכרו ומורשתו של מי שהממשלה החילה עליו חוק זה, רשאית הממשלה להורות לגנז שנתמנה|5.     |פעולות הגנז     |
|לפי חוק הארכיונים, התשט"ו – 1955[1], לעשות את הפעולות הבאות או מקצתן:                              |       |                |
|לכנס את החומר התיעודי על מפעלו;                                                                    |       |                |
|לערוך, לפי המלצת המועצה, תצוגות פומביות של כתביו, יצירותיו, או חומר  תיעודי אחר המתייחס אליו, בין  |       |                |
|בגנזך המדינה ובין במקום ציבורי אחר.                                                                |       |                |
|(א) המועצה תפקח על ביצוע תכנית הנצחה ותדווח לממשלה על ממצאיה בצירוף המלצותיה.                      |6.     |פיקוח           |
|(ב) המועצה רשאית לדרוש מכל מי שנטל חלק בביצוע פעולת הנצחה במימון אוצר המדינה או בתמיכת הממשלה,     |       |                |
|שימסור לה או למי שהיא מינתה לכך כל ידיעה או מסמך הדרושים לה לצורך תפקידי הפיקוח לפי סעיף קטן (א).  |       |                |
|שר החינוך ממונה על ביצוע חוק זה והוא יהיה רשאי, באישור ועדת החינוך והתרבות של הכנסת, להתקין תקנות  |7.     |ביצוע ותקנות    |
|בכל הנוגע לביצועו.                                                                                 |       |                |
|דברי הסבר                                                                                          |                         |
|                                                                                                   |                         |
|                                                                                                   |                         |
|מדינת ישראל טרם נטלה על עצמה אחריות להנצחת זכרם ומורשתם של אישים דגולים, שהעלו תרומה מופלאה לתרבות |                         |
|הישראלית במגוון תחומי יצירה: ספרות, שירה, ציור, מוסיקה ועוד. הגיעה השעה לפעול לתיקון המעוות, הן לשם|                         |
|הנצחת פעלם התרבותי היחודי של אישים אלו – והן כאמצעי להדגשת החשיבות שמייחס העם בישראל – עם הספר, עם |                         |
|הרוח - לערכי התרבות והאמנות. הדרך הנאותה למימוש יעד חשוב זה הינה אימוץ הצעת החוק, שמכוחו תפעל      |                         |
|המועצה הציבורית, בדומה למועצה הפועלת עפ"י חוק הנצחת זכרם של נשיאי ישראל וראשי ממשלותיה, התשמ"ו –   |                         |
|1986.                                                                                              |                         |
