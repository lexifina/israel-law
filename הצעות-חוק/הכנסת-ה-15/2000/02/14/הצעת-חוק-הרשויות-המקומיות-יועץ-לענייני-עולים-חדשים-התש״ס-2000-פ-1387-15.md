|בחוק זה -                                                                                          |1.     |הגדרות          |
|"יועץ לענייני עולים חדשים" – מי שנתמנה לפי חוק זה להיות יועץ לעניני  עולים חדשים;                  |       |                |
|"רשות מקומית" –                                                                                    |       |                |
|עירייה, מועצה מקומית, איגוד ערים, שבהם 10% מכלל התושבים הם עולים חדשים;                   |(1)    |       |                |
|ישוב בו העולים החדשים הינם פחות מ-10% מכלל התושבים והשר קבע לגביו כי יחשב רשות מקומית     |(2)    |       |                |
|לענין חוק זה; החלטת השר תפורסם ברשומות;                                                   |       |       |                |
|"השר" – שר הפנים.                                                                                  |       |                |
|ראש רשות מקומית חייב למנות יועץ לענייני עולים חדשים.                                      |(א)    |2.     |מינוי יועץ      |
|                                                                                          |       |       |וסמכויותיו      |
|היועץ לענייני עולים חדשים יהיה עובד הרשות המקומית ויחולו על מינויו ועבודתו ההוראות החלות  |(ב)    |       |                |
|על עובדי אותה רשות ככל שאינן סותרות הוראות חוק זה; שכרו ישולם מקופת הרשות המקומית בלבד.   |       |       |                |
|על אף האמור בחוק זה ובכל דין, תנאי העסקתו וסמכויותיו של היועץ לענייני עולים חדשים ייקבעו  |(ג)    |       |                |
|בחוזה מיוחד עמו, כפי שיאושר בידי השר או מי שהשר מינה כראש מנהל שירות העובדים ברשויות      |       |       |                |
|המקומיות.                                                                                 |       |       |                |
|התפנתה משרת היועץ לענייני עולים חדשים וראש הרשות המקומית לא מינה יועץ לענייני עולים חדשים |(ד)    |       |                |
|תוך שלושה חודשים, ימנה השר יועץ לענייני עולים חדשים לרשות המקומית.                        |       |       |                |
|כשיר להיות יועץ לענייני עולים חדשים מי שנתמלאו בו התנאים שהשר קבע בתקנות.                          |3.     |תנאי כשירות     |
|היועץ לענייני עולים חדשים כפוף במישרין לראש הרשות המקומית בלבד.                           |(א)    |4.     |כפיפות וסמכות   |
|בתחום הסמכויות שהוענקו ליועץ לענייני עולים חדשים על פי דין, יפעל היועץ אך ורק על פי הוראות|(ב)    |       |                |
|הדין.                                                                                     |       |       |                |
|היועץ לענייני עולים חדשים יוזמן להשתתף בכל ישיבה של מועצת הרשות המקומית ושל כל ועדה       |(א)    |5.     |הזמנות חובה     |
|מועדותיה.                                                                                 |       |       |                |
|נכח היועץ לענייני עולים חדשים בישיבה שהוזמן אליה לפי סעיף זה, תינתן לו הזדמנות להשמיע חוות|(ב)    |       |                |
|דעתו לפני קבלת כל החלטה שיש לה נגיעה לענייני עולים חדשים.                                 |       |       |                |
|היועץ לענייני עולים חדשים יהיה רשאי להיות מיוצג בישיבות כאמור בסעיף זה על ידי עובד הרשות  |(ג)    |       |                |
|המקומית שהוא קבע לעניין זה.                                                               |       |       |                |
|לא יפוטר היועץ לענייני עולים חדשים אלא על פי החלטת מועצת הרשות המקומית ברוב של שני שלישים |(א)    |6.     |פיטורי היועץ    |
|מחבריה, ולאחר שההחלטה אושרה בידי ועדה מקצועית שהשר מינה לצורך סעיף זה; הועדה תהיה מורכבת  |       |       |                |
|מנציג שר הפנים, שר העבודה והרווחה, שר המשפטים והשר לקליטת העלייה.                         |       |       |                |
|החלטת המועצה בדבר פיטורי יועץ לענייני עולים חדשים לא תתקבל אלא בישיבת מועצה שזומנה במיוחד |(ב)    |       |                |
|לעניין זה, ולאחר שניתנה הודעה כדין לכל חברי המועצה שדבר הפיטורים יידון באותה ישיבה, וניתנה|       |       |                |
|ליועץ לענייני עולים חדשים הזדמנות להשמיע לפני המועצה את טענותיו בעניין הפיטורים.          |       |       |                |
|הוראות סעיף זה לא יחולו על היועץ לענייני עולים חדשים בתקופת חצי שנת עבודתו הראשונה ברשות  |(ג)    |       |                |
|המקומית; בתקופה זאת רשאי ראש הרשות המקומית לפטר את היועץ לענייני עולים חדשים בהודעה מוקדמת|       |       |                |
|של שישים ימים.                                                                            |       |       |                |
|האמור בסעיפים קטנים (א) עד (ג) אינו בא לגרוע מסמכותו של בית הדין למשמעת לפי חוק הרשויות   |(ד)    |       |                |
|המקומיות (משמעת), התשל"ח-1978 [1], לפסוק בדבר  פיטוריו של יועץ לענייני עולים חדשים בשל    |       |       |                |
|עבירת משמעת כמשמעותה בחוק האמור.                                                          |       |       |                |
|השר ממונה על ביצוע חוק זה והוא רשאי להתקין תקנות בכל עניין הנוגע לביצועו.                          |7.     |ביצוע ותקנות    |
|30 ימים מיום תחילתו של חוק זה ימנה ראש הרשות המקומית יועץ לענייני עולים חדשים; לא ימונה יועץ       |8.     |תחילת ביצוע     |

|דברי-הסבר                                                                                                                    |
|                                                                                                                             |
|החוק הקיים – פקודת העיריות ופקודת המועצות המקומיות – קובע מספר משרות שחובה על הרשויות המקומיות לקיימן. התפקיד החדש המוצע בחוק|
|זה "יועץ ראש הרשות המקומית לענייני עולים חדשים" מיועד לתת דגש לתחומים הקשורים לחיי העולים החדשים בקהילה. היועץ לענייני עולים |
|חדשים ישמש כמבקר לנושא בפני ראש הרשות המקומית ויקח חלק בישיבות מועצת הרשות וועדותיה. כמו כן, תינתן ליועץ הזכות להשמיע חוות   |
|דעתו טרם קבלת החלטה שיש לה היבט המתייחס לנושא העולים החדשים. תפקיד היועץ יהיה לשמש מעין דובר לקולותיהם של העולים החדשים בכל  |
|נושא הקשור לעניינם.                                                                                                          |
|                                                                                                                             |
