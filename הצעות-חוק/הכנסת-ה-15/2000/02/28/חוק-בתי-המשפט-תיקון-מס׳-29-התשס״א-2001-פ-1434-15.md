|1. בחוק בתי המשפט [נוסח משולב], התשמ''ד-1984 1, בסעיף 63, האמור בו יסומן "(א)"                         |תיקון סעיף 63      |
|ואחריו יבוא:                                                                                           |                   |
|'(ב) על אף הוראות סעיף קטן (א), יכול אדם לייצג בעל דין בבית משפט לתביעות                               |                   |
|קטנות, אם בעל הדין. ייפה את כוחו לכך וייפוי הכוח הוגש לבית המשפט לתביעות                               |                   |
|קטנות; אין לייצג אדם לפי סעיף קטן זה -                                                                 |                   |
|(ו) אם המייצג עוסק בייצוג בדרך קבע;                                                                    |                   |
|(2) אם הייצוג נעשה במהלך הרגיל על עסקיו של המייצג-,                                                    |                   |
|(3) אם הייצוג נעשה בתמורה.'                                                                            |                   |
