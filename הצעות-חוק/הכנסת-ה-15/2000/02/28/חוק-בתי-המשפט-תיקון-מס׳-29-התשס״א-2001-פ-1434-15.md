הכנסת החמש-עשרה

הצעת חוק בתי המשפט (תיקון - ייצוג בעל דין), התש”ס-2000

|בחוק בתי המשפט [נוסח משולב], התשמ"ד-1984[1] , (להלן – החוק העיקרי), בסעיף 63 לחוק העיקרי, האמור בו |1.     |תיקון סעיף 63   |
|יסומן "(א)" ואחריו יבוא:                                                                           |       |                |
|על אף האמור בסעיף קטן (א), בעל דין בבית משפט לתביעות קטנות, יכול שיהא מיוצג על-ידי אדם  |"(ב)      |       |                |
|פרטי שייפה את כוחו לכך וייפוי הכוח הוגש לבית המשפט לתביעות קטנות, ובלבד שמיופה הכוח לא  |          |       |                |
|היה עורך דין."                                                                          |          |       |                |

דברי-הסבר

רבים פונים היום לבית המשפט לתביעות קטנות, נוכח היותו של הליך זה קצר וזול יחסית. אולם, מספר לא מבוטל של אנשים המעוניינים לממש זכותם זו, נמנעים מלעשות כן, בגלל הקושי להתבטא בשפה העברית, דוגמת העולים החדשים.

כיום, פונים האחרונים לחבריהם על מנת שיסייעו להם בכל הקשור להכנת כתב התביעה לבית המשפט לתביעות קטנות, אך בגלל הפחד שלא יוכלו להתבטא בעת הדיון, נעתקות המלים הבודדות שבפיהם, ולעתים קרובות לא יכולים להשיב ב"הן" או "לאו", כאשר שאלת בית המשפט מופנית אליהם.

לפיכך, מוצע להרחיב את יכולת הייצוג בבית המשפט לתביעות קטנות.
