הצעת חוק חסינות חברי הכנסת, זכויותיהם וחובותיהם (תיקון - הגבלת החסינות), התש”ס-2000

|בחוק חסינות חברי הכנסת, זכויותיהם וחובותיהם, התשי"א - 1951 1, בסעיף 4, אחרי סעיף קטן (א1) יבוא:    |1.     |תיקון סעיף 4    |
|הוראות סעיף קטן (א) לא יחולו על פעילויות חבר כנסת שיש בהן כדי לעודד פגיעה באנשי כוחות   |"(א2)     |       |                |
|הביטחון ובאזרחים ישראליים, או כדי לתמוך בארגונים מחוץ למדינת ישראל שמטרתם לפגוע באזרחי  |          |       |                |
|מדינת ישראל או במדינת ישראל או בארגונים ביטחוניים שמשתפים פעולה עם מדינת ישראל."        |          |       |                |

      דברי הסבר

לא ראוי כי חסינותו של חבר כנסת תמשיך ותגן עליו בעודו מעודד פעילות ארגונים שמטרתם לפגוע באזרחי המדינה, באנשי כוחות הביטחון או בארגונים המשתפים  פעולה עם ישראל.

על כן מוצע כי במקרים בהם חבר הכנסת מעודד פעילות שמטרתה פגיעה כאמור, לא תהווה חסינותו מגן מפני העמדה לדין פלילי.
