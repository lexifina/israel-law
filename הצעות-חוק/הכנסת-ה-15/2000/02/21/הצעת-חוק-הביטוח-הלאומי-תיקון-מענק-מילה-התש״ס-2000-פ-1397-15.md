|בחוק הביטוח הלאומי (נוסח משולב), התשנ"ה- 1995 1, אחרי סעיף 44 יבוא:                                |1.     |הוספת סעיף 44 א |
|המוסד ישלם למבוטחת מענק מילה בסכום שלא יעלה על 500 שקלים חדשים כנגד הצגת|44א.    |"מענק מילה       |       |                |
|חשבונית מס שהתקבלה עבור ברית מילה לנולד."                               |        |                 |       |                |

דברי - הסבר

הסכומים שגובים היום מוהלים מגיעים עד לכ- 1000 ₪ ויותר. לעיתים קרובות הכנסות אלה אינן מדווחות לשלטונות המס.

בחוק מוצע כי המוסד לביטוח לאומי ישלם מענק מילה של עד 500 ₪ כנגד קבלה רשמית שתוצג למוסד לביטוח לאומי.
