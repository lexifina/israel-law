|בחוק מיסוי מקרקעין (שבח, מכירה ורכישה), התשכ"ג-1963[1], (להלן – החוק העיקרי), בסעיף 1, אחרי ההגדרה |1.     |תיקון סעיף 1    |
|"שיעור עליית המדד" יבוא:                                                                           |       |                |
|""עולה חדש" –  מי שנכנס לישראל על פי אשרת עולה."                                                   |       |                |
|בחוק העיקרי, בסעיף 9 , אחרי סעיף קטן (1), יבוא:                                                    |2.     |תיקון סעיף 9    |
|על אף האמור בכל דין, עולה חדש יהיה פטור ממס רכישה, אם ביום רכישת הזכות במקרקעין שהה     |"(ז)      |       |                |
|בישראל לא יותר משבע שנים ובלבד שהיה זכאי משרד הבינוי והשיכון על-פי תעודת זכאות שהוצאה לו|          |       |                |
|כדין ולא רכש זכות במקרקעין לפני כן."                                                    |          |       |                |

|דברי-הסבר                                                                                                                    |
|הצעת חוק זו באה לסייע לעולים חדשים להיקלט על הצד הטוב ביותר בארץ ולהעניק פטור ממס רכישה בעת רכישת זכות במקרקעין.             |

|עקב קשיים כלכליים, מתקשים רבים מהעולים החדשים לשלם את המס. התיקון המוצע בא לסייע להם לא רק על ידי הקלה בנטל הכספי, אלא גם    |
|במתן מוטיבציה להשתקע בישראל.                                                                                                 |
