הצעת חוק פטור ממכס לרכב המוביל עיוור, התש”ס-2000

|בחוק זה-                                                                                           |1.     |הגדרות          |
|"עיוור"- מי שמחזיק או זכאי להחזיק תעודת עיוור לפי חוק שירותי הסעד, התשי"ח-1958 [1];                |       |                |
|"מכס"- מסים המוטלים  בגין קנית רכב לשימוש פרטי;                                                    |       |                |
|"השר" – שר העבודה והרווחה.                                                                         |       |                |
|על אף האמור בכל דין, קנית רכב לשימושו הפרטי של עיוור תהיה פטורה מתשלום מכס ובלבד שנתקיימו התנאים   |2.     |פטור            |
|הבאים:                                                                                             |       |                |

|מי שמועסק על ידי העיוור לצורך זה על פי חוזה העסקה.                                |(ב)    |       |       |                |
|השר ממונה על ביצוע חוק זה, והוא רשאי להתקין תקנות בכל ענין הנוגע לביצועו.                          |3.     |ביצוע ותקנות    |

דברי - הסבר

לפני שבועות מספר נערך תחקיר טלויזיוני שהראה כי עיוורים מופלים לרעה בכל הנוגע לשרותי התחבורה הציבורית. נהגי מוניות אינם מעלים עיוורים לרכבם  מחשש לנזק שיגרמו כלבי הנחיה כמו כן  נסיעה באוטובוסים עם כלבי נחיה גם אינה נוחה. מוצע בזאת כי עיוור יקבל פטור ממכס לקנית רכב, מה שיביא לשיווין ולהקלה בתפקוד היומיומי.
