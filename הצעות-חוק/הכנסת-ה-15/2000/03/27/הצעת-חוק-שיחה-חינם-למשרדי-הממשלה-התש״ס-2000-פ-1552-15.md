הצעת חוק שיחה חינם למשרדי הממשלה, התש"ס-2000

|לכל משרד ממשלתי יהיה קו טלפון להתקשרות חינם (להלן – קו טלפון חינם); מספרו של הקו האמור    |(א)    |1.     |קו טלפון חינם   |
|יפורסם על ידי המשרד בשני עיתונים יומיים וכן בכל פרסום של המשרד.                           |       |       |                |
|                                                                                          |       |       |                |
|בקו טלפון חינם יינתן מידע לציבור על המשרד ועל אופן הגשת בקשה או  פניה לבעלי תפקידים באותו משרד.    |2.     |מידע לציבור     |

דברי - הסבר

מוצע, כי לכל משרד ממשלתי יהיה שירות של שיחה חינם (800-1) כך שגם אזרחים מעוטי יכולת יוכלו להתקשר מבלי לחשוש שהזמן הרב בו הם ממתינים ועד אשר הם מוצאים את מבוקשם יעלה להם כסף רב.

השירות יכיל גם מידע אינפורמטיבי על המשרד ועל היחידות השונות ואופן הפניה אליהן.
