|1. בחוק הסדרים במשק המדינה (תיקוני חקיקה להשגת יעדי התקציב), התשנ"ג-1992 1                                |תיקון סעיף 7       |
|(להלן - החוק העיקרי), בסעיף 7, אחרי ההגדרה "מועצה" יבוא:                                                  |                   |
|""מפעל ביטחוני עתיר שטח" - מפעל אשר עיקר פעילותו היא תכנון או ייצור                                       |                   |
|מערכות נשק או תחמושת, אשר שטחו, לרבות השטחים הבנויים המוחזקים                                             |                   |
|בידו בישראל גם אם הוא מתפרש על פני תחום שיפוט של יותר מרשות מקומית                                        |                   |
|אחת, הוא 1,500 דונם לפחות;".                                                                              |                   |
|2. בסעיף 8 לחוק העיקרי בסופו יבוא:                                                                        |תיקון סעיף 8       |
|"(ג) הארנונה המרבית שתטיל מועצה על קרקע תפוסה במפעל ביטחוני עתיר שטח                                      |                   |
|תהיה בשיעור של הסכום המזערי,לקרקע תפוסה למפעל עתיר שטח.                                                   |                   |
|(ר) הארנונה המרבית שתטיל מועצה על בנין במפעל ביטחוני עתיר שטח תהיה                                        |                   |
|בשיעור של הסכום המזערי לתעשיה.                                                                            |                   |
|(ה) מועצה לא תטיל ארנונה על קרקע המוחזקת בידי מפעל ביטחוני עתיר שטח,                                      |                   |
|שהשימוש בה הוא לצורכי בטיחות או ביטחון בלבד.                                                              |                   |
|(ו) היה מפעל בטחוני עתיר שטח פרוש על פני יותר מרשות מקומית אחת, תגבה כל                                   |                   |
|רשות את הארנונה בהתאם לשטח המצוי בשטחה."                                                                  |                   |
