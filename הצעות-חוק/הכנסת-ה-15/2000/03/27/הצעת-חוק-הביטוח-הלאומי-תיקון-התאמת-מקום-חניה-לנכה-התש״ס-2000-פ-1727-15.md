הצעת חוק הביטוח הלאומי (תיקון - התאמת מקום חניה לנכה),

התש”ס-2000

|בחוק הביטוח הלאומי [נוסח משולב] התשנ"ה-1995[1], בסעיף 220, האמור בו יסומן "(א)" ואחריו יבוא:      |        |תיקון סעיף 220  |
|המוסד ישא בהוצאות שהוציאה רשות מקומית עבור התאמת מקום חניה ליד ביתו של מבוטח, שהמוסד קבע  |(1)    |"(ב)    |                |
|כי הוא זכאי לסיוע בפתרון בעית הניידות שלו על ידי רכישת רכב;                               |       |        |                |
|השר, בהתייעצות עם שר הפנים, יקבע בצו את הסכומים שישלם המוסד כאמור בסעיף זה; הסכומים       |(2)    |        |                |
|שישולמו על ידי המוסד יתעדכנו אחת לשנה, ולא יאוחר מ-1 בחודש אפריל."                        |       |        |                |

דברי - הסבר

המוסד לביטוח לאומי מאשר סיוע בפתרון בעית ניידותם של נכים על ידי רכישת מכונית. נכה שאושרה לו ניידות רכב זכאי להתאמת מקום חניה ליד ביתו על ידי הרשות המקומית. התאמת החניה כוללת בין השאר: הצבת תמרור, סימון מקום החניה, רכישת לוחית עם מספר רישוי הרכב והנמכת מדרכה שתקל עליה וירידה של נכה המרותק לכיסא גלגלים. מדובר בהוצאה כספית גבוהה לרשויות המקומיות, ששוב נאלצות לממן מתקציבן הדל את החלטותיה של הרשות המבצעת, שמטילה עליהן משימות, שאינן בתחום אחריותן הישירה.

מוצע, כי המוסד לביטוח לאומי יממן את התאמת מקומות החניה לנכים שמבוצעת על ידי הרשויות המקומיות. שר העבודה והרווחה, בהתייעצות עם שר הפנים, יקבע בצו את הסכומים שישלם המוסד לביטוח לאומי לרשויות המקומיות. סכומים אלה יתעדכנו פעם בשנה.
