הצעת חוק ביטוח בריאות ממלכתי (תיקון - פרסום דבר מינוי נציב קבילות), התש”ס-2000

|בחוק ביטוח בריאות ממלכתי, התשנ"ד-1994[1], בסעיף 43, בסופו יבוא:                                    |1.     |הוספת סעיף 43   |
|דבר מינוי הנציב יפורסם על גבי לוחות מודעות בכל מרפאות קופות החולים ובשני עיתונים יומיים    |"(ג)   |       |                |
|לפחות, בצירוף פרטים על דרכי הגשת הקבילות אליו."                                            |       |       |                |

דברי הסבר

החוק הקים מחייב את שר הבריאות למנות נציב שתפקידו לטפל בקבילות הציבור. מטרת התיקון היא להקל על הציבור את הפניה לנציב קבילות הציבור, על-ידי פרסום פרטי הנציב  ואופן הפניה אליו.
