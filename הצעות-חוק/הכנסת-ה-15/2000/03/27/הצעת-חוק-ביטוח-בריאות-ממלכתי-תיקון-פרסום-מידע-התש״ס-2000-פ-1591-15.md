הצעת חוק ביטוח בריאות ממלכתי (תיקון - פרסום מידע), התש”ס-2000

|בחוק ביטוח בריאות ממלכתי, התשנ"ד-1994[1], בסעיף 26, במקום סעיף קטן (ה) יבוא:                    |1.     |תיקון סעיף 26      |
|                                                                                                |       |                   |
|                                                                                                |       |                   |
|כל קופת חולים תפרסם ברבים ותעמיד לרשות כל חבר, לפי דרישתו, מידע כדלקמן –                        |"(ה)   |                   |
|השירותים העומדים לרשות חבריה, היכן ניתן לקבלם ומיהם נותני השירותים מטעמה;               |(1)    |       |                   |
|שמותיהם של חברי מועצת הקופה, חברי הדירקטוריון והאחראי לבירור תלונות החברים."            |(2)    |       |                   |

דברי הסבר
סעיף 26 (ה) הקיים קובע כי כל קופת חולים תעמיד לרשות החברים בה מידע על שירותיה. מוצע לקבוע כי, בנוסף למידע זה, יועמד לרשות החברים בקופה גם מידע לגבי מנהלי הקופה והאחראי לבירור תלונות החברים.
