הצעת חוק הלוואות לדיור (תיקון - זכאות לדיור ציבורי),                                התש”ס-2000

|בחוק הלוואות לדיור, התשנ"ב-1992[1] (להלן – החוק העיקרי), בשם החוק, אחרי "הלוואות לדיור" יבוא       |1.     |תיקון שם החוק   |
|"וזכאות לדיור ציבורי".                                                                             |       |                |
|אחרי סעיף 7ב לחוק העיקרי יבוא:                                                                     |2.     |הוספת סעיף 7ג   |
|זכאי אשר לא קיבל הלוואה לדיור, יהיה זכאי לשכור דירה ציבורית, כהגדרתה בחוק|7ג.    |"זכאות לדיור     |       |                |
|הדיור הציבורי (זכויות רכישה), התשנ"ט-1988[2], עד לקבלת הלוואה לדיור".    |       |ציבורי           |       |                |

דברי - הסבר

כיום, אין באפשרותם של זוגות צעירים, חיילים משוחררים, עולים חדשים וכיוצא באלה לגייס מימון ראשוני לרכישת דירה, וממילא גם אינם יכולים לממש את זכאותם ולקבל הלוואות ומענקים עבור רכישת דירה, כתוצאה מכך הם נופלים בין הכסאות ונותרים ללא קורת גג כלל.

מוצע בזאת שאותם הזוגות יוכלו להיכנס לדיור ציבורי, בשכירות.
