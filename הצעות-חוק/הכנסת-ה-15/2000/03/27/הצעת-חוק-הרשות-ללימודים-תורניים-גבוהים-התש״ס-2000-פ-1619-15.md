הצעת חוק הרשות ללימודים תורניים גבוהים, התש”ס-2000

|                                                                                                   |       |                |

|בחוק זה –                                                                                          |1.     |הגדרות           |
|"השכלה"-לרבות הוראה,מדע ומחקר;                                                                     |       |                 |
|"לימודים תורניים גבוהים"-לימודים בישיבה,כולל, מכון להכשרת מורים דתיים, מכון למחקר תורני או בית     |       |                 |
|אולפנא על תיכוני לנשים במדינת ישראל;                                                               |       |                 |
|"המועצה"-מועצת הרשות ללימודים תורניים גבוהים המוקמת לפי סעיף 2;                                    |       |                 |
|"השר"-שר החינוך.                                                                                   |       |                 |
|מוקמת בזה רשות ללימודים תורניים גבוהים; הרשות תנוהל באמצעות מועצה שחבריה ימונו על ידי נשיא המדינה  |2.     |הקמה             |
|לפי חוק זה.                                                                                        |       |                 |
|הרשות היא המוסד להערכת לימודים תורניים גבוהים ושקלולם, והיא תמלא את התפקידים המוטלים עליה לפי חוק  |3.     |תפקידים          |
|זה.                                                                                                |       |                 |
|הרשות תהא תאגיד, כשר לכל חובה, זכות ופעולה משפטית.                                                 |4.     |תאגיד            |
|הרשות תהא גוף מבוקר, כמשמעותו בסעיף 9(6) לחוק מבקר המדינה , התשי"ח-1958[1] [נוסח משולב].           |5.     |גוף מבוקר        |
|מספר חברי מועצת הרשות ייקבע מתקופה לתקופה על ידי הממשלה על פי המלצת השר, ובלבד שהמספר לא יפחת מעשרה|6.     |מספר חברים       |
|ולא יעלה על חמישה עשר.                                                                             |       |                 |
|חברי הרשות יוצעו לנשיא המדינה על ידי הממשלה.                                                       |7.     |הרכב הרשות       |
|ראש הרשות יהיה מי שיכהן כראש מוסד להשכלה תורנית גבוהה במדינת ישראל, בעל נסיון בהערכת משקלם של      |       |                 |
|לימודים ומחקרים תורניים.                                                                           |       |                 |
|בין חברי הרשות האחרים יהיו דיין, שני רבנים שהמליצה עליהם מועצת הרבנות הראשית לישראל, וראשי מוסדות  |       |                 |
|ללימודים תורניים גבוהים שהמליץ עליהם השר.                                                          |       |                 |
|נתפנה מקומו של חבר מועצת הרשות, תוך תקופת כהונתה של מועצה, מחמת כל סיבה שהיא, יתמנה במקומו לתקופת  |8.     |חילופי גברי      |
|כהונתה של אותה הרשות חבר אחר בדרך שנקבעה למינויו של החבר שמקומו נתפנה.                             |       |                 |
|נבצר מחבר הרשות לשמש בתפקידו בפועל תקופה קצובה, רשאי השר להציע לנשיא המדינה למנות ממלא מקום לאותו  |       |                 |
|חבר לתקופה כאמור.                                                                                  |       |                 |
|המועצה רשאית לבחור מבין חבריה סגן לראש הרשות.                                                      |9.     |סגן יו"ר         |
|תקופת כהונתה של כל מועצה תהיה חמש שנים מיום מינוי חבריה של אותה מועצה;ואולם המועצה הראשונה תכהן    |10.    |תקופת הכהונה     |
|שנתיים בלבד.                                                                                       |       |                 |
|המועצה תקבע את נוהל דיוניה, במידה שלא נקבע בחוק זה או בתקנות לפיו.                                 |11.    |נוהל דיונים      |
|קבלת עובדי המועצה ומינויים ייעשו בידי הרשות ויהיו כשל עובדי המדינה , בתיאומים שייקבעו בתקנות; תנאי |12.    |עובדים           |
|העבודה ושכרם של עובדי הרשות יהיו זהים לאלה של עובדי המוסדות להשכלה גבוהה.                          |       |                 |
|המועצה לא תהה רשאית למכור או להעביר בדרך אחרת נכס שבבעלותה, למשכנו, להשכירו או להשאילו לתקופה העולה|13.    |סייג להעברת נכסים|
|על עשר שנים,אלא באישור השר; שכירות או שאילה לתקופה נוספת שבצירופה לקודמות הן עולות על עשר שנים,    |       |                 |
|טעונות אישור כאמור.                                                                                |       |                 |
|לעינין סעיפים 4,12, ו-13 רשאית המועצה לפעול באמצעות ועדה מבין חבריה או בצירוף אנשים שאינם מבין     |14.    |ועדות מנהליות    |
|חבריה.                                                                                             |       |                 |
|המועצה תהיה רשאית להעניק תארים בלימודים תורניים גבוהים לבוגרי מוסדות ללימודים תורניים גבוהים.      |15.    |הענקת תארים      |
|המועצה תהיה רשאית להעניק תארים משלוש רמות :תואר ראשון, תואר שני ותואר שלישי.                       |16.    |סוגי תארים       |
|המועצה לא תשמש בכינויים המשמשים באוניברסיטאות או במכללות האקדמיות לתארים אקדמיים,לדרגותיהם.        |       |                 |
|המועצה תקבע את התנאים שהעומד בהם יהיה זכאי לכל אחד מן התארים בהשכלה תורנית גבוהה, לרבות מספר שנות  |17.    |הדרישות לתארים   |
|לימוד קודמות במוסד ללימודים תורניים גבוהים,מבחנים או עבודות בכתב.                                  |       |                 |
|התנאים שתקבע המועצה יפורסמו ברשומות.                                                               |       |                 |
|תואר בלימודים תורניים גבוהים,על פי חוק זה, יהיה זהה לתואר אקדמי על פי חוק המועצה להשכלה            |18.    |שקילות התואר     |
|גבוהה,תשי"ח-1958[2], לגבי כל דין לרבות בתחומים הציבוריים,המנהליים והחינוכיים.                      |       |                 |
|השר רשאי להתקין תקנות לביצוע חוק זה באישור ועדת החינוך והתרבות של הכנסת.                           |19.    |תקנות            |
|דברי  הסבר                                                                                                                   |
|                                                                                                                             |
|הצעת חוק זה מבוססת על מסקנותיה של ועדה שנתמנתה בשנת תשנ"ח -1998 , בידי שר החינוך במטרה לקדם את שקלולם והערכתם של לימודים     |
|תורניים גבוהים.                                                                                                              |
|ועדה זו והצעת חוק שבאה בעקבותיה ,נועדו לתקן את חוסר השוויון השורר כיום , בו אין סימטריה בין הלומדים במוסדות להשכלה גבוהה,על  |
|פי חוק המועצה להשכלה גבוהה,תשי"ח-1958,לבין תלמידים הלומדים במוסדות ללימודים תורניים גבוהים, באשר להם אין מסלול או מסגרת      |
|שתעריך ותשקלל את השכלתם.                                                                                                     |
|מוצע ,על כן, להקים גוף שיהיה מוסמך להעניק תארים עבור לימודים תורניים גבוהים, תארים בעלי מעמד זהה לאלו הניתנים כיום במסלולי   |
|השכלה גבוהה אחרת.                                                                                                            |
|הכוונה היא שהגוף, שייקרא "הרשות ללימודים תורניים גבוהים ", לא יהיה בעל סמכות כלפי המוסדות ללימודים תורניים גבוהים,אלא סמכותו |
|תהיה אך ורק כלפי בוגרי מוסדות אלה, בהערכת הישגיהם.                                                                           |
|יודגש כי החוק אינו אמור לחולל שינוי מהותי בתחום דרגות השכר לבוגרי לימודים תורניים גבוהים,מפני שכבר במצב הקיים, משרד החינוך   |
|מכיר בלימודים אלו כבעלי ערך אקוויוולנטי ללימודי השכלה גבוהה,על-פי סולם מובנה ובכל הנוגע לדרגות שכר.                          |
