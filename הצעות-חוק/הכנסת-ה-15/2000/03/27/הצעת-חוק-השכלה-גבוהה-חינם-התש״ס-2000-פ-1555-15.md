הצעת חוק השכלה גבוהה חינם, התש”ס-2000

|בחוק זה -                                                                                          |1.     |הגדרות          |
|"אזרח" – כמשמעותו בחוק האזרחות, התשי"ב-1952[1];                                                    |       |                |
|כמשמעותו בסעיף 1 לחוק המועצה להשכלה גבוהה,            |-   |"מוסד להשכלה גבוהה"                    |       |                |
|התשי"ח-1958[2], וכן מכללה או מוסד על תיכוני שיוכר     |    |                                       |       |                |
|על-ידי שר החינוך לצורך זה;                            |    |                                       |       |                |
|מסלול לימודים המזכה בקבלת תעודה;                      |-   |"תכנית לימודים"                        |       |                |
|לרבות תואר אקדמי, תעודת-גמר על תיכונית ותעודת-הוראה.  |-   |"תעודה"                                |       |                |
|                                                                                                   |       |                |
|כל אזרח ישראלי, שגילו אינו עולה על 30 שנה, זכאי לתוכנית לימודים אחת חינם במוסד להשכלה גבוהה.       |2.     |זכאות להשכלה    |
|                                                                                                   |       |גבוהה חינם      |
|                                                                                                   |       |                |
|תקופת הזכאות תהיה למשך תכנית לימודים אחת ולא תארך מעבר לכך בתקופה העולה על מחצית ממנה.             |3.     |תקופת הזכאות    |
|                                                                                                   |       |                |
|על אף האמור בכל דין – מלגות ומענקים ממשלתיים הניתנים כסיוע בשכר-לימוד לעניין תכנית לימודים –       |4.     |ביטול מלגות     |
|יבוטלו.                                                                                            |       |ומענקים         |
|                                                                                                   |       |                |
|שר החינוך ושר האוצר ממונים על ביצוע חוק זה, והם רשאים להתקין תקנות בנוגע לביצועו.                  |5.     |ביצוע ותקנות    |

|דברי – הסבר                                                                                                                  |
|                                                                                                                             |
|חינוך והשכלה הינם מוצר ציבורי ברוב מדינות העולם. בכולן, וגם בישראל, החינוך היסודי והתיכון ממומן כולו על ידי המדינה. ברו      |
|המדינות גם החינוך הגבוה ממומן על ידי המדינה, מדינת ישראל היא מן הבודדות בעולם, לרבות העולם השלישי, שלא מתקיימת בה השכלה גבוהה|
|חינם לכל דורש וזכאי. הדבר תמוה במיוחד לנוכח העובדה שבישראל הסטודנט בדרך-כלל הוא חייל משוחרר שמאחוריו שלוש או ארבע שנות שירות |
|קשה למען מולדתו.                                                                                                             |
|מצב כזה לא מתקיים בשום מדינה אחרת.                                                                                           |
|השכלה אקדמית היא השקעה בהשבחתו של האדם והאזרח.                                                                               |
|                                                                                                                             |
|התועלת של ההשכלה הגבוהה אינה רק עבור הפרט, אלא עבור המדינה כולה. תועלת זו באה לידי ביטוי בשני היבטים: בהיבט המקצועי – קיים   |
|מתאם גבוה בין השכלה גבוהה ובין תוצר לאומי גבוה. בהיבט החברתי – השכלה גבוהה מהווה תנאי לתפקוד תקין של חברה דמוקרטית. מסיבות   |
|אלה מוצדקת ההשקעה של המדינה בהרחבת הבסיס החברתי של הנגישות להשכלה גבוהה.                                                     |
|                                                                                                                             |
|ללא השכלה גבוהה חינם, החברה הישראלית תמשיך להנציח בתוכה אי שוויון וניכור קשים. דמוקרטיה אמיתית היא צורת חיים המשתפת שכבות    |
|רחבות ככל האפשר, ובוודאי את אלה המוכשרים לכך, בנכסי תרבות והשכלה.                                                            |
