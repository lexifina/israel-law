|החברה את קו הטלפון תוך שלושה ימי עבודה מקבלת הבקשה בכתב;                              |    |       |       |                |
|ביקש מנוי חיבור קו טלפון לשירותי מידע בתום התקופה האמורה בסעיף קטן (א)(1), תבצע החברה את   |(ה)    |       |                |
|החיבור לא יאוחר משבעה ימים מיום קבלת הבקשה.                                                |       |       |                |
|חיבור קו טלפון לשירותי מידע בעקבות בקשה ראשונה של המנוי לא יחויב בתשלום כלשהו."            |(ו)    |       |                |

דברי הסבר

בשל ריבוי הבעיות בנושא שירותי מידע, מוצע בזאת להשוות את מעמד שירותי המידע למעמד שירותי הבידור, היינו קווי הטלפון ייחסמו לשירות זה, אלא אם כן יבקשו מפורשות לחברם לשירות.
