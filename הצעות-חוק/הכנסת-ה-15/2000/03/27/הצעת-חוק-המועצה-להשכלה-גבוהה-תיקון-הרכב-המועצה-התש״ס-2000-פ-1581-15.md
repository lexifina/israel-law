הצעת חוק המועצה להשכלה גבוהה (תיקון - הרכב המועצה), התש”ס-2000

|בחוק המועצה להשכלה גבוהה, התשי"ח-1958[1] (להלן – החוק העיקרי) בסעיף 4א, בסופו יבוא "וכן לנציגי     |1.     |תיקון סעיף 4א   |
|העולים כאמור בסעיף 4ב."                                                                            |       |                |
|בחוק העיקרי, אחרי סעיף 4א  יבוא:                                                                   |2.     |הוספת סעיף 4ב   |
|מספר נציגי העולים במועצה ישתנה פעם בחמש שנים בתחילת תקופת הכהונה של כל   |4ב.    |"נציגי העולים    |       |                |
|מועצה; השר יקבע את מספר נציגי העולים במועצה לפי היחס שבין הסטודנטים עולים|       |                 |       |                |
|לבין שאר הסטודנטים במוסדות להשכלה גבוהה בישראל."                         |       |                 |       |                |

דברי - הסבר

הצעת החוק הנוכחית באה להסדיר את ייצוגם של נציגי העולים במועצה להשכלה גבוהה.

לא פעם מתעוררות בעיות בהן מעורבים סטודנטים עולים (שמספרם אינו מועט), והממסד ניצב חסר אונים מול בעיות אלה. לכן, קיים צורך בהסדרת נציגות הולמת של העולים במועצה להשכלה גבוהה, וכך – נכשיר כלים להתמודדות של המוסדות להשכלה גבוהה עם בעיותיהם של סטודנטים עולים.
