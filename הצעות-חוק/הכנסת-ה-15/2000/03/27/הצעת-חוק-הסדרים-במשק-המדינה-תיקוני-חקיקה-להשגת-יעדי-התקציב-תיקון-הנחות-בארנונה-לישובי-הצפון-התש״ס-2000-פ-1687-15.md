הכנסת החמש-עשרה

|הצעת חוק של חבר הכנסת איוב קרא                                        |

הצעת חוק הסדרים במשק המדינה (תיקוני חקיקה להשגת יעדי התקציב) (תיקון - הנחות בארנונה לישובי הצפון),

 התש”ס-2000

|בחוק הסדרים במשק המדינה (תיקוני חקיקה להשגת יעדי התקציב), התשנ"ג-1992[1],  בסעיף 12, בסופו יבוא:   |1.     |תיקון סעיף 12   |
|על אף האמור בסעיף זה,  יקבעו השרים הנחה בשיעור של 50% בתשלומי ארנונה כללית לדירות מגורים   |"(ד)   |       |                |
|ולעסקים בישובי גבול הצפון, לעניין סעיף קטן זה, "ישובי גבול הצפון" – ישובים המצויים בקו     |       |       |                |
|העימות, כפי שקבעו השרים."                                                                  |       |       |                |

דברי - הסבר

תושבי הצפון אשר נמצאים על גבול הצפון סובלים חדשות לבקרים מהתקפות טילים אשר מאלצות אותם לרדת למקלטים. דבר זה פוגם באיכות חייהם ובעסקיהם, לכן מוצע בזאת להפחית מתשלום הארנונה שהם משלמים לעיר.

מוצע בזאת להפחית ב-50% את הארנונה לדירות מגורים ועסקים אשר נמצאים בקו העימות בצפון.
