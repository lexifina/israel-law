|2. בסעיף 5וא לחוק העיקרי, בסופו יבוא:                                                                   |תיקון סעיף 15א    |
|"(ו) מפלגה או מפלגות, שהגישו רשימת מועמדים ומעוניינות לשדר תעמולת                                       |                  |
|בחירות בטלוויזיה לפי חוק זה, יפקידו בועדת הבחירות המרכזית עד היום ה-30                                  |                  |
|שלפני יום הבחירות ערבות בנקאית על סך 200,000 שקלים חדשים; תוקף ערבות                                    |                  |
|כאמור יהיה עד שבעה ימים לאחר פרסום תוצאות הבחירות.                                                      |                  |
|(ז) בלי לפגוע בהוראות סעיף קטן (ד), יושב ראש ועדת הבחירות המרכזית לא יאשר                               |                  |
|משדרי תעמולה או יורה על חילוט הערבות או חלק ממנה בהתקיים אחר מאלה, לפי                                  |                  |
|הענין:                                                                                                  |                  |
|(ו) הוא נובח כי שידורי התעמולה מטעם מפלגה או מפלגות קוראים או                                           |                  |
|ממליצים לבוחרים להצביע בעבור רשימת מועמדים שהוגשה על ידי מפלגה או                                       |                  |
|מפלגות אחרות;                                                                                           |                  |
|(2) הוא נוכח כי שידורי התעמולה לא נועדו לשכנע את הבוחרים להצביע                                         |                  |
|בעבור רשימת מועמדים כלשהי;                                                                              |                  |
|(3) כל המועמדים ברשימת המועמדים התפטרו לפני הבחירות.                                                    |                  |
|(ח) ויתרו מפלגה או מפלגות שהגישו רשימת מועמדים, על זמן ؀ࠂࠈࠊࠎࠒשידור לפי סעיף                             |                  |
|קטן (ב) יפקידו ערבות בסכום הקטן מהסכום הנקוב בסעיף קטן (ו), באותו היחס שבין                             |                  |
|זמן השידור שלו הן זכאיות לפי סעיף קטן (ב) לבין זמן השידור שאותו יקבלו                                   |                  |
|בפועל.                                                                                                  |                  |
|(ט) סכום הערבות הבנקאית הנקוב בסעיף קטן (ו), יעודכן בהתאם לעליית מדד                                    |                  |
|המחירים לצרכן, שמפרסמת הלשכה המרכזית לסטטיסטיקה."                                                       |                  |
