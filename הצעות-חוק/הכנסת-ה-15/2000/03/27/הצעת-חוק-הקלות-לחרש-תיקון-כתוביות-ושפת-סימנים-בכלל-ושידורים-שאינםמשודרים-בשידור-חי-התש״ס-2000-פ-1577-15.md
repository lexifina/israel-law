|הצעת חוק של חבר הכנסת מאיר שטרית                                      |

הצעת חוק הקלות לחרש (תיקון - כתוביות ושפת סימנים בכלל ושידורים שאינם משודרים בשידור חי), התש”ס-2000

|בחוק הקלות לחרש, התשנ"ב - 1992[1] בסעיף 1, במקום הסיפה המתחילה במילים "בחוק הבזק, התשמ"ב-1982"     |1.     |תיקון סעיף 1    |
|יבוא: "בחוק הבזק,התשמ"ב-1982 –                                                                     |       |                |
|ישדרו בליווי כתוביות מסך בעברית – בשידורים בעברית, וכתוביות מסך בערבית – בשידורים בערבית, |(1)    |       |                |
|או בתרגום לשפת הסימנים את כלל השידורים בעברית ובערבית, שאינם משודרים בשידור חי;           |       |       |                |
|ישדרו שתי תוכניות חדשות בשבוע לפחות, שילוו בשפת הסימנים."                                 |(2)    |       |                |
|                                                                                          |       |       |                |

דברי - הסבר

רוב התוכניות המשודרות בטלוויזיה אינם מלוות בכתוביות לחרשים, ביניהם התוכניות שאינם משודרות בשידור חי. עובדה זו מונעת מחרשים ליהנות מהתוכניות הללו, וזאת על אף שהם מחויבים בתשלום אגרת טלוויזיה.

הצעת החוק מחייבת להוסיף לכל תוכנית שאיה משודרת בשידור חי כתוביות על מנת שגם החרשים יוכלו ליהנות משידורי טלוויזיה.
