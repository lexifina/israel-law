|מתפרסמת בזה הצעת חוק של חבר כנסת מטעם ועדת הפנים ואיכות הסביבה של הכנסת:                                                 |
|הצעת חוק שמירת הניקיון (תיקון מס' 6) (הרחבת סמכות למתן צווי ניקוי),                                                      |
|התש"ס-2000*                                                                                                              |
|1. בחוק שמירת הניקיון, התשמ"ד-1984 1,  בסעיף גוב -                                                   |תיקון סעיף 13ב     |
|(1) אחרי סעיף קטן (א) יבוא:                                                                          |                   |
|"(א1)(1) נוכח ראש רשות מקומית או מי שהוא הסמיך לענין זה, כי הושלכה                                   |                   |
|פסולת או פסולת בנין ברשות הרבים או כי לוכלבה רשות הרבים, בתחום                                       |                   |
|שיפוט הרשות המקומית, וטרם הוגש כתב אישום ולא הופעלה הסמכות                                           |                   |
|כאמור בסעיף קטן (א), רשאי הוא לצוות כאמור בסעיף קטן (א) על מי                                        |                   |
|שהשליך את הפסולה או על מי שלכלך את רשות הרבים או על בעל הנכס                                         |                   |
|שבו הושלכה הפסולת-, אין בהוראות סעיף קטן זה כרי לגרוע מסמכותו של                                     |                   |
|השר לאיכות הסביבה, או של מי שהוא הסמיך לענין זה לצוות על הרשות                                       |                   |
|המקומית, באמור בסעיף קטן (א) באותו ענין;                                                             |                   |
|(2) ניתן לרשות מקומית צו לפי הוראות סעיף קטן (א), אין בהוצאת צו על                                   |                   |
|ידי הרשות המקומית לפי הוראות סעיף קטן זה, באותו ענין, כדי לגרוע                                      |                   |
|מחובתה למלא אחר הוראות הצו שניתן לה;";                                                               |                   |
|(2) בסעיף קטן (ב), ברישה, אחרי "לענין זה"- יבוא "או ראש הרשות המקומית, או מי                         |                   |
|שהוא הסמיך לענין זה";                                                                                |                   |
|(3) בסעיף קטן (ג), אחרי "מי שהשר ؀ࠂࠈלאיכות הסביבה" יבוא "או ראש רשות                                 |                   |
|מקומית,".                                                                                            |                   |

|דברי הסבר                                                                                                                  |
|זאת רק כאשר השר לאיכות הסביבה לא הוציא צו מכוח                |סעיף 13ב לחוק שמירת הניקיון, התשמ"ד-984ו,                    |
|סמכותו, באותו ענין.                                           |קובע כי השר לאיכות הסביבה, או מי שהסמיך לשם כך,              |
|כן מוצע להבהיר כי אין במתן הסמכות לראש                        |רשאי להוציא צו לניקוי פסולת ומשלא קוים רשאי הוא              |
|הרשות המקומית כדי לגרוע מסמכותו של השר לאיכות                 |לבצע את הנדרש על פי הצו.                                     |
|הסביבה להוציא צווים בכל עת, ואולם מובן כי במצב זה             |מוצע להסמיך גס את ראש הרשות המקומית אשר                      |
|של סמכות מקבילה יידרשו תיאומים לרבות לענין מועדי              |בתחומה מצויה הפסולת להוציא צו באמור, שכן לעתים               |
|ביצוע הצווים.                                                 |מתעורר צורך מיידי להביא לפינויה של פסולת, ואולם              |
|חבר הכנסת אמנון רובינשטיין                                    |                                                             |
