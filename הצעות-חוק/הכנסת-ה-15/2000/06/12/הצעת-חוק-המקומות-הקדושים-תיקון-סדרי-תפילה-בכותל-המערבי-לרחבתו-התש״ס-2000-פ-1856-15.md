הצעת חוק המקומות הקדושים (תיקון - סדרי תפילה בכותל המערבי לרחבתו), התש”ס-2000

|בחוק המקומות הקדושים, התשכ"ז-1967[1], אחרי סעיף 2 יבוא:                                            |1.     |הוספת סעיף 2א   |
|בחוק זה –                                                       |(א)    |2א.    |"הסדרי תפילה     |       |                |
|"רחבת התפילה של הכותל המערבי" – רחבת התפילה של הכותל המערבי     |       |       |בכותל המערבי     |       |                |
|המחולקת לעזרת נשים ועזרת גברים, ונושקת לכותל המערבי;            |       |       |                 |       |                |
|"תשמישי קדושה" – לרבות כיפות, טליתות, ספרי תורה או שופרות.      |       |       |                 |       |                |
|התפילה בעזרת הנשים ובעזרת הגברים ברחבת התפילה של הכותל המערבי   |(ב)    |       |                 |       |                |
|מותרת לכל איש או אישה לתפילת יחיד או רבים, גברים או נשים;       |       |       |                 |       |                |
|המתפללים, נשים או גברים, ברחבת התפילה של הכותל המערבי, בין      |       |       |                 |       |                |
|בקבוצה ובין ביחידות, רשאים להשתמש בתשמישי קדושה בעת תפילתם."    |       |       |                 |       |                |

דברי - הסבר

מעמדו של הכותל המערבי לא מוסדר בחוק המקומות הקדושים אלא בתקנות בלבד; חיוני להבטיח את מעמדו של הכותל המערבי כסמל המאחד את העם היהודי במדינת ישראל גברים ונשים כאחד. לפיכך, מוצע לקבוע כי התפילה ליד הכותל המערבי תותר לגברים ולנשים ביחידות או בקבוצות.
