|מתפרסמת בזה הצעת חוק-יסוד של חבר הכנסת מטעם ועדת החוקה חוק ומשפט שלי הכנסת:                                               |
|הצעת חוק-יסוד: משק המדינה (תיקון מס' 7) (חוק הסדרים                                                                       |
|במשק המדינה)*                                                                                                             |
|1. בחוק-יסוד: משק המדינה 1 , אחרי סעיף 3ב יבוא:                                                      |הוספת סעיף גג       |
|3ג. (א) חוק שמטרתו השגת יעדי תקציב המדינה לשנת כספים פלונית                         |"חוק הסדרים     |                    |
|(להלן - חוק הסדרים), יהא בתוקף עד תום אותה שנת כספים.                               |במשק המדינה     |                    |
|(ב) חוק הסדרים לא יכלול כל הוראה שאינה קשורה קשר ישיר                               |                |                    |
|להוצאות הממשלה כאמור בסעיף 3(א)(2), או למקורות המימון של                            |                |                    |
|התקציב, כאמור בסעיף 3(ב)(4).                                                        |                |                    |
|(ג) כל הוראה בהצעת, חוק הסדרים הבאה לבטל או לתקן חוק,                               |                |                    |
|תועבר על ידי הכנסת לאותה ועדה מועדותיה שהכינה את אותו חוק                           |                |                    |
|לקריאה שניה ולקריאה שלישית."                                                        |                |                    |

|דברי הסבר                                                                                                                    |
|מקורו של הנוהג בתכנית חירום כלכלית שהוצעה                    |חוק ההסדרים במשק המדינה, המוגש מרי שנה על                      |
|בשנת 1985,עקב המצב הכלכלי, שהיה קיים אז ואשר                 |ידי הממשלה כהצעת חוק לכנסת, בולל התייחסות                      |
|אינה רלוונטית זה שנים רבות.                                  |לחוקים רבים באופן הבא לשנותם או לבטלם. הדבר                    |
|כמו כן, בשל הצורך בסמיכות זמנים בהגשת חוק                    |נעשה באופן המקשה על קיום דיון עניני, תוך עקיפת                 |
|ההסדרים במשק המדינה וחוק התקציב, מוגשת הצעת                  |רצונה של הכנסת ומניעת דיון בוערות הכנסת אשר                    |
|חוק ההסדרים זמן קצר לפני שהיא עוברת את כל שלבי               |חוקקו את החוקים המקוריים ואשר נקבעו בתקנון                     |
|הקריאות בכנסת.                                               |הכנסת כמוסמכות לטפל בחוקים אלה.                                |
|הצורך לשמור על עצמאותה של הרשות המחוקקת,                     |נוהג זה, שהשתרש בפעולת הממשלה, פוגע פגיעה                      |
|למנוע קבלת החלטות וקביעת סדר העדיפויות הלאומי                |חמורה בעצמאות הכנסת ועושה פלסתר את הליכי                       |
|לא על ידי הכנסת ולשמור על ؀ࠂࠈסמכותם הטבועה של                |עבודתה, כפי שנקבעה בתקנון הכנסת.                               |
|חבוי הכנסת, מחייב קבלת הצעת חוק זו.                          |                                                               |
|חבר הכנסת חיים כץ                                            |                                                               |
