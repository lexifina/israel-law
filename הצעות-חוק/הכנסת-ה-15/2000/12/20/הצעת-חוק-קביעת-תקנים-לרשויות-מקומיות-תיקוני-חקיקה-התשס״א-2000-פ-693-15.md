|הצעת חוק קביעת תקנים לרשויות מקומיות (תיקוני חקיקה),                                                                          |
|התשס"א-2000*                                                                                                                  |
|1. בפקודת העיריות', בפרק תשיעי, לפני סעיף 167 יבוא:                                                      |תיקון פקודת         |
|                                                                                                         |העיריות             |
|166א. (א) שר הפנים, באישור ועדת הפנים ואיכות הסביבה של                                 |"קביעת תקנים      |                    |
|הכנסת, יקבע תקנים להעסקת עובדים בעיריה (להלן - התקנים).                                |                  |                    |
|(ב) העסקת עובדים בעיריה תיעשה על פי התקנים בלבד-, לענין זה,                            |                  |                    |
|"העסקה" - לרבות באמצעות חברות כוח אדם."                                                |                  |                    |
|2. בפקודת המועצות המקומיות2, אחרי סעיף 35ב יבוא:                                                         |תיקון פקודת         |
|                                                                                                         |המועצות             |
|                                                                                                         |המקומיות            |
|35ג. (א) שר הפנים, באישור. ועדת הפנים ואיכות הסביבה של הכנסת,                          |-קביעת תקנים      |                    |
|יקבע תקנים להעסקת עוברים במועצה המקומית (להלן - התקנים).                               |                  |                    |
|(ב) העסקת עובדים במועצה המקומית תיעשה על פי התקנים                                     |                  |                    |
|בלבד; לענין זה, "העסקה" - לרבות באמצעות חברות כוח אדם."                                |                  |                    |

|דברי הסבר                                                                                                                     |
|מוצע לתקן את פקודת העיריות ואת פקודת                           |פקודת העיריות ופקודת המועצות המקומיות אינן                   |
|המועצות המקומיות, בך ؀ࠂࠈשייקבע בחקיקה ראשית כי שר              |קובעות תקנים להעסקת עובדים. כיום מועסקים                     |
|הפנים יקבע תקנים להעסקת עובדים ברשויות                         |ברשויות המקומיות עובדים רבים מהמספר הנדרש                    |
|המקומיות, וכי תקנים אלה יחייבו את ראשי הרשויות.                |לביצוע העבודה, ובשל הבעיות התקציביות הקשות,                  |
|/                                                              |והגרעונות ההולכים וגדלים בקופות הרשויות, יש                  |
|חברי הכנסת: גדעון עזרא, מיכאל איתן,                            |לצמצם ככל האפשר תופעה זו.                                    |
