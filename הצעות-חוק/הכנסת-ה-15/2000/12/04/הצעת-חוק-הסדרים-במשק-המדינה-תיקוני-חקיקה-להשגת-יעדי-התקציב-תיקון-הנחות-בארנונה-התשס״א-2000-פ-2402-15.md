(תיקון - הנחות בארנונה), התשס”א-2000

|בחוק הסדרים במשק המדינה (תיקוני חקיקה להשגת יעדי התקציב), התשנ"ג-1992[1], בסעיף 12, אחרי סעיף קטן  |1.     |תיקון סעיף 12   |
|(ב) יבוא:                                                                                          |       |                |
|בתקנות לפי סעיף קטן (ב), לא יקבע שר הפנים הנחה מסכום הארנונה הכללית המוטלת על מחזיק בנכס|"(ב1)     |       |                |
|המשמש למגורים לפי מספר הנפשות המתגוררות איתו בנכס, בין כמבחן יחיד ובין בצירוף למבחנים   |          |       |                |
|אחרים."                                                                                 |          |       |                |

דברי - הסבר

תיקון שהתקבל לאחרונה בחוק הביטוח הלאומי [נוסח משולב], התשנ"ה-1995, הגדיל בצורה משמעותית את תשלומי הקצבה עבור הילדים החמישי, השישי והלאה. לאור האמור אין עוד מקום ליתן הנחה בארנונה על בסיס מספר הנפשות המתגוררות בנכס, ולכן מוצע כי שר הפנים לא יהיה רשאי לקבוע הנחות לפי מבחן זה.
