|מתפרסמת בזה הצעת חוק של חבר הכנסת מטעם ועדת העבודה הרווחה והבריאות:                                                          |
|הצעת חוק לתיקון פקודת מס הכנסה (תיקון מס' 127) (פטור לדמי הבראה),                                                            |
|התשס"א-2000*                                                                                                                 |
|1. בפקודת מס הכנסה [נוסח חדש]', בסעיף 9 אחרי פסקה (27) יבוא:                                            |תיקון סעיף 9         |
|"(28) (א) דמי הבראה המשולמים לעובד מאת מעביד מדי שנה - בהתאם לתקרת                                      |                     |
|דמי ההבראה ומכסת ימי ההבראה הקבועים לענין זה, בהסכמים שבין ארגון                                        |                     |
|העובדים המייצג את המספר הגדול ביותר של העובדים במדינה לבין ארגון                                        |                     |
|מעבידים שלדעת שר האוצר בהתייעצות עם שר העבודה והרווחה ובאישור                                           |                     |
|ועדת העבודה הרווחה והבריאות של הכנסת הוא ארגון יציג ונוגע בדבר, כפי                                     |                     |
|שיעודכנו מעת לעת, ובלבד שהסכום לא יעלה על 3,000 שקלים חדשים.                                            |                     |
|(ב) פטור ממס לפי פסקת משנה (א), יחול על רמי הבראה שזכאי להם העובד,                                      |                     |
|אם השתמש בהם לצורך נופש או הבראה בישראל והעביר אישור על כך לידי                                         |                     |
|המעביד.                                                                                                 |                     |
|(ג) שר האוצר, בהתייעצות עם שר העבודה והרווחה ובאישור ועדת העבודה                                        |                     |
|הרווחה והבריאות של הכנסת, יקבע הוראות בענין אישור כאמור בפסקה זו."                                      |                     |
