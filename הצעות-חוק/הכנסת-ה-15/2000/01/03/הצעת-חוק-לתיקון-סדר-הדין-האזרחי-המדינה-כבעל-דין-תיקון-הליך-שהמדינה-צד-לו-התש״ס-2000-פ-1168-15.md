הצעת חוק לתיקון סדר הדין האזרחי (המדינה כבעל - דין) (תיקון - הליך שהמדינה צד לו), התש”ס-2000

|בחוק סדר הדין האזרחי (המדינה כבעלת דין), התשי"ח-1958 [1], סעיף 4 יסומן (א) ואחריו יבוא:            |1.     |החלפת סעיף 4    |
|היועץ המשפטי לממשלה, או עובד אחר של פרקליטות המדינה שהיועץ המשפטי לממשלה הטיל עליו ליצג את|"(ב)   |       |                |
|המדינה בענין מסוים, חייב לפעול כפי שהוטל עליו ולהגן על עמדת הממשלה, או משרדיה, באותו ענין,|       |       |                |
|ובלבד שהדבר יהיה במסגרת המדיניות הכללית של הממשלה, או בהתאם להחלטתה, או בהתאם להחלטת שר   |       |       |                |
|משריה בתחום פעילות משרדו".                                                                |       |       |                |
|עובד פרקליטות המדינה המסרב לקבל על עצמו יצוג של המדינה בניגוד למה שהוטל עליו על פי האמור  |(ג)    |       |                |
|בסעיף קטן (ב), רואים אותו כאילו הגיש בקשה כחוק להתפטר מתפקידו בשירות המדינה."             |       |       |                |

דברי - הסבר

לאחרונה ארע שפרקליטות המדינה סרבה להגן על החלטות שונות של הממשלה ועל מדיניותה בפני בתיהמ"ש, ובכך נטלה לעצמה סמכות לא לה.

מוצע, לתקן את החוק באופן שסירוב כזה יחשב כהתפטרות משירות המדינה כדי למנוע תופעות כאמור.

הצעה זהה בעיקרה הונחה על שולחן הכנסת, ומספרה פ/580.
