|הצעת חוק של חבר הכנסת מקסים לוי                                       |

הצעת חוק שוויון ההזדמנויות בעבודה (תיקון - זכויות הורה), התש”ס-2000

|בחוק שוויון ההזדמנויות בעבודה, התשמ"ח-1988[1], בסעיף 4, בסעיף קטן (א), הסיפה המתחילה במילים "אם    |1.     |תיקון סעיף 4    |
|התקיים בו" – תימחק.                                                                                |       |                |
|                                                                                                                             |
|דברי  הסבר                                                                                                                   |
|                                                                                                                             |
|בניגוד לעקרון חוק שוויון ההזדמנויות בעבודה, שאוסר על מעביד להפלות בין עובדיו מחמת מינם, התיר המחוקק, בסעיף 4 לחוק, הפליה לרעה|
|של עובד בכל הקשור לזכויות הורה.                                                                                              |
|                                                                                                                             |
|זכות העובד להעדר מהעבודה בשל מחלת ילד, ו/או ליום עבודה מקוצר, ו/או להשתמש בשרותי מעון שהמעביד מעמיד לרשות ילדי עובדים וכן    |
|להשתתפות המעביד בעלות החזקת ילדו במעון. כל זאת בתנאי שאשת העובד עובדת ולא נעדרה ממקום עבודתה מכח זכאויות אלו. לעומת זאת,     |
|לעובדת במקום עבודתו של אותו העובד הזכות אינה מותנית בדבר.                                                                    |
|                                                                                                                             |
|עובד, שאשתו אינה עובדת או שלחילופין במקום עבודתה אין סידורי מעון או השתתפות מעביד בהחזקת הילד במעון, אינו זכאי לקבלת זכויות  |
|הורה אלה. העובד לא יוכל להנות מיום עבודה מקוצר אם אשתו עובדת כעצמאית ולא יוכל לקחת את ילדו לטיפול רפואי בשל מחלתו אם אשתו    |
|אינה עובדת.                                                                                                                  |
|                                                                                                                             |
|מאחר וכאמור, סעיף 2 לחוק אוסר על מעביד להפלות בין עובדיו מחמת מינם ובהתייחס לתכליתו החקיקתית של חוק שוויון ההזדמנויות בעבודה |
|ועל עקרונות השוויון בפסיקה, הרי שאין להבחין בין עובד שאשתו זכאית במקום עבודתה לתוספת מעונות ואין היא מממשת אותה לבין עובד    |
|שאשתו עובדת, אולם היא אינה זכאית במקום עבודתה לתוספת מעונות.                                                                 |
|                                                                                                                             |
