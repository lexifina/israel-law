הצעת חוק ההוצאה לפועל (תיקון - הודעה על סיום הליכים), התש”ס-2000

|בחוק ההוצאה, התשכ"ז-1967[1], בסעיף 8, בסופו יבוא:                                                  |1.     |תיקון סעיף 8    |
|הופסק, בוטל או הסתיים הליך פלוני כנגד חייב, תימסר על כך הודעה לחייב; הוטל עיקול על נכסי    |"(ד)   |       |                |
|החייב, הנמצאים בידי צד שלישי והופסק ההליך כאמור, תימסר על כך הודעה לצד השלישי."            |       |       |                |
|                                                                                                                             |
|                                                                                                                             |
|דברי  הסבר                                                                                                                   |
|                                                                                                                             |
|                                                                                                                             |
|על פי המצב המשפטי היום, לא מוטלת על רשויות ההוצאה לפועל חובה לידע חייב אם וכאשר נסתיימו ההליכים נגדו. יתרה מזו, לעיתים לא    |
|נמסרת על כך הודעה גם לצד שלישי (כגון בנק). במצב כזה, עלול החייב להיקלע לקשיים ביורוקרטיים כאשר יתברר, לעיתים שנים לאחר תום   |
|ההליכים נגדו, כי צד שלישי פלוני טרם יודע כי ההליכים הסתיימו.                                                                 |
|                                                                                                                             |
|מוצע אפוא להטיל חובה על רשויות ההוצאה לפועל ליידע את החייב כמו גם צדדים שלישיים (אם יש כאלה), על תום הליכי ההוצאה לפועל,     |
|והסרת מגבלות כלשהן שנוצרו כתוצאה מן ההליכים.                                                                                 |
