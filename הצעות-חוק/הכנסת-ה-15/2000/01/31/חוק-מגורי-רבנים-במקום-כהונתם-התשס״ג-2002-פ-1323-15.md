הצעת חוק מגורים במקום כהונה (דיינים ורבנים), התש”ס-2000

|בחוק זה:                                                                                           |1.     |הגדרות          |
|"דיין" - כהגדרתו בחוק הדיינים, התשט"ו-1955[1];                                                     |       |                |
|"רב" - רב עיר כהגדרתו בחוק הרבנות הראשית לישראל, התש"ם-1980[2] ומי שמונה לרב מקומי כהגדרתו בחוק    |       |                |
|שירותי הדת היהודיים (נוסח משולב), התשל"א-1971[3];                                                  |       |                |
|"מקום מגורים קבוע ועיקרי" - מקום בו מתגורר המכהן כרב או דיין ומשפחתו במהלך רוב ימות השנה.          |       |                |
|מקום מגוריו הקבוע והעיקרי של דיין יהיה במקום כהונתו.                                 |(א)          |2.     |מגורים במקום    |
|                                                                                     |             |       |כהונה -דיין     |
|דיין שמקום מגוריו הקבוע והעיקרי אינו במקום כהונתו, תוקף מינויו כדיין יפוג שנה מיום   |(ב)          |       |                |
|קבלת המינוי באם לא מילא אחר הוראות סעיף קטן (א); מינוי הדיין יפוג לאחר שניתנה לו     |             |       |                |
|הזדמנות סבירה לטעון בעניין לפני הועדה למינוי דיינים.                                 |             |       |                |
|לועדה למינוי דיינים ברוב של שבעה חברים הסמכות לאשר את השהיית המעבר לתקופה שתיראה לה. |(ג)          |       |                |
|מקום מגוריו הקבוע והעיקרי של רב יהיה במקום כהונתו.                                   |(א)          |3.     |מגורים במקום    |
|                                                                                     |             |       |כהונה - רב      |
|רב שמקום מגוריו הקבוע והעיקרי אינו במקום בו הוא מכהן תוקף מינויו יפוג שנה מיום קבלת  |(ב)          |       |                |
|המינוי אם לא מילא אחר הוראות סעיף קטן (א); מינוי הרב יפוג לאחר שניתנה לו הזדמנות     |             |       |                |
|סבירה לטעון בעניין לפני המנהל הכללי של הרבנות הראשית לישראל.                         |             |       |                |
|למנהל הכללי של הרבנות הראשית לישראל אין סמכות לעכב בטלות המינוי.                     |(ג)          |       |                |
|לעניין דיינים ורבנים שמכהנים בפועל בעת כניסתו של חוק זה לתוקף, יחשב כיום המינוי שלהם היום בו נכנס  |4.     |דיינים ורבנים   |
|החוק לתוקף.                                                                                        |       |מכהנים          |
|                                                                                                                             |
|                                                                                                                             |
|דברי  הסבר                                                                                                                   |
|                                                                                                                             |
|עד כה התחייבו הדיינים בחתימת ידם, טרם מינויים על ידי נשיא המדינה, להתגורר במקום כהונתם. בפועל חלק ניכר מן הדיינים לא עמדו    |
|בהתחייבותם ולא מתגוררים במקום כהונתם. ומאידך אין שום מכשיר בידי מנהל בתי בדין לאכוף את ההתחייבות.                            |
|לכן מוצע כאן לקבוע בחוק את החובה להתגורר במקום הכהונה, וכן לאפשר לועדה למינוי דיינים ברוב של שבעה חברים מכשיר לאכוף את החוק  |
|באמצעותו, ובמקרים מסויימים לדחות את המעבר למקום הכהונה.                                                                      |
|                                                                                                                             |
|באופן טבעי ישנה חובה לרב עיר או רב מקומי לגור במקום כהונתו, שכן מילוי חובתו לקהילתו ולמשרתו דורש זאת. עד היום לא נהגו כך     |
|רבנים רבים, ולמרות נסיונותיה של הרבנות הראשית לישראל להסדיר את העניין, עדיין ישנם רבנים אשר אינם מתגוררים במקום כהונתם.      |
|לכן מוצע כאן לקבוע בחוק חובה זו, וכן לאפשר למנהל הכללי של הרבנות הראשית לישראל לאוכפה על מי שאינו פועל על פי החוק.           |
