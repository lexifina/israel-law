הצעת חוק העונשין (תיקון - טיפול רפואי לעברייני מין), התש”ס-2000

|בחוק העונשין התשל"ז-1977[1], (להלן – החוק העיקרי), בסעיף 49 (ב), בסופו יבוא "למעט מי שנידון  למאסר |1.     |תיקון סעיף 49   |
|בגין עבירות-מין."                                                                                  |       |                |
|בסעיף 51 לחוק העיקרי, אחרי סעיף קטן (ג) יבוא:                                                      |2.     |תיקון סעיף 51   |
|לא תמליץ ועדת שחרורים על שחרור אסיר שמרצה עונש מאסר בגין עבירות-מין, לפי סעיף 49(ב), אלא   |"(ג1)  |       |                |
|לאחר שניתן לאסיר טיפול רפואי מניעתי,שיקבע על-ידי שר הבריאות בתקנות."                       |       |       |                |
|                                                                                                                             |
|דברי  הסבר                                                                                                                   |
|                                                                                                                             |
|לאחרונה חלה עלייה מדאיגה במספר עברייני המין בישראל. הד תקשורתי נרחב ניתן ל'אנס הסידרתי' מתל-אביב שהטיל אימתו לאורך תקופה     |
|ארוכה על נשים רבות באזור מרכז הארץ.                                                                                          |
|תיקון החוק המוצע ימנע מאסיר, שהורשע בעבירות מין, שחרור מוקדם אלא אם קיבל טיפול רפואי מניעתי שיקבע בתקנות על-ידי שר הבריאות.  |
