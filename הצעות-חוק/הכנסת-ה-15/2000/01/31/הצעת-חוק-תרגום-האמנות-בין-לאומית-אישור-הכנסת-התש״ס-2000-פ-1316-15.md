|הצעת חוק של חבר הכנסת יוסי כץ                               |

הצעת חוק תרגום האמנות בין-לאומיות (אישור הכנסת),

 התש”ס-2000

|בחוק זה -                                                                                          |1.     |הגדרות          |
|"אמנה" -  הסכם בין לאומי שנכרת בכתב בין מדינת ישראל לבין מדינת חוץ או ארגון בין מדינתי הכפוף למשפט |       |                |
|הבינלאומי יהיה כינויו אשר יהיה.                                                                    |       |                |
|אמנה שהונחה על שולחן הכנסת לצורך קבלת אישור המליאה, תהיה בשפת המקור ובתרגום לעברית בנוסח שיאושר על |2.     |תרגום אמנה      |
|ידי היועץ המשפטי לממשלה.                                                                           |       |                |
|                                                                                                                             |
|                                                                                                                             |
|דברי הסבר                                                                                                                    |
|                                                                                                                             |
|פרשת אישור הסכם וואי על ידי הכנסת חשפה חוסר בהירות במערכת החוקים של מדינת ישראל.                                             |
|                                                                                                                             |
|מוצע, איפוא, להבהיר בחקיקה שכל אמנה או הסכם המובאים לאישור הכנסת חייבים להיות בשפת המקור וכן בשפה העברית.                    |
