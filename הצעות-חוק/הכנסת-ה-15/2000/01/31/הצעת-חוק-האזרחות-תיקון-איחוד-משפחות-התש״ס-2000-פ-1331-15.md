הצעת חוק האזרחות (תיקון - איחוד משפחות), התש”ס-2000

|בחוק האזרחות, התשי"ב-1952[1], בסעיף 7 -                                                            |1.     |תיקון סעיף 7    |
|במקום "יכול השני לקבל" יבוא "יקבל השני רשיון לישיבת קבע באופן מיידי, וכעבור שנה יקבל";     |(1)    |       |                |
|בסופו יבוא "שר הפנים לא יסרב לבקשת התאזרחות לפי סעיף זה אלא אם היתה הבקשה מבוססת על תרמית".|(2)    |       |                |
|                                                                                                                             |
|דברי  הסבר                                                                                                                   |
|                                                                                                                             |
|על פי המצב החוקי הקיים, מתן מעמד של תושבות קבע ואזרחות לבן - או בת זוג של אזרח ישראלי תלוי ברצונו הטוב של שר הפנים ולעיתים   |
|קרובות מסרב משרד הפנים להעניק אזרחות למבקש מסיבות שונות ומשונות ובעיקר בשל השתייכותו הלאומית של המבקש.                       |
|                                                                                                                             |
|הצעת החוק מחייבת מתן רשיון לישיבת קבע לכל מבקש ואזרחות בעבור שנה מיום קבלת אישור לתושבות הקבע על מנת לאחד את המשפחות ולחסוך  |
|מהן סבל מיותר.                                                                                                               |
|                                                                                                                             |
|הצעת חוק הנ"ל באה כדי לתקן מצב עגום זה כך שזכות הסירוב של שר הפנים למתן ישיבת קבע ואזרחות תוגבל למקרים מיוחדים המוגדרים בחוק.|
|                                                                                                                             |
|הצעות חוק דומות הונחו על שולחן הכנסת הארבע-עשרה ומספרה פ/1475, ועל שולחן הכנסת החמש-עשרה ומספרה פ/704.                       |
