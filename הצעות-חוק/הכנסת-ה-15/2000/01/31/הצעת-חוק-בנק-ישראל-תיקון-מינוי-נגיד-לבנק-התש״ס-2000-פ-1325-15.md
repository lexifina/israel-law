|הצעת חוק של חבר הכנסת מוחמד ברכה                                      |

הצעת חוק בנק ישראל (תיקון - מינוי נגיד לבנק), התש”ס-2000

|בחוק בנק ישראל התשי"ד-1954[1], (להלן - החוק העיקרי), בסעיף 8, במקום הסיפה המתחילה במילים "נשיא     |1.     |תיקון סעיף 8    |
|המדינה" יבוא:                                                                                      |       |                |
|"הממשלה על פי המלצת שר האוצר."                                                                     |       |                |
|בסעיף 9(ב) לחוק העיקרי, בסופו יבוא: "ויבצע את החלטותיה במסגרת מדיניותה הכלכלית.                    |2.     |תיקון סעיף 9    |
|                                                                                                                             |
|דברי  הסבר                                                                                                                   |
|                                                                                                                             |
|היות ומדיניות כלכלית הנה פועל יוצא וישיר של השקפת עולם פוליטית, הרי שמן הראוי להעניק לממשלה סוברניות מלאה בקביעת המדיניות    |
|הכלכלית בכללותה, הן הפיסקאלית והן המוניטרית.                                                                                 |
|                                                                                                                             |
|המצב הנוכחי לפיו קיימים שני מוקדי כוח כלכליים אינו מצב בריא ודמוקרטי, ובפרט לאור העובדה שהם אינם פועלים תמיד בהרמוניה ומתוך  |
|אחדות מטרה.                                                                                                                  |
|                                                                                                                             |
|על כן, מוצע בחוק זה שהנגיד יתמנה ע"י הממשלה ועל פי המלצת שר האוצר והוא יבצע את מדיניותה.                                     |
