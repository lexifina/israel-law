|מתפרסמת בזה הצעת חוק של חברי הכנסת מטעם ועדת החינוך והתרבות של הכנסת:                                                     |
|הצעת חוק הרשויות המקומיות (מנהל מחלקת חינוך), התשס"א-2000*                                                                |
|1. בחוק זה - .                                                                                         |הגדרות            |
|"מנהל מחלקת חינוך" - מי שעומד בראש מינהל, אגף או מחלקת חינוך ברשות מקומית,                             |                  |
|הבכיר שביניהם, ובלבד שבכל רשות מקומית יעמוד מנהל מחלקת חינוך אחד;                                      |                  |
|"רשות מקומית" - עיריה, מועצה מקומית או מועצה אזורית.                                                   |                  |
|2. בכל רשות מקומית ימונה מנהל מחלקת חינוך.                                                             |מינוי מנהל        |
|                                                                                                       |מחלקת חינוך       |
|3. מנהל מחלקת חינוך של רשות מקומית יהיה עובד הרשות המקומית ויחולו על דרך                               |תנאי עבודה        |
|מינויו ותנאי העסקתו ההוראות החלות על עובדי אותה רשות מקומית אלא אם כן נקבעה                            |                  |
|בדין הוראה אחרת לענין זה.                                                                              |                  |
|4. (א) לא ימונה ולא יכהן אדם כמנהל מחלקת חינוך אלא אם כן הוא בעל השכלה                                 |כשירות            |
|אקדמית, תעודת הוראה, ותק וניסיון מקצועי, ולאחר ששמע שר החינוך את נציגי מרכז                            |                  |
|השלטון המקומי בישראל והכל כפי שקבע בתקנות.                                                             |                  |
|(ב) מי שעומד בראש מחלקת חינוך ברשות המקומית ערב תחילתו של חוק זה, לא                                   |                  |
|יחולו עליו הוראות סעיף קטן (א).                                                                        |                  |
|5. לא יפוטר מנהל מחלקת חינוך ברשות מקומית במעמד קבוע, אלא לאחר שניתנה                                  |פיטורין           |
|הורעה ברין לכל חברי המועצה שדבר* הפיטורין יידון ؀ࠂࠈבאותה ישיבה ובהתקיים אחד                            |                  |
|מאלה:                                                                                                  |                  |
|(1) באישור מועצת הרשות ברוב חבריה;                                                                     |                  |
|(2) באישור שני שלישים מחברי המועצה שהשתתפו בדיון.                                                      |                  |
|6. שר החינוך יתקין תקנות ראשונות לפי סעיף 4 בתוך שישה חודשים מיום פרסומו של                            |תקנות             |
|חוק זה.                                                                                                |                  |

|דברי הסבר                                                                                                                  |
|ברומה לתפקידים אחרים ברשות המקומית כדוגמת                  |הצעה זו באה לעגן את מעמדו של מנהל מחלקת                        |
|מזכיר, גזבר, מהנדס, מפקח תברואה, מבקר, רופא ורופא          |חינוך כאחראי על מחלקת החינוך ברשות המקומית נובח                |
|וטרינר.                                                    |קשיי מעמדו של מנהל מחלקת חינוך ברשויות                         |
|יודגש כי אין בהצעה זו כדי לשנות את מעמדו                   |המקומיות השונות. מוצע לפיכך, כי שר החינוך יקבע                 |
|של ראש הרשות המקומית כראש החינוך ברשות                     |תנאי כשירות לתפקיד מנהל מחלקת חינוך ולשריין את                 |
|המקומית.                                                   |דרך הפיטורין של מנהל מחלקת חינוך ברשות המקומית,                |
|חברי הכנסת: זבולון אורלב, דוד אזולאי                       |                                                               |
|* הצעת חוק מס' פ/1304; הועברה לועדה ביום כ"ג בתמוז התש"ס (26 ביולי 2000).                                                  |
