התש”ס-2000

|בחוק זה -                                                                                          |1.     |הגדרות          |
|"רשות חינוך מקומית" -                                                                              |       |                |
|לגבי תחום-שיפוטה של רשות מקומית-אותה רשות מקומית; אולם רשאי השר לקבוע בצו שפורסם ברשומות, |(1)    |       |                |
|כי אדם או חבר-בני-אדם, המקיימים מוסד חינוך לגילאי לימוד חובה בתחום מועצה אזורית, יהיו רשות|       |       |                |
|חינוך מקומית נפרדת לגבי שטח המוסד שיוגדר בצו, אם ראה לעשות כן מטעמים מיוחדים, ולאחר שנתן  |       |       |                |
|למועצה האזורית הזדמנות לטעון טענותיה;                                                     |       |       |                |
|לגבי מושב, קבוצה או קיבוץ – ועד המושב, או מזכירות הקבוצה או הקיבוץ, לפי עניין; ושטח המושב,|(2)    |       |                |
|הקבוצה או הקיבוץ הוא תחום השיפוט של הועדה או המזכירות, לפי העניין;                        |       |       |                |
|לגבי שטח אחר – ועד שהוכר, או אדם שנתמנה, בידי השר, בצו שפורסם ברשומות, כרשות חינוך מקומית |(3)    |       |                |
|בשטח שתואר בצו, ואותו שטח הוא תחום השיפוט של אותו ועד או של אותו אדם, לפי העניין;         |       |       |                |
|"מנהל רשות חינוך" – מי שנתמנה להיות מנהל רשות חינוך מקומית;                               |       |       |                |
|"רשות מקומית" – עיריה או מועצה מקומית;                                                    |       |       |                |
|"השר" – שר החינוך;                                                                        |       |       |                |
|מנהל רשות חינוך יהיה מנהל מינהל חינוך או אגף או מחלקת חינוך ברשות מקומית.                          |2.     |מנהל רשות חינוך |
|מנהל רשות חינוך יהיה מי שנתמלאו בו:                                                                |3.     |תנאי כשרות      |
|                                                                                                   |       |לתפקיד          |
|הסמכה כבעל תואר שני במוסד מוכר;                                                           |(1)    |       |                |
|בעל תעודת הוראה או רשיון הוראה;                                                           |(2)    |       |                |
|בעל ניסיון לתקופה של חמש שנים לפחות במערכת החינוך.                                        |(3)    |       |                |
|מי שביום כניסתו לתוקף של חוק זה, משמש כמנהל רשות חינוך יראו אותו כאילו מונה לפי חוק זה, אף אם אינו |4.     |הוראות מעבר     |
|ממלא אחר תנאי הכשירות כמפורט בסעיף 3 ובלבד שישלים את כל הדרוש לקיומם של תנאי הכשירות, תוך שנתיים   |       |                |
|מיום כניסתו של חוק זה לתוקף.                                                                       |       |                |
|                                                                                                   |       |                |
|                                                                                                   |       |                |
|דברי  הסבר                                                                                                                   |
|                                                                                                                             |
|                                                                                                                             |
|נוכח קשיי מעמדו של מנהל רשות חינוך, באה הצעת חוק זו לעגן את מעמדו כבעל סמכויות הביצוע בתחום החינוך, בעוד שנשמר מעמדו של ראש  |
|הרשות המקומית כעומד בראש פירמידת החינוך, ולבסס תנאי כשירות שיאפשרו קבלה לעבודה של אנשי מקצוע שיתרמו לאיכות ויעילות מערכת     |
|החינוך המקומית.                                                                                                              |
