הצעת חוק עבודת נשים (תיקון - הארכת תקופת חופשת הלידה), התש”ס-2000

|בחוק עבודת נשים, התשי"ד-1954[1], בסעיף 6 -                                                         |1.     |תיקון סעיף 6    |
|במקום סעיף קטן (ב) יבוא:                                                                   |(1)    |       |                |
|חופשת הלידה היא ששה עשר שבועות ופריסתה לפני יום הלידה המשוער ואחריו תהא כרצון     |"(ב)   |       |       |                |
|העובדת.";                                                                         |       |       |       |                |
|בכל מקום, במקום "ששה עשר שבועות" יבוא "עשרים שבועות".                                      |(2)    |       |                |
|דברי  הסבר                                                                                                                   |
|                                                                                                                             |
|נשים רבות מתמודדות עם קשיים בחזרתן לעבודה לאחר הלידה. בהתאם לחוק הקיים אורך חופשת הלידה הוא כשלושה חודשים. פרק זמן זה אינו   |
|מספיק לאישה בכדי להיכנס למסלול חיים סדיר כהורה, במיוחד לא כהורה חדש. הארכת תקופת החופשה בחודש תקל באופן משמעותי על הנשים     |
|היולדות, כאשר הדגש הוא על הנשים מן השכבות החלשות של האוכלוסייה הישראלית.                                                     |
|                                                                                                                             |
|כמו כן, מגביל החוק הקיים את אפשרויות פריסת חופשת הלידה על ידי האישה. הצעת החוק באה לתת לעובדת זכויות רחבות יותר בקביעת זמן   |
|החופשה.                                                                                                                      |
|                                                                                                                             |
