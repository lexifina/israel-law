הכנסת החמש-עשרה

|הצעת חוק של חברת הכנסת יהודית נאות                                    |

הצעת חוק יסוד: הממשלה (תיקון - הפסקת כהונתו של סגן שר),

 התש”ס-2000

|בחוק יסוד: הממשלה[1] (להלן החוק העיקרי), בסעיף 38, אחרי פסקה (4) יבוא:                             |1.     |תיקון סעיף 38   |
|הכנסת רשאית להעביר סגן שר מכהונתו בהחלטה ברוב של שבעים מחבריה; הכנסת לא תדון בהעברת סגן שר |"(5)   |       |                |
|מכהונתו אלא על פי המלצת רוב חברי ועדת הכנסת ולאחר שניתנה לסגן השר הזדמנות לטעון טענותיו    |       |       |                |
|בפני הועדה ובפני מליאת הכנסת."                                                             |       |       |                |

דברי הסבר:
מטרת התיקון להשוות בין התנאים הקבועים בחוק לשרים ולסגני שרים, ולקבוע כי הכנסת תוכל להעביר סגן שר מתפקידו, כפי שהיא יכולה לעשות לגבי שר, ברוב של שבעים מחברי הבית.
