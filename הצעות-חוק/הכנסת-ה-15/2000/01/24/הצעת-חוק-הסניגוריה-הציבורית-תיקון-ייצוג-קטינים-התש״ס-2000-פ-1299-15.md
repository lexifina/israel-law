הצעת חוק הסניגוריה הציבורית (תיקון - ייצוג קטינים), התש”ס-2000

|בחוק הסניגוריה הציבורית, התשנ"ו-1995[1], (להלן-החוק העיקרי), בסעיף קטן (א), במקום פסקה (8) יבוא:   |1.     |תיקון סעיף 18   |
|קטין".                                                                                     |"(8)   |       |                |
|                                                                                                                             |
|                                                                                                                             |
|                                                                                                                             |
|דברי  הסבר                                                                                                                   |
|                                                                                                                             |
|חוק הסניגוריה הציבורית לא קובע זכאות לייצוג לקטין (אלא זכות מוגבלת). בתקנות שהותקנו ע"י שר המשפטים נקבע זכות ייצוג לקטינים,  |
|אולם זאת מוגבלת למספר אזורים בארץ באופן המפלה לרעה קטינים על רקע מקום מגוריהם או מקום ביצוע העבירה באופן הפוגע מהותית בעקרון |
|השיוויון ובעקרונות היסוד של הדמוקרטיה בישראל.                                                                                |
|ההצעה נועדה להקנות זכות זאת לכל קטין ללא אפליה על רקע לא רלבנטי, בחקיקה ראשית.                                               |
|הצעת החוק מאמצת את התקנה ללא מגבלת האזור.                                                                                    |
