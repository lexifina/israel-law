הצעת חוק הבטחת סידור ביתי לקטינים נזקקים, התש”ס-2000

|בחוק זה -                                                                                          |1.     |הגדרות           |
|"קטין - כהגדרתו בחוק הנוער (טיפול והשגחה), התש"ך-1960[1], (להלן - חוק הנוער);                      |       |                 |
|"קטין נזקק" – כמשמעותו בחוק הנוער, ובלבד שאין דרך להבטיח לו טיפול והשגחה אלא על ידי הוצאתו לסידור  |       |                 |
|חוץ ביתי;                                                                                          |       |                 |
|                                                                                                   |       |                 |
|"ועדת החלטה" – כהגדרת "הועדה" בסעיף 1 לתקנות הפיקוח על המעונות (אחזקת ילדים במעון רגיל),           |       |                 |
|התשכ"ו-1965[2].                                                                                    |       |                 |
|                                                                                                   |       |                 |
|מטרת חוק זה היא להבטיח לקטינים נזקקים תנאים שיבטיחו להם התפתחות פיסית, נפשית וחברתית תקינה וימנעו  |2.     |מטרת החוק        |
|את הידרדרותם.                                                                                      |       |                 |
|המדינה אחראית לספק סידור חוץ ביתי הולם לכל קטין נזקק, שועדת החלטה או בית משפט מוסמך החליטו בעניינו.|3.     |אחריות המדינה    |
|מצאו ועדת החלטה או בית משפט מוסמך שאין דרך להבטיח טיפול, השגחה או חינוך הדרושים לקטין, זולת בדרך של|4.     |סידור במסגרת     |
|סידור חוץ ביתי, תוסדר בעבורו מסגרת חוץ – ביתית ללא דיחוי.                                          |       |מתאימה           |
|שר העבודה והרווחה ממונה על ביצוע חוק זה והוא רשאי להתקין תקנות בכל הנוגע לביצוע.                   |5.     |ביצוע ותקנות     |
|                                                                                                   |       |                 |
|דברי  הסבר                                                                                                                   |
|                                                                                                                             |
|חוק הנוער (טיפול והשגחה) ותקנות הפיקוח על המעונות מאפשרים את הוצאתו של קטין, שהוגדר כ"קטין נזקק" מבית משפחתו גם כאשר המשפחה  |
|או הקטין מתנגדים לכך. ברם, אין המדינה מחויבת לספק לו מקום בפנימייה או במשפחה אומנת. הבטחת סידור חוץ – ביתי תלויה בזמינותה של |
|פנימייה מתאימה וב"מכסות" העומדות לרשות שירותי הרווחה.                                                                        |
|                                                                                                                             |
|                                                                                                                             |
|                                                                                                                             |
|כך, מוצאים עצמם קטינים במצב בו הם אינם זוכים לסידור קבע בפנימייה או במשפחה אומנת ומוצאים עצמם מטופלים במסגרות זמניות.        |
|                                                                                                                             |
|חוק זה יגן על זכויותיהם של ילדים וידרבן את הקמתם של מעונות בהיקף הנחוץ.                                                      |
