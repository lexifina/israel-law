|מתפרסמת בזה הצעת חוק של חבר הכנסת מטעם ועדת החינוך והתרבות של הכנסת:                                                           |
|הצעת חוק התרבות והאמנות, התשס"ב-2002*                                                                                          |
|1. בחוק זה -                                                                                           |הגדרות                 |
|"תרבות ואמנות" - כל פעילות תרבותית ואמנותית בתחום חיי היצירה והרוח;                                    |                       |
|"הועדה" - ועדת החינוך והתרבות של הכנסת;                                                                |                       |
|"השר" - שר המדע התרבות והספורט.                                                                        |                       |
|2, (א) הממשלה תמנה את המועצה הישראלית לתרבות ואמנות (להלן - המועצה),                                   |מינוי המועצה           |
|על פי הצעת השר; המועצה תייעץ לממשלה, לשר ולמשרד המדע, התרבות והספורט                                   |ומטרותיה               |
|בתחומי התרבות והאמנות ותמלא את התפקידים המוטלים עליה בחוק זה.                                          |                       |
|(ב) המועצה תפעל לשם עידוד וטיפוח של מדיניות תרבות ואמנות, הנותנת ביטוי                                 |                       |
|לחיי היצירה והרוח במדינת ישראל, תוך הבטחת חופש היצירה ומתן ביטוי למגוון התרבותי י                      |                       |
|של החברה בישראל, להשקפות השונות הרווחות בה ולערכיה כמדינה יהודית                                       |                       |
|ודמוקרטית.                                                                                             |                       |
|5. אלה תפקידי המועצה:                                                                                  |תפקידי המועצה          |
|(1) לדון ולהציע תכנית רב שנתית למדיניות בתחומי התרבות והאמנות;                                         |                       |
|(2) לדון ולהציע תכנית רב שנתית בנושא התמיכה במוסדות תרבות ואמנות-,                                     |                       |
|(3) לדון ולגבש המלצות בנושאים בתחומי התרבות והאמנות שיובאו לעיונו של                                   |                       |
|השר, או בנושאים שהשר ביקש שתדון בהם;                                                                   |                       |
|(4) להציע יוזמות, פעולות, מפעלים והקמה של גופים חרשים בתחומי התרבות                                    |                       |
|והאמנות:                                                                                               |                       |
|(5) להציע יוזמות, פעולות ומפעלים לעידוד ולקידום היצירה והאמן, לרבות                                    |                       |
|באמצעות מענקים, מלגות ופרסים-,                                                                         |                       |
|(6) להציע הצעות בדבר חיזוק, טיפוח ועידוד של תחומי תרבות ואמנות חדשים-,                                 |                       |
|(7) ליזום מחקרים בעניני תרבות ואמנות וקיום כנסים, ימי עיון ודיונים                                     |                       |
|ציבוריים;                                                                                              |                       |
|(8) לייעץ לשר לענין קביעת אמות מידה לתמיכה במוסרות תרבות ואמנות לפי                                    |                       |
|סעיף 3א לחוק יסודות התקציב, התשמ"ה-1985 , 1 ולענין גיבוש כללים ועקרונות                                |                       |
|להכרה או לביטול הכרה לצורך תמיכה במוסדות תרבות ואמנות ולצורך מתן מעמר                                  |                       |
|לענין חיקוקים אחרים;                                                                                   |                       |
|(9) לייעץ לממשלה, לשר ולמשרד המדע התרבות והספורט בכל נושא הנוגע                                        |                       |
|למדיניות בתחום התרבות והאמנות ובכל ענין הנוגע לביצוע חוק זה.                                           |                       |
