|בחוק זה –                                                                                          |1.     |הגדרות          |
|"בעל תחנת דלק" – לרבות מי שמוסמך לנהלה;                                                            |       |                |
|"משאבת אויר" – משאבה המופעלת למילוי אויר בצמיגי רכב או כל מכשיר שייעודו העיקרי הוא מילוי אוויר     |       |                |
|בצמיגי כלי רכב, ואשר מחובר לו מד לחץ תקין;                                                         |       |                |
|" תחנת דלק" –עסק למכירת דלק למכוניות, לרבות למתן שירותי סיכה או רחיצה של מכוניות;                  |       |                |
|"השר" – שר התחבורה.                                                                                |       |                |
|לא יינתן רישיון או היתר זמני לתחנת דלק, אלא לאחר שנתקיימו כל התנאים הבאים:                         |2.     |רישוי           |
|השר או מי שהוסמך מטעמו מצא כי בתחנת הדלק מותקנת משאבת אוויר תקינה, המוצבת במרחק סביר      |(1)    |       |                |
|ממשאבת הדלק, המוארת בשעות הלילה שבהן התחנה פתוחה לקהל והזמינה לשימוש הציבור בשעות שבהן    |       |       |                |
|תחנת הדלק פתוחה לקהל;                                                                     |       |       |                |
|נקבעו ברישיון או בהיתר זמני תנאים המחייבים את בעל תחנת הדלק הדלק ומפעילה לוודא תקינות     |(2)    |       |                |
|משאבות האוויר שבתחום תחנת הדלק ולקיים בדיקות על-ידי טכנאי מוסמך לפחות אחת לשישה חודשים.   |       |       |                |
|השר רשאי לפטור בצו מחובת רישוי לפי חוק זה, תחנות דלק שאין ברשותן משאבות אוויר או שברשותן משאבות לא |3.     |פטור מחובת רישוי|
|תקינות, אם בעל תחנת דלק יתחייב להתקין בתחנת הדלק משאבת אוויר תקינה תוך ששה חדשים מיום כניסתו לתוקף |       |                |
|של חוק זה.                                                                                         |       |                |

דברי  הסבר

   1. המילחמה בתאונות הדרכים כבר מזמן לפיל הלבן, שאיש אינו יודע כיצד  להתייחס אליו, אנו עדים לריבוי ועדות, תוכניות מאמרים וביקורות, אך דבר לא תכליתי.
   2. אחת הסיבות הוודאיות לתאונות הדרכים, ללא קשר ישיר לתנאי הדרך או איכות הנוהג ברכב, היא לחץ אויר לא נכון בגלגלי כלי הרכב.
   3.  - כדי לוודא את יכולתם של הנהגים לשמור על לחץ אויר נאות בגלגלי כלי הרכב, יש לוודא הימצאותם של מתקני מלוי אויר בכל תחנות הדלק. המצב היום הוא שמרבית תחנות הדלק שעוני  לחץ האוויר אינם מדוייקים, המשאבות לא תמיד תקינות, ויש לא מעט תחנות שאין בהן כלל מתקני מלוי אויר.
   4. הצעת חוק זו באה לחייב הימצאותם של מתקני מלוי אויר בכל תחנות הדלק, ואף להפוך זאת לחובה שהיא תנאי לרישוי התחנה.
