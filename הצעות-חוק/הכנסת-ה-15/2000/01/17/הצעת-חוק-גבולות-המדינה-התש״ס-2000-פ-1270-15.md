הצעת חוק גבולות המדינה, התש”ס-2000

|גבולותיה של מדינת ישראל, הנם גבולותיה נכון ליום כ"ד באייר התשכ"ז (3 ביוני 1967).                   |1.     |גבולות המדינה   |
|הוראות חוק רמת הגולן, התשמ"ב-1981[1] - בטלות.                                                      |2.     |ביטול הוראות חוק|
|                                                                                                   |       |רמת הגולן       |
|                                                                                                                             |
|                                                                                                                             |
|דברי  הסבר                                                                                                                   |
|                                                                                                                             |
|אחד מיסודותיה של המדינה הנו תחום הריבונות וגבולותיה, ואין מדינה ללא גבולות ידועים מפורסמים וברורים, העדר גבולות פוגע         |
|בריבונותה של המדינה ויוצר מצב אבסורדי, לפיו גבולותיה של המדינה משתנים על פי הנסיבות ועל פי מאזני הכוחות באזור.               |
|                                                                                                                             |
|בעידן החדש, כאשר מדינת ישראל מכריזה על נכונותה לכונן שלום צודק כולל ובר-קיימא עם המדינות השכנות, טוב תעשה המדינה אם תכריז על |
|פי חוק זה על גבולותיה הריבוניים.                                                                                             |
|                                                                                                                             |
|מאחר וכל השטחים אשר נכבשו ביוני 1967, מדינת ישראל מחזיקה בהם על-תקן של כובש, ובניגוד לאמנות הבינלאומיות ולאמנת האו"ם, הרי הם |
|אינם חלק מהשטח הריבוני של מדינת ישראל, והכרזותיה של המדינה על מעמד השטחים או ספוחם אין לו כל תוקף בינלאומי, ואינו משנה ממעמדם|
|כשטח כבוש, ולפיכך הצעת חוק זו מבטלת החוקים אשר ספחו את רמת הגולן מאחר והם סותרים חוק זה.                                     |
|                                                                                                                             |
|פקודות שטח השיפוט והסמכויות, תש"ח -  1948, איננו מגדיר את שטח המדינה, אלא מתייחס למושג לא משפטי אלא דתי והוא "ארץ ישראל",    |
|וכולל בתחום של המדינה גם שטחים המוחזקים ע"י צבא הגנה לישראל, וע"י זה יוצר שני שטחים של המדינה, אחד שהריבון בו הכנסת והאחר    |
|שהריבון בו צה"ל, וכן שתי אוכלוסיות אחת הנושאת אזרחות ומשתתפת בבחירות, ואחרת המנושלת זכויות, דבר הסותר אופיה של המדינה כמדינה |
|דמוקרטית, ולכן ומהנימוקים דלעיל מן הדין לקבל את הצעת החוק, מה גם שממשלת ישראל דרשה וקיבלה מהרשות הפלסטינית שינוי סעיפים באמנה|
|הפלסטינית, מן הדין שתדאג לשנוי חוקים הסותרים את הסכמי אוסלו, ותהליך השלום המתחדש בערוץ הסורי.                                |
