הכנסת החמש-עשרה

|הצעת חוק של חבר הכנסת איוב קרא                            |

הצעת חוק נסיגת כוחות צבא הגנה לישראל מרמת הגולן (סיוע לדרוזים          תושבי הגולן), התש”ס-2000

|בחוק זה -                                                                                          |1.     |הגדרות          |
|"רמת הגולן" – כמשמעותה בחוק רמת הגולן, התשמ"ב-1981[1];                                             |       |                |
|"השר" – שר הבטחון.                                                                                 |       |                |
|כל נסיגה של כוחות צבא הגנה לישראל משטח רמת הגולן, לרבות נסיגה חלקית לא תתבצע אלא אם התמלאו תנאים   |2.     |התנאת נסיגה     |
|אלה:                                                                                               |       |                |
|הבטחת עתידם של האזרחים הדרוזים, תושבי רמת הגולן, בעלי תעודת זהות ישראליות לרבות אלה מהם   |(1)    |       |                |
|שהיו נאמנים לכוחות הביטחון של ישראל;                                                      |       |       |                |
|הקמת יישוב קהילתי בכפר חיטים בסמוך לקבר יתרו, שיהווה מקום מקלט לאזרחים הדרוזים מרמת הגולן |(2)    |       |                |
|בעלי תעודת זיהוי ישראלית לרבות קידום ופיתוח היישוב ודאגה לרווחת תושביו;                   |       |       |                |
|דרוזים תושבי רמת הגולן שיבחרו להישאר בכפריהם ברמת-הגולן, יקבלו שלטון עצמאי – אוטונומיה    |(3)    |       |                |
|בכפריהם ברמת בגולן.                                                                       |       |       |                |
|השר ממונה על ביצוע חוק זה והוא רשאי להתקין תקנות בכל הנוגע לביצועו.                                |3.     |ביצוע ותקנות    |

דברי - הסבר

עקב ההצהרות הגוברות על נסיגה אפשרית מרמת הגולן הריני מציע לחוקק חוק המבטיח ביטחונם של הדרוזים תושבי רמת הגולן אזרחי ישראל וכן אפשרויות סיוע בקליטתם בארץ לרבות מקום מגורים, תעסוקה ותנאי מחיה, בצורה המכובדת ביותר.
