הצעת חוק קביעת שכר חיילים בשירות סדיר, התש”ס-2000

|למונחים שבחוק זה תהיה המשמעות שיש להם בחוק שירות בטחון (נוסח משולב), התשמ"ו-1986[1] (להלן – חוק    |1.     |פרשנות          |
|שירות בטחון).                                                                                      |       |                |
|שכרו החודשי של חייל בשירות חובה המשרת בשטח  או ביחידה קרבית, כהגדרתם בפקודות הצבא מכוח חוק שירות   |2.     |קביעת שכר       |
|בטחון, יהיה בשיעור שלא יפחת משכר המינימום לחודש במשק, כהגדרתו בחוק שכר מינימום, התשמ"ז-1987[2];    |       |                |
|                                                                                                   |       |                |
|בסעיף זה, "שירות חובה" – כהגדרתו בחוק שירות הקבע בצבא הגנה לישראל (גימלאות) (נוסח משולב),          |       |                |
|התשמ"ה-1985[3], ולמעט שירות סדיר נוסף.                                                             |       |                |
|שר הביטחון ממונה על ביצועו של חוק זה והוא רשאי להתקין תקנות לביצועו.                               |3.     |ביצוע ותקנות    |
|                                                                                                                             |
|                                                                                                                             |
|דברי  הסבר                                                                                                                   |
|                                                                                                                             |
|בטחון מדינת ישראל הופקד מכח חוק שירות בטחון (נוסח משולב), התשמ"ו-1986, בידי חיילי צה"ל.                                      |
|                                                                                                                             |
|עיקר העול נופל על כתפי החיילים הקרביים, המסכנים נפשם יומם ולילה למען בטחון ישראל.                                            |
|                                                                                                                             |
|לכיסוי הוצאותיהם מקבלים חיילים אלו שכר מינימלי, שנקבע לפני שנים רבות על בסיס אילוצים ומגבלות תקציביות.                       |
|                                                                                                                             |
|מדינת ישראל מחויבת היום מוסרית וכלכלית לשלם לחיילים אלו שכר הוגן והולם עבור מאמציהם, ובידיה המשאבים הכלכליים הנדרשים.        |
|                                                                                                                             |
|המצב הקיים מפיל על כתפי ההורים את החובה לתמוך כלכלית בילדיהם, כאשר חיילים למשפחות מעוטות הכנסה חסרים אף את האמצעים הנחוצים   |
|לקיום רמת חיים מינימלית.                                                                                                     |
|                                                                                                                             |
|חוק זה מציע לתקן עיוות היסטורי שנמשך עד עצם היום הזה ולהטיל על המדינה את החובה לשלם שכר מינימום לחיילי היחידות הקרביות,      |
|ושיעור של 50 אחוזים ממנו לשאר חיילי צה"ל. בכך תכיר המדינה בחובתה לחיילי צה"ל בכלל, וללוחמים בפרט.                            |
