הצעת חוק התקנת מעליות שבת בבנינים רבי קומות ובבנינים ציבוריים (תיקוני חקיקה), התש"ס-2000

|בחוק התכנון והבניה, התשכ"ה-1965,[1] בסעיף 158א, אחרי סעיף קטן (א) יבוא:                            |1.     |תיקון חוק התכנון |
|                                                                                                   |       |והבניה           |
|בכל בנין, אשר על פי דין חובה להתקין בו שתי מעליות או יותר, וכן בכל בניין ציבורי כהגדרתו |"(א1)     |       |                 |
|בסעיף 158ב יותקן באחת המעליות לוח פיקוד המתאים להפעלת מעלית שבת; לא יינתן היתר לבניית   |          |       |                 |
|בניין כאמור שאין בו תנאי המחייב התקנת לוח פיקוד להפעלת מעליות שבת כאמור."               |          |       |                 |
|בחוק המקרקעין, התשכ"ט-1969[2], בסעיף 59, אחרי סעיף קטן (ד), יבוא:                                  |2.     |תיקון חוק        |
|                                                                                                   |       |המקרקעין         |
|הותקנו בבית משותף שתי מעליות או יותר על פי דין, או היה הבניין ציבורי כמשמעותו בחוק      |"(ה)      |       |                 |
|התכנון והבניה, התשכ"ה-1965, תהא אחת המעליות בעלת לוח פיקוד המאפשר הפעלת מעלית שבת והיא  |          |       |                 |
|תופעל בכל שבת מכניסת השבת עד שעה 24:00 ביום שישי, ומשעה 7:30 ביום השבת ועד לצאת השבת    |          |       |                 |
|בבניין מגורים, ובבניין ציבורי בכל שבת מכניסת השבת ועד לצאתה, או בכל שעות הפעלת יתר      |          |       |                 |
|המעליות; בעלי הדירות רשאים לא למלא אחר הוראות סעיף קטן זה, אם תינתן לכך הסכמה בכתב מכל  |          |       |                 |
|בעלי הדירות, וכל עוד לא דרש אחד מבעלי הדירות אחרת."                                     |          |       |                 |
