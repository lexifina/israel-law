הצעת חוק זכויות הילד, התש”ס-2000

|בחוק זה -                                                                                          |1.     |הגדרות          |
|"ילד" - אדם שטרם מלאו לו שמונה עשרה שנה;                                                           |       |                |
|"האמנה" - אמנת האומות המאוחדות בדבר זכויות הילד, שאישררה מדינת ישראל ביום 4 באוגוסט 1991.[1]       |       |                |
|חוק זה מטרתו להגן על זכויות הילד בישראל ולהבטיח את טובתו ואת התפתחותו בתנאים ההולמים את כבודו כאדם.|2.     |מטרת החוק       |
|לסעיפי האמנה שנוסחם מובא בתוספת יהיה תוקף של חוק.                                                  |3.     |תוקף האמנה      |
|כל רשות מרשויות המדינה חייבת בתחומי פעולתה לכבד, להבטיח ולקדם את זכויות הילד וטובתו בהתאם להוראות  |4.     |חובה            |
|האמנה.                                                                                             |       |                |
|חוק זה בא להוסיף על זכויות הילד על פי כל דין ולא לגרוע מהן.                                        |5.     |שמירת זכויות    |
|תחילתו של חוק זה חודשיים מיום קבלתו.                                                               |6.     |כניסה לתוקף     |
|                                                                                                                             |
|                                                                                                                             |
|דברי  הסבר                                                                                                                   |
|                                                                                                                             |
|אמנת האו"ם בדבר זכויות הילד, פרי עבודה ממושכת ויסודית של מומחים ממדינות שונות, היא אחד ההשגים החשובים של הקהילה הבינלאומית.  |
|מטרתה - להבטיח התפתחות הרמונית של הילד ולהגן על זכותו לגדול בסביבה משפחתית ובאוירה של אהבה והבנה.                            |
|                                                                                                                             |
|הכללתו בחוק הישראלי של חלק א' של האמנה העוסק בחובות המוטלות על המדינה שאישררה את האמנה, תיצור תמריץ חשוב לכל רשויות המדינה   |
|לטפל בכל מצוקותיהם הגשמיות, הנפשיות והחינוכיות של הילדים ולהבטיח תנאים טובים יותר להתפתחותם של כל הילדים, ללא אפליה.         |
