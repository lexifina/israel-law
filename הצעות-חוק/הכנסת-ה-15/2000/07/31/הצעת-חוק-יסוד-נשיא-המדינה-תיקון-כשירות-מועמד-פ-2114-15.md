הצעת חוק יסוד: נשיא המדינה (תיקון - כשירות מועמד)

|בחוק יסוד: נשיא המדינה[1], בסעיף 4, האמור בו יסומן "(א)", ובסופו יבוא:                                    |1.     |           |
|על אף האמור בסעיף קטן (א), לא יהיה כשיר להיות מועמד מי שהורשע בעבירה שבשל חומרתה או נסיבותיה אין|"(ב)     |       |           |
|הוא ראוי לשמש כנשיא המדינה".                                                                    |         |       |           |

דברי - הסבר

בעקבות התרחשויות בשדה הפוליטי בתקופה האחרונה, לפיהן קיים סיכוי כי אדם שהורשע בדין ומרצה תקופת מאסר בפועל עלול לשמש כנשיא המדינה, מוגשת הצעת חוק המחייבת מועמד לתפקיד הנשיא להיות נקי כפיים וללא הרשעה פלילית.

כהונת נשיא המדינה הנה הלכה למעשה סמל עליון לאחדות העם בישראל ובגולה. הנשיא אמור להיות אדם המסמל ומשקף באישיותו ובפועלו את מדינת ישראל ואת החברה הישראלית, ולכן לא יתכן כי תיכלל בעברו הרשעה פלילית.
