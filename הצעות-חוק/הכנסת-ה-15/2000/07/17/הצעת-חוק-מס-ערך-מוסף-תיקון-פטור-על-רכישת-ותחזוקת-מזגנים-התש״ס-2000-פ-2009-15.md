הצעת חוק מס ערך מוסף (תיקון - פטור על רכישת ותחזוקת מזגנים),

התש”ס-2000

|                                                                                                   |       |                |

|בחוק מס ערך מוסף, התשל"ו-1976[1], בסעיף 31, אחרי פסקה (5) יבוא:                                    |1.     |תיקון סעיף 31   |
|על עסקה שהיא רכישה, התקנה, הפעלה ותחזוקה של מערכות מיזוג אויר לתושב שמקום מגוריו באחד   |"(17)     |       |                |
|מהישובים הבאים:                                                                         |          |       |                |
|"טבריה" כהגדרתה בפקודת העיריות[2];                                              |       |          |       |                |
|"בית שאן" כהגדרתה בפקודת העיריות;                                               |       |          |       |                |
|"בקעת בית שאן" כמשמעותה בפקודת המועצות המקומיות[3];                             |       |          |       |                |
|"בקעת הירדן" כמשמעותה בפקודת המועצות המקומיות."                                 |       |          |       |                |

דברי - הסבר

מידות החום באזורים: בית שאן, טבריה, בקעת בית שאן, בקעת הירדן ועמק הירדן הינן גבוהות מאוד, יש תושבים שידם אינה משגת לרכוש מערכות מיזוג אויר, וכתוצאה מכך גם תפוקת העובדים במקום עבודתם פוחתת, לפיכך מוצע בזאת לפטור ממס את תושבי האיזור, ולהשוות את מעמדם לתושבי אילת לעניין רכישת מזגנים.
