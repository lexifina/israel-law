הצעת חוק התגמולים לחסידי אומות העולם (תיקון - הרחבת מעגל הזכאים), התש”ס-2000

|בחוק התגמולים לחסידי אומות העולם, התשנ"ה-1995[1] (להלן – החוק העיקרי), בסעיף 1, בהגדרה "חסיד אומות |1.     |תיקון סעיף 1    |
|העולם", בסופה יבוא "ולענין סעיף 2(ב) גם אם אינו יושב בישראל".                                      |       |                |
|בסעיף 2 לחוק העיקרי, האמור בו יסומן "(א)" ואחריו יבוא:                                             |2.     |תיקון סעיף 2    |
|חסיד אומות העולם המתגורר מחוץ למדינת ישראל יהיה זכאי לתגמול חודשי בשיעור השווה למחצית      |"(ב)   |       |                |
|התגמול האמור בסעיף קטן (א)."                                                               |       |       |                |

דברי - הסבר

מוצע לעגן בחוק התגמולים לחסידי אומות העולם, התשנ"ה-1995 את זכותם של חסידי אומות העולם המתגוררים מחוץ למדינת ישראל לתגמול ממדינת ישראל כאות הוקרה על פעולתם בזמן מלחמת העולם השניה.
