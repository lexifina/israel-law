דברי - הסבר

הצעת חוק זו, מטרתה להסדיר ולחזק את עצמאות מבקר העירייה ואי-תלותו וכן את מינויו, מעמדו, סמכויותיו והאמצעים העומדים לרשותו.

|ההוראה בסעיף 167ג פסקה (6) באה למנוע מינויו של פעיל מפלגה לתפקיד מבקר עירייה, אשר עלול לפגוע באמינותו      |סעיף 1           |
|וביכולתו לפעול באופן בלתי תלוי.                                                                            |                 |
|ההוראה בסעיף 167(ג1) באה לאפשר לאדם שסיים את כהונתו כחבר מועצה ברשות מסוימת, לכהן כמבקר ברשות אחרת.        |                 |
|ההוראה באה להבטיח באופן בלתי תלוי שכר הוגן למבקר גם במקרים של מינוי המבקר ע"י הממונה.                      |סעיף 2           |
|ההוראה בסעיף 170(ה) באה כדי לקבוע שעל עובדי ביקורת חלים כל התנאים של המבקר עצמו, להוציא תקופת הנסיון.      |סעיף 3           |
|ההוראה בסעיף 170א סעיף קטן (ה) באה לקבוע את שעור המינימום בתקציב המבקר על-מנת למנוע את תלות המבקר במבוקרים.|סעיף 4           |
|ההוראה בסעיף 170א סעיף קטן (ה1) באה לקבוע שהטלת משימות נוספות שאינן קבועות בחוק, פוגעות בהיקף עבודת הביקורת|                 |
|ולכן  יש להוסיף תקן כח-אדם, תקציבים ואמצעים עם תוספת המשימות.                                              |                 |
|ההוראה בסעיף 170ב סעיף קטן (א) מיועדת לחיזוק חובת מסירת המידע למבקר, בדומה לאמור בסעיף 9א לחוק הביקורת     |סעיף 5           |
|הפנימית.                                                                                                   |                 |
|ההוראה בסעיף 170ב סעיף קטן (ו) באה כדי לקבוע שהיועץ המשפטי הוא הגורם המוסמך בעירייה לקבוע מהי עבירה פלילית |                 |
|ומה יש לעשות בה.                                                                                           |                 |
|ההוראה בסעיף 170ב סעיף קטן (ז) באה כדי לאפשר למבקר להפנות את חשדותיו לגורם משפטי הנמצא מעל ראש העירייה.    |                 |
|ההוראה בסעיף 170ג בדבר שינוי התאריך מתחייבת מהתאמת שנת הכספים ושנת העבודה לשנה קלנדרית.                    |סעיף 6           |
|התוספת לסעיף 170ג סעיף קטן (א) באה כדי לאחד סעיפים ותקנות בחוק הקיים.                                      |                 |
|ההוראה בסעיף קטן (ד) באה על-מנת למנוע מצב בו בשל העובדה כי ראש העירייה או הועדה לעניני ביקורת לא ביצעו את  |                 |
|המוטל עליהם ובמועד, נעצר מאליו תהליך הטיפול בדו"ח המבקר.                                                   |                 |
|ההוראה בסעיף קטן (ה) באה כדי שהמועצה תדון גם בדו"ח המבקר ולא רק בסיכום והצעות הועדה לעניני ביקורת. כמו-כן  |                 |
|התוספת מנחה כיצד לפעול אם הועדה לעניני ביקורת לא מילאה את חובתה במועד.                                     |                 |
|ההוראה בסעיף קטן (ו) באה כדי להבהיר את מועד פרסום דו"ח הביקורת, כתיקון לעמימות המועד המותר בהגדרה הנוכחית  |                 |
|של החוק, הרואה את מועד הפרסום המותר מהגשת הדו"ח למועצה.                                                    |                 |
|ההוראה בסעיף 170ד הינה הוראה חיונית וחסרה בפקודת העיריות, לפיכך מוספת בזאת כלשונה בחוק הביקורת הפנימית.    |סעיף 7           |
|ההוראה בסעיף 171 באה כדי לחזק את מעמדו של המבקר, למנוע אפשרות פיטוריו השרירותיים כתוצאה משיקולים זרים.     |סעיף 8           |
