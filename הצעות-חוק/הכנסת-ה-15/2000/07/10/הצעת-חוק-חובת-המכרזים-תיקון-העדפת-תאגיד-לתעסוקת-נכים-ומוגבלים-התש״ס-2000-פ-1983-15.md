הצעת חוק חובת המכרזים (תיקון - העדפת תאגיד לתעסוקת נכים ומוגבלים), התש”ס-2000

|בחוק חובת המכרזים, התשנ"ב–1992[1], בסעיף  3א,  אחרי סעיף קטן                                       |1.     |תיקון           |
|(א1) יבוא:                                                                                         |       |סעיף 3א         |
|שר האוצר ושר העבודה והרווחה, באישור ועדת החוקה, חוק ומשפט של הכנסת, יקבעו הוראות בעניין |"(א2)     |       |                |
|העדפה לתאגיד לתעסוקת נכים ומוגבלים, ששמונים וחמישה אחוז מעובדיו זכאים על פי כל דין לגמלה|          |       |                |
|או לתגמול בשל נכותם או לקצבת זקנה של המוסד לביטוח לאומי, במכרז פומבי או בהתקשרות לביצוע |          |       |                |
|עסקה בטובין או לביצוע עבודה או לרכישת שירותים."                                         |          |       |                |
|                                                                                                   |       |                |
|                                                                                                   |       |                |
|דברי הסבר                                                                                                                    |
|הצעת החוק באה להעניק לתאגידים לתעסוקת נכים ומוגבלים מעמד ספק מועדף במכרזים פומביים והתקשרויות הנעשים ע"י רשויות המדינה,      |
|תאגידים ממשלתיים, מועצות דתיות וקופות החולים.                                                                                |
|בסוף שנות ה-80 ביטלה הממשלה את מעמד הספק המועדף לחברת "המשקם" לתעסוקת נכים ומוגבלים, צעד שפגע ביכולת החברה להתמודד עם ספקים  |
|משוק העבודה הטבעי.                                                                                                           |
|הצעת החוק קובעת כי שרי העבודה והרווחה והאוצר יקבעו הוראות מיוחדות, שתכליתן להעניק זכות מועדפת לתאגיד לתעסוקת נכים ומוגבלים,  |
|זאת, על-מנת להבטיח לעובדי התאגידים, שתפוקתם נמוכה, רציפות בתעסוקה גם על חשבון שיקולי כדאיות כספית בהעסקתם. למדינת ישראל      |
|מחוייבות עליונה להבטיח את קיומם של המפעלים המוגנים, כדי למנוע מעובדיהם ליפול כנטל של שירותי הרווחה.                          |
