הצעת חוק תיעוד המידע בועדות ציבוריות, התש”ס-2000

|בחוק זה –                                                                                         |1      |הגדרות            |
|"ועדה ציבורית" – ועדה שמונתה על ידי שר מנכ"ל משרד ממשלתי או בהחלטת ממשלה על מנת שתגיש דין וחשבון  |       |                  |
|או המלצות בכל נושא שהוא.                                                                          |       |                  |
|הועדה תנהל פרוטוקולים של ישיבותיה והחלטותיה.                                             |(א)    |2.     |עריכת פרוטוקולים  |
|בפרוטוקולים ירשמו הפרטים הבאים:                                                          |(ב)    |       |                  |
|מקום ישיבת הועדה ומועדה;                                                         |(1)    |       |       |                  |
|המשתתפים בה;                                                                     |(2)    |       |       |                  |
|החלטת הועדה;                                                                     |(3)    |       |       |                  |
|מהלך הדיונים לרבות הדעות השונות שהועלו בדיונים וכל החומר שהוצג בפני הועדה;       |(4)    |       |       |                  |
|אם ביקש חבר הועדה להימנע מלהשתתף בדיון בבקשה מסוימת בשל ניגוד ענינים או כל נימוק |(5)    |       |       |                  |
|אחר;                                                                             |       |       |       |                  |
|תקציר הדיון.                                                                     |(6)    |       |       |                  |
|החלטות הועדה תהיינה מנומקות, במיוחד כאשר הופנו אליה בקשות ואלו נדחו.                     |(ג)    |       |                  |

דברי - הסבר

מוצע לחייב כי ועדה ציבורית שמונתה על ידי שר, מנכ"ל משרד ממשלתי או בהחלטת ממשלה תחויב בעריכת פרוטוקול מלא שיכיל את דברי כל המשתתפים לרבות דברי מומחים שזומנו לועדה כמו גם תכיל את החומר המלא שהובא בפני הועדה. חוק שה נועד לאפשר לציבור לדעת מה היו שיקולי הועדה בהמלצותיה ובמסקנותיה.
