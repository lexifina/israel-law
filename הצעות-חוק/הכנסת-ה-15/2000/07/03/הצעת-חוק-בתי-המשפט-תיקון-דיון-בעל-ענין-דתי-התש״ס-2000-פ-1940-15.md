|בחוק בתי המשפט [נוסח משולב], התשמ"ב-1984[1], בסעיף 26, אחרי פסקה (5) יבוא:                         |1.     |הוספת סעיף קטן  |

|כמשמעותם בחוק הרבנות הראשית לישראל, התש"ם-1980[2].                                        |       |       |                |

דברי - הסבר

לאחרונה, שופטי בג"ץ מרחיבים את היקף תחום פעילותם, ומעלים לדיון נושאים בעלי היבט דתי, ואף מוציאים לאור פסקים הסותרים לחלוטין את ההלכה היהודית.

הצעת החוק האמורה באה לחייב את צירופם של שני הרבנים הראשיים, לכל הרכב שידון בנושא שהוא בעל עניין דתי - במישרין או בעקיפין.

נוכחותם של הרבנים הראשיים בדיונים האמורים, תתרום ללא ספק להעמקת ולהרחבת הידע ההלכתי שנדרש בדיונים מעין אלו.
