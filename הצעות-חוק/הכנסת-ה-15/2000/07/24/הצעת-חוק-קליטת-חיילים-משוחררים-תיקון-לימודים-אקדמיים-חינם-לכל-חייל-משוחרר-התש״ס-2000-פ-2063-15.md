|בחוק קליטת חיילים משוחררים, התשנ"ד-1994[1], במקום סעיף 13 יבוא:                                    |1.     |החלפת סעיף 13   |
|חייל משוחרר הלומד במוסד להשכלה גבוהה או    בישיבה על תיכונית או במוסד    |13.    |"לימודים אקדמיים |       |                |
|להכשרה מקצועית, זכאי להשתתפות בתשלום שכר הלימוד במוסד האמור באופן שבגין  |       |                 |       |                |
|כל שנת שירות ששירת במסגרת שירותו הסדיר יקבל השתתפות במימון שנת לימודים." |       |                 |       |                |

דברי – הסבר

התיקון מציע להעניק מימון לכל שנת לימודים במוסד להשכלה גבוהה לחייל משוחרר בהתאמה לזמן בו שירת בשירותו הסדיר וזאת על מנת לתגמל כראוי את המשרתים בצה"ל, חיילים, אשר מעניקים לשירות המדינה את שנות חייהם הטובות ומוכנים לסכנן למען הגן עליה, לעודדם להמשיך ללימודים גבוהים ולרכישת מקצוע ולעשות זאת במימון המדינה. בעת, אשר בה חובת השירות לא חלה על כלל האזרחים, יש צורך הן בעידוד הגיוס והן במתן תגמול ערכי למתגייס.
