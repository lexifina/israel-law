הצעת חוק העונשין (תיקון - הסכמה מודעת להפלה), התש”ס-2000

|בחוק העונשין, התשל"ז – 1977, בסעיף 316(ב), אחריו יבוא:                                             |1.     |תיקון סעיף 316  |
|הסיכונים שיש להביא לידיעת האשה לעניין סעיף קטן (ב) הם כל סיכון שהמידע אודותיו דרוש לאשה |"(ב1)     |       |                |
|באורח סביר, כדי לאפשר לה להחליט באופן מודע אם להסכים להפסקת ההריון, לרבות-              |          |       |                |
|חשש לעקרות או לפגיעה בפוריות בעתיד;                                             |(1)    |          |       |                |
|אפשרות של ניקוב הרחם והצורך בניתוח מיידי בעקבות זאת;                            |(2)    |          |       |                |
|אפשרות להיווצרות זיהום מיידי או בשלב מאוחר יותר;                                |(3)    |          |       |                |
|אפשרות להיווצרות אי ספיקה של צוואר הרחם;                                        |(4)    |          |       |                |
|אפשרות לשטפי דם;                                                                |(5)    |          |       |                |
|צורך אפשרי בביצוע גרידה נוספת;                                                  |(6)    |          |       |                |
|אפשרות להפלות חוזרות;                                                           |7)     |          |       |                |
|אפשרות ללידה מוקדמת;                                                            |(8)    |          |       |                |
|אפשרות ללידת פגים;                                                              |(9)    |          |       |                |
|אפשרות להפרעות במחזור;                                                          |(10)   |          |       |                |
|הפרעות אפשריות בהשתרשות השליה;                                                  |(11)   |          |       |                |
|אפשרות של הריון מחוץ לרחם;                                                      |(12)   |          |       |                |
|אפשרות של טראומה נפשית.                                                         |(13)   |          |       |                |
|לעניין סעיף זה, הסכמה להפסקת הריון היא רצונית ומודעת אם, ורק אם, נמסר לאשה כי –            |(ב2)   |       |                |
|קיים חומר הסברה בכתב, הן ביחס לסיכונים כמפורט לעיל, והן ביחס למצב העובר, וכי יש   |(1)    |       |       |                |
|לאשה זכות לקבל חומר זה לעיונה ללא כל תשלום, אם רצונה בכך;                         |       |       |       |                |
|קיים חומר הסברה בכתב ובו פירוט של גופים המציעים חלופות להפסקת הריון, וכי יש לאשה  |(2)    |       |       |                |
|הזכות לקבל חומר זה לעיונה ללא כל תשלום, אם רצונה בכך;                             |       |       |       |                |
|עותק של החומר המודפס הנ"ל הוצע לאשה אם היא בחרה לעיין בו;                         |(3)    |       |       |                |
|האשה אישרה בכתב, לפני הפסקת ההריון, שהמידע החייב להימסר לה בכתב לפי סעיף קטן זה   |(4)    |       |       |                |
|אכן הוצע לה.                                                                      |       |       |       |                |
|מי שהפסיק הריונה של אשה בלא שנתקבלה הסכמתה המודעת כמשמעותה בסעיף זה, דינו - מאסר שנה אחת או|(ב3)   |       |                |
|קנס עשרת אלפים ₪.                                                                          |       |       |                |
|                                                                                                   |       |                |
|דברי הסבר                                                                                                                    |
|הצעת החוק המוגשת בזאת הינה פרי מחקרו של פרופ' אליאב שוחטמן מן הפקולטה למשפטים באוניברסיטה העברית בירושלים, בנושא "דרישת      |
|ההסכמה המודעת בהפסקות הריון".                                                                                                |
|                                                                                                                             |
|על-פי סעיף 13(א) לחוק זכויות החולה, התשנ"ו-1996, לצורך מתן טיפול רפואי יש לקבל את הסכמתו המודעת של המטופל. ביחס להפסקות הריון|
|קיימת הוראה מיוחדת  בסעיף 316 לחוק העונשין, התשל"ז-1997, ולפיה אין להפסיק הריון אלא לאחר קבלת הסכמתה המודעת של האשה. החוק    |
|מתייחס במפורש לצורך ליידע את האשה ביחס לסיכונים הגופניים והנפשיים הכרוכים בהפסקת הריון, אבל אין בחוק כל פירוט בעניין זה. כמו |
|כן, אין החוק מתייחס במפורש לצורך ליידע את האשה ביחס למצב העובר בעת הפסקת ההריון, וגם לא ביחס לאפשרויות חלופיות העומדות בפני  |
|האשה אם תחליט להמשיך את ההריון. אי-מתן מידע מלא ומפורט לאשה, שולל ממנה את האפשרות לקבל החלטה שקולה כדרישת החוק. על-פי ממצאיהן|
|של שתי וועדות ציבורית שהוקמו במרוצת השנים, ומפרסומים שונים עולה, כי קיימים ליקויים בנושא ההסברה לאשה המבקשת להפסיק את הריונה.|
|מוצע תיקון לחוק העונשין, ברוח החקיקה החדישה בכמה ממדינות ארה"ב – חקיקה אשר קיבלה את אישורו של בית-המשפט העליון שם. תכלית     |
|ההצעה היא להביא לכך, שכל אשה המבקשת להפסיק את הריונה, תקבל את כל המידע הדרוש לה על-מנת לגבש החלטה שקולה, וזאת בלא להתערב כלל |
|בזכותה להחליט בעצמה בעניין.                                                                                                  |
