|1. בחוק הביטוח הלאומי [נוסח משולב], התשנ"ה-1995 1', האמור בסעיף 100 יסומן "(א)-                        |תיקון סעיף 100      |
|ואחריו יבוא:                                                                                           |                    |
|"(ב) השר, באישור ועדת העבודה והרווחה, יקבע -                                                           |                    |
|(ו) הוראות, מבחנים, כללים ומועדים, בדבר תשלום מקדמה למבוטח שהגיש                                       |                    |
|תביעה לדמי פגיעה;                                                                                      |                    |
|(2) מועדים למתן תשובות המוסד למבוטח בענין זכאותו לדמי פגיעה.                                           |                    |
|(ג) מבוטח ששולמה לו מקדמה על חשבון דמי הפגיעה לפי הוראות סעיף קטן (ב)                                  |                    |
|ונקבע, בהחלטה שניתנה על ידי פקיד תביעות או בית הרין שהמבוטח אינו זכאי למקדמה,                          |                    |
|יחזיר למוסד כל תשלום עודף שקיבל, והוראות סעיף 515 יחולו לענין זה בשינויים                              |                    |
|המחויבים.'                                                                                             |                    |
