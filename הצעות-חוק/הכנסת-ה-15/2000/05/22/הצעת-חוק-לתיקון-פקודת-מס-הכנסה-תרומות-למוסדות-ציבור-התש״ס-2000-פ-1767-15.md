הכנסת החמש-עשרה

|הצעת חוק של חבר הכנסת יורי שטרן                          |

הצעת חוק לתיקון פקודת מס הכנסה (תרומות למוסדות ציבור), התש”ס-2000

|בפקודת מס הכנסה[1], בסעיף 46(א), במקום הסיפה המתחילה במילים                                        |1.     |תיקון סעיף 46   |
|"35% מסכום התרומה" יבוא:                                                                           |       |                |
|"יזוכה הסכום שנתרם מהמס שהוא חייב בו באותה שנה, ובלבד שלא יינתן זיכוי בשנת מס פלונית בשל סכום כולל |       |                |
|של תרומות, העולה על 30% מההכנסה החייבת של הנישום באותה שנת מס."                                    |       |                |

דברי - הסבר

גופים עסקיים רבים שמעוניינים לתרום למוסדות ציבור נתקלים בבעיית מיסוי, כיוון שפקודת מס הכנסה מאפשרת מתן זיכוי עד גובה של כ-450,000 ₪.
מוצע לפיכך לעודד מתן תרומות מצד חברות עסקיות כפי שנהוג ברוב מדינות העולם המערבי.
