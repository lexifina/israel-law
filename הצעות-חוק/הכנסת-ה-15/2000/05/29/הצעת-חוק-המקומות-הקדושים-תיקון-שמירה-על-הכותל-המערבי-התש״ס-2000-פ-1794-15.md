הצעת חוק המקומות הקדושים (תיקון - שמירה על הכותל המערבי),

 התש”ס-2000

|בחוק המקומות הקדושים, התשכ"ז-1967[1], אחרי סעיף 2 יבוא:                                            |1.     |הוספת סעיף 2א   |
|מקום התפילה שברחבת הכותל המערבי יחולק לעזרת גברים ולעזרת נשים   |(א)    |2א.    |"שמירה  על הכותל |       |                |
|באמצעות מחיצה, ולא תותר בו תפילה מעורבת של גברים ונשים.         |       |       |המערבי           |       |                |
|לא יקוים טקס דתי בעזרת הנשים שליד הכותל המערבי, הכולל הוצאת ספר |(ב)    |       |                 |       |                |

דברי - הסבר

מעמדו של הכותל המערבי לא מוסדר במפורש בחוק אלא בתקנות בלבד. חיוני להבטיח את מעמדו של הכותל המערבי ואת שמירת קדושתו. לשם כך, מוצע לקבוע בחוק כי מקום התפילה שליד הכותל יחולק לעזרת גברים ולעזרת נשים, וכי לא יקוים כל טקס דתי בעזרת הנשים. כמו כן, מוצע לקבוע כי כל העובר על איסור זה דינו מאסר שבע שנים.
