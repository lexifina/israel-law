|בחוק האזרחים הותיקים, התש"ן-1989[1] (להלן – החוק העיקרי), בסעיף 10 -                               |1.     |תיקון סעיף 10   |
|האמור בו יסומן "(א)";                                                                      |(1)    |       |                |
|אחרי "אזרח ותיק" יבוא "שגילו עד 75 שנים";                                                  |(2)    |       |                |
|אחריו יבוא:                                                                                |(3)    |       |                |
|משרד העבודה והרווחה יתן תעודת אזרח ותיק מיוחדת לכל תושב ישראל בהגיעו לגיל | (1)   |"(ב)   |       |       |                |
|75 שנים.                                                                  |       |       |       |       |                |
|אזרח ותיק שגילו 75 שנים ומעלה זכאי להנחה בשיעור של 100% מדמי הנסיעה       |(2)    |       |       |       |                |
|בתחבורה הציבורית, הן העירונית והן הבין עירונית, והיא תינתן על כל סוגי     |       |       |       |       |                |
|הכרטיסים הקיימים בתחבורה הציבורית."                                       |       |       |       |       |                |

|דברי – הסבר                                                                                                                      |
|עם סיומה של שנת הגימלאי ולאחר הסקת המסקנות המתבקשות, עלינו למצוא פתרונות של ממש וליישמם בפועל על מנת לעזור לגימלאים בישראל לחיות |
|את חייהם בשלווה ובכבוד.                                                                                                          |
|התיקון המוצע בא לסייע לאוכלוסייה המבוגרת (החל מגיל 75) בארץ לממש את חופש התנועה על-ידי הענקת הנחה של 100% מדמי הנסיעה בכל סוגי   |
|התחבורה הציבורית.                                                                                                                |
