הצעת חוק השכלה גבוהה חינם, התשס”א-2001

|בחוק זה -                                                                                          |1.     |הגדרות          |
|"אזרח" – כמשמעותו בחוק האזרחות, התשי"ב-1952[1]                                                     |       |                |
|"מוסד להשכלה גבוהה" – כמשמעותו בסעיף 1 לחוק המועצה להשכלה גבוהה, התשי"ח-1958[2], וכן מכללה או מוסד |       |                |
|על תיכוני אחר שיקבע השר;                                                                           |       |                |
|"תכנית לימודים" - מסלול לימודים המזכה בקבלת תעודה;                                                 |       |                |
|"תעודה" - תואר אקדמי, תעודת-גמר על תיכונית, תעודת-הוראה וכל תעודה אחרת שיקבע השר;                  |       |                |
|"השר" – שר החינוך.                                                                                 |       |                |
|אזרח ישראלי, שגילו אינו עולה על 30 שנה, זכאי ללמוד תוכנית לימודים אחת חינם, במוסד להשכלה גבוהה.    |2.     |זכאות להשכלה    |
|                                                                                                   |       |גבוהה חינם      |
|תקופת הזכאות להשכלה גבוהה חינם כאמור בסעיף 2 לא תפחת ממשך תכנית לימודים אחת כנהוג במוסד להשכלה     |3.     |תקופת הזכאות    |
|גבוהה שבו לומד האזרח לגבי מסלול הלימודים שבו הוא לומד (להלן – משך מסלול הלימודים), ולא תעלה על משך |       |                |
|מסלול הלימודים ומחציתו.                                                                            |       |                |
|על אף האמור בכל דין  מלגות ומענקים ממשלתיים הניתנים כסיוע בשכר-לימוד לעניין תכנית לימודים – יבוטלו.|4.     |ביטול מלגות     |
|                                                                                                   |       |ומענקים         |
|השר ושר האוצר ממונים על ביצוע חוק זה, והם רשאים להתקין תקנות בנוגע לביצועו.                        |5.     |ביצוע ותקנות    |

|דברי – הסבר                                                                                                                  |
|                                                                                                                             |
|חינוך והשכלה הינם מוצר ציבורי ברוב מדינות העולם. בכולן, וגם בישראל, החינוך היסודי והתיכוני ממומן כולו על ידי המדינה. ברור    |
|המדינות גם החינוך הגבוה ממומן על ידי המדינה, מדינת ישראל היא מן הבודדות בעולם, לרבות העולם השלישי, שלא מתקיימת בה השכלה גבוהה|
|חינם לכל דורש וזכאי. הדבר תמוה במיוחד לנוכח העובדה שבישראל הסטודנט הוא בדרך-כלל חייל משוחרר שמאחוריו שלוש או ארבע שנות שירות |
|קשה למען מולדתו.                                                                                                             |
|מצב כזה לא מתקיים בשום מדינה אחרת.                                                                                           |
|השכלה אקדמית היא השקעה בהשבחתו של האדם והאזרח.                                                                               |
|                                                                                                                             |
|התועלת של ההשכלה הגבוהה אינה רק עבור הפרט, אלא עבור המדינה כולה. תועלת זו באה לידי ביטוי בשני היבטים: בהיבט המקצועי – קיים   |
|מתאם גבוה בין השכלה גבוהה ובין תוצר לאומי גולמי. בהיבט החברתי – השכלה גבוהה מהווה תנאי לתפקוד תקין של חברה דמוקרטית. מסיבות  |
|אלה מוצדקת ההשקעה של המדינה בהרחבת הבסיס החברתי של הנגישות להשכלה גבוהה.                                                     |
|                                                                                                                             |
|ללא השכלה גבוהה חינם, החברה הישראלית תמשיך להנציח בתוכה אי שוויון וניכור קשים, דמוקרטיה אמיתית היא צורת חיים המשתפת שכבות    |
|רחבות ככל האפשר, ובוודאי את אלה המוכשרים לכך, בנכסי תרבות והשכלה.                                                            |
|                                                                                                                             |
