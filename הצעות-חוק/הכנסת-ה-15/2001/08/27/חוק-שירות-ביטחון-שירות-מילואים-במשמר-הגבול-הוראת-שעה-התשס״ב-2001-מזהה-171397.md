|(ב) נקרא יוצא צבא לשירות מילואים כאמור בסעיף קטן (א) יתייצב                         |                      |
|לשירות במשמר הגבול בהתאם לאמור בצו.                                                 |                      |
|(ג) יוצא צבא, החייב להתייצב לשירות מילואים לפי סעיף זה,                             |                      |
|רואים אותו, לענין פרק חמישי לפקודת המשטרה, התשל"א-1971 2                            |                      |
|(להלן - פקודת המשטרה), כמי שנמנה עם כוחות משטרת ישראל מן הזמן                       |                      |
|שנקבע להתייצבותו בצו לפי סעיף קטן (א); לא התייצב, בלא צידוק                         |                      |
|מספיק, רואים אותו כאילו באותו זמן עזב את השירות שלא ברשות.                          |                      |
|(ר) שירות מילואים במשמר הגבול לפי סעיף זה דינו בדין שירות                           |                      |
|מילואים לכל דבר וענין, והוא כשאין הוראה מפורשת אחרת בחוק זה,                        |                      |
|לענין מסוים.                                                                        |                      |

|התשט"ו-1955 3 והתקנות לפיו כחייל כמשמעותו בסעיף 1 לאותו חוק,                        |בשירות מילואים        |

|משטרה בביר שמונה לענין זה؀ࠂࠆࠈࠌࠒ על ידי המפקח הכללי של משטרת ישראל,                  |                      |
