הצעת חוק לתיקון פקודת מס הכנסה (ביטול מקדמות מס), התשס”א-2001

|בפקודת מס הכנסה[1] אחרי סעיף 180 יבוא:                                                             |1.     |הוספת סעיף 180א |
|נישום שחב במס על הכנסה שנתקבלה משני מקורות הכנסה שונים       |(א)    |180א.      |"פטור ממקדמה     |       |                |
|כמשמעותם בסעיפים 2 ו-3 או מצירוף שני סכומים שנקבע לגביהם בכל |       |           |                 |       |                |
|דין שדינם כהכנסה לענין פקודה זו, יהיה, על אף האמור בפקודה זו,|       |           |                 |       |                |
|פטור מתשלום מקדמה לפי סימן זה על הכנסה מאחד ממקורות ההכנסה אם|       |           |                 |       |                |
|הכנסתו ממקור זה לאותה שנת מס שבה המקדמה היתה צריכה להשתלם    |       |           |                 |       |                |
|אינה עולה על 5,000 שקלים חדשים (להלן – הסכום הקובע).         |       |           |                 |       |                |
|שר האוצר רשאי בצו לשנות את הסכום הקובע."                     |(ב)    |           |                 |       |                |

דברי - הסבר

שכיר שיש לו הכנסה נמוכה נוספת על משכורתו, חייב כיום בתשלום מקדמות למס הכנסה גם אם מקדמות אלה גובהן הוא אפסי. הטרדה הכרוכה בתשלום נמוך זה רבה, והתועלת מועטה. לפיכך מוצע לבטל את חוב תשלום המקדמות בגין הכנסות אלה, עד לתקרה שנתית של 5,000 שקלים לשנת מס.
