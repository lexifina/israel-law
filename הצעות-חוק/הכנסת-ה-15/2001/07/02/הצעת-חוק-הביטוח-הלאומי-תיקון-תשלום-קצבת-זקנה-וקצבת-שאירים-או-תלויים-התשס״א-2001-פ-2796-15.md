הצעת חוק הביטוח הלאומי (תיקון - תשלום קצבת זקנה וקצבת שאירים או תלויים), התשס”א-2001

|בחוק הביטוח הלאומי (נוסח משולב), התשנ"ה-1995[1], בסעיף 320 במקום פסקה (ה) יבוא:                    |1.     |תיקון סעיף 320  |
|על אף האמור  בסעיף קטן (ג)(1), זכאי לקצבת זקנה שנעשה זכאי לקצבת תלויים או לקצבת שאירים וכן |"(ה)   |       |                |
|זכאי לקצבת תלויים או לקצבת שאירים שנעשה זכאי לקצבת זקנה, ישולמו לו את קצבת הזקנה וכן קצבת  |       |       |                |
|השאירים או התלויים, לפי הענין".                                                            |       |       |                |

דברי - הסבר

ישנן אלמנות של נפגעי תאונות עבודה אשר הצליחו במאמץ עילאי לגדל משפחה ולהתפרנס בחרוק שיניים.

דא עקא, משהן מגיעות לגיל זקנה נשללת מהם מחצית הקצבה, למרות ששלמו דמי ביטוח לאומי מלאים כל השנים.

בשנת 1995 תוקן החוק והן זכו למחצית הקצבה בהגיען לגיל זקנה. כעת מוצע להשלים את התיקון ולזכות אותן במלוא קצבת הזקנה.

הצעת חוק דומה בעיקרה  של ח"כ  אפי אושעיה הונחה על שולחן הכנסת ה- 14 ומספרה פ/1833.
