הצעת חוק דמי מחלה (היעדרות בשל מחלת ילד) (תיקון - הגדלת ימי מחלה למשפחות חד-הוריות), התשס”א-2001

|בחוק דמי מחלה (היעדרות בשל מחלת ילד), התשנ"ג-1993[1], בסעיף 1, במקום הסיפה המתחילה במילים "או שהילד|1.     |תיקון סעיף 1    |
|נמצא" יבוא:                                                                                        |       |                |
|"נמצא הילד בהחזקתו הבלעדית של העובד, זכאי העובד לזקוף עד 16 ימים בשנה של היעדרות בשל מחלת ילדו     |       |                |
|כאמור."                                                                                            |       |                |

דברי - הסבר

המצב כיום הוא, שכל הורה רשאי להשתמש ב-8 ימי מחלה בשנה ממכסת ימי המחלה שלו, כדי להישאר בבית עם ילדו החולה, כך שלמשפחה עם שני הורים ישנם 16 ימי מחלה בשנה למטרה זו.  ואילו חד-הוריים נאלצים להסתפק ב-8 ימי מחלה בלבד.

הצעת חוק זו באה להגדיל את מכסת ימי המחלה עבור חד-הוריים ל-16 יום, כך שמשפחות אלו יזכו להשוואת תנאיהן לאילו של משפחה בה ישנם שני הורים.
