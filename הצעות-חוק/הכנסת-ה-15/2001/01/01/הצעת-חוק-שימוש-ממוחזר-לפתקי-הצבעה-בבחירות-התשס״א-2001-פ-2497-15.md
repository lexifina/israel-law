שירותי משרד/הצעת חוק/3117ב

הכנסת החמש-עשרה

|הצעת חוק של חבר הכנסת אליעזר זנדברג                            |

הצעת חוק שימוש בנייר ממוחזר לפתקי הצבעה בבחירות,                           התשס”א-2001

|בחוק זה –                                                                                          |1.     |הגדרות          |
|"בחירות" – כמפורט בתוספת לחוק זה לרבות בחירות חוזרות, מיוחדות או מוקדמות;                          |       |                |
|"מיחזור" – כהגדרתו בחוק איסוף ופינוי פסולת למיחזור, התשנ"ג-1993[1],                                |       |                |
|"נייר ממוחזר" – נייר שהופק בתהליך מיחזור;                                                          |       |                |
|"השר" – השר לאיכות הסביבה.                                                                         |       |                |
|פתקי הצבעה המשמשים בבחירות יהיו מנייר ממוחזר בלבד.                                                 |2.     |שימוש בנייר     |
|                                                                                                   |       |ממוחזר          |
|השר  ממונה על ביצועו של חוק זה והוא רשאי להתקין תקנות לביצועו.                                     |3.     |ביצוע ותקנות    |

תוספת

(סעיף 1)

1. בחירות לכנסת ולראש הממשלה;
2. בחירות למועצה של רשות מקומית;
3. בחירות לראש רשות מקומית;
4. בחירות למועצה אזורית;
5. בחירות לראש מועצה אזורית.

דברי הסבר

מוצע לקבוע בחוק כי פתקי הצבעה בבחירות לכנסת, לראשות הממשלה ולרשויות מוניציפליות יהיו מנייר ממוחזר, זאת בשים לב לכמות הנייר העצומה הנדרשת בבחירות אלה ולהשלכות שיש לחקיקה שכזו על עקרונות השמירה על הסביבה.

עוד יתרום התיקון המוצע בחוק להרחבת פעילות מיחזור הנייר בארץ ויהווה תמריץ לפעולות מיחזור נוספות.
