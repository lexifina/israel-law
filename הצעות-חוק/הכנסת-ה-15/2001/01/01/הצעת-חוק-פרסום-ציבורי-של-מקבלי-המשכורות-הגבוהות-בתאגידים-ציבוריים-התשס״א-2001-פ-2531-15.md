הצעת חוק פרסום ציבורי של מקבלי המשכורות הגבוהות בתאגידים ציבוריים, התשס”א-2001

|בחוק זה –                                                                                          |1.     |הגדרות          |
|"תאגיד ציבורי" –ממשלת ישראל, רשות מקומית, עמותה, תאגיד שהוקם לפי חוק, גוף שנמצא בבעלות או בשליטה   |       |                |
|ישירה או עקיפה של הממשלה או של רשות מקומית, לרבות חברת בת ממשלתית וחברה מעורבת כמשמעותן בחוק החברות|       |                |
|הממשלתיות התשל"ה-1975[1], וכן כל גוף המתוקצב, במישרין או בעקיפין, מתקציב המדינה.                   |       |                |
|לא יאוחר מיום 1 בינואר בכל שנה יפרסם שר הפנים את משכורתיהם של העובדים הבכירים בתאגיד ציבורי        |2.     |פרסום           |
|שמשכורתם עולה על 20,000 ₪ בשני עיתונים יומיים שלפחות אחד מהם הוא עיתון נפוץ כמשמעותו בסעיף 1א לחוק |       |                |
|התכנון והבניה, התשכ"ה-1965[2], בעיתון המתפרסם מידי שבוע לפחות בעל תפוצה רחבה היוצא לאור בישראל בשפה|       |                |
|הערבית, ובאינטרנט; חובת הפרסום האמורה תחול גם על מינויים שנעשו במהלך השנה לאחר מועד הפרסום; מועד   |       |                |
|הפרסום יהא לא מאוחר מחודש לאחר המינוי.                                                             |       |                |
|שר הפנים ממונה על ביצוע חוק זה והוא יתקין תקנות לביצועו.                                           |3.     |ביצוע ותקנות    |

דברי - הסבר

חדשות לבקרים אנו עדים לתופעה בה תאגידים ציבוריים משלמים משכורות עתק לעובדיהם, בדין ולעתים רבות שלא בדין, והיעדר הפרסום מסייע לאותם תאגידים להתנהג שלא על פי נורמות התנהגות סבירות לתאגידים ציבוריים.

במטרה להיאבק בתופעה שבה עושים שימוש לרעה בכספי ציבור, מוצע להטיל על תאגידים ציבוריים חובת פרסום רשימת שמות העובדים המקבלים משכורות העולות על     20,000 ₪
