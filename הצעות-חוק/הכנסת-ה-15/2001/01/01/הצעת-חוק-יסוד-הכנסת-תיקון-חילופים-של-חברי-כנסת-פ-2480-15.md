|בחוק יסוד: הכנסת[1], בסעיף 43, האמור בסעיף קטן (ב) יסומן "(ג)" ולפניו יבוא:                        |1.     |תיקון סעיף 43   |
|נתפנתה מישרתו של חבר הכנסת, ואין ברשימה מי שימלא את המקום הפנוי, ימנה נשיא המדינה ללא דיחוי|"(ב)   |       |                |
|חבר חדש מבין האנשים הזכאים להבחר לכנסת לפי הצעת הסיעה, אשר מטעמה נבחר חבר הכנסת שמקומו     |       |       |                |
|התפנה."                                                                                    |       |       |                |

דברי - הסבר

התיקון המוצע מטרתו לאפשר לסיעה שהתפנה בה מקומו של חבר כנסת, להמשיך ולהיות מיוצגת באותו מספר מנדטים בו זכתה בבחירות. המצב החוקי הנוכחי עלול למנוע מסיעה כאמור לעשות זאת, ובכך לעוות את רצון הבוחר.
