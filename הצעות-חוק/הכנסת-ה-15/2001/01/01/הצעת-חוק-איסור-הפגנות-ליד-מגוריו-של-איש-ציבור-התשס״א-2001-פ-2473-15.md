הצעת חוק איסור הפגנות ליד מגוריו של איש ציבור, התשס”א-2001

|לא יערכו הפגנות בקרבת בתיהם הפרטיים או מעונותיהם הרשמיים של איש ציבור לרבות בן זוגו, בנו, אחיו     |1.     |                |
|והוריו.                                                                                            |       |                |
|בחוק זה -                                                                                          |2.     |                |
|"איש ציבור" - ראש-ממשלה, שר, סגן שר, חבר-הכנסת, ראש עיר ורשויות מקומיות, שופט, פקיד ממשלה, איש     |       |                |
|המשרת בכוחות הביטחון או המשטרה של מדינת ישראל ודיפלומט זר.                                         |       |                |
|לא יוצגו משמרות מחאה מכל סוג שהוא במרחק של פחות מ-200 מטרים מבתיהם או מעונם של אישי ציבור;         |3.     |                |
|הוראות סעיפים 1 ו-3 לא יחולו על הפגנה או משמרת מחאה הממוקמת מטעמים סבירים מול משרד או מקום עבודה   |4.     |                |
|ראשי של האמורים לעיל או בצומת ראשית או בכיכר מרכזית המצויים בקרבה לביתו או מעונו של איש ציבור.     |       |                |

דברי הסבר

החוק נועד למנוע הפעלת לחץ וטרור כלפי אישי ציבור על-ידי הפרעות למהלך חייהם הפרטיים והמשפחתיים. החוק בא להפריד בין הזכויות הדמוקרטיות להפגין בציבור, ולהביע דעה ולנסות להשפיע מחד – לבין ניצולה לשם הפעלת לחץ פיזי נפשי אנטי-דמוקרטי באופיו על איש הציבור ו/או על בני משפחתו, ו/או על שכניו, על-מנת למרר את חייהם על בסיס יום-יומי.
