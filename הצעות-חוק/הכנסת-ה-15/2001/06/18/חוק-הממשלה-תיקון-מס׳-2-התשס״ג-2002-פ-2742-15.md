|                                                                                                             |הממשלה         |
|8א. (א) מינה שר ועדה נושא או אירוע מסוים                             |"מתן סמכויות לועדת                    |               |
|המצויים בתחום אחריותו (להלן- ועדת בדיקה                              |בדיקה ממשלתית                         |               |
|ממשלתית), רשאי שר המשפטים, באישור                                    |                                      |               |
|הממשלה, לקבוע כי לוועדה יהיו הסמכויות                                |                                      |               |
|של ועדת חקירה, לפי סעיפים 9 עד 1 ו ו-27(ב)                           |                                      |               |
|לחוק ועדות חקירה, התשכ"ט-1968 2 (להלן -                              |                                      |               |
|חוק ועדות חקירה), ובלבד שבראש הועדה                                  |                                      |               |
|יעמוד שופט אשר יצא לגמלאות או שפרש.                                  |                                      |               |
|(ב) קבע שר המשפטים כי לועדת בדיקה                                    |                                      |               |
|ממשלתית יהיו הסמכויות של ועדת חקירה                                  |                                      |               |
|כאמור בסעיף קטן (א), תפורסם ברשומות                                  |                                      |               |

|וסמכויותיה.                                                          |                                      |               |
|(ג) לא יכהן כחבר בועדת בדיקה ממשלתית מי                              |                                      |               |
|שעלול להימצא במצב של ניגוד עניינים, בין                              |                                      |               |
|תפקידו כחבר הועדה לבין ענין אישי או י                                |                                      |               |
|תפקיד אחר שלו.                                                       |                                      |               |
|(ד) על ועדת בדיקה ממשלתית יחולו הוראות                               |                                      |               |
|סעיפים 14 ו-22 לחוק ועדות חקירה.                                     |                                      |               |
|(ה) בגמר דיוניה תעביר הועדה דין וחשבון על                            |                                      |               |
|תוצאות בדיקתה והמלצותיה אל השר אשר                                   |                                      |               |
|מינה אותה, והשר יביאן בפני הממשלה.                                   |                                      |               |
|(ו) מצאה ועדת בדיקה ממשלתית כי קיים חשש                              |                                      |               |
|לביצוע עבירה פלילית, תעביר את הדין                                   |                                      |               |
|והחשבון לידיעת היועץ המשפטי לממשלה.                                  |                                      |               |
|(ז) לעניין סעיף זה, "שר" - לרבות מספר שרים                           |                                      |               |
|במשותף".                                                             |                                      |               |
