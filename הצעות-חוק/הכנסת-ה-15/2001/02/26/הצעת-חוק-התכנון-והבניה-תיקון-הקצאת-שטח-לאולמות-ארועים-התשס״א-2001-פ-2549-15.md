הצעת חוק התכנון והבניה (תיקון - הקצאת שטח לאולמות ארועים),

התשס”א-2001

|בחוק התכנון והבניה, התשכ"ה–1965[1] (להלן – החוק העיקרי), בסעיף 62א(א), בסופו יבוא:                 |1.     |תיקון סעיף 62א  |
|בכפוף להוראות סימן ח' שבפרק ג' – הקמת אולמות ארועים באזורים המיועדים בתכנית לתעשיה או   |"(11)     |       |                |
|לתעשיה זעירה."                                                                          |          |       |                |
|אחרי סעיף 63א לחוק העיקרי יבוא:                                                                    |2.     |הוספת סעיף 63ב  |
|יועדה בתכנית מיתאר או בתכנית מפורטת קרקע למטרת תעשיה, יראו ייעוד כאמור   |63ב.   |"אולמות ארועים   |       |                |
|כאילו הוא כולל גם היתר להקמת אולמות ארועים; אין בהוראות סעיף זה כדי לגרוע|       |                 |       |                |
|מסמכותה של ועדה מקומית לכלול בתכנית מיתאר או בתכנית מפורטת, קרקע שיועדה  |       |                 |       |                |
|בתכניות כאמור למטרת אולמות ארועים בכל מספר שהוא."                        |       |                 |       |                |

דברי - הסבר

כיום לא ניתן להתיר בתכנית מיתאר או בתכנית מפורטת לקרקע למטרת תעשיה, הקמת אולמות אירועים. לפיכך, מוצע לחייב כי תכנית מיתאר או תכנית מפורטת לקרקע למטרת תעשיה תכלול היתר להקמת אולמות אירועים, וכי הנושא יהיה בסמכות הועדה המקומית לתכנון ולבניה.
