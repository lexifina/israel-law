|70ג. (א) רשות תימרור מקומית תציב, בצמוד לבית ספר, תמרור האוסר                      |-הסדר חניה לרכב    |                  |
|חניה או העמדת רבב, והיא רשאית לקבוע כי איסור החניה יחול רק בימים                   |להסעת תלמידים      |                  |
|מסוימים ובשעות מסוימות שבהם משמש מקום החניה להעלאה ולהורדה                         |                   |                  |
|של תלמידים: איסור חניה כאמור לא יחול על רכב המיועד להסעת 30                        |                   |                  |
|תלמידים ומעלה.                                                                     |                   |                  |
|(ב) גורלו של מקום שהחניה בו אסורה כאמור בסעיף קטן (א) יספיק                        |                   |                  |
|לחניית רבב אחד לפחות המיועד להסעת 30 תלמידים ומעלה.                                |                   |                  |
|(ג) אין בהוראות סעיף זה כדי לגרוע מחובה לפי כל דין לקבוע                           |                   |                  |
|הסדרי חניה לרבות הקצאת מקומות חניה, והפקעה לצורך הקצאה                             |                   |                  |
|כאמור.                                                                             |                   |                  |
|(ד) בסעיף זה, "בית ספר" - כהגדרתו בחוק פיקוח על בתי ספר,                           |                   |                  |
