הצעת חוק הכשרות המשפטית והאפוטרופסות (תיקון - שלילת אפוטרופסות מהורה רוצח הורה), התשס”ב-2001

|בחוק הכשרות המשפטית והאפוטרופסות, התשכ"ב-1962[1], בסעיף 27, האמור בו יסומן "(א)" ואחריו יבוא:      |1.     |תיקון סעיף 27   |
|הורה שהורשע בעבירה לפי סעיף 300 לחוק העונשין,                                              |"(ב)   |       |                |
|התשל"ז-1977[2] כלפי בן זוגו, לא יהיה אפוטרופוס של ילדם הקטין, אלא אם כן החליט בית המשפט    |       |       |                |
|אחרת מנימוקים שירשמו."                                                                     |       |       |                |

דברי - הסבר

על פי המצב הקיים היום, הורה שרוצח את ההורה האחר של הקטין נותר אפוטרופוס חוקי על הקטין. ביטול האפוטרופסות כרוך בהליך ארוך ומסובך, לעיתים אף נוצר מצב אבסורדי לפיו הרוצח, בהיותו אפוטרופוס לקטין, הופך אחראי על הרכוש שהוריש הקורבן לילדים המשותפים.

מוצע לקבוע בחוק כי מי שהורשע ברצח ההורה האחר של הקטין, לא יהיה האפוטרופוס לקטין, זולת מקרים מיוחדים בהם יוכל בית המשפט לקבוע אחרת מנימוקים שירשמו, כמו טובת הקטין.
