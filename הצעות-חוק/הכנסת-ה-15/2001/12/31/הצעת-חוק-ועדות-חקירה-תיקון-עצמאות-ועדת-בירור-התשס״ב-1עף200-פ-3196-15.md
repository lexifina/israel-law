הצעת חוק ועדות חקירה (תיקון - עצמאות ועדת בירור), התשס”ב-2001

|בחוק ועדות חקירה, התשכ"ט-1968[1], בסעיף 28(א) במקום הסיפה המתחילה במילים "ובלבד שלא נתמנתה" יבוא   |1.     |תיקון סעיף 28   |
|"ובלבד שבראש ועדה כאמור יעמוד שופט או שופט שיצא לגמלאות או שפרש", ובסופו יבוא:                     |       |                |
|על אף הוראות סעיף קטן (א), לא ימנה שר ועדת בירור בענין לגביו מונתה ועדת חקירה, ואם מונתה|"(א1)     |       |                |
|ועדת חקירה לאחר מינוי ועדת בירור, לא תמשיך ועדת הבירור בפעולתה."                        |          |       |                |

דברי - הסבר

חוק ועדות חקירה, התשכ"ט-1968 (להלן – החוק) קובע כי הממשלה רשאית להקים ועדת חקירה לגבי ענין שהוא בעל חשיבות ציבורית חיונית, שבראשה שופט. סעיף 28 לחוק קובע כי אין הוראותיו באות לגרוע מסמכותו של שר למנות ועדת בירור לשם בדיקת ענין שבתחום תפקידיו, אולם אין הגבלה על זהות העומד בראשה.

מוצע כי בדומה לועדת חקירה, גם בראש ועדת בירור יעמוד גורם עצמאי ובלתי תלוי. לפיכך מוצע לקבוע הוראה לפיה בראש ועדת בירור יעמוד שופט.

הצעת החוק תסייע למיצוי האמת, הן מן ההיבט העניני, והן מן ההיבט הציבורי.
