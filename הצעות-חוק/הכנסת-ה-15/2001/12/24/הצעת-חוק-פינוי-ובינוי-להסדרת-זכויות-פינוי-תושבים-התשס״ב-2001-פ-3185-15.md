הצעת חוק פינוי ובינוי להסדרת זכויות פינוי תושבים, התשס”ב-2001

|בחוק זה -                                                                                          |1.     |הגדרות           |
|"יזם" – אדם אשר קיבל על פי חוק זכויות לבנות על מקרקעין שעליהם מתגוררים תושבים, לאחר הסדר לפינוי    |       |                 |
|אותם תושבים;                                                                                       |       |                 |
|"מכרז פינוי ובינוי" – מכרז או תהליך אחר לקבלת הצעות מיזמים לניהול הליך של פינוי התושבים והסדרת     |       |                 |
|זכויותיהם ובינוי על המקרקעין המפונים בהתאם להוראות חוק זה;                                         |       |                 |
|"מקרקעין" – מקרקעין שבבעלות המדינה או בחזקתה, שלגביהם נתקבלה החלטה לאפשר בניה ופיתוח תוך פינוי     |       |                 |
|התושבים והסדרת זכויותיהם על ידי היזם, או שהוגדר כאזור שיקום בהתאם להוראות חוק בינוי ופינוי של אזורי|       |                 |
|שיקום, התשכ"ה-1965[1];                                                                             |       |                 |
|"תכנית" – תכנית כהגדרתה בחוק התכנון והבניה, התשכ"ה-1965[2] (להלן – חוק התכנון והבניה) המגדירה את   |       |                 |
|זכויות הבניה במקרקעין;                                                                             |       |                 |
|"תושב" – תושב היושב דרך קבע במקרקעין לפחות 7 שנים.                                                 |       |                 |
|תושב זכאי לפתח חצרותיו ולשנות כל דבר בבתיו, למעט פעולות שלגביהן דרוש היתר על פי חוק התכנון והבניה, |2.     |זכויות פיתוח     |
|התשכ"ה-1965.                                                                                       |       |לתושבים          |
|יזם יגיע להסדר עם תושבים במקרקעין שעליהם קיבל זכויות, ויתחיל בביצוע הבניה במקרקעין בתוך 3 שנים מיום|3.     |הגבלת פרק זמן    |
|שקיבל את זכויות הבינוי והפינוי במקרקעין; לא התחיל היזם בביצוע הבניה כאמור, אלא הגיע להסדר עם       |       |לביצוע פינוי     |
|התושבים - יחוייב בהשבת הזכויות.                                                                    |       |ובינוי           |
|מינהל מקרקעי ישראל או מדינת ישראל יכללו בכל מכרז פינוי ובינוי או בכל התקשרות לצורכי פינוי ובינוי,  |4.     |תנאי במכרז –     |
|תנאי כאמור בסעיף 5.                                                                                |       |הגבלת זמנים      |
|יזם יעניק לכל תושב, במסגרת הסדר לפינוי תושבים, אפשרות לקבל לפחות יחידת דיור אחת או יחידות דיור, הכל|5.     |זכויות תושבים    |
|לפי שווי הזכויות המוקצות לבניה והכל בהתאם לחוק התכנון והבניה, התשכ"ה-1965 אלא אם ויתר התושב על זכות|       |                 |
|זו בכתב; ויתר התושב על זכות זו, יקבל פיצוי בשווי שלא יפחת מערך יחידת הדיור או יחידות הדיור אותם היה|       |                 |
|מקבל אלמלא ויתר; אין בפיצוי זה כדי לפגוע בכל הסדר ובפיצויים אחרים שיינתנו לתושבים.                 |       |                 |
|הוראות חוק זה יחולו גם על יזם שקיבל זכויות במקרקעין לפני תחולתו של חוק זה ובלבד שלענין סעיף 4 יראו |6.     |תחולה            |
|את יום תחילת החוק ביום קבלת הזכויות על ידיו.                                                       |       |                 |

דברי - הסבר

ישנן שכונות רבות שהן שכונות שיקום. כדי למנוע סבל מהתושבים בשכונות על ידי היזמים  ולהחזיקם  כבני  ערובה מוצע  בזה לאפשר  להם לשפר  את איכות  חייהם  למעט

פעולות שדרוש להן היתר בניה על פי חוק. מוצע בזה לצמצם את זכויות היזם כדי למנוע ספסרות בכספי המדינה.
