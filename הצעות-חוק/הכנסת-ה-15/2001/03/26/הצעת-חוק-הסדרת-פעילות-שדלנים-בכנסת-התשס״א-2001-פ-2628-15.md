הצעת חוק הסדרת פעילות שדלנים בכנסת, התשס”א-2001

|בחוק זה –                                                                                          |1.     |הגדרות          |
|"שדלן" – מי שנוקט, דרך עיסוק, בפעולות לשכנוע חבר כנסת בענייני חקיקה והחלטות הכנסת;                 |       |                |
|"ועדה" – ועדת מוועדות הכנסת, לרבות ועדה משותפת וועדה לעניין מסוים;                                 |       |                |
|"בן משפחה" – בן זוג, הורה, צאצא וכל קרוב משפחה שפרנסתו עליו;                                       |       |                |
|"פעולת חקיקה" – ניסוח, הגשה, אישור, הנחה, דיון או הצבעה בקשר להצעת חוק בכנסת או בועדה או בקשר      |       |                |
|לתקנות הטעונות אישור או הסכמה של הכנסת או  של ועדה.                                                |       |                |
|מי ששואף לפעול כשדלן בכנסת, יבקש מיושב ראש הכנסת היתר לפעולתו;                             |(א)    |2.     |הכרה            |
|יושב ראש הכנסת ישיב לבקשה תוך שבועיים מיום שהוגשה;                                         |(ב)    |       |                |
|יושב ראש הכנסת יסדיר בתקנות, באישור ועדת הכנסת, תנאים לאישור בקשות לפי סעיף זה.            |(ג)    |       |                |
|לא יינתן היתר לפעולה כשדלן בכנסת –                                                                 |3.     |סייגים למתן היתר|
|למי שהוא עובד המדינה, כהגדרתו בחוק שירות המדינה (גמלאות) [נוסח משולב], התש"ל-1970[1];      |(1)    |       |                |
|למי שהוא עובד מפלגה, כמשמעותה בחוק מימון מפלגות, התשל"ג-1973[2], מהמפלגות המיוצגות בכנסת   |(2)    |       |                |
|המכהנת.                                                                                    |       |       |                |
|שדלן לא יהיה חבר בגוף בוחר, כהגדרתו בחוק שירות המדינה (סיוג פעילות מפלגתית ומגבית כספים),  |(א)    |4.     |סיוג פעילות     |
|התשי"ט-1959[3].                                                                            |       |       |מפלגתית         |
|מי שבהיותו חבר בגוף בוחר ביקש לפעול כשדלן, תיפסק כהונתו בגוף הבוחר עם אישור בקשתו.         |(ב)    |       |                |
|אסור לשדלן –                                                                                       |5.     |איסורים         |
|להציע או לתת לחבר הכנסת או לעובד הכנסת, או לבני משפחותיהם, מתנה או טובת הנאה, למעט מתנה    |(1)    |       |                |
|שמותר לתיתה על פי חוק שירות הציבור (מתנות), התש"ם-1979[4];                                 |       |       |                |
|להטעות חבר כנסת ביחס לעובדה מהותית כלשהי הנוגעת לפעולת חקיקה;                              |(2)    |       |                |
|ליצור מצג מטעה של טובת או רעת הציבור הנוגעת לפעולת חקיקה;                                  |(3)    |       |                |
|לפעול בשם אדם או ארגון שאינו קיים, או בשם אדם או ארגון קיים – ללא הסכמתו.                  |(4)    |       |                |
|העובר על הוראות חוק זה, ישלול יושב ראש הכנסת את ההיתר שנתן לו לפעול כשדלן בכנסת; לא ייתן יושב ראש  |6.     |עונשין          |
|הכנסת לאותו אדם היתר לפעול כשדלן, במשך חמש שנים מיום שנשלל רשיונו.                                 |       |                |
|בחוק משכן הכנסת ורחבתו, התשכ"ח-1968[5], סעיף 29ב – בטל.                                            |7.     |תיקון חוק משכן  |
|                                                                                                   |       |הכנסת ורחבתו    |

דברי הסבר

הצעת החוק באה להסדיר את עבודת השתדלנים בכנסת ולקבוע כי:

|שדלן לא יהיה עובד מדינה, עובד מפלגה או חבר בגוף בוחר של מפלגה.                                                     |1.      |
|לא ייתן שדלן מתנה או טובת הנאה לחבר כנסת ולא יטעה במכוון או יספק מידע שקרי לחבר כנסת.                              |2.      |
|שדלן אשר יעבור על הוראות החוק, לא יוכל לעבוד כשדלן בכנסת במשך חמש שנים.                                            |3.      |

הצעות חוק דומות הונחו על שולחן הכנסת השתיים עשרה והשלוש עשרה.
