הצעת חוק סדר הדין הפלילי (תיקון - עדות מוקדמת של נפגע מעבירה של סחר בבני אדם לעיסוק בזנות), התשס”ב-2001

|בחוק סדר הדין הפלילי [נוסח משולב], התשמ"ב-1982[1], בסעיף 17 האמור בו יסומן "(א)" ובסופו יבוא:      |1.     |תיקון סעיף 117  |
|הוגש כתב אישום לבית משפט או נפתחה חקירה בעבירה לפי סעיף 203א לחוק העונשין, התשל"ז –        |"(ב)   |       |                |
|1977[2], רשאי בית המשפט לגובת לאלתר עדותו של מי שלהנחת דעתו של בית המשפט נפגע מהעבירה      |       |       |                |
|האמורה על פי בקשתו של תובע או של מי שעשוי להיות נאשם בעבירה; החלטת בית המשפט בבקשה תינתן לא|       |       |                |
|יאוחר מתום 7 ימים מיום הגשתה."                                                             |       |       |                |

דברי - הסבר

הצעת חוק זו באה לקבוע כי כאשר נפתחה חקירה בעבירה של סחר בבני אדם לעיסוק בזנות בית המשפט יגבה עדות של קורבנות העבירה לאלתר. זאת על מנת לאפשר לקורבנות לחזור בהקדם האפשרי לארץ מוצאם. החלטת בית המשפט בבקשה כאמור תינתן לא יאוחר מתום 7 ימים מיום הגשת הבקשה.
