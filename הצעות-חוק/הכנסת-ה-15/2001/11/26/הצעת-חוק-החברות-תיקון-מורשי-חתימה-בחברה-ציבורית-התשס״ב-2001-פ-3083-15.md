הצעת חוק החברות (תיקון - מורשי חתימה בחברה ציבורית), התשס”ב-2001

|בחוק החברות התשכ"ט-1999[1] (להלן – החוק עיקרי), בסעיף 1, אחרי ההגדרה "מיזוג" יבוא:                 |1.     |תיקון סעיף 1    |
|""מורשה חתימה" – מיופה כח לפעול בחשבון בנק של חברה, ובלבד שהוא רשום אצל התאגיד הבנקאי כמי שרשאי    |       |                |
|לפעול בחשבון;                                                                                      |       |                |
|אחרי סעיף 264 לחוק העיקרי יבוא:                                                                    |2.     |הוספת סעיף 264א |
|לא יהיה תוקף להתחייבות ממונית של חברה ציבורית אלא אם ניתנה בידי שני   |264א.      |"התחייבות ממונית |       |                |
|מורשי חתימה לפחות".                                                   |           |של חברה ציבורית  |       |                |

דברי הסבר

לאור ריבוי מקרים שבהם ניתנו התחייבויות ממוניות של חברות ציבוריות בחריגה מהרשאה, וללא כיסוי, מוצע לקבוע כי באופן קוגנטי יהיה תוקף להתחייבות של חברה ציבורית רק אם ניתנה בידי שני מורשי חתימה לפחות. בכך ניתן יהיה לצמצם את התופעה השלילית רבת ההיקף של התחייבויות ממוניות שניתנו בחריגה מהרשאה או שהחברה איננה יכולה לעמוד בהן.
