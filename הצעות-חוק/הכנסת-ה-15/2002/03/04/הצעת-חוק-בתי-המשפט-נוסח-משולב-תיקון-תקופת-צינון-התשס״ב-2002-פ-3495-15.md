הצעת חוק בתי המשפט [נוסח משולב] (תיקון - תקופת צינון), התשס”ב-2002

|בחוק בתי המשפט [נוסח משולב], התשמ"ד-1984[1], בסעיף 2, האמור בו יסומן (א) ואחריו יבוא:              |1.     |תקופת צינון ליועץ|
|                                                                                                   |       |המשפטי לממשלה    |
|                                                                                                   |       |ולפרקליט המדינה  |
|לא ימונו היועץ  המשפטי לממשלה או פרקליט המדינה, לשופט בית המשפט העליון אלא אם עברה תקופה  |"(ב)   |       |                 |
|של 5 שנים מיום סיום כהונתם."                                                              |       |       |                 |

דברי - הסבר

כדי שההחלטות של היועץ המשפטי ופרקליטת המדינה תהיינה אובייקטיביות בצורה מוחלטת. מוצע שתהיה תקופת צינון כדי שגם למראית עין יהיה ברור ששיקוליה אינם קשורים למינוי אפשרי לבית המשפט העליון.
