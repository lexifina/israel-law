שרותי משרד/הצעת חוק/5228ד

הכנסת החמש-עשרה

|הצעת חוק של חבר הכנסת אופיר פינס-פז                                   |

הצעת חוק סיוג מועמדות של נבחר במוסדות ההסתדרות הכללית החדשה שפרש מסיעתו, התשס”ב-2002

|בחוק זה –                                                                                          |1.     |הגדרות           |
|"מוסדות ההסתדרות" – כל גוף נבחר בהסתדרות הכללית החדשה ולרבות הנהגת ההסתדרות והגופים הנבחרים במרחבים|       |                 |
|השונים;                                                                                            |       |                 |
|"פרישה מסיעה" – לרבות הצבעה במוסדות ההסתדרות שלא בהתאם לעמדת הסיעה, ואולם, הצבעה כאמור לא תיחשב    |       |                 |
|כפרישה אם הנבחר למוסדות ההסתדרות לא קיבל כל תמורה בעד הצבעתו;                                      |       |                 |
|"תמורה" – במישרין או בעקיפין, בהבטחה או בהתחייבות לעתיד, ולרבות הבטחת מקום ברשימת מועמדים למוסדות  |       |                 |
|ההסתדרות, או מינוי הנבחר עצמו או אדם אחר לתפקיד כלשהו.                                             |       |                 |
|נבחר במוסדות ההסתדרות הכללית החדשה שפרש מסיעתו ולא התפטר מכהונתו סמוך לפרישתו, לא ייכלל, בבחירות   |2.     |סייג למועמדות    |
|הבאות למוסדות ההסתדרות, ברשימת מועמדים שהגישה מפלגה שהיתה מיוצגת על ידי סיעה במוסדות ההסתדרות בעת  |       |נבחר במוסדות     |
|פרישתו.                                                                                            |       |ההסתדרות הכללית  |
|                                                                                                   |       |החדשה שפרש מסיעתו|

דברי הסבר

הצעת החוק באה להשוות המצב הקיים לגבי הבחירות לכנסת (מכח סעיף 6א לחוק-יסוד: הכנסת) לזה הקיים לגבי הבחירות להסתדרות הכללית החדשה על מנת למנוע מצב של קלנתריזם. הצעת החוק באה למנוע מצב שבו בעל תפקיד הסתדרותי מטעם מפלגה מבצע מהלך הנוגד את עמדת מפלגתו תוך הסכם עם מפלגה אחרת שתשריין לו מקום ברשימת המועמדים שלה בבחירות הבאות להסתדרות.
