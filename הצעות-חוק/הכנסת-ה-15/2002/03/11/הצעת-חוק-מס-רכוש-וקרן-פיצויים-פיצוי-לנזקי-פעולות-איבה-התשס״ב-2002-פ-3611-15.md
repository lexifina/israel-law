הצעת חוק מס רכוש וקרן פיצויים (פיצוי לנזקי פעולות איבה), התשס”ב-2002

|בחוק מס רכוש וקרן פיצויים, התשכ"א-1961[1], בסעיף 36, אחרי סעיף קטן (ב) יבוא:                       |1.     |תיקון הגדרת "נזק|
|                                                                                                   |       |עקיף"           |
|ישולמו פיצויים בעד נזק איבה שנגרם עקב פעולות ששר הבטחון הכריז עליהן כפעולות איבה שארעו  |"(ב1)     |       |                |
|החל ביום 1 בספטמבר 2001 בהתאם לכללים שיקבע שר האוצר כאמור בסעיף קטן (א); לענין סעיף זה  |          |       |                |
|"נזק איבה" – נזק שנגרם לגופו של נכס וכן הפסד, מניעת רווח או אי אפשרות לנצל נכס".        |          |       |                |
|שר האוצר באישור ועדת הכספים יתקין תקנות לביצוע הוראות חוק זה בתוך שלושה חודשים מיום פרסומו.        |2.     |תקנות וביצוע    |

דברי הסבר

העימות בו מצויה ישראל בשנה האחרונה גרם נזק כבד לבעלי נכסים במדינת ישראל. כיום, אין מקבל בעל נכס פיצוי על הנזק העקיף שנגרם לו עקב פעולת איבה (למעט שמונה יישובים שזכאותם נקבעה בתקנות). לאחר פיגוע נגרמים נזקים עקיפים כבדים לבעלי עסקים – נזק באבדן הזמנות לבעל עסק, נזק למשך זמן סגירת העסק לשיקומו, אי תשלום שכר לעובדים. ההצעה מבקשת לתקן מצב זה ולקבוע זכאות לנזק עקיף לכל בעל נכס שנפגע כתוצאה מפעולות איבה על פי תקנות מס רכוש וקרן פיצויים (תשלום פיצויים) (נזק מלחמה ונזק עקיף), התשל"ג-1973 אשר חלות כיום רק לגבי ישובים בודדים.
