הצעת חוק איור הכרה בישות מדינית בשטחי ארץ ישראל, התשס”ב-2002

|לענין חוק זה –                                                                                     |1.     |הגדרות          |
|"החלטת ממשלה" – החלטה של הממשלה, בדרך של אישור אמנה או הסכם או בדרך אחרת, לרבות התחייבות לעתיד     |       |                |
|והתחייבות המותנית בתנאים;                                                                          |       |                |
|"שטח" – שטחי יהודה , שומרון או חבל עזה.                                                            |       |                |
|הצעה להחלטת ממשלה לפיה תוכר ישות מדינית בשטח בארץ ישראל, טעונה אישור של הכנסת בהחלטה שתקבל ברוב    |2.     |אישור הכנסת     |
|חבריה, טרם קבלתה בממשלה.                                                                           |       |להכרה בישות     |
|                                                                                                   |       |מדינית בשטחי ארץ|
|                                                                                                   |       |ישראל           |

�
�
דברי - הסבר
�
לאחרונה פורסמו ידיעות בדבר נכונות הממשלה לאפשר הקמת יישות מדינית פלסטינית בתחומי ארץ ישראל שממערב לירדן.
�
הקמת יישות מדינית נוספת בתחומי ארץ ישראל שממערב לירדן, הינה גורלית לעתידה של מדינת ישראל ולגבולותיה.

�
תיחום גבולות המדינה כשלעצמו הינו בעל אופי תחרותי מובהק.
�
לפיכך, מתחייב תהליך אישור פרלמנטרי להסכמים שתוצאותם הקמת יישות מדינית כאמור, או הכרה בה.
