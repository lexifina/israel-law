|בחוק חובת המכרזים, התשנ"ב-1992[1], בסעיף 3א,  אחרי סעיף קטן (ג) יבוא:                              |1.     |תיקון סעיף 3א   |
|על אף האמור בכל דין, המדינה, הרשויות המקומיות והגופים המצויים בשליטתן של המדינה או הרשויות |"(ד)   |       |                |
|המקומיות לא יתקשרו עם יצרן או עם נותן שירותים שאינו מקומי, אלא אם למעלה מ-85% מהייצור,     |       |       |                |
|השירותים והעבודות המוצעים יתבצעו על ידי אזרחי המדינה או תושביה ובלבד שלא התקיים אחד מאלה:  |       |       |                |

|המיוצרים בישראל".                                                                 |       |       |       |                |
|פסילת ההצעה תעמוד בסתירה להתחייבויות כמפורט בסעיף קטן (א(2)".                     |(3)    |       |       |                |

דברי - הסבר

מוצע למנוע ממדינת ישראל וכן מהרשויות המקומיות או מגוף שנמצא בשליטתן להתקשר במכרז עם יצרנים או נותני שירותים שאינם ישראלים אלא אם כן למעלה מ-85% מהייצור, השירותים והעבודות המוצעים יתבצעו על ידי ישראלים.

כן מוצע כי ההעדפה האמורה לתוצרת מקומית לא תחול בחריגים מסויימים. כך, למשל, במצב בו מחיר הטובין מן הסוג נשוא המכרז שאינם מיוצרים בישראל נמוך ממחצית ממחיר הטובין המיוצרים בישראל.
