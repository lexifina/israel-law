הצעת חוק לתיקון פקודת התעבורה (תיקון - איסור כניסה למשאיות בדרך מהירה), התשס”ב-2002

|בפקודת התעבורה [1], אחרי סעיף 71 יבוא:                                                             |1.     |הוספת סעיף 71א  |
|נוהג ברכב מסחרי שמשקלו הכולל מעל 4000 ק"ג לא יכנס לדרך מהירה או לדרך שאינה דרך|71א.   |"הגבלת תנועה|       |                |
|עירונית, שאין בה יותר ממסלול אחד בכיוון הנסיעה, בין השעות 07:00-09:00 ובין    |       |לרכב מסחרי  |       |                |
|השעות 16:00-18:00."                                                           |       |            |       |                |
|                                                                                                                             |
|דברי  הסבר                                                                                                                   |
|                                                                                                                             |
|הצעה לתיקון פקודת התעבורה באה להקל על העומס הבלתי נסבל בכבישים ראשיים, בין עירוניים, בשעות השיא בבוקר ובערב, כאשר תושבי      |
|המדינה נוסעים בכבישים, בדרכם אל עבודתם ובחזרה. התנועה בשעות אלה יוצרת מצב בלתי נסבל, בעיקר בכבישים דו מסלוליים בהם היא מתעכבת|
|למשך שעות. עקב נסיעת משאיות בכבישים אלה, נוצרים פקקים בלתי נסבלים, הגורמים לנהגים להתנהג בצורה עצבנית ובלתי אחראית שיש בה כדי|
|לסכן את הנוסעים  בכבישים ולגרום בעקיפין לתאונות דרכים, שיתכן והיו יכולות להמנע.                                              |
|אין כל סיבה שמשאיות המעבירות סחורה או אביזרים כבדים, לא יסיעו את סחורתם בשעות בהן התנועה על הכביש דלילה יותר, כמו בשעות הבוקר|
|המוקדמות, שעות הצהריים, והלילה ובכך ימנע העומס בכבישים וסיכונים אחרים, בהן תאונות דרכים.                                     |

הצעת חוק זהה של ח"כ לימור לבנת וקב' חכי"ם הונחה על שולחן הכנסת ה-15 ומספרה פ/1329.
