|הצעת חוק של חבר הכנסת איוב קרא                                |

הצעת חוק הסדרים במשק המדינה (תיקוני חקיקה להשגת יעדי התקציב)

(תיקון - פטור מארנונה לנכה צבא הגנה לישראל), התשס”ב-2002

|בחוק ההסדרים במשק המדינה (תיקוני חקיקה להשגת יעדי התקציב), התשנ"ג-1992[1], בסעיף 12, אחרי סעיף קטן |1.     |תיקון סעיף 12   |
|(ג) יבוא:                                                                                          |       |                |
|על אף האמור בסעיף קטן (ג), מועצת רשות מקומית תעניק פטור מארנונה לדירה המשמשת למגורים       |"(ד)   |       |                |
|בבעלותו של נכה בהגדרתו בסעיף 1 לחוק הנכים (תגמולים ושיקום) [נוסח משולב], התשי"ט-1959[2]    |       |       |                |
|(להלן – חוק הנכים), שדרגת נכותו לא פחותה                                                   |       |       |                |
|מ-20%, ובלבד שדירת המגורים כאמור היא הנכס היחיד של הנכה;                                   |       |       |                |
|לענין זה -                                                                                 |       |       |                |
|את דרגת הנכות תקבע ועדה רפואית, לפי סעיף 10 בחוק הנכים.".                                  |       |       |                |

דברי - הסבר

מוצע תיקון בחקיקה שנכי צה"ל מדרגת נכות 20% עד 100% יקבלו פטור מתשלום ארנונה על בית שהוא בפועל משכנו הפרטי לכל דבר ועניין ואם נכה צה"ל מחזיק בית מגורים נוסף ישלם ארנונה רגילה.
