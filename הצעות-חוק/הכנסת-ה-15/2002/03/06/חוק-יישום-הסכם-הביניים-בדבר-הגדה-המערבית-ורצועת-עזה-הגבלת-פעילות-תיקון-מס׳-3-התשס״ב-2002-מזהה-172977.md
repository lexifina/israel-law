|מתפרסמת בזה הצעת חוק מטעם הממשלה;                                                                                          |
|הצעת חוק יישום הסכם הביניים בדבר הגדה המערבית ורצועת עזה                                                                   |
|(הגבלת פעילות) (תיקון מס' 3), התשס"ב-2002                                                                                  |
|1. בחוק יישום הסכם הביניים בדבר הגדה המערבית ורצועת עזה (הגבלת פעילות),                                 |הוספת סעיף 7K     |
|התשנ"ה-1994 1, אחרי סעיף 7 יבוא:                                                                        |                  |
|7א (א) המגייס אזרח ישראלי או תושב ישראל לשרת בכוח מזוין של                             |"איסור גיוס     |                  |
|המועצה או בכוח מזוין זר אחר הפועל בתחומי המועצה, דינו - מאסר                           |והתגייסות       |                  |
|שבע שנים.                                                                              |                |                  |
|(ב) אזרח ישראלי או תושב ישראל המתגייס לשרת באחד                                        |                |                  |
|מהכוחות המזוינים באמור בסעיף קטן (א), או המשתייך לכוח כאמור, או                        |                |                  |
|הפועל בשירותו של כוח כאמור, דינו - מאסר חמש שנים.                                      |                |                  |
|(ג) לענין סעיף זה, "כוח מזוין" - לרבות גופי מודיעין של                                 |                |                  |
|המועצה."                                                                               |                |                  |

|דברי הסבר                                                                                                                |
|בצדה הוא שבע שנות מאסר, ואילו התגייסות או                    |קיימת תופעה של גיוס תושבי מדינת ישראל                      |
|פעילות במסגרת גורמים אלה תהיה עבירה פלילית,                  |ואזרחיה, בעיקר מקרב תושבי מזרח ירושלים, למנגנוני           |
|שהעונש המרבי הקבוע בצדה הוא חמש שנות מאסר,                   |הביטחון של הרשות הפלסטינית ולכוחות מזוינים                 |
|וזאת כדי ליתן בידי רשויות האכיפה כלים חוקיים                 |אחרים הפועלים בשטחי הרשות הפלסטינית, ופעילות               |
|להתמודד עם תופעה זו.                                         |של מגויסים אלה בשירות הכוחות המזוינים האמורים              |
|עבירות דומות, שעניינן גיוס והתגייסות לכוח מזוין              |בתחומי מדינת ישראל ובתחומי המועצה.                         |
|של מדינת חוץ, מצויות בסעיף 221 לחוק העונשין,                 |מציאות זו פוגעת בביטחון המדינה. ואינה                      |
|התשל"ז-1977 אך עבירות אלה אינן ישימות, לפי לשונן,            |מתיישבת עם כיבוד ריבונותה של מדינת ישראל.                  |
|על התופעה המפורטת לעיל, בין השאר ؀ࠂࠈהואיל וסעיף 122          |מוצע לקבוע כי גיוס אזרחי מדינת ישראל ותושביה               |
|לחוק העונשין עוסק ב"מדינת חוץ".                              |למנגנונים שונים ברשות הפלשתינית ולכוחות מזוינים            |
|                                                             |אחרים יהיה עבירה פלילית, שהעונש המרבי הקבוע                |
