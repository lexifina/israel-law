הצעת חוק לתיקון פקודת העיריות (תיקון - מזכיר העירייה), התשס”ב-2002

|בפקודת העיריות[1] (להלן – הפקודה) בסעיף 1, אחרי ההגדרה "מועצה" יבוא:                                |1.     |תיקון סעיף 1     |
|"מזכיר" – מי שמונה לכך על ידי המועצה ובאין מזכיר  המנהל הכללי או עובד אחר של העיריה שהמועצה החליטה  |       |                 |
|שימלא את תפקידי המזכיר לפי הפקודה;".                                                                |       |                 |
|                                                                                                    |       |                 |
|בפקודה, בסעיף 167(א), במקום "מזכיר או מנהל כללי" יבוא "מזכיר".                                      |2.     |תיקון סעיף 167   |
|                                                                                                    |       |                 |
|בפקודה, בסעיף 170(ב1)(1) לפקודה, אחרי "מנהל כללי" יבוא "מזכיר".                                     |3.     |תיקון סעיף 170   |
|                                                                                                    |       |                 |
|תחילתו של חוק זה ביום תחילתו של חוק לתיקון פקודת העיריות (מס' 77), התשס"א-2001[2].                  |4.     |תחילה            |
|                                                                                                    |       |                 |
|דברי הסבר                                                                                                                     |
|לאחרונה תוקנה פקודת העיריות והוספו לה הוראות העוסקות במזכירים ובמנכ"לים. במסגרת זו תוקן, בין היתר, סעיף 167(א) לפקודה, ונקבע  |
|כי עירייה יכולה מעתה לבחור מנכ"ל או מזכיר. עד לתיקון זה לא כללה הפקודה התייחסות למנכ"ל של עיריה.                              |
|מן התיקון עולות שתי בעיות עיקריות:                                                                                            |
|האחת – מלשון הסעיף ניתן להבין, כי עירייה אינה יכולה לבחור גם במזכיר וגם במנכ"ל, אלא רק באחד מהם. אולם בפועל קיימות היום עיריות|
|בהן מאוישים שני התפקידים גם יחד, לכאורה בניגוד לאמור בפקודה, ויש צורך לסיים כהונתו של אחד מן השניים, גם בניגוד לרצונה של      |
|העירייה וצרכיה.                                                                                                               |
|השניה – הפקודה מעניקה סמכויות סטוטוריות למזכיר בלבד. סמכויות אלה לא הוענקו במקביל גם למנכ"ל. התוצאה היא כי בעירייה שבה מכהן   |
|מנכ"ל בלבד, הוא אינו מוסמך לפעול את אותן פעולות שרק מזכיר הוסמך להן, מאחר ומדובר בסמכויות מהותיות.הדבר פוגע ביכולת העיריה     |
|לתפקד.                                                                                                                        |
|יש להעיר כי מבחינה מהותית קיים הבדל בין תפקידי "מזכיר" ובין תפקידי "מנכ"ל", ולא ניתן להפכם  למקשה  אחת  באופן מלאכותי. כך,    |
|למשל, משמש מזכיר לעתים קרובות כ -  עובד עיריה שמשרת משך שנים ארוכות את כלל העירייה וחברי המועצה ואינו צמוד בהכרח לראש רשות    |
|מסוים. לפיכך חשוב כי תפקיד זה יעוגן בחקיקה, מבלי שעיריות יסיקו מהתיקון כי עליהן לבחור באחד מבעלי התפקידים.                    |
|סעיף 170(ב1)(1) לפקודה, קובע כי לעניין משרות מסוימות יש חובה להביא בפני ועדת המכרזים הדנה באיוש אותו תפקיד חוות דעת של היועץ  |
|המשפטי של העירייה. הסעיף מפרט מהן אותן משרות (גזבר, יועץ משפטי, מבקר, מהנדס, מנהל כללי או פקח). רשימה זו אינה כוללת משרה של   |
|מזכיר, ויש להוסיפה.                                                                                                           |
|לאור האמור לעיל, ועל מנת לאפשר את המשך פעילותן התקינה של עיריות מבלי לפגוע בתכליתם של התיקונים שנעשו, יש לתקן תיקון נוסף את   |
|הפקודה על מנת להבהיר את הנקודות לעיל.                                                                                         |
