שרותי משרד/הצעת חוק/4834מ

הכנסת החמש-עשרה

|הצעת חוק של חבר הכנסת אבשלום וילן                                     |

הצעת חוק יישום ההסכם בדבר רצועה עזה ואזור יריחו (הסדרים כלכליים והוראות שונות) (תיקוני חקיקה) (תיקון - קיזוז חיובים), התשס”ב-2002

|בחוק יישום ההסכם בדבר רצועת עזה ואזור יריחו (הסדרים כלכליים והוראות שונות) (תיקוני חקיקה),         |1.     |תיקון סעיף 16ב  |
|התשנ"ה-1994[1], בסעיף 16, במקום סעיף קטן (ב) יבוא:                                                 |       |                |
|מן הסכומים המועברים יקוזזו חיובים כספיים נוספים, שהינם חיובים כספיים קצובים, שהרשות        |"(ב)   |       |                |
|הפלסטינית או תאגידים שבשליטתה או שבניהולה חבים –                                           |       |       |                |
|לישראל או לתאגידים שבשליטתה או שבניהולה;                                          |(1)    |       |       |                |
|לאדם אחר בישראל וניתנה לכך הסכמת הרשות הפלסטינאית או בהתקיים התנאים שקבע שר האוצר |(2)    |       |       |                |
|ובהתאם להסדרים שקבע."                                                             |       |       |       |                |

דברי - הסבר

�
נוסח החוק דהיום מבחין בין שלוש הוראות קיזוז שונות: הוראה קשיחה המחייבת קיזוז חובות של הרשות הפלסטינית לישראל מהסכומים המועברים לרשות, הוראת קיזוז שניה המעניקה לשר האוצר שיקול דעת באשר להוראת קיזוז של חיובים כספיים שהרשות הפלסטינית או תאגידים שבשליטתה או שבניהולה חבים למדינה או לתאגידים שבשליטתה או שבניהולה, והוראת קיזוז שלישית המסמיכה את שר האוצר להורות על קיזוז גם לאדם אחר בישראל, בתנאי שהתקיימו תנאים שקבע שר האוצר ובהתאם להסדרים שקבע.
�
מוצע לשנות את הוראות הקיזוז המפורטות לעיל להוראות קשיחות, המחייבות קיזוז של החיובים הכספיים של הרשות הפלסטינית או תאגידים שבשליטתה או שבניהולה חבים למדינה או לתאגידים שבשליטתה או שבניהולה או לאחרים בישראל, וזאת כאשר המדובר בחיוב כספי קצוב.
�
