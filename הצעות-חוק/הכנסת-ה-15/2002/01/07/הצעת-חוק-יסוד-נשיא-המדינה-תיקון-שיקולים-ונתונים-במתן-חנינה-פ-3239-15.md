הצעת חוק יסוד: נשיא המדינה (תיקון - שיקולים ונתונים במתן חנינה)

|בחוק יסוד: נשיא המדינה, התשכ"ד-1964[1], בסעיף 11, אחרי סעיף קטן (ב) יבוא:                          |1.     |תיקון סעיף 11   |
|השיקולים והנתונים אותם יביא נשיא המדינה בחשבון בבואו לחון עבריינים או להקל בעונשם –     |"(ב1)     |       |                |
|ייקבעו בחוק".                                                                           |          |       |                |

דברי - הסבר

כיום, אין בחוק-יסוד: נשיא המדינה כל אזכור לשיקולים או לנתונים אותם צריך הנשיא להביא בחשבון בבואו להחליט בדבר חנינת עבריינים או הקלה בעונשם. על פי התיקון, יפנה הסעיף לחוק בו ייקבעו שיקולים אלה.
