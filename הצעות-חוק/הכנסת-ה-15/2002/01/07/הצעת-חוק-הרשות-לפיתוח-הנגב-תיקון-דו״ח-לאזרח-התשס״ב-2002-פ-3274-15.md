הצעת חוק הרשות לפיתוח הנגב (תיקון - דו”ח לאזרח), התשס”ב-2002

|בחוק הרשות לפיתוח הנגב, התשנ"ב-1991[1] אחרי סעיף קטן (א) יבוא:                                     |1.     |תיקון סעיף 24   |
|הרשות תפרסם מעת לעת, דין וחשבון, שיכלול מידע אודות ההטבות הניתנות לתושבי הנגב או לאזרח  |"(א1)     |       |                |
|המעתיק את מקום מגוריו לנגב; דין וחשבון כאמור יועמד לעיון הציבור.                        |          |       |                |

דברי - הסבר

מוצע לחייב בחוק את הרשות לפיתוח הנגב להכין דו"ח שיועד לציבור, ובו פירוט ההטבות הניתנות בנגב, כך תוכל הרשות לסייע למעבר תושבים לנגב.
