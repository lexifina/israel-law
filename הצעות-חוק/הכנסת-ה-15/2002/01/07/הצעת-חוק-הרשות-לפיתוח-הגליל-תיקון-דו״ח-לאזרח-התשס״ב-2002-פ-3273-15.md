הצעת חוק הרשות לפיתוח הגליל (תיקון - דו”ח לאזרח), התשס”ב-2002

|בחוק הרשות לפיתוח הגליל, התשנ"ד-1993[1] בסעיף 24, אחרי סעיף קטן (א) יבוא:                          |1.     |תיקון סעיף 24   |
|הרשות תפרסם מעת לעת, דין וחשבון שיכלול מידע אודות כל ההטבות הניתנות לתושבי הגליל, או    |"(א1)     |       |                |
|לאזרח המעתיק את מגוריו לגליל; דין וחשבון כאמור יועמד לעיון הציבור.                      |          |       |                |

דברי - הסבר

מוצע לחייב בחוק את הרשות לפיתוח הגליל להכין דו"ח שיועד לציבור ובו פירוט ההטבות הניתנות בגליל. כך תוכל הרשות לסייע למעבר תושבים לגליל.
