הצעת חוק למניעת הסתננות (עבירות ושיפוט) (תיקון - ביקור בני משפחה), התשס”ב-2002

|בחוק למניעת הסתננות (עבירות ושיפוט), התשי"ד-1954[1], בסעיף 2א, האמור בו יסומן (א) ואחריו יבוא:     |1.     |תיקון סעיף 2א   |
|האמור בסעיף קטן (א), לא יחול על מי שיוצא או מארגן יציאה לארצות המוזכרות בסעיף קטן (א),     |"(ב)   |       |                |
|לצורך מפגש או מפגשים עם קרובי משפחה בדרגת קרבה ראשונה; לענין סעיף זה, "קרוב משפחה בדרגה    |       |       |                |
|ראשונה" – הורה, אח, אחות, ילד, סב, סבתא, דודים ובני דודים.                                 |       |       |                |

דברי - הסבר

עם קום המדינה בשנת 1948 ובשנים שבאו לאחר מכן נפרדו, או הופרדו, בני משפחות פלסטיניות רבות מאחיהם, אחיותיהם וקרובים אחרים בדרגה ראשונה. בשל מצב המלחמה ששרר בין מדינת ישראל והמדינות הערביות השכנות, לא התאפשר מפגש בין בני המשפחה.
זהו מצב שהדעת לא סובלת, לא אנושי ומנוגד לזכויות היסוד הבסיסיות של האדם וכל אדם. במצב החוקי הקיים, מפגשים מהסוג הנ"ל מוגדרים כעבירה על החוק.
כדי לתקן מצב  אבסורדי זה וכדי לתקן את המצב החוקי הקיים, מוצע לבטל כל אחריות פלילית מהמעשים הנ"ל.
