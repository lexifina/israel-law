הצעת חוק יסוד: מבוא לחוקה, התשס"ב-2002

|ההכרזה על הקמת מדינת ישראל[1] תהווה את המבוא לחוקת מדינת ישראל.                                    |1.     |המבוא לחוקה     |
|                                                                                                   |       |                |

דברי - הסבר

הצעת החוק קובעת כי ההכרזה על הקמת המדינה תהווה את פרק המבוא לחוקת מדינת ישראל לכשתתקבל. ההכרזה כוללת את ערכי היסוד של מדינת ישראל את השתלשלות האירועים ההסטורית שהובילה להקמת מדינת ישראל וכן את הקביעה כי תכונן חוקה למדינת ישראל. לפיכך, ראוי שתהווה את פרק המבוא לחוקה.
