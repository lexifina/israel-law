הכנסת החמש-עשרה

|הצעת חוק של חבר הכנסת דוד מגן                            |

הצעת חוק לתיקון פקודת סדר הדין הפלילי (מעצר וחיפוש) (פטור מאחריות לאזרח המסייע לשוטר), התשס”ב-2002

|בפקודת סדר הדין הפלילי (מעצר וחיפוש) [נוסח חדש], התשכ"ט-1969[1] בסעיף 20 האמור בו יסומן "(א)"      |1.     |תיקון סעיף 20   |
|ואחריו יבוא:                                                                                       |       |                |
|עזר אדם לשוטר, הדורש באופן סביר את עזרתו, לעצור אדם שהוא מוסמך לעוצרו או למנוע בריחתו, לא  |"(ב)   |       |                |
|ישא אותו אדם באחריות אזרחית או פלילית בשל מעצר או עיכוב שלדעת בית המשפט ביצע אותו בתום לב  |       |       |                |
|ולמען שלום הציבור."                                                                        |       |       |                |

דברי - הסבר

פקודת סדר הדין הפלילי (מעצר וחיפוש) [נוסח חדש], התשכ"ט-1969, בסעיף 20, מחייבת כל אדם לעזור לשוטר הדורש באופן סביר את עזרתו לעצור אדם. כמו כן, לפי הפקודה שוטר המבצע מעצר בלתי חוקי בתום לב ולמען שלום הציבור פטור מאחריות פלילית או אזרחית. ראוי לקבוע פטור דומה גם לאדם שעוזר לשוטר בעת מעצר כזה.
