|בעקבות ריבוי מקרי אלימות במשפחה בישראל (על פי הממצאים המשטרתיים נרצחות בישראל מידי שנה 17 נשים על יד בני זוגן). על פי |1.    |
|הנתונים הסטטיסטיים של משרד העבודה והרווחה כ-200,000  נשים מוכות בישראל, אחת מתוך 7 נשים היא אשה מוכה, נתונים קשים אלו |      |
|והעובדה כי הרשויות מתקשות להלחם בתופעה מצדיקים ביצוע התיקון בחוק אשר יביאו לזירוז הליכי הטיפול המשפטי בעבירות מסוג זה.|      |
|                                                                                                                      |      |
|זירוז ההליכים המשפטיים משיג מטרה משולשת:                                                                              |      |
|יש בכך עידוד לקורבן לשבור את מעגל השתיקה ולפנות לרשויות מבלי לחשוש שהגורם האלים ישוחרר תוך זמן קצר ויהווה    |א.     |      |
|סכנה מוחשית נוספת עבורו, במקרים אלו רב הסיכוי שהקורבן המתלונן לא יחזור בו מתלונתו ולא יהיה מושפע מלחצים לעשות|       |      |
|כן בעיקר מצד התוקף ומקורביו.                                                                                 |       |      |
|האפקט ההרתעתי שיוגש בעקבות הטיפול הדחוף בעבריינים פוטנציאלים בחינת "הכאת הברזל כל עוד הוא חם".               |ב.     |      |
|הקלה באיסור הראיות דהיינו, ככל שהגשת כתב האישום סמוכה לקרות האירוע, קל יותר הן למשטרה והן לפרקליטות לאסוף    |ג.     |      |
|ראיות בעיקר כאשר מדובר בראיות בעלות אפקט מיידי, כמו חבלות גופניות ונפשיות אשר מתכהה חומרתן עם חלוף העיתים.   |       |      |
