הצעת חוק הרשויות המקומיות (בחירת ראש הרשות וסגניו וכהונתם)
(תיקון - פטירת ראש הרשות), התשס”ג-2002

|בחוק הרשויות המקומיות (בחירת ראש הרשות וסגניו וכהונתם), התשל"ה-1975[1], בסעיף 24א, בסופו יבוא:     |1.     |תיקון סעיף 24א  |
|על אף האמור בסעיף קטן (א)(2), נפטר ראש הרשות לפני תחילת כהונתו או בשנה הראשונה לכהונתו     |"(ד)   |       |                |
|ולמעלה משנה לפני מועד הבחירות, כאמור בסעיף 3, תבחר המועצה בראש רשות מבין חבריה לפי סעיף 26 |       |       |                |
|ויראו אותו כאילו נבחר בבחירות מיוחדות."                                                    |       |       |                |
|תחילתו של חוק זה ביום קבלתו בכנסת והוא יחול גם אם נפטר ראש רשות לפני יום התחילה ובלבד שטרם התקיימו |2.     |תחילה           |
|בחירות מיוחדות בעקבות פטירתו.                                                                      |       |                |

דברי - הסבר

תיקון זה בא לקבוע כי במקרה שבו נפטר ראש רשות סמוך לבחירתו, מן הראוי שלא לקיים שוב בחירות מיוחדות והמועצה היא שתבחר בראש הרשות מבין חבריה.

תיקון זה ימנע מהלך בחירות נוסף סמוך לקודם, יחסוך כספי ציבור וימנע  מן הרשות ותושביה תקופה נוספת של אי ודאות.
