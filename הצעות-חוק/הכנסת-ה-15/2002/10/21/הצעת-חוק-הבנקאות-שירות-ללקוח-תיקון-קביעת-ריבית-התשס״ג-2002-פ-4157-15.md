הצעת חוק הבנקאות (שירות ללקוח) (תיקון - קביעת ריבית),                      התשס”ג-2002

|בחוק הבנקאות (שירות ללקוח), התשמ"א-1981[1], בסעיף 8, האמור בו יסומן "(א)" ואחריו יבוא:             |1.     |תיקון סעיף 8    |
|על אף האמור בכל דין נקבעה ריבית לזכות או לחובה על בסיס תקופתי, תחושב הריבית ביחס לפרק זמן  |"(ב)   |       |                |
|קצרים או ארוכים מאותה תקופה בשלמותה, לפי מספר הימים שבאותו פרק זמן ביחס למספר הימים        |       |       |                |
|המצוינים באותה שנה (365 ימים בשנה רגילה), ושיעור הריבית לצורך חישוב זה יהיה השיעור השנתי של|       |       |                |
|הריבית שנקבעה, ללא חישוב של ריבית דריבית".                                                 |       |       |                |

דברי הסבר

עד תחילת שנות התשעים היה נוהג בנקאי מקובל לחייב את לקוחות הבנקים בריבית המחושבת לפי 360 ימים בשנה ולא לפי 365 ימים בשנה. נוהג בנקאי פסול זה זכה לביקורת נוקבת מצד בתי המשפט בישראל. הצעת חוק זו באה על מנת למנוע באופן קוגנטי שימוש בנוהג פסול זה שכל מטרתו להגדיל את הריבית בה מחויבים הלקוחות בדרך בלתי הוגנת.
