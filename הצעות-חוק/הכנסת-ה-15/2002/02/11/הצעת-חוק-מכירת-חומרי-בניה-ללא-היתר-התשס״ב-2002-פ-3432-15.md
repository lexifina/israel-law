הצעת חוק מכירת חומרי בניה ללא היתר, התשס"ב-2002

|לא ימכור אדם ולא יספק מעל לשמונה ק"ב בטון ומעל לטון ברזל (להלן – חומרי בניה), לאדם שלא    |(א)    |1.     |איסור מכירה     |
|ניתן לו היתר בניה;                                                                        |       |       |                |
|סיפק אדם חומרי בניה לאדם, במישרין או בעקיפין, ללא שהוצג בפניו היתר בניה המתיר במפורש בניה |(ב)    |       |                |
|וללא שהעתק מהיתר הבניה כאמור נשמר בידיו – חזקה עליו שידע, כי הוא מספק חומרי בניה לאדם     |       |       |                |

|העובר על הוראות סעיף 1 לחוק, לרבות על דרך של רשלנות, דינו – מאסר שנתיים או קנס פי חמישה מן הקנס    |2.     |עונשין          |

דברי - הסבר

ברחבי הארץ פועלים אנשים רבים הבונים בניה בלתי חוקית ללא היתרים מתאימים. הצעת חוק זו באה למנוע בניה ללא היתר. על יד כך שתהא זו עבירה פלילית למכור חומרי בניה לאדם ללא היתר כדין.
