הצעת חוק הכנסת (תיקון - עונשין), התשס”ב-2002

|בחוק הכנסת, התשנ"ד -1994[1], אחרי סעיף 5 יבוא:                                                     |1.     |הוספת סעיף 5א   |
|אדם שמסר מידע כוזב, בעל פה או בכתב, במהלך דיון בועדה מועדות הכנסת, במטרה     |5א.    |"עונשין     |       |                |
|להטעות את חברי הועדה, דינו – מאסר שנה."                                      |       |            |       |                |

דברי - הסבר

   1. במסגרת תפקיד הכנסת כרשות המחוקקת: אדם המוסר מידע כוזב לועדת כנסת במטרה להטעות את חברי הועדה, משבש את עבודת הכנסת ועלול לגרום לנזק כבד לציבור, אם תתקבלנה החלטות שגויות של ועדת כנסת או חמור מכך חקיקה לא נאותה והכל כתוצאה מהמידע המטעה.
   2. במסגרת תפקיד הכנסת כרשות המפקחת על הרשות המבצעת:  יכולת הפיקוח של הכנסת נפגמת  אם אין סנקציה כנגד נציגי הרשות המבצעת או גורמים הקשורים ברשות המבצעת המופיעים בפני ועדות הכנסת ומוסרים להן מידע מוטעה.

אמנם עדיין אין סנקציה ברורה כנגד מי שאינם מוכנים לענות לשאלות או לתת מידע לוועדת כנסת בעבודתה, אולם חשוב שבשלב הראשון תהווה מסירת המידע הכוזב עבירה פלילית.
