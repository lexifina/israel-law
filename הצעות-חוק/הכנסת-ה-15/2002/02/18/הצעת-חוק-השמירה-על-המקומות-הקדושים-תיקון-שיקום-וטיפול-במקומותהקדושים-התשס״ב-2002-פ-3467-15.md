הצעת חוק השמירה על המקומות הקדושים (תיקון - שיקום וטיפול במקומות הקדושים), התשס”ב-2002

|בחוק השמירה על המקומות הקדושים, התשכ"ז-1967[1], אחרי סעיף 1 יבוא:                                  |1.     |הוספת סעיף 1א   |
|נציגי הקהילות הדתיות המשתמשות במקומות הקדושים, או עמותות המייצגות קהילות |1א.    |"שיקום וטיפול    |       |                |
|אלו, יהיו רשאים לערוך  שימור, שיפוץ ושיקום של המקומות הקדושים, הכל בתיאום|       |במקומות הקדושים  |       |                |
|עם משרד הדתות כפי שייקבע שר הדתות".                                      |       |                 |       |                |

דברי - הסבר

מאז קום המדינה, נמצאים המקומות המקודשים ובמיוחד של המוסלמים והנוצרים בסכנה מאחר ונמנעת מהם עבודות שימור, שיקום ושיפוץ.

חוק זה בא לתקן את העוול והפגיעה ברגשות הדתיים של חלק לא מבוטל מאזרחי המדינה  ולאפשר להם להגן על המקומות המקודשים שלהם, דבר שהינו אלמנטרי ביותר.
