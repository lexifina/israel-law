|הגדרות              |1. בחוק זה -                                                                                          |
|                    |"דירה" - דירה או חלק מדירה שבנייתה נסתיימה, המשמשת למגורים או מיועדת למגורים                          |
|                    |לפי טיבה;                                                                                             |
|                    |"חוזה שכירות" - חוזה להשכרת דירה;                                                                     |
|                    |"שכירות'- - במשמעות שכירות מקרקעין בסעיף 3 לחוק המקרקעין, התשכ"ט-1969 1, למעט                         |
|                    |חבירה לדורות.                                                                                         |
|קביעת שכר דירה      |2. שכר דירה שנקבע בחוזה שבירות או לפיו יהיה נקוב בשקלים חדשים בלבד ולא                                |
|                    |יוצמד לשערו של מטבע חוץ.                                                                              |
|תשלום שכר דירה      |3. (א) בסעיף זה -                                                                                     |
|                    |"המדד" - מדד המחירים לצרכן שמפרסמת הלשכה המרכזית לסטטיסטיקה;                                          |
|                    |"הפרשי הצמדה" - תוספת לשכר דירה בסיסי, בסכום המחושב לפי שיעור עליית המדד,                             |
|                    |מהמרד האחרון שפורסם לפני החודש הראשון הכלול בתקופת השכירות לפי חוזה                                   |
|                    |השבירות לבין המדד האחרון שפורסם סמוך למועד עדכון שכר הדירה-,                                          |
|                    |"שכר דירה בסיסי" - שבר דירה שעל שוכר לשלם למשכיר בעד החודש הראשון הכלול                               |
|                    |בתקופת השכירות לפי חוזה שכירות שביניהם.                                                               |
|                    |(ב) הוראה בחוזה שכירות הנוגדת את הוראות סעיף 2, לא יהיה לה תוקף,                                      |
|                    |והמשכיר יהיה זכאי לקבל מהשוכר, נוסף על שכר הדירה הבסיסי, רק הפרשי הצמדה; שילם                         |
|                    |השוכר שכר דירה צמוד למטבע חוץ, יהיה זכאי להשבת ההפרש בין הסכום ששילם, לבין                            |
|                    |הסכום שהיה עליו לשלם אילו היה חייב בתשלום שכר רירה בתוספת הפרשי הצמדה                                 |
|                    |בלבד.                                                                                                 |
|התיישנות            |4. תקופת ההתיישנות של תביעה לפי חוק זה תהיה שלוש שנים.                                                |

|דברי הסבר                                                                                                                |
|המיועדות לשמש למגורים, לגבי חוזי שכירות שנכרתו            |התופעה של הצמדת תשלום שכר דירה לדולר של                       |
|לאחר יום תחילתו של חוק זה ועד תום שנתיים ממועד            |ארה-ב הפכה מאז שנות האינפלציה לנפוצה ביותר;                   |
|התחילה, ייקבע שכר דירה בשקלים חדשים בלבד, ולא             |לאור השינויים החלים בשער הדולר אשר אינם משקפים                |
|תותר הצמדתו למטבע חוץ-, כן מוצע כי לא יהיה תוקף           |את המחירים בישראל ואינם רלוונטיים לענין שכירות                |
|לקביעת שכר דירה במטבע חוץ או הצמדתו למטבע חוץ             |הדירות נראה שאין הצדקה להצמדת שכר הדירה לשער                  |
|והמשכיר יהיה זכאי, נוסף על שכר הדירה הבסיסי, רק           |של מטבע חוץ, אשר גורמת עוול למשכירים ולשוכרים                 |
|להפרשי ההצמדה למדד המחירים לצרכן, כך גם אם                |ומביאה להטיה לא מוצדקת של מדד המחירים לצרכן.                  |
|השוכר ؀ࠂࠈࠊࠎࠒשילם שכר דירה צמוד למטבע חוץ, הוא יהיה        |כדי לשרש תופעה פסולה זו ומתוך הנחה שבטווח                     |
|זכאי לקבל מהמשכיר את ההפרשים שבין הסכום                   |הארוך יורגל שוק הדירות להשכרה לשיטת הצמדה                     |
|ששילם לבין הסכום שהיה עליו לשלם אילו הוצמד שכר            |למטבע ישראלי, מוצע לקבוע בהוראת שעה לתקופה של                 |
|הדירה הבסיסי למרד המחירים לצרכן.                          |שנתיים, כי שכר הדירה של דירות המשמשות או                      |
