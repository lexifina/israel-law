|בחוק כלי היריה, התש"ט-1949[1], (להלן – החוק העיקרי) בסעיף 14, האמור בו יסומן "(א)" ואחריו יבוא:    |1.     |תיקון סעיף 14   |
|בעל כלי יריה רשאי להפקידו למשמורת בתחנת משטרה, לתקופה קצובה, שיודיע עליה והוא רשאי     |"(ב)       |       |                |

|שר הפנים ייקבע בתקנות אגרה שעל מפקיד כלי יריה, לפי סעיף קטן (ב) לשלם בעד תקופת ההפקדה  |(ג)        |       |                |
|וכן דרכים ומועדים לתשלום האגרה כאמור."                                                 |           |       |                |

דברי - הסבר

על פי החוק הנוהג רשאית המשטרה לחלט או להשמיד כלי יריה שבעליו הפקיד בתחנת המשטרה בשל אי נחיצות.

אי הנחיצות כאמור יכול תהא זמנית בלבד, בשל מחלה, שליחות ממושכת בחו"ל וכיו"|ב.

הצעת זאת באה לאפשר הפקדת כלי היריה, תמורת תשלום הולם במחסני המשטרה. כלי היריה כאמור יוחזר, כמובן, למפקיד, בתום התקופה הקצובה בשונה מכלי שהופקד שלא לתקופה קצובה וללא תשלום אגרה והוא בר חילוט.
