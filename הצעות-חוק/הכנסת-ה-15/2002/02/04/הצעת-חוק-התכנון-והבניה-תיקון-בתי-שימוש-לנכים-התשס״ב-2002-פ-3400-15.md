|בחוק התכנון והבניה, התשכ"ה-1965[1], בסעיף 151, בסופו יבוא:                                         |1.     |תיקון סעיף 145  |
|על אף האמור בסעיף 145, במקום שאינו כפוף להוראות פרק ה'                   1, הצבת מבנה יביל |"(ה)   |       |                |
|של בית שימוש לנכים לא תיחשב כסטייה מתוכנית ואינה טעונה היתר, אך טעונה אישור של מהנדס הוועדה|       |       |                |

|לעניין סעיף זה, "מבנה יביל"- מבנה, בין שהוא בנוי אבן ובין שהוא בנוי ביטון, טיט, ברזל, עץ או|       |       |                |
|כל חומר אחר, הניתן להובלה בשלמות ממקום ייצורו כשהוא מוכן להקמה."                           |       |       |                |

דברי הסבר

נוכח המצב הקשה השורר בנוגע לשירותים לנכים בישראל, מוצע להקל בהליכי התכנון והרישוי של הצבת בתי שימוש יבילים לנכים, על מנת לעודד הקמת מתקנים כאלה לרווחת הנכים אף במבנים שאינם כפופים כיום להוראות פרק ה-1 לחוק התכנון והבניה בדבר התקנת סידורים מיוחדים לנכים ציבוריים, כגון תחנות תדלוק חניונים וגנים ציבוריים. זאת במיוחד על –ידי הליכים מהירים וחיסכון בעלויות הכרוכות בהקמת בית שימוש יביל לעומת מבנה דומה קבוע.
