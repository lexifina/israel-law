|מתפרסמת בזה הצעת חוק של חבר הכנסת מטעם ועדת הכלכלה של הכנסת:                                                                 |
|הצעת חוק משק החשמל (הגבלת צריכת חינם של חשמל על ידי עובד                                                                     |
|חברת החשמל), התשס"ב-2002*                                                                                                    |
|           |1. בחוק זה -                                                                               |הגדרות              |
|           |"החברה" - חברת החשמל לישראל בע"מ;                                                          |                    |
|           |"המועד הקובע" - יום פרסומו של חוק זה-,                                                     |                    |
|           |"עובד" - עובד החברה;                                                                       |                    |
|           |"עובד חרש" - עובד שהחל לעבוד בחברה אחרי המועד הקובע;                                       |                    |
|           |"צריכת יתר" - צריכת חשמל העולה על פי שניים מהצריבה הממוצעת;                                |                    |
|           |"צריכה ממוצעת" - הממוצע השנתי של צריכת החשמל במשקי הבית בישראל;                            |                    |
|           |"השר" - שר התשתיות הלאומיות.                                                               |                    |
|2. על אף האמור בכל הסכם קיבוצי, חוזה עבודה, נוהג או הסדר מחייב אחר -                                    |תשלומי עובר         |
|(ו) עובר שאינו עובד חרש ישלם לחברה את מלוא התשלום בעד צריכת היתר                                        |בעד צריכת           |
|שצרך;                                                                                                   |חשמל                |
|(2) עובד חדש ישלם לחברה את מלוא התשלום בער החשמל שצרך.                                                  |                    |
|           |5. השר יפרסם ברשומות אחת לשנה הודעה ברבר הצריכה הממוצעת.                                   |פרסום הודעה         |
|להתקין     |4. השר ממונה על חוק זה והוא רשאי באישור ועדת הכלכלה של הכנסת,                              |ביצוע ותקנות        |
|           |תקנות בכל הנוגע לביצועו, לרבות לענין הצריכה הממוצעת.                                       |                    |

|דברי הסבר                                                                                                                  |
|ישלמו העובדים את המחיר המלא. כמו כן מוצע                   |האפשרות לצרוך חשמל חינם על ידי עובדי חברת                      |
|שעובדים חדשים המצטרפים לחברת החשמל לאחר                    |החשמל מביאה, לשימוש לא רציונלי ובזבזני במשאב                   |
|קבלתו של חוק זה, ישלמו על ؀ࠂࠈצריכת החשמל שלהם ככל          |יקר זה.                                                        |
|אזרח במדינה.                                               |ניסיונות שנעשו בעבר להביא לצמצום בהטבה זו                      |
|הועדה סבורה שאף אם יש בחוק זה משום פגיעה                   |לא עלו יפה, ועדיין ישנם עובדים הצורכים למעלה                   |
|בקנינם של עובדי החברה או בחופש העיסוק, הרי                 |מ-25,000 קוט"ש בשנה, צריבה העולה על פי חמישה                   |
|שפגיעות אלה עומדות במבחני פסקאות ההגבלה                    |מצריכת החשמל הממוצעת של משקי הבית בישראל.                      |
|שבחוק-יסוד: כבוד האדם וחירותו, ובחוק-יסוד: חופש            |לכן מוצע לקבוע כי עובדי חברת החשמל יוכלו                       |
|העיסוק, שכן הפגיעות, אם ישנן, הן לתכלית ראויה ואינן        |לצרוך חשמל חינם בשיעור של ער פי שניים מהצריכה                  |
|עולות על הנדרש.                                            |הממוצעת של משפחה בישראל, ועל צריכה מעבר לכך                    |
|חבר הכנסת אברהם פורז                                       |                                                               |
