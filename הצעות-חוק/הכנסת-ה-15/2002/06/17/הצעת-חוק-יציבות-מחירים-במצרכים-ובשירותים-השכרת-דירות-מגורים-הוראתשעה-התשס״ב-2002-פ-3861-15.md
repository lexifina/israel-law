|2002).                                                                                             |       |                |

|חודשים.                                                                                   |       |       |                |

דברי - הסבר

|הטלטלה הפתאומית בערך השקל הישראלי, גרמה לכך שציבור גדול ניפגע מיידית מהשינויים שבאו עקב כך בשערי הדולר, והכוונה היא |1.     |
|לשוכרי דירות למגורים. עם ציבור זה נמנים סטודנטים, אנשים שאין בבעלותם דירה ורבים שנאלצים לשכור את דירתם בהעדר פתרון  |       |
|דיור אחר.                                                                                                           |       |
|על אף  האיסור לנקוב במחירים דולריים, חוזים והסכמים רבים מתייחסים לדולר כאל המטבע הקובע את ערך התשלום על- פי החוזה   |2.     |
|,לרבות על- ידי הצמדתו לשער הדולר, והשינויים הנ"ל הביאו לכך שרבים אינם יכולים לעמוד בעליית מחירי השכירות – בייחוד    |       |
|לנוכח העובדה ששכר העבודה אינו צמוד לשער  הדולר, ובמקרים רבים, בשל הקשיים הכלכליים של המעסיקים – שכר זה הופחת, חמור  |       |
|יותר המצב במקרה של דיירים  שבכלל פוטרו מעבודתם.                                                                     |       |

|הבראת המשק. הצעת חוק זו אינה מתיימרת להפעיל פתרון כה רחב, אך היא באה להגן על אותם אנשים שאמצעיהם בכספיים מוגבלים,   |       |
|לפחות לתקופה  של מספר חודשים, בתקווה שעד לסיום אותה תקופה יחול שינוי לטובה במשק בישראלי, או שיעודכן השכר כתוצאה     |       |
