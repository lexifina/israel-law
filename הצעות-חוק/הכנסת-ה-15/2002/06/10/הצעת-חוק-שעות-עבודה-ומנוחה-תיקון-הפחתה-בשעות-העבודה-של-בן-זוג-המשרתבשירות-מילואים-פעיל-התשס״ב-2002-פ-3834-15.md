|בחוק שעות עבודה ומנוחה, התשי"א-1951[1], אחרי סעיף 5 יבוא:                                          |1.     |הוספת סעיף 5א   |
|יום העבודה של בן זוג או בת זוג של המשרת בשירות מילואים פעיל יהיה -              |(א)    |"5א.      |       |                |
|בכל יום יעבוד בן או בת הזוג של המשרת בשירות מילואים פעיל שעה אחת פחות,  |(1)    |       |          |       |                |

|המשרת או המשרתת בשירות מילואים פעיל יחויב לתת העתק של זימון למילואים למקום      |(ב)    |          |       |                |
|העבודה של בן או בת הזוג, לפחות חודש לפני השירות.                                |       |          |       |                |

דברי - הסבר

נטל השירות במילואים נופל למעשה לא רק על המשרת במילואים אלא גם על בן או בת זוגו, שבהעדרו של המשרת במילואים נופל עליהם עול הטיפול בבית, במשפחה ובילדים.

מוצע לאפשר לבן זוגו של המשרת במילואים לעבוד שעה פחות בכל יום, בדומה לאישה שלאחר לידה.
