הצעת חוק רשות שדות התעופה (תיקון - אישור הכנסת לתשלומים שגובה הרשות), התשס”ב-2002

|בחוק רשות שדות התעופה, התשל"ז-1977[1] בסעיף 29(ד), בסופו יבוא – "ואין חובה על המשתמש לקבוע אותו    |1.     |תיקון סעיף 29    |
|שירות".                                                                                            |       |                 |

דברי - הסבר

סעיף 29 לחוק רשות שדות התעופה, התשל"ז-1997, קובע:

|הרשות  רשאית  להציע לשר התחבורה תקנות בדבר תעריפי אגרות שישתלמו לה  או  לאחרים  בעד       |(א)    |29.    |"תעריפי אגרות    |
|השימוש בשדות התעופה של הרשות ובמתקנים שבהם ובעד  השירותים  שנותנים  בהם  היא  או  אחרים,  |       |       |                 |
|ובדבר סדרי גבייתם ותשלומם;  שר  התחבורה  רשאי להתקין תקנות, כאמור, אף אם הרשות לא הציעה לו|       |       |                 |
|אותן, ובלבד שיתייעץ ברשות תחילה, כל תקנות לפי סעיף קטן זה טעונות אישור הממשלה וועדת הכלכלה|       |       |                 |
|של הכנסת.                                                                                 |       |       |                 |
|..............                                                                            |(ב)    |       |                 |
|...............                                                                           |(ג)    |       |                 |
|האמור  בסעיף  זה  לא  יתפרש כגורע מסמכות הרשות לתת שירות ולגבות בעדו  תשלום  אף אם לא     |(ד)    |       |                 |
|נקבעה לאותו שירות אגרה בתקנות, והוא כשאין חובה על פי חיקוק ליתן אותו שירות."              |       |       |                 |

בהתאם לסעיף זה (וסעיף 2 לחוק רשות שדות התעופה (הוראת שעה), התש"ח-1980, שהטיל על רשות  שדות  התעופה  את החובה לתפעל גם את מסופי המעבר היבשתיים הנקובים בחוק זה), נקבעו בתקנות האגרות שרשות שדות התעופה רשאית לגבות, ותעריפיהן.

ואולם,  מסתבר, כי מכוח סעיף קטן (ד) לאותו סעיף, גובה הרשות, בנוסף לאגרות גם דמי שימוש ודמי טיפול, בסכומים ניכרים, הגבוהים משמעותית מסכום האגרות המאושרות.

מוצע,  לפיכך,  לאפשר לרשות לגבות תשלום בעד שירותים שהיא נותנת (בעצמה או באמצעות אחרים),  רק  אם  המשתמש  יכול לוותר על אותו שירות, שאם לא כן, יחשב התשלום לאגרה ויהיה טעון אישור הממשלה וועדת הכלכלה של הכנסת.

הצעת חוק זהה הונחה על שולחן הכנסת הארבע-עשרה ומספרה פ/2261.

הצעת חוק זהה הונחה על שולחן הכנסת החמש-עשרה ומספרה פ/298.
