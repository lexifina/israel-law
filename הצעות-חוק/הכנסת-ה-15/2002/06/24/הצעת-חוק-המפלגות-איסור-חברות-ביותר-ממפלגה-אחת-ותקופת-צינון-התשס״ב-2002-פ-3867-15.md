הצעת חוק המפלגות (איסור חברות ביותר ממפלגה אחת ותקופת צינון), התשס”ב-2002

|בחוק המפלגות, התשנ"ב-1992 (להלן – החוק העיקרי), בסעיף 15, האמור בו יסומן "(א)" ואחריו יבוא:        |1.     |תיקון סעיף 15   |
|החליט אדם להפסיק את חברותו במפלגה, ימסור הודעה על כך בכתב בדואר רשום ליושב ראש המפלגה, |"(ב)       |       |                |
|והוא יפסיק להיות חבר אותה מפלגה מיום ששלח את ההודעה.                                   |           |       |                |

|חלפו שלושה חודשים מהיום שבו הפסיק את חברותו כאמור באותו סעיף קטן.                      |           |       |                |

דברי – הסבר

הצעת החוק באה על מנת להרתיע ביתר שאת אותם הנרשמים כחברים ביותר ממפלגה אחת ובמרמה משפיעים על תוצאות הבחירות הפנימיות באותה המפלגה. תופעה זו הפכה לתופעה נפוצה במחוזותינו ומוצע להחמיר עם עונשם של מי שעוברים על החוק בצורה זו.

כלי נוסף הבא להתמודד עם התופעה הוא תקופת צינון של שלושה חודשים במעבר ממפלגה למפלגה.
