הצעת חוק חסינות חברי הכנסת, זכויותיהם וחובותיהם (תיקון - הגבלת חסינות מהותית), התשס”ב-2002

|בחוק חסינות חברי הכנסת, זכויותיהם וחובותיהם, התשי"א-1951[1], בסעיף 1, בסופו יבוא:                  |1.     |תיקון סעיף 1    |
|"למען הסר ספק, הבעת דעת או מעשה של חבר הכנסת שיש בהם אחד מאלה, אין רואים אותם, לעניין סעיף זה,     |       |                |
|כהבעת דעה או כמעשה הנעשה במילוי תפקידו או למען מילוי תפקידו כחבר הכנסת:                            |       |                |
|הסתה לאלימות;                                                                              |(1)    |       |                |
|שלילת האופי הדמוקרטי של מדינת ישראל."                                                      |(2)    |       |                |

דברי - הסבר

בשנים  האחרונות התבטאו מספר חברי כנסת באופן שניתן היה לפרש כהסתה לאלימות או  שלילת אופיה הדמוקרטי של ישראל, תוך ניצול חוק החסינות הקיים כיום.

לפיכך,  מוצע  לתקן  את החוק כך שכל חבר כנסת המתבטא באופן היכול להתפרש כהסתה לאלימות או שלילת  אופיה  הדמוקרטי של המדינה, יאלץ לשאת באחריות החוקית ככל האזרח מבלי להסתתר מאחורי חוק חסינות חברי הכנסת.

הצעת חוק דומה הוגשה בכנסת הארבע-עשרה ומספרה פ/2501.

הצעות חוק דומות הוגשו בכנסת ה-15 של ח"כ אברהם יחזקאל (פ/185) ושל ח"כ אופיר פינס-פז וח"כ רן כהן (פ/3580).

הצעת חוק דומה בעיקרה הונחה על שולחן הכנסת ה-15 ע"י ח"כ אליעזר כהן וקב' חכ"ים, ועברה קריאה ראשונה ביום 29.1.02 ופורסמה ברשומות – הצ"ח מס' 3066 התשס"ב
עמ' 210.
