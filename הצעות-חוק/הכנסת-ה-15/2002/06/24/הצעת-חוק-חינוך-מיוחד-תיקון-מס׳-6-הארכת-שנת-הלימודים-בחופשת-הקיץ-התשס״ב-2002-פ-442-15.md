|הצעת חוק חינוך מיוחד (תיקון מס' 6) (הארכת שנת הלימודים בחופשת הקיץ), התשס"ב-2002*                                            |
|1. בחוק חינוך מיוחד, התשמ"ח- 1988 1,  במקום סעיף 14 יבוא:                                              |החלפת                |
|                                                                                                       |סעיף 14              |
|14. (א) (1) שנת הלימודים במוסדות לחינוך מיוחד                                   |משך שנת               |                     |
|תימשך מעבר לשנת לימודים רגילה למעט                                              |לימודים               |                     |
|שבועיים שייקבעו בידי השר בחופשת קיץ.                                            |                      |                     |
|(2) מספר שעות הלימוד ביום של ילד בעל צרכים                                      |                      |                     |
|מיוחדים במוסד לחינוך מיוחד, בתקופה                                              |                      |                     |
|שמעבר לשנת הלימודים הרגילה (להלן -                                              |                      |                     |
|תקופת ההארכה), לא יפחת ממספר השעות                                              |                      |                     |
|שהוא לומד ביום בשנת הלימודים הרגילה.                                            |                      |                     |
|(ב) השר, בהתייעצות עם ועדת החינוך והתרבות של                                    |                      |                     |
|הכנסת, רשאי לקבוע, לענין מוסדות מסוימים או לענין                                |                      |                     |
|לקויות מסוימות, ששנת הלימודים לא תוארך לגביהם                                   |                      |                     |
|או שתקופת ההארכה לגביהם תהיה קצרה יותר                                          |                      |                     |
|מהאמור בסעיף קטן (א), אם מצא כי נתקיימו נסיבות                                  |                      |                     |
|המצדיקות זאת.                                                                   |                      |                     |
|(ג) השר, בהתייעצות עם מרכז השלטון המקומי ועם איגוד                              |                      |                     |
|המועצות האזוריות, יקבע הוראות לעניין מתכונת                                     |                      |                     |
|הפעילות החינוכית והטיפולית וכן לעניין שירותים                                   |                      |                     |
|אחרים שיינתנו בתקופת ההארכה, ובידי מי יינתנו;                                   |                      |                     |
|ואולם, קביעה כאמור, בנושאים הנוגעים לתחום                                       |                      |                     |
|טיפולו של משרד העבודה והרווחה, תיעשה בהסכמת                                     |                      |                     |
|שר העבודה והרווחה.                                                              |                      |                     |
|(ד) השר רשאי לקבוע כי לימודים במוסדות לחינוך מיוחד                              |                      |                     |
|יתקיימו גם בתקופות של חופשת לימודים רגילה.                                      |                      |                     |
|2. חוק זה יוחל בהדרגה החל בשנת הלימודים התשס"ג, על מוסדות לחינוך מיוחד על פי                           |החלה בהדרגה          |
|קביעת השר, ובלבד שהחלתו תושלם לא יאוחר מתחילת שנת הלימודים התשס"ו.                                     |                     |

|דברי הסבר                                                                                                                 |
|כאורכו של יום הלימודים של הילד בעל הצרכים המיוחדים         |על פי הוראת סעיף 14 הקיים לחוק חינוך מיוחד,                   |
|במהלך שנת הלימודים הרגילה. עם זאת, מאחר שקיימים            |התשמ-ח-1988, קובע שר החינוך והתרבות את התקופה שבה             |
|מוסדות מסויימים ולקויות מסויימות לגביהם עשויה להיות        |נמשכת שנת הלימודים הרגילה במוסדות לחינוך מיוחד                |
|הצדקה שלא להאריך את שנת הלימודים או להאריכה                |במהלך החופשות מלימודים.                                       |
|לתקופה אחרת, מוצע לקבוע חריג על פיו השר, לארור             |עבור חלק מן הילדים הלומדים במוסדות החינוך המיוחד,             |
|התייעצות עם ועדת החינוך והתרבות של הכנסת, יוכל             |ובמיוחד הילדים האוטיסטים, מהווה המסגרת החינוכית               |
|להוציא מתחולת הכלל מוסדות או לקויות כאמור. נסיבות          |מסגרת חיונית גם במהלך החופשות. לפי המצב הקיים היום,           |
|שיצדיקו סטיה מהכלל עשויות להיות נעוצות באופיה של           |חלק מן האוכלוסיות הלומדות במוסדות החינוך המיוחד אינן          |
|המסגרת החינוכית (למשל כיתה המשולבת במוסד רגיל),            |לומדות כלל במהלך חופשת הקיץ או שיום הלימודים בתקופה           |
|באופיה של הלקות ובחומרתה ובצרכים שונים של המערכת           |זו הוא קצר יותר מיום הלימודים במהלך שנת הלימודים              |
|(הקשורים בתקציב, כוח אדם וכדו').                           |הרגילה. לגבי לקויות מסויימות הדבר גורם לחוסר יכולת טל         |
|מאחר שמתכונת הפעילות במוסדות החינוך המיוחד                 |משפחות הילדים בעלי הצרכים המיוחדים לתפקד כראוי                |
|במהלך חופשת הקיץ איננה זהה בתוכנה ובכוח האדם המפעיל        |במהלך תקופת הקיץ, וכן לפגיעה בילדים עקב השינוי בשגרת          |
|אותה למתכונת יום הלימודים במהלך שנת הלימודים הרגילה,       |יומם.                                                         |
|מוצע, שהשר יוכל לקבוע הוראות גם לגבי מתכונת הפעילות        |מטרת התיקון המוצע היא לעגן בחקיקה את הכלל על                  |
|החינוכית והטיפולית ולגבי שירותים אחרים שיינתנו؀ࠂࠈࠊࠎࠒ בתקופת|פיו הלימודים במוסדות החינוך המיוחד יימשכו גם בתקופת           |
|ההארכה, ובידי מי יינתנו.                                   |.חופשת הקיץ, למעט שבועיים שייקבעו כחופשה, ושאורכו של          |
|                                                           |יום הלימודים במהלך תקופת ההארכה האמורה יהיה לפחות             |
