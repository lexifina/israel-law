|מתפרסמות בזה הצעות חוק של חברי הכנסת מטעם ועדת הכלכלה של הכנסת:                                                              |
|הצעת חוק רישוי שירותי התעופה (תיקון) (מוביל נקוב), התשס"ב-2002*                                                              |
|1. בחוק רישוי שירותי התעופה, התשכ"ג-1963  1(להלן - החוק העיקרי), בסעיף 1,                               |תיקון סעיף 1        |
|בסופו יבוא:                                                                                             |                    |
|""מוביל אווירי" - מי שבידו רישיון להפעיל כלי טיס בטיסה מסחרית לפי הוראות                                |                    |
|חוק זה;                                                                                                 |                    |
|"מוביל נקוב" - מוביל אווירי אשר הוסמך על ירי שר התחבורה להפעיל קו תעופה                                 |                    |
|סדיר שהוסכם עליו בהסכם עם מדינה זרה שמדינת ישראל או ממשלת ישראל                                         |                    |
|היא צד לו (בחוק זה - ההסכם)."                                                                           |                    |
|2. אחרי סעיף 2 בחוק העיקרי יבוא:                                                                        |הוספת סעיף 2א       |
|2א. (א) שר התחבורה יסמיך מוביל אווירי להיות מוביל נקוב לתקופה                          |-מוביל נקוב     |                    |
|שיקבע, ורשאי הוא להסמיך יותר ממוביל אווירי אחד למדינה זרה אם                           |                |                    |
|ההסכם מתיר זאת.                                                                        |                |                    |
|(ב) לא ביצע מוביל נקוב טיסות בקו תעופה, בהתאם להסכם                                    |                |                    |
|במהלך תקופה של שישה חורשים רצופים, יבטל שר התחבורה בתום                                |                |                    |
|ששת החורשים האמורים את הסמכתו כמוביל נקוב ויסמיך מוביל אווירי                          |                |                    |
|אחר כמוביל נקוב לאותו קו תעופה; ואולם רשאי השר, בנסיבות מיוחדות,                       |                |                    |
|לדחות את ביטול ההסמכה של מוביל נקוב לתקופה שלא תעלה על שישה                            |                |                    |
|חודשים, ובאישור ועדת הכלכלה של הכנסת - לתקופות נוספות שכל                              |                |                    |
|אחת מהן לא תעלה על שישה חודשים."                                                       |                |                    |

|דברי הסבר                                                                                                                  |
|מוצע כי במקרה שמוביל נקוב אינו מקיים טיסות                   |על פי הסכמי תעופה שבין ישראל למדינות זרות,                   |
|במשך תקופה של שישה חודשים רצופים, יבטל שר                    |קיים מטעם כל מדינה מוביל אווירי שהוענק לו מעמד               |
|התחבורה את הסמכתו כמוביל נקוב ויסמיך מוביל נקוב              |של מוביל נקוב, שתפקידו לבצע, במקביל למוביל הנקוב             |
|אחר לאותו קו, אלא אם כן החליט, מטעמים מיוחדים,               |של מדינת החוץ, את הטיסות הסדירות לאותה מדינה.                |
|לדחות את מועד ؀ࠂࠈביטול ההסמכה לתקופה שלא תעלה                |פעמים המוביל הנקוב אינו מקיים טיסות סדירות                   |
|על שישה חודשים נוספים; עם זאת, השר יהיה רשאי,                |בקו שבו הוענק לו מעמד כזה. וכתוצאה מכך מופעל                 |
|באישור ועדת הכלכלה של הכנסת, לדחות את מועד                   |אותו קו באופן בלעדי על ידי המוביל הנקוב של מדינת             |
|ביטול ההסמכה לתקופות נוספות, שכל אחת מהן לא                  |החוץ, בשעה שמובילים אוויריים אחרים במדינת ישראל              |
|תעלה על שישה חודשים.                                         |מבקשים לבצע טיסות סדירות באותו קו.                           |
|חבר הכנסת נחום לנגנטל                                        |                                                             |
