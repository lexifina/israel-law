הצעת חוק ערבויות מטעם המדינה (תיקון - הגבלת סכום הערבויות המצטבר), התשס”ב-2002

|בחוק ערבויות מטעם המדינה, התשי"ח-1958[1], בסעיף 3, במקום הסיפא החל במילים "בכל שנת כספים" יבוא     |1.     |תיקון סעיף 3    |
|"לרבות ערבויות שניתנו לפי חוק זה בשנות כספים קדומות ובלבד שערבויות אלה טרם הופטרו, לא יעלה על 10%  |       |                |
|מהתקציב הרגיל לאותה שנת כספים; ואולם הממשלה רשאית להגדיל את השיעור האמור בשנת כספים מסוימת באישור  |       |                |
|ועדת הכספים של הכנסת."                                                                             |       |                |

דברי - הסבר

כדי להסיר ספק, מוצע לקבוע כי יתרת הערבויות התלויה ועומדת בכל רגע נתון לא תעלה על 10% מהתקציב הרגיל של שנת התקציב השוטפת, אלא באישור של ועדת הכספים של הכנסת.
