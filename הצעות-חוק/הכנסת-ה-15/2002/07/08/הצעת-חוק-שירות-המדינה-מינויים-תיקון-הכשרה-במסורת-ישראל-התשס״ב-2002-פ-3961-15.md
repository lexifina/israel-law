|בחוק שירות המדינה (מינויים), התשי"ט-1959[1], האמור בסעיף 23 יסומן "(א)" ואחריו יבוא:               |1.     |תיקון סעיף 23   |
|מבלי לגרוע מן האמור בסעיף קטן (א), מי שנתמנה למשרת שגריר, ציר או קונסול יעבור מסלול הכשרה  |"(ב)   |       |                |
|במסורת ישראל כפי שתקבע ועדת השירות בהתייעצות עם הרבנות הראשית לישראל."                     |       |       |                |

דברי - הסבר

שגרירים וקונסולים המייצגים את ישראל חייבים, לצורך הקשר עם הקהילות היהודיות בתפוצות, לעבור מסלול הכשרה מינימלי במסורת ישראל, בכדי לייצג את מדינת ישראל והעם היהודי.
