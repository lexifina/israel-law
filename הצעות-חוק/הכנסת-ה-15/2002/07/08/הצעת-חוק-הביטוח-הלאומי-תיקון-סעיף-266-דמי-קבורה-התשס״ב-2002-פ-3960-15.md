הצעת חוק הביטוח הלאומי (תיקון  סעיף 266 - דמי קבורה),                    התשס”ב-2002

|בחוק הביטוח הלאומי [נוסח משולב], התשנ"ה-1995 האמור בסעיף 266 יסומן (א) ואחריו יבוא:                |1.     |תיקון סעיף 266  |
|אדם שנפטר בישראל או תושב ישראל שהיה חולה סיעודי ומאושפז במשך תקופה העולה על 12 חודשים,     |"(ב)   |       |                |
|במוסד סיעודי שלא במקום מגוריו הרשום במרשם התושבים, תוכל משפחתו לקבור אותו במקום בו נמצא    |       |       |                |
|המוסד הסיעודי, ודמי הקבורה כמשמעותם בסעיף 266 ישולמו על ידי המוסד לביטוח לאומי."           |       |       |                |

דברי - הסבר

תושבי ישראל הנמצאים במוסד סיעודי אינם מסוגלים  לשנות את  כתובתם  במרשם התושבים, כדי שיוכלו להיקבר בקרבת מקום למשפחתם, וכדי לממש את זכאותם לתשלום דמי קבורה על חשבון המוסד, כפי שזכאי כל תושב ישראל.

התיקון יאפשר למשפחה של תושב ישראל שנפטרו לאחר ששהו במוסד סיעודי, לממש את זכותם לתשלום של הוצאות הקבורה על ידי הביטוח הלאומי.

כמו כן ימנע התיקון בחוק את הסחיטה מהמשפחות האבלות על מות יקיריהן, בידי החברה קדישא.

כמו כן יצוין  כי להצעת חוק זו אין עלות תקציבית מכיוון שבתקציב המוסד חושבו ההוצאות השנתיות עבור תשלום דמי קבורה, לתושב ישראל.
