|"הוראות פסקה זו לא יחולו על חומר ארכיוני שזכות העיון בו הוגבלה בחוק                                    |                     |

|הקהל אשר נקבע לפי החוק האמור."                                                                         |                     |
|(2) בפסקה (5) -                                                                                        |                     |
|(א) אחרי המילים "לארם הנוגע בדבר" יבוא "ואם יש באירוע ענין ציבורי                                      |                     |
|רשאי הוא לאשר פרסום סיכום ממצאי התחקיר ברבים";                                                         |                     |
|(ב) בסיפה, אחרי המילים "ואולם לא יועבר" יבוא "או יפורסם" ובמקום                                        |                     |
|המילים "העברתו תפגע" יבוא "העברתו או פרסומו יפגעו".                                                    |                     |

|דברי הסבר                                                                                                                   |
|(א) התאמת חסיון תחקיר צבאי לתקנות                            |סעיף 539א לחוק השיפוט הצבאי, התשט"ו-1955                      |
|הארכיונים (עיון בחומר ארכיוני המופקד בגנזך),                 |(להלן - החש"צ) אשר הוסף לחש"צ בתיקון מסי 33 (סייח             |
|התשכ"ז-1966 (ק"ח התשכ"ז, .עמ' 468), המאפשרות                 |התשנ"ח, עמ' 6), קובע את חיסיונם של תחקירים צבאיים             |
|חשיפת חומר מוגבל של צבא הגנה לישראל לאחר                     |הקשורים לאימונים ולפעילות מבצעית; מטרת החיסיון                |
|שחלפו 50 שנים והחומר נבדק בהיבטי ביטחון שדה                  |לשרת את תרבות התחקיר והפקת הלקחים בצה"ל כך                    |
|("סריקה"), וזאת כרי לאפשר גם למגזר האזרחי להפיק              |שחיילים יוכלו למסור באופן חופשי למפקדיהם מידע                 |
|לקחים מתחקירים צבאיים וללמוד מהם.                            |מלא בדבר שגיאות וטעויות שביצעו, הם וחבריהם,                   |
|(ב) התרת פרסום המידע העולה מתחקיר צבאי                       |במהלך אימונים ופעילות מבצעית, בלא חשש שדבריהם                 |
|במקרה שבו הרמטכ"ל רואה חשיבות ציבורית בפרסום                 |יהיו להם לרועץ במסגרת הליכים פליליים בהמשך.                   |
|הפקת הלקחים מאירוע שיש בו ענין ציבורי, וזאת כדי              |בסעיף 539א(ב) מפורטים כמה מקרים שבהם ניתן                     |
|למנוע פגיעה באמון הציבור במערכת הצבאית                       |להעביר את חומר התחקיר או את סיכום ממצאיו,                     |
|וביכולתה לחקור אירועים שהתרחשו בקרבה, ולהפיק                 |בהתאם לגורם שלו נמסר המידע.                                   |
|את הלקחים המתבקשים למניעת הישנות מקרים מעין                  |התיקון המוצע מבקש להתיר באופן מפורש פרסום                     |
|אלה בעתיד-, במקרה כזה מוצע, כי הרמטכ"ל יוכל לאשר             |המידע העולה מן התחקיר בשני מקרים נוספים לאלה                  |
|רק פרסום מוגבל בהיקפו שיכלול את סיכום ؀ࠂࠈממצאי               |המפורטים בסעיף 539א(ב) הקיים:                                 |
|התחקיר ולא את שאר חומר התחקיר הכולל למשל                     |                                                              |
