הכנסת החמש-עשרה

הצעת חוק יישום ההסכם בדבר רצועת עזה ואזור יריחו (הסדרים כלכליים והוראות שונות) (תיקוני חקיקה) (תיקון - קיזוז), התשס”ב-2002

|בחוק יישום ההסכם בדבר רצועת עזה ואזור יריחו (הסדרים כלכליים והוראות שונות) (תיקוני חקיקה),         |1.     |תיקון סעיף 16   |
|התשנ"ה-1994[1], בסעיף 16, בסופו יבוא:                                                              |       |                |
|על אף האמור בכל דין, יקוזזו מן הסכומים המועברים כספים נוספים שהרשות הפלסטינית או תאגידים   |"(ג)   |       |                |
|שבשליטתה או בניהולה חבים למדינת ישראל או ליחיד שהינו תושב ישראל או לחברה תושבת ישראל עקב   |       |       |                |
|פעולת איבה; מדינת ישראל לא תעביר כספים אלא לאחר קיזוז חובות כאמור."                        |       |       |                |

דברי - הסבר

בעקבות פעולות הטרור של הרשות הפלסטינית נגד מדינת ישראל ואזרחיה ולאור המצב הכלכלי הקשה בו חברות ישראליות פושטות את הרגל ומפטרות עובדים, מוצע להרחיב את נוסח החוק בענין יישום ההסכם בדבר רצועת עזה ואזור יריחו התשנ"ה-1994, לפיו ניתן יהיה לקזז חובות שהרשות הפלסטינית או תאגידים שבשליטתה או בניהולה חבים למדינת ישראל או ליחיד שהינו תושב ישראל או לחברה תושבת ישראל, באופן שמדינת ישראל תעביר לרשות הפלסטינית כספים שהיא חייבת לה רק לאחר שהרשות הפלסטינית תשלם את כל חובותיה למדינת ישראל ולתושבי מדינת ישראל.
