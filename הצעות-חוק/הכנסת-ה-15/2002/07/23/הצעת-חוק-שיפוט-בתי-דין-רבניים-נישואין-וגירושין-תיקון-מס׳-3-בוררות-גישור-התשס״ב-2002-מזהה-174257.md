|(ג) הוראות לפי חוק הבוררות, התשכ"ח-1968  2, יחולו על בוררות                            |                               |

|10ב. (א) בסעיף זה -                                                                    |גישור                          |
|"גישור" - הליך שבו נועד מגשר עם בעלי הרין, כדי להביאם לידי הסכמה                       |                               |
|ליישוב הסכסוך, בלי שיש בידו סמכות להכריע בו-,                                          |                               |
|"מגשר" - מי שתפקידו לסייע בידי בעלי הדין להגיע להסדר של גישור                          |                               |
|בדרך של ניהול משא ומתן חופשי ואין בידו הסמכות להכריע                                   |                               |
|בסכסוך;                                                                                |                               |
|"הסדר גישור" - הסבם בין בעלי הדין על יישוב סכסוך ביניהם שהושג                          |                               |
|בסיומו של הליך גישור.                                                                  |                               |
|(ב) בית דין רבני הדן בענין שבסמכותו, רשאי, בהסכמת בעלי הדין,                           |                               |
|להעבירו לגישור.                                                                        |                               |
|(ג) בהליך הגישור רשאי מגשר להיוועד עם בעלי הרין, יחד או                                |                               |
|לחוד, ועם כל מי שקשור לסכסוך-, ורשאי הוא להיפגש עם בעל דין,                            |                               |
|בהסכמתו, בלי עורך דינו.                                                                |                               |
|(ר) דברים؀ࠂࠆࠈࠌࠒ שנמסרו במסגרת הליך גישור לא ישמשו ראיה בהליך                           |                               |
|בפני בית דין רבני ובהליך משפטי אחר.                                                    |                               |
|(ה) העביר בית דין רבני ענין לגישור, יעכב את ההליכים שלפניו                             |                               |
|לתקופה שיקבע, ורשאי הוא להאריך את התקופה בהסכמת בעלי הרין.                             |                               |
|(ו) לא הגיעו בעלי הדין להסדר גישור עד תום התקופה, כאמור                                |                               |
|בסעיף קטן (ה), יחודשו ההליכים בבית הדין הרבני; אולם, רשאי בית הדין,                    |                               |
|על פי בקשה של המגשר או של בעל דין, לחדשם בכל עת לפני תום                               |                               |
|התקופה האמורה.                                                                         |                               |
|(ז) הגיעו בעלי הדין להסדר גישור, יודיע על כך המגשר לבית הדין                           |                               |
|הרבני ובית הדין יהיה רשאי ליתן להסדר תוקף של פסק דין.                                  |                               |
|(ח) בית דין רבני רשאי, על פי בקשת בעל דין לתת להסדר גישור,                             |                               |
