|מתפרסמת בזה הצעת חוק של חבר הכנסת מטעם ועדת החוקה חוק ומשפט של הכנסת:                                             |

|הצעת חוק לשחרור מוקדם של אסירים (תיקוני חקיקה), התשנ"ח-1998*                                                 |

|1. בחוק העונשין, התשל"ז-1977 1 -                                                                                   |תיקון חוק        |
|(1) בסעיף 49 -                                                                                                     |העונשין          |
|(א) בסעיף קטן (א), במקום "ונשא ענשו שני שלישים מאותה תקופה'' יבוא                                                  |                 |
|"ונשא מחצית מאותה התקופה" ובסופו יבוא "ואם החליט שלא לעשות כן,                                                     |                 |
|רשאי הוא לשחררו כאמור, בכל עת לאחר מכן.'';                                                                         |                 |
|(ב) במקום סעיף קטן (ב) יבוא:                                                                                       |                 |
|"(ב) מי שנידון למאסר לתקופה העולה על שישה חודשים ונשא מחצית                                                        |                 |
|מאותה התקופה, רשאית ועדת שחרורים לשחררו, ואם החליטה שלא                                                            |                 |
|לעשות כן, רשאית היא לשחררו כאמור בכל עת לאחר מכן.";                                                                |                 |
|(2) בסעיף 51, אחרי סעיף קטן (ה) יבוא:                                                                              |                 |
|"(ו) השר לבטחון הפנים, באישור ועדת החוקה חוק ומשפט של הכנסת, יקבע                                                  |                 |
|בכללים, נתונים שעל ועדת שחרורים להביאם בחשבון בבואה להחליט בענין                                                   |                 |
|שחרורו המוקדם של אסיר; כללים באמור ייקבעו לאחר שהשר נתן הזדמנות                                                    |                 |
|לרשות לשיקום האסיר, במשמעותה בחוק הרשות לשיקום האסיר, התשמ"ג-                                                      |                 |
|1982 2, להמליץ את המלצותיה."                                                                                       |                 |
|2. בפקודת בתי הסוהר [נוסח חדש], התשל"ב-1971 3, בסעיף 28, במקום "שני שלישים"                                        |תיקון פקודת      |
|יבוא "מחצית".                                                                                                      |בתי הסוהר        |
|3. ؀ࠂࠒࠔࠖࠤהוראות חוק זה יחולו גם על מי שנידון למאסר לפני תחילתו.                                                    |תחולה            |
|4. תחילתו של חוק זה שלושה חודשים מיום פרסומו.                                                                      |תחילה            |

|דברי הסבר                  |

|לפי המצב החוקי הקייס היום אפשר לרון בשחרור                     |
|מוקדם של אסיר רק לאחר שנשא שני שלישים מתקופת                   |
|מאסרו.                                                         |
|מוצע לאפשר שחרור מוקדם של אסיר כבר לאחר                        |
|שנשא מחצית מתקופת מאסרו וזאת כדי להקטין את                     |
|הצפיפות בבתי הסוהר ולקדם את שיקום האסיר.                       |

|עוד מוצע להסמיך את השר לבטחון הפנים ואת                         |
|ועדת השחרורים לשוב ולדון בכל עת, בענין שחרורו                   |
|המוקדם של אסיר שנשא מחצית מתקופת מאסרו.                         |
|להצעה זו לא צפויות עלויות כספיות.                               |
|חבר הכנסת ראובן ריבלין                                          |
