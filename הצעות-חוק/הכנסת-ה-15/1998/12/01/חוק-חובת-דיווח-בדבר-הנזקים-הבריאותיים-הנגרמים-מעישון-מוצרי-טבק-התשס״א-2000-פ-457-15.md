|מתפרסמות בזה הצעות חוק של חברי הכנסת מטעם ועדת העבודה והרווחה של הכנסת:                                                                |

|הצעת חוק למניעת נזקים מעישון מוצרי טבק, התשנ"ט-1998                                                      |

|1. בחוק זה -                                                                                                                  |הגדרות          |
|"הועדה" - ועדת העבודה והרווחה של הכנסת;                                                                                       |                |
|"מוצרי טבק" - כהגדרתם בחוק הגבלת הפרסומת למוצרי טבק לעישון, התשמ"ג-1983 1;                                                    |                |
|"השר" - שר הבריאות.                                                                                                           |                |
|2. (א) השר ירווח לכנסת, מדי שנה, על מצב העישון והתמותה מעישון סיגריות                                                         |דיווח           |
|בישראל.                                                                                                                       |                |
|(ב) הריווח יכלול את הפרטים האלה:                                                                                              |                |
|(ו) אחוז המעשנים בישראל מכלל האוכלוסיה;                                                                                       |                |
|(2) מספר המעשנים בכל קבוצת גיל, בקרב הנוער, ובקרב גברים ונשים;                                                                |                |
|(5) אחוז המעשנים במגזרים שונים, לרבות בצבא ההגנה לישראל, במגזר                                                                |                |
|הערבי והדרוזי, בקרב העולים  החדשים לפי ארצות מוצאם, במגזר החרדי                                                               |                |
|ובמקומות עבודה;                                                                                                               |                |
|(4) פעילות משרד הבריאות בתחום מניעת העישון ונזקיו, לרבות פעולות                                                               |                |
|הסברה, פעולות בכלי התקשורת, פעילות חינוך, וכל פעילות אחרת;                                                                    |                |
|(5) פעילות לעידוד גמילה מעישון;                                                                                               |                |
|(6) כל פעולת חקיקה וחקיקת משנה לשם מניעת העישון או צמצומו, לרבות                                                              |                |
|למניעת הנזק ללא-מעשנים מן העישון, ובדבר השלמתה, ואם לא הושלמה -                                                               |                |
|מה הן הסיבות לכך;                                                                                                             |                |
|(7) מצב אכיפתם של חוקים קיימים לשם מניעת העישון או צמצומו, לרבות                                                              |                |
|להגבלה או לאיסור של העישון במקומות ציבוריים ובמקומות עבודה;                                                                   |                |
|(8) מידע עדכני ברבר הנזקים הנגרמים מן העישון והחשיפה לו;                                                                      |                |

|דברי הסבר                       |

|העישון ידוע כגורם הראשון במעלה לתמותה,                        |
|הניתן למניעה. לפי נתוני ארגון הבריאות העולמי,                 |
|מיליוני בני אדם מתים מדי שנה ממחלות לב, כלי דם                |
|וסרטן שנגרמו מעישון.                                          |
|בארה"ב הממשל חייב על פי החוק, זה כ-30 שנה,                    |
|להגיש מדי שנה דו"ח לקונגרס על נזקי העישון                     |
|והפעולות הנעשות למניעתו.                                      |

|בישראל לא קיים מידע מוסמך ומרוכז לטיפול                           |
|יסודי בנזקי העישון. הצעת החוק תגרום לריכוז מידע                   |
|כזה, ותביא לעליית؀ࠂࠒࠔ࠘ࠜࠞࠠ המודעות הציבורית לנושא.                 |
|עלות החוק לפי דברי המציע - 150,000 שקלים                          |
|חדשים בשנה, והוא ימומן מסעיף הרזרבה הכללית                        |
|בתקציב המדינה.                                                    |
