|1. אחרי סעיף 28 לחוק חוזה -הביטוח, התשמ"א-1981  1יבוא:                                                             |הוספת סעיף 28א     |
|28א. מבטח בביטוחים אישיים שלא שילם למוטב שהוא המבוטח את תגמולי                               |"ריבית מיוחדת        |                   |
|הביטוח שלא היו שנויים במחלוקת בתום לב, במועדים שבהם היה עליו לשלמם                           |                     |                   |
|לפי סעיף 27, רשאי בית המשפט לחייבו, בנוסף לסכום של תגמולי הביטוח                             |                     |                   |
|האמורים ולסכום של הפרשי הצמדה על הסכומים האמורים, בשיעור שלא                                 |                     |                   |
|יעלה על פי שלושה מן הריבית הקבועה בהגדרת הפרשי הצמדה וריבית                                  |                     |                   |
|שבחוק פסיקת ריבית והצמדה, התשכ"א-1961;                                                       |                     |                   |
|לענין זה, "ביטוחים אישיים" - ביטוח רכב (רכוש), ביטוח דירות                                   |                     |                   |
|ותכולתן, ביטוח חיים וביטוחי תאונות אישיות, למעט ביטוח אחריות."                               |                     |                   |

|דברי הסבר               |

|הסעיף המוצע יקנה סמכות לבית המשפט הדן                            |
|בתביעת המבוטח נגד חברת ؀ࠂࠒࠔࠖࠤהביטוח לפסוק פיצויים                |
|לטובת המבוטח כאשר התגמולים המגיעים לו כדין                       |
|מעוכבים מעבר למותר.                                              |
|הסעיף נועד להרתיע את חברות הביטוח מלהשהות ?                      |
|את חיוכיהן שאינם שנויים במחלוקת על ידי אימוץ                     |
|מכשיר עונשי המקובל בארצות חוץ. כשם שסעיף 25                      |

|לחוק שולל את זכאות המבוטח הנוהג במרמה, כן ראוי                    |
|שיכלול החוק הוראה בדבר ריבית מיוחדת למקרה של                      |
|הפרת חובות תום הלב של המבטח. היות והודאות סעיף                    |
|28 אינן מעמידות את המבוטח במצב בו היה עומד אלמלא                  |
|הופרה חובת המבטח קיים צורך להעניק לבית המשפט                      |
|כוח להגדיל את פיצויי המבוטח.                                      |
|חבר כנסת: מרדכי וירשובסקי                                         |

|1 ס"ח התשמ"א, עמ' 94: התשמ"ד, עמ' 72.                 |
