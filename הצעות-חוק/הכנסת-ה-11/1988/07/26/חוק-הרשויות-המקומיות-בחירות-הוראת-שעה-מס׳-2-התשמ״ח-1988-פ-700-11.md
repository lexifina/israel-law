|מתפרסמת בזה הצעת חוק מטעם ועדת החוקה חוק ומשפט של הכנסת:                         |

|[188]            |חוק הרשויות המקומיות (בחירות) (הוראת שעה),                                                   |
|                 |התשמ"ח-1988                                                                                  |

|1. בחוק זה -                                                                                                       |הגדרות              |
|"רשימה מנועה" - רשימת מועמדים שמנעו ממנה להשתתף בבחירות לכנסת השתים-עשרה לפי                                       |                    |
|סעיף 7א לחוק-יסוד: הכנסת;                                                                                          |                    |
|"רשימה קשורה" - רשימת מועמדים הקשורה לרשימה מנועה, במישרין או בעקיפין, באופן גלוי                                  |                    |
|או באופן סמוי, בהתחשב באפיונים הבאים, כולם או קצתם: שמה או סימונה, מטרותיה או                                      |                    |
|מעשיה, זהותם של יוזמיה או חבריה.                                                                                   |                    |
|2. נערכו הבחירות לכלל הרשויות המקומיות ביום הבחירות לכנסת השתים עשרה, לא                                           |מניעת השתתפות       |
|תשתתף בבחירות אלה רשימה הקשורה לרשימה מנועה.                                                                       |רשימת מועמדים       |
|3. (א) יושב ראש ועדת הבחירות המרכזית לכנסת השתים-עשרה רשאי, בהתייעצות עם                                           |קביעת רשימת         |
|סגניו, לקבוע כי רשימת מועמדים שהוגשה בבחירות לרשויות המקומיות, היא רשימה קשורה.                                    |מועמדים כרשימה      |
|(ב) קביעה לפי סעיף קטן (א) תיעשה על-פי עתירה של ועדת הבחירות של הרשות                                              |קשורה               |
|המקומית הנוגעת בדבר, שעל הגשתה החליטה הוועדה ברוב חבריה, או בידי היועץ המשפטי                                      |                    |
|לממשלה; העתירה תוגש לא יאוחר מהיום ה-19 שלפני יום הבחירות.                                                         |                    |
|(ג) לא תינתן החלטה בעתירה אלא לאחר שניתנה לבאי-כוח הרשימה הקשורה הזדמנות                                           |                    |
|נאותה להשמיע טענותיהם.                                                                                             |                    |
|(ד) הגשת עתירה וההחלטה עליה על-פי סעיף זה, יכול שייעשו אף אם טרם הכריע                                             |                    |
|בית-המשפט העליון בערעור לפי סעיף 64 לחוק הבחירות לכנסת [נוסח משולב], התשכ"ט-                                       |                    |
|1969/ במקרה זה יהיו מותנות בתוצאות הערעור.                                                                         |                    |
|(ה) החלטה בעתירה לפי סעיף זה ؀ࠂࠒࠔࠖࠤתינתן לא יאוחר מהיום ה-12 שלפני יום הבחירות;                                    |                    |
|(ו) שום בית משפט לא יזדקק לבקשת סעד בקשר להחלטה לפי סעיף זה, או בקשר לדיון                                         |                    |
|בעתירה לפיו.                                                                                                       |                    |
|4, נקבע סופית כי רשימת מועמדים היא רשימה קשורה - יודיע על כך פקיד הבחירות                                          |הודעת פקיד          |
|בהודעתו לפי סעיף 48 לחוק הרשויות. המקומיות (בחירות), התשכ"ה-.1965 2.                                               |הבחירות             |
|5. שר המשפטים רשאי, בהתייעצות עם יושב-ראש ועדת הבחירות המרכזית לכנסת, להתקין                                       |תקנות סדרי דין      |
|תקנות סדרי דין בעתירה לפי חוק זה.                                                                                  |                    |
|6. שר הפנים ממונה על ביצוע חוק זה והוא רשאי להתקין תקנות בכל הנוגע לביצועו.                                        |ביצוע ותקנות        |

|דברי הסבר             |

|מטרת החוק היא למנוע מרשימות הרוצות להתמודד                      |
|בבחירות לרשויות המקומיות והקשורות עם רשימות שנפס-               |
|לו לרוץ לבחירות לכנסת, מלהשתתף בבחירות לרשויות                  |

|המקומיות מטעמי גזענות ופגיעה בדמוקרטיה. ,                          |
|ביצוע החוק אינו כרוך בהוצאה תקציבית.                               |
