|חוק העיסוק באופטומטריה, התשמ"ד-1984                                   |

|הגדרות       |1. בחוק זה -                                                                                                 |
|             |"אופטומטריה" - מדידה של כושר הראייה או של טווח הראייה של אדם, קביעה של                                       |
|             |מצב ההסתגלות או השבירה של עינו של אדם, התאמת עדשות לשיפור הראיה, מתן                                         |
|             |מרשם או הוראה בדבר שימוש במכשיר אופטי לראייה לתרגילי עיניים, לאימון                                          |
|             |הראייה או ליישורה, ומתן מרשם לעדשות מגע, התאמתן או קביעתן לעינו של אדם ;                                     |
|             |"אופטומטראי" - מי שהורשה לפי חוק זה לעסוק באופטומטריה;                                                       |
|             |"המנהל" - המנהל הכללי של משרד הבריאות, או מי שהוא הסמיך לענין חוק זה;                                        |
|             |"הועדה המייעצת" - הועדה המייעצת שמונתה לפי סעיף 9.                                                           |

|2. (א) המנהל יתן רשיון לעסוק באופטומטריה למבקש שהוא בעל הכשרה מקצועית                                             |זכאות לרשיון       |
|באופטומטריה.                                                                                                      |                   |
|(ב) אלד, ייחשבו כבעלי הכשרה מקצועית בארפטומטריה לענין חוק זה:                                                     |                   |
|(1) מי שסיים בהצלחה לימודי אופטומטריה, בישראל או מחוצה לה, במוסד                                                  |                   |
|או בקורס שהמנהל הכיר בהם לענין פסקה זו;                                                                           |                   |
|(2) מי שסיים בהצלחה לימודי אופטומטריה, בישראל או מחוצה לה,                                                        |                   |
|במוסד או בקורס שהמנהל הכיר בהם לענין פסקה זו ובנוסף התמחה בעבודה                                                  |                   |
|מעשית באופטומטריה במשך תקופה שקבע המנהל לענין אותו מוסד או                                                        |                   |
|קורס ושלא תעלה על שנה ועמד בהצלחה בבחינות מקצועיות שקבע המנהל.                                                    |                   |
|(ג) שר הבריאות לאחר התייעצות עם הועדה המייעצת, יתקין תקנות בדבר -                                                 |                   |
|(1) התנאים למתן הכרה במוסד או בקורס לענין סעיף זה;                                                                |                   |
|(2) סדרי ההתמחות והפיקוח עליה;                                                                                    |                   |
|(3) פרטי הבחינות וסדריהן.                                                                                         |                   |
|3. (א) לא יעסוק אדם באופטומטריה ולא ישתמש בתואר אופטומטראי או תואר דומה                                           |ייחוד העיסוק       |
|המרמז על היותו אופטומטראי אלא אם כן בידו רשיון שניתן לו לפי חוק זה.                                               |והכינוי            |
|(ב) הוראת איסור העיסוק באופטומטריה כמפורט בסעיף קטן (א) לא יחול -                                                 |                   |
|(1) על רופא מורשה ;                                                                                               |                   |
|(2) על מתמחה בעבודה מעשית באופטומטריה בפיקוחו ובהדרכתו של                                                         |                   |
|אופטומטראי מורשה או של רופא מורשה.                                                                                |                   |
|4. (א) שר הבריאות רשאי לקבוע בתקנות, לאחר התייעצות בועדה המייעצת -                                                |מומחיות מוכרת      |
|(1) שענף פלוני באופטומטריה הוא מומחיות מוכרת ואת התנאים, ההכשרה                                                   |                   |
|הנדרשת, הבחינה וסדרי מתן התואר והתעודה למומחה מוכר;                                                               |                   |
|(2) שירותים מסויימים באופטומטריה שייוחדו למומחים מוכרים.                                                          |                   |
|(ב) בתקנות לפי סעיף קטן (א) (2) ייקבעו הוראות בדבר המשך מתן השירות                                                |                   |
|בידי מי שנתן שירות שיוחד למומחה מוכר לפני שהוא יוחד כאמור, לרבות התנאים,                                          |                   |
|ההגבלות והתקופה להמשך מתן השירות.                                                                                 |                   |
