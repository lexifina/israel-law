|מתפרסמת בזה הצעת חוק מטעם  הכלכלה של הכנסת :                                   |

|חוק מפעלים העומדים בפני סגירה (רכישה בידי עובדים),                                                 |
|התשמ"ו-1986                                                                                        |

|1. בחוק זה -                                                                                                            |הגדרות            |
|"מפעל" - מקום עבודה בענף התעשיה או בענף הבניה שבו מועסקים לא יותר מ-200                                                 |                  |
|עובדים, והוא נכס הנמצא בבעלותו של תאגיד או יחיד, שהתקיים בו אחד מאלה:                                                   |                  |
|(1) הוא נסגר כליל;                                                                                                      |                  |
|(2) הופסקה בו עיקר הפעילות למשך שלושה חדשים;                                                                            |                  |
|(3) הוא בבעלות של תאגיד שניתן נגדו צו כינוס נכסים לרבות צו זמני או                                                      |                  |
|מונה לו מפרק לרבות מפרק זמני;                                                                                           |                  |
|(4) היא בבעלות של יחיד שניתן נגדו צו כינוס נכסים, לרבות צו זמני, או                                                     |                  |
|שמונה לו נאמן בפשיטת רגל;                                                                                               |                  |
|"עובד" - עובד מפעל אשר ביום הגשת הבקשה לפי סעיף 5 מלאה שנה לפחות לעבודתו                                                |                  |
|באותו מפעל;                                                                                                             |                  |
|"ארגון העובדים היציג" - ארגון העובדים המייצג את המספר הגדול ביותר של עובדים                                             |                  |
|בישראל.                                                                                                                 |                  |
|2. (א) הממשלה וארגון העובדים היציג יקימו קרן למתן הלואות לשם רכישת                                                      |הקרן              |
|מפעלים בידי עובדי אותם מפעלים (להלן - הקרן).                                                                            |                  |
|(ב) הסכומים שהממשלה וארגון העובדים היציג יעבירו לקרן ומועדי העברת                                                       |                  |
|הסכומים, ייקבעו בהסכמים בין הממשלה ובין ארגון העובדים היציג, ובלבד שהסכומים                                             |                  |
|שיעבירו הממשלה וארגון העובדים היציג לקרן יהיו בשיעורים שווים, זולת אם הוסכם                                             |                  |
|ביניהם אחרת לענין זה.                                                                                                   |                  |
|(ג) כספי הקרן יושקעו באוצר המדינה על פי הוראות שיקבע החשב הכללי                                                         |                  |
|במשרד האוצר, וחשבונות הקרן ינוהלו בידי החשב הכללי על פי הנחיות הועדה, שהוקמה                                            |                  |
|לפי סעיף 3.                                                                                                             |                  |
|3. (א) לצורך ביצוע תפקידי הקרן על פי חוק זה ימנו שר התעשיה והמסחר ושר                                                   |הועדה             |
|העבודה והרווחה ועדה אשר תקבע את מדיניות הקרן ודרכי פעולתה (להלן - הועדה).                                               |                  |

|דברי הסבר                |

|מטרתו של חוק זה לאפשר רכישת מפעלים קטנים                      |
|ובינוניים, הנמצאים בסכנת סגירה, בידי עובדיהם,                 |
|לשב עידוד הפיתוח והתעסוקה במשק, ומניעת אבטלה.                 |
|המציאות היא,שמפעלים נסגרים,במיוחד                             |
|במקומות קטנים ובעיירות  פיתוח מסיבות של רווחיות               |
|לא מספקת,  החלטת  רן לצמצם או להעביר את                       |
|עסקיו, ובמפעלים משפחתיים - סגירה בשל מות אחר                  |

|הבעלים, אי המשכת העסקים בידי בני משפחות הבעלים                    |
|וכיוצא באלה.                                                      |
|במקרים כאמור מוצע לאפשר המשך קיום המפעל                           |
|על ידי מכירתו לעובדיו, בכפוף לתנאים וסייגים                       |
|כמפורט להלן.                                                      |
|מוצע להקים קרן משותפת לממשלה ולארגון                              |
|העובדים  היציג שתסייע לעובדים במפעל .העומד                        |

|סדר עבודת        |(ב) בועדה יהיו ששה חברים במפורט להלן :                                                                           |
|הועדה            |(1) נציג משרד -תעשיה והמסחר, והוא יהיה יושב-ראש הועדה;                                                           |
|                 |(2) נציג שר העבודה והרווחה, והוא יהיה ממלא מקום היושב-ראש;                                                       |
|                 |(3) נציג משרד האוצר;                                                                                             |
|                 |(4) שלושה נציגים של ארגון העובדים היציג שהוא יקבעם.                                                              |
|                 |(ג) לישיבות הועדה יוזמן, ללא זכות הצבעה, נציג ארגון המעבידים אשר לדעת                                            |
|                 |יושב ראש הועדה הוא ארגון מעבידים יציג בענף בו פועל המפעל, שלגביו הוגשה                                           |
|                 |בקשת סיוע לפי סעיף 5.                                                                                            |
|                 |4. הועדה תקבע את סדרי עבודתה ותהיה רשאית להסמיך אחד או יותר מחבריה                                               |
|                 |לפעול בשמה לביצוע החלטותיה.                                                                                      |
|הגשת בקשה        |5- (א) ועד עובדים של מפעל או נציגות מיוחדת של העובדים במפעל שהוסמכו                                              |
|לסיוע            |לענין סעיף זה באסיפת עובדים בידי רוב העובדים באותו מפעל, רשאים לפנות לועדה                                       |
|                 |בבקשה לקבלת סיוע מהקרן לשם רכישת המפעל בידי העובדים בו.                                                          |
|                 |(ב) שר העבודה והרווחה רשאי, בהתייעצות עם שר התעשיין והמסחר, לקבוע                                                |
|                 |בתקנות הוראות בענין סדר כינוס אסיפת העובדים לענין סעיף קטן (א).                                                  |
|עמדת המפעל       |6. הוגשה בקשה כאמור בסעיף 5, תיתן הועדה למי שמוסמך לפעול מטעם המפעל                                              |
|                 |הזדמנות להשמיע עמדתו לפני הועדה.                                                                                 |
|הטיפול בבקשת     |7. (א) החליטה הועדה כי יש מקום לבדוק את הבקשה, תזמין הוות דעת מקצועית                                            |
|הסיוע            |(להלן - חוות הדעת) לגבי המפעל שלענינו הוגשה הבקשה; חוות הדעת תכלול היבטים                                        |
|                 |כלכליים, משפטיים ותעסוקתיים הקשורים בבקשה.                                                                       |
|                 |(ב) חוות הדעת תמומן מכספי הקרן.                                                                                  |
|                 |(ג) הועדה רשאית, בהסכמת מי שמוסמך לפעול מטעם ؀ࠂࠐࠒࠖࠠࠢࠦࠬ࠮࠰࠾המפעל, להביא לידיעתם                                    |
|                 |של קונים אפשריים של המפעל, מידע על המפעל וכן את הוות הדעת או הלק ממנה.                                           |
|                 |(ד) משקיבלה הועדה את הוות הדעת ולא נמצא קונה למפעל, רשאית הועדה,                                                 |
|                 |לפי שיקול דעתה, להחליט על סיוע לעובדים ברכישת המפעל בהתאם להוראות חוק זה.                                        |
|הסיוע            |8. (א) הסיוע של הועדה לרכישת מפעל יינתן בדרך של הלוואה לאגודה שיתופית                                            |
|                 |של העובדים שהוקמה לפי סעיף 9, ובתנאים שתקבע הועדה.                                                               |
|                 |(ב) כל ההסכמים והמסמכים המשפטיים הקשורים ברכישת המפעל בידי העובדים                                               |
|                 |יהיו טעונים אישור הועדה.                                                                                         |

|דברי הסבר                     |

|בסכנת סגירה לרכוש את המפעל. את מדיניות הקרן                     |
|תקבע ועדה משותפת לנציגי משרדי הממשלה                            |
|הנוגעים ולארגון העובדים היציג                                   |
|כאשר מפעל עומד  בסכנת סגירה ועובדי אותו                         |
|מפעל יפנו לועדה בבקשה לסייע ברכישתו, תפנה                       |

|הועדה לקבל חוות דעת לגביו, ובאין קונה למפעל                    |
|תינתן זכות לעובדים לרכוש את המפעל, בסיוע הקרן.                 |
|העובדים יקימו לצורך רכישה זו אגודה שיתופית ולה                 |
|ועד אגודה לניהול המפעל.                                        |

|9. לשם רכישת המפעל וניהולו תוקם בידי העובדים אגודה שיתופית על פי פקודת                                              |אגודה שיתופית    |
|האגודות השיתופיות 1 (להלן - הפקודה), ולעניז חוק זה יחולו על האגודה הוראות                                           |של העובדים       |
|מיוחדות אלה, בנוסף להוראות הפקודה והתקנות שלפיה:                                                                    |                 |
|(1) הבקשה לרישום האגודה, כאמור בסעיף 8 לפקודה, תיחתם בידי שני                                                       |                 |
|שלישים לפחות מן העובדים; לכל עובד תהיה הזכות להימנות עם חותמי                                                       |                 |
|הבקשה לרישום האגודה;                                                                                                |                 |
|(2) השיעור המזערי של השתתפותו של חבר בהון האגודה ייקבע בידי                                                         |                 |
|הועדה;                                                                                                              |                 |
|(3) התקנות המוצעות של האגודה, כאמור בסעיף 8 לפקודה, טעונות אישור                                                    |                 |
|הועדה; לאחר רישום האגודה וכל עוד לא נפרעו חובותיה, טעון כל שינוי                                                    |                 |
|מוצע בתקנותיה אישורה של הועדה;                                                                                      |                 |
|(4) שיעור הגמול שישולם לחבר האגודה בעד עבודתו במפעל שרכשה                                                           |                 |
|האגודה טעון אישור האסיפה הכללית של האגודה בהתאם לכללים שייקבעו                                                      |                 |
|בתקנותיה ;                                                                                                          |                 |
|(5) בתקנות האגודה ייקבעו הוראות לענין הצטרפות חברים לאגודה;                                                         |                 |
|(6) חדל חבר האגודה, דרך קבע, לעבוד במפעל שרכשה האגודה, תפקע                                                         |                 |
|חברותו באגודה, הכל בהתאם לכללים שייקבעו בתקנות האגודה;                                                              |                 |
|(7) ועד האגודה יהיה מורכב משלושה נציגים של חברי האגודה שתבחר                                                        |                 |
|בהם האסיפה הכללית שלה, וארבעה נציגים של הועדה; הרכב ועד האגודה                                                      |                 |
|לפי הוראות פסקה זו הוא למשך שנתיים מיום החלטת הועדת לסייע לעובדים                                                   |                 |
|ברכישת המפעל או מיום רישום האגודה לפי הפקודה, לפי המאוחר, ואולם                                                     |                 |
|הועדה רשאית לקצר את התקופה האמורה אם ראתה שאין עוד צורך בפיקוח                                                      |                 |
|שלה על אופן ניהול האגודה.                                                                                           |                 |
