|59א. (א) בעל דירה רשאי להתקין במקום סביר על גג הבית המשותף,                                            |"דוד שמש        |                      |
|שהוא רכוש משותף, דוד לחימום מים על ידי אנרגית השמש (להלן -                                             |                |                      |
|דוד שמש) לרבות המיתקנים הקשורים לכך וצינורות להולכת המים                                               |                |                      |
|לדירתו, ללא הסכמת בעלי הדירות האחרים, ובלבד שנתקיימו שני אלה:                                          |                |                      |
|(1) הוא קיבל היתר להתקנה לפי חוק תכנון והבניה,                                                         |                |                      |
|התשכ"ה--1965 2, ומילא אחרי תנאי ההיתר;                                                                 |                |                      |
|(2) המקום שעליו יותקן דוד השמש אינו משמש את בעלי                                                       |                |                      |
|הדירות למטרה כלשהי שהוסכם עליה, בין בהחלטה של                                                          |                |                      |
|בעלי הדירות ובין בהתנהגות, והוא לא נועד לשמש למטרה                                                     |                |                      |
|כלשהי לפי תקנון הבית המשותף.                                                                           |                |                      |
|(ב) לא הספיק גג הבית המשותף למספר דודי שמש כמספר                                                       |                |                      |
|הדירות בבית, לא יתקין בעל דירה דוד שמש כאמור בסעיף קטן (א) ;                                           |                |                      |
|אלא לאחר שקיבל את הסכמת כל בעלי הדירות האחרות; ובלבד שאם                                               |                |                      |
|התנגד לכך בעל דירה אחת שזכויותיו ברכוש המשותף אינן עולות על                                            |                |                      |
|12.5 אחוזים מכלל הזכויות ברכוש המשותף, וההתנגדות היתה מטעמים                                           |                |                      |
|בלווי סבירים או שהסכמתו הותנתה בתנאים בלתי סבירים, רשאי המפקח                                          |                |                      |
|להרשות את התקנת דוד השמש.                                                                              |                |                      |
|(ג) תעודה בחתימת מהנדס הועדה המקומית לתכנון ולבניה                                                     |                |                      |
|תשמש ראיה בשאלה אם גג הבית מספיק או אינו מספיקה למספר דודי                                             |                |                      |
|שמש כמספר הדירות בבית.                                                                                 |                |                      |

|דברי הסבר                                |

|מטרת החוק המוצע לסייע במאמצים לחסוך                              |
|באנרגיה,                                                         |
|לפי החוק הקיים לא ניתן לשנות זכויות            |לסעיף 59א         |
|של בעלי דירות בבית משותף ללא                   |                  |
|הסכמת כל בעלי הדירות. מאחר וגג הבית הינו רבוש                    |
|משותף של כל בעלי הדירות, אין בעל דירה רשאי                       |
|להתקין על הגג דוד שמש ללא הסכמת כל בעלי                          |
|הדירות.                                                          |
|כיוצא בזה, מיתקני ההסקה או חימום המים הינם                       |
|רכוש משותף וכל בעל דירה חייב להשתתף בהוצאות                      |
|הדרושות להחזקתם התקינה ולהבטחת השירותים המחו-                    |
|ייבים בהתאם לחלקו ברכוש המשותף.                                  |

|מוצע שבעל דירה יהיה רשאי להתקין דוד שמש                           |
|על הגג ללא הסכמת פעלי הדירות האחרים. תנאי לכך                     |
|הוא שיקבל היתר לפי חוק התכנון והבניה וההתקנה                      |
|؀ࠂࠒࠔ࠘ࠢࠤࠦ࠴࠶תהא תואמת את תנאי ההיתר, ושהמקום איננו משמש             |
|למטרה אחרת שהסכימו עליה בעלי הדירות או שנועד                      |
|לשמש למטרה אחרת לפי תקנון מוסכם.                                  |
|עם זאת מוצע שאם שטת הגג איננו מספיק לדודי                         |
|שמש כמספר הדירות בבית יהיה צורך לקבל את הסכמת                     |
|כל בעלי הדירות. אולם אם בעל דירה אחת בבית,                        |
|שחלקו ברכוש המשותף אינו עולה על 12.5 אחוזים                       |
|מכלל הזכויות ברכוש המשותף, מתנגד מטעמים בלתי                      |
|סבירים, יהיה המפקח רשאי להתיר את התקנת דוד                        |
|השמש.                                                             |
