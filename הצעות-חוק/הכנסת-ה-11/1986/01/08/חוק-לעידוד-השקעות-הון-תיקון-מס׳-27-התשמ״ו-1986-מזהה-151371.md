|דברי הסבר                   |

|חוק לעידוד השקעות הון, התשי"ט-1959, מעניק                            |
|לבעל מפעל מאושר מענק השקעה והטבות במס הכנסה.                         |
|מענק ההשקעה הוא בשיעור משווי הנכסים של                               |
|המפעל, כשהשיעור משתנה בהתאם לאזור שבו מצוי                           |
|המפעל, כלהלן: באזור פיתוח אי שיעור המענק הוא                         |
|35%, באזור פיתוח ב' 20% ובאזור אחר - 5%;                             |
|(בהצעת חוק לעידוד השקעות הון (תיקון מסי 25),                         |
|התשמ"ה-1985, הנדונה עתה בועדת הכספים של הכנ-                         |
|סת, הוצע להפחית את שיעור המענק ב-5%).                                |
|ההטבות במס הכנסה ניתנות ללא אבחנה בין                                |
|האזורים השונים, ואלה הן: בתקופה של שבע שנים                          |
|מתחייבת ההכנסה מהמפעל במס חברות בשיעור של                            |
|30% בלבד ופטורה מכל מס אחר; ובעל המניות בחברה                        |
|חייב בשל הדיבידנד המשתלם מתוך ההכנסה האמורה                          |
|שהופקה באותה תקופה במס בשיעור של 15% בלבד.                           |

|ההטבות המוענקות על פי החוק הקיים מעוררות                         |
|קשיים בשני תחומים: התחום האחד הוא המגבלות                        |
|התקציביות שאינן מאפשרות למרכז ההשקעות להיענות                    |
|לכל הבקשות של היזמים לאשרם במפעלים מאושרים;                      |
|הקושי השני הוא בעובדה שהמענק הוא בשיעור משווי                    |
|הנכסים, ועל כן יש לו משמעות רבה לגבי מפעלים                      |
|עתירי נכסים, אך אין לו משמעות של ממש לגבי                        |
|מפעלים עתירי ידע וטכנולוגיה.                                     |
|התיקון המוצע נועד לענות לבעיות אלה, בהעמידו                      |
|לזכות היזמים אפשרות של בחירה במסלול הטבות                        |
|חילופי, הכולל ויתור מוחלט על מענק ההשקעה תמורת                   |
|הגדלת ההטבות במס הכנסה, זאת לתקופה המשתנה,                       |
|בהתאם לאזור שבו מצוי המפעל, כלהלן:                               |
|(1) מפעל באזור פיתוח א' יהא זכאי לפטור מוחלט                     |
|מהמס במשך 10 שנים;                                               |

|1 ס"ח התשי"ט, עמ' 34; התשמ"ה, עמ' 200.         |

|2. אחרי סעיף 50 לחוק העיקרי יבוא:                                                                                 |הוספת סיעיף 51     |
|51. (א) קיבל מפעל אישור אחרי יום פרסומו של חוק לעידוד השקעות                                 |"מסלול הטבות        |                   |
|הון (תיקון מסי 27), התשמ"ו-1986 (להלן - יום התחילה) או קיבל                                  |חילופי              |                   |
|אישור לפני יום התחילה אך עד אותו ירם טרם ניתן לגביו מענק, רשאי                               |                    |                   |
|בעלו, תוך שלושה חדשים מיום התחילה, לבחור במסלול הטבות חילופי                                 |                    |                   |
|במקום מענק השקעה לפי הפרק הששי ובמקום ההטבות במס לפי סעיף                                    |                    |                   |
|47; הוראה זו לא תחול לגבי הרחבה של מפעל קיים.                                                |                    |                   |
|(ב) בעל מפעל שבחר במסלול הטבות חילופי יהיה זכאי להטבות                                       |                    |                   |
|؀ࠂࠎࠐࠔࠞࠠࠢࠨשלהלן בשל הכנסתו החייבת שהושגה מאותו מפעל:                                          |                    |                   |
|(1) אם המפעל נמצא באזור פיתוח א' - לפטור ממס במשך                                            |                    |                   |
|10 שנים מתחילת תקופת ההטבות;                                                                 |                    |                   |
|(2) אם המפעל נמצא באזור פיתוח ב' - לפטור ממס במשך                                            |                    |                   |
|6 שנים מתחילת תקופת ההטבות, והטבות במס על פי סעיף                                            |                    |                   |
|47 ביתרת תקופת ההטבות ;                                                                      |                    |                   |
|(3) אם המפעל נמצא באזור אחר - לפטור ממס במשך                                                 |                    |                   |
|שנתיים מתחילת תקופת ההטבות, והטבות במס על פי סעיף 47                                         |                    |                   |
|ביתרת תקופת ההטבות.                                                                          |                    |                   |
|(ג) קיבל אדם דיבידנד ששולם מתוך הכנסה של מפעל שהושגה                                         |                    |                   |
|בתקופה שבה בעל המפעל פטור ממס לפי סעיף קטן (ב), יהא חייב עליו,                               |                    |                   |
|על אף האמור בסעיף 47(ב)(2), במס הכנסה בשיעור של 40%; הוא                                     |                    |                   |
|הדין לגבי פירות השקעה המשתלמים על ידי חברה מתוך דיבידנד כאמור.                               |                    |                   |
|(ד) בסעיף זה, "תקופת ההטבות" - כאמור בסעיף 45(א)(1);                                         |                    |                   |
|(ה) הבוחר במסלול הטבות חילופי יודיע על כך בכתב למינהלה                                       |                    |                   |
|תוך שלושה חדשים מיום התחילה."                                                                |                    |                   |
|3. על אף האמור בסעיף 51 לחוק העיקרי כפי שהוסף בחוק זה, רשאים השרים, בשל                                           |הוראת מעבר         |
|נימוקים מיוחדים, להתיר גם לבעל מפעל מאושר שקיבל מענק לראשונה אחרי יום ט'                                          |                   |
|בניסן התשמ"ה (31 במרס 1985), לבחור במסלול הטבות חילופי כאמור בסעיף קטן (א)                                        |                   |
|של הסעיף האמור, ובלבד שיחזיר תוך שלושה חדשים מיום שהתירו השרים כאמור את                                           |                   |
|המענק ומענק ההישבון שקיבל, בתוספת הפרשי הצמדת למדד המחירים לצרכן שמפרסמת                                          |                   |
|הלשכה המרכזית לסטטיסטיקה מן המדד שפורסם לאחרונה לפני קבלתו עד המדד שפורסם                                         |                   |
|לאחרונה לפני החזרתו; בקשה להיתר לבחור כאמור תוגש לשרים תוך שלושה חדשים                                            |                   |
|מיום פרסומו של חוק זה.                                                                                            |                   |
