|[76]           |חוק חיילים משוחררים (מענק הסתגלות), התשמ"ז-1987                                                |

|1. כל חייל המשתחרר משירות סדיר לפי חוק שירות בטחון [נוסח משולב], התשמ"ו                                             |זכות            |
|- 1986 1, של יותר מששה חדשים רצופים, יהיה זכאי למענק לפי חוק זה מאת המדינה.                                         |                |
|2. המענק ישולם בשלושה שיעורים שווים של 900 שקלים חדשים כל אחד -                                                     |סכום            |
|(1) ב-1 בספטמבר שלאחר השחרור ;                                                                                      |                |
|(2) ב-1 בספטמבר בשנת שלאחר מכן;                                                                                     |                |
|(3) ב-1 בספטמבר בשנה שלאחר מכן;                                                                                     |                |
|ובלבד שחייל ששירת פחות משלוש שנים יהיה זכאי לששית מכל אחד משיעורי                                                   |                |
|המענק בשל פל תקופה של ששת חדשים ששירת, ולעניו זה תעוגל תקופה אחת                                                    |                |
|של שלושה חדשים או יותר כלפי מעלה.                                                                                   |                |
|3. המענק לפי חוק זה יהיה בנוסף לכל הענקה אחרת המשתלמת לחייל משתחרר                                                  |שמירה           |
|לפי דין או לפי פקודות הצבא.                                                                                         |                |
|4. שר האוצר ממונה על ביציע חוק זה ؀ࠂࠊࠌוהוא רשאי להתקין תקנות בכל ענין הנוגע                                         |ביצוע ותקנות    |
|לביצועו.                                                                                                            |                |
|5. תהילתו של חוק זה ביום ז' באלול התשמ"ז (1 בספטמבר 1987) והוא יחול אף                                              |תחילה ותחולה    |
|על מי שהשתחרר לפני כן, ואולם לא יזכה אדם לפיו בשיעור מענק זולת המגיע לו                                             |                |
|לפי סעיף 2 ביום התחילה או אחריו.                                                                                    |                |
