|מתפרסמת בזה הצעת חוק מטעם ועדת הפנים ואיכות הסביבה של הכנסת:                       |

|חוק לתיקון פקודת העיריות (מס' 33), התשמ"ז-1987                                           |

|1. אחרי סעיף 249 לפקודת העיריות 1, יבוא:                                                                           |הוספת סעיף         |
|                                                                                                                   |249א               |
|249א. פעלה העירית על פי סמכויותיה לפי סעיף 249(30) והוקמה                                        |"תאגידים         |                   |
|הברה, עמותה, אגודה שיתופית או אגודה אחרת שמטרותיה במסגרת                                         |עירוניים         |                   |
|סמכויות העירית ותפקידיה, ויש בידי העיריה לפחות מחצית ההון או                                     |                 |                   |
|מחצית כוח ההצבעה בתאגיד כאמור (להלן - תאגיד עירוני), יחולו                                       |                 |                   |
|הוראות אלה:                                                                                      |                 |                   |
|(1) מועצת העיריה תקבע את נציגיה בגוף המנהל של התאגיד                                             |                 |                   |
|העירוני; נציגים אלה יכול שיהיו חברי המועצה או עובדי                                              |                 |                   |
|העיריה; נציגי העיריה יקפידו על כך שפעולות התאגיד העירוני                                         |                 |                   |
|יהיו במסגרת מטרות העיריה, תפקידיה וסמכויותיה;                                                    |                 |                   |
|(2) נציגי העיריה כאמור, שהינם חברי המועצה, ייבחרו כך                                             |                 |                   |
|שיישמרו, ככל האפשר, יחסי הכוחות של הסיעות במועצה;                                                |                 |                   |
|(3) נציג עיריה כאמור, שהינו חבר המועצה, לא יהיה רשאי                                             |                 |                   |
|לקבל שכר או כל תמורה אחרת בעד כהונתו בתאגיד העירוני,                                             |                 |                   |
|אלא -באישור מאת שר הפנים;                                                                        |                 |                   |
|(4) הוראות סעיף 122 א (א) לא יחולו על תאגיד עירוני בשל                                           |                 |                   |
|כך בלבד שחבר המועצה או עובד העיריה הוא נציג העיריה                                               |                 |                   |
|בגוף המנהל שלו.                                                                                  |                 |                   |

|דברי ؀ࠂࠔࠖ࠘ࠦהסבר         |

|הנושא של תאגידים עירוניים אינו מוסדר די                        |
|הצורך. למרות שמכוח סעיף 249 (30) לפקודת העיריות                |
|הוקם מספר ניכר של תאגידים כאלה, הרי עדיין                      |
|קיימת אי בהירות בכל הנוגע למעמדם של אותם                       |
|חברי מועצת העיריה או עובדיה שנבחרו על ידי                      |
|מועצת העיריה להיות נציגיה בתאגיד. ההצעה באה,                   |

|איפוא, להסדיר את מינוי נציגי העיריה בתאגיד                    |
|עירוני.                                                       |
|כמו כן באה ההצעה למנוע פסילת קשרים עסקיים                     |
|בין העיריה לבין התאגיד, רק בשל מינוים של חברי                 |
|מועצה או עובדי העירית לכהונה בגוף המנהל של                    |
|התאגיד העירוני.                                               |

|חבר הכנסת דב בן-מאיר            |
