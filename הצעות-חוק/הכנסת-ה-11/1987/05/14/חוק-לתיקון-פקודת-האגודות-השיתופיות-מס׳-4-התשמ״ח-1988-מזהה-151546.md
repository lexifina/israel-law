|חוק לתיקון פקודת האגודות השיתופיות (מס' 4), התשמ"ז-1987[53]                                             |

|סעיף 6 לפקודת האגודות השיתופיות/ יבוא:                                                        |1. אחרי           |הוספת סעיף 6א      |
|6א. (א) י- חבר באגודה רשומה, שהרשם סיווג אותה כמושב עובדים או ככפר                            |"חברות של         |                   |
|שיתופי (להלן - ישוב שיתופי), יהיה בן-זוגו לחבר באותה אגודה אם נתקיימו                         |בן-זוג בישוב      |                   |
|כל אלה:                                                                                       |שיתופי            |                   |
|(1) בן הזוג הגיש לאגודת הודעה בטופס שנקבע בתקנות על רצונו                                     |                  |                   |
|להיות חבר באגודה:                                                                             |                  |                   |
|(2) בן הזוג כשיר לפי תקנות האגודה להיות חבר בה:                                               |                  |                   |
|(3) בני הזוג גרים דרך קבע בישוב השיתופי;                                                      |                  |                   |
|(4) בני הזוג מחזיקים כדין במשק חקלאי בתחום הישוב השיתופי                                      |                  |                   |
|כבעלים, חוכרים או חוכרי-משנה, או כבני רשות של האגודה או של                                    |                  |                   |
|מוסד מיישב כמשמעותו בחוק המועמדים להתיישבות חקלאית,                                           |                  |                   |
|התשי"ג-1953 2.                                                                                |                  |                   |
|(ב) מי שנתקיימו לגביו התנאים המפורטים בסעיף קטן(א) יהיה, על אף                                |                  |                   |
|האמור בתקנות האגודה, לחבר האגודה מעת ؀ࠂࠒࠔࠖࠤהגשת ההודעה כאמור בפסקה                            |                  |                   |
|(א)(1), ויחולו עליו הזכויות והחובות של חבר באגודה לפי פקודה זו ולפי                           |                  |                   |
|תקנות האגודה.                                                                                 |                  |                   |
|(ג) אין בהוראות סעיף זה כדי לגרוע מהוראות תקנות האגודה בדבר                                   |                  |                   |
|פקיעת חברות בה, יציאת חבר או הוצאתו ממנה."                                                    |                  |                   |

|דברי הסבר              |

|מטרת החוק המוצע היא להבטיח כי החברות באגודה                    |
|שהיא ישוב שיתופי תהא גם לבן זוגו של חבר האגודה, אם             |
|רצונו בכך ואם הוא כשיר להיות חבר האגודה. ההצטרפות              |

|תהא בהגשת הודעה מאת בן הזוג על רצונו להצטרף לאגודה            |
|כטופס שייקבע בתקנות.                                          |
