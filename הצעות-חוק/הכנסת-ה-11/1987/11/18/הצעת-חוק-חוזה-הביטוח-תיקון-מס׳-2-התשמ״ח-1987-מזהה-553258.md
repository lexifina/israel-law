|[86]             |חוק חוזה הביטוח (תיקון מס' 2), התשמ"ח-1987                                                    |

|1. בחוק חוזה הביטוח, התשמ"א-1981 1, אחרי סעיף 27 יבוא:                                                           |הוספת סעיף 27א         |
|27א. לא שילם מבטח תגמולי הביטוח במועדם כאמור בסעיף 27,                                         |"פיצויים עונשיים |                       |
|בהסתמכו על טענה משוללת יסוד או לליא הצדקת עניינית בנסיבות                                      |                 |                       |
|העניין, או בחוסר תום-לב, רשאי בית המשפט לחייב המבטח, בנוסף                                     |                 |                       |
|לתגמולי הביטוח, בתשלום פיצויים למבוטח בשיעור של עד 30% משווי                                   |                 |                       |
|תגמולים אלה."                                                                                  |                 |                       |

|דברי הסבר                       |

|הסעיף המוצע יקנה סמכות לבית-המשפט הדן                             |
|בתביעת המבוטח נגד חברת הבימות לפסוק פיצויים                       |
|לטובת המבוטח כאשר התגמולים המגיעים לו כדין                        |
|מעוכבים מעבר למותר.                                               |
|הסעיף נועד להרתיע את חברות הביטוח מלהשהות                         |
|את חיוביהן שאינם שנויים במחלוקת על-ידי אימוץ                      |
|מכשיר עונשי המקובל  בארצות חוץ. כשם שסעיף 25                      |

|לחוק שולל את זכאות ؀ࠂࠒࠔࠖࠤהמבוטח הנוהג במרמה, כן                         |
|ראוי שיכלול החוק הוראה עונשית למקרה של הפרת                             |
|חובות תום-הלב של המבטח. היות והוראות) סעיף 28                           |
|אינן מעמידות את המבוטח במצב בו היה עומד אלמלא                           |
|הופרה חובת המבטח, קיים צורך להעניק לבית-המשפט                           |
|כוח להגדיל את פיצויי המבוטח, ותוספת של 30%                              |
|נראית מאיימת דיה.                                                       |
|חבר הכנסת: מרדכי וירשובסקי                                              |

|1 ס"ח התשמ"א, עמ' 94; התשמ"ד, עמ' 72.         |
