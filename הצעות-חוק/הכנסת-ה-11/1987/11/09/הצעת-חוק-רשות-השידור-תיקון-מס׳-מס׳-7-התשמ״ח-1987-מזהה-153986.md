|19 א. (א), ראה הועד המנהל כי בשל שיבוש חמור של יחסי העבודה                                      |"הפסקת שידורים      |                     |
|ברשות או בשל ליקוי חמור בניהולה של הרשות, נבצר מאת הרשות                                        |                    |                     |
|להמשיך ולקיים באופן סדיר את שידורי הרדיו או את שידורי הטלויזיה,                                 |                    |                     |
|רשאי הוא, באישור השר, להורות על הפסקת שידורי הרדיו או הטלויזיה                                  |                    |                     |
|או על צמצומם, או על הפסקה או צמצום של פעולות אחרות של הרשות ;                                   |                    |                     |
|הודעה על כך תפורסם ברשומות.                                                                     |                    |                     |
|(ב) הוראה לפי סעיף קטן (א) תעמוד בתקפה לתקופה שלא                                               |                    |                     |
|תעלה על תשעים ימים, וניתן, בהסכמת ועדת החינוך והתרבות של                                        |                    |                     |
|הכנסת, להאריכה לתקופות נוספות של תשעים ימים כל אחת; הודעה                                       |                    |                     |
|על הארכה כאמור תפורסם ברשומות.                                                                  |                    |                     |
|(ג) נתן הועד המנהל הוראה לפי סעיף קטן (א), רשאי הוא,                                            |                    |                     |
|באישור השר, להטיל על אדם שהסכים לכך, שיקיים מטעם הרשות,                                         |                    |                     |
|שידורי רדיו או שידורי טלויזיה או יבצע פעולות אחרות של הרשות,                                    |                    |                     |
|הכל כפי שיורה הועד המנהל ולפי הסדרים ותנאים שיקבע, ובלבד                                        |                    |                     |
|שהוראות החוק החלות על שידורי הרשות יחולו על השידורים מטעמה                                      |                    |                     |
|לפי סעיף זה, בשינויים ובתיאומים הנדרשים.                                                        |                    |                     |
|(ל) הוראות סעיף זה אינן באות לגרוע מסמכויות שנקבעו                                              |                    |                     |
|בחוק זד. או על פיו."                                                                            |                    |                     |

|דברי הסבר                  |

|מאז חקיקת חוק רשות השידור, והקמתה של-                             |
|רשות השידור בשנת 1965 חולפו עשרים ושלוש שנים.                     |
|בבואה להקים את רשות השידור בחוק- מיוחד, לא                        |
|נתנה הכנסת את דעתה ؀ࠂࠒࠔࠖࠤלאפשרות הפסקה או צמצומים                 |
|של השידורים או חלק מהם או של פעולות אחרות של                      |
|הרשות. מצב משפטי זה קיים גם בחוקים דומים                          |
|במדינות המערב בהן פועלות רשויות שידור                             |
|סטטוטוריות ממלכתיות. לאור הנסיון שהצטבר                           |
|לאחרונה ברשות השידור, ולאחר שהיועץ המשפטי                         |
|לממשלה קבע, כי בהעדר הסדר מפורש בחוק לא ניתן                      |
|להפסיק או לצמצם את שידורי הרשות, מוצע בזה                         |
|לשנות את המצב המשפטי הקיים ולקבוע הסדר ברור                       |
|ומפורט בסוגיה.                                                    |

|התיקון המוצע בא לתת סמבות לוועד המנהל של                               |
|רשות השידור, באישור השר הממונה עלי ביצוע ח1וק                          |
|רשות השידור, התשכ"ה-1965, להפסיק שידורים או                            |
|לצמצמם במקרה שיווצרו התנאים הקבועים בחוק                               |
|המצדיקים נקיטתם של אמצעים אלה.                                         |
|? התיקון המוצע גם מסמיך את הועד המנהל, ?                               |
|באישור השר, לפעול לקיומם, של שידורים מטעם                              |
|הרשות באמצעות גורמים מחוצה לה, והכל בכפוף                              |
|להוראות חוק רשות השידור החלות על שידורי                                |
|הרשות.                                                                 |
