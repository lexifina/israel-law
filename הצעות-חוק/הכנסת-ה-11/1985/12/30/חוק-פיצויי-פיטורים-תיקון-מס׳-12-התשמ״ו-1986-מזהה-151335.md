|יבוא:                                                                                                                    |סעיף 13א      |
|13א. נעשה הסכם קיבוצי במטרה למבוע פיטורי עובדים במקום העבודה                                  |"חישוב הפיצויים           |              |
|או לצמצמם ונקבע בו כי שכרם של העובדים יופחת זמנית לעומת                                       |כשחשכה הופחת              |              |
|השכר שהיו זכאים לו אילולא אותו הסכם, ועובד זכאי לפי חוק זה                                    |זמנית                     |              |
|לפיצויי פיטורים שחישובם מבוסס על השכר שהופחת על פי הסכם                                       |                          |              |
|כאמור, יראו אותו עובד לענין חישוב הפיצויים, כאילו שכרו לא                                     |                          |              |
|הופחת; לענין זה, "הסכם קיבוצי" - לרבות הסדר קיבוצי,"                                          |                          |              |
|2. (א) בסעיף זה -                                                                                                        |הוראת שעה     |
|"התקופה הקובעת" - התקופה שבין ו' בחשון התשמ"ה (1 בנובמבר 1984) לבין כ'                                                   |              |
|באדר ב' התשמ"ו (31 במרס 1986);                                                                                           |              |
|"עובד זכאי" -                                                                                                            |              |
|(1) עובד שיחסי העבודה בינו לבין מעבידו נפסקו בתקופה הקובעת;                                                              |              |
|(2) עובד שיחסי העבודה בינו לבין מעבידו נפסקו לפני התקופה הקובעת, אם                                                      |              |
|זכותו לפיצויי פיטורים מותנית על פי חיקוק במילוי תנאי מצדו לאחר יום                                                       |              |
|הפסקת יחסי עובד ומעביד או במילוי תנאי במשך תקופה מסויימת שלאחר אותו                                                      |              |
|יום, והתנאי נתמלא או שהתקופה נסתיימה בתקופה הקובעת;                                                                      |              |
|(3) חליפו של עובד כאמור בפסקאות (1) ו- (2).                                                                              |              |
|(ב) עובד זכאי שהשכר ששימש בסיס לחישוב פיצויי' הפיטורים שהגיעו לו לפי                                                     |              |
|החוק העיקרי כלל תוספת יוקר או פיצוי התייקרות שחלו בתקופה הקובעת, זכאי לקבל                                               |              |
|ממעבידו תוספת לפיצויי הפיטורים בשיעור המפורט בתוספת.                                                                     |              |
|(ג) שולמה לעובדים תוספת יוקר לגבי התקופה שלאחר פרסומו של חוק זה,                                                         |              |
|רשאי שר העבודה והרווחה להקטין בצו את השיעורים שבתוספת המתייחסים לאותה                                                    |              |
|תקופה, במידה המתחייבת, לדעתו, מתשלום תוספת היוקר כאמור.                                                                  |              |
|(ד) סכום התוספת לפיצויי הפיטורים כאמור בסעיף קטן (א) יופחת באותה                                                         |              |
|מידה שפיצויי הפיטורים ששולמו לעובד עלו על סכום הפיצויים המגיע לו על פי החוק                                              |              |
|העיקרי.                                                                                                                  |              |
