|2. (א) בחירת המבקר תיערך לא מוקדם מתשעים ימים ולזג יאוחר                                    |מועד הבחירה          |                     |

|מקומו של המבקר לפני תום תקופת כהונתו, תיערך הבחירה תוך                                      |                     |                     |
|ארבעים וחמישה ימים מהיום שבו נתפנה מקומו.                                                   |                     |                     |

|הבחירה ויודיע עליו בכתב לכל חברי הכנסת לפחות עשרים ימים לפני                                |                     |                     |
|יום הבחירה.                                                                                 |                     |                     |
|(ג) הל מועד הבחירה שלא בזמן אחד הכנסים של הכנסת, יכנס                                       |                     |                     |
