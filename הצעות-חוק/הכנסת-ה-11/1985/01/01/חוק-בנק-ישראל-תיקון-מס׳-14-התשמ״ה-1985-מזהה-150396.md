|חוק בנק ישראל (תיקון מס' 14), התשמ"ה-1985                                    |

|החלפת ס.עיף 32    |1. במקום סעיף 32 לחוק בנק ישראל, התשי"ד-1954 1, יבוא:                                                            |
|                  |32. (א) הנגיד רשאי, באישור הממשלה וועדת הכספים של הכנסת,                                      |"ביטול שטר        |
|                  |להורות בצו כי מטבע בסכום הנקוב בשטר כסף או במעה המצויינים                                     |כסף או מעה        |
|                  |בצו לא יהיה הילך חוקי בישראל.                                                                 |                  |
|                  |(ב) המוסר שטר כסף או מעה שבוטלו כאמור בסעיף קטן (א)                                           |                  |
|                  |לבנק ישראל תוך תקופה שתיקבע בצו יהיה זכאי לקבל תמורתם, ללא                                    |                  |
|                  |עמלה, הילד חוקי שווה ערך.                                                                     |                  |
|                  |(ג) הורה הנגיד כאמור בסעיף קטן (א) -                                                          |                  |
|                  |(1) כל אימת שיש לשלם סכום שלא ניתן לשלמו אלא                                                  |                  |
|                  |בשימוש בשטר כסף או במעה שבוטלו, יעוגל אותו סכום                                               |                  |
|                  |לסכום הקרוב שניתן לשלמו בהליך חוקי; סכום שהוא מחצית                                           |                  |
|                  |שטר הכסף או המעה הקרובים שהם הילד חוקי יעוגלו כלפי                                            |                  |
|                  |מעלה;                                                                                         |                  |
|                  |(2) כל אימת שיש לשלם או לרשום סכום שלא ניתן לשלמו                                             |                  |
|                  |או לרשמו אלא בשימוש בשטר כסף או במעה שבוטלו רשאי                                              |                  |
|                  |המשלם או הרושם לעגלו ؀ࠂࠐࠒࠔכאמור בפסקה (1)."                                                   |                  |

|דברי הסבר                  |

|החוק המוצע בא לשנות את הוראת סעיף 32 שלפיו                          |
|רשאי נגיד בנק ישראל, באישור הממשלה וועדת                            |
|הכספים של הכנסת, להורות ששטר כסף או מעה                             |
|שיפורטו בצו יוצאו מהמחזור ולא יהיו עוד הילך                         |
|חוקי. השינוי יאפשר להורות למשל, שמעה בסכום                          |
|של אגורה חדשת אחת לא תהיה הילך חוקי.                                |

|כמו כן, מוצע לקבוע הוראה בדבר עיגול סכום                         |
|שיש לשלם או לרשום. ההוראה מתייחסת גם לענין                       |
|הרישום, מכיון שהמחשב המצוי אינו יכול להכיל עוד                   |
|את כל הספרות של הסכום שיש לרשמו,                                 |

|1 ס"ח התשי"ד, עמ' 192.             |
