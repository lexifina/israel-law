|1. (א) בתקופה שמיום י"ד בשבט התשמ"ה (5 בפברואר 1985) עד יום ט"ו בתשרי                                             |תחולה               |
|התשמ"ו (30 בספטמבר 1985) יחול חוק זה על כל המצרכים והשירותים או סוגי מצרכים                                       |                    |
|ושירותים או על מצרכים ושירותים מסויימים, הכל כפי שיקבעו בצו שר התעשיה והמסחר                                      |                    |
|ושר האוצר (להלן - השרים); השרים רשאים לקבוע כי תחולתו של חוק זה תסתיים במועד                                      |                    |
|מוקדם יותר, ובלבד שלא יקדם מיום ט"ו בתמוז התשמ"ה (4 ביולי 1985).                                                  |                    |
|(ב) מצרך או שירות שחוק זה הוחל עליו לפי סעיף קטן (א), לא יחולו לגביו                                              |                    |
|באותה תקופה הוראות פרק שני 1 לחוק הפיקוח על מצרכים ושירותים, התשי"ח-1957 1                                        |                    |
|(להלן - חוק הפיקוח) והוראות כל דין אחר בדבר קביעת מחיר ושינוי מחיר.                                               |                    |
|(ג) על אף האמור בסעיפים קטנים (א) ו- (ב), אם נקבע למצרך או לשירות                                                 |                    |
|מחיר מרבי או שכר מרבי לפי סעיף 6 לחוק הפיקוח, לא יחול חוק זה על אותו מצרך                                         |                    |
|או שירות ואולם העלאת מחירו לפי הסעיף האמור בתקופת תקפו של חוק זה טעונת                                            |                    |
|הסכמת שר התעשיה והמסחר ישר האוצר.                                                                                 |                    |
|2. (א) לא ימכור אדם במהלך עסקו מצרך שחוק זה חל עליו ולא יעשה במהלך                                                |איסור העלאת         |
|עסקו שירות שחוק זה חל עליו, במחיר העולה. על הסכום בשקלים שבו מכר את המצרך                                         |מחיר                |
|או עשה את השירות, כדין, לאחרונה במועד הקובע (להלן - המחיר הקובע); הותרה                                           |                    |
|העלאה במחירו של המצרך או השירות לפי תקנה 8 לתקנות שעת חירום (יציבות מחירים                                        |                    |
|במצרכים ובשירותים) (מס' 2), התשמ"ה--1984 2, יהיה המחיר הקובע המחיר שהותר                                          |                    |
|כאמור.                                                                                                            |                    |
|(ב) היה מקובל במועד הקובע מתן הנחה במקרים מסויימים ממחיר מצרך או                                                  |                    |
|שירות, דרך כלל או בתנאים מסויימים, לא ימכור אדם מצרך ולא יעשה שירות, באותם                                        |                    |
|מקרים, במחיר העולה על המחיר לאחר מתן ההנחה כאמור; הוראה זו לא תחול על                                             |                    |
|מכירה מיוחדת.                                                                                                     |                    |

|בדבר הקפאת המחירים לתקופות קצובות ומתן היתרים                      |
|מעת לעת להעלאת מחירים בשיעור קצוב לכל המצר-                        |
|כים והשירותים. לפיכך יש צורך בחוק מיוחד שיחול                      |
|בתקופת ההסכם.                                                      |
|מוצע להסמיך את שר התעשיה והמסחר יחד עם                             |
|שר האוצר לקבוע את המצרכים והשירותים עליהם                          |
|יחולו החוק ולקבוע את שיעור ההעלאה של אותם                          |
|מצרכים ושירותים מעת לעת.                                           |
|על המצרכים והשירותים שייקבעו בצו כאמור                             |
|יחולו הוראותיו של חוק זה בלבד.                                     |
|בהתאם למוצע יהיה אסור לאדם למכור. במהלך                            |
|עסקו מצרך או לעשות שירות במחיר העולה על המחיר                      |
