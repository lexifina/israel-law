|מתפרסמת בזה הצעת חוק מטעם הממשלה:                    |

|חוק יד יצחק בן-צבי (תיקון), תשל"א-1970                                    |

|1, אחרי סעיף 8 לחוק יד יצחק בן-צבי, תשכ"ט-1969  1 (להלן - החוק העיקרי), יבוא:                              |הוספת סעיף 8א       |
|8א, (א) התקן לעובדי יד יצחק בן-צבי ותפקידם יהיו כשל עובדי                             |"קבלה עובדים        |                    |
|המדינה, בשינויים ובתיאומים שיקבע ראש הממשלה על פי המלצת הועד                          |ותנאי עבודתם        |                    |
|המנהל ולאחר התייעצות עם שר האוצר.                                                     |                    |                    |
|(ב) יד יצחק בן-צבי תקבל או תמנה את עובדיה בדרך הקבועה                                 |                    |                    |
|לעובדי המדינה, בתיאומים שייקבעו בתקנות.                                               |                    |                    |
|(ג) השכר, הגמלאות ותנאי העבודה האחרים של עובדי יד יצחק                                |                    |                    |
|בן-צבי יהיו כשל עובדי המדינה, ובלבד שראש הממשלה רשאי, על פי                           |                    |                    |
|המלצת הועד המנהל ולאחר התייעצות עם שר האוצר, לקבוע שינויים                            |                    |                    |
|ותיאומים שייראו לו דרושים להתאמת ההוראות החלות על עובדי המדינה                        |                    |                    |
|למבנה של יד יצחק בן-צבי.                                                              |                    |                    |
|(ד) אין האמור בסעיף זה בא לגרוע מסמכות יד יצחק בן-צבי                                 |                    |                    |
|לחתום על חוזים מיוחדים؀ࠂࠒࠔࠖࠤ עם עובדים המועסקים בתפקידים זמניים,                      |                    |                    |
|לתקופות או למשימות ובתנאים שקבע ראש הממשלה על פי הצעת הועד                            |                    |                    |
|המנהל לאחר התייעצות עם שר האוצר."                                                     |                    |                    |
|2. חוק זה יחול מיום תחילתו גם על עובדי יד יצחק בן-צבי שנתקבלו לעבודה לפני                                  |תחילה               |
|תחילתו.                                                                                                    |                    |
