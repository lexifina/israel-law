|מתפרסמת בזה הצעת חוק מטעם חבר הכנסת;                                                                           |
|חוק לימוד חובה (תיקון מס' 9), תשל"ב-1972                                                                       |

|1. בחוק לימוד חובה, תש"ט-1949  1(להלן - החוק העיקרי), אחרי סעיף 4 יבוא:                                   |הוספת סעיף /א       |
|4א. (א) השר או מי שהוסמך מטעמו, או רשות חינוך מקומית, רשאים                              |"חובת בדיקה      |                    |
|להורות כי ילד או נער בגיל לימוד חובה יעבור בדיקות רפואיות או                             |                 |                    |
|בדיקות אחרות, כדי לקבוע התאמתו או כשרו ללמוד במוסד חינוך מוכר                            |                 |                    |
|מסויים; ניתנה הוראה כאמור, תחול על הילד או הנער ועל כל אחד                               |                 |                    |
|מהוריו החובה לאפשר את הבדיקות האמורות, ואם סירבו להישמע                                  |                 |                    |
|להוראה, דינו של כל אחד מההורים - מאסר חודש ימים, זולת אם הוכיח                           |                 |                    |
|מעל לכל ספק סביר שעשה כמיטב יכלתו כדי שהילד או הנער יעבור                                |                 |                    |
|את הבדיקה האמורה.                                                                        |                 |                    |
|(ב) על אף האמור בסעיף קטן (א), לא יישלח ילד או נער לבדיקה                                |                 |                    |
|האמורה אלא לאחר שמנהל מוסד החינוך שבו לומד הילד התייעץ עם                                |                 |                    |
|מומחה או רופא מתוך רשימה שקבע השר.                                                       |                 |                    |
|(ג) ניתנה הוראה לבדיקה כאמור בסעיף קטן (א), רשאי כל אחד                                  |                 |                    |
|מההורים, תוך 21 יום מיום שקיבל הודעה בכתב על חובת הבדיקה,                                |                 |                    |
|לערר על ההוראה לפני ועדת עררים, ואין ערעור על החלטתה; השר                                |                 |                    |
|רשאי לקבוע בתקנות את הרכב ועדת העררים, ואת דרכי פעולתה.                                  |                 |                    |
|(ד) הועבר הילד או הנער ממוסד ؀ࠂࠊࠌחינוך מוכר למוסד חינוך מוכר                             |                 |                    |
|אחר, חייב כל אחד מההורים של הילד או של הנער לדאוג לכך שהילד                              |                 |                    |
|או הנער יבקר באופן סדיר במוסד החינוך שאליו הועבר, והאמור בסעיף                           |                 |                    |
|4 יחול על כל אחד מההורים בשינויים המחוייבים."                                            |                 |                    |
|2. בסעיף 5(ב) לחוק העיקרי, אחרי פסקה (2) יבוא:                                                            |תיקון סעיף 5        |
|"(3) מי שניתנה עליו הוראת פטור לפי סעיף זה, לא יחולו                                                      |                    |
|לגביו הוראות סעיפים 6, 7 ו- 10 אלא בכפוף לתנאים ול-                                                       |                    |
|סייגים שבהוראות הפטור, ובלבד שתישמר בה חובה לספק                                                          |                    |
|לילד או לנער לימודים במסגרת שקבע השר בכל מקרה                                                             |                    |
|שהילד או הנער מסוגל לכך."                                                                                 |                    |
