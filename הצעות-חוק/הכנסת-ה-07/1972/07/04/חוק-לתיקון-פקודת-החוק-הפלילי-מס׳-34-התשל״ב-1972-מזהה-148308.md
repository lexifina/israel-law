|66א. (א) המחזיק נשק ואין בידו להוכיח רשות חוקית להחזקתו, דינו -                      |"החזקת נשק לא      |                   |
|מאסר שבע שנים.                                                                       |חוקי או נשיאתו     |                   |
|(ב) הנושא נשק ואין בידו להוכיח רשות חוקית לנשיאתו, דינו -                            |                   |                   |
|מאסר עשר שנים.                                                                       |                   |                   |
|(ג) בסעיף זה, "נשק" - כלי יריה, כמשמעותו בחוק כלי היריה,                             |                   |                   |
|תש"ט-21949, תחמושת, פצצה, רימון או כל חפץ נפיץ אחר או חלק                            |                   |                   |
|של אחד מאלה.                                                                         |                   |                   |
|(ד) מקום שנמצא בו נשק, רואים את מחזיק המקום כמחזיק הנשק,                             |                   |                   |
|כל עוד לא הוכח היפוכו של דבר.                                                        |                   |                   |
|(ה) תעודה החתומה בידי קצין משטרה בדרגת מפקח ומעלה                                    |                   |                   |
|והיא מאשרת שחפץ פלוני הוא נשק, תשמש ראיה לדבר, כל עוד                                |                   |                   |
|לא הוכח היפוכו; אולם הנאשם זכאי להזמין את חותם התעודה לחקירה,                        |                   |                   |
|ואם עשה כן, לא תשמש התעודה ראיה אלא אם חותם התעודה נענה                              |                   |                   |
