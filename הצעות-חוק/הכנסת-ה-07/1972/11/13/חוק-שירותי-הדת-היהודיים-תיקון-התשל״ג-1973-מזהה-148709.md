|חוק שירותי הדת היהודיים (תיקון), תשל"ג-1972                                    |

|הוספת סעיף 10א    |1, אחרי סעיף 10 לחוק שירותי הדת היהודיים ננוסח משולב], תשל"א-1971 1, יבוא:                                |
|                  |10א. (א) כל אימת שנראה לשר הדתות שמועצה לא מילאה חובה או                             |"מועצה שאיבה        |
|                  |לא ביצעה עבודה שהיא נדרשת או מוסמכת לעשות לפי חוק זה, רשאי                           |ממלאה חובה          |
|                  |הוא לדרוש ממנה בצו למלא את החובה או לבצע את העבודה תוך זמן                           |                    |
|                  |הנקוב בצו.                                                                           |                    |
|                  |(ב) לא מילאה המועצה אחרי הצו תוך הזמן האמור, רשאי שר                                 |                    |
|                  |הדתות למנות אדם הנראה לו מתאים מקרב עובדי המדינה, שימלא את                           |                    |
|                  |החובה או יבצע את העבודה, ובלבד שהשכר וההוצאות הכרוכות בכך יהיו                       |                    |
|                  |במסגרת התקציב המאושר של המועצה."                                                     |                    |

|דברי הסבר                |

|מוצע לתת סמכות לשר הדתות ביחס למועצות הד-                    |
|תיות כסמכות שניתנה לכל ממונה על מחוז ביחס לכל                |
|מועצה מקומית שבמחוזו. וזו לשונו של סעיף 36 לפקודת            |
|המועצות המקומיות:                                            |
|"מועצה המסרבת למלא חובה ؀ࠂࠐࠒࠔמסויימת                         |
|36. (א) כל אימת שנראה לממונה שמועצה מקומית לא                |
|מילאה חובה או לא ביצעה עבודה שהיא נדרשת או                   |
|מוסמכת לעשות/ לפי הפקודה או לפי צו הכינון או לסי             |
|כל דין אחר, רשאי הוא לדרוש ממנה בצו למלא החובה               |
|או לבצע העבודה תוך זמן הנקוב בצו.                            |

|(ב) לא מילאה המועצה אחרי הצו תוך הזמן האמור,                 |
|רשאי הממונה למנות אדם הנראה לו מתאים, שימלא את               |
|החובה או יבצע את העבודה, ורשאי הוא לקבוע את                  |
|שכרו ולהורות שהשכר וההוצאות למילוי החובה או                  |
|לביצוע העבודה יהיו על קופת המועצה."                          |
|התיקון המוצע בא להבטיח ששירותי דת יסופקו                     |
|בצורה סדירה ותקינה גם כאשר המועצה הדתית אינה                 |
|ממלאה את חובותיה כראוי' מחמת סכסוכים פנימיים או              |
|מסיבות אחרות.                                                |

|1 ס"ח תשל"א, עמ' 130.    |
