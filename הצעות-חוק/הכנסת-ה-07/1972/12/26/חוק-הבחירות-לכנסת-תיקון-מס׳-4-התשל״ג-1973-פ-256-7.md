|1. בסעיף 81 לחוק הבחירות לכנסת ננוסח משולב], תשכ"ט-1969 -                                                   |תיקון סעיף 81      |
|(1) במקום סעיף קטן (כ) יבוא:                                                                                |                   |
|"(ב) לשם חלוקת המנדטים יחולק המספר הכללי של הקולות                                                          |                   |
|הכשרים של כל הרשימות המשתתפות בחלוקת המנדטים למספר חברי                                                     |                   |
|הכנסת נוסף אחד, דהיינו ל-121, והמספר השלם היוצא מן החילוק בהש-                                              |                   |
|מטת השברים יהיה "המודד הכללי".";                                                                            |                   |
|(2) במקום סעיף קטן (ג) יבוא:                                                                                |                   |
|"(ג) כל רשימה המשתתפת בחלוקת המנדטים תזכה במספר המנ-                                                        |                   |
|דטים היוצא מחילוק מספר קולותיה הכשרים במודד הכללי.";                                                        |                   |
|(3) במקום סעיף קטן (ד) יבוא;                                                                                |                   |
|"(ד) המנדטים שנותרו אחרי חלוקת המנדטים לפי סעיף קטן (ג)                                                     |                   |
|יחולקו בין הרשימות המשתתפות בחלוקת המנדטים באופן זה:                                                        |                   |
|(1) לכל רשימה ייקבע "מודד הרשימה" על ידי חילוק                                                              |                   |
|מספר קולותיה הכשרים למספר המנדטים שקיבלה לפי סעיף                                                           |                   |
|קטן (ג) נוסף אחד;                                                                                           |                   |
|(2) הרשימה שקיבלה את מודד הרשימה הגדול ביותר                                                                |                   |
|תזכה במנדט נוסף;                                                                                            |                   |
|(3) היו לשתי רשימות או יותר, אחרי השמטת השברים,                                                             |                   |
|מודדים שווים, תכריע הגרלה שתערוך הועדה המרכזית,                                                             |                   |
|איזו מהן תזכה במנדט נוסף;                                                                                   |                   |
|(4) החלוקה תימשך לפי הוראות פסקאות (1), (2) ו-(3)                                                           |                   |
|עד תום כל המנדטים, בתנאי שרשימה שזכתה במנדט נוסף                                                            |                   |
|לפי פסקאות (2) או (3) ייקבע לה מודד רשימה חדש בהתחשב                                                        |                   |
|עם המנדט הנוסף הזה."                                                                                        |                   |

|דברי הסבר            |

|לפי החוק הקיים מתחלקים, החל משנת 1951, המנ-                 |
|דטים הנוספים מעל לאלה שניתנו לרשימות שעברו את               |
|אחוז החסימה בהתאם למודד ؀ࠂࠒࠔࠖࠤהשלם לפי גודל העודפים.        |
|שיטה זו של חלוקת המנדטים העודפים איננה צודקת. כך            |
|"שילמה" בבחירות לכנסת השביעית רשימה אחת 8196                |
|קולות בעד כל מנדט שקיבלה בשעה שרשימת אחרת                   |
|"שילמה" בעד כל מנדט שלה 14023 קולות. לפי שיטת               |
|חלוקת העודפים המוצעת' שיטת האגנבאך-בישוף ושיטת              |
|ד' הונט, מתחלקים המנדטים העודפים לפי שיטת הממו-             |

|צע המשותף הגבוה ביותר. לפי שיטה זאת "התשלום" של               |
|קולות בעד כל מנדט הוא השווה ביותר והצודק ביותר                |
|הניתן.                                                        |
|תוצאות חלוקת המנדטים על פי שיטת האגנבאך-                      |
|בישוף זהה עם תוצאות חלוקת המנדטים מאת ד'הונט;                 |
|היא נתקבלה בחוק הבחירות לאסיפה המכוננת (הכנסת                 |
|הראשונה) ונחשבת בעולם כצודקת ביותר בבחירות                    |
|שבהן מספר המנדטים העומד לחלוקה הוא רב.                        |
|חברי הכנסת : יוחנן בדר ואברהם עופר                            |
