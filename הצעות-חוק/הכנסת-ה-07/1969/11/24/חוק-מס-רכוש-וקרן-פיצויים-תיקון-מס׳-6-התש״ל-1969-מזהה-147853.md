|1. בחוק מס רכוש וקרן פיצויים, תשכ"א-1961 1, אחרי סעיף 46ב יבוא:                                                  |הוספת סעיף 46ג      |
|46ג. (א) שר האוצר, באישור ועדת הכספים של הכנסת, רשאי לקבוע                                   |"ביטוח נכסים       |                    |
|בתקנות, כי הוראות חוק זה, כולן או מקצתן, יחולו גם על סוגים מסויימים                          |מחוץ לשטח          |                    |
|של מקרקעין, מלאי או ציוד הנמצאים מחוץ לשטח המדינה, בין בדרך                                  |המדינה             |                    |
|כלל ובין כשהם בבעלותם של סוגי בני אדם מסויימים, הכל כפי שנקבע                                |                   |                    |
|כאמור.                                                                                       |                   |                    |
|(ב) בתקנות לפי סעיף קטן (א) ייקבעו גם פרטים אלה:                                             |                   |                    |
|(1) שיעור המס, ובלבד שלא יעלה על 40% מהמס שהיה                                               |                   |                    |
|משתלם אילו היו המקרקעין, המלאי או הציוד נמצאים בשטח                                          |                   |                    |
|המדינה;                                                                                      |                   |                    |
|(2) סוגי הנזק שבעדם ישולמו פיצויים לבעלי המקרקעין,                                           |                   |                    |
|המלאי או הציוד ושיעורי הפיצויים."                                                            |                   |                    |
