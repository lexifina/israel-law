|"רשות מקומית" - עיריה או מועצה מקומית, למעט מועצה אזורית;                                                |                  |
|"ראש רשות" - ראש רשות מקומית;                                                                            |                  |

|2 . ראש רשות ייבחר בבחירות אישיות, כלליות, ישירות, שוות וחשאיות.                                         |שיטת הבחירות      |
|3 . הבחירות לראש רשות יתקיימו ביום הבחירות למועצה ותקופת כהונתו תהא כתקופת                               |מועד הבחירות      |
|כהונתה של המועצה.                                                                                        |ותקופת הכהונה     |

|(ב) מי שזכאי להיכלל ברשימת מועמדים ולהיבחר חבר המועצה זכאי גם להיות                                      |ולהיבחר           |
|מועמד ולהיבחר ראש הרשות, ומי שפסול לכהן כחבר המועצה פסול גם לכהן כראש                                    |                  |
|הרשות.                                                                                                   |                  |
|5. כל קבוצת בוחרים המונה 250 איש, או חמישה אחוזים ממספר הבוחרים שבפנקס                                   |הצעת מועמדים      |

|מועמדות אלא בצירוף הסכמתו בכתב של המועמד.                                                                |                  |

|המועמדים למועצה.                                                                                         |                  |
|7. (א) סדרי הבחירות למועצה, לרבות ועדת הבחירות, פקיד הבחירות, פנקס הבוחרים,                              |ארגון הבחירות     |
|ועדות הקלפי, תחנות הקלפי, ספירת הקולות ופרסום תוצאות הבחירות, שנקבעו, הוקמו                              |                  |
|או נתמנו לצורך הבחירות למועצה יחולו וישמשו גם לצורך הבחירות לראש הרשות.                                  |                  |
|(ב) ההצבעה בבחירות לראש רשות תהיה לפני אותה ועדת קלפי שלפניה מצביעים                                     |                  |
|בבחירות למועצה, אולם תיעשה במעטפות נפרדות, שצבען שונה מאלה שמשתמשים בהן                                  |                  |
|בבחירות למועצה, וכן בקלפי נפרדת? מעטפה של הבחירות לראש הרשות שנמצאה בקלפי                                |                  |
|של הבחירות למועצה, או להיפך - הקול שבה לא ייפסל בשל כך בלבד; פתקי ההצבעה                                 |                  |
|ישאו את שמו של המועמד ושם משפחתו, ותו לא.                                                                |                  |

|הבחירות למועצה לבחירות לראש רשות,                                                                        |                  |
