|1. בסעיף 1 לחוק שירות עבודה בשעת-חירום, תשכ"ז-1967  1 (להלן - החוק העיקרי)-                                   |תיקון סעיף 1         |
|(1) במקום הגדרת "מפעל" יבוא:                                                                                  |                     |
|""מפעל" - אחד מאלה;                                                                                           |                     |
|(1) כל מפעל של תועלת ציבורית, כל עסק של תעשיה,                                                                |                     |
|מסחר, תחבורה או חקלאות וכל מוסד חינוך, בין שהוא קיים                                                          |                     |
|ובין שהוא עתיד לקום;                                                                                          |                     |
|(2) עבודה מטעם המדינה או רשויותיה או רשות מקומית,                                                             |                     |
|לרבות עבודות ביצורים או בניית מקלטים;                                                                         |                     |
|(3) שירותים בין מטעם המדינה או רשויותיה או רשות                                                               |                     |
|מקומית ובין שלא מטעמן;"                                                                                       |                     |
|(2) בהגדרת "מפעל חיוני" בסופו יבוא "וכן כל מפעל או חלק ממנו שאפשר                                             |                     |
|להפעילו לצרכי קיום המשק ושפעולתו חיונית לקיום הספקה או שירותים                                                |                     |
|הדרושים לציבור או ליצוא, ושר העבודה, בהתייעצות עם שר המסחר                                                    |                     |
|והתעשיה, אישר אותו לענין זה".                                                                                 |                     |
|2. בסעיף 3 לחוק העיקרי -                                                                                      |תיקון סעיף 3         |
|(1) בסעיף קטן (א) -                                                                                           |                     |
|נא) ברישה, אחרי "תושב קבוע" יבוא "- למעט חייל, שוטר, וכן אשה                                                  |                     |

|דברי הסבר              |

|הגדרת "מפעל" בסעיף 1 לחוק העיקרי                |סעיף 1        |
|אומרת: "כל מפעל של תועלת ציבורית                |              |
|וכל מיזם או עסק של תעשיה, מסחר, תחבורה או חק-                  |
|לאות, בין שהוא קיים ובין שהוא עתיד לקום, ועבודה                |
|ושירותים מטעם המדינה או רשויותיה או רשות מקומית,               |
|לרבות עבודות ביצורים".                                         |
|להבטחת קיומו והפעלתו של החלק החיוני למשק                       |
|המדינה בשעת חירום, כגון מפעלי תשתית חשובים או                  |
|ענפי יצוא חיוניים, מוצע -                                      |
|(א) להרחיב את הגדרת מפעל, שתכלול גם מוסדות                     |
|חינוך ובניית מקלטים, ולהרחיב את המונח "שירותים"                |
|שיכלול גם שירותים שאינם מטעם המדינה או מטעם רשות               |
|מקומית. מפעל כאמור, שנהרס או נפגע בפעולת מלחמה                 |
|ויש הכרח חיוני לשקמו באותה שעה, יש לאפשר הצבת                  |
|כוח אדם מתאים לביצוע פעולה זו.                                 |

|(ב) להרחיב את הגדרת "מפעל חיוני" ולכלול בו                   |
|גם מפעל הדרוש לקיום המשק ושפעולתו חיונית לקיום               |
|הספקה או שירותים לציבור או ליצוא.                            |
|(א) לפי סעיף 3 לחוק חייבים בשירות עבודה         |            |
|בני 17 עד 65 בגבר, ובנות 18 עד 60 באשה.         |            |
|מוצע להרחיב את הגילים כדי 16 עד 65 בגבר ו-16                 |
|؀ࠂࠒࠔ࠘ࠢࠤࠦ࠴࠶עד 60 באשה. למעשה עוסקים בני גילים אלה כיום        |
|בשעת חירום רגילה בביצוע עבודות משק שונות ומן                 |
|הדין שיינתן לגייס אותם בעת הצורך לשירות עבודה.               |
|(ב) בסעיף 3 לחוק נקבע, כי חייב בשירות עבודה                  |
|כל מי שהוא תושב ובן אחד הגילים האמורים לעיל, אולם            |
|פטורים משירות העבודה חיילים, שוטרים, נשים בהריון             |
|וסוגי אנשים ששר העבודה קבע בתקנות.                           |
