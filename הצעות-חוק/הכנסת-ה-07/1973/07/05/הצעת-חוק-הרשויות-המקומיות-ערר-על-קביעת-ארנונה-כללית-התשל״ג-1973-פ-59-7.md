|3. מי שחוייב בתשלום ארנונה כללית רשאי להשיג עליה לפני מנהל הארנונה על יסוד                                   |השגה             |
|טענה מטענות אלה:                                                                                             |                 |
|(1) הנכס שבשלו נדרש התשלום אינו מצוי באזור כפי שנקבע בהודעת                                                  |                 |
|התשלום?                                                                                                      |                 |
|(2) נפלה טעות בציון סוג הנכס או גדלו.                                                                        |                 |
|4. (א) מנהל הארנונה ישיב למשיג תוך ששים יום מיום קבלת ההשגה.                                                 |תשובת מנהל       |
|(ב) לא השיב מנהל הארנונה תוך ששים יום - ייחשב הדבר כאילו החליט לקבל                                          |הארנונה          |
|את ההשגה.                                                                                                    |                 |
|5. המועצה תמנה ועדת ערר אחת או יותר, בהרכב של שלושה חברים מבין בעלי הזכות                                    |ועדת ערר         |
|להיבחר כחברי המועצה, ואת היושב ראש שלהן.                                                                     |                 |
|6. (א) הרואה ؀ࠂࠊࠌעצמו מקופח בהחלטה לפי סעיף 4, רשאי, תוך שלושים יום מיום שנמ-                                |ערר              |
|סרה לו ההחלטה, לערור לפני ועדת ערר.                                                                          |                 |
|(ב) עברו ששים יום כאמור בסעיף 4(ב) והיתה למנהל הארנונה סיבה טובה להעדר                                       |                 |
|תשובה, רשאי הוא לפנות לועדת הערר בבקשה לבטל את קבלת ההשגה.                                                   |                 |
