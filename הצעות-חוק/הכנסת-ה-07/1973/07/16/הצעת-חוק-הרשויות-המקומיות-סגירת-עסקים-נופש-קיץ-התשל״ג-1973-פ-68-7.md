|חוק הרשויות המקומיות (סגירת עסקים - נופש קיץ), תשל"ג-1973                                            |

|הגדרות ותחולה      |1. (א) בחוק זה -                                                                                         |
|                   |"עסק קמעוני" -                                                                                           |
|                   |(1) בית מסחר קמעוני, לרבות בית מסחר שעוסקים בו בעסק קמעוני באופן                                         |
|                   |חלקי;                                                                                                    |
|                   |(2) חנות לממכר מזון, למעט מזנון, קיוסק, חלון, אשנב או סידור אחר                                          |
|                   |למכירת אוכל מוכן או משקה לצריכה בו במקום;                                                                |
|                   |(3) עסק למתן שירותים שמספר העובדים בו לרבות בעלים ושותפים אינו                                           |
|                   |עולה על 10;                                                                                              |
|                   |"פתוח" - לרבות עשיית עסק או מלאכה במקום סגור ולרבות אי סגירת מקום כאמור;                                 |
|                   |"יום מנוחה" - כמשמעותו בפקודת סדרי השלטון והמשפט, תש"ח-1948 1.                                           |
|                   |(ב) חוק זה לא יחול על תחנות דלק או חנויות השק"ם.                                                         |
|סגירת עסקים        |2. בתקופה שמיום 1 ביולי עד 31 באוגוסט (להלן - תקופת הנופש) לא יפתח אדם ולא                               |
|                   |ירשה בעל לפתוח עסק קמעוני ביום שלישי בשבוע, למעט ערב יום מנוחה, משעה 14.00                               |
|                   |עד שעה 05.00 למחרתו.                                                                                     |
|סגירה מאוחרת       |3. בתקופת הנופש ؀ࠂࠌࠎמותר לפתוח עסק קמעוני ביום חמישי בשבוע או ביום הקודם לערב                            |
|                   |יום מנוחה עד שעה .21.00                                                                                  |
|עונשין             |4. העובר על הוראות חוק זה, דינו - קנס 5,000 לירות.                                                       |
|קנסות ועבירות      |5. (א) הוראות פקודת העיריות 2 בענין עבירות קנס יחולו על עבירות לפי חוק זה.                               |
|קנם                |(ב) קנסות לפי חוק זה ישולמו לקופת הרשות המקומית שבתחומה נעברה העבירה.                                    |
|ביצוע ותקנות       |6. שר הפנים ממונה על ביצוע חוק זה והוא רשאי להתקין תקנות בכל ענין הנוגע                                  |
|                   |לביצועו.                                                                                                 |
|תחילה              |7. תחילתו של חוק זה תשעים יום אחרי פרסומו ברשומות.                                                       |
