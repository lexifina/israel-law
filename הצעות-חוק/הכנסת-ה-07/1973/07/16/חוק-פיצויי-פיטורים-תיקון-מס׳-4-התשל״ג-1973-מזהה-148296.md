|חוק פיצויי פיטורים (תיקון מס' 3), תשל"ג-1973                          |

|1. בחוק פיצויי פיטורים, תשכ"ג-1963 1, אחרי סעיף 11 יבוא:                                                |הוספת סעיף 11א       |
|11א. המתגייס למשטרת ישראל או לשירות בתי הסוהר, ובסמוך לפני                           |"פיצויים למתגייס  |                     |
|גיוסו היה עובד והתפטר מעבודתו על מנת להתגייס כאמור, יהיו הוא או                      |למשטרה            |                     |
|שאיריו זכאים לפיצויי פיטורים אם נתקיימה בו אחת מאלה;                                 |                  |                     |
|(1) הוא שירת במשטרה או בשירות בתי הסוהר ששה                                          |                  |                     |
|חדשים לפחות;                                                                         |                  |                     |
|(2) שירותו כאמור נפסק מחמת אחת העילות המזכות                                         |                  |                     |
|בפיצויי פיטורים לפי חוק זה;                                                          |                  |                     |
|(3) שירותו כאמור נפסק מחמת שנמצא בלתי מתאים לשי-                                     |                  |                     |
|רות, ובלבד שלא נפסק השירות בנסיבות שלא היו מזכות                                     |                  |                     |
|אותו בפיצויי פרישה מהמשטרה או משירות בתי הסוהר,                                      |                  |                     |
|הכל לפי הענין."                                                                      |                  |                     |
|2. חוק זה יחול רק על מי שהתפטר מעבודתו אחרי תחילת חוק זה.                                               |תחולה                |

|דברי הסבר               |

|תיקון זה בא לעודד את הגיוס למשטרה, לרבות                       |
|משמר-הגבול, ולשירות בתי הסוהר. מוצע לזכות את                   |
|המתגייס בפיצויי פיטורים ממעבידו הקודם, אם שירת                 |
|במשטרה או בשירות בתי הסוהר ששה חדשים לפחות או                  |
|ששירותו נפסק, עוד קודם לכן, מחמת אחת העילות שלפי               |
|חוק פיצויי פיטורים מזכות עובד בפיצויים אף אם הת-               |
|פטר או נמצא בלתי מתאים לשירות.                                 |
|ההוראה לא ؀ࠂࠐࠒࠔתחול לגבי מי ששירותו נפסק בנסיבות               |

|שלא היו מזכות אותו בפיצויי פרישה לפי כללי השירות             |
|במשטרה או בשירות בתי הסוהר, כגון הרשעה בעבירה                |
|פלילית שיש עמה קלון, הרשעה בעבירה חמורה על                   |
|המשמעת, או התנהגות גרועה או מבישה בתקופת השירות.             |
|הוראה דומה בעיקרה לתיקון המוצע קיימת בחוק                    |
|החיילים המשוחררים (החזרה לעבודה), תש"ט-1949,                 |
|לגבי המתחייבים לשירות קבע בצה"ל.                             |

|1ס"ח תשכ"ג, עמ' 136; תשכ"ד, עמ' 176; תשכ"ה,עמ' 215; ה"ת תשל"ג, עמ' 165.            |
