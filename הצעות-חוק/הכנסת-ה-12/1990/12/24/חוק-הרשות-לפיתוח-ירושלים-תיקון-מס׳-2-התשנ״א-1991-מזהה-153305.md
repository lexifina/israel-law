|22ג. (א) למפעל עתיר ידע ולמפעל עתיר טכנולוגיה בירושלים שאושר                          |"הטבות למפעלים    |                        |
|כמפעל מאושר על פי חוק לעידוד השקעות הון, התשי"ט-21959 (להלן - חוק                     |עתירי ידע         |                        |
|העידוד), יינתנו ההטבות הניתנות למפעל באזור פיתוח א' לפי חוק העידוד.                   |ולמפעלים עתירי    |                        |
|(ב) לבנין תעשייתי ולבנין תעשייתי משופץ כהגדרתם בחוק העידוד,                           |טכנולוגיה         |                        |
|הנמצאים בירושלים ואשר הושכרו למפעל עתיר ידע או למפעל עתיר                             |                  |                        |
|טכנולוגיה, יינתנו ההטבות הניתנות לבנינים כאמור באזור פיתוח א' לפי חוק                 |                  |                        |
|העידוד.                                                                               |                  |                        |
|(ג)- סעיף זה יחול על מפעל מאושר, בנין תעשיית'- ובנין תעשייתי                          |                  |                        |
|משופץ שקיבלו אישור לפי חוק העידוד מיום כ"ד באדר ב' התשמ"ט (31 במרס                    |                  |                        |
|1989) עד יום כ"ד באדר ב' התשנ"ב (31 במרס 1992).                                       |                  |                        |

|דברי הסבר             |

|סעיף 22ג לחוק הרשות לפיתוח ירושלים, התשמ"ח-                 |
|1988, שהוסף בתיקון משנת התש"ן, קובע כי למפעלים              |
|מאושרים שהם מפעלים עתירי ידע או מפעלים עתירי                |
|טכנולוגיה בירושלים יינתנו ההטבות הניתנות באזור פיתוח        |
|א'.                                                         |
|בחוק עידוד השקעות הון, התשי"ט-1958, ניתנות                  |
|הטבות גם ל"בנין תעשייתי", שהוא בנין שהוקם בהתאם             |
|לתכנית מאושרת, המושכר למפעל תעשייתי מאושר, ול-              |
|"בנין ؀ࠂࠐࠒࠔתעשייתי משופץ", שהוא בנין ששימש כבנין תעשייתי    |
|ושנערך בו שיפוץ, והחלק המשופץ מושכר למפעל תעשייתי           |
|מאושר.                                                      |
|סעיף 22ג האמור, בניסוחו הקיים, אינו מאפשר מתן               |
|ההטבות לפי תנאי אזור פיתוח א' לבנינים כאמור אשר             |

|יושכרו למפעלים עתירי ידע ולמפעלים עתירי טכנולוגיה            |
|בירושלים.                                                    |
|התיקון המוצע בא לאפשר זאת. תחולת התיקון תהיה                 |
|בתחולת הסעיף הקיים.                                          |
|השפעת החוק המוצע על תקציב המדינה: יינתנו הטבות               |
|לפי תנאי אזור פיתוח א/ גם לבנין תעשייתי ולבנין תעשייתי       |
|משופץ שיושכרו למפעלים עתירי ידע ועתירי טכנולוגיה             |
|בירושלים. אולם מעשית לא צפויה השפעה תקציבית של               |
|ממש, שכן לפי המצב הקיים ניתן היה לקבל אותן הטבות             |
|בדרך אחרת, היינו שהמפעל המאושר עצמו היה משקיע גם             |
|כבנין כחלק מן התכנית המאושרת שלו.                            |
