|מתפרסמת בזה הצעת חוק מטעם הממשלה:                                                                                  |
|מבוא                                                                                                               |
|העיסוק באופטומטריה הוסדר בשנת 1980 מכוח חוק הפיקוח על מצרכים ושירותים,                                             |
|התשי"ח-1957, באכרזת הפיקוח על מצרכים ושירותים (עיסוק באופטומטריה); התש"ם-1980                                      |
|(ק"ת התש"ם, עמ' 2165), ובצו הפיקוח על מצרכים ושירותים (עיסוק באופטומטריה),                                         |
|התש"ם-1980 (ק"ת התש"ם, עמ' 2166) (להלן - הצו).                                                                     |
|בחוגי האופטומטראים הובעה התנגדות להסדרת המקצוע בחקיקת משנה בלבד, ואף הוגשה                                         |
|עתירה בענין לבית הדין הגבוה לצדק (בג"צ 590/82). בדיון בעתירה קיבל עליו משרד הבריאות                                |
|להכין הצעת חוק בנדון, וביום 4.7.84 אכן הונחה לפני הכנסת הצעת חוק העיסוק באופטומטריה,                               |
|התשמ"ד-1984 (ה"ח התשמ"ד, עמ' 289). הצעת החוק נדונה בקריאה ראשונה והועברה לדיון                                     |
|לוועדת העבודה והרווחה של הכנסת. בשל חילוקי דעות בין שלושת האיגודים של האופטומטראים                                 |
|בישראל לגבי החוק המוצע, הוקפא הדיון בוועדה והוא לא הושלם עד היום.                                                  |
|לאחרונה הוגשה עתירה נוספת לבג"צ לביטול הצו. מאחר שלדעת הממשלה יש להסדיר את                                         |
|העיסוק באופטומטריה באופן שהוא ייוחד לבעלי הכשרה מתאימה אשר עסקו במקצוע על פי                                       |
|רשיון מטעם משרד הבריאות, שבה הממשלה ומגישה בזה מחדש הצעת חוק מתאימה.                                               |
|הוראות החוק המוצע דומות בעיקרן להוראות שנקבעו בצו, אולם הוכנסו בהן מספר                                            |
|שינויים, שהעיקר בהט הוא: הקביעה שההכרה בלימודי אופטומטריה תינתן רק אם יתנהלו                                       |
|במסגרת מוסד מוכר ולא בקורס חיצוני.                                                                                 |
|כמו כן נכללה בהצעת החוק הוראה חדשה שנועדה לאפשר את העיסוק באורטופטיקה (טיפול                                       |
|בפזילה) בבית'חולים שאישר המנהל: מוצע להסמיך את מנהל משרד הבריאות לפטור מהוראות                                     |
|החוק, כולן או חלקן, אורטופטיקאי המועסק בבית חולים, כך שהוא יוכל לבצע טיפולים מסויימים,                             |
|על אף שהם ייחודיים לאופטומטריסטים.                                                                                 |

|1. בחוק זה -                                                                                             |הגדרות               |
|"אופטומטריה" - מדידה של כושר הראייה או של טווח הראייה של אדם, קביעה של מצב                               |                     |
|ההסתגלות או השבירה של קרני האור בעינו של אדם, התאמת עדשות לשיפור הראייה, מתן                             |                     |
|מרשם או הוראה בדבר שימוש במכשיר אופטי לראייה לתרגילי עיניים, לאימון הראייה או                            |                     |
|ליישורה, ומתן מרשם לעדשות מגע, התאמתן או קביעתן לעינו של אדם;                                            |                     |
|"אופטומטראי" - מי שהורשה לפי חוק זה לעסוק באופטומטריה;                                                   |                     |
|"המנהל" - המנהל הכללי של משרד הבריאות, או מי שהוא הסמיך לענין חוק זה;                                    |                     |
|"השר" - שר הבריאות;                                                                                      |                     |
|"ועדה מייעצת" - הועדה המייעצת שמונתה לפי סעיף 12;                                                        |                     |

|2. (א) המנהל יתן רשיון לעסוק באופטומטריה למבקש שהוא בעל הכשרה מקצועית                                    |זכאות לרשיון         |
|באופטומטריה.                                                                                             |                     |

|(1) מי שבידו תעודה המעידה כי סיים בהצלחה לימודי אופטומטריה בישראל או                                     |                     |
|מחוצה לה, במוסד ולפי תכנית לימודים שהכיר בהם המנהל;                                                      |                     |
|(2) סיים התמחות שנקבעה בתקנות;                                                                           |                     |

|על היותו אופטומטראי אלא אם כן יש בידו רשיון לפי חוק זה.                                                  |והכינוי              |
|(ב) הוראת איסור העיסוק באופטומטריה כמפורט בסעיף קטן (א) לא תחול -                                        |                     |
|(1) על רופא מומחה במחלות עיניים, או מתמחה במחלות עיניים לפי תקנות                                        |                     |
|הרופאים (אישור תואר מומחה ובחינות), התשל"ג-21973 (להלן - רופא עיניים) ועל                                |                     |
|רופא מורשה שהוכיח להנחת דעתו של המנהל כי בתקופה של 5 שנים לפני תחילתו                                    |                     |
|של חוק זה ייחד עיסוקו לרפואת עיניים;                                                                     |                     |
|(2) על מי שמתמחה בעבודה מעשית באופטומטריה בפיקוחו ובהדרכתו של                                            |                     |
|אופטומטראי מורשה או של רופא מורשה.                                                                       |                     |
|4. (א) המנהל רשאי לפטור מהוראות חוק זה, כולן או חלקן, את מי שעוסק באורטופטיקה                            |פטור מתחולה          |
|בבית-חולים שאישר המנהל.                                                                                  |                     |
|(ב) בסעיף זה, "אורטופטיקה" - מדידה של פעילות השרירים של העין ומידת ההתאמה                                |                     |
|הדו-עינית; טיפול - בפיקוחו של רופא עיניים - בפזילה ובעין עצלה בדרך של כיסוי עין, תירגול                  |                     |
|ומיכשור אופטי מתאים.                                                                                     |                     |
