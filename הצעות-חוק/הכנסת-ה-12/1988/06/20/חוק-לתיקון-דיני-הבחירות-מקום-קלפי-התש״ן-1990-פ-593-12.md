|הבחירות לכנסת    |"(א1) מקום קלפי יהיה, בכפוף לאמור בסעיף קטן (ב), בבניין ציבורי שיותקנו                                           |
|                 |בו סידורים מיוחדים- לנכים, בהתאם להוראות פרק ה1 לחוק התכנון והבניה,                                              |
|                 |ה-תשכ"ה-1965 - 2".                                                                                               |
|תיקון חוק        |2.  אחרי סעיף 31(א) לחוק הרשויות המקומיות (בחירות), התשכ"ה-1965 3, יבוא:                                         |
|הרשויות          |"(א1)  מקום  קלפי יהיה, בכפוף לאמור בסעיף קטן (ב), בבניין ציבורי שיותקנו                                         |
|המקומיות         |י בו סידורים מיוחדים לנכים, בהתאם להוראות פרק ה1 לחוק התכנון והבניה,                                             |
|(בחירות)         |התשכ"ה-1965".                                                                                                    |
|הוראת שעה        |3. (א) בבחירות לכנסת השתים עשרה ייקרא סעיף 68 (א1) לחוק הבחירות לכנסת                                            |
|                 |[נוסח משולב], התשכ"ט-1969, כאילו נאמר בו:                                                                        |
|                 |"(א1) (1) מקום קלפי יהיה, ככל האפשר ובכפוף. לאמוד בסעיף קטן (ב),,                                                |
|                 |בבניין ציבורי שהותקנו ובו סידורים מיוחדים לנכים, בהתאם להוראות                                                   |
|                 |פרק  ה' 1 לחוק התכנון והבניה, התשכ"ה-1965;                                                                       |
|                 |(2)" לא היה מקום הקלפי בבנין כאמור, תעשה ועדת הבחירות האזורית                                                    |
|                 |את הסידורים הנדרשים כדי להבטיח הצבעתם של נכים; שר, הפנים                                                         |
|                 |רשאי לקבוע ובתקנות ؀ࠂࠌࠎהסדרים לענין זה."                                                                         |
|                 |(ב) בבחירות לרשויות המקומיות שתיערכנה ולראשונה לאחר תחילתו של חוק                                                |
|                 |זה, ייקרא.סעיף 31 (א1) לחוק הרשויות, המקומיות (בחירות), התשכ"ה-1965, כאילו                                       |
|                 |נאמר בו:                                                                                                         |
|                 |"(א1) (1) מקום קלפי יהיה, ככל האפשר ובכפוף לאמור בסעיף קטן (ב),                                                  |
|                 |ובבניין ציבורי שהותקנו בו סידורים מיוחדים לנכים, בהתאם להוראות                                                   |
|                 |פרק ה'1 לחוק התכנון והבניה, התשכ"ה-1965;                                                                         |
|                 |(2) לא היה מקום הקלפי בבנין כאמור, תעשה ועדת הבחירות את                                                          |
|                 |הסידורים הנדרשים כדי להבטיח הצבעתם של נכים; השר רשאי לקבוע                                                       |
|                 |בתקנות הסדרים לענין זה."                                                                                         |
