|מתפרסמת כזה הצעת חול, מטעם ועדת החוקה חוק ומשפט של הכנסת:                          |

|חוק חובת מכרזים, התשנ"א-1991                          |

|[457]       |

|1. בחוק זה -                                                                                               |הגדרה             |
|"תאגיד ממשלתי" - חברה ממשלתית, חברת בת ממשלתית, תאגיד שהוקם כחוק, וכן כל תאגיד                             |                  |
|שהממשלה משתתפת בתקציבו כדי יותר מ-50%.                                                                     |                  |
|2. לא תתקשר המדינה, ולא יתקשר תאגיד ממשלתי בחוזה לביצוע עסקה - במקרקעין,                                   |חובת מכרז         |
|בטובין, או למתן שירותים, אלא על פי מכרז פומבי, שיבטיח הזדמנות שווה למשתתפים בו, ואשר                       |                  |
|תנאיו ואופן פרסומו יהיו על פי חוק זה.                                                                      |                  |
|3. (א) שר האוצר, באישור ועדת הכספים של הכנסת, יקבע בתקנות לגבי המדינה                                      |דרכי מכרז         |
|ותאגידים ממשלתיים -                                                                                        |                  |
|(1) את צורות המכרזים ודרכי הזמנתם וקבלתן של הצעות מחירים;                                                  |                  |
|(2) את אופן הרכבתן ואיושן של ועדות מכרזים, ואת אמות המידה לבחירת                                           |                  |
|ההצעות המתאימות;                                                                                           |                  |
|(3) הוראות מיוחדות ותנאים מיוחדים למכרזים לסוגיהם השונים של המוסדות                                        |                  |
|והתאגידים שהחוק הזה חל עליהם;                                                                              |                  |
|(4) את אופן פרסומם של המכרזים ברבים?                                                                       |                  |
|(5) סכומים וסוגי עסקאות שלגביהם לא תהיה חובה לערוך מכרז פומבי אלא מכרז                                     |                  |
|סגור ותנאיו?                                                                                               |                  |
|(6) סכומים וסוגי עסקאות שלגביהם לא תהיה חובה לערוך מכרז כלל;                                               |                  |
|(7) כל ענין אחר הנראה לו דרוש לשם ניהול תקין והוגן של עסקאות ובמטרה                                        |                  |
|להבטיח את קבלת ההצעות שיעניקו את מרב היתרונות לממשלה או לתאגיד.                                            |                  |
|(ב) תקנות לפי סעיף זה ניתן לקבוע דרך כלל או לסוגי עסקאות או לסוגי הגופים                                   |                  |
|המתקשרים.                                                                                                  |                  |

|דברי הסבר             |

|לפי המצב החוקי הקיים כיום, חלה חובת המכרז הפומבי            |
|כחובה חוקית רק על הרשויות המקומיות. הממשלה פועלת            |
|על פי הוראות תקנון כספים ומשק של החשב הכללי שאינו           |
|נורמה חוקית מחייבת, ואילו מוסדות ומפעלים רבים,              |
|שהממשלה או הרשויות משתתפות בהנהלתם או בתקציבם,              |
|פטורים מחובה זו של עריכת מכרזים פומביים, ויכולים            |
|למסור הזמנות לעבודות או לרכישתם؀ࠂࠒࠔ࠘ࠜࠞࠠ ומכירתם של נכסים    |
|ללא מכרז כלל.                                               |
|שיטת המכרזים, על אף הבעיות המתעוררות בהפעלתה,               |

|מבטיחה, בהפעלה נכונה, פיקוח ציבורי אובייקטיבי על             |
|הוצאות כספי הציבור, ומהווה הדרך הטובה ביותר לבחינת           |
|הצעות מחירים ותנאים אחרים בקשר לעסקאות הנערכות               |
|בכספי הציבור.                                                |
|החוק המוצע בא לקבוע חובת עריכת מכרזים בכל                    |
|המוסדות שהממשלה מעורבת בתקציבם או בהנהלתם. כן                |
|מוצע שגם מכרזי הרשויות המקומיות יתבססו על הוראות             |
|החוק המוצע. בדרך זו תובטח אחידות של גישה וטיפול              |
|בנושא מורכב זה.                                              |
