|1. בסעיף 135 לחוק הרשות השניה לטלוויזיה ורדיו, התש"ן-1990 1, סעיפים קטנים (ד) ו-(ה)                      |תיקון סעיף 135        |
|יסומנו כסדרם (ה) ו-(ו) ולפניהם יבוא:                                                                     |                      |
|"(ד) לענין סעיף זה -                                                                                     |                      |
|(1) "תשדיר שירות" - תשדיר שעיקרו ומגמתו הדרכה לציבור בדרך של מתן מידע                                    |                      |
|לציבור על התועלת שבשירות שאליו התשדיר מתייחס ועל הדרך להשגתו, והכוונת                                    |                      |
|הציבור על ידי הסברה וייעוץ, הכל בנושאים שבטובת הציבור;                                                   |                      |
|(2) "שידור חסות" - ציון השתתפותו של גורם חוץ במימון מישדר (להלן -                                        |                      |
|המממן), לרבות בדרך של פרסום מוצריו, תיאור מאפייניהם העיקריים וציון סימן                                  |                      |
|מסחרי של המממן או מוצריו."                                                                               |                      |
