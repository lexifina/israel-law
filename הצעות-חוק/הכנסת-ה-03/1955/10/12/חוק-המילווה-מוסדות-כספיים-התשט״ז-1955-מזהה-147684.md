|1 . בחוק זה -                                                                                                     |הגדרות               |
|"מוסד כספי" - בנק כמשמעותו בפקודת הבנקאות, 1941 1, או אגודה שיתופית לאשראי ;                                      |                     |
|"שטרי ערך" - שטרי ערך שהוצאו בהתאם לחוק זה.                                                                       |                     |
|2. הממשלה מורשית בזה ללוות ממוסדות כספיים סכום שלא יעלה על עשרה מיליון                                            |סמכות ללוות          |
|לירות ולהוציא למטרה זו שטרי ערך.                                                                                  |                     |
|3. (א) שטרי הערך ייפדו ביום י' בחשון תשכ"א (31 באוקטובר 1960).                                                    |פדיון, ריבית         |
|(ב) שטרי הערך ישאו ריבית בשיעור של שלושה למאה לשנה, שתשולם בשיעורים                                               |ושאר תנאים           |
|חצי שנתיים ביום 1 במאי וביום 1 בנובמבר של כל שנה מיום כ' באייר תשט"ז (1 במאי                                      |                     |
|1956) ואילך.                                                                                                      |                     |
|(ג) הממשלה רשאית לפני המועד הקבוע בסעיף קטן (א)' לפדות בערכם הנקוב                                                |                     |
|את כל שטרי הערך, או חלק יחסי שווה מכל שטר ושטר' לאחר מתן הודעה מוקדמת של                                          |                     |
|שלושה חדשים לפחות בה ייקבע מועד הפדיון ; ההודעה תפורסם ברשומות. ניתנה הודעה                                       |                     |
|כאמור' לא ישאו שטרי הערך, או החלק היחסי של כל שטר ושטר, הכל לפי הענין, ריבית                                      |                     |
|לאחר המועד שהממשלה קבעה כמועד לפדיון.                                                                             |                     |
|(ד) שטרי הערך ייערכו בצורת תעודות סטוק, וכל תעודה תהיה בסכום שהוא.                                                |                     |
|מכפלה של עשר לירות ; התעודות יהיו לזכות הבעלים הרשומים או למוכ"ז.                                                 |                     |
|(ה) שר האוצר יקבע בתקנות את שאר התנאים של שטרי הערך, ובכלל זה נוסחם                                               |                     |
|ודרכי העברתם.                                                                                                     |                     |

|דברי הסבר                                                                                                         |
|בשנת 1950 הוציאה הממשלה, בהתאם להוראות חוק המילווה (מוסדות כספיים),                                               |
|תש"י-1950, שטרי ערך בסכום כולל של חמישה מיליון לירות שנמכרו כולם למוסדות                                          |
|כספיים. מועד פרעונם של כל שטרי הערך האמורים יחול ביום ט"ו בחשון תשט"ז (31                                         |
|באוקטובר 1955).                                                                                                   |
|החוק המוצע בא לאפשר לממשלה להוציא שטרי ערך חדשים בסכום כולל של                                                    |
|10 מיליון לירות בתנאים זהים לתנאי המילוות הדומים הקודמים. מחצית מסכום שטרי                                        |
|הערך האמורים באים להחליף את שטרי הערך משנת 1950 שזמן פרעונם יחול ביום ט"ו                                         |
|בחשון תשט"ז (31 באוקטובר 1955) והמחצית קשניה תוצע לרכישה למוסדות כספיים                                           |
|להחזקתם כחלק מהנכסים הנזילים שעליהם להחזיק לגבי פקדונותיהם. מאתר ופקדונותיהם                                      |
|של מוסדות האשראי גדלו בשנים האחרונות וכתוצאה מכך גדל הסכום שעליהם להשקיע                                          |
|במילווה ממשלתי באה התוספת של שטרי הערך להשיב על צורך זה.                                                          |
