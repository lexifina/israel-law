|חוק מקדמת בטחון, תשי"ז-1957                                                                                |                   |
|1, הממשלה מורשית בזה לקבל מבנק ישראל (להלן - הבנק) והבנק מורשה בזה לתת                                     |מילווה לממשלה      |
|לממשלה מילווה בסכום של 65 מיליון לירות (להלן - המילווה) לצורך סילוק המקדמות                                |מבנק ישראל         |
|הארעיות שהממשלה קיבלה מהבנק למימון הוצאות בטחון בשנת הכספים 1956/57.                                       |                   |
|2. תנאי המילווה ומועד פרעונו ייקבעו בהסכם בין שר האוצר לבין נגיד הבנק,                                     |תנאי המילווה       |
|באישורה של ועדת הכספים של הכנסת.                                                                           |                   |
|דברי הסבר                                                                                                  |                   |
|בשנת הכספים 1956/57 קיבלה הממשלה מבנק ישראל מקדמות ארעיות במטבע                                            |                   |
|חוץ לכיסוי הוצאות הבטחון הדחופות. מקדמות אלה מסתכמות ב-66 מיליון לירות. לפי                                |                   |
|סעיף 45 לחוק בנק ישראל, תשי"ד-1954, חייבת הממשלה להחזיר את כל המקדמות שניתנו                               |                   |
|לה על ידי הבנק לא יאוחר מתום שנת הכספים בה ניתנו המקדמות.                                                  |                   |
|החוק המוצע מטרתו לאפשר לממשלה סילוק המקדמות האמורות על ידי ؀ࠂࠈהמרתן                                        |                   |
|במילתה שתנאיו ומועד פרעונו ייקבעו בהסכם בין שר האוצר לבין נגיד הבנק באישור                                 |                   |
|ועדת הכספים של הכנסת.                                                                                      |                   |
