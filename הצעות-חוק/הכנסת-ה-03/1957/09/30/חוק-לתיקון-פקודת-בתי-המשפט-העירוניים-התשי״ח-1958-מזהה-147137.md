חוק לתיקון פקודת בתי המשפט העירוניים, תשי"ח-1957

|1. בסעיף 8א לפקודת בתי המשפט העירוניים 1 -                                                                 |תיקון סעיף 8א    |
|(1) במקום סעיף קטן (1) יבוא סעיף קטן זה:                                                                   |                 |
|"(1) שר המשפטים רשאי, בצו, להקים בית משפט עירוני שאזור שיפוטו                                              |                 |
|יהיה התחום של כל רשות מקומית, אחת או יותר;                                                                 |                 |
|"רשות מקומית", לענין סעיף זה - עיריה או מועצה מקומית כמשמעותה                                              |                 |
|בפקודת המועצות המקומיות, 21941.";                                                                          |                 |
|(2) בסעיף קטן (2), במקום המלים "של מועצה מקומית", בכל מקום שהן, יבואו                                      |                 |
|המלים "של רשות מקומית'/                                                                                    |                 |
|דברי הסבר                                                                                                  |                 |
|מטעמים של חסכון ושל יעילות אין זה תמיד רצוי להקים בית משפט עירוני לעיריה                                   |                 |
|אחת בלבד. לעתים יש לרשויות מקומיות שכנות ענין לכך שיוקם בית משפט עירוני משותף                              |                 |
|ושישתתפו בהוצאות ניהולו. החוק הקיים מאפשר להקים בית משפט עירוני לעיריה אחת                                 |                 |
|בלבד או למועצה מקומית או למספר מועצות מקומיות; אולם אין בו כדי לאפשר הקמת בית                              |                 |
|משפט עירוני למספר؀ࠂࠌࠎ עיריות או לעיריה ולמועצה מקומית גם יחד. החוק המוצע בא לאפשר                          |                 |
|מגמה זו.                                                                                                   |                 |
