|מתפרסמת בזה הצעת חוק מטעם ועדת הכספים של הכנסת:                                                                               |
|חוק מבקר המדינה (הוראת שעה), תשי"ח-1957                                                                      |                 |
|1. על אף האמור בסעיף 11 (א) (1) לחוק מבקר המדינה, תש"ט-1949 1, ימציא מבקר                                    |הארכת מועד       |
|המדינה את הדין וחשבון לשנת הכספים 1956/57 לשר האוצר לא יאוחר מיום כ"ה בשבט                                   |                 |
|תשי"ח (15 בפברואר 1958).                                                                                     |                 |
|2. תחילתו של חוק זה ביום קבלתו בכנסת.                                                                        |תחילה            |
|דברי הסבר                                                                                                    |                 |
|סעיף 11 (א) (1) לחוק מבקר המדינה קובע שעל המבקר להגיש את הדין וחשבון השנתי                                   |                 |
|לשר האוצר לפני יום 31 בדצמבר לכל שנה.                                                                        |                 |
|ועדת הכספים של הכנסת דנה כעת כתיקונים לחוק מבקר המדינה והיא עומדת להגיש                                      |                 |
|לכנסת בעוד מועד הצעת חוק מקיפה. בין הבעיות העומדות לדיון בועדה נמצאת גם בעיית                                |                 |
|המועדים הקבועים בחוק מבקר המדינה בקשר להכנת הדין וחשבון השנתי והטיפול בו                                     |                 |
|על ידי שר האוצר והועדה. הדיון בועדת הכספים טרם נסתיים ולכן מוצע כעת שלא לתקן                                 |                 |
|את החוק תיקון של ؀ࠂࠆקבע אלא לחוקק הוראת שעה שתכליתה להעתיק את המועד להגשת                                    |                 |
|הדין וחשבון לשנת הכספים 1956/57 מיום ח' בטבת תשי"ח (31 בדצמבר 1957) ליום כ"ה                                 |                 |
|בשבט תשי"ח (15 בפברואר 1958).                                                                                |                 |
