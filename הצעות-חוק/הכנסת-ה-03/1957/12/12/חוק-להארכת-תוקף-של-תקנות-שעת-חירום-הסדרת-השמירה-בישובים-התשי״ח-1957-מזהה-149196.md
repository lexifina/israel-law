|1. תקפן של תקנות-שעת-חירום (הסדרת-השמירה בישובים), תשט"ז-1956 1 (להלן -                                   |הארכת תוקף       |
|התקנות), מוארך בזה עד יום כ' בטבת תשי"ט (31 בדצמבר 1958),                                                 |                 |

|דברי הסבר                                                                                                 |                 |
|ביום ט"ז באייר תשט"ז (27 באפריל 1956) התקין שר הפנים תקנות-שעת-חירום                                      |                 |
|שמטרתן לאפשר לישובים להטיל את חובת השמירה על תושביהם. תקפן של תקנות אלה                                   |                 |
|הוארך מדי פעם בפעם על-ידי הכנסת, ולאחרונה נקבע כי תקפן יפקע ביום ח' בטבת                                  |                 |
|תשי"ח (31 בדצמבר 1957). הצורך בתקנות אלה בעינו עומד ולכן מציעה הממשלה להאריך                              |                 |
|את תקפן עד סוף שנה זו,                                                                                    |                 |
|וזהו הנוסח של תקנות-שעת-חירום (הסדרת השמירה בישובים), תשט"ז-1956:                                         |                 |
|תקנות-שעת-חירום בדבר הסדרת השמירה בישובים                                                                 |                 |
|1. בתקנות אלה -                                                                     |הגירות               |                 |
|"מועצה" - מועצתה של רשות מקומית; ולגבי ישוב הנמצא מחוץ לתחום                        |                     |                 |
|רשות מקומית, יראו את הממונה על המחוז בו נמצא הישוב, כמועצה                          |                     |                 |
|לענין תקנות אלה;                                                                    |                     |                 |
|"מפקד אזור (מא"ז)"- אדם שנתמנה על ידי מפקד הגנה מרחבית להיות                        |                     |                 |
|מפקד אזור (מא''ז) או רכז בטחון שוטף (רב"ש), לצרכי תקנות אלה.                        |                     |                 |
|"שמירה" - לרבות פעולה הדרושה, לדעת מפקד אזור (מא"ז), לשמירה                         |                     |                 |
|על בטחון תושבי ישוב או רכושם.                                                       |                     |                 |
|2. מועצה רשאית, באישור שר הפנים, להסדיר, בחוק עזר שיפורסם                           |הסדרת השמירה         |                 |
|ברשומות (להלן - חוק העזר), את השמירה בתחומה, כולו או מקצתו.                         |                     |                 |
|3. בחוק העזר רשאית המועצה להטיל חובת השמירה בתחום ישוב                              |חוקי עזר             |                 |
|מסויים על תושבי אותו ישוב שנמצאו מסוגלים לכך בדרך שתקבע בחוק                        |                     |                 |
|העזר, ומשעשתה כן, תקים באותו חוק עזר, לאזורה כולו או לכל חלק                        |                     |                 |
|ממנו לחוד כפי שתקבע בחוק העזר, ועדת שמירה או רשות שמירה וכן                         |                     |                 |
|ועדת עררים ותקבע בו את ؀ࠂࠎࠐࠔࠚࠜࠞסמכויותיהן; ובלבד שהסדר השמירה לפי                   |                     |                 |
|חוק העזר ייעשה בהתאם להוראת מפקד אזור (מא"ז).                                       |                     |                 |

|ונפגע תוך כדי קיום חובת השמירה ועקב קיומה, דינו כדין נפגע ספר                       |הגימלאות             |                 |
|כמשמעותו בחוק הגימלאות לנפגעי ספר, תשי"ז-1956 2, ודין הפגיעה                        |לנפגעי ספר           |                 |
