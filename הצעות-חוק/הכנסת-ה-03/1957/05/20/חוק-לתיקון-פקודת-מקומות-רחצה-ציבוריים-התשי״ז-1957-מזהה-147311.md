|                 | דברי הסבר                                                                                               |
|                 |פקודת מקומות רחצה ציבוריים, סעיף 2, מעניקה לשר הפנים את הסמכות "להכריז                                   |
|                 |בצו כי כל אזור שיפורט באותו צו ושאינו חלק מאזור עיריה או מאזור מועצה מקומית יהא                          |
|                 |מקום רחצה ציבורי לצרכי פקודה זו". סעיף 3 לפקודה הנ"ל מורה שעם התפרסם צו כאמור,                           |
|                 |רשאי הממונה על המחוז בו נמצא האזור שעליו ניתן חצה להתקין חוקי עזר בדבר נקיטת                             |
|                 |אמצעים לשמירת בטחונם של המתרחצים. נקיון המקום והסדר הטוב. לא הפקודה הנ"ל/                                |
|                 |ולא כל חוק אחר, מעניקים סמכות לאסור כליל את הרחצה במקום מסויים/ גם אם הרחצה                              |
|                 |כרוכה בסכנת נפשות כגון: מקומות בהם קרקע הים, הנהר או האגם בוגדניים או שמצוי בהם                          |
|                 |؀ࠂࠈזרם חזק או מערבולת מסוכנת או שהמים במקומות אלה מזוהמים ועלולים לפגוע בבריאותם                         |
|                 |של המתרחצים, גם לרשויות המקומיות' אשר להן מוענקות סמכויות מסויימות להתקנת                                |
|                 |חוקי עזר בדבר "הפיקוח על הרחצה על שפת הים" (סעיף 98(2) לפקודת העיריות' 21934),                           |
|                 |אין סמכות לאסור כליל את הרחצה במקרים המפורטים לעיל,                                                      |
|                 |לשם מניעת אסונות בנפש ובבריאות כתוצאה מרחצה במקומות מסוכנים או מזוהמים,                                  |
|                 |באה ההצעה להעניק לשר הפנים לאחר התייעצות עם שר הבריאות' את הסמכות לאסור                                  |
|                 |את הרחצה בכל שטח מסויים מחוף הים, נהר או אגם בו קיימת לדעתו סכנה כאמור; על                               |
|                 |העובר על איסור זה יוטל קנס עד 100 לירות.                                                                 |
|                 |סעיף 2 שבהצעה בא למנוע ספק העלול להתעורר מהוראות סעיף 1, בקשר לסמכויות                                   |
|                 |המוענקות לשר התחבורה על פי פקודת הנמלים 3, סעיף 17 , לאסור את הרחצה בשטח הנמל.                           |
