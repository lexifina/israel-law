|דעתו של המנהל כי האיגרת לא נמסרה לתעודתה' רשאי שר האוצר להורות בצו' כי אותה                               |                 |

|לביצועו.                                                                                                  |ו                |
|דברי הסבר                                                                                                 |/                |
|סעיף 16 לחוק מילווה עממי מיוחד' תשי"ד-1954, קובע כדלהלן:                                                  |                 |
|"שילם אדם סכום מקדמה ולא הודיע למנהל עד תום 3 חדשים מיום תחילתו של חוק                                    |                 |
|זה כי רכש אגרות חוב שעליו לרכוש לפי סעיף 14 או כי ברצונו לרכוש אגרות חוב נושאות                           |                 |
|ריבית, רשאי המנהל לשלוח לו 'אגרות חוב נושאות פרסים בסכום האמור ועם מסירתן                                 |                 |
|יראוהו כאילו רכש את אגרות החוב ؀ࠂࠊࠌשנשלחו אליו וניכה ממחירן את סכום המקדמה ששילם                          |                 |
|בעדן".                                                                                                    |                 |
|בזמנו נשלחו על ידי מנהל המקדמה איגרות חוב לכל משלמי המקדמה בהתאם לסעיף                                    |                 |
|16 האמור.י האיגרות נשלחו בדואר רשום לפי המענים שהיו בידי מנהל המקדמה.                                     |                 |
|התברר עתה כי איגרות חוב במספר ניכר לא הגיעו לתעודתן וכל הבירורים במשרד                                    |                 |
|הדואר לא העלו כלום. יש חשש כי האיגרות הגיעו לידי אנשים שלא היו זכאים להן ולא                              |                 |
|הוחזרו.                                                                                                   |                 |
|איגרות החוב נערכו אמנם על שם הבעלים הרשומים, אולם בהתאם לסעיף 2 לחוק                                      |                 |
|יהיו מאליהן לאיגרות חוב למוכ"ז ביום י"א באדר תשי"ח (3 במרס 1958)' והאנשים                                 |                 |
|שלידיהם הגיעו איגרות החוב האבודות והמחזיקים בהן שלא כדין עלולים להעבירן, לאחר                             |                 |
|המועד האמור, לקונים בתום לב.                                                                              |                 |
