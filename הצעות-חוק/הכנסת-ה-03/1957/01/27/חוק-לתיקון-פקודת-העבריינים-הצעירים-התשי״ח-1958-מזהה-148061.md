|1. סעיף 18 לפקודת העבריינים הצעירים, 1937 1 (להלן - הפקודה), יהיה סעיף קטן (1)                             |תיקון סעיף 18      |
|לסעיף 18, ולאחריו יווסף סעיף קטן זה:                                                                       |                   |
|"(2) שלח בית המשפט צעיר לבית ספר לתיקון עבריינים צעירים או למוסד                                           |                   |
|אחר שנועד לכך על ידי שר הסעה רשאי בית המשפט, על אף האמור בפקודה                                            |                   |
|זו, לחייב את הוריו של הצעיר וכן מי שחייב במזונותיו, במידה שהוא חייב,                                       |                   |
|בהוצאות הנגרמות על ידי כך, וכן לקבוע שיעור השתתפותו של כל אחד. מהם                                         |                   |
|ודרכי התשלום."                                                                                             |                   |
|ד ב ר י ה ס ב ר                                                                                            |                   |
|                                                                                                           |                   |
|לפי החוק הקיים יכול בית המשפט לחייב את ההורים או מי שחייב בכלכלת צעיר,                                     |                   |
|להשתתף בהוצאות החזקתו במקרים שהוא נדון בהתאם לסעיף 16 לפקודה, כלומר צעירים                                 |                   |
|שאינם עבריינים אולם זקוקים להשגחה ולהגנה. לעומת זה אין הוראה מקבילה בסעיף 18                               |                   |
|הדן בצעירים שהואשמו ؀ࠂࠊࠌבעבירה.                                                                            |                   |
|לאור הדמיון הרב בין הזקוקים להשגחה ולהגנה לבין צעירים שכבר עברו                                            |                   |
|עבירה, אין טעם בהבחנה זאת ומוצע שבית המשפט יוכל לחייב את ההורים בכל מקרה                                   |                   |
|שצעיר נשלח למעון, במידה ויש באפשרותם להשתתף בהוצאות.                                                       |                   |
|לפי הצעת חוק שיריתי הסעד, תשט"ז-1956, המונחת על שולחן הכנסת יוכלו                                          |                   |
|שר הסעד או רשות מ קומית לתבוע את המזונות עבור הצעיר. אולם תביעה כזאת תידון                                 |                   |
|בפני בית משפט מחוזי או בית דין בעוד שבמקרים שלפנינו רצוי ששופט הנוער יחליט                                 |                   |
|בו במקום גם בדבר ההוצאות.                                                                                  |                   |
