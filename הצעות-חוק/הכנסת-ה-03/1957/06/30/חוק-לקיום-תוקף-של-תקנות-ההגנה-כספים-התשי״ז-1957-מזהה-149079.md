חוק לקיום תוקף של תקנות ההגנה (כספים), תשי"ז-1957

|קיום תוקף      |1. תקנות ההגנה (כספים), 1941 1, יעמדו בתקפן עד שתפורסם הכרזה של הכנסת -                                    |
|               |בהתאם לסעיף 9(ד) לפקודת סדרי השלטון והמשפט' תש"ח-1948 2 - כי חדל מצב החירום                                |
|               |להתקיים.                                                                                                   |
|תחילה          |2. תחילתו של חוק זה היא ביום ד' באב תשי"ז (1 באוגוסט 1957).                                                |
|               |דברי הסבר                                                                                                  |
|               |תקנות ההגנה (כספים)' 1941' המהוות את הבסיס החוקי לפיקוח על מטבע חוץ הותקנו                                 |
|               |בשעתו מכוח חקיקה בריטית שתקפה פקע בשנת 1951. מאז קום המדינה תוקנו התקנות מספר                              |
|               |פעמים על מנת להתאימן לצרכי המדינה המיוחדים, וכן הוארך תקפן מדי פעם בפעם בחוק                               |
|               |הכנסת' ולאחרונה' בחוק לקיום תוקף של תקנות ההגנה (כספים)' תשי"ז-1956' עד ליום ג'                            |
|               |באב תשי"ז (31 ביולי 1957).                                                                                 |
|               |תקנות ההגנה (כספים)' 1941' מסדירות ענינים אלה:                                                             |
|               |1. ההגבלה על המסחר במטבע חוץ, בזהב' בניירות ערך זרים;                                                      |
|               |2. החובה למכור לשר האוצר ؀ࠂࠊࠌכל מטבע חוץ;                                                                  |
|               |3. פיקוח על יבוא ויצוא של מטבע חוץ ושל זהב;                                                                |
|               |4. הגבלות על תשלומים לתושבי חוץ ועל עסקים עמהם;                                                            |
|               |5. פיקוח על הוצאת הון מניות והוצאות ניירות ערך למוכ"ז.                                                     |
|               |הפיקוח על כל הענינים האמורים דרוש' לדעת הממשלה' כל זמן שקיים הפער העצום                                    |
|               |בין היבוא ובין היצוא וכל עוד הכלכלה הישראלית צריכה להיות מותאמת למשק של קליטת                              |
|               |עליה המונית.                                                                                               |
|               |לפיכך מוצע בזה להפסיק אחת ולתמיד את הצורך בהארכות חוזרות ונשנות של                                         |
|               |תקנות ההגנה (כספים)' 1941' ולקיים אותן עד למועד שתפורסם אכרזה' בהתאם לפקודת                                |
|               |סדרי השלטון והמשפט' תש"ח-1948, כי מצב החירום שהוכרז מיד לאחר הקמת המדינה'                                  |
|               |חדל מלהתקיים,                                                                                              |

1 ע''ר 1941' תוס' 2 מס' 1138, עמ' 1380.
2 ע"ר תש"ח, תוס' א' מס' 2, עמ' 1.
