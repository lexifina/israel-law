|21947".                                                                                                   |                  |
|2. כל שומה לפי פקודת מס הכנסה' 1947 (להלן-הפקודה), לשנת שומה או לשנת מס                                   |תיקון שומות       |
|כלשהי/ שבה הותר ניכוי כופר כהוצאה לענין סעיף 11 לפקודה, תתוקן בהתאם להוראות                               |                  |
|סעיף 60א לחוק מילווה חובה' תשי"ג-1953; תיקון כזה ניתן לערעור כאילו היה צו לפי                             |                  |
|סעיף 59 (5) לפקודה.                                                                                       |                  |
|דברי הסבר                                                                                                 |                  |
|בית המשפט העליון, בפסק דינו בע"א 25/57/ החליט/ כי לפי החוק הקיים, כופר                                    |                  |
|מילווה חובה ששולם לפי חוק מילווה חובה ניתן לניכוי כהוצאה לפי סעיף 11 לפקודה                               |                  |
|לצורך חישוב ההכנסה החייבת במס. החוק המוצע בזה בא לשלול אפשרות זו של ניכוי                                 |                  |
|תשלומי כופר מילווה חובה ؀ࠂࠊࠌכהוצאה כאמור' מטעמים אלה:                                                     |                  |
|1. עמדתם המוצהרת של הנהלת מילווה חובה וגם של נציבות מס הכנסה לגבי ציבור                                   |                  |
|משלמי המילווה היתה' כי אין אפשרות לנכות את תשלומי כופר מילווה חובה לענין סעיף 11                          |                  |
|לפקודה, ודבר זה היה לחייבים במילווה אחד הטעמים לבחור בין תשלום כופר לבין מילווה                           |                  |
|חובה; רבים ממשלמי מילווה חובה היו בוחרים בתשלום כופר אילו הותר הניכוי האמור,                              |                  |
|2. הסכומים ששולמו ככופר מילווה חובה מגיעים כדי 17.25 מיליון לירות לערך והובאו                             |                  |
|בחשבון תקציבי שנים קודמות. החזרת חלק ניכר מסכום זה יהווה בעיה תקציבית שיקשה                               |                  |
|להתגבר עליה.                                                                                              |                  |
