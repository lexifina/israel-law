|                    |16. (א) דיין יצא לקיצבה -                                                            |"קיצבה                    |
|                    |(1) בהגיעו לגיל שבעים ואם היה רב ראשי לישראל או                                      |                          |
|                    |ראש אבות בתי דין - בהגיעו לגיל שבעים וחמש;                                           |                          |

|                    |תפקידו.                                                                              |                          |
|                    |(ב) דיין רשאי לצאת לקיצבה -                                                          |                          |
|                    |(1) לאחר שכיהן עשרים שנה' אם הגיע לגיל ששים;                                         |                          |

|                    |(ג) בחישוב תקופת כהונתו של דיין לענין סעיף קטן (ב) תצורף                             |                          |
|                    |אליה' כל תקופת שירותו במדינה או במוסד אחר שועדת הכספים של                            |                          |

|דברי הסבר                                                                                                                            |
|סעיף 16 לחוק הדיינים קבע לאמר:                                                                                                       |
|"16 (א) גיל הקיצבה של דיין הוא שבעים שגה; ואולם אם היה רב                                                                            |
|ראשי לישראל או ראש אבות בתי דין, גיל הקיצבה הוא שבעים וחמש                                                                           |
|שנה.                                                                                                                                 |
|(ב) דיין יפרוש לקיצבה לפני גיל זה -                                                                                                  |
|(1) אם ביקש זאת בדרך שתיקבע בתקנות; או                                                                                               |
|(2) אם החליטה ועדת המינויים' על יסוד חוות דעת                                                                                        |
|רפואית, שמחמת מצב בריאותו נבצר ממנו למלא תפקידו."                                                                                    |

|ולדיינים, הוברר כי ההוראות בחוק לוקות בחסר. על כן מוצע להשלים את ההוראות בדבר                                                  |
