|1. בחוק השופטים, תשי"ג-1953  1(להלן - החוק), במקום סעיף 17 יבוא סעיף זה:                                            |החלפת סעיף 17        |
|17. (א) שופט יצא לקיצבה -                                                                      |"קיצבה               |                     |
|(1) בהגיעו לגיל שבעים;                                                                         |                     |                     |
|(2) בכל עת, אם החליטה ועדת המינויים, על יסוד חוות דעת                                          |                     |                     |
|רפואית' שמחמת מצב בריאותו נבצר ממנו למלא את תפקידו.                                            |                     |                     |
|(ב) שופט רשאי לצאת לקיצבה -                                                                    |                     |                     |
|(1) לאחר שכיהן עשרים שנה, אם הגיע לגיל ששים;                                                   |                     |                     |
|(2) לאחר שכיהן חמש עשרה שבה, אם הגיע לגיל ששים וחמש;                                           |                     |                     |
|(3) בכל עת' אם אישרה זאת ועדת המינויים לפי בקשתו.                                              |                     |                     |
|(ג) בחישוב תקופת כהונתו של שופט לענין סעיף קטן (ב) תצורף                                       |                     |                     |
|אליה כל תקופת שירותו במדינה או במוסד אחר שועדת הכספים של                                       |                     |                     |
|הכנסת אישרה אותו לעבין זה' או מקצתה של תקופה זו' בהתחשב עם כל                                  |                     |                     |
|תשלום או זכות שרכש לרגל פרישתו משירותו הקודם, הכל לפי כללים                                    |                     |                     |
|ותנאים שקבעה ועדת הכספים."                                                                     |                     |                     |

|דברי הסבר                                                                                                                                 |
|סעיף 17 לחוק השופטים קבע לאמר:                                                                                                            |
|"17 (א) גיל הקיצבה של שופט הוא שבעים שבה,                                                                                                 |
|(ב) שופט יפרוש לקיצבה לפני גיל זה -                                                                                                       |
|(1) אם ביקש זאת בדרך שתיקבע בתקנות; או                                                                                                    |
|(2) אם החליטה ועדת המינויים, על יסוד חוות דעת                                                                                             |
|רפואית' שמחמת מצב בריאותו בבצר ממבו למלא תפקידו'/                                                                                         |
|בדיוני ועדת הכספים שהתנהלו לאחרונה לשם קביעת שיעורי הגימלאות לשופטים,                                                                     |
|הוברר כי ההוראות בחוק לוקות בחסר. על כן מוצע להשלים את ההוראות בדבר גיל הפרישה                                                            |
|לקיצבה של שופטים (סעיף 1) . כן מוצע לקבוע בחוק שאם יועבר שופט מכהונתו' לא יהיה                                                            |
|זכאי בדרך כלל לגימלה. אולם במקרים שבהם יועבר שופט מכהונתו כיון ש"נהג שלא כהלכה                                                            |
|במילוי תפקידו" (סעיף 22 (א) (1)) או ש"התנהג באופן שאינו הולם את מעמדו של שופט                                                             |
|בישראל" (שם, פסקה (2)), והמקרים אינם חמורים עד כדי כך שמן הדין והצדק לשלול                                                                |
|את גימלתו' ניתנה סמכות מיוהדת לבית הדין להמליץ על תשלום הגימלה ועל שיעורה.                                                                |
