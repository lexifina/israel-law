|מתפרסמות בזה הצעות חוק מטעם הממשלה:                         |

|חוק מקרקעי העם, תשי"ט-1959                                      |

|1. בחוק זה מקרקעי העם - כמשמעותו בחוק-יסוד: מקרקעי העם 1 (להלן-חוק היסוד).                                               |הגדרה            |
|2. ואלה העסקאות שסעיף 2 לחוק היסוד לא יחול עליהן:                                                                        |היתר מכירה       |
|(1) פעולות רשות הפיתוח לפי חוק רכישת מקרקעים (אישור פעולות ופי-                                                          |                 |
|צויים), תשי"ג-1953 2;                                                                                                    |                 |
|(2) העברת זכות בעלות במקרקעי העם לטובת נפקדים הנמצאים בישראל                                                             |                 |
|תמורת מקרקעין שהוקנו לאפוטרופוס לנכסי נפקדים מכוח חוק נכסי נפקדים,                                                       |                 |
|תש"י-1950 3;                                                                                                             |                 |
|(3) העברת זכות בעלות במקרקעי העם למילוי התחייבות חוזית שנתחייבו                                                          |                 |
|בה כדין לפני תחילת חוק היסוד;                                                                                            |                 |
|(4) העברת זכות בעלות במקרקעין תמורת מקרקעין אחרים שהוחלפו בהם                                                            |                 |
|או שנרכשו לצרכי ציבור;                                                                                                   |                 |
|(5) מכירת מקרקעי העם או העברת זכות בעלות בדרך אוזרת' כמידה שיש                                                           |                 |
|בכך צורך ליישור גבולות או להשלמת נחלאות או למטרות אחרות כיוצא                                                            |                 |
|באלה' ובלבד ששטח המקרקעין בכל פעם אינו עולה על 100 דונם?                                                                 |                 |
|(6) העברת מקרקעי העם בין המדינה' רשות הפיתוח וקרן הקימת לישראל                                                           |                 |
|לבין עצמם;                                                                                                               |                 |
|(7) העברת מקרקעי המדינה או מקרקעי רשות הפיתוח למטרת פיתוח לא-                                                            |                 |
|חקלאי או העברת מקרקעין שהם קרקע עירונית. ובלבד ששטח כל ההעברות                                                           |                 |
|מכוח פסקה זו יחד לא יעלה על؀ࠂࠎࠐࠒ השטח שנקבע בסעיף 3 (4) (ג) לחוק רשות                                                    |                 |
|פיתוח (העברת נכסים), תש"י-1950 4.                                                                                        |                 |
|3. שרי האוצר והחקלאות ממונים על ביצוע חוק זה והם רשאים להתקין תקנות ככל                                                  |ביצוע ותקנות     |
|הנוגע לביצועו.                                                                                                           |                 |

|דברי הסבר                                                                                                                      |
|סעיף 2 להצעת חוק-יסוד: מקרקעי העם, הנמצא עתה על שולחן הכנסת אומר:                                                              |
|'"מקרקעי העם לא יימכרו וזכות הבעלות בהם לא תועבר בשום דרך אחרת.*                                                               |
|סעיף 3 לאותה הצעת חוק אומר:                                                                                                    |
|"סעיף 2 לא יחול על סוגי מקרקעין שהוצאו לענין זה, בחוק, מכלל מקרקעי העם ולא                                                     |
|יחול על סוגי עסקאות שנקבעו לענין זה בחוק."                                                                                     |
|החוק המוצע בא לקבוע את סוגי המקרקעין והעסקאות אשר עליהם לא יחול איסור                                                          |
|המכירה.                                                                                                                        |
|סעיף 3 (4) (ג) לחוק רשות פיתוח (העברת נכסים), תש"י-1950, המאוזכר כסעיף 2(7)                                                    |
|לחוק המוצע מגביל מכירת מקרקעין מן הסוג המדובר בו לשטח מקסימלי של מאה אלף                                                       |
