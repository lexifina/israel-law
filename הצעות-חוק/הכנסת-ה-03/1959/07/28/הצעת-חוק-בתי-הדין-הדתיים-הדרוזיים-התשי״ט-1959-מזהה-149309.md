|מתפרסמות בזה הצעות חוק מטעם הממשלה:                            |

|חוק בתי הדין הדתיים הדרוזיים, תשי"ט-1959                                              |

|1. בחוק זה-                                                                                                      |הגדרות                 |
|"בית דין" - בית דין דתי דרתי שהוקם בהכרזת הממשלה;                                                                |                       |
|"בית אין לערעורים" - בית דין דתי דרוזי לערעורים שהוקם בהכרזת הממשלה;                                             |                       |
|"דיין" - חבר בית דין דתי דרוזי או בית דין דרוזי לערעורים.                                                        |                       |
|2. (א) עניני נישואין וגירושין של חברי העדה הדרוזית בישראל, אזרחי המדינה או                                       |סמכות שיפוט            |
|תושביה' יהיו בשיפוטם הייחודי של בתי הדין.                                                                        |                       |
|(ב) בעניני המעמד האישי של חברי העדה הדרוזית, כמפורט בסעיף 51 לדבר-                                               |                       |
|המלך-במועצה על ארץ-ישראל, 1947-1922 1, או בפקודת הירושה2, אשר בהם אין לבית                                       |                       |
|דין שיפוט ייחודי לפי סעיף קטן (א), יהא לבית הדין שיפוט לאחר שכל הצדדים הנוגעים                                   |                       |
|בדבר הביעו הסכמתם לכך.                                                                                           |                       |
|(ג) בית הדין לערעורים ידון בערעורים על פסקי דין של בתי הדין.                                                     |                       |
|(ד) לבתי הדין ולבית הדין לערעורים יהיו הסמכויות המוענקות לבתי דין דתיים                                          |                       |
|בחוק בתי דין דתיים (הזמנה לבית הדין), תשט"ז-1956 3.                                                              |                       |
|3. בית הדין ידון בשלושה, ובית הדין לערעורים ידון במספר דיינים שלא יפחת משלושה.                                   |הרבב בית הדין          |
|4. הדיינים יתמנו על ידי נשיא המדינה לפי הצעת ועדת מינויים שתובא לפני הנשיא                                       |מינוי דיינים           |
|על ידי שר הדתות.                                                                                                 |                       |
|5. (א) ועדת המינויים (להלן - הועדה) תהיה של תשעה חברים: הראש הרוחני של                                           |ועדת המינויים          |
|העדה הדרוזית בישראל; חכם דת דרוזי שייבחר בדרך שתיקבע בתקנות; שר הדתות; שר                                        |                       |
|המשפטים וחבר אחר של הממשלה שייבחר על ידיה; שני חברי כנסת, אם אפשר חברי                                           |                       |
|העדה הדרוזית, שייבחרו על ידי הכנסת בבחירה חשאית ויכהנו כל עוד הם חברי הכנסת.                                     |                       |
|ואם תמה כהונת הכנסת - עד שתיבחר הכנסת החדשה חברים אחרים במקומם; שני עורכי-                                       |                       |
|דין העובדים במקצועם שייבחרו על ידי המועצה המשפטית לשלוש שנים.                                                    |                       |
|(ב) הרכב הועדה יפורסם ברשומות,                                                                                   |                       |
|(ג) שר הדתות יהיה יושב ראש הועדה.                                                                                |                       |
|(ד) הועדה תוכל לפעול אף אם פחת מספר חבריה, כל עוד לא פחת מששה.                                                   |                       |
|6. (א) ראה שר הדתות שיש למנות דיין, יודיע על כך ברשומות ויכנס את הועדה.                                          |סדרי עבודת             |
|(ב) אלה רשאים להציע מועמדים: שר הדתות; הראש הרוחני של העדה הדרוזית                                               |הועדה                  |
|בישראל; שלושה חברי הועדה כאחד.                                                                                   |                       |
|(ג) הצעת הועדה על מינויו של דיין תהיה על דעת רוב חבריה שהשתתפו בהצבעה.                                           |                       |
|(ד) שאר סדרי דיוניה ועבודה של הועדה ייקבעו על ידיה.                                                              |                       |
|7. מי שנתמנה דיין חייב, בטרם ישב בדין, להצהיר בפני נשיא המדינה הצהרה זו:                                         |הצהרת אמונים           |
|"אני מתחייב לשמור אמונים למדינת ישראל ולחוקיה, לשפוט את העם                                                      |                       |
|משפט צדק, לא להטות משפט ולא להכיר פנים".                                                                         |                       |

|18. (א) בית הדין המשמעתי יביא את מסקנותיו, לזכות או לחובה, לפני שר הדתות.                                              |מסקנות בית הדין     |
