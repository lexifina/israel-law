|מתפרסמת בזה הצעת חוק מטעם הממשלה :                   |

|חוק לתיקון פקודת המועצות המקומיות (מס' 3), תשי"ט-1959                                            |

|1, בסעיף 6 לפקודת המועצות המקומיות, 11941, בסופו, יבואו מלים אלה:                                                |תיקון סעיף 6       |
|"אולם על גביית דמי השתתפות בהוצאותיה של המועצה לביצוע עבודה                                                      |                   |
|על פי הוק עזר, יחולו ההוראות שבתוספת השלישית לפקודת העיריות,                                                     |                   |
|21934, בשינויים המחוייבים לפי הענין."                                                                            |                   |
|2. תחילתו של חוק זה היא ביום תחילתו של חוק לתיקון פקודת העיריות (מס' 17),                                        |תחילה              |
|תשי"ט-.1959                                                                                                      |                   |
|דברי הסבר                                                                                                        |                   |
|סעיף 6 לפקודת המועצות המקומיות, 1941, קובע, כי כל תשלומי החובה המשתלמים                                          |                   |
|למועצה מקומית - כגון היטלים, אגרות ודמי השתתפות בהוצאות עבודות המועצה -                                          |                   |
|חוץ מארנונות - ייגבו על ידי המועצה בדרך שעיריה גובה את האגרות המגיעות לה,                                        |                   |
|היינו, בהגשת תובענה לבית המשפט.                                                                                  |                   |
|אך בינתיים הציעה הממשלה חוק לתיקון פקודת העיריות (מס' 17), תשי"ט-1959 3,                                         |                   |
|לפיו יינתן לעיריות לגבות אגרות, היטלים ודמי השתתפות בהוצאות עבודות העיריה                                        |                   |
|מכוח חוק עזר באותה דרך שבה גובים את האתונות העירוניות, דהיינו על ידי עיקולים                                     |                   |
|מינהליים, ללא צורך בהגשת תביעה משפטית. לגביית דמי השתתפות בהוצאות עבודות                                         |                   |
|העיריה מכוח חוק עזר נקבע גם הסדר מיוחד, שלפיו ניתנת לחייב זכות ערר על דרישת                                      |                   |
|התשלום הקודמת לעיקול המינהלי, והערר יתברר לפני ועדת ערר, שהרכבה ודרכי הבירור                                     |                   |
|שלה נקבעו בתוספת השלישית המוצעת בתיקון האמור, ועל החלטתה של הועדה ניתנת                                          |                   |
|זכות ערעור לבית המשפט המחוזי.                                                                                    |                   |
|התוצאה של התיקון האמור בפקודת העיריות ؀ࠂࠌࠎתהיה איפוא, שגם כל תשלומי החובה                                        |                   |
|המגיעים למועצה מקומית יינתנו לגביה בדרך של עיקולים מינהליים, ללא צורך בהגשת                                      |                   |
|תובענה. אולם מאחר שסעיף 6 לפקודת המועצות המקומיות, 1941, מצמיד את דרכי הגביה                                     |                   |
|של כל תשלומי החובה במועצות לדרכי הגביה של אגרות בעיריות, ולגבי אגרות אין                                         |                   |
|זכות ערר וערעור, נמצא שהחייב בדמי השתתפות בהוצאות עבודה של מועצה מקומית                                          |                   |
|משולל אותה זכות ערר וערעור הניתנת בעיריות לחייב בדמי השתתפות כאלה.                                               |                   |
|כדי למנוע הפליה לרעה זו, בא התיקון המוצע לסעיף 6 ומבטיח, כי דרכי הערעור                                          |                   |
|המוצעים לענין החיוב בדמי השתתפות בהוצאות עבודות העיריה יהיו נוהגים גם במועצות                                    |                   |
|המקומיות.                                                                                                        |                   |
