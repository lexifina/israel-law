|חוק הבחירות לכנסת (תיקון), תשי''ט-1959                                                |

|1. בחוק הבחירות לכנסת, תשי"ט-1959  1(להלן - חוק הבחירות), בכותרת לפרק                                              |תיקון הכותרת        |
|השביעי, יווסף בסופה "ושוטרים".                                                                                     |לפרק שביעי          |
|2, בסוף הפרק השביעי לחוק הבחירות יווסף סעיף זה:                                                                    |הוספת סעיף 56א      |
|56א. (א) לא יאוחר מ-14 יום לפני יום הבחירות ימציא שר המשטרה                                  |"הצבעה של           |                    |
|ליושב ראש הועדה המרכזית רשימה, שתפרט את שמו של כל שוטר                                       |שוטרים              |                    |
|הכלול בפנקס הבוחרים לכנסת ואשר ביום הבחירות יוצב, לשם מילוי                                  |                    |                    |
|תפקידו, מחוץ לישוב שרשימות הבוחרים של אזורי הקלפי שבתחומו                                    |                    |                    |
|כוללות את שמו.                                                                               |                    |                    |
|(ב) הרשימה תציין ליד שמו של כל שוטר את אזור הקלפי                                            |                    |                    |
|שרשימת הבוחרים שלו כוללת את שמו, תפרט את כל הפרטים המתייחסים                                 |                    |                    |
|אליו כפי שהם רשומים באותה רשימת בוחרים, ותציין את אזור הקלפי                                 |                    |                    |
|שבתחומו יוצב השוטר ביום הבהירות כאמור.                                                       |                    |                    |
|(ג) יושב ראש הועדה המרכזית ימחוק את השמות הכלולים                                            |                    |                    |
|ברשימה כאמור בסעיף קטן (א) מרשימות הבוחרים בהן הם רשומים,                                    |                    |                    |
|יוסיף אותם לרשימות הבוחרים של אזורי הקלפי שבתחומם יוצבו השוט-                                |                    |                    |
|רים ויודיע על כך בכתב לכל שוטר הנוגע בדבר."                                                  |                    |                    |

|דברי הסבר                                                                                                          |
|תפקידי המשטרה לשמירת הסדר ביום הבחירות ؀ࠂࠎࠐࠒלכנסת מחייבים הוצאת שוטרים                                             |
|מהישובים בהם הם גרים והצבתם כישובים אחרים.                                                                         |
|בהתאם לסעיף 4 (ב) לחוק הבחירות לכנסת' תשי''ט-1959, רשאי בוחר להצביע                                                |
|רק בקלפי אשר רשימת הבוחרים הקשורה אליה כוללת את שמו, בהתאם לחוק פנקס הבו-                                          |
|חרים לכנסת, תשי"ט-כ1959 2,לול שמו של כל שוטר, ככל יתר האזרחים, ברשימת הבוחרים                                      |
|של אזור קלפי שבתחום הישוב בו הוא תושב.                                                                             |
|מוצע, על כן, לאפשר לשוטרים, שיוצבו ביום הבחירות בישובים שאין הם תושבים                                             |
|בהם, להצביע במקום משמרתם. הדבר ייעשה על ידי תיקון רשימות הבוחרים בידי יושב                                         |
|ראש ועדת הבחירות המרכזית על סמך רשימה שתוגש לו על ידי שר המשטרה לא יאוחר                                           |
|מארבעה עשר יום לפני יום הבחירות. יושב ראש ועדת הבחירות המרכזית יודיע על התיקון                                     |
|בכתב לכל שוטר הנוגע בדבר.                                                                                          |
