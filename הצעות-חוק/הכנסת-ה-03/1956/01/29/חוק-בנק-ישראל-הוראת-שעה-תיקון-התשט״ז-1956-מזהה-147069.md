חוק בנק ישראל (הוראת שעה) (תיקון), תשט"ז-1956

|ן. בסעיף (1) לחוק בנק ישראל (הוראת שעה), תשט"ו-1955, יימחקו המלים "אך לא                               |תיקון החוק         |
|יאוחר מיום כ"א בשבט תשט"ז (3 בפברואר 1956)" .                                                          |                   |
|דברי הסבר                                                                                              |                   |
|י בשלהי תשט"ו נתקבל בכנסת חוק בנק ישראל (הוראת שעה)' תשט"ו-1955, אשר                                   |                   |
|הסמיך את הממשלה' באישור ועדת הכספים של הכנסת, להכניס את סעיף 78 לחוק בנק                               |                   |
|ישראל' תשי"ד-1954,תקפו אף לאחר תום שנה מיום תחילת חוק בנק ישראל; תשי"ד-                                |                   |
|1954 ,אך לא יאוחר מאשר ביום כ"א בשבט תשט"ז (3 בפברואר 1956).                                           |                   |
|נגיד בנק ישראל הגיע עתה לידי החלטה שלא להשתמש בסמכותו לפי סעיף 56                                      |                   |
|לחוק בנק ישראל' תשי"ד-1954, לקבוע את שער הריבית, לאחר שהממשלה עומדת להציע                              |                   |
|לכנסת חוק ריבית כללי אשר יחול על בנקים. ועל כל יתר המלווים והלווים גם יחד.                             |                   |
|- . רק במקרה וקבלת החוק הכללי תתעכב מסיבה זו או אחרת' יצטרך הנגיד לשקול                                |                   |
|מחדש בדבר؀ࠂࠊࠌ שימוש בסמכותו האמורה ; ולצורך זה מציעה הממשלה להשאיר את חוק בנק                          |                   |
|ישראל (הוראת שעה)' תשט"ו--1955, בתקפו, אך להוציא מתוכו את גבול הזמן. התוצאה                            |                   |
|תהיה כי כל עוד לא נתקבל חוק חדש על הריבית, יישאר בתקפו החוק העותמני על. הריבית,                        |                   |
|הקובע שער ריבית מכסימלית של תשעה אחוזים למאה לשנה.                                                     |                   |
