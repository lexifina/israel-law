 חוק העיריות (אישור פעולות), תשט"ז-1956

|פרשנות           |1. בחוק זה תהא לכל מונח המשמעות שיש לו בפקודת העיריות, 1934 1 (להלן -                                  |
|                 |הפקודה), וייקרא עמה כאחד אם אין כוונה אחרת משתמעת.                                                     |
|אישור פרסום      |2. פרסמה מועצה בתחום העיריה, לא יאוחר מיום י"ט בניסן תשט"ז.(31 במרס 1956),                             |
|הודעות           |הודעה בדבר הטלת ארנונות לשנת הכספים 1956/57 ובדבר שיעורן ומועדי שילומן של                              |
|ארנונות          |ארנונות כאמור, רואים את. הפרסום, לענין סעיף 102 (ג) לפקודה, כאילו נעשה כדין.                           |
|! י              |ד ב ר י ה מ ב ר                                                                                        |
|ו                |לפי סעיף 102 (ג) לפקודת העיריות, 1934, חייבת מועצת עיריה לפרסם בתחום                                   |
|                 |עיריה, לא יאוחר מיום 15 במרס שלפני כל שנת כספים שלגביה הוטלו ארנונות, הודעה                            |
|                 |בדבר הטלת האתונות, שיעורן ומועדי שילומן. הדיונים בדבר הנחיות לשיטת המסים של                            |
|                 |הרשויות המקומיות ובדבר היקף המענק שיעמוד לרשותן בשנת הכספים 1956/57 - לא                               |
|                 |נשלמו בעוד ؀ࠂࠌࠎࠒࠖ࠘מועד לאפשר לרשויות המקומיות לקבוע עד ל-15 במרס 1956 את האתונות                       |
|                 |ואת דרך הטלתן בשנת הכספים 1956/57. אולם למעשה הגישו כל העיריות לשר הפנים                               |
|                 |את החלטותיהן בדבר הטלת האתונות לשנת הכספים האמורה ושר הפנים אישרן לפני 31                              |
|                 |במרס 1956, ואף עלה בידי העיריות לפרסם בתחומיהן עד אותו תאריך את ההודעות                                |
|                 |הדרושות.                                                                                               |
|                 |על כן, בא החוק המוצע ליתן תוקף חוקי להודעות אלה לגבי שנת הכספים 1956/57'                               |
|                 |אף-על-פי שנתפרסמו לאחר 15 במרס.                                                                        |
