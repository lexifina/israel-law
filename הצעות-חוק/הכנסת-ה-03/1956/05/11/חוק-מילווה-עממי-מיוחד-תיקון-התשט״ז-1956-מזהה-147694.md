|העממי המיוחד, תשט"ו-1955 2 (להלן - התקנות).                                                                 |               |

|בעיקר בגלל ריכוז הזכויות במקומות מסויימים, וכן בידי אנשים המחזיקים במספר אגרות                              |               |

|הקובעת שאגרות החוב הנפדות בתוספת פרס יעלו לראשונה, הוראה המקשה על האפשרות                                   |               |
|לקבוע שיטת הגרלה אחרת.                                                                                      |               |

|התקנות על אף ההוראה שבסעיף 18 לחוק הקובעת' כי התקנות הנוגעות לשיטת ההגרלה                                   |               |
