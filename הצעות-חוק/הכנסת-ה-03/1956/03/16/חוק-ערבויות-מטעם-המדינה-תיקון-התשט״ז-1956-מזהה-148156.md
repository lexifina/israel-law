מתפרסמות בזה הצעות חוק מטעם הממשלה:

חוק ערבויות מטעם המדינה (תיקון), תשט"ז-1956

|1. בסעיפים 1 ו-2 לחוק ערבויות מטעם המדינה' תשי"ד-1954 1, לאחר "1955/56"                                  |תיקון סעיפים   |
|יווסף "1956/57".                                                                                         |. נ ו-2        |
|דברי הסבר                                                                                                |               |
|חוק ערבויות מטעם המדינה, תשי"ד-1954,  הרשה את שר האוצר באישור ועדת                                       |               |
|הכספים של הכנסת, לערוב, בשם מדינת ישראל למילווה או להתחייבות כספים אחרת, אשר                             |               |
|לדעתו נועדו לשמש לפיתוח או לעידוד של ענף משק בעל חשיבות כלכלית או לסייע לכל                              |               |
|תכלית אחרת שיש בה ענין לכלל, בהגבלות המפורטות בחוק.                                                      |               |
|תחולת החוק האמור הוגבלה תחילה לשנת הכספים 1954/55 ולאחר מכן הוארכה                                       |               |
|בחוק ערבויות מטעם המדינה (תיקון)' תשט"ו-1955 2, גם לשנת הכספים 1955/56.                                  |               |
|משרד האוצר הכין ושלח למשרדי הממשלה הצעת-תזכיר לחוק של קבע בענין                                          |               |
|ערבויות מטעם המדינה, אולם השינויים והחידושים שבהצעת-התזכיר האמורה דורשים                                 |               |
|עיון, וההצעה תוגש לממשלה עם ؀ࠂࠌࠎליבון הבעיות הדורשות בירור נוסף.                                         |               |
|היות ותקפו של חוק הערבויות הנוכחי פג ביום 31.3.56, והיות והדיונים בהצעה                                  |               |
|החדשה לא יוכלו כנראה להסתיים ולעבור את כל שלבי החקיקה עד התאריך האמור, מוצע                              |               |
|בזה להאריך לתקופה של שנה נוספת את החוק הקיים.                                                            |               |

1 ס"ח 102, תשי"ד, עמ' 171.
