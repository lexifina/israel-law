|                |כתב-אישום.                                                                                                |
|טענות שלפני     |2. על-אף האמור בכל דין אחה משנסתיימה פרשת הסניגורית במשפט פלילי, רשאי                                     |
|ההרשעה          |היועץ המשפטי לממשלה או בא כוחו לסכם תחילה את טענות הקטיגוריה, ולאחר מכן רשאי                              |
|                |הנאשם או בא כוחו לסכם את טענות הסניגורית,                                                                 |
|טענות שלאחר     |3. על אף האמור בכל דין אחר, משהורשע נאשם בדינו במשפט פלילי, רשאי היועץ                                    |
|ההרשעה          |המשפטי לממשלה או בא כוחו לטעון טענותיו לענין גזר הדין, ולאחריו רשאים הנאשם ובא                            |
|                |כוחו לטעון טענותיהם לענין גזר הדין.                                                                       |
|                |דברי הסבר                                                                                                 |
|                |במשפטים פליליים המתנהלים בבתי המשפט השונים, סדרי הטענות בסיכומים                                          |
|                |שלפני ההרשעה ובסיכומים שלפני הטלת העונש אינם שווים. בו בזמן שבבית משפט שלום                               |
|                |יש לנאשם תמיד זכות המלה האחרונה (תקנות 272 ו-274 לתקנות הפרוצידורה בבתי משפט                              |
|                |השלום, 1940) 1 הרי בבית משפט מחוזי בשפיטה על פי כתב אישום, ניתנת זכות המלה                                |
|                |האחרונה לקטיגור דוקא (סעיפים 42 ו-45 לפקודת הפרוצידורה הפלילית (שפיטה- על פי                              |
|                |כתב אישום) 2; ואולם בבית משפט מחוזי בשפיטה בדיון דחוף, ؀ࠂࠈזכות המלה האחרונה ניתנת                         |
|                |לנאשם לפני ההרשעה ולקטיגור לפני הטלת העונש (תקנות 18 ו-23 לתקנות בתי משפט                                 |
|                |מחוזיים (דיון דחוף), 31938.                                                                               |
