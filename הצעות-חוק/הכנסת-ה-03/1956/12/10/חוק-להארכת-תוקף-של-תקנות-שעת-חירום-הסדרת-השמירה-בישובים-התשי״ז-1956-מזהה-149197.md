|1. בתקנה 3 לתקנות' במקום המלים "תקים באותו חוק עזר ועדת שמירה וועדת עררים"                                    |תיקון הקנה 3    |
|יבואו המלים "תקים באותו חוק עזר, לאזורה כולו או לכל חלק ממנו לחוד כפי שתקבע בחוק                              |                |

|3א. מי שקיים חובת שמירה המוטלת עליו מכוח חוק עזר לפי תקנה 3 .                          |,,תחולת חוק           |                |
|ונפגע תוך כדי קיום חובת השמירה ועקב קיומה' דינו כדין נפגע ספר                          |הגימלאות              |                |
|כמשמעותו בחוק הגימלאות לנפגעי ספר, תשי"ז-1956 2, ודין הפגיעה                           |לזפגעי ספר            |                |
|כדין פגיעת ספר כמשמעותה בחוק האמור."                                                   |                      |                |
|דברי הסבר                                                                                                     |                |
|ביום ט"ז באייר תשט"ז (27 באפריל 1956) התקין שר הפנים תקנות-שעת-חירום                                          |                |
|שמטרתן לאפשר לישובים להטיל את חובת השמירה על תושביהם. הכנסת האריכה את                                         |                |
|תקפן של ؀ࠂࠊࠌתקנות אלה עד סוף שנה זו. הצורך בתקנות אלה בעינו עומד' ולכן מציעה הממשלה                           |                |
|להאריך את תקפן לשנה נוספת.                                                                                    |                |
|יחד עם זאת נתגלה הצורך להבטיח ליוצאים לשמירה, מכוח חיוב על פי התקנות,                                         |                |
|ולמשפחותיהם פיצוי במקרה של פגיעות בשעת השמירה. במידה והשמירה היא בישובי                                       |                |
|ספר שחל עליהם חוק הגימלאות לנפגעי ספר, תשי"ז-1956, קיים הסדר לפי החוק ההוא.                                   |                |
|החוק המוצע בא להשוות את הפגיעות בשעת השמירה מכוח התקנות במקום כל שהוא בארץ                                    |                |
|לפגיעות בספר ולהעניק לנפגעים ולמשפחותיהם את הזכויות של נפגעי ספר לפי חוק                                      |                |
|הגימלאות לנפגעי ספר, תשי"ז-1956.                                                                              |                |
|בזמן האחרון נתגלה הצורך בהסדר השמירה גם בישובים עירוניים מסויימים.                                            |                |
|במקומות כאלה יהיה צורך בפיזור הסמכויות של ועדות השמירה ושל ועדות העררים,                                      |                |
|לאזורים מסויימים של ישובים אלה. החוק המוצע בא לאפשר פיזור כאמור.                                              |                |
