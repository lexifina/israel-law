מתפרסמת בזה הצעת חוק מטעם הממשלה:

חוק לתיקון פקודת הרשויות המקומיות (מס עסקים), תשט"ז-1956

|1. פקודת הרשויות המקומיות (מס עסקים), 1945 1, תתוקן כך:                                                  |תיקח סעי!* 3     |
|בסעיף 3 2, במקום המלים "אלף לירות ישראליות"" בכל מקום שהן מצויות בו.                                     |                 |
|יבואו המלים "אלפיים לירות ישראליות".                                                                     |                 |
|2* י רשות מקומית הבאה לתקן חוק עזר שנתנה לפי הפקודה ולהגדיל את מם העסקים                                 |תחי5ה            |
|בתוקף הוראות חוק זה' לא תקבע תחילתו של התיקון בתאריך. מוקדם מתחילת חוק זה.                               |                 |
|דברי הסבר                                                                                                |                 |
|החוק המוצע מעלה את השיעור המכסימלי של מם העסקים שרשויות מקומיות                                          |                 |
|רשאית להטילו, מ-1000 לירות ל-2000 לירות לשנה. בהעלאה זו יש צורך כדי לסייע בידי                           |                 |
|הרשויות המקומיות לאזן את תקציביהן.                                                                       |                 |
|השיעור המכסימלי של המס הועלה פעמים אחדות מאז פורסמה הפקודה הקיימת                                        |                 |
|בשנת 1945. בשנת 1948 עמד על 120 לירות לשנה, אחרי קום המדינה תיקנה הכנסת את                               |                 |
|הפקודה והעמידה את המכסימום על סכום של 250 לירות (תיקון משנת תש"ט-1949),                                  |                 |
|ואחרי כן על 1000 לירות (תיקון משנת תשי"ב-1952). כל העלאות אלו היו מחוייבות                               |                 |
|על פי הצורך לעזור לרשויות המקומיות לאזן את תקציביהן.                                                     |                 |
|בשנת הכספים 1954/55 היתה ההכנסה ממס זה (שבאה מ-63946 בתי ؀ࠂࠎࠐࠒעסק) -                                     |                 |
|3,428,418 לירות. ההכנסה בשנת הכספים 1955/56 היא, לפי האומדן, 3,714,515 לירות.                            |                 |
|לפי שיעורי המס המוטלים על ידי חוקי העזר הקיימים של הרשויות המקומיות,                                     |                 |
|יוצא כי -                                                                                                |                 |
|57,449 בתי עסק (89,8%) משלמים מס עד 100 לירות ;                                                          |                 |
|4,208 בתי עסק (6,6%) משלמים מס מ-101 עד 250 לירות ;                                                      |                 |
|1,422 בתי עסק (2,2%) משלמים מס מ-251 עד 500 לירות ;                                                      |                 |
|887 בתי עסק (1,4%) משלמים מס מ-501 עד 1000 לירות.                                                        |                 |
|.. העלאת השיעור המכסימלי מ-1000 לירות ל-2000 לירות, כפי שמוצע כעת, תגדיל                                 |                 |
|את ההכנסה ממס העסקים, לפי האומדן, בסכום נוסף של 1.500,000 לירות לשנה בקירוב.                             |                 |
