|1 . אחרי סעיף 122 לפקודת העיריות 1 יבוא:                                                                   |הוספת סעיף        |
|                                                                                                           |122א              |
|122א. (א) חבר מועצה, בן זוגו, סוכנו או שותפו או תאגיד שיש לאחד                       |"איסור התקשרות       |                  |
|מהאמורים חלק העולה על עשרה אחוזים בהונו או ברווחיו, או שאחד                          |בחוזים               |                  |
|מהם מנהל בו, לא יהיה צד לחוזה או לעסקה עם העיריה.                                    |                     |                  |
|(כ) הוראת סעיף קטן (א) לא תחול -                                                     |                     |                  |
|(1) לגבי חוזה בדבר מתן שירות מהשירותים שהעיריה                                       |                     |                  |
|מספקת לתושביה, לאחד מהמנויים בסעיף קטן (א);                                          |                     |                  |
|(2) לגבי הסכם בהליכי רכישה לפי פקודת הקרקעות (רכי-                                   |                     |                  |
|שה לצרכי ציבור), 21943, או בהליכי העברת מקרקעין כמקום                                |                     |                  |
|רכישה כאמור;                                                                         |                     |                  |
|(3) לגבי חוזה או עסקה שהמועצה ברוב חבריה ובאישור                                     |                     |                  |
|השר התירה ובתנאים שהתירה? הודעה על מתן היתר כאמור                                    |                     |                  |
|תפורסם ברשומות.                                                                      |                     |                  |
|(ג) העובר ביודעין על הוראות סעיף קטן גא), דינו - מאסר                                |                     |                  |
|שנה אחת או קנס חמישים אלף לירות או פי שלושה משוויה של טובת                           |                     |                  |
|ההנאה שהושגה על ידי העבירה או שלושת הענשים כאחד.                                     |                     |                  |
|(ד) חוזה שנערך בניגוד להוראות סעיף זה ניתן לביטול על פי                              |                     |                  |
|החלטת המועצה ברוב חבריה ובאישור השר, ובלבד שלא יהיה בביטול                           |                     |                  |
|החוזה כדי לגרוע מזכויות צד שלישי שנרכשו בתום לב.                                     |                     |                  |
|(ה) לענין סעיף זה, דין התקשרות עם תאגיד שלעיריה שליטה                                |                     |                  |
|בו כדין התקשרות עם העיריה ; לענין זה, שליטה - כמשמעותה לפי סעיף                      |                     |                  |
|2 לחוק מס שבח מקרקעין, תשכ"ג-1963 3.                                                 |                     |                  |
|(י) הוראות סעיף זה לא יחולו על התקשרויות שנעשו לפני                                  |                     |                  |
|תחילת כהונתו של חבר המועצה שבשלו חל האיסור.                                          |                     |                  |
|(ז) אין בהוראות סעיף זה כדל לגרוע מהוראות סעיף 122."                                 |                     |                  |
|2. הוראות סעיף 122א לפקודה לא יחולו על התקשרויות שנעשו לפני קבלת חוק זה בכנסת.                             |הוראת מעבר        |

|דברי הסבר                 |

|בפקודת העיריות אינה קיימת הוראה האוסרת על                  |
|חבר מועצת עיריה להתקשר בחוזים ועסקאות עם                   |
|העיריה. ההגבלה היחידה בנושא זה מצויה בסעיף                 |
|12؀ࠂࠐࠒࠔ2 לפקודת העיריות, הקובע שחבר מועצה שיש לו,          |
|במישרין או בעקיפין, חלק או טובת הנאה בחוזה או עסק          |
|שנעשה עם העיריה, חייב להודיע על כך למועצה, ונאסר           |
|עליו להשתתף בדיונים ובהצבעה בקשר לאותו חוזה או             |
|עסק. יש הגורסים כי חובת הודעה זו מקנה דווקא יתרון          |
|מסויים לחבר המועצה.                                        |
|בעיריות נצטבר נסיון רב על השלילה שיש בקיומן של             |

|יחסים חוזיים ועסקיים בין העיריה לבין אחד מחברי               |
|המועצה ועל לזות השפתיים הכרוכה ביחסים כאלה.                  |
|מוצע איפוא להגביל את האפשרות של התקשרות                      |
|חוזית או עסקית בין עיריה לבין חבר המועצה או גורמים           |
|אחרים שלחבר המועצה יש אינטרס אישי ישיר בעסקיהם.              |
|בנוסף לעונש שיוטל על העובר על הוראות החוק,                   |
|מוצע כי חוזה שייערך בניגוד להוראות המוצעות יהיה              |
|ניתן לביטול בהחלטת מועצת העיריה שתתקבל ברוב                  |
|חברי המועצה ובאישור שר הפנים, ובלבד שביטול החוזה             |
|לא יפגע בזכויות צד שלישי שהושגו בתום לב,                     |
|חבר הכנסת חיים קורפו                                         |
