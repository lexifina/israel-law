|חוק-יסוד: הכנסת (תיקון מס' 6)                          |

|1. במקום סעיף 24 לחולק -יסוד: הכנסת 1 יבוא:                                                                 |החלמת סעיף 24         |
|24. (א) הכנסת תדון ותחליט בכל מספר חברים; ואולם המנין החוקי                               |"מנין            |                      |
|להחלטות הכנסת בקריאה השניה ובקריאה שלישית של הצעות חוק הוא                                |                 |                      |
|עשרים וחמישה חברים.                                                                       |                 |                      |
|(ב) קבע יושב ראש- הישיבה, על פי דרישה של חמישה חברי                                       |                 |                      |
|הכנסת הנוכחים באולם המליאה, ואם נכחו פחות מחמישה - על פי                                  |                 |                      |
|דרישת אחד מהם, כי לא נכח מנין חוקי כאמור בסעיף קטן (א), לא                                |                 |                      |
|תקויים ההצבעה, והיא תידחה לישיבה הרגילה הקרובה של הכנסת. .                                |                 |                      |
|(ג) אישר יושב-ראש הישיבה בכתב כי נכח מנין חוקי כאמור                                      |                 |                      |
|בסעיף קטן (א), יהיה האישור ראיה מכרעת לקיומו של אותו מנין.                                |                 |                      |
|(ד) לא היתה. דרישה כאמור בסעיף קטן (ב), תחליט הכנסת, על                                   |                 |                      |
|אף האמור בסעיף קטן (א), בכל מספר חברים אף בקריאה שניה ובקריאה                             |                 |                      |
|שלישית של הצעת חוק.                                                                       |                 |                      |
|גירסה א'                                                                                                    |                      |
|ללא סעיף קטן (ה).                                                                                           |                      |
|גירסה בי                                                                                                    |                      |
|(ה) הוראת סעיף קטן (א) לענין מנין חוקי לא תחול על הצעת                                                      |                      |
|חוק שהציע חבר הכנסת."                                                                                       |                      |

|דברי הסבר            |

|הצעה זו באה להסדיר נושא שנדון במשך שנים רבות,              |
|הן בציבור והן בין חברי הכנסת - ענין המנין החוקי בי-        |
|؀ࠂࠒࠔࠖࠤשיבות הכנסת. התברר שבמרבית הפרלמנטים במדינות         |
|דמוקרטיות בעולם קיים הסדר לגבי קוורום (לדוגמה              |
|אנגליה, ארצות הברית, גרמניה המערבית, צרפת).                |

|יתירה מזו, ברוב המוסדות הפועלים במדינה על פי                  |
|חוקיה (כגון רשויות מקומיות וגופים נבחרים אחרים)               |
|קיימת הוראה לענין מנין חוקי. לא יתכן כי דוקא הכנסת            |
|תהיה פטורה מחובה זו, ומוצע לכן להנהיג גם בה הסדר              |
|בענין זח, לפחות בהצבעות בקריאה שניה ושלישית של                |
|הצעות חוק.                                                    |
