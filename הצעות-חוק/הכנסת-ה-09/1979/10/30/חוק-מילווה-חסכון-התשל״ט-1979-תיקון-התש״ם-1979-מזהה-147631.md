|חוק מילווה חסכון, תשל"ט-1979 (תיקון), תש"ם-1979                                      |

|תיקון סעיף 3        |1, בסעיף 3 לחוק מילווה חסכון, תשל"ט-1979 1, האמור בו יסומן (א) ואחריו יבוא:                                   |
|                    |"(ב) מעביד ששילם הכנסת עבודה בעד עבודה באחד מאלה יהיה                                                         |
|                    |פטור ממילווה בשל אותה הכנסה:                                                                                  |
|                    |(1) במפעל תעשייתי שעיקר פעילותו בשנת המס היא פעי-                                                             |
|                    |לות ייצורית כמשמעותה בחוק עידוד התעשיה (מסים),                                                                |
|                    |תשכ"ט-1969 2;                                                                                                 |
|                    |(2) במשק חקלאי המשמש בעיקר לייצור תוצרת חקלאית                                                                |
|                    |לרבות צמחים ובעלי חיים;                                                                                       |
|                    |(3) בהובלת נוסעים או בהובלת מטענים ביבשה' בים או                                                              |
|                    |באויר;                                                                                                        |
|                    |(4) בעבודות בניה' לרבות עבודות חפירה' ביוב' סלילת                                                             |
|                    |כבישים ודרכים, עבודות עפר ועבודות הקשורות בהכנה                                                               |
|                    |לבניה ובהשלמתה;                                                                                               |
|                    |(5) בניהול בית מלון, פנסיון, בית מרגוע או בית אירוח."                                                         |
|תחילה               |2. תחילתו של חוק זה ביום י' בתשרי תש"ם (1 באוקטובר 1979).                                                     |

|דברי הסבר            |

|מטרתו של התיקון המוצע היא ביטול מילווה חסכון,                 |
|؀ࠂࠐࠒࠔתשל"ט-1979, על הענפים היצרניים במשק, וזאת כדי            |
|להקל על קשיי המילות והאשראי של ענפים מועדפים                  |
|אלה ולהגביר את כושר התחרות שלהם במשק.                         |
|לביטול מילווה חסכון האמור על המעסיקים בענפ-                   |
|התעשיה, החקלאות, התחבורה, הבניה והתיירות אץ                   |

|השפעה משמעותית על ההכנסות הריאליות של אוצר                  |
|המדינה, מכיון שהתנאים הנוכחים של המילווה הם טובים           |
|ודומים לתנאי השוק. לפי הערכת משרד האוצר ובנק                |
|ישראל ניתן יהיה לכסות את הקטנת הגביה ממילווה                |
|החסכון המוצע על ידי הנפקת מילווה מרצון בסכום                |
|דומה. זאת ועוד, ביטול מילווה החסכון על הענפים               |
|האמורים יביא לחסכון בהוצאות מינהליות.                       |
