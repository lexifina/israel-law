|מתפרסמת בזה מטעם הממשלה הצעת חוק לתיקון פקודת המשטרה :                                                                  |
|מבוא                                                                                                                    |
|בית המשפט העליון, בבג"צ 789/78 ,פסק כי המסגרת החוקית שבה הטיל המפקח                                                     |
|הכללי איסור על התארגנות שוטרים איבנה המסגרת המתאימה וכי המפקח הכללי לא היה                                              |
|מוסמך לאסור התארגנות בפקודת קבע.                                                                                        |
|מטרת החוק המוצע היא -                                                                                                   |
|(א) להקנות לשר הפנים באישור ועדת הפנים ואיכות הסביבה של הכנסת, סמכות                                                    |
|להתקין תקנות, שיש בהן שלילת זכות מוקנית בדין, כמו הזכות להתארגן בארגון                                                  |
|עובדים, אם הדבר דרוש לפעולה התקינה של המשטרה;                                                                           |
|(כ) למען מנוע ספק - להקנות תוקף לפקודות קבע מגבילות שהוציא בעבר המפקח                                                   |
|הכללי, הדרושות כדי להבטיח את פעולתה התקינה של המשטרה ושבלעדיהן לא תוכל                                                  |
|המערכת המשטרתית לתפקד כיאות.                                                                                            |

|חוק לתיקון פקודת המשטרה (מס' 6), תשל"ט-1979                                      |

|1. אחרי סעיף 94 לפקודת המשטרה [נוסח חדש], תשל"א-11971 (להלן - הפקודה),                                   |הוספת סעיף 94א       |
|יבוא:                                                                                                    |                     |
|94א. ראה השר כי הדבר דרוש לשם פעולתה התקינה של המשטרה,                                |"תקנות באישור     |                     |
|רשאי הוא, באישור ועדת הפנים ואיכות הסביבה של הכנסת, להתקין                            |ועדה של הכנסת     |                     |
|תקנות בענין ארגון המשטרה, ניהולה והמשטר והמשמעת בה, שיש בהן.,                         |                  |                     |
|לאסור או להגביל -                                                                     |                  |                     |
|(1) הקמת ארגון שוטרים, חברות בו ונקיטת כל פעולה הבאה                                  |                  |                     |
|לקדם הקמת ארגון כאמור;                                                                |                  |                     |
|(2) התראיינות שוטרים שלא בהתאם לפקודות הקבע של                                        |                  |                     |
|המשטרה;                                                                               |                  |                     |
|(3) הפגנות ותהלוכות של שוטרים;                                                        |                  |                     |
|(4) כל פעולה בעלת אופי דומה לפעולות המצויינות בפסקאות                                 |                  |                     |
|(1) עד (3) שיש בה כדי לפגוע בפעולתה התקינה של המשטרה."                                |                  |                     |
|2. בסעיף 56 (ב) לפקודה, כמקום פסקה (1) יבוא;                                                             |תיקון סעיף 50        |
|"(1) קנס שאינו עולה על שכר עשרים ואחד יום?".                                                             |                     |
|3. פקודות קבע שהוציא המפקח הכללי לפני תחילתו של חוק זה, רואים אותן שהוצאו                                |שמירת דינים          |
|כדין.                                                                                                    |                     |

|דברי הסבר                |

|מוצע לאפשר לשר הפנים, באישור ועדת             |סעיף1        |
|הפנים ואיכות הסביבה של ؀ࠂࠄࠆࠊ࠘ࠚהכנסת, להתקין   |             |
|תקנות אף אם יש בהן שלילה או הגבלה של זכות שבדין,            |
|ובלבד שנוכח כי התקנת תקנות שכאלה הינה חיונית                |
|להבטיח את פעולתה התקינה של המשטרה וכי בלעדי                 |
|התקנות לא תוכל המערכת המשטרתית לתפקד כיאות.                 |
|לפי סעיף 56 (ב) (ו) לפקודה, מוסמך המפ-        |סעיף 2       |
|קח הכללי של המשטרה להטיל על קצין              |             |
|בדרגת מפקח ומעלת עונש של 75 לירות קנס בלבד,                 |
|בעוד שלפי סעיף 52 לפקודת מוסמך הוא להטיל על                 |
|שוטרים שאינם קצינים קנס בשיעור שאינו עולה על שכר            |

|ארבעה עשר יום. לא יתכן כי הקנס המוטל על שוטרים               |
|יהיה גבוה מזה המוטל על קצינים, ומוצע להסמיך את               |
|המפקח הכללי להטיל גם על קצינים קנס בשיעור שכר                |
|21 יום.                                                      |
|קיימות כיום פקודות קבע מגבילות בעניינים        |סעיף 3       |
|חיוניים, כגון איסור מגע עם העתונות אלא         |             |
|לפי הסמכה לכך, איסור פעילות מפלגתית, ואיסור                  |
|ארגון הפגנות והשתתפות בהן. מוצע להקנות תוקף לפ-              |
|קודות הקבע שהוציא המפקח הכללי לפני תיקון החוק                |
|ויראו את פקודות הקבע הקיימות כאילו הוצאו כדין.               |
|תקנות האוסרות על התארגנות שוטרים יביא השר                    |
|לאישור ועדת הפנים ואיכות הסביבה של הכנסת.                    |
