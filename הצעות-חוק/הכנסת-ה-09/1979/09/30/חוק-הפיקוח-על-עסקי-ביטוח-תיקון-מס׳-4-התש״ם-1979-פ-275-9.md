|חוק הפיקוח על עסקי ביטוח (תיקון מס' 4), תשל"ט-1979                                     |

|1. אחלי סעיף 4 לחוק הפיקוח על עסקי ביטוח, תשי"א-1951 1, יבוא:                                                 |הוספת סעיף 4א    |
|4א. (א) כל חוזה לביטוח חיים, גין אם נעשה במישרין עם מבטח ובין                             |"הוראות מיוחדות    |                 |
|אם בעשה באמצעות קופת גמל, בנק או מוסד אחר כיוצא באלה, חייב                                |בדבר ביטוח         |                 |
|להיות מלווה במסמך כחתימת ידו של המבוטח או בא-כוחו החוקי, שבו                              |חיים               |                 |
|יפורטו תנאי הביטוח, לרכות שמם ומענם של המבטח ושל חברת הביטוח                              |                   |                 |
|האחראית לתשלום סכום הביטוח וכן גובה הפרמיה ויתר הוצאות הביטוח.                            |                   |                 |
|(ב) נפטר המבוטח, תשלם חברת הביטוח לזכאים לפי הפוליסה                                      |                   |                 |
|את סכום הביטוח תוך חודש ימים מהיום שהוגשה לה דרישה לכך בצירוף                             |                   |                 |
|תעודת פטירה המציינת את סיבת המוות; אין בהוראה זו בדי למנוע בעד                            |                   |                 |
|חברת הביטוח לדרוש ידיעות ומסמכים נוספים, ובלבד שהדבר לא יעכב                              |                   |                 |
|את תשלום סכום הביטוח.                                                                     |                   |                 |
|(ג) על אף האמור בסעיף קטן (ב) רשאית חברת הביטוח, במקרה                                    |                   |                 |
|שקיים חשד לרמיה, להשהות את תשלום סכום הביטוח לתקופה של לא                                 |                   |                 |
|יותר משלושה חדשים - או לתקופה ארוכה יותר שהזכאים לתשלום                                   |                   |                 |
|סכום הביטוח הסכימו לה - עד גמר ההליכים, אם הגישה תוך התקופה                               |                   |                 |
|האמורה תביעה לביטול הפוליסה עקב דמיה; לא הוגשה תביעה כאמור                                |                   |                 |
|או שהתביעה נדחתה יתווספו לסכום הביטוח ריבית בשיעור של 3%                                  |                   |                 |
|לשנה והפרשי הצמדה מתום חודש ימים מיום הגשת הדרישה לתשלום                                  |                   |                 |
|עד ליום התשלום למעשה."                                                                    |                   |                 |

|דברי הסבר                 |

|תיקון זה בא למלא חלל בחוק הפיקוח ולהגן בעיקר               |
|על חברי קופות הגמל המבוטחים בפוליסה קולקטיבית              |
|של ביטוח חיים בסכום השווה ליתרת חסכונותיהם, עד             |
|לתקרה משתנה, שהיא כעת 70,000 לירות.                        |
|סעיף 4א(א) בא להבטיח שחבר קופת הגמל יהיה                   |
|מודע לתנאי ביטוח החיים הקולקטיבי ולהוצאות. היום            |
|מתואר ביטוח זה על-ידי קופות הגמל כ"؀ࠂࠒࠔࠖࠤהטבה" או          |
|''הענקה'' אוטומטית לחברי קופות הגמל, כאשר חבר              |
|בקופה יכול "לרכוש" ביטוח על סכום גבוה יותר. למע-           |
|שה, מנכה הקופה מהרווחים מדי שגה סך של 7 פרומיל             |
|לכל לירה ביטוח, שזו פרמיה אחידה לכל הגילאים                |
|ויקרה לעומת ביטוח רגיל לגבי הגילאים הצעירים.               |
|סעיף 4א (ב) מסדיר כלל המקובל בדרך כלל בפו-                 |
|ליסות ביטוחי חיים הנערכות שלא באמצעות קופת גמל.            |
|סעיף 4א (ג) בא להגן על היורשים הזכאים בפגי הטר-            |
|דות וסחבת. המצטרף לקופת גמל חותם על סעיף בטופס             |

|ההצטרפות, שבו מופיעה שורת מחלות שהוא מצהיר                   |
|שאינו סובל ולא סבל מהן. אין הוא נדרש לעבור בדיקה             |
|רפואית, גם לא להמציא תעודת בריאות של רופא, ואפי-             |
|לו אינו נדרש, ברוב מקרים, לנקוב בשם קופת החולים              |
|שאליה הוא משתייך - שלא כמו בביטוח חיים של יחיד               |
|(לא קולקטיבי). לאחר מותו, רשאית חברת הביטוח                  |
|לתבוע מהיורשים כל מסמך, לרבות תעודה המעידה על                |
|מצב בריאותו של חבר הקופה הנפטר בתאריך ההיס-                  |
|טורי שבו הצטרף לקופה. גם אם חברת הביטוח אינה                 |
|מטרידה את היורשים, היא מזמינה תעודות רפואיות                 |
|מהעבר מאת קופות החולים, וככל שתאריך ההצטרפות                 |
|לקופה רחוק יותר, המתנת היורשים יותר ארוכה. על-פי             |
|התיקון המוצע, פטורים היורשים מחובת המצאת מס-                 |
|מכים, למעט תעודת הפטירה, וגם חקירות חברת הביטוח              |
|מוגבלות בזמן לשלושה חדשים מיום הגשת התביעה                   |
|ותעודת הפטירה.                                               |
