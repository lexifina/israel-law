|1 . בחוק זה -                                                                                               |הגדרות              |
|(1) "תעשיין" - בעל מפעל תעשייתי שעיקר פעילות מפעלו בשנת המס היא                                             |                    |
|פעילות ייצורית, כמשמעותה בחוק עידוד התעשיה (מסים), תשכ"ט-1969 1                                             |                    |
|(להלן - חוק עידוד התעשיה);                                                                                  |                    |
|(2) "חקלאי" - בעל משק חקלאי שעיקר פעילות משקו בשנת המס היא                                                  |                    |
|בייצורה וגידולה של תוצרת חקלאית;                                                                            |                    |
|(3) "יצוא" - בין במישרין ובין באמצעות אחר המקבל עמלה' לרבות מכירה                                           |                    |
|לגוף המייצא את כל המוצרים או התוצרת שהוא קונה מהתעשיין או החקלאי;                                           |                    |
|(4) "פדיון שנתי" - סכום שנתקבל או שזכאים לקבלו. בשנת המם, בעד                                               |                    |
|מכירת מוצרים או תוצרת, למעט מסים עקיפים המוטלים על המוצר המוגמר                                             |                    |
|הנמכר, ובתוספת החזרי סכומים ששילם יצואן כמס וכמס קניה על טובין                                              |                    |
|ששימשו לו בייצור המוצרים המיוצאים;                                                                          |                    |
|(5) "פדיון בעד יצוא" - הפדיון השנתי בניכוי הסכום שנתקבל או שזכאים                                           |                    |
|. לקבל, בשנת המס, בעד מכירות שאינן יצוא, למעט מסים עקיפים המוטלים על                                        |                    |
|המוצר המוגמר הנמכר?                                                                                         |                    |
|(6)  "מסים עקיפים" - בלו, מס קניה, מס ערך מוסף והיטל לפי תקנות שעת                                          |                    |
|חירום (תשלומי חובה)' תשי"ח-1958 2;                                                                          |                    |
|(7) "שנת המס" - שנת המס 1978 ;                                                                              |                    |
|(8) תהא לכל מונח אחר המשמעות שיש לו בחוק מס מעסיקים, תשל"ה-                                                 |                    |
|1975  3(להלן - חוק מס מעסיקים).                                                                             |                    |
|2, תעשיין המייצא 20% לפחות ממוצריו וחקלאי המייצא 20% לפחות מתוצרתו זכאים,                                   |החזר מס מעסיקים     |
|בכפוף לאמור בסעיף 4, להחזר חלק ממס המעסיקים שהם חייבים בו לשנת המס, שהוא                                    |לתעשיין ולחקלאי     |
|כיחס הפדיון בעד יצוא בשנת המס לפדיון השנתי באותה שנה.                                                       |                    |
