|הוספת סעיפים     |1. בחוק המקרקעין, תשכ"ט-1969 1, אחרי סעיף 59 יבוא:                                                          |

|                 |59א. (א) בעל דירה רשאי להתקין במקום סביר על גג הבית המשותף,                          |'"התקנת דוד שמש      |
|                 |שהוא רכוש משותף, דוד לחימום מים על ידי השמש (להלן - דוד שמש),                        |                     |
|                 |לרבות המיתקנים הקשורים לכך וצינורות להולכת המים לדירתו, ללא                          |                     |
|                 |הסכמת בעלי הדירות האתרים, ובלבד שנתקיימו שני אלה:                                    |                     |
|                 |(1) הוא קיבל היתר להתקנה לפי חוק התכנון והבניה,                                      |                     |
|                 |תשכ"ה-1965 2, ומילא אחר תנאי ההיתר;                                                  |                     |
|                 |(2) המקום שעליו יותקן דוד השמש אינו משמש את בעלי                                     |                     |
|                 |הדירות למטרה כלשהי שהוסכם עליה, בין בהחלטה של                                        |                     |
|                 |בעלי הדירות ובין בהתנהגות, והוא לא נועד לשמש למטרה                                   |                     |
|                 |כלשהי לפי תקנון הבית המשותף.                                                         |                     |
|                 |(ב) אם שטח גג הבית המשותף אינו מספיק למספר דודי שמש                                  |                     |
|                 |כמספר הדירות בבית, לא יהיה בעל דירה רשאי להתקין דוד שמש כאמור                        |                     |
|                 |בסעיף קטן (א) אלא לאחר שקיבל את הסכמת כל בעלי הדירות האחרות,                         |                     |
|                 |ובלבד שאם בעל דירה אחת, שזכויותיו ברכוש המשותף אינן עולות על                         |                     |
|                 |12.5 אחוזים מכלל הזכויות ברכוש המשותף, התנגד מטעמים בלתי                             |                     |

|דברי הסבר                 |

|במסגרת המאמצים לחסוך באנרגיה מוצעים תיקונים                |
|בחוק הקיים לגבי בתים משותפים.                              |
|לפי החוק הקיים לא ניתן לשנות זכויות של בעלי די-            |
|רות בבית משותף ללא הסכמת כל בעלי הדירות. מאחר              |
|שגג הבית הינו רכוש משותף של כל בעלי הדירות, אין            |
|בעל דירה רשאי להתקין על הגג דוד שמש ללא הסכמת              |
|כל בעלי הדירות.                                            |
|כיוצא בזה, מיתקני ההסקה או חימום המים הינם רכוש            |
|משותף וכל בעל דירה חייב להשתתף בהוצאות הדרושות             |
|להחזקתם התקינה ולהבטחת השירותים המחריבים,                  |
|בהתאם לחלקו ברכוש המשותף.                                  |
|לפי המוצע, יהיה בעל דירה רשאי להתקין דוד שמש               |
|על הגג ללא הסכמת בעלי הדירות האחרים, אך בתנאי              |
|שיקבל היתר לפי חוק התכנון והבניה וההתקנה תהא               |
|תואמת את תנאי ההיתר, ושהמקום איננו משמש למטרה              |

|אחרת שהסכימו עליה בעלי הדירות או שנועד לשמש                     |
|למטרה אחרת לפי תקנון מוסכם,                                     |
|אם שטח הגג איננו מספיק לדודי שמש כמספר הדי-                     |
|רות בבית יהיה צורך לקבל את הסכמת כל בעלי הדי-                   |
|רות; אך אם בעל דירה אחת בבית, שחלקו ברכוש המ-                   |
|שותף אינו עולה על 12.5 אחוזים מכלל הזכויות ברכוש                |
|המשותף, מתנגד מטעמים בלתי סבירים, יהיה המפקח                    |
|רשאי להתיר את התקנת דוד השמש.                                   |
|מוצע עוד כי בעל דירה יהיה רשאי להינתק מהמע-                     |
|רכת להסקה או לחימום מים, אך לא ייגרע בכך מהחלק                  |
|במערכת זו ؀ࠂࠒࠔ࠘ࠜࠞࠠהצמוד לדירתו, ועם זאת יהיה חייב בהו-          |
|צאות הקבועות להחזקה התקינה של המערכת. אשר                       |
|להוצאות השוטפות הכרוכות בשימוש במערכת החימום,                   |
|יקבע שר המשפטים בתקנות את מידת הפטור של                         |
|המתנתק.                                                         |
