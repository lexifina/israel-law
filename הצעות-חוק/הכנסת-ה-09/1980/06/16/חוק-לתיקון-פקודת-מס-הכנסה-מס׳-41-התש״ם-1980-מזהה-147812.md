|מתפרסמות בזה הצעות חוק מטעם הממשלה:               |

| חוק לתיקון פקודת מס הכנסה (מס' 40), תש"ם-1980                                   |

|1. אחרי סעיף 130 לפקודת מס הכנסה 1 (להלן - הפקודה), יבוא:                                                |הוספת סעיף 130א        |
|130א. (א) יהלומן יהיה רשאי לנהל במטבע חוץ את פנקסי החשבונות                             |"ניהול פנקסים   |                       |
|שהוא חייב בניהולם על פי סעיף 130, לגבי עסקו ביהלומים, לפי כללים                         |במטבע חוץ       |                       |
|שיקבע שר האוצר באישור ועדת הכספים של הכנסת שיכללו את התנאים                             |וקביעת ההכנסה   |                       |
|שבהם יהיה רשאי מי שבחר לנהל פנקסים כאמור לחזור בו מבחירתו;                              |בהתאם לכך       |                       |
|לענין זה -                                                                              |                |                       |
|"יהלומן" - מי שעסקו או חלק מעסקו עיבוד יהלומים, מסחר                                    |                |                       |
|ביהלומים או תיווך בהם;                                                                  |                |                       |
|"עסק ביהלומים" - עיבוד יהלומים, מסחר ביהלומים או                                        |                |                       |
|תיווך בהם.                                                                              |                |                       |
|(ב) שר האוצר רשאי, באישור ועדת הכספים של הכנסת, לקבוע                                   |                |                       |
|לגבי יהלומן שבחר לנהל פנקסים כאמור בסעיף קטן (א) כללים לקביעת                           |                |                       |
|הכנסתו החייבת וחישובה, ובמיוחד לענין ההוצאות, ההכנסות והפחת,                            |                |                       |
|וכללים בדבר חיוב במס, ותשלום מס והפרשי הצמדה וריבית עליו, הכל                           |                |                       |
|בהתחשב בניהול הפנקסים כמטבע חוץ כאמור; כללים לפי פסקה זו יחולו                          |                |                       |
|על אף האמור בכל דין."                                                                   |                |                       |
|2. בסעיף 145א לפקודה, במקום "שהוא בעל עסק זעיר מסוג שקבע שר האוצר וניהל"                                 |תיקון סעיף 145א        |
|יבוא "כמפורט להלן שניהל", ובסופו יבוא:                                                                   |                       |
|"(1) בעל עסק זעיר מסוג שקבע שר האוצר;                                                                    |                       |
|(2) יהלומן כמשמעותו בסעיף 130א, למעט יהלומן שוויתר                                                       |                       |
|על אותן הקלות מהוראות הנציב לניהול פנקסים, שקבע שר                                                       |                       |
|האוצר".                                                                                                  |                       |

|דברי הסבר           |

|כידוע נתעוררו קשיים בענין ניהול פנקסי חשבונות               |
|בידי היהלומנים, למרות העובדה שחובת ניהול הפנקסים            |
|חלה עליהם, וזאת בשל בעיות מיוחדות בענף היהלומים.            |
|במגמה להתגבר על הקשיים וליצור כלים מתאימים                  |
|לניהול הפנקסים מונו במשך השנים האחרונות שתי ועדות,          |
|הראשונה, בראשותו של סגן נציב מס הכנסה, מר ס'                |
|מועלם, שהגישה המלצות עוד במרס 1977, והשניה,                 |
|שמונתה לא מכבר, בראשותו של המשנה ליועץ המשפטי               |
|לממשלה, מר י' בר-סלע.                                       |
|הוועדות הביאו בחשבון את העובדות שתעשיית היה-                |
|לומים בארץ היא תעשיית מפתח שענף היהלומים הוא                |

|הענף היחיד שבו ישראל מהווה מרכז בינלאומי, ושכל                |
|המערכת של תעשיית היהלומים והמסחר בהם מתנהלת                   |
|במטבע חוץ משום שכל חומר הגלם מיובא מחוץ לארץ                  |
|וכמעט כל המכירות הן ליצוא.                                    |
|הצעת החוק באה לממש את המלצותיה של ועדת                        |
|בר-סלע, אשר הציעה לאפשר ניהול פנקסים במטבע                    |
|חוץ בענף היהלומים. דבר זה מחייב תיאומים בכל                   |
|המערכת וקביעת הוראות השונות מהוראות החוק הקיי-                |
|מות בענין קביעת ההכנסה החייבת וחישובה, כולל חישוב             |
|ההוצאות, ההכנסות והפחת.                                       |
