|חוק המועצות החקלאיות (ועדות קנסות), התשמ"א-1980                                 |

|1. בחוק המועצה לייצור ולשיווק של ירקות, התשי''ט-1959  1-                                                    |תיקון חוק         |
|(1) במקום סעיף 43ב יבוא:                                                                                    |המועצה לייצור     |
|                                                                                                            |ולשיווק של ירקות  |
|43ב. (א) יוקמו ועדות קנסות.                                                             |"ועדות קנסות       |                  |
|(ב) ועדת קנסות תדון בשלושה והם שופט בית משפט שלום,                                      |                   |                  |
|או חבר לשכת עורכי הדין והוא כשיר לכהן כשופט בית משפט שלום,                              |                   |                  |
|שמינה אותו שר המשפטים והוא ישמש יושב ראש הועדה, ושני נציגי                              |                   |                  |
|ציבור.                                                                                  |                   |                  |
|(ג) השרים יקבעו שתי רשימות של נציגי ציבור, האחת מתוך                                    |                   |                  |
|רשימות שהגישו להם הארגונים שהם לדעת השרים ארגונים יציגים של                             |                   |                  |
|המגדלים והשניה מתוך רשימות שהגישו להם ארגונים שהם לדעת הש-                              |                   |                  |
|רים ארגונים יציגים של המשווקים המורשים, ובלבד שחברי המועצה                              |                   |                  |
|לא ייכללו ברשימות.                                                                      |                   |                  |
|(ד) יושב ראש הועדה יקבע את שני נציגי הציבור, אחד מכל                                    |                   |                  |
|רשימה, מתוך הרשימות שנקבעו לפי סעיף קטן (ג), אשר ידונו בענין                            |                   |                  |
|פלוני,                                                                                  |                   |                  |
|(ה) הודעה על הקמת ועדות קנסות ומענן תפורסם ברשומות,                                     |                   |                  |
|(ו) שר המשפטים רשאי לקבוע את סדרי הדין של הועדות; כל                                    |                   |                  |
|עוד לא נקבעו סדרי דין כאמור, רשאית ועדת קנסות לקבוע לעצמה את                            |                   |                  |
|סדרי הדין.                                                                              |                   |                  |

|דברי הסבר           |

|בחוקי המועצות החקלאיות הדנים בפירות, בפרחי                  |
|נוי, בירקות ובלול קבועות ועדות קנסות שבפניהן                |
|מובאים עבריינים על הוראות מסויימות בחוקי המוע-              |
|צות. בחוק מועצת הפירות, שהוא משנת התשל"ג,                   |
|נקבע שהרכב הועדה יהיה של שופט בית משפט שלום,                |
|או מי שכשיר להיות שופט בית משפט שלום, ושני                  |
|נציגי ציבור. בחוקי מועצות הירקות והלול שהינם מוק-           |
|דמים יותר - משנת התשיי'ט ושנת התשכ"ד - נקבע                 |
|רק שחברי הועדה יהיו שלושה שלא מבין חברי                     |
|המועצה.                                                     |
|מוצע לקבוע הוראות כגון אלה שבחוק מועצת                      |

|הפירות גם בשאר החוקים, וזאת במיוחד לאור ההגדלה                |
|המשמעותית של סכומי הקנסות שהועדות הוסמכו                      |
|להטיל בחוק המועצות החקלאיות (עונשין), התש"ם-                  |
|1980.                                                         |
|ו                                                             |
