|חוק מס הכנסה (הטבות לחיילים משוחררים בתעשיה) (הוראות שעה),                                         |
|התשמ"א-1980                                                                                        |

|הגדרות    |1 . בחוק זה -                                                                                           |
|          |"מפעל תעשייתי" - כמשמעותו בחוק עידוד התעשיה (מסים), התשכ"ט-1969 1(להלן                                  |
|          |- חוק עידוד התעשיה);                                                                                    |
|          |"מפעל תעשייתי מזכה" - מפעל תעשייתי שעל העסקת עובדים בו חל הסכם קיבוצי או                                |
|          |צו הרחבה, כמשמעותם בחוק הסכמים קיבוציים, התשי"ז-1957 2;                                                 |

|דברי הסבר                    |

|מטרת החוק המוצע היא לעודד חיילים משוחררים                    |
|לעבוד בתעשיה, ועל ידי כך לאפשר היצע כוח אדם                  |
|גדול יותר לתעשיה.                                            |
|חייל משוחרר, לענין חוק זה, הוא מי שהשתחרר                    |
|משירות סדיר בצה"ל או משירות במשמר הגבול או                   |
|משירות קבע בצה"ל שהתנדב בדרך של התחייבות.                    |

|ההטבות לסי חוק זה יינתנו לחייל ששוחרר בתקו-                  |
|סה שבין יום פרסומו של חוק זה לבין יום 31 במרס 1982           |
|והתחיל לעבוד במפעל תעשייתי תוך חצי שנה מיום                  |
|שחרורו, או ששוחרר תוך שנה לפני פרסומו של חוק זה              |
|והתחיל לעבוד במפעל תעשייתי תור חצי שנה מיום                  |
|הפרסום, או ששוחרר תור השנה כאמור והוא כבר                    |
|עובד במפעל תעשייתי.                                          |

|1 ס"ח התשכ"ט, עמ' 232; התש"ם, עמ' 103,     |
|2 ס"ח התשי"ז, עמ' 63.                      |

|"חייל משוחרר" - כל אחד מאלה ;                                                                                |פטור ממס       |
|(1) מי שסיים את תקופת השירות הסדיר בצבא -הגנה לישראל שהוא חייב בו                                            |               |
|על פי חוק שירות בטחון, התשי"ט-1959 [נוסח משולב]3 (להלן - חוק שירות                                           |               |
|בטחון);                                                                                                      |               |
|(2) מי שסיים את תקופת שירותו במשמר הגבול בתקופת השירות הסדיר שהוא                                            |               |
|חייב בו על פי חוק שירות בטחון;                                                                               |               |
|(3) מי שסיימה שירות לאומי על פי חוק שירות לאומי, התשי"ג-1953 4;                                              |               |
|(4) מי שלאחר תקופת השירות הסדיר שהוא חייב בו על פי חוק שירות בטחון                                           |               |
|המשיך בשירות סדיר על פי התנדבות בדרך של התחייבות לשירות קבע במשך                                             |               |
|תקופה של לא יותר משנתיים;                                                                                    |               |
|"עובד זכאי" - כל אחד מאלה:                                                                                   |               |
|(1) חייל משוחרר ששוחרר בין יום פרסומו של חוק זה ובין תום שנת המס 1981                                        |               |
|והתחיל ؀ࠂࠎࠐࠔࠚࠜࠞלעבוד במפעל תעשייתי מזכה תוך חצי שנה מיום שחרורו;                                             |               |
|(2) חייל משוחרר ששוחרר תוך שנה לפני יום פרסומו של חוק זה והתחיל לעבוד                                        |               |
|במפעל תעשייתי מזכה תוך חצי שנה מיום הפרסום האמור;                                                            |               |
|(3) חייל משוחרר ששוחרר תוך שנה לפני יום פרסומו של חוק זה והוא-עובד                                           |               |
|במפעל תעשייתי מזכה.                                                                                          |               |
|2. עובד זכאי יהיה זכאי לשש נקודות זיכוי כמשמעותן בסעיף 33א לפקודת מס הכנסה6                                  |               |
|(להלן - הפקודה), בנוסף על נקודות הזיכוי המגיעות לו על פי הפרק השלישי לחלק גי                                 |               |
|לפקודה (להלן - נקודות זיכוי נוספות) בשנה הראשונה לעבודתו במפעל התעשייתי                                      |               |
|המזכה, ולשלוש נקודות זיכוי נוספות בשנה השניה לעבודתו במפעל, כאמור.                                           |               |
|3. (א) מעביד המעסיק עובד זכאי לא יהא רשאי לשלם לאותו עובד שכר נמוך מזה                                       |חובת מעביד     |
|המשתלם לעובד אחר המועסק בתפקיד זהה ואשר יש לו אותו ותק בעבודה.                                               |לשלם שכר       |
|(ב) מעביד- אשר לא מילא אחר הוראות סעיף קטן (א), רשאי העובד להגיש                                             |שווה           |
|תובענה נגדו לבית הדין לעבודה לפי חוק בית דין לעבודה, התשכ"ט-1969 6.                                          |               |
