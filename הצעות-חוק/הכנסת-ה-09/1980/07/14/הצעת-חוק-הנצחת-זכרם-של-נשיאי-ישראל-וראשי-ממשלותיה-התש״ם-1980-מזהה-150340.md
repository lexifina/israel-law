|חוק הנצחת זכרם של נשיאי ישראל וראשי ממשלותיה, תש"ם-1980                                               |

|1. הממשלה תמנה מועצה לענין הנצחת זכרם של מי שנשאו את משרת נשיא המדינה                                      |המועצה            |
|או ראש הממשלה (להלן - המועצה); המועצה תמנה לא יותר מ-21 חברים ותהא                                         |                  |
|מורכבת מנציגי הממשלה ואנשי ציבור; הממשלה תמנה אהד מנציגיה במועצה להיות                                     |                  |
|יושב ראש,                                                                                                  |                  |
|2. תקופת כהונתו של חבר המועצה היא חמש שנים; ניתן למנותו מחדש.                                              |תקופת כהונה       |
|3. המועצה תקבע את נוהל דיוניה ככל שלא נקבעו בחוק זה או בתקנות לפיו.                                        |נוהל              |
|4. (א) המועצה תציע לממשלה, בין ביזמתה ובין לפי פנייה מאת הממשלה, תכנית                                     |תכנית הנצחה       |
|להנצחת זכרו של כל מי שכיהן כנשיא המדינה או -ראש הממשלה.                                                    |                  |
|(ב) התכנית תפרט את פעולות ההנצחה שתבצע הממשלה ואת פעולות ההנצחה                                            |                  |
|שיבצעו גופים ציבוריים בתמיכת הממשלה, לרבות תמיכה במפעלים או מוסדות הנושאים                                 |                  |
|את שמו של הנפטר, הכל כפי שהמועצה תראה כהולם את הנצחת זכרו של הנפטר, בשים                                   |                  |
|לב לאישיותו, לפועלו ולשאר שיקולים הנוגעים לענין; התכנית תכלול אומדן של                                     |                  |
|ההוצאות הכרוכות בביצועה והצעת מקורות לכיסוין.                                                              |                  |
|(ג) תכנית הנצחה טעונה אישור הממשלה.                                                                        |                  |
|(ד) ניתן לשנות תכנית הנצחה בדרך האמורה בסעיף זה לענין הכנתה ואישורה.                                       |                  |
|5. במסגרת הפעולות להנצחת זכרו שלי מי שכיהן כנשיא המדינה או כראש הממשלה                                     |מעולות הגנז       |
|רשאית הממשלה להורות לגנז שנתמנה לפי חוק הארכיונים, תשט"ו-1955 1, לעשות                                     |                  |
|את הפעולות הבאות או מקצתן:                                                                                 |                  |
|(1) לכנס את החומר התיעודי על פעולותיו;                                                                     |                  |
|(2) לפרסם את מבחר נאומיו, הרצאותיו וכתביו, במתכונת שיקבע ؀ࠂࠊࠌהגנז                                          |                  |
|בהתייעצות עם המועצה, ובלבד שלגבי נכסים שאינם של המדינה לא ייפגעו                                           |                  |
|זכויותיהם של בני משפחת הנפטר או של אדם אחר;                                                                |                  |
|(3) לערוך, לפי המלצת המועצה, תצוגות פומביות של כתביו או חומר                                               |                  |
|תיעודי אחר המתייחס אליו, בין בגנזך המדינה ובין במקום ציבורי אחר,                                           |                  |
|6.  (א) המועצה תפקח על ביצוע תכנית הנצחה ותדווח לממשלה על ממצאיה                                           |פיקוח             |
|בצירוף המלצותיה.                                                                                           |                  |
|(ב) המועצה רשאית לדרוש מכל מי שנטל חלק בביצוע פעולת הנצחה במימון                                           |                  |
|אוצר המדינה או בתמיכת הממשלה, שימסור לה או למי שהיא מינתה לכך כל ידיעה                                     |                  |
|או. מסמר הדרושים לה לצורף תפקידי הפיקוח לפי סעיף קטן (א).                                                  |                  |
|7. חוק זה יחול על פעולות הנצחה אף שהחלו בהן לפני תחילתו.                                                   |תחולה             |
|8. הממשלה תמנה אחד משריה להיות ממונה על ביצוע חוק זה והוא יהיה רשאי                                        |ביצוע החוק        |
|להתקין תקנות בכל הנוגע לביצועו; הודעה על המינוי תפורסם ברשומות.                                            |                  |

|1 ס"ח תשט"ו, עמ' 14.    |
