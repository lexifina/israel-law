|                 |145א. (א) בסעיף זה -                                                               |"הגבלת הספקת        |
|                 |"החברה" - חברת החשמל לישראל בע"מ או חברת החשמל                                     |חשמל, מים           |
|                 |והשירות הציבורי לירושלים בע"מ, הכל לפי העניו;                                      |וטלפון              |
|                 |"המנהל" - מנהל שירותי הטלפון של משרד התקשורת או                                    |                    |
|                 |אדם שהוא הסמיך;                                                                    |                    |
|                 |"שירותי טלפון" - השירות שנותן משרד התקשורת לגבי טלפון.                             |                    |
|                 |(ב) (1) לא תתחיל החברה בעבודות לאספקת חשמל למקר-                                   |                    |
|                 |קעין אלא לאחר שמבקש העבודות המציא לה אישור                                         |                    |
|                 |הועדה המקומית על כך.                                                               |                    |
|                 |(2) לא תספק החברה חשמל למקרקעין אלא לאחר                                           |                    |
|                 |שמבקש החיבור המציא לה אישור הועדה המקומית על כך.                                   |                    |
|                 |(ג) לא יתקין המנהל טלפון במקרקעין אלא לאחר שהמבקש                                  |                    |
|                 |לקבל שירות טלפון צירף לבקשתו אישור הועדה המקומית על כה                             |                    |
|                 |(ד) (1) לא יספק אדם מים למקרקעין לצורך ביצוע עבודה                                 |                    |
|                 |בקרקע או בבנין, כאשר העבודה נקבעה כטעונת היתר כדי                                  |                    |
|                 |להבטיח ביצוע כל תכנית, אלא לאחר שהמבקש המציא                                       |                    |
|                 |אישור הועדה המקומית על כך.                                                         |                    |
|                 |(2) לא יספק אדם מים למקרקעין - שלא לצורך ביצוע                                     |                    |
|                 |עבודה כאמור בפסקה (1) - אלא לאחר שהמבקש המציא                                      |                    |
|                 |אישור הועדה ؀ࠂࠒࠔ࠘ࠚࠜࠞהמקומית על כך.                                                 |                    |
|                 |(ה) (1) הועדה המקומית תיתן אישורים כאמור בסעיפים קטנים                             |                    |
|                 |(ב), (ג) ו-(ד) אם נתנה לגבי המקרקעין שבהם מדובר                                    |                    |
|                 |היתר לפי הוראות פרק זה ולאחר שנוכחה כי העבודות                                     |                    |
|                 |, במקרקעין בוצעו ללא סטיה מההיתר.                                                  |                    |
