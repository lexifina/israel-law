|מתפרסמות בזה הצעות חוק מטעם הממשלה:                  |

|חוק רשות שדות התעופה (הוראת שעה), תש"ם-1980                                      |

|1, בחוק זה -                                                                                                |פרשנות             |
|(1) יהא לכל מונח המשמעות שיש לו בחוק רשות שדות התעופה, תשל"ז-                                               |                   |
|1977 1(להלן - החוק העיקרי), ושני החוקים יתפרשו כאחד;                                                        |                   |
|(2) "מסוף מעבר" - מסוף מעבר יבשתי לתנועת בני אדם, טובין וכלי רכב                                            |                   |
|בין ישראל לבין מצרים.                                                                                       |                   |
|2. (א) עד יום שיקבע שר התחבורה בהודעה ברשומות באישור ועדת הכלכלה של                                         |סמכויות זמניות     |
|הכנסת' יהא זה מתפקידה של הרשות' בנוסף לתפקידיה האחרים לפי סעיף 5 לחוק העיקרי -                              |                   |
|(1) להחזיק, להפעיל, לפתח ולנהל את מסופי המעבר המפורטים בתוספת                                               |                   |
|(להלן - מסופי המעבר של הרשות)' בין שהם בישראל ובין שהם מחוצה לה'                                            |                   |
|לבצע בהם פעולות תכנון ובניה ולתת בהם שירותים נלווים לכל הפעולות                                             |                   |
|האלה;                                                                                                       |                   |
|(2) לנקוט אמצעים לבטחונם של מסופי המעבר של הרשות ושל בני האדם,                                              |                   |
|הטובין, כלי הרכב, המבנים והציוד שבהם, בהתאם להוראות שר התחבורה.                                             |                   |
|(ב) בנוסף על שירות שהרשות תתן על פי סעיף קטן (א) רשאית היא לתת שירו-                                        |                   |
|תים אחרים במסופי המעבר של הרשות או בקשר אתם שניתן לתתם אגב מילוי תפקידיה                                    |                   |
|כאמור.                                                                                                      |                   |
|(ג) במלאה את תפקידיה ובמתן שירותים לפי סעיף זה תונחה הרשות בעקרונות                                         |                   |
|מתן שירות יעיל לרווחת המשתמשים במסופי המעבר של הרשות ובהבטחת תנאי תפעול                                     |                   |
|ברמה נאותה לרשויות המוסמכות שיפעלו במסופי המעבר של הרשות.                                                   |                   |
|(ד) (1) החוק העיקרי - למעט סעיפים 26 עד 28 ו-32 שבו - יחול על מילוי                                         |                   |
|תפקידיה של הרשות לפי סעיף זה, בשינויים המחוייבים לפי העניין.                                                |                   |

|דברי הסבר                  |

|בנספח השלישי להסכם השלום בין ישראל לבין מצ-                  |
|רים הובטחה זכות תנועה חפשית של בני אדם וכלי רכב              |
|של שתי המדינות בין ישראל לבין מצרים. בהסדרים                 |
|שנקבעו, בהתאם להסכם השלום, בין מצרים לבין ישראל              |
|בדבר מעבר יבשתי של בני אדם, טובין וכלי רכב, נקבע             |
|כי המעבר יהיה בנקודת מעבר באל-עריש ובנקודות                  |
|מעבר נוספות שייקבעו.                                         |
|הממשלה החליטה להעביר את האחריות לניהולם                      |
|ולהפעלתם של מסופי המעבר היבשתיים הישראליים בין               |
|ישראל לבין מצרים לאחריות משרד התחבורה, וזאת                  |
|במגמה שמסופים אלה יופעלו בידי רשות אזרחית, ומשרד             |
|התחבורה ؀ࠂࠒࠔ࠘ࠞࠠࠢ࠲יעביר את האחריות לניהול ולהפעלה של          |

|מסופי המעבר היבשתיים לרשות שדות התעופה, שהת-                 |
|מחתה בהפעלת מסופים אויריים ויכולה לתרום מנסיונה              |
|בתחום זה.                                                    |
|בחוק רשות שדות התעופה, תשל"ז-1977, נקבעו                     |
|מסגרות אחריותה, סמכויותיה ותפקידיה של רשות שדות              |
|התעופה. מסגרות אלה מוגבלות לשדות התעופה של                   |
|הרשות בלבד. העברת האחריות לתפעול מסופי המעבר                 |
|היבשתיים מחייבת חקיקת חוק מיוחד כמוצע, שיחול                 |
|כהוראת שעה, עד מועד שיקבע שר התחבורה באישור                  |
|ועדת הכלכלה של הכנסת.                                        |
|על העוברים במסופים תוטל אגרה, שתיועד לכיסוי                  |
|חלקי של עלות הפעלתם.                                         |
