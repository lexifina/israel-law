|חוק מימון מפלגות (תיקון מס' 4), התשמ"א-1981                               |

|1. בסעיף 13 לחוק מימון מפלגות, התשל"ג-1973 1( להלן - החוק העיקרי), האמור                                 |תיקון סעיף 13        |
|בסעיף קטן (ב) יסומן (ה) ובמקום סעיף קטן (א) יבוא:                                                        |                     |
|"(א) פרשו חבר אחד או שני חברים מסיעה, לא יהיו הם זכאים למימון הוצאות                                     |                     |
|שוטפות, ומימון הוצאותיה השוטפות של הסיעה שממנה פרשו לא ישתנה.                                            |                     |
|(ב) עברו חבר אחד או שני חברים מסיעה לסיעה, לא ישתנה מימון ההוצאות                                        |                     |
|השוטפות של אף אחת משתי הסיעות.                                                                           |                     |
|(ג) פרשו שלושה חברים לפחות מסיעה והקימו סיעה חדשה, ישתנה מימון                                           |                     |
|ההוצאות השוטפות של הסיעה שממנה פרשו ותהיה הסיעה החדשה זכאית למימון                                       |                     |
|הוצאות שוטפות, החל בחודש שלאחר שועדת הכנסת אישרה את השינוי.                                              |                     |
|(ד) עברו שלושה חברים לפחות מסיעה לסיעה, ישתנה מימון הוצאותיהן השוט-                                      |                     |
|פות של שתי הסיעות, החל בחודש שלאחר שועדת הכנסת אישרה את השינוי."                                         |                     |
|2 . בסעיף 13א לחוק העיקרי؀ࠂࠊࠌ, אחרי סעיף קטן (ב) יבוא:                                                   |תיקון סעיף 13א       |
|"(ג) התפלגה סיעה בהסכמת רוב חבריה, אחרי שועדת הכנסת הכירה בה, תהיה                                       |                     |
|כל אחת מהסיעות החדשות זכאית למימון הוצאות שוטפות, אף אם היא מונה                                         |                     |
|חבר אחד או שני חברים."                                                                                   |                     |
|חבר הכנסת יהודה חשאי                                                                                     |                     |
