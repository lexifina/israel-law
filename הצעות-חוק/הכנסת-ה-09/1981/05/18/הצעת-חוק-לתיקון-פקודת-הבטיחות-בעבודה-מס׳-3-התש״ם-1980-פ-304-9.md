|מתפרסמת כזה מטעם ועדת העבודה והרווחה הצעת חוק של חבר הכנסת:                   |

|חוק לתיקון פקודת הבטיחות בעבודה (מס' 3), התשמ"א-1981                                  |

|1. אחרי סעיף 236 לפקודת הבטיחות בעבודה [נוסח חדש], התש"ל-1970 1, יבוא:                                     |הוספת סעיף 236א   |
|236א. (א) נוכח מפקח עבודה כי לא נקטו באמצעי הבטיחות הנד-,                                         |"קנס    |                  |
|רשים על פי פקודה זו או על פי תקנה לפיה לגבי מכונה מסוכנת, רשאי                                    |        |                  |
|מפקח העבודה לפי שיקול דעתו להטיל על העבריין ברירת קנס בסכום                                       |        |                  |
|של 2,000 שקלים או להעמידו לדין.                                                                   |        |                  |
|(ב) מצא מפקח עבודה כי עובד הפר הוראת שימוש בציוד                                                  |        |                  |
|מגן, רשאי הוא להטיל לפי שיקול דעתו קנס של 100 שקלים על העובד                                      |        |                  |
|או של 200 שקלים על מנהל עבודה, וזאת בנוסף על האחריות המוטלת                                       |        |                  |
|על תופש המפעל או הבעל."                                                                           |        |                  |

|דברי הסבר                    |

|תאונות העבודה הן מכת המדינה, הן גורמות                    |
|לאבדן נפש ולנזק כלכלי גדול. בשנת 1977 נהרגו               |
|בתאונות עבודה 200 עובדים, נפגעו 90,000؀ࠂࠒࠔࠖࠤ עובדים       |
|ומהם נשארו נכים 6,000 עובדים. למשק אבדו קרוב              |
|לששה מיליון ימי עבודה, לעומת 400,000 ימי עבודה            |
|שאבדו באותה שנה מחמת שביתות: פי 12 יותר.                  |

|מטרת הצעת חוק זו היא להגביר את הפיקוח ואת                      |
|ההרתעה על עבירות בטיחות בעבודה, וזאת על ידי                    |
|קביעת מקרים שבהם תוענק למפקח עבודה סמכות של                    |
|הטלת קנס במקום הזמנה לדין.                                     |
|חבר הכנסת ירוחם משל                                            |
