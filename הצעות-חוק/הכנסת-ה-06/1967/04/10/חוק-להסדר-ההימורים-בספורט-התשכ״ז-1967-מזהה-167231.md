|1 . תקום מועצה להסדר ההימורים בספורט (להלן - המועצה) שתהיה מוסמכת לארגן                                         |הקמת המועצה          |

|במספר שלא יפחת מששה ולא יעלה על שנים עשר, מחציתם נציגי ארגוני ספורט ומוסדות                                     |                     |
|ספורט ומחציתם עובדי המדינה.                                                                                     |                     |
|(ב) השרים ימנו אחד מחברי המועצה ליושב ראש המועצה ואחד לסגן יושב ראש.                                            |                     |
|(ג) חברי המועצה לא יקבלו מהמועצה שכר בעד שירותיהם, אולם המועצה רשאית                                            |                     |
|לשלם את הוצאותיו של חבר המועצה שהוא נציג ארגון ספורט או מוסד ספורט.                                             |                     |
|5 .(א) רוב חברי המועצה, וביניהם היושב ראש או סגנו, יהיו מנין חוקי בישיבותיה.                                    |נוהל המועצה          |
|(ב) החלטות המועצה יתקבלו ברוב דעות הנוכחים והמצביעים; היו הדעות שקולות                                          |                     |
|יכריעו בענין השרים.                                                                                             |                     |
|(ג) המועצה תקבע את סדרי עבודתה בעצמה, במידה שלא נקבעו בתקנות.                                                   |                     |
|6 .(א) דרכי קבלת עובדים למועצה ותנאי עבודתם, לרבות תחולת השיפוט המשמעתי,                                        |עובדים               |
|יהיו כשל עובדי המדינה, בתיאומים שיקבעו השרים בתקנות.                                                            |                     |
|(ב) לענין חוק לתיקון דיני העונשין (עובדי הציבור), תשי"ז-1957 2, פקודת העדות3,                                   |                     |
|פקודת הנזיקים האזרחיים, 1944 4, וחוק שירות המדינה (סיוג פעולה מפלגתית ומגביות                                   |                     |
|כספים), תשי"ט-1959 5, דין עובדי המועצה כדין עובדי המדינה.                                                       |                     |
|7 . ההימורים שתארגן המועצה ייערכו לפי תכנית שתקבע המועצה בתקנות באישור                                          |עריכת הימורים        |
|השרים, ובלבד שייקבע בה כי לא פחות ממחצית ההכנסות מעריכת הימור על פי התכנית                                      |                     |
|תשולם לזוכים בהימור.                                                                                            |                     |
|8 .(א) הסכום שיוותר בידי המועצה מעריכת ההימורים לאחר ניכוי התשלומים לזוכים                                      |השימוש ביתרת         |
|והוצאות המועצה; ישמש לקידומם ולפיתוחם של תרבות הגוף, החינוך הגופני והספורט                                      |ההכנסות              |
|בישראל.                                                                                                         |                     |

דברי הסבר
תכליתו של החוק המוצע להקים רשות ממלכתית לקיום הימורים על תוצאות משחקי
ספורט, שתפקידה יהיה לערוך את ההימורים בצורה הוגנת כלפי המהמרים ולייעד את
הרווחים לקידום ענף הספורט.
לפי החוק הקיים עריכת הימור טעונה היתר שר האוצר, אולם מתברר שאין בסמכות
זו כדי להשיג את התכלית האמורה. בבג"צ 131/65 (פסקי דין י"ט 11, עמי 369) הוטלה בספק
סמכותו של שר האוצר לסרב ליתן היתר לעריכת הימורים על פי סעיף 8 לחוק לתיקון דיני
העונשין (משחקים אסורים, הגרלות והימורים), תשכ"ד-1964, אף אם אין הרווחים מיועדים
לפיתוח ממשי של הספורט.
