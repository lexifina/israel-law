|מתפרסמת בזה הצעת חוק מטעם הממשלה:                   |

|חוק לתיקון פקודת בתי הדואר (מס' 7), תשכ"ז-1967                                   |

|1. במקום סעיף 3 לפקודת בתי הדואר1 (להלן - הפקודה) יבוא:                                                   |החלפת סעיף 3    |
|3. (0 שר הדואר, באישור ועדת הכספים של הכנסת, רשאי לקבוע                               |"סמכות לקבוע        |                |
|את האגרות בעד שירותי הדואר ושירותים אחרים שבהנהלתו ואת הנסיבות                        |אגרות               |                |
|שבהן יוטלו, ובלבד שקביעת אגרות לשירותים המפורטים בתוספת                               |                    |                |
|החמישית אינה טעונה אישור כאמור.                                                       |                    |                |
|(2) שר הדואר, באישור ועדת הכספים של הכנסת, רשאי לשנות                                 |                    |                |
|את התוספת החמישית ולהוסיף עליה."                                                      |                    |                |
|2. אחרי התוספת הרביעית לפקודה יבוא:                                                                       |הוספת תוססת     |
|"תוספת חמישית                                                                                             |חמישית          |
|(סעיף 3)                                                                                                  |                |
|1. קשר בין-עירוני בטלפון או בטלקס-אם האגרה נקבעת עקב                                                      |                |
|פתיחתן או סגירתן של מרכזות טלפון או טלקס או עקב שינוי בהן.                                                |                |
|2. קשר בין-לאומי כטלפון או בטלקס, משלוח חבילה לחו"ל, משלוח                                                |                |
|מברק לחו"ל, והכל אם האגרה נקבעת עקב הגדלתו או הקטנתו של אותו                                              |                |
|חלק מהאגרה המשתלם למוביל, למינהל דואר או למפעיל אחר בחו"ל."                                               |                |
|דברי הסבר                                                                                                 |                |
|פקודת בתי הדואר המקורית נתנה את הסמכות לקבוע תשלומים בעד השירותים של                                      |                |
|משרד הדואר למנהל הכללי של הדואר. בשעתו מצאה ועדת הכספים, שיש מקום לפיקוח                                  |                |
|פרלמנטרי על קביעת התשלומים הללו, ובשנת ؀ࠂࠌࠎתשכ"ג תוקנה הפקודה והסמכות לקביעת                              |                |
|התשלומים הועברה לידי שר הדואר באישור ועדת הכספים. במשך השנים שעברו מאז                                    |                |
|טיפלה ועדת הכספים במאות שינויים שיגרתיים בתעריפים שאינם אלא התאמה לתעריפים                                |                |
|שבחו"ל או נובעים מנסיבות אובייקטיביות. לנוכח מצב זה הביעה ועדת הכספים את משאלתה                           |                |
|להוריד ממנה את הטיפול בשינויים שיגרתיים. החוק המוצע בא למלא אחרי רצונה זה של                              |                |
|ועדת הכספים. השירותים כנ"ל יפורטו בתוספת לפקודה, ושר הדואר יהיה מוסמך לשנותה,                             |                |
|באישור ועדת הכספים של הכנסת, לפי הנסיבות שנשתנו.                                                          |                |
