|מתפרסמת בזה הצעת חוק מטעם הממשלה :                   |

|חוק תקציבי השירותים הדתיים היהודיים (תיקון מס' 2), תשכ"ז-1967                                              |

|1. במקום סעיף 7 לחיק תקציבי השירותים הדתיים, תש"ט-1949 1, יבוא:                                              |תיקון סעיף 7     |
|7. (א) הרכב כל מועצה דתית יחודש על ידי שר הדתות בהתאם                                 |"חידוש ההרכב          |                 |
|לסעיף 4(1) עד (5) לא יאוחר מיום כ"ו באלול תשכ"ז (1 באוקטובר                           |                      |                 |
|1967)' ומכאן ואילך כל ארבע שנים לאחר היום האמור.                                      |                      |                 |
|(כ) הודעה על ההרכב החדש תפורסם ברשומות; עד יום הפרסום                                 |                      |                 |
|יוסיף לכהן ההרכב הקודם' ומאותו יום יכהן ההרכב החדש."                                  |                      |                 |
|דברי הסבר                                                                             |                      |                 |
|התיקון המוצע בא להסדיר דרך קבע את חידוש הרכבן של המועצות הדתיות. מוצע                                        |                 |
|שהרכבי המועצות יחודשו עד יום 1 באוקטובר 1967, וכל ארבע שנים לאחר תאריך זה,                                   |                 |
|ושההוראות שבסעיף 4 לחוק' בדבר הקמת מועצה דתית ברשות מקימית שעדיין לא הוקמה                                   |                 |
|בה' יהיו להסדר קבע לגבי כל המועצות הדתיות בארץ, כקיימות בעתידות.                                             |                 |
|וזה נוסחם של סעיפים 4 ו-7 לחוק:                                                                              |                 |
|4. ברשות מקומית שאין בה מועצה דתית רשאי שר הדתות להקים מועצה דתית, בהתאם              |"הקמת מועצות          |                 |
|להוראות אלה:                                                                          |דתיות                 |                 |
|(1) מספר חברי המועצה הדתית שלא יעלה על מספר חברי הרשות המקומית,                       |                      |                 |
|ייקבע על-ידי שר הדתות;                                                                |                      |                 |
|(2) ממספר חברי המועצה הדתית יוצעו כמועמדים:                                           |                      |                 |
|(א) 45% על-ידי שר הדתות;                                                              |                      |                 |
|(ב) 45% על-ידי הרשות המקומית;                                                         |                      |                 |
|(ג) 10% על-ידי הרבנות המקומית;                                                        |                      |                 |
|לצורך קביעת מספר המועמדים כאמור ייחשב שבר המגיע לחצי ומעלה כיחידה שלמה;               |                      |                 |
|(3) שלושת הגופים הנזכרים בפסקה (2) יחוו דעתם על המועמדים להתמנות כחברי                |                      |                 |
|המועצה הדתית מבחינת התאמתם ؀ࠂࠌࠎהאישית לשמש בתפקיד זה ומבחינת ייצוגם המתאים,           |                      |                 |
|בתוך המועצה הדתית, של הגופים ושל העדות המעונינים בקיומם של השירותים                   |                      |                 |
|הדתיים במקום;                                                                         |                      |                 |
|(4) (א) לא הציעה הרשות המקומית לשר הדתות מכסת המועמדים למועצה הדתית                   |                      |                 |
|לפי פסקה (2) (ב) תוך שלושים יום מיום שנשלחה אליה דרישת השר, תישלח                     |                      |                 |
|דרישה נוספת; לא נענתה הרשות המקומית גם לדרישה הנוספת תוך חמישה עשר                    |                      |                 |
|יום מיום שנשלחה, רשאי שר הדתות להציע את מכסת החברים שנועדה לרשות                      |                      |                 |
|המקומית.                                                                              |                      |                 |
|(ב) הוראת פסקת משנה (א) תחול גם על מכסת המועמדים לפי פסקה (2) (ג);                    |                      |                 |
|(5) נתגלעו חילוקי דעות בין שלושת הגופים הנזכרים בפסקה (2) יובאו חילוקי                |                      |                 |
|הדעות להכרעת ועדת שרים המורכבת משר הדתות, שר המשפטים ושר הפנים או                     |                      |                 |
|נציגיהם; ערער שר על החלטת הועדה, תכריע הממשלה.                                        |                      |                 |
|7. כהונתה של מועצה דתית תיתם לא יאוחר מיום י"ט באדר כי תשכ"ז (31 במרס 1967)."         |                      |                 |

|1 ס"ח 19, תש"ט, עמ' 150; ס"ח 479, תשכ"ו, עמ' 50.        |
