|1. בסעיף 3 לחוק חופשה שנתית, תשי"א-1951 1 (להלן - החוק העיקרי)' בסעיף                                       |תיקון סעיף 3     |
|קטן(א) -                                                                                                    |                 |
|(1) בפסקה (5)' הסיפה אחרי הנקודה-פסיק תימחק;                                                                |                 |
|(2) בסוף הסעיף הקטן יבוא:                                                                                   |                 |
|"בימי החופשה לא ייכלל אלא מנוחה שבועית אחת לכל שבעה ימי חופשה."                                             |                 |
|2. בסעיף 10 לחוק העיקרי' בסעיף קטן (ג)' אחרי "שעות העבודה הרגילות" יבוא "זולת                               |תיקון סעיף 10    |
|אם נקבע אחרת בהסכם קיבוצי שאושר לענין זה על ידי שר העבודה".                                                 |                 |
|דברי הסבר                                                                               |                  |                 |
|א. במסגרת משא ומתן לקראת הסכם קיבוצי מתברר לעתים כי צריך לאפשר                                              |                 |
|גמישות בחישוב שכר העבודה לענין תשלום דמי חופשה שנתית. מוצע איפוא לאפשר                                      |                 |
|שבהסכם קיבוצי ייקבע הסדר אחר הנראה לצדדים, וכי הסדר זה יהיה טעון אישורו של                                  |                 |
|שר העבודה (סעיף 2).                                                                                         |                 |
|ב. ההוראה שבימי חופשה לא תיכלל אלא מנוחה שבועית אחת לכל שבעה ימי                                            |                 |
|חופשה מצויה כיום בסיפה של פסקה (5) בסעיף 3 (א) לחוק העיקרי. כדי להבהיר שכוונת                               |                 |
|החוק שהוראה זו תחול בכל מקרה' ולא רק כאשר אורך החופשה הוא למעלה מ-21 יום,                                   |                 |
|מוצע להעביר את ההוראה לסוף סעיף קטן (א) (סעיף 1).                                                           |                 |
|ואלה סעיפי החוק העיקרי שהחוק המוצע בא לתקנם:                                                                |                 |
|3. (א) אורך החופשה לכל שנת עבודה אצל מעביד אחד או במקום עבודה אחד הוא:                  |אורך החופשה       |                 |
|(1) בעד כל אחת מ-4 השנים הראשונות - 14 יום;                                             |                  |                 |
|(2) בעד השנה החמישית - 16 יום;                                                          |                  |                 |
|(3) בעד השנה השישית - 18 יום;                                                           |                  |                 |
|(4) בעד השנה השביעית - 21 יום;                                                          |                  |                 |
|(5) בעד השגה השמינית ואילך - יום נוסף לכל שגת ؀ࠂࠌࠎעבודה עד לחופשה של 28                 |                  |                 |
|יום; בימי החופשה לא ייכלל אלא יום מנוחה שבועית אחד לכל שבעה ימי חופשה.                  |                  |                 |
|אך שר העבודה רשאי לקבוע, בתקנות, לעבודה מסויימת חופשה ארוכה מזו, אם ראה צורך            |                  |                 |
|בכך מטעמים שבבריאות העובד או שבנסיבות העבודה.                                           |                  |                 |
|10. (א) המעביד חייב לשלם לעובד בעד ימי החופשה דמי חופשה בסכום השווה לשכרו הרגיל.        |דמי החופשה        |                 |
|(ב) השכר הרגיל לענין סעיף זה הוא -                                                      |                  |                 |
|(1) לגבי עובד שגמול עבודתו, כולו או הלקו, משתלם על בסיס של חודש או תקופה                |                  |                 |
|ארוכה מזו - שכר העבודה שהעובד היה מקבל בעד אותו סרק זמן אילו לא יצא                     |                  |                 |
|לחופשה והוסיף לעבוד;                                                                    |                  |                 |
|(2) לגבי עובד בשכר - שכר העבודה היומי הממוצע כפול במספר ימי החופשה;                     |                  |                 |
|שכר העבודה היומי הממוצע הוא הסכום היוצא מחילוק שכר רבע השנה שקדמה                       |                  |                 |
|לחופשה למספר תשעים; היו ברבע השנה כאמור חדשי עבודה לא-מלאה, יחושב                       |                  |                 |
|השכר היומי הממוצע לפי רבע השנה של העבודה המלאה ביותר שבשנים עשר                         |                  |                 |
|החדשים שקדמו לחופשה, הכל לסי בחירת העובד.                                               |                  |                 |
|(ג) שכר עבודה לענין סעיף קטן (ב) הוא כל תמורה, בכסף או בשווה כסף, המשתלמת               |                  |                 |
|לעובד על ידי המעביד בעד שעות העבודה הרגילות; סכום המשתלם לעובד לכיסוי הוצאות            |                  |                 |
|מיוחדות שאינן קיימות בעת החופשה, אין רואים אותו כחלק משכר העבודה.                       |                  |                 |
