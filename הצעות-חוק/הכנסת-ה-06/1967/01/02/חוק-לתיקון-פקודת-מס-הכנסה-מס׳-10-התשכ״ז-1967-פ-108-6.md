|1, בסעיף 9 לפקודת מס הכנסה 1, במקום פסקה (1) יבוא:                                                                 |תיקון סעיף 9     |
|"משכורתו של נשיא המדינה והגימלה המשתלמת לו או לשאיריו על פי                                                        |                 |

|דברי-הסבר                                                                                                          |                 |
|סעיף 16 לחוק-יסוד: נשיא המדינה' מסמיך את הכנסת - וזו רשאית לאצול סמכותה                                            |                 |
|לועדת הכספים - לקבוע את "משכורתו של נשיא המדינה ותשלומים אחרים שישולמו לו                                          |                 |
|בתקופת כהונתו או אחריה' לרבות אלה שישולמו לשאיריו",                                                                |                 |
|משכורתו של הנשיא פטורה ממס הכנסה על סי הוראות סעיף 9 (1) לפקודת מס הכנסה                                           |                 |
|הקובע:                                                                                                             |                 |
|"9. פטורים ממס:                                                                                                    |                 |
|(1) משכורתו של נשיא המדינה"..                                                                                      |                 |
|פטור זה אינו חל על הגימלה המשתלמת לנשיא בתום כהונתו ולא על זו המשתלמת                                              |                 |
|לשאיריו. לעומת זאת קיבלה הכנסת בשעתה את חוק הנשיא חיים וייצמן (גימלה ועזבון),                                      |                 |
|תשי"ג- 1953 3,ולפיו הגימלה ؀ࠂࠌࠎשנקבעה לאלמנת הנשיא הראשון "תהיה פטורה ממסי ממשלה".                                 |                 |
|נמצא שלפי החוק הקיים משכורתו של נשיא המדינה אמנם פטורה ממס-הכנסה, אך                                               |                 |
|לא הגימלה המשתלמת לו או לשאיריו. החוק המוצע בא להחיל פטור זה גם עליה.                                              |                 |
