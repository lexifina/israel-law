|מתפרסמות בזה הצעות חוק מטעם הממשלה:                   |

|חוק לתיקון פקודת סדרי השלטון והמשפט (מס' 12), תשכ"ז-1967                                               |

|1, בסעיף 9 לפקודת סדרי השלטון והמשפט, תש"ח-1948 1, בסעיף קטן (ג), בסופו יבוא                                 |תיקון סעיף 9      |
|"בחישוב התקופה של שלושה חדשים לא יבוא במנין הזמן שבין כנסי הכנסת".                                           |                  |
|דברי הסבר                                                                                                    |                  |
|בסעיף 9 (ג) לפקודת סדרי השלטון והמשפט, תש"ח-1948, נאמר:                                                      |                  |
|"(ג) תקנה-לשעת-חירום, תקפה יפקע כעבור שלושה חדשים מיום התקנתה, בלתי אם                                       |                  |
|הוארך תקפה או נתבטלה התקנה קודם לכן על ידי פקודה של מועצת המדינה הזמנית, או נתבטלה                           |                  |
|על ידי הרשות המתקינה."                                                                                       |                  |
|המחוקק אמנם נתן את דעתו לשאלה מה דינה של תקנה-לשעת-חירום שתקפה פקע                                           |                  |
|בתקופה שבין כנסת לכנסת וקבע, בסעיף 38 לחוק-יסוד; הכנסת, הוראה זו:                                            |                  |
|"כל חיקוק שתקפו היה פוקע תוך שני החדשים האחרונים לתקומת כהונתה של הכנסת היוצאת,                              |                  |
|או תוך ארבעה חדשים לאחר שהכנסת החליטה להתפזר, או תוך שלושת החדשים הראשונים                                   |                  |
|לתקופת כהונתה של הכנסת הנכנסת - יעמוד בתקפו עד חום שלושת החדשים האמורים.*                                    |                  |
|אולם אין הוראה כללית הקובעת את גורלם של חיקוקים שתקפם פקע בזמן שכין                                          |                  |
|כנסי הכנסת. בתיקון לסעיף 2 לחוק מס מכס ובלו (שינוי תעריף), תש"ט-1949, שנתקבל                                 |                  |
|בשנת תש؀ࠂࠌࠎ"ך-1960, נקבע כי בחישוב תקופת תקפם של צווים המגדילים את שיעורי המכס                               |                  |
|והבלו ושטרם אושרו על ידי הכנסת, לא יבוא במנין הזמן שבין כנסי הכנסת.                                          |                  |
|כל תקנות-שעת-חירום שהותקנו אחרי יום ח' באייר תשכ"ז (18 במאי 1967) -                                          |                  |
|תקפן יפקע בזמן שבין מושב הקיץ ומושב החורף של הכנסת. מאחר שיהא צורך להציע                                     |                  |
|את הארכת תקפן של חלק לפחות מתקנות אלה, ואין שהות לכנסת לקיים דיון בהצעות אלה                                 |                  |
|לפני סיום מושב הקיץ, מוצע שגם בחישוב התקופה של שלושת החדשים כאמור בסעיף                                      |                  |
|9 (ג) לא יבוא במנין הזמן שבין כנסי הכנסת.                                                                    |                  |

|1 ע"ר תש"ח, תוס' א' מס' 2, עמ' 1; ס"ח 499, תשכ"ז, עמ' 74.            |
