|1. בסעיף 8 לחוק בתי הדין הדתיים הדרוזיים, תשכ"ג-1962  1(להלן - החוק העיקרי),                             |תיקון סעיף 8       |
|בסופו יבוא;                                                                                              |                   |
|"בית דין או בית דין לערעורים שמספר הקאדים-מד'הב פחת בו משלושה,                                           |                   |
|משום שאחד מחבריו פרש מן הכהונה, יצא לקיצבה, נפטר או נבצר ממנו                                            |                   |
|למלא תפקידו, רשאי הוא לדון בשנים".                                                                       |                   |
|2. על אף האמור בסעיף 19 לחוק העיקרי -                                                                    |הוראות מעבר        |
|(1) מי שהיה קאדי-מד'הב ויצא לקיצבה לפני תחילתו של חוק זה, רשאי                                           |                   |
|מיום תחילתו של חוק זה להמשיך לכהן בתפקידו שכיהן ערב צאתו לקיצבה,                                         |                   |
|ודינו כקאדי-מד'הב שטרם יצא לקיצבה?                                                                       |                   |
|(2) ראש בית הדין לערעורים המכהן גם כיושב ראש המועצה הדתית הדרוזית,                                       |                   |
|רשאי, כל עוד הוא מכהן כאמור, להמשיך בתפקידו כראש בית הדין לערעורים.                                      |                   |
|3. הליך שנתקיים בבית דין או בבית דין לערעורים לפני תחילתו של חוק זה לא ייפסל                             |אישור פעולות       |
|מחמת זאת בלבד שדנו בו בשנים.                                                                             |                   |

|דברי הסבר                                                                                                  |
|חוק בתי הדין הדרוזיים, תשכ"ג-1962, מחייב את בתי הדין הללו לדון בהרבבים של                                  |
|שלושה. למעשה אין בבתי דין אלה כי אם שלושה קאדים-מד'הב, ונמצא שבכל מקרה                                     |
|שנבצר מאחד מהקאדים-מד'הב לשבת בדיון, ועל אחת כמה וכמה אם פרש, יצא לקיצבה                                   |
|או נפטר, אין בית הדין יכול לפעול. ואילו מינוים של קאדים-מד'הב כרוך בקשיים שאינם                            |
|מאפשרים מינוי תכוף של קאדי-מד'הב נוסף. על כן מוצע לאפשר במקרים כאלה לבית                                   |
|הדין לדון בשנים. כן באה הצעת החוק לתת תשריר להליכים שנתקיימו בשנים.                                        |
|הוראות המעבר בסעיף 2 מכוונות לאפשר לקאדי-מד'הב שפרש בינתיים לקיצבה                                         |
|להמשיך בתפקידו, על אף הגיעו לגיל ؀ࠂࠊࠌࠐࠔהפרישה, כל עוד לא ניתן למנות אחר תחתיו, ולאפשר                      |
|לראש המועצה הדתית הדרוזית להמשיך ולמלא תפקידו כראש בית הדין הדתי לערעורים                                  |
|על אף הגיעו לגיל הפרישה. ראש המועצה הדתית בעדה הדרוזית נחשב כסמכות עליונה                                  |
|בכל עניני דת ודין, ואין למנות אחר לתפקיד ראש בית הדין לערעורים.                                            |
|ואלה הם סעיפי החוק שמוצע לשנותם:                                                                           |
|8. בית דין ידון בשלושה; בית הדין לערעורים ידון בלא פחות משלושה.                          |הרכב בתי הדין    |
|10. (א) קאדי-מד'הב יצא לקיצבה -                                                          |קיצבה            |
|(1) בהגיעו לגיל שבעים;                                                                   |                 |
|(2) משקבעה ועדת המינויים, על יסוד חוות דעת רפואית, שמחמת מצב בריאותו                     |                 |
|נבצר ממנו להמשיך במילוי תפקידו.                                                          |                 |
|(ב) קאדי-מד'הב רשאי לצאת לקיצבה -                                                        |                 |
|(1) לאחר שכיהן עשרים שנה, אם הגיע לגיל ששים;                                             |                 |
|(2) לאחר שניהן חמש עשרה שנה, אם הגיע לגיל ששים וחמש;                                     |                 |
|(3) אם ביקש זאת ובקשתו אושרה על ידי ועדת המינויים.                                       |                 |
|(ג) בחישוב תקופת כהונתו של קאדי-מד'הב לענין סעיף קטן (ב) תצורף אל תקופת                  |                 |
|כהונתו כקאדי-מד'הב כל תקופת שירותו במדינה או במוסד אחר שועדת הכספים של הכנסת             |                 |
|אישרה אותו לענין זח, או מקצתה של תקופה זו, הכל לפי כללים שקבעה ועדת הכספים.              |                 |
