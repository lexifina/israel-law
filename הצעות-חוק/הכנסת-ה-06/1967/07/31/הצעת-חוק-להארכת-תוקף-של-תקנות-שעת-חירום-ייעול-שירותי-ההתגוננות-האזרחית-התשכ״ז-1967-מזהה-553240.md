|2. תחילתו של חוק זה היא ביום כ"ח באב תשכ"ז (3 בספטמבר 1967).                                                    |תחילה         |
|דברי הסבר                                                                                 |                     |              |
|תקנות-שעת-חירום (ייעול שירותי ההתגוננות האזרחית), תשכ"ז-1967, קובעות                                            |              |
|הוראות נוספות לחוק ההתגוננות האזרחית, תשי"א-1951, ומטרתן העיקרית היא לייעל את                                   |              |
|שירותי הגא שלא בשעת הרגיעה. הוראות אלה כוללות, כין השאר, מתן סמכויות לפינוי                                     |              |
|מקלטים ולציודם וכן לחיוב תושבים להצטייד בציוד אישי להתגוננות אזרחית.                                            |              |
|תקפן של תקנות אלה יפקע ביום כ"ח באב תשכ"ז (3 בספטמבר 1967). מאחר שהצורך                                         |              |
|בתקנות בעינו עומד מציעה הממשלה להאריך את תקסן עד סיום שנת 1967.                                                 |              |
|וזה נוסח התקנות שמוצע להאריך את תקפן:                                                                           |              |
|בתוקף סמכותי לסי סעיף 9(א) לפקודת סדרי השלטון והמשפט, תש''ח-1948  1 אני מתקין                                   |              |
|תקנות אלה:                                                                                                      |              |
|1. בתקנות אלה יהיו לכל המונחים אותה משמעות שיש להם בחוק ההתגוננות האזרחית,                |פרשנות               |              |
|תשי"א-1951 (להלן-חוק הגא).                                                                |                     |              |
|2. על אף האמור בסעיפים 7, 7א ו-7ב לחוק הגא -                                              |תפקידים              |              |
|(א) יראו את התפקידים שהוכרזו על פי סעיף 7 לחוק האמור או שיוכרזו על פיו כתפקידים           |נדרשים בהגא          |              |
|שהפעולות הקשורות בהט מוגבלות לתחום מחוז הגא;                                              |                     |              |
|(ב) תהיה הסמכות של מפקד הגא מחוזי לתת הודעת הצבה גם בידי מי שהוסמך לכך על                 |                     |              |
|ידי מפקד הגא מחוזי;                                                                       |                     |              |
|(ג) לא יוצב אדם למלא תפקיד נדרש בהגא, לא ייקרא למלאו ולא יהיה חייב למלאו                  |                     |              |
|או ליטול חלק בתמרוני הגא, מחוץ לתחום מחוז הגא שבו גר או עובד.                             |                     |              |
|3. הוראה או צו שינתנו על פי התקנות שהותקנו לפי סעיף 14ב לחוק הגא יהיו טעונים-פרסום        |הוראה או צו לפי      |              |
|ברשומות.                                                                                  |סעיף 14ב לחוק        |              |
|                                                                                          |הגא                  |              |
|4. (א) הוכרז מצב הכן בהגא על פי סעיף 21(א) לחוק הגא יחולו הוראות אלה:                     |הוראות מיוחדות       |              |
|(1) הרשיונות לפי סעיף 15(א) לחוק הגא, חמקנים זכות שימוש במקלט למטרה                       |למצב הכן             |              |
|אחרת מאשר לחסות בו בשעת התקפה - בטלים;                                                    |                     |              |
|(2) על המחזיק במקלט לפנותו מיד מחמטלטלים שבו, למעט הציוד שהוא חייב                        |                     |              |
|להחזיקו במקלט לפי דיני ההתגוננות האזרחית, או לפי תקנות אלה או על פיהן;                    |                     |              |

|(3) מפקד הגא מחוזי או מי שהוסמך על ידיו רשאי, אם שוכנע שהדבר דרוש למתן                     |                    |
|מחסה לציבור בשעת התקפה, להורות בצו למחזיק במחסה ציבורי לסנותו מהמטלטלים                    |                    |
|שבו, כולם או מקצתם, ולהפסיק את השימוש בו, כולו או מקצתו, שלא לצורך                         |                    |
|ההתגוננות האזרחית;                                                                         |                    |
|(4) חבר הגא שמונה לכך על ידי ראש הגא או על ידי מפקד הגא מחוזי יהיה רשאי,                   |                    |
|תוך שימוש בסמכויותיו לסי סעיף 9 לחוק הגא, לפנות מטלטלין מתוך מקלט או מתוך                  |                    |
|מחסה ציבורי, אם יש בהט כדי להפריע לשימוש יעיל במקלט או במחסה הציבורי לצרכי                 |                    |
|התגוננות אזרחית; השימוש בסמכויות לפי תקנת משנה זו ייעשה תוך נקיטת ؀ࠂࠊࠌࠐࠔכל                 |                    |
|הצעדים הסבירים, בהתחשב בנסיבות המיוחדות של כל מקרה, למניעת נזק למטלטלים                    |                    |
|או להפחתתו של הנזק;                                                                        |                    |
|(5) המחזיק במקלט או במחסה ציבורי חייב לפתחו ולהחזיקו פתוח בכל עת, כדי                      |                    |
|לאפשר בשעת התקפה לכל אדם, הנמצא סמוך למקלט או למחסה הציבורי, כניסה                         |                    |
|מיידית לתוכו.                                                                              |                    |
|5. (א) מפקד הגא מחוזי, או מי שהוסמך על ידיו, רשאי לצוות על כל מחזיק במקלט או               |חובת הצטיידות       |
|במחסה ציבורי שבתחום המחוז, לצייד את המקלט או את המחסה הציבורי בציוד כסי שיקבע בצו,         |                    |
|להחזיק את הציוד במצב ראוי לשימוש ולהתקין לפני הכניסה למקלט או למחסה הציבורי, במקום         |                    |
|בולט לעין, שילוט מתאים.                                                                    |                    |
|(ב) מפקד הגא מחוזי רשאי להטיל בצו על כל אדם חגר או העובר בתחום מחוזו להצטייד               |                    |
|בציוד אישי להתגוננות אזרחית, עבורו ועבור הקטינים הגרים עמו, ולשאת את הציוד, להתקינו        |                    |
|או להשתמש בו בכל דרך אחרת במועד ובנסיבות, הכל כסי שיקבע מפקד הגא מחוזי באותו צו            |                    |
|או בצו אחר.                                                                                |                    |
|6. (א) צו לפי תקנות אלה יכול להיות כללי, לסוג מסויים או אישי.                              |צווים               |
|(ב) צו לפי תקנות אלה אינו טעון פרסום ברשומות.                                              |                    |
|(ג) צו לפי תקנות אלה מחייב את האדם שעליו הוא חל מן הזמן שהגיע לידיעתו.                     |                    |
|(ד) צו שפורסם ברשומות, רואים אותו כאילו הגיע לידיעת האדם שעליו הוא חל בצהרי                |                    |
|היום שלאחר יום הפרסום.                                                                     |                    |
|(ה) צו שלא פורסם ברשומות, הרי -                                                            |                    |
|(1) אם הוא נמסר לאדם שעליו הוא חל, או לאדם בגיר הגר עמו, רואים אותו                        |                    |
|כאילו הגיע לידיעת אותו אדם בזמן המסירה;                                                    |                    |
|(2) אם הוא נשלח לאדם שעליו הוא חל בדואר רשום לפי מען מקום מגוריו הקבוע,                    |                    |
|או לפי מען מקום עסקיו, רואים אותו כאילו הגיע לידיעת אותו אדם בתום 48 שעות                  |                    |
|מזמן שנמסר לדואר למשלוח;                                                                   |                    |
|(3) אם הוצג באופן בולט על פני הדלת של מקום מגוריו הקבוע או של מקום עסקיו                   |                    |
|של אדם שעליו הוא חל, רואים אותו כאילו הגיע לידיעת אותו אדם בתום 12 שעות                    |                    |
|מזמן ההצגה;                                                                                |                    |
|(4) אם פורסם ברדיו או לפחות בשלושה עתונים יומיים, רואים אותו כאילו חגיע                    |                    |
|לידיעת אותו אדם שעליו הוא חל, למחרת יום הפרסום.                                            |                    |
|7. (א) כל המפר הוראה מהוראות תקנות אלה או הוראה שניתנה על פיהן, או המתרשל                  |עונשין              |
|בקיומה, דינו - מאסר שנה או קנס של אלף וחמש מאות לירות או שני העונשים גם יחד.               |                    |
|(ב) תקנות אלה אינן גורעות מאחריות סלילית של אדם למעשה או למחדל לפי כל דין                  |                    |
|אחר, אך לא ישא אדם באחריות פלילית לאותו מעשת או מחדל יותר מפעם אחת.                        |                    |
|8. (א) הסמכויות שבתקנות אלה או על פיהן באות להוסיף על הסמכויות לפי כל דין אתר              |תקנות אלה           |

|(ב) הטלת חובה בתקנות אלה או טל פיהן, אין בה כדי לפטור מקיום חובה כלפי רשות                 |                    |
