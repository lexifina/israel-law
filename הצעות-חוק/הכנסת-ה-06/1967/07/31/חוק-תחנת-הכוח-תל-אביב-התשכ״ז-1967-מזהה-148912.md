|מתפרסמות בזה הצעות חוק מטעם הממשלה:                     |

|חוק תחנת הכוח תל-אביב, תשכ"ז-1967                             |

|1. הממשלה רשאית על פי הצעת חברת החשמל לישראל בע"מ, לאשר תכנית לבניה                                        |אישור תכנית     |
|ולהפעלה של תחנת כוח חשמלית בשטח הנמצא בתחום עירית תל-אביב-יפו ובמימי החופין                                |תחנת הכוח       |
|הסמוכים לו (להלן - תחנת הכוח) ורשאית הממשלה לתקן את התכנית, הן ביזמתה היא                                  |                |
|והן על פי הצעה כאמור; תכנית שאושרה כאמור, וכפי שתוקנה מזמן לזמן, תיקרא להלן                                |                |
|"תכנית תחנת הכוח".                                                                                         |                |
|2, אושרה תכנית תחנת הכוח, לא יהיו הקמת תחנת הכוח, הפעלתה והשימוש בה טעונים                                 |פטור            |
|רשיון, היתר, פטור, אישור וכיוצא באלה, על פי חוק התכנון והבניה, תשכ"ה-1965 1,                               |                |
|פקודת המלאכות והתעשיות (הסדרתן)2 והתקנות על פיהם.                                                          |                |
|3. הממשלה תקבע בתקנות את דרכי הפיקוח על ביצוע תכנית תחנת הכוח, הפעלתה                                      |פיקוח ודו"חות   |
|והשימוש בה, הכל כדי להבטיח שיהיו לפי התכנית, ורשאית היא, בתקנות אלה -                                      |                |
|(0 לקבוע כי הוראות חוק התכנון והבניה, תשכ"ה-1965, פקודת המלאכות                                            |                |
|והתעשיות (הסדרתן) והתקנות על פיהם, כולן או מקצתן, יחולו, בשינויים                                          |                |
|ובהתאמות שתקבע, על הקמת תחנת הכוח, הפעלתה והשימוש בה;                                                      |                |
|(2) להטיל חובה להגיש לה דינים וחשבונות חד-פעמיים או תקופתיים כפי                                           |                |
|שייראה ؀ࠂࠌࠎלה.                                                                                             |                |
|4. שרי הפיתוח והפנים ממונים על ביצוע חוק זה והם רשאים להתקין תקנות לביצועו.                                |ביצוע ותקנות    |
|דברי הסבר                                                                                                  |                |
|קיים צורך חיוני להתחיל ללא דיחוי בהקמת תחנת הכוח החשמלית רדינג ד' בסמוך                                    |                |
|לתחנת הכוח הקיימת.                                                                                         |                |
|הקמת תחנת-הכוח מצריכה הטלת תנאים והסדרים מיוחדים החורגים מתחום פעולתם                                      |                |
|וסמכותם של המוסדות הפועלים לפי חוק התכנון והבניה, תשכ"ה - 1965' ולפי פקודת                                 |                |
|המלאכות והתעשיות (הסדרתן). השיקולים בקביעת התכנית של תחנת הכוח ופרטיה חורגים                               |                |
|גם הם מהחיקוקים האמורים.                                                                                   |                |
|החוק המוצע יאפשר לממשלה לקבוע תכנית ולהחיל עליה את הוראות שני החיקוקים                                     |                |
|האמורים הצריכות לענין ודרכי פיקוח מיוחדים על ביצוע תכנית תחנת הכוח, הפעלתה                                 |                |
|והשימוש בה.                                                                                                |                |
