|מאחר שהצורך בתקנות בעינו עומד, מציעה הממשלה להאריך את תקפן עד סיום                                                  |

|וזה נוסח התקנות שמוצע להאריך את תקפן:                                                                               |
|בתוקף סמכותי לפי סעיף 9 (א) לפקודת סדרי השלטון והמשפט, תש"ח-1948, אני מתקין                                         |
|תקנות-שעת-חירום אלה:                                                                                                |
|1. בתקנות אלה -                                                                          |הגדרות                    |
|"התנדבות לעבודה" - עבודה בהתנדבות בעסק, במפעל, במשק ובשירות ציבורי ושלא על מנת           |                          |
|לקבל פרס;                                                                                |                          |
|"משק" - עבודה חקלאית ושירותים חקלאיים;                                                   |                          |
|"מתנדב" - מי שעושה בהתנדבות לעבודה אצל הזולת;                                            |                          |
|"המעסיק" - מי שאצלו מועסק המתנדב;                                                        |                          |
|"חוק הביטוח" - חוק הביטוח הלאומי, תשי"ד-1953;                                            |                          |
|"עובד" ו"עובד עצמאי" - במשמעותם בסעיף 1 לחוק הביטוח;                                     |                          |
|"מועד תשלום" - כמשמעותו בתקנות הביטוח הלאומי (גביית דמי-ביטוח), תשי"ד-1954.              |                          |
|2. לענין חלק ב' לחוק הביטוח:                                                             |דינו של מתנדב             |
|(1) מתנדב שבתקופת ההתנדבות לעבודה הוא מבוטח כעובד שמעבידו חייב לפי חוק                   |לענין חוק הביטוח          |
|הביטוח בתשלום דמי-ביטוח בעדו, או כעובד עצמאי - ייחשב לגבי ההתנדבות                       |                          |
|לעבודה כממשיך לעבוד אצל אותו המעביד או לעסוק במשלח-ידו כעובד עצמאי,                      |                          |
|לפי הענין.                                                                               |                          |
|(2) מתנדב שאינו מהסוג האמור בפסקה (1) -                                                  |                          |
|(א) ייחשב לגבי ההתנדבות לעבודה כאדם המצוי בהכשרה מקצועית לפי                             |                          |
|סעיף 16 (א) (2) לחוק הביטוח אם הוא מתחת לגיל 18 ועבודתו בהתנדבות                         |                          |
|תיחשב בהכשרתו המקצועית;                                                                  |                          |
|(ב) ייחשב לגבי ההתנדבות ؀ࠂࠊࠌࠐࠔלעבודה כעובד ועבודתו בהתנדבות תיחשב כעבודה                 |                          |
|שלגביה מתקיימים יחסי מעביד ועובד אם הוא בן 18 ומעלה.                                     |                          |
|3. המעסיק ישלם דמי-ביטוח נגד פגיעה בעבודה (להלן - דמי-ביטוח) במקרים הבאים בלבד:          |חישוב דמי הביטוח          |
|(1) בעד מתנדב כאמור בתקנה 2 (2) (א) לפי הכללים שבתקנה 27 (א) לתקנות                      |                          |
|הביטוח הלאומי (ביטוח מפני פגיעה בעבודה), תשי"ד-1954 (להלן - התקנות בדבר                  |                          |
|פגיעה בעבודה);                                                                           |                          |
|(2) בער מתנדב כאמור בתקנה 2 (2) (ב) - לפי שכר של 15 לירות ליום ושיעור                    |                          |
|דמי-הביטוח הוא לפי סעיף הסיכון של מקום העבודה בהתנדבות כאמור בתוספת                      |                          |
|הראשונה לתקנות בדבר פגיעה בעבודה.                                                        |                          |
|4. המעסיק יגיש במועד תשלום דמי-הביטוח רשימה שמית של מתנדבים המועסקים אצלו עם             |הגשת דו"ח                 |
|ציון מספר תעודת הזהות של כל אחד מהם.                                                     |                          |

|בכל תביעה לגימלה לפי תקנות אלה ובכל תביעה להחזרת גימלה שניתנה בטעות או שלא כדין          |לביטוח לאומי              |
