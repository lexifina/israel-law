|דברי הסבר                                                                                                   |                   |
|קבלת משקאות משכרים בחצריו של יצרן, הוצאתם והובלתם משם, טעונות היתר של                                       |                   |
|מנהל אגף המכס והבלו (להלן - המנהל); ו"היתר" פירושו, בין היתר, תעודה שניתנה מאת                              |                   |
|סיטונאי בהרשאת המנהל; וזו לשון ההגדרה:                                                                      |                   |
|""היתר" - היתר שניתן מאת המנהל או מאת פקיד שהרשהו המנהל כראוי, לרבות תעודה                                  |                   |
|שניתנה מאת סיטונאי בהרשאת המנהל."                                                                           |                   |
|מוצע עתה, שגם תעודה שניתנה על ידי יצרן תשמש "היתר", בתנאי שניתנה בהרשאת                                     |                   |
|המנהל או על פי הוראותיו (סעיף 1).                                                                           |                   |
