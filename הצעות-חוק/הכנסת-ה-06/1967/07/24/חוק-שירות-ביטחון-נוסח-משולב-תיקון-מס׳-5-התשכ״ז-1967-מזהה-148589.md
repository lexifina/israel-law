|חוק שירות בטחון [נוסח משולב] (תיקון מס' 5), תשכ"ז-1967                                   |

|1. בסעיף 16 (ד) לחוק שירות בטחון, תשי"ט-1959 ננוסח משולב]1, במקום "עד יום אי                             |תיקון סעיף 16      |
|בתשרי תשכ"ח (5 באוקטובר 1967)" יבוא "עד יום א' בתשרי תשל"א (1 באוקטובר 1970)".                           |                   |
|2. תחילתו של חוק זה היא ביום א' בתשרי תשכ"ח (5 באוקטובר 1967).                                           |תחילה              |
|דברי הסבר                                                                                                |                   |
|בסעיף קטן (א) לסעיף 16 לחוק הקיים נאמר:                                                                  |                   |
|''שנים עשר החדשים הראשונים לשירותו הסדיר של יוצא-צבא יוקדשו בעיקרם, אחרי אימון                           |                   |
|צבאי ראשוני, להפשרה חקלאית, כפי שייקבע בתקנות, אלא שלגבי יוצא-צבא שנשלח לשירות                           |                   |
|בחיל האויר או בחיל הים רשאי שר הבטחון להורות שתקופת שירותו המיועדת להכשרה חקלאית                         |                   |
|תוקדש כולה או מקצתה לשירות באותו חיל.*                                                                   |                   |
|בסעיף קטן (ד) לאותו סעיף נקבע:                                                                           |                   |
|"עד יום א' בתשרי תשכ"ח (5 באוקטובר 1067) רשאי שר הבטחון להורות לגבי יוצא-צבא בגיל                        |                   |
|18 או יותר, כי תקופת שירותו ؀ࠂࠊࠌהסדיר המיועדת להכשרה חקלאית תידחה או תוקדש, על אף                        |                   |
|האמור בסעיף קטן (א), כולה או מקצתה, לשירות סדיר שאיגו בגדר הכשרה חקלאית.*'                               |                   |
|החוק המוצע בא להאריך את התקופה שבה רשאי שר הבטחון לתת הוראה כאמור                                        |                   |
|בסעיף קטן (ד) לשלוש שבים נוספות, בלומר עד יום אי בתשרי תשל"א (1 באוקטובר 1970).                          |                   |

|1 ס"ח תשי"ט, עמ' 286; תשכ"א, עמ' 140; תשכ"ג, עמ' 128; תשכ"ד, עמ' 10; תשכ"ד, עמ' 168.         |
