|"שירות-חירום" - שירות ששר הבטחון, באישור ועדת החוץ והבטחון של הכנסת, הכריז                                 |                   |
|עליו כעל שירות-חירום לענין חוק זה.                                                                         |                   |
|2. (א) שר הבטחון רשאי למנות קצינים מוסמכים לצורך חוק זה.                                                   |קצינים מוסמכים     |
|(ב) כל מינוי של קצין מוסמך יפורסם ברשומות.                                                                 |                   |
|3. (א) היו בידי קצין מוסמך ראיות מספיקות לכך שחייל בשירות-חירום נפטר במדינה                                |אישור סטירת        |

|(ב) אישור פטירת חייל יכיל את הפרטים על הנפטר הידועים לקצין המוסמך; ואלה                                    |                   |
|הם הפרטים:                                                                                                 |                   |
|(0 שם המשפחה והשם הפרטי;                                                                                   |                   |
|(2) מספר הזהות במרשם האוכלוסין;                                                                            |                   |
|(3) המספר האישי הצבאי;                                                                                     |                   |
|(4) שמות ההורים;                                                                                           |                   |
|(5) הגיל;                                                                                                  |                   |
|(6) המין;                                                                                                  |                   |
|(7) הדת;                                                                                                   |                   |
|(8) האזרחות;                                                                                               |                   |
|(9) המען האזרחי האחרון;                                                                                    |                   |
|(10) תאריך הפטירה או תאריך הפטירה המשוער;                                                                  |                   |
|(11) מקום הפטירה או מקום הפטירה המשוער או המקום שבו נמצאה הגופה;                                           |                   |
|(12) מקום הקבורה;                                                                                          |                   |
|(13) המבצע או התפקיד שבו נפטר.                                                                             |                   |
|(ג) לא כלל אישור פטירת חייל פרט מהפרטים המנויים בפסקאות (2), (3), (4), (5),                                |                   |
|(7), (8), (9) או (02, לא יהיה בכך כדי לגרוע מתקפו של האישור.                                               |                   |
|4. (א) מי שנתן אישור פטירת חייל ימסרנו לידי פקיד רישום, והוא ירשום את הפטירה                               |רישום הפטירה       |
|בפנקס הפטירות המתנהל על פי חוק המרשם.                                                                      |                   |
