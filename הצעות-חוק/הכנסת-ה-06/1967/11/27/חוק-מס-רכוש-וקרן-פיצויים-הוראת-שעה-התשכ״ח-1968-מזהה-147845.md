|מתפרסמת בזה הצעת חוק מטעם הממשלה:                      |

|חוק מס רכוש וקרן פיצויים (הוראת שעה), תשכ"ח-1967                                    |

|1, בחוק זה תהא לכל מונח המשמעות שיש לו בחוק מס רכוש וקרן פיצויים, תשכ"ג-                                   |הגדרות             |
|1963 1(להלן - החוק העיקרי).                                                                                |                   |
|2. על אף האמור בסעיף 7 לחוק העיקרי, לא יעלה שווים של בנין עירוני או של בנין                                |הקפאת המס על       |
|תעשייתי לשנת המס 1967 על השווי שנקבע להם לשבת המס 1966.                                                    |בנינים             |
|3. שר האוצר, באישור ועדת הכספים של הכנסת, רשאי לקבוע בתקנות כי בעלי מלאי,                                  |סמכות להקפיא       |
|או סוגים מסויימים של בעלי מלאי, לא יידרשו לשלם לשנת המס 1967, על מלאי בדרך כלל                             |את המס על מלאי     |
|או מסוג שנקבע, מס גבוה מהמס שהוטל על מלאי כזה שהיה בבעלותם בשנת המס 1966,                                  |                   |
|והכל בכפוף לתנאים שנקבעו כתקנות.                                                                           |                   |
|דברי הסבר                                                                                                  |                   |
|1. מס רכוש על בנינים עירוניים ובניינים תעשייתיים נקבע בשיעור מסויים משוויים,                               |                   |
|ושווי זה מבוסס על מכפלת דמי השכירות השנתיים הצפויים בעדם ב-.25                                             |                   |
|העלאת דמי השכירות בשנת המס 1966 לגבי בנינים שחוק הגנת הדייר, תשי"ד-1954,                                   |                   |
|חל עליהם, מחייבת במקביל עליה בשוויים של אותם בנינים לצורך מס רכוש, ועליה זו                                |                   |
|בשווי גוררת עמה כמובן העלאה במס.                                                                           |                   |
|בעקבות מדיניותה המוצהרת של הממשלה להימנע מהעלאת מסים (להוציא מסים                                          |                   |
|המיועדים לכיסוי הוצאות לשעת חירום), מוצע לקבוע כי לא יידרש אדם לשלם לשנת המס                               |                   |
|1967 מס רכוש בעד בניבים עירוניים ובביבים תעשייתיים שחוייבו במס כבביבים לשבת המס                            |                   |
|1966 בסכום העולה על סכום המס שחוייבו בו לשבת המס 1966 (סעיף 2).                                            |                   |
|2. מס רכוש על מלאי בקבע בשיעור מסויים מן ؀ࠂࠌࠎהשווי, ושוויו של מלאי לשבת מס מסו-                            |                   |
|יימת הוא בדרך כלל השווי שבקבע למלאי ליום האחרון של שבת המס הקודמת לעבין חישוב                              |                   |
|מס הכבסה שבעל המלאי חייב בו.                                                                               |                   |
|בעקבות המיתון בפעילות הכלכלית בשבת המס 1966 הצטבר בעבפי ייצור מסויימים                                     |                   |
|מלאי טובין למעלה מהמקובל בהם, ובמצא שבעל מלאי כזה חייב לשלם מס גבוה מהמקובל                                |                   |
|כשבים כתקבן, למרות שהיקף העסקים לא גדל.                                                                    |                   |
|מוצע איפוא להעביק לשר האוצר, באישור ועדת הכספים של הכבסת, סמכות לקבוע                                      |                   |
|בתקבות כי בעלי מלאי כאמור לא יידרשו לשלם מס העולה על זה שהיה עליהם לשלם בשבת                               |                   |
|1966. השר יוכל להתנות הטבה זו בתנאים שיקבע (סעיף 3).                                                       |                   |

|1 ס"ח תשכ"א, עמ' 100; ס''ח תשכ''ד, עמ' 91; ס''ח תשכ"ה, עמ' 197: ס"ח 494, תשכ''ז, עמ' 26.  |
