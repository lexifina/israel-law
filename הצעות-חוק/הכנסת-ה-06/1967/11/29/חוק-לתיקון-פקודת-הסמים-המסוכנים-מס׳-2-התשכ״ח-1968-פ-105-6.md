|מתפרסמת בזה הצעת חוק מטעם חבר הכנסת:                     |

|חוק לתיקון פקודת הסמים המסוכנים (מס' 2), תשכ"ח-1967                                            |

|1. אחרי סעיף 16 לפקודת הסמים המסוכנים, 1936 1, יבוא;                                                           |הוספת סעיף 16א     |
|16א. (א) העושה אחד המעשים המפורטים להלן, דינו - מאסר 10 שנים:                             |''הדחת קטין         |                   |
|(1) נותן לקטין, שלא כדין, סם מסוכן, הן בתמורה והן בלי                                     |לסמים מסוכנים       |                   |
|תמורה;                                                                                    |                    |                   |
|(2) משדל קטין להתמסר לסם מסוכן, בעישון, במאכל או                                          |                    |                   |
|בשתיה או בכל צורה אחרת' או משתמש בכוח' באמצעי                                             |                    |                   |
|הרדמה או השכרה, באיומים או במרמה, כדי להביא קטין                                          |                    |                   |
|להתמסר לסם מסוכן בעישון, במאכל או בשתיה או בכל                                            |                    |                   |
|צורה אחרת;                                                                                |                    |                   |
|(3) משיג בשביל קטין סם מסוכן או כלים שבהם מעשנים                                          |                    |                   |
|סמים מסוכנים, אך תהא זאת הגנה טובה לנאשם אם יוכיח                                         |                    |                   |
|לבית המשפט שהשיג את הכלי לקטין שלא לשימוש בסם                                             |                    |                   |
|מסוכן;                                                                                    |                    |                   |
|(4) מזמין קטין לדירתו או לרכבו או לכל מקום אחר' או                                        |                    |                   |
|מעכבו במקום כאמור, כדי שהקטין יוכל להתמסר לסם מסוכן                                       |                    |                   |
|או לעשן סם מסוכן או לטעום ממנו או לשתות או לאכול כל                                       |                    |                   |
|דבר שבו מהול סם מסוכן, או לקלוט אותו בכל צורה שהיא;                                       |                    |                   |
|(5) מזמין קטין למקום שבו בגירים מתמסרים לסמים                                             |                    |                   |
|מסוכנים או מעכב אותו במקום כאמור.                                                         |                    |                   |
|(ב) מי שהורשע בעבירה לפי סעיף קטן (א), יוטל עליו עונש                                     |                    |                   |
|מאסר' אם כעונש יחיד ואם בצירוף ؀ࠂࠎࠐࠒלעונש אחר' אך לא יוטל עליו                            |                    |                   |
|מאסר על תנאי ולא ישוחרר לתקופת מבחן."                                                     |                    |                   |

|דברי הסבר                                                                                                               |
|לאחרונה נתגלו רשתות פושעים המפתים קטינים וקטינות להתמסר לסמים מסוכנים,                                                  |
|הן בעישון והן במאכל או בשתיה' כדי להפוך אותם ללקוחות של סוחרים אלה, דינם של                                             |
|מפתים אלה רצוי שיהיה לפחות כדין אנסים וסרסורים לזנות. מעשיהם עשויים להשחית                                              |
|קבוצות שלמות של צעירים מבחינה בריאותית ונפשית כאחת.                                                                     |
|בהתחשב בחומרת המעשים האלה' מוצע להטיל ענשים חמורים שישמשו הרתעה לכל                                                     |
|מי שינסה להשחית קטינים וקטינות.                                                                                         |
|חבר-הכנסת; ש' כהן-צידון                                                                                                 |
