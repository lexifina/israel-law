|תיקון סעיף 5  |1. בחוק גבים לאומיים ושמורות טבע, תשכ"ג-1963 1, במקום סעיף 5 יבוא:                                     |
|              |5. (א) נכלל בשטח המיועד להיות גן לאומי שטח צבאי או שטח אחר                          |"שטחים בעלי        |
|              |שהוא, לדעת שר הבטחון, בעל חשיבות בטחונית, או הודיע שר הבטחון                        |חשיבות בטחונית     |
|              |לשר הפנים כי בקרבתו של השטח המיועד כאמור נמצא שטח צבאי, לא                          |                   |
|              |יכריז שר הפנים על השטח כגן לאומי אלא אחרי שהובטח לגביו מילוי                        |                   |
|              |דרישותיו של שר הבטחון.                                                              |                   |
|              |(ב) בשטח צבאי, האיסורים וההגבלות לפי חוק זה או התקנות שעל                           |                   |
|              |פיו לא יחולו על צבא-הגנה לישראל או על שלוחה אחרת של מערכת                           |                   |
|              |הבטחון שאישר אותה שר הבטחון.                                                        |                   |
|              |(ג) הוראות בקשר להתנהגות צבא-הגנה לישראל במקומות קדו-                               |                   |
|              |שים שבגן לאומי יתן שר הבטחון בהתייעצות עם שר הדתות, ובקשר                           |                   |
|              |לאתרים היסטוריים שבו - בהתייעצות עם שר החינוך והתרבות; ההוראות                      |                   |
|              |לא יהיו טעונות פרסום ברשומות.                                                       |                   |
|              |(ד) "שטח צבאי'/ לענין סעיף זה - מקרקעין שבידי צבא-הגנה                              |                   |
|              |לישראל או בידי שלוחה אחרת של מערכת הבטחון שאישר אותה שר                             |                   |
|              |הבטחון, וכן שטח המשמש אותם כשטח אימונים."                                           |                   |
|              |דברי הסבר                                                                                              |
|              |1. סעיף 5 לחוק גנים לאומיים ושמורות טבע, תשכ"ג-1963, אומר כך:                                          |
|              |''נכלל בשטח המיועד להיות גן לאומי שטח שהוא, לדעת שר הבטחון, בעל חשיבות בטחונית, או הודיע               |
|              |שר הבטחון לשר הפנים שבקרבתו של השטח המיועד נמצא שטח המוחזק בידי צבא-הגנא לישראל-לא                     |
|              |יכריז שר הפנים על השטח המיועד כגן לאומי אלא אחרי התייעצות עם שר הבטחון.'*                              |
|              |לעומת זאת נקבע בסעיף؀ࠂࠊࠌ 4 לחוק, כי ההכרזה של שטח כגן לאומי מותנה בהבטחת                               |
|              |מילוין של דרישות משרד הדתות, משרד החינוך והתרבות ומשרד החקלאות בכל הנוגע                               |
|              |לשמירת המקומות הקדושים, האתרים ההיסטוריים ושמורות הטבע, הכל לפי הענין, שבתוך                           |
|              |השטח המיועד לגן לאומי.                                                                                 |
|              |סעיף 27 לחוק קובע שהוראות סעיפים 4 עד 8 יחולו על שמורות הטבע בשינויים                                  |
|              |המחוייבים לפי הענין.                                                                                   |
|              |הנסיון הוכיח כי יש להעניק למילוי הדרישות של משרד הבטחון בקשר לשטחים                                    |
|              |צבאיים שבתוך גן לאומי מיועד - אותו מעמד שסעיף 4 מעניק לדרישותיהם של משרדי                              |
|              |הדתות, החינוך והתרבות והחקלאות. החוק המוצע בא לבצע מגמה זו.                                            |
|              |2. סעיף 46 לחוק אומר:                                                                                  |
|              |''לענין חוק זה, דין מקרקעי המדינה כדין כל מקרקעין אחרים".                                              |
|              |מתעורר ספק אם בשים לב להוראה זו יהיה צבא-הגנה לישראל, בפעולותיו בשטחים                                 |
|              |של גנים לאומיים ושמורות טבע, מוגבל בהגבלות החוק הקיים. החוק המוצע בא להבהיר,                           |
|              |שהכרזתם של שטחים צבאיים כגן לאומי או כשמורת טבע לא תגביל את הצבא בפעולותיו.                            |
|              |עם זאת מוצע לחייב את הצבא לקבוע כללי התנהגות של חייליו כדי למנוע פגיעה במקומות                         |
