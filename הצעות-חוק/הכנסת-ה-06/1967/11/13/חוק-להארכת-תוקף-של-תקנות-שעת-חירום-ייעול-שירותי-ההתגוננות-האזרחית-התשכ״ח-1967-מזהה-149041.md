|חוק להארכת תוקף של תקנות-שעת-חירום                                        |
|(ייעול שירותי ההתגוננות האזרחית), תשכ"ח-1967                              |

|1. תקפן של תקנות-שעת-חירום (ייעול שירותי ההתגוננות האזרחית), תשכ"ז-1967 1                                     |הארכת תוקף    |
|(להלן - התקנות), מוארך בזה עד יום י' בטבת תשכ"ט (31 בדצמבר 1968).                                             |              |
|2, תחילתו של חוק זה היא ביום פקיעתן של התקנות על פי חוק סדרי השלטון והמשפט                                    |תחילה         |
|(הוראות שעה), תשכ"ז-1967 2.                                                                                   |              |
|דברי הסבר                                                                                                     |              |
|תקנות-שעת-חירום (ייעול שירותי ההתגוננות האזרחית), תשכ"ז-1967, קובעות                                          |              |
|הוראות נוספות לחוק ההתגוננות האזרחית, תשי"א-1951, ומטרתן העיקרית היא לייעל                                    |              |
|את שירותי הגא שלא בשעת רגיעה. הוראות אלה בוללות, בין השאר, מתן סמכויות לפינוי                                 |              |
|מקלטים ולציודם וכן לחיוב תושבים להצטייד כציוד אישי להתגוננות אזרחית.                                          |              |
|ב-31 ביולי 1967 הגישה הממשלה לכנסת הצעת חוק להארכת תקפן של התקנות עד                                          |              |
|סוף שנה זו (הצעות חוק 742); אולם הצעה זו לא הגיעה לקריאה ראשונה. בינתיים קיבלה                                |              |
|הכנסת את חוק סדרי השלטון והמשפט (הוראות שעה), תשכ"ז-1967, ומכוח חוק זה הוארך                                  |              |
|תקפן של התקנות מעבר לתקופה של שלושה חדשים - היא תקופת תקפן על פי סעיף 9                                       |              |
|לפקודת סדרי השלטון והמשפט, תש"ח-1948 - כי؀ࠂࠌࠎ בחישוב תקופה זו של שלושה חדשים לא                               |              |
|תבוא במנין התקופה שבין המושב השני של הכנסת בשנת תשכ"ז לבין פתיחת המושב                                        |              |
|הראשון של הכנסת בשנת תשכ"ח.                                                                                   |              |
|על פי הארכה זו יפקע תקפן של התקנות בימים האחרונים של חודש נובמבר של שנה                                       |              |
|זו. אולם בינתיים מתברר, כי יהיה צורך להאריך את תקפן של התקנות מעבר ליום 31                                    |              |
|בדצמבר 1967.                                                                                                  |              |
|מוצע, איפוא, להאריך את תקפן של התקנות לשנה נוספת, היינו עד סוף שנת 1968.                                      |              |
|הממשלה אישרה כבר תיקונים מקיפים של חוק ההתגוננות האזרחית, תשי"א-1951, וההצעה                                  |              |
|לביצוע תיקונים אלה תונח על שולחן הכנסת בזמן הקרוב. אם יתקבלו ההצעות שיוגשו                                    |              |
|ייהפך תוכן התקנות שמוצע להאריך את תקפן לחוק של קבע.                                                           |              |
|ההצעה בהצעות חוק 742-שבדברי ההסבר שלה ניתן הנוסח המלא של התקנות -                                             |              |
|מתבטלת בזה.                                                                                                   |              |
