|              |תקפן הוארך על-ידי הכנסת עד יום כ"ט בכסלו תשכ"ח (31 בדצמבר 1967).                                        |
|              |הצורך בתקנות האמורות בעינו עומד. הממשלה מציעה להאריך את תוקף התקנות                                     |

|              |וזה נוסח של תקנות שעת חירום (אזורי בטחון), תש"ט-1949;                                                   |
|              |1. (א) רצועת אדמה בתוך שטח ישראל ברוחב הניתן להלן מכל בקודה שעל קו גבול שטח          |"שטח מוגן         |

|              |(ב) ''שטח ישראל" - פירושו, בתקנה זו, השטח שבו חל משפט מדינת ישראל.                   |                  |
|              |2. (א) שר הבטחון רשאי, מזמן לזמן, בצו בחתימת ידו שיפורסם ברשומות, להכריז שהשטח       |אזורי בטחון       |
|              |המוגן, או כל חלק ממנו, יחיה אזור בטחון לצורך תקנות אלה.                              |                  |
|              |(ב) צו לפי תקנת משנה (א) שניתן אחרי שנכנס לתקפו חוק להארכת תוקף של תקנות-            |                  |
|              |שעת-חירום (אזורי בטחון), תש"י-1950, יובא בפני הועדה לעניני חוץ ובטחון של הכנסת תוך   |                  |
|              |עשרה ימים מיום פרסומו ברשומות והועדה רשאית, על ידי החלטה שתפורסם ברשומות, לבטל       |                  |
|              |בכל עת צו כאמור.                                                                     |                  |
|              |3. תושב קבוע של אזור בטחון הוא, לצורך תקנות אלה, אדם אשר ביום שבו היה אזור מסויים    |תושבים קבועים     |
|              |לאזור הבטחון, בתוקף אכרזה לפי תקנה 2, ישב באותו אזור ישיבת קבע.                      |                  |
|              |4. שר הבטחון רשאי למנות כל קצין צבא-הגנה לישראל בדרגת סגן-אלוף או בדרגה גבוהה        |רשויות מוסמכות    |
|              |מזו להיות, לצורך תקנות אלה, רשות מוסמכת לאזור בטחון שיפרש במינוי.                    |                  |
|              |5. (א) שר הבטחון ימנה לגבי כל אזור בטחון ועדה מייעצת של שלושה חברים או יותר,         |ועדה מייעצת       |
|              |שתייעץ לרשות המוסמכת בנוגע לשימוש בסמכויותיה לפי תקנח .8                             |                  |
|              |(ב) חברי הועדה המייעצת יתמנו מתוך באי כוח הרשויות המקומיות שתחום שיפוטן הוא          |                  |
|              |באזור הבטחון ובסביבתו ומתוך התושבים הקבועים של אזור הבטחון ותושבי סביבתו; ואט אין    |                  |
|              |רשויות מקומיות כאמור, או שאינן פעילות למעשה - יתמנו חברי הועדה המייעצת מתוך התו-     |                  |
|              |שבים הקבועים של אזור הבטחון ומתוך תושבי סביבתו.                                      |                  |
|              |6. (א) אסור לאדם, שאינו תושב קבוע, להימצא כאזור בטחון או להיכנס אליו, אלא אם הוא     |איסורים           |
|              |חייל או שוטר במילוי תפקידו, או אם הורשה לכך על פי רשיון בכתב מאת רשות מוסמכת         |                  |
|              |ובהתאם לתנאי הרשיון; אך שר הבטחון רשאי, בצו על פי תקנה 2 או בצו נפרד בחתימת ידו,     |                  |
|              |. שיפורסם ברשומות, להוציא מכלל האיסור האמור, לגבי אזור הבטחון כולו או לגבי חלק ממנו, |                  |
|              |סוג מסויים של בני אדם, בין ללא תנאי ובין בתנאים.                                     |                  |
|              |(ב) אדם הנמצא באזור בטחון בניגוד לתקנה זו, רשאי כל חייל וכל שוטר, שהורשו לכך         |                  |
|              |על ידי רשות מוסמכת, להוציאו מאזור הבטחון במועד שנקבע על ידי הרשות המוסמכת, עם        |                  |
|              |מטלטליו או בלעדיהם, ולהשתמש לצורך זה במידת הכוח הדרושה.                              |                  |
|              |(ג) הוצאת אדם מאזור בטחון על פי תקנת משנה (ב) לא תגרע מאחריותו של אותו אדם           |                  |
|              |על פי תקנה 7.                                                                        |                  |
