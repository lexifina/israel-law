|חוק-יסוד; הממשלה                         |

|1. הממשלה היא הרשות המבצעת של המדינה והיא עושה כשם המדינה, בכפוף לכל דין,                                 |מהות וסמכות          |
|כל פעולה שעשייתה אינה מוטלת בחוק על רשות אחרת.                                                            |                     |
|2. הממשלה מכהנת מכוח אמון הכנסת.                                                                          |מקור הכוח            |
|3. הממשלה אחראית כפני הכנסת אחריות משותפת ומוסרת לכנסת דין וחשבון על                                      |אחריות ודיווח        |
|פעולותיה.                                                                                                 |                     |
|4. מקום מושבה של הממשלה הוא ירושלים.                                                                      |מקום מושב            |
|5. הממשלה מורכבת מראש הממשלה ומשרים אחרים; ראש הממשלה יהיה מכין חברי                                      |הרכב                 |
|הכנסת, שר אחר יכול שיהיה מבין חברי הכנסת או מחוצה לה.                                                     |                     |
|6. (א) נשיא המדינה' לאחר התייעצות עם נציגי סיעות בכנסת' יטיל על אחד מחברי                                 |הטלת התפקיד          |
|הכנסת את התפקיד להרכיב את הממשלה.                                                                         |להרכיב ממשלה         |
|(ב) הודיע חבר הכנסת לנשיא המדינה' תוך שלושה ימים מיום שהתפקיד הוטל עליו'                                  |                     |
|שאינו מוכן לקבלו' יטיל הנשיא את התפקיד על חבר הכנסת אחר' והוא יחזור ויעשה כן                              |                     |
|כל אימת שחבר הכנסת שהתפקיד הוטל עליו הודיע לנשיא כאמור.                                                   |                     |
|7. (א) חבר הכנסת שנשיא המדינה הטיל עליו את התפקיד להרכיב ממשלה' והוא לא                                   |תקופות להרכבת        |
|הודיע לנשיא כאמור בסעיף 6 (ב)' נתונה לו תקופה של ארבעה עשר ימים למילוי תפקידו.                            |הממשלה               |
|(ב) נשיא המדינה רשאי להאריך את תקופת ארבעה עשר הימים לתקופה נוספת עד                                      |                     |
|שבעה ימים ולהאריכה לתקופה נוספת שניה עד שבעה ימים, אם ייראה לו הדבר מוצדק על פי                           |                     |
|דין וחשבון שמסר לו אותו חבר הכנסת לפני עבור כל תקופה ותקופה.                                              |                     |
|8. (א) אם עד תום התקופות הנתונות לו לפי סעיף 7 לא הודיע חכר הכנסת שהורכבה                                 |הטלת התפקיד          |
|ממשלה' או שהודיע לנשיא המדינה לפני כן שאין בידו להרכיב ממשלה' יעשה נשיא המדינה                            |מחדש                 |
|שנית כאמור בסעיף 6' ובלבד שלא יטיל את התפקיד על אותו חבר הכנסת; לחבר הכנסת                                |                     |
|שעליו הוטל התפקיד לפי סעיף קטן זה נתונה תקופה של ארבעה עשר ימים למילוי תפקידו.                            |                     |
|(ב) עברה תקופה זו וחבר הכנסת לא הודיע שהורכבה ממשלה' או שהודיע לנשיא                                      |                     |
|המדינה לפני כן שאין בידו להרכיב ממשלה' רשאי נשיא המדינה להטיל ולחזור ולהטיל את                            |                     |
|התפקיד על אחד מחברי הכנסת שהודיע לנשיא שהוא מוכן לקבל את התפקיד; לחבר הכנסת                               |                     |
|שעליו הוטל התפקיד לפי סעיף קטן זה נתונה' בכפוף להוראות סעיף קטן (ג)' תקופה של                             |                     |
|ארבעה עשר ימים למילוי תפקידו.                                                                             |                     |
|(ג) לא הטיל נשיא המדינה את התפקיד לפי סעיף קטן (כ)' או שהטילו וחבר הכנסת                                  |                     |
|שעליו הוטל התפקיד לא הודיע לנשיא המדינה שהורכבה ממשלה' ונציגי סיעות בכנסת                                 |                     |
|שחבריהן מהווים רוב חברי הכנסת המליצו לפני נשיא המדינה להטיל את התפקיד על חבר                              |                     |
|הכנסת פלוני' יטילו הנשיא על אותו חבר הכנסת; ואולם אם באה ההמלצה לפני הנשיא בעוד                           |                     |
|מוטל התפקיד על חבר הכנסת לפי סעיף קטן (ב), יטילו הנשיא בהתאם להמלצה רק כעבור                              |                     |
|שבעה ימים מהיום שהוטל התפקיד לפי סעיף קטן (ב), זולת אם אותו חבר הכנסת הודיע                               |                     |
|לנשיא לפני כן שהורכבה ממשלה או שאין בידו להרכיב ממשלה; לחבר הכנסת שעליו הוטל                              |                     |
