|""בניני הכנסת", "רחבת הכנסת" פירושם כמשמעותם שתינתן למושגים אלה על-ידי החלטות                                |                |

|שקטרו 300 מטר שמרכזו הוא בנין הכנסת."                                                                        |                |
|הגבלת שטחה של רחבת הכנסת לעיגול שקטרו לא יותר מ-300 מטר מתאימה                                               |                |
|אמנם למקום שבו נמצא בנין הכנסת מאז שנת 1951, אך אין היא מתאימה למשכן                                         |                |
|החדש שאליו מתעתדת הכנסת לעבור. החוק המוצע בא, לכן, להסיר הגבלה זו ולאפשר                                     |                |
