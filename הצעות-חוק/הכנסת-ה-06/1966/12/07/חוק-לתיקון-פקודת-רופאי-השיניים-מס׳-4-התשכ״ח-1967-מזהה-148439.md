|                |(1).                                                                                                      |
|                |דברי הסבר                                                                                                 |
|                |לפי סעיף 9 לפקודת רופאי שיניים, 1945, אין רופא שיניים רשאי לתת לחולה שבטיפו-                              |
|                |לו אלא סמי הרדמה כלליים מסויימים, וביחס לאחרים יש צורך בנוכחותו של רופא מוסמך.                            |
|                |לפי הצעת החוק לתיקון פקודת המתעסקים ברפואה, תשכ"ז-1966, מותר יהיה לתת                                     |
|                |לרופאי שיניים מסויימים רשיונות לעסוק באנסתזיולוגיה (הרדמה) לצורך טיפול רפואי.                             |
|                |מוצע שעל רופא שיניים בעל רשיון כזה לא יחולו ההגבלות על השימוש בסמי הרדמה                                  |
|                |החלות על רופאי שיניים, דרך כלל, וכן שבעל רשיון כאמור יוכל לשמש רופא מוסמך,                                |
|                |כאשר החוק מחייב את נוכחותו בשעת מתן סם הרדמה כללי על ידי רופא שיניים.                                     |
|                |וזה נוסח סעיף 9 לפקודת רופאי שיניים, 1945:                                                                |
|                |9. (1) בכפוף לכל תקנות, שהותקנו לפי פקודה זו, ולהוראות סעיף קטן (2), יהיה מותר        |"אנשים שהורשו      |
|                |לאדם, שהורשה לעסוק בריפוי שיניים, להחזיק ולהשתמש לצרכי ؀ࠂࠊࠌעבודתו בכל סם שיהיה נדרש,  |לעסוק בריפוי       |
|                |ולתת לחולה בהמשך הטיפול בו סם הרדמה מקומי או כללי, אך הוא לא יתן לחולה כל סם הרדמה    |שיניים רשאים       |
|                |כללי, זולת גז תחמוצת חנקן או סם הרדמה אחר, שיהיה מאושר מטעם המנהל בתקנות שתותקנה      |להחזיק סמים וכוי   |
|                |לפי פקודה זו, אלא אם כן יהיה נוכח רופא מוסמך, העוסק במקצועו למעשה, ויהיה אחראי להגשתו |                   |
|                |לחולה.                                                                                |                   |
|                |(2) מרפא שיניים לא יחזיק או ישתמש לצרכי עבודתו בלא רשותו של המנהל בכתב,               |                   |
|                |בכל סם או תכשיר רפואי הנקובים בתוספת השניה של פקודת הרוקחים, ולא יבצע כל ניתוח        |                   |
|                |בחולה בלווית סם הרדמה כללי.'*                                                         |                   |
