|1, אחרי סעיף 3 לפקודת המתעסקים ברפואה, 1947 1, יבוא:                                                         |הוספת סעיפים      |
|                                                                                                             |3א-3ג             |
|3א. על אף האמור בסעיפים 3 ו-5 רשאי שר הבריאות לתת לרופא שיניים                          |"רשיון לרופאי       |                  |
|רשיון לעסוק באנסתזיולוגיה אם נתקיימו בו תנאים אלה:                                      |שיניים מסויימים     |                  |
|(1) הוא למד רפואת שיניים חמש שנים אקדמאיות לפחות באו-                                   |לעסוק               |                  |
|ניברסיטה או בבית ספר לרפואת שיניים ששר הבריאות הכיר בהם לענין                           |באנסתזיולוגיה       |                  |
|פקודה זו וקיבל דיפלומה ששר הבריאות הכיר בה לענין פקודה זו;                              |                    |                  |
|(2) אחרי קבלת הדיפלומה ברפואת שיניים עבר בהצלחה' להנחת דעתו                             |                    |                  |
|של שר הבריאות' חוק לימודים של שנה אחת לפחות באנסתזיולוגיה'                              |                    |                  |
|במוסד או בשיעורים מיוחדים שהכיר בהם שר הבריאות.                                         |                    |                  |
|3ב. מי שניתן לו רשיון לעסוק באנסתזיולוגיה כאמור בסעיף 3א רשאי                           |תחום פעולותיו       |                  |
|לעסוק בהרדמה במוסד רפואי או ביחידה רפואית שבשירותם נמצא מומחה                           |של בעל רשיון        |                  |
|באנסתזיולוגיה (הרדמה), כפי שנקבע בתקנות, באותם סוגי הרדמה שקבע                          |לעסוק               |                  |
|לו המומחה; אולם רשאי הוא לעסוק גם בסוגי הרדמה אחרים בהשגחתו                             |באנסתזיולוגיה       |                  |
|האישית של המומחה.                                                                       |                    |                  |
|3ג. בכפוף לאמור בסעיף 3ב ולענין עיסוקו בהרדמה, דינו של מי שניתן                         |דינו של בעל         |                  |
|לו רשיון לעסוק באנסתזיולוגיה כדין אדם המורשה לעסוק ברפואה."                             |רשיון לעסוק         |                  |
|                                                                                        |באנסתזיולוגיה       |                  |
|דברי הסבר                                                                                                    |                  |
|לפי פקודת המתעסקים ברפואה, 1947, רשאי רופא בלבד לעסוק באנסתזיולוגיה                                          |                  |
|(הרדמה). מי שאינו רופא יכול לטפל בהרדמתו של חולה؀ࠂࠌࠎ רק בהשגחתו האישית של רופא.                              |                  |
|ההרדמה' הנעשית בעיקר לצרכי ניתוח' דורשת ידע מיוחד והתמחות ולא כל רופא                                        |                  |
|יכול למלא בהצלחה את התפקיד של מרדים.                                                                         |                  |
|בישראל ניכר מחסור ברופאים-מרדימים ואין סיכויים להתמחותם של רופאים במספר                                      |                  |
|מספיק בענף רפואה זה בעתיד הנראה לעין.                                                                        |                  |
|לעומת זאת נמצאים רופאי שיניים בעלי ידע נרחב במקצועות רפואיים, שלאחר                                          |                  |
|הכשרה נוספת במשך שנה יהיו מסוגלים לשמש מרדימים ברפואה.                                                       |                  |
|מוצע על כן ששר הבריאות יהיה רשאי לתת רשיון לעסוק בהרדמה לרופא שיניים,                                        |                  |
|אם נוכח, להנחת דעתו, שהמועמד למד במשך חמש שנים לפחות באוניברסיטה מוכרת,                                      |                  |
|קיבל דיפלומה מוכרת ועבר הכשרה מיוחדת בהרדמה במשך שנה.                                                        |                  |
|בעל רשיון כזה יהיה מוגבל לעסוק בהרדמה רק במוסד שבו מועסק בעל תואר מומחה                                      |                  |
|לאנסתזיולוגיה (הרדמה) והוא יהיה מוגבל לעסוק רק באותם סוגי הרדמה שקבע לו המומחה.                              |                  |
|מומחה באנסתזיולוגיה (הרדמה) הוא רופא שהתמחה בהרדמה במשך שלוש שנים                                            |                  |
|לפחות' במוסד מוכר ובהדרכה מיוחדת, בנוסף להתמחויות אחרות הנדרשות ממנו לשם                                     |                  |
|קבלת האישור כמומחה בענף רפואה זה.                                                                            |                  |
