|מתפרסמת בזה הצעת חוק מטעם הממשלה:                     |

|חוק למניעת הונאה בכשרות, תשכ"ו-1966                                      |

|1. בחוק זה -                                                                                               |הגדרות            |
|"כשר" כשר לפי דין תורה;                                                                                    |                  |
|"תעודה" - תעודה מאת מועצת הרבנות הראשית או מאת רב המכהן כרב במקום בו נמצא                                  |                  |
|בית האוכל או האטליז או בית המטבחיים או במקום בו מיוצר המצרך, הכל לפי הענין,                                |                  |
|ויש בידו אישור מאת מועצת הרבנות הראשית שהוא כשיר לשמש רב בישראל; אם אין                                    |                  |
|באותו מקום רב כאמור המוכן לטפל בנתינת תעודות, יהיה רב לצרכי סעיף זה רב                                     |                  |
|כשיר כאמור המכהן כרב במקום אחר;                                                                            |                  |
|"ייצור של מצרך" - לרבות אריזתו וכל פעולה הנותנת לו את הצורה שבה נמכר המצרך                                 |                  |
|לצרכן.                                                                                                     |                  |
|2. (א) מי שמנהל בית אוכל או אטליז והוא הציג בו מודעה או סימן המציינים את                                   |בתי אוכל          |
|בית האוכל או האטליז ככשרים, בלי שהיתה בידו תעודה המאשרת כשרותם/ אשם בעבירה.                                |ואטליזים          |
|(ב) מי שמנהל בית אוכל או אטליז ויש בידו תעודה כאמור בסעיף קטן (א), והוא                                    |                  |
|הציג מודעה או סימן המציינים את בית האוכל או האטליז ככשרים, והוא הגיש בו ללקוחותיו                          |                  |
|או מכר בו מצרכים שאינם כשרים, אשם בעבירה.                                                                  |                  |
|(ג) בסעיף זה -                                                                                             |                  |
|"בית אוכל" - מקום בו עוסקים במכירת מאכלים או משקאות לציבור לשם                                             |                  |
|אכילה או שתיה בו במקום;                                                                                    |                  |
|"מצרך" - לענין בית אוכל - מאכלים ומשקאות; ולענין אטליז - בשר                                               |                  |
|ומוצרי בשר.                                                                                                |                  |
|3. (א) מי שעוסק בייצור מצרכים והוא מציין מצרך שייצר כמצרך כשר בלי שהיתה                                    |מצרכים            |
|בידו תעודה המאשרת כשרותו של המצרך, אשם בעבירה.                                                             |                  |
|(ב) מי שעוסק בייצור של מצרך שניתנה עליו תעודה כאמור בסעיף קטן (א),                                         |                  |
|והמצרך שהוא ייצר אינו כשר' אשם בעבירה.                                                                     |                  |
|(ג) מי שעוסק במכירת מצרכים ומכר מצרך שאינו כשר בתארו כאילו הוא כשר,                                        |                  |
|אשם בעבירה? באישום לפי הוראה זו תהא זאת הגנה שהמצרך יוצר על-ידי יצרן מוכר                                  |                  |
|ונשא ציון המעיד על כשרותו.                                                                                 |                  |
|4. (א) מי שעוסק בשחיטה בבית מטבחיים ציבורי והכריז על שחיטה כשרה בלי שהיתה                                  |בתי מטבחיים       |
|בידו תעודה המאשרת שהוא מורשה לשחיטה כשרה' אשם בעבירה.                                                      |                  |
|(ב) מי שעוסק בשחיטה בבית מטבחיים ציבורי ויש בידו תעודה כאמור בסעיף                                         |                  |
|קטן (א) ושחיטתו אינה כשרה, אשם בעבירה.                                                                     |                  |
|5. באישום לפי סעיף 2 (א), 3 (א) או 4 (א), חובת ההוכחה שהתעודה ؀ࠂࠊࠌࠐࠖ࠘האמורה היתה                           |חובת ההוכחה       |
|בידו - על הנאשם.                                                                                           |                  |
