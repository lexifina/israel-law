|1. סעיף 3 (א) לחוק נוטריונים למסמכים יוצאי-חוץ, תש"י-1950, קובע לאמור:                                        |                 |
|"שר המשפטים יתן ؀ࠂࠌࠎרשיון לכהן כנוטריון לאדם שנתמלאו בו תנאים אלה:                                            |                 |
|(1) הוא רשום בפנקס עורכי הדין בישראל, ועסק ברציפות או לסירוגין, לא פחות                                       |                 |
|מעשר שנים - מהן לפחות שתי שנים בארץ - באחד הדברים האלה או בשניהם:                                             |                 |
|(1) עריכת דין;                                                                                                |                 |
|(11) תפקיד בשירות המשפטי של מדינת ישראל או של ממשלת ארץ-ישראל;                                                |                 |
|(2) הועדה מצאה אותו ראוי לשמש כנוטריון.'*                                                                     |                 |
|נמצא שתקופת כהונתו של אדם בישראל כשופט' ובחוץ לארץ-כשופט או כנוטריון אינה                                     |                 |
|נחשבת במנין עשר השנים, ומוצע לתקן את הליקוי (סעיף 1).                                                         |                 |
