|1. בחוק זה -                                                                                                  |הגדרות         |
|"שלט" - כל דבר שיש בו הודעה לרבים בדרך של כתב, דפוס, הדבקה, הצגה, הארה,                                       |               |
|צביעה' חריטה וכיוצא באלה;                                                                                     |               |
|"דרך"' "דרך עירונית"' "אזור מהירות מיוחדת" ו-"תמרור" - כמשמעותם בפקודת                                        |               |
|התעבורה 1 והתקנות לפיה;                                                                                       |               |
|"ועדה מחוזית" - כמשמעותה בחוק התכנון והבניה, תשכ"ה-1965 2.                                                    |               |
|2. לא יתקין אדם שלט בתוך מאה מטרים מצירה של דרך, שלא בהיתר לפי חוק זה                                         |איפור התקנת    |
|(להלן - היתר), למעט דרך עירונית או דרך הנמצאת באזור מהירות מיוחדת.                                            |שלטים          |
|3 . הסמכות ליתן היתר היא, כתחום רשות מקומית - אותה רשות באישור הועדה המחוזית,                                 |הסמכות לתת     |
|ומחוץ לתחום רשות מקומית - הועדה המחוזית.                                                                      |היתרים         |
|4. הועדה המחוזית תשתמש להפעלת סמכויותיה לפי חוק זה בועדת משנה שחבריה יהיו:                                    |ועדת משנה      |
|(1) נציג שר העבודה' יושב ראש;                                                                                 |               |
|(2) נציג שר התחבורה;                                                                                          |               |
|(3) נציג שר הפנים;                                                                                            |               |
|(4) נציג שר המשטרה;                                                                                           |               |
|(5) נציג שר החקלאות.                                                                                          |               |
|5. לא יינתן היתר אלא אם -                                                                                     |תנאי להיתר     |
|(1) השלט נועד למניעת תאונות דרכים או למניעת שריפות;                                                           |               |
|(2) השלט מורה על מציאותו של מפעל פלוני והוא מותקן בחצרי המפעל                                                 |               |
|או בסמוך לו;                                                                                                  |               |
|(3) השלט מורה על אתר היסטורי' מקום קדוש או מקום מקודש?                                                        |               |
|(4) המקום המיועד להתקנת השלט הוא בית אירוח' תחנת דלק או תחנת                                                  |               |
|אוטובוסים, ואין בו כדי להסיח את דעתו של הנוהג כרכב.                                                           |               |
|6. לא תתיר ולא תאשר ועדת משנה התקנת שלט המורה -                                                               |סייג להיתר     |
|(1) על אתר היסטורי - אלא לאחר התייעצות עם שר החינוך והתרבות או                                                |               |
|מי שהשר הסמיכו לכך?                                                                                           |               |
|(2) מקום קדוש או מקודש - אלא לאחר התייעצות עם שר הדתות או מי                                                  |               |
|שהשר הסמיכו לכך?                                                                                              |               |
|(3) בענינים הנוגעים לבטיחות ותנועה בדרכים - אלא לאחר התייעצות עם                                              |               |
|שר התחבורה או מי שהשר הסמיכו לכך.                                                                             |               |
