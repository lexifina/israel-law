|1 . בחוק זה -                                                                                              |הגדרות                |
|"חוסה" - קטין שלא מלאו לו 14 שנה וכן נכה וזקן שאינם יכולים לדאוג לצרכי עצמם;                               |1                     |
|"אחראי לחוסה" - הורה, לרבות הורה חורג, מאמץ, אפוטרופוס או מי שהחוסה נמצא                                   |                      |
|במשמרתו או בהשגחתו.                                                                                        |                      |
|2. אחראי לחוסה העושה אחד המעשים המנויים להלן, דינו - מאסר שלושה חדשים או                                   |הגנה על חוסים         |
|קנס אלף לירות ;                                                                                            |                      |
|(1) גורם או מרשה שהחוסה יימצא במקום הפתוח לציבור, כדי להסב תשומת                                           |                      |
|לב הציבור לענין שהאחראי מעונין בו, או אגב נסיון להסב תשומת לב הציבור                                       |                      |
|לכך;                                                                                                       |                      |
|(2) גורם או מרשה שהחוסה יימצא במקום כל שהוא, כדי להפעיל על אדם                                             |                      |
|לחץ לעשות מעשה או לחדול ממעשה, או אגב נסיון להפעיל על אדם לחץ כזה;                                         |                      |
|(3) נמצא עם החוסה במקום הפתוח לציבור והדבר גורם להסבת תשומת לב                                             |                      |
|הציבור לענין שהאחראי מעונין בו ושלמענו קבע שם מקומו, או ללחץ על אדם                                        |                      |
|לעשות מעשה או לחדול ממעשה;                                                                                 |                      |
|ויש במציאותו או בתנאי החזקתו של החוסה באותו מקום כדי לפגוע בבריאותו הגופנית או                             |                      |
|הנפשית, דינו - מאסר שלושה חדשים או קנס אלף לירות.                                                          |                      |
|3. נמצא חוסה במקום ובתנאים כאמור בסעיף 2, חזקה שיש בכך כדי לפגוע בבריאותו                                  |חזקה                  |
|הגופנית או הנפשית,؀ࠂࠊࠌ מלבד אם הוכח ההיפך.                                                                 |                      |
|4. (א) היה קצין משטרה סבור שאדם פלוני עובר על הוראות סעיף 2, רשאי הוא                                      |העברת חוסה            |
|לנקוט כל האמצעים הדרושים לדעתו להעברת החוסה למקום מגוריו, או, בהתייעצות עם                                 |והחזקתו               |
|פקיד סעד, למקום מתאים אחר.                                                                                 |                      |
|(ב) הועבר חוסה למקום שהוא מחוץ לרשותו של האחראי לחוסה, לא יוחזק בו יותר                                    |                      |
|משבוע ימים אלא באישור בית משפט השלום.                                                                      |                      |
|דברי הסבר                                                                                                  |                      |
|ניצולם של קטינים, נכים וזקנים שאינם יכולים לדאוג לעצמם, על ידי הוריהם                                      |                      |
|והאחראים האחרים לטיפול בהם, לשם לחץ מופגן על יחידים ומוסדות, היא תופעה שכיחה                               |                      |
|בציבור.                                                                                                    |                      |
|אין החוק המוצע בא למנוע אדם מהעלות דרישותיו ומהביע רצונו בפומבי בדרך                                       |                      |
|שימצא לנכון, אך ככל שמעשיו עלולים לפגוע בשלומם של הקטינים, הנכים או הזקנים,                                |                      |
|יש למנוע אותם. מטרת החוק המוצע היא לאפשר הבאתם לדין של האחראים להעמדת בני                                  |                      |
|חסותם במצב העשוי לגרום להם נזק גופני או נפשי, ולתת בידי השלטונות אמצעים לטיפול                             |                      |
|בקטינים, בנכים ובזקנים שהועמדו במצב כזה.                                                                   |                      |
