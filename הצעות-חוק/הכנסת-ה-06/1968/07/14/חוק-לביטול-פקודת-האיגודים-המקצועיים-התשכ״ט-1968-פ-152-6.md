|מתפרסמת בזה הצעת חוק מטעם חבר הכנסת:               |

|חוק לביטול פקודת האיגודים המקצועיים, תשכ"ח-1968                                           |

|1, פקודת האיגודים המקצועיים, 1947  1- בטלה.                                                                    |ביטול        |
|דברי הסבר                                                                                                      |             |
|בפקודה הנ"ל נאמר, כי תחילתה תהיה ביום שייקבע ע"י הנציב העליון. אולם הנציב                                      |             |
|העליון לא השתמש בסמכות זו. היא עברה אחרי קום המדינה לידי הממשלה, וזו העבירתה                                   |             |
|אל שר העבודה, אך גם הממשלה ושר העבודה לא השתמשו בה.                                                            |             |
|הוראות הפקודה דנות ברישום הסתדרויות פועלים, איגודי מעבידים ואגודות מעורבות                                     |             |
|של פועלים ומעבידים. הן מסדירות את מעמדם המשפטי של ארגונים אלה, את מבניהם                                       |             |
|הפנימי, את ניהול חשבונותיהם וכו', וקובעות כי על הארגונים הללו לא תחול לא פקודת                                 |             |
|החברות, לא פקודת האגודות השיתופיות ולא חוק האגודות העותומני.                                                   |             |
|אילו שר העבודה נתן תוקף לפקודה בכוח סמכותו העומדת לו לפי סעיף 1 שלה לקבוע                                      |             |
|את תחילתה, היה הדבר מחולל מהפכה בדרכי הקמתם؀ࠂࠌࠎ, ארגונם ופעילותם של האיגודים                                   |             |
|המקצועיים בארץ, שכן ההסדרים הכלולים בפקודה אינם הולמים כלל את התפיסה הנהוגה                                    |             |
|ומקובלת אצלנו בתחום זה.                                                                                        |             |
|לפיכך מוצע בזה לבטל את הפקודה.                                                                                 |             |
|חבר הכנסת : י' ה' קלינגהופר                                                                                    |             |
