|1. בפקודת העדות 1, לאחר חלק 5 יבוא:                                                                          |הוספת חלק 5א     |
|"חלק 5א - העתקים צילומיים                                                                                    |                 |
|23א. בחלק זה -                                                                         |פרשנות               |                 |
|"העתק צילומי" - העתק ממקור המתקבל בהליכי צילום, או בשיטה                               |                     |                 |
|אחרת שנקבעה בתקנות, ושעל פיהם מתקבל העתק משתמר מדוייק                                  |                     |                 |
|של המקור, בין בגדלו המקורי ובין בגודל שונה.                                            |                     |                 |
|23כ. העתק צילומי של מסמך מסוג שנקבע לענין זה בתקנות, אשר                               |העתק צילומי          |                 |
|מצורף אליו אישור שההעתק נעשה מן המקור באופן ובתנאים שנקבעו                             |כראיה                |                 |
|לאותו סוג-מסמכים בתקנות, ישמש ראיה לכאורה בהליכים משפטיים -                            |                     |                 |
|(1) בכל מקרה שלפי הדין מותר להוכיח תוכן מסמך על-                                       |                     |                 |
|ידי העתקו;                                                                             |                     |                 |
|(2) אם המקור בוער על פי תקנות ובתנאים שנקבעו בהן,                                      |                     |                 |
|ומצורף להעתק אישור על כך כפי שנקבע בתקנות לאותו סוג                                    |                     |                 |
|מסמכים.                                                                                |                     |                 |
|23ג. אין בהוראות סעיף 23ב כדי לגרוע מכל דין אחר בדבר כשרותו                            |שמירת דינים          |                 |
|לראיה של העתק צילומי שנעשה שלא לפי הוראותיו, אלא להוסיף עליו."                         |                     |                 |

|2. לאחר סעיף 40 לפקודת העדות יבוא:  41                                                                                       |
|41. שר המשפטים רשאי להתקין תקנות לענין פקודה זו."                                                      |''תקנות             |
|דברי הסבר                                                                                                                    |
|עם ריבוי החומר הארכיוני במוסדות ציבוריים ופרטיים מתעורר יותר ויותר הצורך                                                     |
|להשתמש בשיטות גניזה חדישות, כגון השמדת המסמכים המקוריים וצילומם במיקרופילם.                                                  |
|החוק הקיים גורם לעיכוב בפיתוח שיטות גניזה כאלה. לפיו אין העתקים צילומיים של                                                  |
|מסמכים כשרים להתקבל כראיה בהליכים משפטיים, אלא אם הם תעודות ציבוריות לפי                                                     |
|סעיף 23 לפקודת העדות, או אם המקור הושמד או אבד, או שאין להשיגו, ומצרפים אל                                                   |
|ההעתק ראיות המוכיחות שהוא העתק נכון של המסמך המקורי. במקרה של؀ࠂࠊࠌࠐࠔ גניזת מסמכים                                             |
|בשיטות האמורות, ובעיקר כשהגניזה נעשית במסגרת של מוסדות ועסקים גדולים או                                                      |
|כשעברה תקופה ניכרת מזמן הגניזה, קשה להביא ראיות נוספות כאמור.                                                                |
|כשירותם של העתקים צילומיים כראיה בפני עצמם מעסיקה זה מזמן את דעתם של חכמי                                                    |
|משפט ומומחים במדינות שונות. מצד אחד עדיף התצלום על פני המקור, בהיות צילומו                                                   |
|התכוף של המסמך המקורי מונע אפשרות של זיופים מכאן ואילך. אך מאידך גיסא, אם                                                    |
|המסמך זוייף במקורו, הרי כל עוד המקור קיים יש אפשרויות של בדיקה וגילוי הזיוף, מה                                              |
|שאין כן בהעתקו הצילומי.                                                                                                      |
|החוק המוצע בא לתת אפשרות לשימוש בהעתקים צילומיים שנעשו בתנאים שנקבעו                                                         |
|לעריכתם והמבטיחים נאמנות למקור. התנאים ייקבעו מזמן לזמן בתקנות, באשר עשויים                                                  |
|לחול תנאים שונים לגבי סוגי מסמכים שונים ושיטות העתקה שונות, כגון לגבי מועד                                                   |
|הגניזה, היינו התקופה שבה יש לשמור על המסמך המקורי, והיא עשויה להיות שונה לפי                                                 |
|סוגי המסמכים ולפי סוגי המוסדות. כל הפרטים הללו ייקבעו בתקנות.                                                                |
|החוק המוצע מוגע את הצורך בהוכחה מיוחדת של מהימנות המסמך, אם הוא נערך                                                         |
|בתנאים המבטיחים זאת לפי התקנות. אולם הדלת אינה ננעלת בפני בעל דין להוכיח את                                                  |
|אי-מהימנות ההעתק או לטעון כל טענה הפוסלת את הראיה המוגשת על ידי ההעתק הצילומי.                                               |
