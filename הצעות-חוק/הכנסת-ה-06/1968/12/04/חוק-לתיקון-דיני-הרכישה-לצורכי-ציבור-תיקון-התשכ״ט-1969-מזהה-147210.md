|1, בסעיף 1 לחוק לתיקון דיני הרכישה לצרכי ציבור, תשכ"ד-1964  1(להלן - החוק                                    |תיקון סעיף 1        |
|העיקרי), בהגדרת "חוק רכישה", במקום "פקודת בנין ערים, 1936" 2 יבוא "חוק התכנון                                |                    |
|והבניה, תשכ"ה-1965"3.                                                                                        |                    |
|דברי הסבר                                                                                                    |                    |
|בתשכ"ד-1964 קיבלה הכנסת את החוק לתיקון דיני הרכישה לצרכי ציבור, הקובע,                                       |                    |
|שאם יופקעו מחלקה אחת בהפקעות חוזרות חלקים מסויימים ללא תשלום פיצויים, הן מכוח                                |                    |
|חוק אחד והן מכוח חוקים שונים, לא יעלה סך כל ההפקעות החוזרות האלה על 25%                                      |                    |
|משטחה המקורי של החלקה לפני ההפקעה הראשונה. אחוז זה נקבע בזמנו משום שכל                                       |                    |
|החוקים המאפשרים הפקעה ללא תשלום פיצויים נקטו מקסימום כזה להפקעה חד פעמית.                                    |                    |
|בינתיים נתקבל בשנת תשכ"ה-1965 חוק התכנון והבניה, וחוק זה העלה את המקסימום                                    |                    |
|להפקעה מכוחו ללא תשלום פיצויים מ-25% ל-40%. נוצרה אפוא אי-התאמה בין חוק זה                                   |                    |
|לבין החוק משנת תשכ"ד-1964 הקובע את המקסימום להפקעות חוזרות ל-25%.                                            |                    |
|החוק המוצע בא לסלק אי-התאמה זו ולקבוע, שהעלאת המקסימום מ-25% ל-40%                                           |                    |
|לפי חוק התכנון והבניה, המכוונת לאפשר לרשות מקומית הפקעת שטח גדול יותר, כוחה יפה                              |                    |
|גם בהפקעות חוזרות, אם יש ביניהן הפקעה אחת לפחות שהיא על פי חוק התכנון והבניה,                                |                    |
|אלא שהשטח המופקע העודף על 25% עומד לזכות הפקעה זו בלבד, ואילו לגבי כל יתר                                    |                    |
|ההפקעות, שלפי חוקי רכישה אחרים, המקסימום יהיה 25%, כאמור בחוק משנת תשכ"ד.                                    |                    |
|נמצא, שאם נרכש לפי חוקי רכישה אחרים שטח של 20%, ניתן לרכוש לפי חוק                                           |                    |
|התכנון והבניה עוד 20% מהשטח המקורי, אך אם נרכש לפי חוק התכנון והבניה רק עוד                                  |                    |
|10%, אין לרכוש עוד לפי החוקים האחרים אלא 5% נוספים.                                                          |                    |
