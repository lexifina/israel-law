|2. אחרי סעיף 33 לחוק העיקרי יבוא:                                                                          |הוספת סעיף 33א    |
|33א. הוציא הבנק מטבע שהוכרז על ידי הנגיד באישור הממשלה כמטבע                         |"מטבעות זכרון       |                  |

|לפי הוראותיה, לחברה שהקימה לשם סחר במטבעות והנמצאת בשליטתה."                         |                    |                  |
|דברי הסבר                                                                                                  |                  |
|סעיף 33 לחוק בנק ישראל' תשי"ד-1954, קובע לאמור:                                                            |                  |
|"המוסר לבנק סכום כסף במטבע זכאי לקבל תמורתו באותו סכום, וללא חשלום, שטרי כסף או                            |                  |
|מעות בעלי ערך נקוב ככל שידרוש המוסר, אלא שאם לא יוכל הבנק ؀ࠂࠌࠎליתן ככל שידרוש המוסר                        |                  |
|יתן שטרי כסף או מעות שערכם הנקוב קרוב ביותר לערך הנקוב שדרש המוסר."                                        |                  |
|נתעורר הספק כי סעיף זה מקנה זכות לכל אדם לדרוש מהבנק מטבע בעל תכונה                                        |                  |
|מיוחדת (כגון מטבע מלוטש או ישר מהמטבעה) או מטבע שהוצא' הודפס או הוטבע בשנה                                 |                  |
|מסויימת דווקא. התיקון בא להבהיר כי חובת הבנק לפי סעיף 33 היא לפרוט מטבע ולא לתת                            |                  |
|שירות נומיסמטי (סעיף 1).                                                                                   |                  |
|הבנק מוציא מזמן לזמן מטבעות זכרון לציון מאורעות היסטוריים. מאחר שגם מטבע                                   |                  |
|זכרון המוצא על ידי הבנק הוא הילך חוקי' מוצע לקבוע בחוק כי מטבע זכרון לא יוצא                               |                  |
|על ידי הבנק לציבור הרחב אלא יימסר לממשלה או לפי הוראותיה לחברה שהקימה לשם                                  |                  |
