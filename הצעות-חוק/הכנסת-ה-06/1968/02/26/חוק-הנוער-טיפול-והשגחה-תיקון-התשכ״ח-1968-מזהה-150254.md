|דברי הסבר                                                                                                |                    |
|סעיף 24 לחוק הנוער (טיפול והשגחה)' תש"ך-1960' קובע:                                                      |                    |
|המפרסם בלי רשות בית המשפט שמו של קטין שהובא לפני בית המשפט או שפקיד הסעד פועל                            |                    |
|לגביו לפי חוק זה, וכן המפרסם כל דבר העשוי להביא לידי זיהוי של קטין כאמור, דינו - מאסר                    |                    |
|ששה חדשים.                                                                                               |                    |
|הנסיון הוכיח שהוראה זו צרה מדי. מאז מתן החוק הושמעו תלונות על סבל שנגרם                                  |                    |
|לקטינים לא רק על ידי גילוי העובדה שהובאו לפני בית המשפט הדן בקטינים נזקקים                               |                    |
|במובן סעיף 2 לחוק או שפקיד הסעד מטפל בהם, אלא גם על ידי רמזים שקטין פלוני מובא                           |                    |
|לפני בית משפט בשל ביצוע עכירות או שהנו מעורב במעשים בלתי-מוסריים                                         |                    |
|אחרים, או רמז על קרבתו המשפחתית של הקטין למבוגר שמיוחסת לו؀ࠂࠌࠎࠒࠖ࠘ התנהגות פלילית                         |                    |
|או בלתי-מוסרית.                                                                                          |                    |
