|מתפרסמות בזה הצעות חוק מטעם הממשלה:                     |

|חוק לפיקוח על יצוא הצמח ומוצריו (תיקון מס' 2), תשכ"ח-1968                                         |

|1, בסעיף 2א לחוק לפיקוח על יצוא הצמח ומוצריו' תשי"ד-1954 י' בתחילתו' יימחקו                                   |תיקון סעיף 2א    |
|המלים "בתקופה שעד יום ג' בניסן תשכ"ח (1 באפריל 0968".                                                         |                 |
|דברי הסבר                                                                                   |                 |                 |
|חוק לפיקוח על יצוא הצמח ומוצריו' תשי"ד-1954 (להלן - החוק העיקרי), בא                                          |                 |
|להבטיח את רמת התוצרת החקלאית המיועדת ליצוא ואת שמה הטוב בשוקי חוץ לארץ.                                       |                 |
|אחד האמצעים לכך הוא ההוראה שאין לייצא צמחים לפני שנבדקו על ידי מבקר וקיבלו                                    |                 |
|את אישורו בדבר כשרותם ליצוא. למונח "צמח" ניתן בחוק פירוש רחב ביותר הכולל גם                                   |                 |
|שימורי צמחים ומוצרים המופקים מצמחים, כגון יין או שמן, ששר החקלאות הכריז עליהם                                 |                 |
|כצמח לענין החוק האמור.                                                                                        |                 |
|הנסיון של הפעלת החוק במשך ארבע-עשרה שנים הוכיח' כי ההוראות הנוקשות                                            |                 |
|בדבר הבדיקה מתאימות לצמחים טריים, הנבדקים כרגיל בשיטות מהירות; ואילו מוצרים                                   |                 |
|תעשייתיים, כגון שימורים, טעונים בדיקות כימיות ובקטריולוגיות המבוצעות בקצב הרבה                                |                 |
|יותר איטי שאינו מדביק' ואינו יכול להדביק' את קצב הייצור. תהליך זה מכביד על היצואן                             |                 |
|ומונע בעדו לקיים את מועדי ההספקה בהתאם להתחייבויות שקיבל על עצמו לגבי לקוחות                                  |                 |
|בחוץ-לארץ, אף על פי שיש לו במפעלו אמצעי בדיקה נאותים המאפשרים לוודא אם כשרים                                  |                 |
|השימורים או המוצרים ליצוא בהתאם לדרישות שנקבעו בתקנות.                                                        |                 |
|לפיכך הוספה לפני כשנתיים, בחוק לפיקוח על יצוא הצמח ומוצריו (תיקון), תשכ"ו-                                    |                 |
|1966' הוראה בחוק העיקרי המאפשרת לשר המסחר והתעשיה (הממונה על ביצוע החוק בכל                                   |                 |
|הנוגע לשימורים ומוצרי צמחים)' ולמי שהשר הסמיכו לכך, להתיר יצוא של שימורים                                     |                 |
|ומוצרים המופקים מצמחים גם ללא בדיקת מבקר' אם נוכח שבידי היצרן אמצעי בדיקה                                     |                 |
|נאותים. אותה שעה הגבילה הכנסת את תוקף ההוראה האמורה למשך שנתיים, ؀ࠂࠌࠎהיינו עד                                 |                 |
|ליום ג' בניסן תשכ"ח (1 באפריל 1968)' וזאת כדי לאפשר לה לעמוד בבחינת הנסיון המעשי.                             |                 |
|במשך תקופת המבחן הוכיחה הוראה זו את יעילותה וקידמה את יצוא השימורים.                                          |                 |
|יחד עם מתן ההיתרים, פיתח משרד המסחר והתעשיה שיטה של פיקוח הלכה למעשה.                                         |                 |
|דוגמאות ניטלו במפעלו של היצרן וגם בנמל היצוא' לשם בחינת התאמתם של המוצרים                                     |                 |
|ליצוא והשוואתם עם האמור בהצהרת היצרן.                                                                         |                 |
|החוק המוצע בא' איפוא' להסיר את הגבלת הזמן שנקבעה בזמנו לתקופת מעבר.                                           |                 |
|להלן נוסח סעיף 2א לחוק העיקרי שהחוק המוצע בא לתקנו:                                                           |                 |
|2א. (א) נתקופה שעד יום ג' בניסן תשכ"ח (1 באפריל 1968) רשאי שר המסחר והתעשיה,                |"פטור מבדיקה     |                 |
|או מי שהשר הסמיכו לכך, להתיר, לפי שיקול דעתו, יצוא שימורי צמחים ומוצרים המופקים             |                 |                 |
|מצמחים (להלן - שימורים), אף אם לא הוגשו לבדיקה כאמור בסעיף 2, ובלבד שהוכח להנחת             |                 |                 |
|דעתו, כי בידי יצרן השימורים אמצעי בדיקה נאותים כדי לבדוק אם השימורים כשרים ליצוא            |                 |                 |
|בהתאם לתקנות שהותקנו על פי סעיף 6.                                                          |                 |                 |
|(ב) היתר לפי סעיף קטן (א) יכול שיהיה כללי או מוגבל לעיסקת יצוא אחת או עיסקאות               |                 |                 |
|יצוא אחדות או לסוגי שימורים, ויכול הוא להיות מותנה בתנאים; ובלבד שאם היה ההיתר כללי         |                 |                 |
|או לסוגי שימורים, תיערך מזמן לזמן גם בדיקה כאמור בסעיף 2 על אף מתן ההיתר."                  |                 |                 |
