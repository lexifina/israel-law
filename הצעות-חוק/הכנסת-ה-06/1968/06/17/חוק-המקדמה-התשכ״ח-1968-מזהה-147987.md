|חוק המקדמה, תשכ"ח-1968                                                                                     |                   |
|1. הממשלה מורשית מה לקבל מבנק ישראל (להלן - הבנק) והבנק מורשה בזה לתת                                      |                   |
|לממשלה מקדמות בסכום כולל שלא יעלה על 130 מיליון לירות.                                                     |                   |
|2, תנאי המקדמות ומועדי פרעונן ייקבעו בהסכמים בין שר האוצר ובין נגיד הבנק באי-                              |תנאי המקדמות       |
|שורה של ועדת הכספים של הכנסת.                                                                              |                   |
|דברי הסבר                                                                                                  |                   |
|החוק המוצע בא לאפשר לממשלה לקבל מבנק ישראל מקדמות בסכום כולל של                                            |                   |
|130 מיליון לירות. כספי המקדמות ישמשו למטרות הבאות:                                                         |                   |
|1. סך של 63.5 מיליון לירות תלווה הממשלה לאל-על נתיבי אויר לישראל בע"מ למימון                               |                   |
|חלקי של רכישת שני מטוסי בואינג 707 ומטוס אחד בואינג 747, כולל חלקי חילוף ומנועים.                          |                   |
|2. סך של 35 מיליון לירות תלווה הממשלה לחברת קו צנור אילת אשקלון בע"מ למימון                                |                   |
|חלקי של הוצאות הקמת צינור הדלק מאילת לאשקלון בקוטר של 42 אינצ'.                                            |                   |
|3. סך של 21 מיליון לירות תלווה הממשלה לחברת ים המלח למימון ؀ࠂࠈהרחבת המפעל.                                 |                   |
|4. סך של 10.5 מיליון לירות תלווה הממשלה לערד, תעשיות כימיות בע"מ למימון חלקי                               |                   |
|של הקמת מפעל לייצור חומצה זרחתנית ודו-סידן זרחתני.                                                         |                   |
|לפי סעיף 45 לחוק בנק ישראל, תשי"ד-1954 1, על הממשלה לפרוע מקדמות שניתנו                                    |                   |
|על ידי בנק ישראל לפני תום שנת הכספים שבה ניתנו. החוק המוצע מתיר החזרת המקדמות                              |                   |
|במשך תקופה ארוכה יותר ועל פי תנאים שייקבעו בהסכמים בין שר האוצר לבין נגיד בנק                              |                   |
|ישראל ובאישור ועדת הכספים של הכנסת.                                                                        |                   |
|בגלל שיעורי הריבית הגבוהים השוררים היום בשוק הכספים מוצע לממן את התכניות                                   |                   |
|הנ"ל מהקרנות של בנק ישראל במקום להיזקק למילוות בחו"ל או לאשראי ספקים.                                      |                   |
|/                                                                                                          |                   |
