|5א. על אף האמור בסעיף 5, חייבים עובדים למסור לממונה הראשי                            |"חובת הודעה על      |                 |
|הודעה כאמור באותו סעיף על כל שביתה, וחייב מעביד למסור לו הודעה                       |שביתה או השבתה      |                 |
|כאמור על כל השבתה, חמישה עשר יום לפחות לפני תחילתן."                                 |                    |                 |
|2. בסעיף 6 לחוק העיקרי, במקום "לפי סעיף 5" יבוא 'ילפי סעיפים 5 או 5א".                                     |תיקון סעיף 6     |
|דברי הסבר                                                                                                  |                 |
|חוק יישוב סכסוכי עבודה, תשי"ז-1957, קובע כסעיף 5 כי צד לסכסוך עבודה רשאי                                   |                 |
|להודיע על הסכסוך לממונה הראשי על יחסי עבודה שנתמנה על פי הוראות החוק. משנמסרה                              |                 |
|הודעה כזאת לממונה הראשי, רשאי הוא להתערב כסכסוך, וליטול לידיו את התיווך בו,                                |                 |
|או להטיל את התיווך על ממונה על יחסי עבודה, או על מתווך מיוחד שנתמנה, לענין אותו                            |                 |
|סכסוך עבודה, על ידי שר העבודה.                                                                             |                 |
|מהנסיון הרב שהצטבר מאז חקיקתו של החוק נתברר, כי במקרה שסכסוך עבודה גורר                                    |                 |
|אחריו החלטת עובדים לשבות מעבודה, או החלטת מעבידים להשבית את העבודה, מן הדין                                |                 |
|שתהיה חובה מפורשת למסור על כך הודעה לממונה.                                                                |                 |
|החוק המוצע בא לקבוע חובת מסירת הודעה על כל ؀ࠂࠊࠌשביתה או השבתה, הנובעת                                      |                 |
|מסכסוך עבודה, לפחות חמישה-עשר יום קודם לכן. תקופת ביניים זו תשמש למגע נוסף                                 |                 |
|בין הצדדים לסכסוך ולאפשרות תיווך.                                                                          |                 |
|להלן הוראות החוק העיקרי שהחוק המוצע מתקנן או מאזכרן;                                                       |                 |
|5. צד בסכסוך עבודה רשאי להודיע על הסכסוך לממונה הראשי; תוכן ההודעה, צורתה ודרך       |"מסירת הודעות       |                 |
|מסירתה יקבע שר העבודה בתקנות.                                                        |על סכסוך עבודת      |                 |
|6. נמסרה הודעה לסי סעיף 5 או שנודע לממונה הראשי בדרך אחרת על סכסוך עבודה,            |החלטה               |                 |
|יחליט הממונה הראשי אם יתווך בסכסוך; החליט לחיוב - יטול לידיו את תפקיד המתווך, אם שר  |על תיווך            |                 |
|העבודה לא נטל לידיו תפקיד זה, או יטיל את התיווך על ממונה או על מי שיתמנה במיוחד על   |                    |                 |
|ידי שר העבודה ליישוב אותו סכסוך עבודה."                                              |                    |                 |
