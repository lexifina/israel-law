|חוק לתיקון פקודת ביטוח כלי רכב של מבוע (סיכוני צד שלישי)                                              |
|(מס' 2), תשכ"ח-1968                                                                                   |

|1, בסעיף 6 לפקודת ביטוח כלי רכב של מבוע (סיכוני צד שלישי), 1947 1, במקום התנאי                                 |תיקון סעיף 6     |
|המגביל בסעיף קטן (1) יבוא:                                                                                     |                 |
|"ואולם אין חובה שהפוליסה תכסה -                                                                                |                 |
|(1) חבות של מעביד בשל מוות או חבלה גופנית של עובדו, אם היא                                                     |                 |
|מכוסה לפי חלק בי לחוק הביטוח הלאומי, תשי"ד-1953 2, או על ידי                                                   |                 |
|ביטוח מרצון, ובמידה שהיא מכוסה כאמור;                                                                          |                 |
|(2) חבות שבחוזה."                                                                                              |                 |
|2. כסעיף 2 לחוק לתיקון פקודת כלי רכב של מנוע (סיכוני צד שלישי), תשכ"ח-1967 3,                                  |תיקון טעות       |
|כרישה של פסקה (1), במקום המלים "הסיפה, החל במלים "ואדם שנתחייב בדינו"" יבוא                                    |                 |
|"הקטע הפותח במלים "ואדם שנתחייב בדינו" ומסיים במלים "מתאריך החיוב בדין"."                                      |                 |
|דברי הסבר                                                                                                      |                 |
|סעיף 6 לחוק לתיקון פקודת ביטוח כלי רכב של מנוע (סיכוני צד שלישי), 1947,                                        |                 |
|כפי שתוקן על ידי סעיף 4 (1) לחוק המתקן משנת תשכ"ח-1967, קובע כי אין חובה שהפו-                                 |                 |
|ליסה תכסה -                                                                                                    |                 |
|"(1) חבות בשל מוות או חבלה גופנית של עובד במידה שהחבות מכוסה לפי חלק ב'                                        |                 |
|לחוק הביטוח הלאומי/ תשי"ד-1953, או על ידי ביטוח מרצון;                                                         |                 |
|(2) חבות שבחוזה.'*                                                                                             |                 |
|לפני תיקון הסעיף האמור היה הפטור מביטוח חובה חל רק על חבות של מעביד בשל                                        |                 |
|מוות או חבלה גופנית של עובדו שאירעה תוך כדי עבודתו של העובד. תוצאתו האפשרית                                    |                 |
|והבלתי רצויה של התיקון היא, שנהגי כלי רכב שלא ביטחו עצמם ביטוח מרצון לא יהיו                                   |                 |
|מבוטחים במקרים של פגיעות באנשים הזכאים בגלל פגיעות אלה לגימלאות לנפגעי עבודה                                   |                 |
|؀ࠂࠊࠌמהמוסד לביטוח לאומי, כגון עובדים שנפגעו בדרך למקום עבודתם או ממנו. עם זאת יהיו                             |                 |
|נהגים אלה חשופים בפני תביעת שיפוי מצד המוסד לביטוח לאומי לפי סעיף 70 לחוק הביטוח                               |                 |
|הלאומי, תשי"ד-1953.                                                                                            |                 |
|תוצאה נלווית נוספת להעדר חובת הביטוח של הרכב המנועי במקרים אלה היא,                                            |                 |
|שהמוסד לביטוח לאומי לא יוכל למעשה לממש את זכותו לשיפוי מאת נהג בלתי מבוטח                                      |                 |
|כאמור.                                                                                                         |                 |
|כדי למנוע תוצאות אלה מוצע לצמצם את הפטור ולהחילו רק על חבות המעביד                                             |                 |
|בשל מוות או חבלה גופנית של עובדו (סעיף 1).                                                                     |                 |
|סעיף 2 להצעת החוק בא לתקן טעות בנוסח סעיף 2 לחוק המתקן משנת תשכ"ח-                                             |                 |
|1967. סעיף 2 של החוק המתקן בא לתקן את סעיף 4 לפקודה המקורית על ידי החלפת קטע                                   |                 |
|מנוסח המקור בנוסח שונה. אך בשל לשונו של התיקון הושמט מנוסח המקור קטע שלא                                       |                 |
|היתה כוונה להשמיטו, וזה לשונו:                                                                                 |                 |
|"אדם, שנפסל מכוח תקפו של חיוב בדין לפי הסעיף הזה, או לפי צו שניתן לפיו, מלהחזיק                                |                 |
|ברשיון נהגות, או מלהשיגו, יהיו רואים אותו - לצרכי פקודת התעבורה - כאילו הוא פסול                               |                 |
|לפי קביעותיה של הפקודה ההיא."                                                                                  |                 |
|התיקון המוצע בא להחזיר קטע זה למקומו (סעיף 2).                                                                 |                 |
