|חוק להסדר התדיינות בין בני-זוג, תשכ"ה-1964                                       |

|1, הגיש אדם נגד בן-זוגו קובלנה פרטית בשל תקיפה או תובענה אזרחית, בין שעילתן                                  |סייגים להתדיינות   |
|נולדה לפני נישואיהם ובין בתקופת נישואיהם, רשאי בית המשפט -                                                   |                   |
|(1) אם הוא סבור שהקובלנה היא טרדנית או קנטרנית - לדחותה מבלי                                                 |                   |
|לפסוק בענין;                                                                                                 |                   |
|(2) אם בית דין דתי עושה להחזרת שלום הבית בין בני-הזוג - לעכב שמיעת                                           |                   |
|המשפט;                                                                                                       |                   |
|(3) אם הוא סבור שניהול המשפט או המשכו עשויים לסכן שלום הבית בין                                              |                   |
|בני-הזוג במידה שאינה שקולה כנגד התועלת הצפויה לקובל או לתובע -                                               |                   |
|לעכב שמיעת המשפט ולהטיל על פקיד סעד, או על אדם אחר שהסכים לכך,                                               |                   |
|לתווך בענין בין בני-הזוג.                                                                                    |                   |
|2. חוק זה אינו גורע מהוראות חוק שיפוט בתי-דין רבניים (נישואין וגירושין),                                     |שמירת חוק          |
|תשי"ג-1953 1, מסמכות בית-המשפט לפי כל דין לדחות תובענה אזרחית על הסף או                                      |                   |
|למחוק כתב תביעה.                                                                                             |                   |
|3, בסעיף 9 לפקודת הנזיקים האזרחיים, 1944 2, סעיף קטן (1) בטל. וסעיף קטן (2) יצויין                           |ביטול              |

|נזיקין, וזה לשונו:                                                                                           |                   |
|9. (1) כל תביעה משפטית על נזיקים אזרחיים שנעשו לפני נישואין, או כל עוד הם תופסים,           |"בעל ואשה      |                   |
|לא תוגש בידי אחד הצדדים בנישואין אלה או בידי כל אדם המייצג את רכושו (של בעל) או             |               |                   |
|רכושה (של אשה), נגד הצד השני בנישואין אלה או נגד כל אדם המייצג את רכושו (של הבעל)           |               |                   |
|או רכושה (של האשה)."                                                                        |               |                   |
|אין איסור כזה לגבי סכסוכים בין בני-זוג בעניני ממון אחרים ולא לגבי משפטים פליליים                             |                   |
|(קובלנה פרטית).                                                                                              |                   |
|2. חסימת הגישה לבית המשפט מביאה לשורה של תוצאות בלתי-רצויות; לעתים מופקר                                     |                   |
|הצד החלש לשרירות-לב בן-זוגו, לעתים נדחף הנפגע לעשות דין לעצמו, או שהוא מגיש                                  |                   |
|קובלנה פלילית - צעד העשוי להגביר את המרירות במשפחה יותר ממשפט אזרחי. במקרים                                  |                   |
|שהם כיום רוב תביעות הנזיקין - פגיעות-גוף ברשלנות, ביחוד בתאונות דרכים - פועל                                 |                   |

|ומאחר שההתדיינות אסורה, נאלץ המזיק בעצמו לפצות את בן-זוגו. נמצא שאת דמי-                                               |

|3. איסור ההתדיינות בין איש לאשה ידוע רק בתחום המשפט המקובל האנגלי. הוא                                                 |
|הונהג בארץ על ידי המחוקק המנדטורי זמן קצר לפני תום המנדט. בינתיים הניעו הקשיים                                         |
|המתוארים לעיל את המחוקק האנגלי להחליף את האיסור המוחלט של המשפט המקובל                                                 |
|במתן רשות לבית המשפט לעכב תובענה בנזיקין4, החוק המוצע הולך בדרך דומה, אבל                                              |
|מרחיק לכת לטובת הנפגע:                                                                                                 |
|(א) אין הוא מסתפק כהפסקת המשפט, כי צפונה בכך הסכנה שהנפגע יישאר שוב                                                    |
|ללא סעד ויעשה דין לעצמו. יש לדאוג לחיסול הסכסוך בדרך אחרת. לשם כך פותח החוק                                            |
|המוצע דרך לתיווך בין המתדיינים מחוץ לכתלי בית המשפט; ואילו במקרים שבית דין                                             |
|מוסמך לעניני אישות עוסק בהחזרת שלום הבית, מספיק לעכב את המשפט כדי לתת לבית                                             |
|הדין חופש פעולה.                                                                                                       |
|(ב) כיוצא בזה אין להצטמצם בעניני נזיקין בלבד. הצורך לתווך קיים בכל משפט                                                |
|אחר בין איש לאשה, אם תובענת ממון ואם קובלנה פלילית. החוק המוצע מחייב נקיטת אמ-                                         |
|צעים אלה גם במשפטים אזרחיים אחרים ובמקרים החשובים ביותר של קובלנה פרטית -                                              |
|תקיפות. לגבי קובלנות בשל לשון הרע אין הדבר נחוץ, כי סעיף 25(א) להצעת חוק לשון                                          |
