|הוראות שעה  |1, לענין הבחירות שיתקיימו בחודש חשון תש"ל יראו בחוק הרשויות המקומיות (בחי-                                |
|            |רות), תשכ"ה-1965 1, כאילו -                                                                               |
|            |(1) אחרי סעיף 61 נוסף סעיף זה:                                                                            |
|            |61א. נוכח שר הפנים כי קיימות באזור קלפי פלוני נסיבות מיוחדות                     |"הוראות במקרים         |
|            |המצדיקות זאת לדעתו, רשאי הוא להורות על דחיית מועד פתיחת הקלפי,                   |מיוחדים                |
|            |על הפסקת ההצבעה ועל חידושה וכן על הוספת זמן להצבעה עד 48 שעות                    |                       |
|            |אחרי המועד הנקוב בסעיף 55? הוראה כאמור יכול שתפרט את הסידורים                    |                       |
|            |להבטחת קיום הבחירות באותו אזור קלפי, לרבות קביעת מקום קלפי                       |                       |
|            |אחר ומינוי ועדת קלפי; שר הפנים יודיע על ההוראה לבוחרים, ליושב                    |                       |
|            |ראש ועדת הבחירות, לפקיד הבחירות ולועדת הקלפי הנוגעת בדבר,                        |                       |

|דברי הסבר             |

|כדי להבטיח ביצוע תקין של הבחירות     |פסקה (1)         |
|לרשויות המקומיות, מוצע להעניק סמכות  |                 |
|לשר הפנים, בנסיבות המצדיקות זאת לדעתו, להורות על      |
|דחיית ההצבעה באזור קלפי פלוני ועל הארכת זמן           |
|ההצבעה.                                               |
|לפי סעיף 81 (א) לחול, הרשויות המקו-  |פקקה (2)         |
|מיות (בחירות), תשכ"ה-1965, חייל      |                 |
|הרוצה להצביע בקלפי לחיילים חייב לזהות את עצמו         |
|בפני ועדת הקלפי בתעודת הזהות שלו, כמו כל אזרח         |
|אחר, ונוסף לכך בתעודת החייל שלו.                      |
|וזה לשון הסעיף:                                       |
|"חייל הרוצה להצביע בקלפי לחיילים חייב לזהות           |
|את עצמו؀ࠂࠐࠒࠔ כאמור בסעיף 60 ונוסף לכך על ידי          |
|תעודת החייל שלו או בתעודת השוטר שלו."                 |
|סעיף 60 לחוק קובע לאמור:                              |
|"זיהוי בוחרים - 60. (א) הרוצה להצביע חייב             |
|לזהות את עצמו לפני ועדת הקלפי.                        |

|(ב) כאמצעי זיהוי ישמשו אך ורק פנקס זיהוי            |
|שניתן לפי תקנות שעת חירום (רישום תושבים), תש"ה-     |
|1948, או תעודת זהות שניתנה לפי פקודת מרשם התו-      |
|שבים, תש"ט-.1949                                    |
|(ג) מי שהצביע תטביע ועדת הקלפי בפנקס הזיהוי         |
|או בתעודת הזהות שלו 1זותמת המעידה שהצביע/ תנקב      |
|את הפנקס או התעודה ותמחוק את שם המצביע מרשימת       |
|הבוחרים."                                           |
|התברר כי לא כל החיילים נושאים ביום הבחירות את       |
|שתי התעודות הנזכרות. כדי לאפשר להם להצביע מוצע      |
|לתקן את החוק על ידי הוספת הוראה המאפשרת לשר         |
|הפנים/ בהתייעצות עם שר הבטחון/ לתת הוראות מיוחדות   |
|לגבי הזדהותם של חיילים בפני ועדות קלפי לחיילים      |
|וסימון הצבעתם. הוראות אלה יחולו רק באזורים שקבע     |
|שר הפנים בהתייעצות עם שר הבטחון.                    |
|התיקון מוצע כהוראת שעה לבחירות המתקיימות בחשון      |
|תש"ל.                                               |
