|4ב. חייל שנפטר בתקופת לחימה והובא לקבורה בבית קברות צבאי                                 |העברת גופה של        |
|ארעי או בבית קברות אחר שלא בחר בו קרובו, יחולו על העברת גופתו                            |חייל שנפטר           |
|ממקום הקבורה הוראות אלה:                                                                 |בתקופת לחימה         |
|(1) מי ששר הבטחון מינה לכך (להלן - הממונה؀ࠂࠒࠔ࠘ࠤࠦࠨ࠶࠸) רשאי,                               |                     |
|בהתייעצות עם המנהל הכללי של משרד הבריאות או עם מי                                        |                     |
|שהסמיך לכך, לצוות כי הגופה תועבר לבית קברות צבאי או                                      |                     |
|אזרחי, הכל כפי שבחר קרובו של הנפטר;                                                      |                     |
|(2) הובא החייל לקבורה בבית קברות צבאי ארעי, יודיע                                        |                     |
|הממונה בכתב לקרובו על כוונתו לצוות כאמור בפסקה (1);                                      |                     |
|לא הודיע הקרוב לממונה על בית הקברות הצבאי או האזרחי                                      |                     |
|שבו בחר לקבורת החייל, תוך 60 יום מהיום שבו נמסרה לו                                      |                     |
|ההודעה כאמור, תועבר גופתו של החייל לקבורה בבית קברות                                     |                     |

|כשקרוביו או מעניהם אינם ידועים;                                                          |                     |
|(3) הובא החייל לקבורה בבית קברות צבאי או בבית קברות                                      |                     |

|(4) בכפוף לאמור בפסקה (3) יצווה הממונה על העברת                                          |                     |
