|חוק לתיקון תקנות-שעת-חירום (תשלומי חובה) (מס' 2), תשכ"ט-1969                                            |

|1. תקנה 21 לתקנות-שעת-חירום (תשלומי חובה), תשי"ח-1958 1 (להלן - התקנות),                                      |הוספת תקנות    |
|תסומן "25" ולפניה יבוא:                                                                                       |24-21          |
|21. (א) שר המסחר והתעשיה, שר האוצר ושר העבודה ביחד (להלן -                             |"היטל לקידום         |               |
|השרים) רשאים לקבוע בצו כללי, כי בעל מפעל בענף הטקסטיל וההל-                            |המחקר                |               |
|בשה ישלם היטל למען קידום המחקר או הכשרת כוח אדם אקדמאי או                              |                     |               |
|מקצועי לצרכי תעשיית הטקסטיל וההלבשה (להלן-קידום המחקר).                                |                     |               |
|(ב) ההיטל יהיה בסכום מסויים או באחוז מסויים מסך כל שכר                                 |                     |               |
|העבודה המשתלם לכלל עובדי המפעל, לרבות מנהליו, בפרק זמן מסויים,                         |                     |               |
|או באחוז מסויים מערך הטובין שיוצרו במפעל בפרק זמן מסויים, או                           |                     |               |
|לפי חישוב אחר, הכל כפי שנקבע בצו.                                                      |                     |               |
|22. דין היטל לפי תקנה 21 כדין היטל על פי תקנה 2 ודין כעל מפעל                          |תחולת התקנות         |               |
|כאמור בתקנה 21 כדין מחזיק טובין, ותקנות אלה יחולו לגביהם בשינויים                      |                     |               |
|המחוייבים לפי הענין ובשינוי נוסף זה: בתקנה 7, בפסקה (1), כמקים                         |                     |               |
|"בטובין שעליהם הוטל ההיטל" קרי "במפעל שבעליו חוייב בהיטל לפי                           |                     |               |
|תקנה 21".                                                                              |                     |               |
|23. סכומי ההיטל שייגבו לפי תקנה 21 יועברו לקרן מיוחדת שתוקם                            |הקמת קרן             |               |
|לענין זה (להלן - הקרן).                                                                |                     |               |
|24. (א) השרים ימנו מינהלה לקרן.                                                        |מינהלה לקרן          |               |
|(ב) חברי המינהלה יהיו שלושה נציגי הממשלה ושלושה נציגי                                  |                     |               |
|היצרנים בענף הטקסטיל וההלבשה, שיתמנו לאחר התייעצות עם מנהל                             |                     |               |
|אגף הטקסטיל בהתאחדות ؀ࠂࠒࠔࠖࠤבעלי תעשיה; אחד מחברי הקרן יתמנה על                         |                     |               |
|ידי השרים להיות יושב ראש הקרן.                                                         |                     |               |
|(ג) המינהלה, באישור השרים, תקבע מזמן לזמן את דרכי השי-                                 |                     |               |
|מוש בכספי הקרן לקידום המחקר.                                                           |                     |               |
|(ד) המינהלה תפעל לפי הנחיות השרים."                                                    |                     |               |

|דברי הסבר              |

|מורגש כיום צורך מיוחד למחקר שימושי ולהכשרת         |
|כוח אדם אקדמאי לשימוש במחקר בענף הטקסטיל. אגף      |
|הטקסטיל בהתאחדות בעלי התעשיה מכיר בחשיבותה של      |
|הבעיה, ולפתרונה הוא הציע הקמת קרן מתאימה שתיזון    |
|מהיטלים שייגבו לשם כך על פי הסדר חוקי מחייב.       |
|ההתמחות התעשייתית שתבוא בעקבות מחקרים עשויה        |

|לתרום תרומה מכרעת לקידומה של תעשיית הטקסטיל,         |
|לפיתוחה ולביסוסה המשקי.                              |
|מוצע, איפוא, כי יוטל היטל בשיעור מסויים משכר         |
|העבודה הכולל המשתלם לעובדי כל מפעל טקסטיל או         |
|בשיעור מסויים מערך המוצרים שיוצרו במפעל, או          |
|בשיעור אחר שייקבע, וכי סכומי ההיטל יועברו לקרן       |
|מיוחדת. דרכי השימוש בכספי הקרן ייקבעו על ידי         |
|מינהלה שתתמנה לכך.                                   |
