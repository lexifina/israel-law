|תיקון מעיף 18     |בסעיף 18 לחוק התכנון והבניה, תשכ"ה-1965  1(להלן - החוק העיקרי), אחרי סעיף                         |
|                  |(ה) יבוא:                                                                                         |
|                  |"(ה1) נציג רשות הכבאות שתחומה כולל את תחום הועדה המקומית,                                         |
|                  |בעל הכשרה מקצועית בעניני מניעת שריפות, יוזמן דרך קבע לדיוני                                       |
|                  |ועדת המשנה ותהיה לו דעה מייעצת בענינים הנוגעים לשריפות."                                          |
|תיקון סעיף 19     |האמור בסעיף 19 לחוק העיקרי יסומן (א) ואחריו יבוא:                                                 |
|                  |"(ב) נציג רשות הכבאות שתחומה כולל את תחום הועדה המקומית,                                          |
|                  |בעל הכשרה מקצועית בעניני מניעת שריפות, תהיה לו דעה מייעצת                                         |
|                  |בענינים הנוגעים לשריפות; היה תחומה של הועדה כלול ביותר מרשות                                      |
|                  |כבאות אחת, יקבע שר הפנים את רשות הכבאות שתמנה את הנציג לענין                                      |
|                  |סעיף קטן זה."                                                                                     |
|תיקון סעיף 29     |בסעיף 29 לחוק העיקרי, אחרי סעיף קטן (ב) יבוא:                                                     |
|                  |"(ב1) נציג רשות הכבאות שתחומה כולל את תחום הועדה המקו-                                            |
|                  |מית, בעל הכשרה מקצועית בעניני מניעת שריפות, יוזמן דרך קבע                                         |
|                  |לדיוני ועדת המשנה ותהיה לו דעה מייעצת בענינים הנוגעים לשריפות;                                    |
|                  |לא היתה לועדה מקומית ועדת משנה, תחול הוראה זו לגבי דיוני הועדה                                    |
|                  |המקומית."                                                                                         |

|דברי הסבר           |

|מקרי ؀ࠂࠒࠔࠖࠠהשריפות הרבים שאירעו בארץ נתגלו     |
|במבנים                                         |
|יים טכניים רבים אשר הכבידו על כיבוי השריפות.   |
|ות ונזקים רבים ניתן היה למנוע לו היתה תשומת    |
|התאימה ניתנת לאספקטים של מניעת שריפות וכיבוין  |
|נה, בעת בדיקת תכנית הבניה בטרם מתן ההיתר.      |

|כדי להבטיח תשומת לב זאת מוצע לקבוע כי נציג רשות   |
|הכבאות, בעל הכשרה מקצועית בעניני שריפות, יוזמן    |
|לישיבות ועדת התכנון והבניה הנותנת למעשה את ההי-   |
|תרים, בין אם זו ועדת משנה המוסמכת לכך על סי החוק  |
|ובין אם זו מליאת הועדה.                           |
