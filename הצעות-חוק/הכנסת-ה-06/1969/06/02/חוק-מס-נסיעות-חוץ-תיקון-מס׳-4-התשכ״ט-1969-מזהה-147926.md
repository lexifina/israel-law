|דברי הסבר                                                                                                   |                  |
|סעיף 3 לחוק מס נסיעות חוץ, תשי"א-1950, כפי שתוקן, קובע לאמור:                                               |                  |
|3. (א) שיעור המס המוטל על רכישת כרטיסי נסיעה לסוגיהם ייקבע על ידי שר האוצר,             |"שיעור המס         |                  |
|באישור ועדת הכספים של הכנסת, בצו שיפורסם ברשומות.                                       |                   |                  |
|(ב) המס ייקבע באחוז ממחיר כרטיס הנסיעה או בסכום קצוב, או בשתי הדרכים כאחת,              |                   |                  |
|אך לא יעלה על 100% ממחיר הכרטיס בתוספת 150 לירות.".                                     |                   |                  |
|בצו מס נסיעות חוץ (קביעת שיעורי המס), תשכ"ט-1969 2, הועלו שיעורי מס הנסי-                                   |                  |
|עות כדלקמן:                                                                                                 |                  |
|(א) על כרטיס נסיעה בכלי טיס - מ-7.5% ממחיר הכרטיס בתוספת -.290 ל"י                                          |                  |
|ל-7.5% ממחיר הכרטיס בתוספת -.500 ל"י;                                                                       |                  |
|(ב) על כרטיס נסיעה בכלי שיט - מ-%7.5 ממחיר הכרטיס בתוספת -.255 ל"י                                          |                  |
|ל%7.5 ממחיר ؀ࠂࠈהכרטיס בתוספת -.450 ל"י.                                                                     |                  |
|עקב ההגבלה הקיימת בסעיף 3 (ב) לחוק, לפיה המס אינו יכול לעלות על 100% ממחיר                                  |                  |
|הכרטיס בתוספת 150 לירות, אי אפשר היה להחיל את ההעלאה הנ"ל על כרטיס נסיעה                                    |                  |
|ככלי טיס שמחירו למטה מ-160 ל"י ועל כרטיס נסיעה בכלי שיט שמחירו למטה מ-110 ל"י.                              |                  |
|החוק המוצע בא לאפשר את העלאת המס כאמור על כל כרטיסי הנסיעה, על ידי                                          |                  |
|העלאת תקרת המס עד ל-350 לירות מעל מחיר הכרטיס.                                                              |                  |
