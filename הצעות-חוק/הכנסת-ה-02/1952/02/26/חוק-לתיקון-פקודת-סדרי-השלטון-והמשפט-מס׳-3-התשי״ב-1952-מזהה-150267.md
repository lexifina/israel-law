מתפרסמת בזה הצעת חוק מטעם הממשלה:

חוק לתיקון פקודת סדרי השלטון והמשפט (מס' 3), תשי"ב-1952

|1. פקודת סדרי השלטון והמשפט, תש"ה - 1948 ,1 תתוקן כך:                                                     |תיקון הפקודה      |
|(א) בסעיף 16, אחרי המלים "יכיל את כל השינויים הנובעים מתוך הקמת המדינה                                    |                  |
|ורשויותיה" יבואו המלים "ואת כל התיקונים שנעשו בחוק לאחר מכן".                                             |                  |
|(ב) אחרי סעיף 16 ייווסף סעיף זה:                                                                          |                  |
|"נוסח מרוכז 16א, שר המשפטים רשאי להוציא נוסח חדש של כל חוק שהוחק אחרי                                     |                  |
|הקמת המדינה ותוקן בחוקים שבאו אחריו. נוסח זה יתן את החוק בצורתו                                           |                  |
|המתוקנת, ועם פרסומו ברשומות יבוא הוא במקום החוק המקורי על כל                                              |                  |
|תיקוניו."                                                                                                 |                  |
|דברי הסבר                                                                                                 |                  |
|1* סעיף 16 לפקודת סדרי השלטון והמשפט, תש"ח - 1948, מייפה את כוחו של שר                                    |                  |
|המשפטים להוציא נוסח חדש של חוקי המשטר המנדטורי שיש להם תוקף בישראל. וזה                                   |                  |
|לשון הסעיף:                                                                                               |                  |
|"שר המשפטים רשאי להוציא נוסח חדש של כל חוק שהיה קיים בארץ ישראל ביום                                      |                  |
|ה' באייר תש"ח (14 במאי 1948) ואשר עודנו בר תוקף במדינה. נוסח זה יכיל את                                   |                  |
|כל השינויים הנובעים מתוך הקמת המדינה ורשויותיה ועם פרסומו בעתון הרשמי                                     |                  |
|לא יהיה עוד תוקף לכל נוסח אחר של אותו חוק."                                                               |                  |
|תכליתו של הסעיף הזה היתה כפולה ;                                                                          |                  |
|(א) לתת את התחיקה המנדטורית, במידה שיש לה תוקף בישראל, בצורה עברית                                        |                  |
|מתוקנת ואגב כך לחתום אותה, היינו - לנפותה מן היסודות שנתבטלו או שנשתנו ולהגישה                            |                  |
|כפי תקפה עד כאן (up to date).                                                                             |                  |
|(ב) לתת לנוסח העברי תוקף מכריע ולשים קץ למצב שבו כל החומר הנוגע                                           |                  |
|לבירור המשפטי, הן שבכתב והן שבעל פה, ؀ࠂࠒࠔࠖࠤהוא עברי, ואילו בגוף החוק - האנגלית היא                        |                  |
|המכרעת.                                                                                                   |                  |
|מאז ניתן סעיף 16 תיקן המוסד המחוקק של המדינה תיקונים מקיפים בכמה וכמה                                     |                  |
|חוקים מנדטוריים, ביטל חלקים מהם ונתן במקומם חלקים חדשים. למען האחידות היה                                 |                  |
|הכרח ליתן חלקים חדשים אלה, ככל האפשר, בלשון הפקודה המקורית, גם במקום שנתבקש                               |                  |
|ניסוח אחר, לדוגמה: פקודת מס ההכנסה.                                                                       |                  |
|מובן מאליו, כי הניסוח החדש צריך לכלול את כל התיקונים הללו, שאם לא כן                                      |                  |
|לא יהא טעם ואפשרות לנסח מחדש חוק מנדטורי שתוקן על ידי המוסד המחוקק של                                     |                  |
|ישראל. אך כדי להסיר ספק מוצע בזה להבהיר את הענין במפורש.                                                  |                  |
|2. סעיף 16 מתייחס, כאמור, לחוקי המשטר המנדטורי. אולם יש חוקים שניתנו על ידי                               |                  |
|המוסד המחוקק הישראלי ותוך ארבע שנות קיומה של המדינה חזר המחוקק ותיקן בהם                                  |                  |
|במה פעמים, עד שקשה לעתים לעמוד על נוסחם כפי שהוא מחייב כיום, דבר הגורם קושי                               |                  |
|למשפטאי ולמחוקק כאחד. לדוגמה: פקודת סדרי השלטון והמשפט, תש"ח-1948, חוק                                    |                  |
|המעבר, תשיט - 1949 וחוק שירות בטחון, תש"ט - 1949. מקרים כאלה עשויים לרבות                                 |                  |
|בעתיד, והתיקון המוצע בא לאפשר הוצאת חוקים כאלה בנוסחם המרוכז והמתוקן לתועלת                               |                  |
|כל הדורש אליהם,                                                                                           |                  |
