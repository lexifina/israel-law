מתפרסמת בזה הצעת חוק מטעם הממשלה:

חוק שירות בטחון (תיקון), תשי"ב-1952

|1. חוק שירות בטחון, תש"ט-1949 1, יתוקן כך:                                                                 |תיקון החוק         |
|בסעיף 11 במקום סעיף קטן (0 יבוא סעיף קטן זה:                                                               |                   |
|"(ד) יוצא צבא, אשה, שהוכיחה באופן שייקבע בתקנות ולרשות שתיקבע על                                           |                   |
|פיהן, כי טעמים שבמצפון או טעמים שבהכרה דתית מונעים אותה מלשרת                                              |                   |
|בשירות בטחון, תהיה פטורה מחובת אותו שירות."                                                                |                   |
|2 (א) אשה שהיתה ערב תחילת תקפו של חוק זה פטוריה מחובת שירות בטחון לפי                                      |הוראת מעבר         |
|סעיף 11 (ד) לחוק שירות בטחון, תש"ט-1949, הפטור שלה - בטל ; ומותר יהיה לקראה                                |                   |
|להתייצב לשירות סדיר בתקופות המנויות בסעיף 6 (ד) לאותו חוק או תוך שנים עשר חודש                             |                   |
|מיום תחילת תקפו של חוק זה, הכל לפי המועד המאוחר יותר.                                                      |                   |
|(ב) אין האמור בסעיף קטן (א) בא לגרוע מהוראות סעיף 11 (ד) לחוק שירות                                        |                   |
|בטחון, תש"ט-1949, כפי שתוקן בחוק זה.                                                                       |                   |
|דברי הסבר                                                                                                  |                   |
|סעיף 11 (ד) לחוק שירות בטחון, תש"ט-1949, קובע:                                                             |                   |
|"יוצא צבא, אשה, שהצהירה כי טעמים שבמצפון או טעמים שבהכרה דתית מונעים                                       |                   |
|. אותה מלשרת בשירות בטחון, תהא פטורה מחובת שירות בטחון, באופן שייקבע בתקנות."                              |                   |
|החוק המוצע בא לתקן הוראה זו. לפי החוק הקיים אשה הטוענת מניעה מטעמים                                        |                   |
|שבמצפון או שבהכרה דתית די שתצהיר על כך; לפי החוק המוצע תהא חייבת להוכיח זאת                                |                   |
|בפני רשות מיוחדת שתיקבע לכך.                                                                               |                   |
|אשה שבשעתו היתה פטורה מחובת שירות בטחון מטעמים שבמצפון או בהכרה                                            |                   |
|דתית - הפטור שלה בטל. ואם לא תוכיח את זכותה לפטור משירות בטחון לפי ההוראה                                  |                   |
|המתוקנת,؀ࠂࠐࠒࠔ תוכל להיקרא לשירות סדיר תוך שנה מיום תחילת תקפו של החוק המוצע,                               |                   |
|אף אם התקופה שבה אפשר לקרוא לה לשירות לפי סעיף 6 (ד) לחוק שירות בטחון, תש"ט-                               |                   |
|1949, עברה לפני תחילת תקפו של החוק המוצע, או תעבור לפני תום השנה,                                          |                   |
|ואלה הוראות סעיף 6 (ד):                                                                                    |                   |
|"יוצא-צבא לא ייקרא להתייצב לשירות סדיר אלא אם הזמן שנקבע להתיצבות הוא                                      |                   |
|תוך תקופות אלה ;                                                                                           |                   |
|(1) אם ביום שנכנס חוק זה לתקפו הוא באחד הגילים שמ-18 עד 25 ועד בכלל -                                      |                   |
|תוך עשרים וארבעה חדש ים מיום שנכנס חוק זה לתקפו ;                                                          |                   |
|(2) אם ביום שנכנס חוק זה לתקפו הוא באחד הגילים שמ-26 עד 29 ועד בכלל -                                      |                   |
|תוך שנים עשר חדשים מיום שנכנס חוק זה לתקפו ;                                                               |                   |
|                                                                                                           |1                  |
|(3) אם הגיע לגיל 18 אחרי שנכנס חוק זה לתקפו - תוך עשרים וארבעה חדשים                                       |\                  |
|מיום הגיעו לגיל 18;                                                                                        |                   |
|(4) אם הגיע לארץ כעולה אחרי שנכנס חוק זה לתקפו - תוך תקופה שתיקבע                                          |                   |
|בתקנות."                                                                                                   |                   |

1 סטר החוקים 25 מיום כ"א באלול תש"ט (15.9.40), עמ' 271.
