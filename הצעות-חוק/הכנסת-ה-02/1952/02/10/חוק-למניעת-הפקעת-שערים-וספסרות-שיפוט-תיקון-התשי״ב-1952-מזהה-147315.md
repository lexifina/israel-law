מתפרסמות בזה הצעות חוק מטעם הממשלה:

חוק למניעת הפקעת שערים וספסרות (שיפוט) (תיקון), תשי"ב-1952

|1, חוק למניעת הפקעת שערים וספסרות (שיפוט), תשי"א-1951 1, יתוקן כך:                                         |תיקוז החוק       |
|בסעיף 4, במקום סעיף קטן (ב) יבוא סעיף קטן זה:                                                              |                 |
|"(ב) כל בית משפט אחר שערב תחילת תקפו של חוק זה היה מוסמך לדון בעבירות                                      |                 |
|נגד המשק לולא הוראות פקודת מניעת הפקעת שערים וספסרות (שיפוט), תש"ח-                                        |                 |
|1948 2, יהיה מוסמך לדון באותן עבירות על אף האמור בסעיף קטן (א)."                                           |                 |
|2. תקפו של חוק זה הוא מיום ט' באדר א' תשי"א (15 בפברואר 1951).                                             |תחילת תוקף       |
|דברי הסבר                                                                                                  |                 |
|פקודת מניעת הפקעת שערים וספסרות (שיפוט), תש"ח-1948, העניקה לבתי הדין                                       |                 |
|למניעת הפקעת שערים וספסרות סמכות ייחודית לדון בעבירות נגד הפיקוח הכלכלי. פקודה                             |                 |
|זו הוחלפה על ידי חוק למניעת הפקעת שערים וספסרות (שיפוט), תשי"א-1951, וסעיף 4                               |                 |
|לאותו חוק היה מיועד ؀ࠂࠊࠌלבטל סמכות ייחודית זו ולהחזיר לבתי המשפט המחוזיים ולבתי משפט                       |                 |
|השלום אותה סמכות לדון בעבירות אלה שחלתה להם לפני תחילת תקפה של הפקודה האמורה.                              |                 |
|וזהו לשון הסעיף בנוסחו הקיים:                                                                              |                 |
|"4. (א) בית דין מוסמך לדון בכל עבירה נגד המשק.                                                             |                 |
|(ב) האמור בסעיף קטן (א) אינו בא לגרוע מכל סמכות לדון בעבירה נגד המשק                                       |                 |
|הנתונה לבית משפט אחר על פי כל חוק אחר."                                                                    |                 |
|נתעוררו ספקות אם מטרה זו הושגה ע"י הסעיף בניסוחו הנ"ל, ופסקי דין סותרים                                    |                 |
|ניתנו בנידון מאת בתי משפט מחוזיים בתל אביב ובירושלים. החוק המוצע בא להסיר ספק                              |                 |
|זה ולהבהיר את כוונת המחוקק.                                                                                |                 |
