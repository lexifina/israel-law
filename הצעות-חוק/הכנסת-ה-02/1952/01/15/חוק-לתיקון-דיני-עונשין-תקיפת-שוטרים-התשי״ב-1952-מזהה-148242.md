מתפרסמת בזה הצעת חוק מטעם הממשלה:

חוק לתיקון דיני הענשין (תקיפת שוטרים), תשי"ב-1952

|1. התוקף שוטר כשהוא ממלא תפקידו כחוק, וכן התוקף אדם העוזר לשוטר או מסייע                                   |תקיפת            |
|בידו, דינו - מאסר עד 5 שנים ולא פחות משלושה חדשים.                                                         |שוטרים           |
|                                                                                                           |בשעת מילוי       |
|                                                                                                           |תפקידם           |
|2. המתנגד בכוח לשוטר כשהוא ממלא תפקידו כחוק, או לאדם העוזר לשוטר או מסייע                                  |התנגדות          |
|בידו' דינו - מאסר עד 5 שנים ולא פחות משנה.                                                                 |לשוטרים          |
|                                                                                                           |בשעת מילוי       |
|                                                                                                           |תפקידם           |
|3. העושה מעשה בכוונה להפריע לשוטר כשהוא ממלא תפקידו כחוק או להכשילו בכך,                                   |הפרעה לשוטר      |
|או להפריע לאדם או להכשילו מעזור לשוטר או מסייע בידו, דינו - מאסר עד 3 שנים                                 |בשעת מילוי       |
|ולא פחות מחודש ימים.                                                                                       |תפקידו           |
|4. סעיף 251 (ב) לפקודת החוק הפלילי, 1936 1 - בטל.                                                          |ביטולים          |
|דברי הסבר                                                                                                  |                 |
|סעיף 251 (ב) לפקודת החוק הפלילי, 1936, קובע כי כל אדם התוקף, מתנגד בכוח,                                   |                 |
|או מכשיל בזדון כל ؀ࠂࠐࠒࠔשוטר כשהוא ממלא את תפקידו כחוק, או כל אדם אחר העוזר לאותו                           |                 |
|שוטר, אשם בעוון ודינו מאסר עד שנתיים ימים.                                                                 |                 |
|העונש הקבוע בסעיף זה נראה, לרגל ריבוי העבירות החמורות נגד שוטרים במילוי                                    |                 |
|תפקידם, קל מדי, והצעה זו באה להחמיר בענשים אלה.                                                            |                 |
