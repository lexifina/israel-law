חוק התקציב לשנת 1952/53, תשי"ב-1952

|1. הממשלה רשאית להוציא בשנת הכספים המתחילה ביום ו' בניסן תשי"ב (1 באפריל                                     |תקציב לשנת   |
|1952) והמסתיימת ביום ט"ו בניסן תשי"ג (31 במרס 1953) הנקראת להלן "שנת הכספים                                  |1952/53      |
|1952/53", סכום של 168,450,000 לירות (להלן - התקציב),                                                         |             |
|2 אומדן הכנסות המדינה לכיסוי התקציב בשנת הכספים 1952/53 הוא כמפורט                                           |אומר!        |
|בתוספת הראשגנה לחוק זה.                                                                                      |ההכנסות      |
|3. חלוקת הסכום של התקציב לסעיפי הוצאה' לסעיפי משנה ולפרטי הוצאה תהיה                                         |פרטי התקציב  |
|כמפורט בתוספת השניה לחוק זה.                                                                                 |             |
|4. (א) ועדת הכספים של הכנסת, על פי הצעת הממשלה, תחליט על חלוקת הסכום                                         |תקציבים      |
|שהוקצב בסעיף הוצאה 30 "תקציבים מיוחדים" ותקבע את הסכומים שיוקצבו ממנו -                                      |מיוחדים      |
|(1) לתקציב הבטחון;                                                                                           |             |
|(2) להשתתפות בתקציב הפיתוח ;                                                                                 |             |
|(3) לרזרבה מיוחדת.                                                                                           |             |
|(ב) הסכום שיוקצב לפי סעיף קטן (א) לתקציב הבטחון ביחד עם הסכום המוקצב                                         |             |
|בסעיף הוצאה 06 - "משרד הבטחון" ייקרא להלן "תקציב הבטחון" \ חלוקתו של תקציב                                   |             |
|הבטחון לסעיפי משנה ולפרט,י הוצאה תיקבע על ידי ועדת הכספים של הכנסת על פי                                     |             |
|.הצעת הממשלה.                                                                                                |             |
|(ג) שר האוצר רשאי לקבוע, באישורה של ועדת הכספים של הכנסת, את המטרות                                          |             |
|אשר להן ישמשו הסכומים שיוקצבו לפי סעיף קטן (א) להשתתפות בתקציב הפיתוח                                        |             |
|ולרזרבה מיוחדת,                                                                                              |             |
|5 . (א) על פי הצעת הממונה על סעיף הוצאה, רשאי שר האוצר, או מי שנתמנה לכך                                     |שינויים      |
|על ידיו, לגבי כל סעיף הוצאה, פרט לסעיפי הוצאה של הכנסת ושל משרד מבקר                                         |             |
|המדינה, -                                                                                                    |             |
|(1) להעביר באישור ועדת הכספים של הכנסת, כל סכום מסעיף משנה אחד                                               |             |
|לסעיף משנה אחר שבאותו סעיף הוצאה;                                                                            |             |
|(2) להעביר כל סכום מפרט אחד לפרט אחר שבאותו סעיף משנה של הוצאה.                                              |             |
|(ב) לצורך סעיף קטן (א), הממונה על סעיף הוצאה הוא -                                                           |             |
|(1) לגבי לשכת נשיא המדינה - מי שנתמנה לכך על ידי הנשיא;                                                      |             |
|(2) לגבי כל סעיף הוצאה אחר - השר שנקבע לכך על ידי הממשלה או מי                                               |             |
|שנתמנה לשם כך על ידי אותו שר,                                                                                |             |
|(ג) לגבי סעיף ההוצאה של הכנסת, רשאית ועדת הכספים של הכנסת, על פי הצעת                                        |             |
|יושב ראש הכנסת, להעביר כל סכום מסעיף משנה אחד לסעיף משנה אחר, או מפרט אחד                                    |             |
|לפרט אחה שבאותו סעיף הוצאה.                                                                                  |             |
|(ד) לגבי סעיף הוצאה של משרד מבקר המדינה, רשאית ועדת הכספים של הכנסת,                                         |             |
|על פי הצעת מבקר המדינה, להעביר כל סכום מסעיף משנה אחד לסעיף משנה אחר, או                                     |             |
|מפרט אחד לפרט אחר שבאותו סעיף הוצאה.                                                                         |             |
