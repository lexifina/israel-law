|חוק לתיקון פקודת מטבעות קטנות, תשי"ג-1952                                    |

|תיקון הפקודה       |1 . אחר סעיף 1 לפקודת מטבעות קטנות, תש"ט-1948 1, ייווסף סעיף זה:                                                |
|                   |1א. הממשלה רשאית להוציא ולחזור ולהוציא מזמן לזמן מטבעות שלא                                |"הוצאת              |
|                   |ממתכת בהתאם לחוק זה, והוראות הפקודה בדבר מטבעות מתכת יחולו                                 |מטבעות              |
|                   |עליהם בשינויים המחוייבים לפי הענין."                                                       |שלא ממתנת           |
|אישור פעולות       |2 פעולה שנעשתה אחרי יום ט"ז בשבט תשי"ב (12 בפברואר 1952) ולפני תחילת                                            |
|                   |תקפו של חוק זה, ושהיתד. נעשית כדין אילו היה חוק זה בר תוקף אותה שעה, רואים אותה                                 |
|                   |כאילו נעשתה כדין.                                                                                               |
|                   |דברי הסבר                                                                                  |                    |
|                   |פקודת מטבעות קטנות' תש"ט-1948, מעניקה לממשלה סמכות להוציא מטבעות                                                |
|                   |מתכת בלבד. הממשלה הוציאה מטבעות כאלו כדי להחליף את המצלצלים שהוצאו על ידי                                       |
|                   |ממשלת המנדט.                                                                                                    |
|                   |בתחילת שנת 1952 חל מחסור ניכר במטבעות מתכת. כדי להתגבר עליו ועל הקשיים                                          |
|                   |הכרוכים בו, הוצאו בפברואר 1952 מעות ؀ࠂࠈנייר בערך נקוב של 50 ו-100 פרוטות. הואיל                                 |
|                   |ומחסור המתכת בשוק העולמי איננו מאפשר עדיין הוצאת מטבעות מתכת ומעות הנייר                                        |
|                   |עדיין במחזור/ בא החוק המוצע לתת גושפנקא חוקית להוצאת המעות הללו.                                                |
