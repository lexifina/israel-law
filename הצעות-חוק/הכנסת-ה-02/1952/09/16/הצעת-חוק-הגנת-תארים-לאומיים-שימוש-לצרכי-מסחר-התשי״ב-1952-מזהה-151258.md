| חוק הגנת תארים לאומיים (שימוש לצרכי מסחר), תשי"ב-1952                                                          |                |
|1. בחוק זה "תואר לאומי" פירושו - המלים "ישראל" ו"לאומי", לכל שינויי צורה                                        |פירושים         |
|דקדוקיים שלהם.                                                                                                  |                |
|2. לא יירשמו בשם הכולל תואר לאומי -                                                                             |רישום שם        |
|(1) חברה, כמשמעותה בפקודת החברות 1;                                                                             |הכולל           |
|(2) אגודה שיתופית, כמשמעותה בפקודת האגודות השיתופיות 2;                                                         |תואר לאומי      |
|(3) שותפות, כמשמעותה בפקודת השותפויות 3 ;                                                                       |                |
|(4) אגודה לפי החוק העותומני על האגודות ;                                                                        |                |
|(5) שם עסק כמשמעותו בפקודת רישום שמות עסק' 1935 4;                                                              |                |
|(6) סימן מסחרי, כמשמעותו בפקודת סימני המסחר' 1938 5,                                                            |                |
|אלא בהיתר מאת שר המשפטים ובהתאם לתנאי ההיתר.                                                                    |                |
|3. (א) פרט לציון מקום ייצורה של הסחורה, לא ישתמש אדם בתואר לאומי לתיאור                                         |שימוש           |
|עסק או סחורה לצורך פרסום או הפצה, אלא בהיתר מאת שר המשפטים ובהתאם לתנאיו;                                       |בתואר לאומי     |
|אולם מי שהשתמש בתואר לאומי כאמור לפני תחילת תקפו של חוק זה זכאי להוסיף .                                        |                |
|ולהשתמש בו לאותה מטרה בלבד.                                                                                     |                |
|(ב) העובר על סעיף זה, דינו - קנס עד אלף לירות.                                                                  |                |
|4. שר המשפטים ממונה על ביצוע חוק זה, והוא רשאי להתקין תקנות בכל דבר                                             |כיצוע ותקנות    |
|הנוגע לביצועו.                                                                                                  |                |
|דברי הסבר                                                                                                       |                |
|החוק המוצע בא למנוע שימוש בתארים לאומיים לצרכי מסחר ועסק' תוך ביצול                                             |                |
|הרושם המדומה העלול להתעורר כי העסק או סחורתו. נהנים מחסות רשמית. תארים                                          |                |
|לאומיים לענין זה הם המלים "ישראל" ו"לאומי" לכל שינויי צורה דקדוקיים שלהם.                                       |                |
|החוק הקיים כולל הוראות האוסרות על חברות, אגודות שיתופיות ושותפויות את                                           |                |
|השימוש בכינויים מסויימים, כגון מלכותי' ؀ࠂࠈקיסרי, עירוני וכד/ או בשמות המביעים חסות                              |                |
|מלכותית, ממשלתית וכד'; פקודת רישום שמות,עסק, 1934, אוסרת, בין היתר, רישומו                                      |                |
|של עסק ששמו כולל מלים המורות, כי יש לבעליו הזכות להשתמש בתואר צבאי                                              |                |
|או בתואר כבוד מסויים, ופקודת סימני מסחר אוסרת רישום סימן מסחרי המכיל סמלי                                       |                |
|מלכות, וסימנים הנותנים יסוד להנחה שלבעל העסק חסות רשמית וכר. הוראות אלה                                         |                |
|אינן הולמות ברובן את המצב במדינת ישראל. החוק המוצע משלים את מערכת ההוראות                                       |                |
|הללו לגבי תארים לאומיים, וקובע כי אין לרשום כל גוף (חברה, אגודה שיתופית, שותפות,                                |                |
|אגודה עותומנית), שם עסק או סימן מסחרי בשם כולל תואר לאומי, וכן אין להשתמש                                       |                |
|בתואר לאומי לתיאור עסק או סחורה לצרכי פרסום או הפצה, אלא על פי היתר מאת                                         |                |
|שר המשפטים.                                                                                                     |                |
|על מנת להפחית ככל האפשר את הפגיעה בזכויותיהם של בעלי עסקים המשתמשים                                             |                |
|כיום, בתארים לאומיים בעסקיהם קובע החוק המוצע כי האיסור לא יפגע בזכותו של מי                                     |                |
|שהשתמש בתואר לאומי כאמור לפני תחילת תקפו של החוק המוצע.                                                         |                |
