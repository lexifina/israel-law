|מתפרסמת בזה הצעת חוק מטעם הממשלה:                                                                                            |
|חוק לתיקון פקודת החברות (מס' 3),תשי"ב-1952                                                                                   |
|1. פקודת החברות 1, תתוקן כך :                                                                              |תיקון פקודת      |
|(1) בסעיף (5) (1) (ד), בסיפא, ייווסף תנאי מגביל זה :                                                       |החברות           |
|"אך יכול שר המשפטים להרשות' בתנאים שיקבע לכל מקרה, שסכום קר                                                |                 |
|המניות, כולו או מקצתו, יהיה נקוב במטבע שאינו מטבע ישראלי, אם שר                                            |                 |
|האוצר אישר שמתן רשות כזאת הוא לתועלת הציבור".                                                              |                 |
|(2), בסעיף 53א תיווסף פסקה זו:                                                                             |                 |
|"אלא שאם נרשמה חברה כשסכום קרן המניות שלה, כולו או מקצתו, נקוב -                                           |                 |
|על פי הרשאת שר המשפטים לפי סעיף 5(1) (ד) - במטבע שאינו מטבע                                                |                 |
|ישראלי, יוכל שר המשפטים להרשות, בתנאים שיקבע לכל מקרה, שכל סכום                                            |                 |
|של מניות חדשות שהוצאו על ידי אותה חברה או כל שינוי בהון שלה יהין:                                          |                 |
|נקוב באותו מטבע. אם שר האוצר אישר שמתן רשות כזאת הוא לתועלר                                                |                 |
|הציבור".                                                                                                   |                 |
|דברי הסבר.                                                                                                 |                 |
|1. לפי פקודת החברות, צריך סכום קרן המניות של כל חברה להיות נקוב במטבע                                      |                 |
|ישראלי (סעיף 5(1) (ד)): חברה המגדילה את הונח על ידי הוצאת מניות חדשות, צריך                                |                 |
|שהסכום הנקוב של המניות הנוספות יהיה אף הוא נקוב במטבע ישראלי, פרט לחברה                                    |                 |
|שנרשמה לפני חקיקת פקודת החברות (1929), ושסכום קרן המניות שלה נקוב במטבע, חוץ                               |                 |
|(סעיף 53א).                                                                                                |                 |
|2.. יש מקרים ؀ࠂࠈבהם דורשת תועלת הציבור להרשות רישום חברה חדשה כחברה ישראלית                                |                 |
|כשהון המניות שלה, כולו או מקצתו, נקוב במטבע חוץ. החוק המוצע בא לאפשר רישום                                 |                 |
|כזה, אך הוא מתנה את הרישום באישור שר האוצר' כי הרישום הוא לתועלת הציבור,.                                  |                 |
|ובהרשאת שר המשפטים הרשאי להתנות בה תנאים שייראו לו. חברה שנרשמה כך תוכל,                                   |                 |
|באותה דרך עצמה, להגדיל את קרן מניותיה בסכום שיהיה נקוב באותו מטבע חוץ שבו                                  |                 |
|נקוב ההון המקורי, כולו או מקצתו.                                                                           |                 |
