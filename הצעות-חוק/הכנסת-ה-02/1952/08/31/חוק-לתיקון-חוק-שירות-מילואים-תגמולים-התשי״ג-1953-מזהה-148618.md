חוק לתיקון חוק שירות מילואים (תגמולים), תשי"ב--1952

|1, חוק שירות מילואים (תגמולים), תשי"ב-1952 ,1 יתוקן כך:                                                     |תיקון החוק      |
|בסעיף 5, אחרי סעיף קטן (ג) ייווסף סעיף קטן זה:                                                              |                |
|"(ד) רשאי שר העבודה באישור ועדת העבודה של הכנסת לשבות בתקנות/                                               |                |
|לעתים מזומנות, את הסכומים שבסעיף קטן (ב), בשים לב לתנודות באינדכס                                           |                |
|יוקר המחיה המשמש בסיס לחישוב תוספת היוקר המשתלמת על שכר העבודה."                                            |                |
|דברי הסבר                                                                                                   |                |
|סעיף 5 (ב) לחוק שירות מילואים (תגמולים), תשי"ב-1952, קובע כי בחישוב שכר                                     |                |
|העבודה לקביעת גובה התגמול המשתלם למשרת במילואים יראו שכר עבודה העולה על                                     |                |
|-.110 ל"י לחודש כאילו היה -.110 ל'יי, ושכר עבודה שהוא פחות מ-70 ל"י לחודש יראו                              |                |
|כאילו היה -.70 ל"י.                                                                                         |                |
|בקביעת הסכומים הנ"ל הובא בחשבון שכר העבודה בעת חקיקת החוק. בינתיים חלו                                      |                |
|שינויים בשכר העבודה כתוצאה מעליית ؀ࠂࠎࠐࠒאינדכס יוקר המחיה והתברר הצורך בהגדלת                                |                |
|הסכומים.                                                                                                    |                |
|החוק המוצע יאפשר לשר העבודה לשנות לעתים מזומנות את הסכומים שהם התחום                                        |                |
|לקביעת התגמול, בשים לב לתנודות באינדכס יוקר המחיה. שינוי הסכומים ייעשה בתקנות                               |                |
|באישור ועדת העבודה של הכנסת.                                                                                |                |
