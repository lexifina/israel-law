חוק המילוות (מוסדות כספיים) (תיקון), תשי"ב-1952

|1, חוק המילוות (מוסדות כספיים)' תשי"א-1951 1, יתוקן כך:                                                      |תיקון החוק    |
|בסעיף 2' במקום המלים "חמישה מליון לירות" יבואו המלים "ששה וחצי מליון                                         |              |
|לירות".                                                                                                      |              |
|דברי הסבר                                                                                                    |              |
|חוק המילוות (מוסדות כספיים), תשי"א-1951, העניק לממשלה את הסמכות ללוות                                        |              |
|ממוסדות כספיים סכום שלא יעלה על חמישה מליון לירות ולהוציא למטרה זו שטרי ערך,                                 |              |
|שייפדו בתאריך כ"ה בתשרי תשי"ז (30 בספטמבר 1956).                                                             |              |
|הממשלה קיבלה' בתוקף החוק האמור' ממוסדות כספיים הלוואות בסך כולל של                                           |              |
|חמישה מליון לירות' והוציאה תמורתם שטרי ערך ؀ࠂࠌࠎהנושאים ריבית של שלושה למאה לשנה.                             |              |
|הממשלה מציעה עכשיו להעלות את המכסימום שנקבע בחוק האמור ב-1/2 1 מליון                                         |              |
|כדי לאפשר לה לקבל הלוואות נוספות ממוסדות כספיים בתנאים השווים לתנאי ההלוואות                                 |              |
|שנתקבלו לפי החוק האמור.                                                                                      |              |

2 ספר החוקים 81 מיום ז' בתמוז תשי"א (11.7.51), עמ' 240.
