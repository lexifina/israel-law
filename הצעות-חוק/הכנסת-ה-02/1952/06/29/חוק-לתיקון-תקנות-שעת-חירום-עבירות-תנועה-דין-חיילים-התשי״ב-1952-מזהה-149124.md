חוק לתיקון תקנות-שעת-חירום (עבירות תנועה - דין חיילים)'
תשי"ב-1952

|תיקון       |1, תקנות-שעת-חירום (עבירות תנועה - דין חיילים), תש"ט-1949 ,1 יתוקנו כך:                                 |
|התקנות      |בתקנה 1 (א), בפסקה (2), במקום המלים "בענין התנועה בדרכים" שבסופה, יבואו                                 |
|            |המלים "בענין הנוגע לכלי רכב והסדר התחבורה הצבאית או בענין התנועה בדרכים".                               |
|            |דברי הסבר                                                                                               |
|            |תקנות-שעת-חירום (עבירות תנועה - דין חיילים), תש"ט-1949, הותקנו בזמנו                                    |
|            |בקשר עם המבצע שפתח בו הצבא למניעת תאונות דרכים ("מבצע מרדכי"),                                          |
|            |תוקף התקנות הוארך על ידי הכנסת עד יום י"ג בטבת תשי"ג (31 בדצמבר 1952).                                  |
|            |התקנות האמורות מסדירות את השיפוט ב"עבירות תנועה" שנעברו על ידי                                          |
|            |חיילים 5 ולצורך זה מגדירות התקנות "עבירת תנועה" כך:                                                     |
|            |"עבירת תנועה" פירושו -                                                                                  |
|            |(1) עבירה לפי פקודת התעבורה 2 או לפי תקנות התעבורה3   או לפי חוק אחר                                    |
|            |הנוגע לתנועה בדרכים - שחייל יכול להיתבע עליה בבתי הדין של הצבא לפי תקנה 97                              |
|            |של החוקה (היא חוקת השיפוט תש"ח).                                                                        |
|            |(2) עבירה לפי תקנה 98 של החוקה על ידי עשיית מעשה או השתמטות מעשיית                                      |
|            |מעשה שלא בהתאם להוראה, לפקודה או לתקנה בענין התנועה בדרכים.                                             |
|            |הצבא עומד להנהיג בשטח התחבורה הצבאית שיטה שמטרתה לחסוך ؀ࠂࠌࠎࠒࠖ࠘וליעל את                                  |
|            |השימוש בכלי רכב. כדי להבטיח את ביצועה של השיטה הזו בא החוק המוצע להרחיב                                 |
|            |את היקף המונח "עבירת תנועה" ולהוסיף עליו גם עבירות על הוראות פקודות ותקנות                              |
|            |בענינים הנוגעים לכלי רכב והסדר התחבורה הצבאית, כגון החזקת כלי רכב וציודו,                               |
|            |שמירתם, והשימוש בהם.                                                                                    |

1 ספר החוקים 30 מיום י' בטבת תש"י (30,12.49), עמ' 36.
