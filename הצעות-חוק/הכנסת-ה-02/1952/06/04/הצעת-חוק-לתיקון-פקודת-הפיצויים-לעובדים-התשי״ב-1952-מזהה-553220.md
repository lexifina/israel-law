חוק לתיקון פקודת הפיצויים לעובדים, תשי"ב-1952

|תיקון המקורה   |1. פקודת הפיצויים לעובדים, 1947  1(להלן - הפקודה), תתוקן כך:                                            |
|               |(א) בסעיף 2, בהגדרת "עובד", במקום פסקה (1) תבוא פסקה זו:                                                |
|               |"(ו) אדם המועבד שלא בעבודת כפיים ושכרו עולה על אלפיים לירות לשנה ; או"                                  |
|               |(ב) בתוספת הראשונה -                                                                                    |
|               |(1) בפסקה 1 (2) (א) במקום המלים ,,שבע מאות וחמישים לירות" יבואו המלים                                   |
|               |"אלף מאה עשרים וחמש לירות" ובמקום המלים "אלף וחמש מאות לירות"                                           |
|               |יבואו המלים "אלפיים מאתיים וחמישים לירות".                                                              |
|               |(2) בפסקה 1 (2) (ד.) במקום המלים "חמישים לירות" יבואו המלים "שבעים                                      |
|               |וחמש לירות".                                                                                            |
|               |(3) בפסקה 1 (3) (א) במקום המלים "שתי לירות" יבואו המלים "שלוש לירות".                                   |
|               |(4) בפסקה 2 (1) במקום המלים "שמונה לירות" יבואו המלים "שתים עשרה                                        |
|               |לירות'/ ובמקום המלים "חמש לירות" יבואו המלים "שבע וחצי לירות".                                          |
|               |(5) בפסקה 3א (2) במקום המלים "מאה וחמישים לירות" יבואו המלים "מאתיים                                    |
|               |עשרים וחמש לירות'/ ובמקום המלים "מאתיים וחמישים לירות" יבואו המלים                                      |
|               |"שלוש מאות שבעים וחמש לירות'/                                                                           |
|הוראות מעבר    |2, (א) אירעה חבלה לפני יום תחילת תקפו של חוק זה וסכום הפיצויים לפי הפקודה                               |
|               |לא נקבע קביעה סופית לפני אותו יום - ייקבעו סכום הפיצויים החד פעמיים ותוספת                              |
|               |הילדים, במקרה של מות העובד, כאילו היה חוק זה בתקפו ביום החבלה.                                          |
|               |(ב) עובד שהיה ביום תחילת תקפו של חוק זה, או ביום שלאחר מכן, זכאי לפי                                    |
|               |הוראות הפקודה, לתשלום שבועי בעד אי כושר עבודה, מחמת חבלה שאירעה לפני תחילת                              |
|               |תקפו של חוק.זה؀ࠂࠌࠎ, יהיה זכאי לגבי התקופה שלאחר תחילת תקפו לקבל תשלומים שבועיים                         |
|               |לפי הוראות חוק זה.                                                                                      |
|               |דברי הסבר                                                                                               |
|               |החוק המוצע בא להגדיל את הפיצויים המשתלמים על פי פקודת הפיצויים לעובדים,                                 |
|               |1947. פקודה זו תוקנה בשנת 1948; הפיצויים שנקבעו בה הוגדלו ולעובד שנפגע בתאונת                           |
|               |עבודה ניתנה זכות לעזרה ולטיפול רפואי. לפי הפקודה המקורית היה מכסימום הפיצויים                           |
|               |השבועיים -.4 לירות והמכסימום למקרה מוות - סכום חד פעמי של -.500 ל"י. התיקון                             |
|               |משנת 1948 העלה את מכסימום הפיצויים השבועיים ל-.8 ל"י ואת המכסימום למקרה מוות                            |
|               |ל-.1,500 ל"י.                                                                                           |
|               |בקביעת סכומי הפיצויים בשנת 1948 הובא בחשבון שכר ממוצע של -.46 ל"י                                       |
|               |לחודש. החוק המוצע בא להגדיל את סכומי הפיצויים בשים לב לתנודות שחלו בשכר העבודה                          |
|               |מאז 1948, והוא מגדיל ב-50% את מכסימום הפיצויים המשתלמים לפי הפקודה כפי שתוקנה                           |
|               |בשנת 1948 וכן את הסכומים שמעביד חייב לשלם בקשר להוצאות עזרה וטיפול רפואי לרגל                           |
|               |תאונת עבודה.                                                                                            |
|               |החוק הקיים אינו חל לגבי עובד שעבודתו אינה עבודת כפיים ושכרו עולה על                                     |
|               |-.1,000 ל"י לשנה; החוק המוצע בא להעניק את הזכויות הנובעות מהפקודה גם לעובד                              |
|               |שעבודתו אינה עבודת כפיים אם שכרו לשנה אינו עולה על -.2,000 ל"י ,י תיקון זה נראה                         |
|               |הכרחי נוכח התנודה בשכר העבודה.                                                                          |
