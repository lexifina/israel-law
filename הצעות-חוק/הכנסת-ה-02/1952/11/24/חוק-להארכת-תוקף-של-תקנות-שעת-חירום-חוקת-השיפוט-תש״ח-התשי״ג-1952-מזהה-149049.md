|                |עד יום כ"ה בטבת תשי"ד (31 בדצמבר 1953).                                                                     |

|                |דברי הסבר                                                                                                   |
|                |לחוקת השיפוט תש"ח ניתן, תוקף, בצורה של תקנות-שעת-חירום, ביום ד' באלול                                       |
|                |תש"ח (8 בספטמבר 1948). במכשיר משפטי זמני לקיום המשמעת והשיפוט בצבא-הגגה                                     |
|                |לישראל.                                                                                                     |
|                |הממשלה הגישה בזמנו לכנסת הראשונה הצעת חוק - היא - הצעת חוק- השיפוט                                          |
|                |הצבאי, תש"ט-21949 - שנועדה להסדיר את עניני המשמעת והשיפוט בצבא הסדר של                                      |
|                |קבע ; אולם הכנסת הראשונה לא סיימה את הדיון בהצעת חוק זו.                                                    |
|                |י בינתיים האריכה הכנסת הראשונה פעמים מספר את תקפה של חוקת השיפוט תש"ח,                                      |
|                |ואף תיקנה אותה פעמיים.                                                                                      |
|                |תקפה של חוקת השיפוט תש"ח עומד לפקוע ביום י"ג ؀ࠂࠈבטבת תשי"ג (31 בדצמבר                                       |
|                |1952).                                                                                                      |
|                |הממשלה מציעה להאריך את תקפה של חוקת השיפוט תש"ח עד תום שנת ,1953                                            |
