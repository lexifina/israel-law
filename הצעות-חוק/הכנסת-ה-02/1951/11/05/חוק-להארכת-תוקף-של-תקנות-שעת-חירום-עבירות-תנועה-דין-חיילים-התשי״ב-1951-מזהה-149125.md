תשי"ב-1951

|1, תקפן של תקנות-שעת-חירום (עבירות תנועה - דין חיילים), תש"ט-1949 1, מוארך                                    |הארכת תוקף          |

|2. תקפו של חוק זה הוא מיום ב' בטבת תשי"ב (31 בדצמבר 1951),                                                    |תחילת תוקף          |
|דברי הסבר                                                                                                     |                    |
|תקנות-שעת-חירום (עבירות תנועה - דין חיילים), תש"ט-1949, הותקנו בזמנו                                          |                    |
|בקשר עם המבצע שפתח בו הצבא למניעת תאונות דרכים ("מבצע מרדכי").                                                |                    |
|תוקף התקנות הוארך על ידי הכנסת עד יום ב' בטבת ؀ࠂࠊࠌתשי"ב (31 בדצמבר 1951).                                     |                    |
|הנסיון הוכיח את תועלתן המרובה של התקנות, והצורך בהן בעינו עומד. הממשלה                                        |                    |
|מציעה, איפוא, להאריך את תקפן.                                                                                 |                    |
|הואיל והתקנות צמודות לחוקת השיפוט תש"ח, מציעה הממשלה להאריך את התקנות                                         |                    |
|האלה לאותו תאריך שהוצע לגבי הארכת תקפה של חוקת השיפוט תש"ח.                                                   |                    |
