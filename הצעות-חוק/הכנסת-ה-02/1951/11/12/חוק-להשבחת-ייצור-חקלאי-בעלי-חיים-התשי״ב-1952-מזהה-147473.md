חוק להשבחת ייצור חקלאי (בעלי חיים), תשי"ב-1951

|פירושים         |1. בחוק זה -                                                                                             |
|                |"בעל חיים" פירושו - בקר, צאן, סוס, חמור, עוף בית, דבורים וכל בעל חיים                                    |
|                |אחר ששר החקלאות הכריז, באכרזה שפורסמה ברשומות, כבעל חיים לצורך חוק זה,                                   |
|                |וכולל ביצי דגירה;                                                                                        |
|                |"השבחת בעלי חיים" פירושו - השבחת תנובתם של בעלי חיים, שיפור המצ-                                         |
|                |רכים המופקים מהם ומגופותיהם, והעלאת כוח עבודתם, כושר התנגדותם למחלות ופריונם;                            |
|                |"מפקח" פירושו - אדם ששר החקלאות מינהו להיות מפקח לצורך חוק זה.                                           |
|ועדות מיעצות    |2. (א) שר החקלאות ימנה, לצורך חוק זה, ועדה מיעצת או ועדות מועצות; בכל                                    |
|                |ועדה יהיו אנשים מן הציבור ומעובדי המדינה.                                                                |
|                |(ב) ועדה מיעצת יכולה להיות כללית או מיוחדת לסוג מסוים של בעלי חיים.                                      |
|תקנות           |3. שר החקלאות רשאי, לאחר התיעצות בועדה מיעצת שנתמנתה לפי סעיף 2, להת-                                    |
|                |קין תקנות בכל הנוגע להשבחת בעלי חיים, לרבות תקנות -                                                      |
|                |(א) האוסרות או המגבילות גידולם של בעלי חיים, או של כל סוג מסוגיהפ,                                       |
|                |לצרכי רביה, או את השימוש בהם להרבעה טבעית או להזרעה מלאכותית ;                                           |
|                |(ב) האוסרות או המגבילות את שחיטתם והשמדתם של בעלי חיים העשויים                                           |
|                |לשמש לרביה, להרבעה ולהזרעה מלאכותית!                                                                     |
|                |(ג) המסדירות, המגבילות או האוסרות מסחר בזרמה של בעלי חיים המיועדת                                        |
|                |להזרעה מלאכותית;                                                                                         |
|                |(ד) האוסרות התעסקות בהזרעה מלאכותית שלא ברשיון, וקובעות את התנאים                                        |
|                |לקבלת הרשיון וכן לשלילתו;                                                                                |
|                |(ה) הקובעות אזורים מוגנים לשם ביצוע ניסויים בהשבחת בעלי חיים, או לשם                                     |
|                |הגנה על טוהר גזעם, המטילות באזורים אלה הגבלות על החזקת בעלי חיים או קובעות                               |
|                |תנאים להחזקתם;                                                                                           |
|                |(0 הקובעות תנאים סניטריים ואחרים שיש לקיים בקשר לביצוע הרבעה טבעית                                       |
|                |או הזרעה מלאכותית של בעלי חיים;                                                                          |
|                |(ז) המטילות פיקוח על יבוא ויצוא של בעלי חיים לצרכי רביה;                                                 |
|                |(ח) הקובעות אגרות לכל בקשה, אישור או תעודה אחרת, שיוגשו או שיינתנו                                       |
|                |בהתאם לתקנות שהותקנו לפי חוק זה.                                                                         |
|סמכויות מפקח    |4. מפקח רשאי -                                                                                           |
|                |(א) להיכנס בכל עת לתחומי כל קרקע שאינה מקום מגורים לשם פיקוח על קיום                                     |
|                |הוראות התקנות שהותקנו לפי חוק זה;                                                                        |

|(ב) לתפוס כל בעל חיים שלפי דעת המפקח נעברה בו עבירה על תקנה שהותקנה                                             |                |
|לפי חוק זה, וכן לתפוס כל חפץ שיש בו כדי לשמש עדות ביחס לעבירה כזאת; בשעת                                        |                |
|התפיסה יתן המפקח למחזיק בעל החיים או למחזיק החפץ קבלה על הדברים שתפס;                                           |                |
|(ג) לסמן או לסרס בעלי חיים שגידולם או שימושם להרבעה או להזרעה מלאכו-                                            |                |
|תית נאסרו או הוגבלו על פי תקנה שהותקנה לפי חוק זה;                                                              |                |
|(ד) לעשות כל דבר שהוטל על מפקח בתקנות שהותקנו לפי חוק זח.                                                       |                |
|5. העובר על תקנה שהותקנה לפי חוק זה, דינו - מאסר עד שנה אחת או קנס עד שלוש                                      |עבירות          |
|מאות לירות או שני העבשים כאחד.                                                                                  |                |
|6. שר החקלאות ממונה על ביצוע חוק זה.                                                                            |ביצוע           |
|דברי הסבר                                                                                                       |                |
|החוק המוצע ישמש מסגרת לשורת תקנות, שמגמתן השבחת בעלי חיים חקלאיים                                               |                |
|על ידי הטלת אמצעי פיקוח על ריבוים ועל גידולם.                                                                   |                |
|השבחת בעלי חיים - משמעותה הטבת תכונותיהם של בעלי חיים לפי התפקידים                                              |                |
|שעליהם למלא במשק: חיזוק כוח עבודתם, העלאת הכמות והאיכות של תנובתם ושל                                           |                |
|המצרכים המופקים מהם, חיסונם בפני מחלות והגדלת פריונם.                                                           |                |
|החוק המוצע מחייב את שר החקלאות למנות ועדה מיעצת או ועדות מיעצות                                                 |                |
|שיתיעץ בהן בבואו להתקין תקנות בנוגע להשבחת בעלי חיים.                                                           |                |
|יש לציין שכמה ועדות מסוג זה כבר פועלות ליד המחלקה לבעלי חיים שבמשרד                                             |                |
|החקלאות, ותכליתו של סעיף 2 היא לתת לועדות אלה מעמד בחוק.                                                        |                |
|הפיקוח על ביצוע התקנות נמסר למפקחים ולצורך זה הוענקו להם סמכויות אלה:                                           |                |
|א) להיכנס לתחומי כל קרקע שאינה מקום מגורים לשם פיקוח על קיום התקנות;                                            |                |
|ב) לתפוס בעלי חיים שיש יסוד לחשוב כי נעברה בהם עבירה וכן כל חפץ שיכול                                           |                |
|לשמש עדות על כך;                                                                                                |                |
|ג) לסמן או לסרס בעלי חיים;                                                                                      |                |
|ד) לעשות כל דבר שיוטל עליהם בתקנות-                                                                             |                |
|העובר על הוראה מהוראות התקנות, דינו - מאסר עד שנה אחת או קנס עד שלוש                                            |                |
|מאות לירות או שני העבשים כאחד.                                                                                  |                |
