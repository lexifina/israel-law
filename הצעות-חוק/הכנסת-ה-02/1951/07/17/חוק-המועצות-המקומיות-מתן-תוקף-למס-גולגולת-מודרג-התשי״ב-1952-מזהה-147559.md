חוק המועצות המקומיות (מתן תוקף למס גולגולת מודרג),
תשי"א-1951

|1. מס גולגולת, שמועצה מקומית הטילה, או דימתה להטיל, בשנת הכספים 1950 -                                    |מתן תוקף        |
|1951 או קודם לכן, לפי סעיף 5 לפקודת המועצות המקומיות, 1941 1, והוראות הצו המכונן                          |למס גולגולת     |
|אותה, אין רואים אותו כמוטל שלא כחוק או כבלתי ניתן לגביה בשל כך בלבד שהודרג                                |מודרג           |
|לפי גודל ההכנסות של החייבים בו.                                                                           |                |
|דברי הסבר                                                                                                 |                |
|בתוקף סמכויותיהן לפי סעיף 5(1) (ד) לפקודת המועצות המקומיות, 1941, נוהגות                                  |                |
|מועצות מקומיות להטיל מם גולגולת על תושבי שטחי שיפוטן. אחדות מן המועצות האלה                               |                |
|החליטו, באישור השלטונות המרכזיים המוסמכים, להדריג את שיעורי המס הזה בהתאם                                 |                |
|לגודל ההכנסות של החייבים בו, בראותן בהטלת מס מודרג כזה שיטה צודקת יותר של                                 |                |
|חלוקת נטל המסים, ובהסתמכו על סעיף 5(2) לפקודה האמורה והצווים המכוננים אותן,                               |                |
|שלפיהם מותרת הטלת מסים מקומיים "לפי מכסות אחוזים שונות או דרגות שונות... על                               |                |
|בני אדם מסוגים שונים".                                                                                    |                |
|נמצאו עוררים על חוקיותו של מם גולגולת מודרג, ובית המשפט העליון, בדונו                                     |                |
|בשאלה זו בבג"צ 34/50, אסנין ואחרים נגד המועצה המקומית עיר יזרעאל - עפולה                                  |                |
|ואחרים (תשי"א פסקים, כרך ג', עמ' 373) פסק כי הדין עמם. בית המשפט העליון הסכים                             |                |
|אמנם לדעה כי "שיטת המס המודרג, המבוססת על שיעור הכנסתו של אדם או על גודל                                  |                |
|רכושו, היא השיטה הקרובה ביותר לחלוקה צודקת וישרה של עומס המסים", אך קבע יחד                               |                |
|עם זאת כי "עצם המושג "מס גולגולת", כפי שהוא עולה מפירוש המלות, מורה על מס אשר                             |                |
|הוא נקבע לא על סמך הכנסתו השנתית או כלל רכושו של אדם, אלא, מטילים אותו על                                 |                |
|גולגולת בלבד, והוא מס אחיד לכל נפש, בחינת "העשיר לא ירבה והדל לא ימעיט" ".                                |                |
|כללו של דבר: מם גולגולת הוא לפי עצם מהותו מס אחיד, שווה לכל נפש, שהדירוג                                  |                |
|בו אינו מותר. משום כך ؀ࠂࠌࠎומשום יתר הנימוקים המפורטים בפסק דינו, הגיע בית ה משפט                          |                |
|העליון לכלל מסקנה כי מם הגולגולת המודרג בעיר יזרעאל - עפולה, אשר שימש נושא                                |                |
|לדיון שהתנהל בפני בית המשפט, אינו ניתן לגביה.                                                             |                |
|לאור פסק דין זה קיים חשש כי אנשים אשר טרם שילמו את מם הגולגולת המודרג                                     |                |
|כפי המכסה שהושתה עליהם יסרבו עתה לעשות זאת ; ואילו מי שפרע כבר את מסיו יוכל                               |                |
|לתבעם בחזרה. מצב זה יש בו כדי לערער את משק הכספים של המועצות המקומיות הנו-                                |                |
|געות בדבר, שכן תקציביהן היו מיוסדים על ההנחה שמס הגולגולת שהוטל על התושבים                                |                |
|אף ייגבה מידם,                                                                                            |                |
|כדי לקדם את פני הסכנה הזאת, מן ההכרח ליתן תוקף למס הגולגולת המודרג                                        |                |
|שהוטל על ידי המועצות המקומיות בעבר, במידה שמס זה היה חוקי מכל שאר הבחינות;                                |                |
|ותפקיד זה נועד למלא החוק המוצע בזה.                                                                       |                |
|יש להדגיש כי כל עיקרה של הצעת חוק זו לא בא אלא להכשיר הכשר חוקי את                                        |                |
|דירוג מס הגולגולת שהוטל בעבר? ואין בה משום שינוי של שיטת המסים המקומיים                                   |                |
|לגבי העתיד. שאלה זו של קביעת שיטה חדשה להטלת מסים מקומיים תבוא על פתרונה                                  |                |
|הכולל במסגרת רחבה יותר.                                                                                   |                |
