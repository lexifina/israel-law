מתפרסמת בזה הצעת חוק מטעם הממשלה :

חוק העיריות (הוראת שעה), תשי"ג-1953

|1. בחוק זה יתפרש כל מונח כמשמעותו בפקודת העיריות',1934 1 (להלן - הפקודה),                                |פירושים          |
|אם אין כוונה אחרת משתמעת.                                                                                |                 |
|2. לצורך פרסום הודעה בדבר הטלת ארנונות שהוטלו לשנת הכספים 1953/54, שיעורן                                |תיקון הפקודה     |
|ומועדי שילומן, יראו סעיף 102 (ג) לפקודה כאילו נאמר "25 במרס" במקום ,,15 במרס".                           |                 |
|3. תקפו של חוק זה הוא מיום כ"ח באדר תשי"ג (15 במרס 1953).                                                |תחילת תוקף       |
|דברי הסבר,                                                                                               |                 |
|לפי החוק הקיים על מועצת עיריה לפרסם, בתחום העירית' לא יאוחר מיום 15                                      |                 |
|במרס שלפני שנת כספים שלגביה הוטלו ארנונות' הודעה בדבר הטלתן, שיעורן ומועדי                               |                 |
|שילומן. החוק המוצע קובע לגבי שנת הכספים 1953/54 כי המועד לפרסום ההודעה יתם                               |                 |
|ב-25 במרס כאמור.                                                                                         |                 |
|לפי החוק הקיים טעונות הארנונות שמועצת עיריה רשאית להטילן בתחום שיפוטה                                    |                 |
|לכל שנת כספים אישור מטעם؀ࠂࠎࠐࠒ שר הפנים. אין המועצה רשאית לפרסם הודעה בדבר הטלת                           |                 |
|הארנונות האמורות לפני שאושרו ע"י שר הפנים, והנה מספר עיריות לא הספיקו להעביר                             |                 |
|לשר הפנים את החלטותיהן בדבר הטלת הארנונות במועד שיאפשר לשר את הבדיקה                                     |                 |
|הדרושה ואת מתן אישורו ולעיריות את תיקון ההחלטות, אם יהיה צורך בכך. משום כך,                              |                 |
|יש צורף דחוף לדחות לשנת הכספים 1953/54 את המועד לפרסום הטלת הארנונות מטעם                                |                 |
|העיריות בעשרה ימים, עד ל"25במרס.                                                                         |                 |
