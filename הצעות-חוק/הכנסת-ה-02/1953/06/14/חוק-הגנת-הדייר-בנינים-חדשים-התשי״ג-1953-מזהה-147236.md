חוק הגנת הדייר (בנינים חדשים), תשי"ג-1953 .

|פירושים          |1. בחוק זה -                                                                                           |
|                 |"פקודת הדירות" פירושו - פקודת הגבלת שכר דירה (דירות), 1940 ;                                           |
|                 |"פקודת בתי עסק" פירושו - פקודת ההגבלות על שכר דירה (בתי עסק), 1941 2;                                  |
|                 |"תקנות ההגנה" פירושו - תקנות ההגנה (תיקון) (מס' 13)' 1943 3.                                           |
|בנינים           |2. מושכר הנמצא בבנין או בתוספת בנין שבנייתם הושלמה לאחר יום י"ד בטבת                                   |
|חרשים            |תשי"ג (1 בינואר 1953) ושהושכר לראשונה אחרי תחילת תקפו של חוק זה - לא יחולו                             |
|                 |עליו הוראות פקודת הדירות' פקודת בתי עסק והוראות תקנות ההגנה' חמש שנים מתאריך                           |
|                 |השכרתו לראשונה.                                                                                        |
|ביצוע ותקנות     |3. שר המשפטים ממונה על ביצוע חוק זה; והוא רשאי להתקין תקנות בכל ענין                                   |
|                 |הנוגע לביצועו.                                                                                         |
|                 |.דברי הסבר                                                                                             |
|                 |סעיף 55 להצעת חוק הגנת דיירים, תשי"ג-1952' קובע' כי דירות ובתי עסק                                     |
|                 |בבנינים חדשים יהיו פטורים, חמש שנים לאחר השכרתם לראשונה, מההגבלות בענין                                |
|                 |שכר דירה מכסימלי ובענין החזרת החזקה שנקבעו באותה הצעה.                                                 |
|                 |הוראות אלה של הצעת החוק האמורה מעכבות עסקי שכירות בבנינים חדשים.                                       |
|                 |שכירות שתיעשה לפי החוק הקיים תהיה כפופה, לכל ההגבלות הקיימות' ובעלי דירות                              |
|                 |או בתי עסק בבנינים חדשים מהמסים להשכירם כל עוד ההוראות ؀ࠂࠌࠎࠒࠖ࠘האמורות של חוק                           |
|                 |הגנת דיירים לא נכנסו לתקפן.                                                                            |
|                 |אד מכיוון שההוראות המקיפות שבחוק הגנת דיירים מחייבות דיון ממצה וממושך                                  |
|                 |בכנסת. ואילו ענין הפטור של בנינים חדשים אינו סובל דיחוי' בא החוק המוצע בזה                             |
|                 |וקובע את הפטור לפי סעיף 55 של הצעת חוק הגנת דיירים במסגרת החוק הקיים.                                  |
