|1. בחוק זה "ארנונה" פירושו - ארנונה המוטלת על ידי -רשות מקומית על מחזיקים.                               |פירושים         |
|כמשמעותם בפקודת העיריות, 1934 1, ובצווים שעל פי פקודת המועצות המקומיות' 1941 -                           |                |
|הכל לפי הענין, וכן ארנונת גולגולת המוטלת על פי פקודת המועצות המקומיות, 1941.                             |                |
|2.  אלה יהיו פטורים; בתקופות האמורות להלן, מתשלום כל ארנונה שהיו חייבים בה                               |פטור            |
|אלמלא חוק זה:                                                                                            |                |
|(1) מי שמשרת שירות סדיר בצבא-הגנה לישראל לפי חוק שירות בטחון-.                                           |                |
|תש"ט-1949 3. (להלן - בסעיף זה - חייל) - כל עוד הוא חייל כאמור ועד                                        |                |
|תום.ארבעה חדשים מיום שחרורו;                                                                             |                |
|(2) הורה של חייל' המוכיח להנחת דעתה של הרשות המקומית שבמקום                                              |                |
|מגוריו, כי כל פרנסתו היתה על החייל סמוך לפני תחילת שירותו וכי אין לו'                                    |                |
|ואין הוא מסוגל להשיג, פרנסה די מחייתו - כל עוד הוא במצב האמור וכל                                        |                |
|עוד החייל פטור לפי פסקה (1).                                                                             |                |
|3. אלה יהיו פטורים, בתקופות האמורות להלן, מתשלום שני שלישים של ארנונה                                    |פטור חלקי       |
|שהיו חייבים בה אלמלא חוק זה:                                                                             |                |
|(1) מי שמשרת שירות סדיר בצבא-הגנה לישראל שלא לפי חוק שירות בטחון,                                        |                |
|תש"ט-1949 - כל עוד הוא משרת באמור;                                                                       |                |
|(2) נכה הזכאי לתגמולים לפי חוק הנכים (תגמולים ושיקום)', תש"ט-1949 4                                      |                |
|- כל עוד הוא זכאי כאמור ,י                                                                               |                |
|(3) מי שמוכיח להנחת דעתה של הרשות המקומית שבמקום מגוריו, כי                                              |                |
|איבד חמישים אחוז או יותר מכשרו לעבודה כתוצאה מחבלה שנחבל בה לאחר                                         |                |
|יום ט"ז בכסלו תש"ח (29 בנובמבר 1947) עקב פעולות האיבה במלחמת                                             |                |
|השחרור וכי אין לו, ואין הוא מסוגל להשיג, פרנסה די מחייתו - כל  עוד .                                     |                |
|הוא במצב האמור;                                                                                          |                |
|(4) מי שמוכיח להנחת דעתה של הרשות המקומית שבמקום מגוריו, כי איבד                                         |                |
|חמישים אחוז או יותר מבשרו לעבודה כתוצאה מחבלה שנחבל בה או מחלה                                           |                |
|שחלה בה עקב שירותו באחד מצבאות מעצמות הברית בשעת מלחמת העולם                                             |                |

|הוא במצב האמור;                                                                                          |                |
|(5) מי שמוכיח להנחת דעתה של הרשות המקומית שבמקום מגוריו, כי איבד                                         |                |
|חמישים אחוז או יותר מכשרו לעבודה כתוצאה מחבלה שנחבל בה או מחלה                                           |                |
