חוק גימלאות לשרים, תשי"ד-1953

|1. בחוק זה -                                                                                               |פירושים              |
|"שאיר" פירושו -                                                                                            |                     |
|(1) מי שהיתה אשת הנפטר ביום מותו וכל עוד לא נישאה לאחר.                                                    |                     |
|(2) ילדו של הנפטר, לרבות ילד חורג וילד מאומץ, וכן נכדו של הנפטר                                            |                     |
|שכל פרנסתו היתה עליו ביום מותו, כל עוד הוא אחד מאלה:                                                       |                     |
|(א) לא מלאו לו שמונה עשרה שנים ;                                                                           |                     |
|(ב) מלאו לו שמונה עשרה שנים, אך לא מלאו לו עשרים וארבע שנים,                                               |                     |
|והוכיח להנחת דעתו של שר האוצר, כי הוא עסוק בלימודים ; .                                                    |                     |
|(ג> אינו מסוגל לכלכל את עצמו.                                                                              |                     |
|(3) הורה של הנפטר, לרבות הורה חורג והורה מאמץ, שכל פרנסתו היתה על                                          |                     |
|הנפטר ביום מותו,                                                                                           |                     |
|2, אדם שחדל מכהן בתורת שר תשולם לו כל ימי חייו, החל מסוף החודש שבעדו קיבל                                  |קצבאות               |
|את משכורתו האחרונה בתורת שר, קצבה חדשית בשיעור המפורט להלן, ובלבד שלא                                      |למי שחדל             |
|תעלה על שני שלישים ממשכורת שרים אותה שעה.                                                                  |מכהן כשר             |
|שיעור הקצבה לשרים יהיה לפי שנות כהונתם:                                                                    |                     |
|(1) עד שנתיים - 10% ממשכורת שרים;                                                                          |                     |
|(2) שנתיים עד חמש שנים - 35% ממשכורת שרים ;                                                                |                     |
|(3) חמש שנים ומעלה - 7% ממשכורת שרים לכל שנת כהונה.                                                        |                     |
|בסעיף זה, "משכורת שרים" פירושו - המשכורת על כל התוספות הקבועות המשת-                                       |                     |
|למת לרוב חברי הממשלה.                                                                                      |                     |
|3. לצורך חישוב שיעור קצבתו של שר לפי חוק זה -                                                              |הוראות לחישוב        |
|(1) יצורפו כל תקופות כהונתו בתורת שר בזמן מן הזמנים ;                                                      |                     |
|(2) כל תקופת כהונתו בתורת חבר הועד הלאומי של כנסת ישראל בארץ                                               |                     |
|ישראל או חבר ההנהלה של ההסתדרות הציונית העולמית, שקדמה לחברות                                              |                     |
|בממשלה, דינה כדין כהונת שר;                                                                                |                     |
|(3؀ࠂࠌࠎࠒࠖ࠘) כל תקופת כהונתו במועצת המדינה הזמנית ובכנסת שקדמה לחברותו                                       |                     |
|בממשלה ;                                                                                                   |                     |
|(4) לענין סעיף 2 פסקה (3), יהא כל חודש מחדשי הכהונה בתורת שר שאינם                                         |                     |
|עולים לשנה תמימה מזכה בחלק שנים עשר מן הקצבה המגעת בעד כל שנת                                              |                     |
|כהונה, וכל פרק זמן של כהונה שאינו עולה לחודש ייחשב כחודש מלא.                                              |                     |
|4. שר שנפטר תשולם לשאיריו, בעד החודש שבו נפטר השר ובעד ששה חדשים נוספים,                                   |משכורת               |
|המשכורת, עם כל התוספות, שהיתה משתלמת אותה שעה לשר, אילולא נפטר ; מכאן ואילך                                |וקצבאות              |
|ישולמו לשאיריו קצבאות חדשיות בשיעור שהיה משתלם לאותו שר, אילו חדל ביום פטי-                                |                     |
