|סכומי המקדמה ששולמו לפי החוק יוחזרו לאחר מכן בשיעורים ובמועדים אלה ;                                      |               |
|י 30% מסכום המקדמה ינוכה ממס הכנסה שאותו אדם יהא חייב בו בכל אחת משנות                                    |               |
|השומה 1954/55 ו-1955/56 והיתרה תנוכה מסכום מס הכנסה שאותו אדם יהא חייב בו                                 |               |
|בשנת השומה 1956/57.                                                                                       |               |
|אדם שלא יהיה חייב במס הכ נסה באחת משנות השומה האמורות או שסכום המס                                        |               |
|שהוא יהיה חייב בו יהיה קטן מסכום המם שהותר לו לנכות ימאותה שנת שומה, יוחזר לו                             |               |
|העודף במזומנים, או ייזקף על חשבון כל חוב אחר שהוא חייב למדינה, הכל לפי בחירתו                             |               |
|(סעיף 14),                                                                                                |               |
|אדם שהכנסתו בשנת השומה 1953/54 תהא פחותה מהכנסתו בשנת השומה 1952/53,                                      |               |
|יהיה רשאי לפנות למנהל בבקשה להקטין את סכום המקדמה (סעיף 11).                                              |               |
|החוק המוצע קובע במפורש, שכל הצהרה שמסר אדם בקשר לתשלום המקדמה, וכן                                        |               |
|על קביעה של המנהל לענין זה, לא תהא להן כל השפעה על עניני מס ההכנסה שאותו                                  |               |
|אדם חייב בו (סעיף 15).                                                                                    |               |
