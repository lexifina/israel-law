|1. הכנסת היא בית המחוקקים של המדינה.                                                                       |מהות                 |

|5. כל אזרח ישראל, שביום האחרון שלפני שנת הבחירות היה בן עשרים ואחת ומעלה,                                  |הזכות להיבחר         |

|של הכנסת היוצאת.                                                                                           |הבחירות              |

|שבו הוחלט להתפזר.                                                                                          |                     |

|יפעלו כסדרם.                                                                                               |                     |
|9. תוצאות הבחירות יפורסמו ברשומות תוך ארבעה עשר יום מיום הבחירות.                                          |פרסום                |
|                                                                                                           |תוצאות               |
|                                                                                                           |הבחירות              |
|10. (א) הכנסת הבאה תתכנס למחרת היום שבו תמה תקופת כהונתה של הכנסת היוצאת.                                  |כינוס הכנסת          |

|הבחירות ברשומות.                                                                                           |                     |

|הראשון שלאחריו.                                                                                            |                     |
|(ד) הכנסת תתכנס בשעה שתים עשרה בצהרים במקום שבו ישבה לאחרונה הכנסת                                         |                     |
|היוצאת.                                                                                                    |                     |
|11. הכנסת תיפתח על ידי נשיא המדינה, ובהעדרו מישיבת הפתיחה - על ידי זקן חברי                                |מתיחת הכנסת          |
|הכנסת הנוכחים.                                                                                             |                     |
|12. (א) נשיא המדינה או חבר הכנסת שפתח את הישיבה יקרא בישיבת הפתיחה באזני                                   |הצהרת                |
|חברי הכנסת את נוסח ההצהרה הזאת:                                                                            |אמונים של            |
|"אני מתחייב לשמור אמונים למדינת ישראל ולמלא באמונה את                                                      |חברי הכנסת           |
|שליחותי בכנסת",                                                                                            |                     |
|וכל חבר מחברי הכנסת, בזה אחר זה, יקום ויצהיר:                                                              |                     |
