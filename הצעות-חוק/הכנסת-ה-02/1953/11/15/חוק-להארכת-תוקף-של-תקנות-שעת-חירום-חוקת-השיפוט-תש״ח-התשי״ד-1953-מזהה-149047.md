חוק להארכת תוקף של תקנות-שעת-חירום
(חוקת השיפוט תש"ח), תשי"ד-1953

|1, תקפן של תקנות-שעת-חירום (חוקת השיפוט תש"ח), תש"ח-1948 1, מוארך בזה                                         |הארכת תוקף        |
|עד יום ו' בטבת תשט"ו (31 בדצמבר 1954).                                                                        |                  |
|2, תקפו של חוק זה הוא מיום כ"ה בטבת תשי"ד (31 בדצמבר 1953).                                                   |תחילת תוקף        |
|דברי הסבר                                                                                                     |                  |
|לחוקת השיפוט תש"ח ניתן תוקף, בצורה של תקנות-שעת-חירום, ביום ד' באלול                                          |                  |
|תש"ח (8 בספטמבר 1948), כמכשיר משפטי זמני לקיום המשמעת והשיפוט בצבא-הגנה                                       |                  |
|לישראל.                                                                                                       |                  |
|הממשלה הגישה בזמנו לכנסת הראשונה הצעת חוק - היא הצעת חוק השיפוט                                               |                  |
|הצבאי, תש"ט-1949  2- שנועדה להסדיר את עניני המשמעת והשיפוט בצבא הסדר של                                       |                  |
|קבע ; אולם הכנסת הראשונה לא סיימה את הדיון בהצעת חוק זו.                                                      |                  |
|בינתיים האריכה הכנסת הראשונה פעמים מספר את תקפה של חוקת השיפוט תש"ח,                                          |                  |
|ואף תיקנה אותה שלוש פעמים.                                                                                    |                  |
|תקפה של חוקת ؀ࠂࠌࠎהשיפוט תש"ח עומד לפקוע ביום כ"ה בטבת תשי"ד (31 בדצמבר                                        |                  |
|1953).                                                                                                        |                  |
|הממשלה מציעה להאריך את תקפה של חוקת השיפוט תש"ח עד תום שנת 1954,                                              |                  |
|כדי שתהא שהות מספקת בידי הממשלה לסיים את הדיון בהצעה חדשה של חוק קבע ולהגי-                                   |                  |
|שה לכנסת השניה וכדי שתהא בידי הכנסת שהות מספקת לסיים את הדיון באותה הצעה.                                     |                  |
