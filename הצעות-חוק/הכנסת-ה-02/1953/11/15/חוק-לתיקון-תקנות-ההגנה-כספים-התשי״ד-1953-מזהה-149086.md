|תיקון תקנות        |1. תקנות ההגנה (כספיט), 1941 1, יתוקנו כך:                                                               |
|חחננה              |בתקנה 7 (1) (א), אחרי המלים "מסוג שיפורט בצו" יבוא פסיק ואחריו יבואו המלים                               |
|                   |"לרכשם או לרכוש כל זכות בהם".                                                                            |
|                   |דברי הסבר                                                                                                |
|                   |תקנה 7 (1) (א) לתקנות ההגנה (כספים)' 1941' אומרת:                                                        |
|                   |יכול שר האוצר להורות בצו' כי - בהתחשב עם כל פטורים שהוא יכול לקבוע                                       |
|                   |עליהם הוראות בצו' ואם לא ניתנה רשות על ידי שר האוצר או בשמו אסור                                         |
|                   |לשום אדם למכור או להעביר ניירות ערך מסוג שיפורט בצו או לעשות כל דבר                                      |
|                   |שכרוכה בו יצירת שעבוד על ניירות ערך מסוג כנ"ל או כל דבר הפוגע בזכו-                                      |
|                   |יותיו או בסמכויותיו של שר האוצר ביחס לניירות ערך מסוג כנ"ל' דהיינו,                                      |
|                   |ניירות ערך מסוג אשר' לדעת שר האוצר' עלולים למכור אותם בחוץ לארץ.                                         |
|                   |התיקון המוצע בא להסמיך את שר האוצר לאסור לא רק מכירתם, העברתם ושעבודם                                    |
|                   |של ניירות ערך ؀ࠂࠊࠌמסויימים, אלא גם רכישתם ורכישת זכויות בהם. סמכות זו דרושה לשר                          |
|                   |האוצר לשם מניעת עסקאות על ידי תושבי ישראל לרכישת ניירות ערך העוברים לסוחר                                |
|                   |בחוץ לארץ ושיווקם בישראל ללא פיקוח.                                                                      |
