חוק להארכת תוקף של תקנות-שעת-חירום
(הוראות בדבר רישום ציוד וגיוסו), תשי"ד-1953

|הארכת תוקף       |1. תקפן של תקנות-שעת-חירום (הוראות בדבר רישום ציוד וגיוסו), תשי"א-1951 1,                                  |
|                 |מוארך בזה עד יום ו' בטבת תשט"ו (31 בדצמבר 1954).                                                           |
|תחילת תוקף       |2 . תקפו של חוק זה הוא מיום כ"ה בטבת תשי"ד (31 בדצמבר 1953).                                               |
|                 |דברי הסבר                                                                                                  |
|                 |ביום ז' במיון תשי"א (11 ביוני 1951) התקין שר הבטחון תקנות-שעת-חירום (הוראות                                |
|                 |בדבר רישום ציוד וגיוסו)' תשי"א-1951, שמטרתן לאפשר את רישומם המהיר וגיוסם                                   |
|                 |לצרכי צבא-הגנה לישראל,של כלי טיס, כלי שיט וכלי רכב למיניהם, ממונעים ובלתי                                  |
|                 |ממונעים, לרבות טרקטורים, מכונות חפירה, הובלה, הרמה והעמסה, וחלקים וחלקי חילוף                              |
|                 |ואביזרים של ציוד כאמור, וכן סוסים ובעלי חי אחרים המשמשים לרכיבה, הובלה או                                  |
|                 |סחיבה.                                                                                                     |
|                 |תקפן של תקנות אלה הוארך על ידי הכנסת עד יום כ"ה בטבת תשי"ד (31 בדצמבר                                      |
|                 |1953), והן؀ࠂࠊࠌ עומדות לפקוע באותו יום.                                                                     |
|                 |הממשלה תגיש בזמן הקרוב ביותר הצעת חוק קבע שיבוא במקום התקנות האלה,                                         |
|                 |וכדי שתהא שהות בידיה לנסח סופית את ההצעה האמורה, וכדי שתהא בידי הכנסת שהות                                 |
|                 |מספקת לסיים את הדיון בה, כשתוגש, מציעה בזה הממשלה להאריך את תקפן של התקנות                                 |
|                 |עד יום וי בטבת תשט"ו (31 בדצמבר 1954).                                                                     |
