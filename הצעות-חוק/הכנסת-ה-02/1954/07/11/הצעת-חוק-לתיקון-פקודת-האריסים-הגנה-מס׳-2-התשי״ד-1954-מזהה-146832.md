מתפרסמת בזת הצעת חוק מטעם הממשלה:

חוק לתיקון פקודת האריסים (הגנה) (מס' 2), תשי"ד-1954

|1, בפסקה (2) לסעיף 23 שלפקודת האריסים (הגנה)1, אחרי "מידי הקרן הקיימת                                     |תיקון סעיף 28  |
|לישראל" יווסף "או מידי החברה להתישבות היהודים בארץ ישראל - פיק"א".                                        |               |
|דברי הסבר                                                                                                 |               |
|פקודת האריסים (הגנה) קובעת הוראות שתכליתן להגן על אריסים של משקים                                         |               |
|חקלאיים בקרקעות מירי. הפקודה אינה מתירה לבעל הקרקע להפסיק אריסות אלא אם נתן                               |               |
|לאריס שטח מחיה במקום אחר, אינה מתירה להעלות דמי האריסות אלא באישור הממונה                                 |               |
|על המחוז וכר.                                                                                             |               |
|בשנת 1942 הוסיפה ממשלת המנדט לתקנות ההגנה' 1939, תקנה 48א שהגבילה                                         |               |
|את תחומי ההגנה הניתנת על ידי הפקודה שלא תחול אלא על אריסים שעיבדו את קרקעו-                               |               |
|תיהם לראשונה לפני יום תחילתה של אותה תקנה ; כן שללה התקנה את ההגנה מאריסים                                |               |
|המעבדים את קרקעות המדינה,                                                                                 |               |
|הממשלה הציעה בשעתה הצעת חוק הבאה להכליל את הוראות התקנה בתוך הפקודה ;                                     |               |
|ההצעה נתקבלה על ידי הכנסת בחוק לתיקון פקודת האריסים (הגנה), תשי"ג--1953, אלא                              |               |
|שבאותו חוק הוסיפה הכנסת, מיזמתה היא, סוג נוסף של אריסים שלא ייהנו מההגנה הניתנת                           |               |
|בפקודה, והם אריסים המעבדים קרקעות שקיבלו במישרין מידי הקרן הקיימת؀ࠂࠎࠐࠒ לישראל                             |               |
|(להבדיל מאריסים המעבדים קרקעות שהן כיום בבעלותה של הקרן הקיימת לישראל,                                    |               |
|אך האריסים קיבלו אותן בשעתם מידי הבעלים הקודמים - לגבי אריסים אלה נשארה                                   |               |
|ההגנה בתקפה).                                                                                             |               |
|בעקבות התיקון האחרון הזה נמצא שראוי להעניק אותה עמדה לענין הפקודה גם                                      |               |
|למוסד המיישב הגדול האחר, היא החברה להתישבות היהודים בארץ-ישראל - פיק"א,                                   |               |
|החוק המוצע בא לקיים זאת.                                                                                  |               |

1 חוקי א"י, כרך א' פרק מ' עמ' 476; ס"ח 117, תשי"ג, עמ'36.
