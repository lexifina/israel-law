חוק תשלום פיצויים מאיטליה, תשט"ו-1955

|1. בחוק זה "תובעים" - תושבי ישראל שמטלטליהם היו, במלחמת העולם השניה'                                       |הגירות            |
|נתונים לאמצעים כגון תפיסה, עיקול או פיקוח, כשהיו במעבר בשטח איטליה ובכללו                                  |                  |
|טריאסטה ; והביטוי "תביעה" יתפרש בהתאם לכך.                                                                 |                  |
|2. (א) שר המשפטים רשאי למנות ועדה של חמישה לצורך חוק זה (להלן - הועדה) ו                                   |מינוי ועדה י      |
|יושב ראש הועדה יהיה שופט שלום.                                                                             |לבירור תביעות     |
|(ב) הועדה היא גוף מואגד והיא זכאית להתקשר בחוזים, לרכוש ולהחזיק נכסים                                      |                  |
|ולהוציאם מרשותה ולהיות צד בכל הליך משפטי או משא ומתן אחר.                                                  |                  |
|(ג) הורעה על מינוי הועדה, על הרכבה ומענה תפורסם ברשומות.                                                   |                  |
|3. שר המשפטים רשאי לקבוע בתקנות את הגמול שיינתן לחברי הועדה, למעט היושב                                    |גמול              |
|ראש ולמעט חבר הועדה שהוא עובד המדינה.                                                                      |                  |
|4. הועדה תברר תביעות התובעים ותחלק ביניהם, בדרך הקבועה בחוק זה ובתקנות'                                    |תפקיד ה.ע-ה       |
|את הסכום של תשע מאות אלף לירות אשר שר האוצר יעמיד לרשותה מאוצר המדינה.                                     |                  |
|5. תובע יגיש תביעתו לועדה, בדרך ובמועד שייקבעו בתקנות.                                                     |הגשת תביעה        |
|6. (א) לועדה יהיו כל הסמכויות שאפשר להעניק לועדת חקירה לפי הסעיפים 5 ו-5א                                  |הועדה -           |
|לפקודת ועדות חקירה 1.                                                                                      |סמכויות ונוה5     |
|(ב) סדרי הדין לפני הועדה ייקבעו בתקנות,                                                                    |                  |
|7 .הועדה רשאית לסטות מדיני הראיות, אם היא משוכנעת שהדבר דרוש לגילוי האמת                                   |ראיות             |
|ולמיצוי הצדק ; החליטה הועדה לסטות מדיני הראיות כאמור, תרשום את הטעמים שהניעוה                              |                  |
|להחלטתה.                                                                                                   |                  |
|8. סכומים ששולמו לתובעים או לנציגיהם לפני תחילת חוק זה מאוצר המדינה' יראו                                  |מפרעות            |
|אותם כמפרעות ששולמו להם על חשבון תביעותיהם לפי חוק זה.                                                     |                  |
|9. תובע שתביעתו אושרה זכאי לקבל מאת הועדה' מתוך הסכום הנקוב בסעיף 4 לאחר                                   |סילוק תביעות      |
|ניכוי הוצאות הועדה שקבעה אותן באישור שר האוצר, חלק יחסי כיחס שבין תביעתו כפי                               |                  |
|שאושרה לבין סך כל התביעות שאושרו.                                                                          |                  |
|10. (א) לא תהיה זכות תביעה לתובע אלא לפי הוראות חוק זה והתקנות שהותקנו לפיהן.                              |יחוד התביעה       |
|(ב) סעיף זה אינו בא לפגוע בזכות הביעה על פי משפט מדינת חוץ.                                                |                  |
|11. הועדה רשאית לעכב ולנכות לטובת גוף מואגד שאושר לענין זה על ידי שר המשפטים,                              |הוצאות ורמי       |
|מן הכספים שישולמו לתובעים לפי סעיף 9' אותם הסכומים שהם לדעת הועדה פיצוי סביר                               |עמלה              |
|על הוצאות ודמי עמלה למען אותם התובעים.                                                                     |                  |
|12 .(א) החלטה מנומקת של הועדה בכל תביעה לפי חוק זה תיערך בכתב ותימסר .                                     |החלטה וערעור      |
|לתובע.                                                                                                     |                  |
|(ב) הרואה עצמו מקופח על ידי החלטת הועדה ؀ࠂࠌࠎࠒࠚࠜࠞרשאי תוך שלושים יום מהיום שבו                              |                  |
|נמסרה לו ההחלטה' לערער עליה לפני בית המשפט המחוזי בירושלים והוראות. תקנות..                                |                  |
