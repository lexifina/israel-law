|(31 במרס 1956)".                                                                                             |                 |
|דברי הסבר                                                                                                    |                 |
|חוק תקציבי השירותים הדתיים היהודיים, תש"ט-1949, קובע הסדר בדבר תקציבן                                        |                 |
|של המועצות הדתיות היהודיות הקיימות' המטפלות בסיפוק שירותים דתיים לתושבים                                     |                 |
|היהודיים.                                                                                                    |                 |
|בסעיף 3 (ה) של החוק הנ"ל נאמר שמועצה דתית קיימת לא תכהן יותר משנה אחת                                        |                 |
|מיום פרסום החוק ברשומות. החוק נתפרסם ברשומות ביום כ"ב באב תש"ט (17 באוגוסט                                   |                 |
|1949), וכתובתן של המועצות הדתיות הקיימות עמדה איפוא לתום ביום ג' באלול. תש"י                                 |                 |
|(16 באוגוסט 1950).                                                                                           |                 |
|מאז הוארכה תקופת כהונתן של המועצות הדתיות הקיימות מפעם לפעם2 , ؀ࠂࠎࠐࠒולאחרונה,                                |                 |
|ביום י"ז באדר ב' תשי"ד (22 במרס 1954) ,נתקבל בכנסת חוק תקציבי השירותים הדתיים                                |                 |
|היהודיים (תיקון), תשי"ד-1954, 8 המאריך את תקופת כהונתן של המועצות הדתיות                                     |                 |
|הקיימות עד יום ח' בניסן תשט"ו (31 במרס 1955).                                                                |                 |
|הממשלה דנה בהצעת חוק המועצות הדתיות הבא לקבוע הסדר לסיפוק צרכי הדת                                           |                 |
|הציבוריים של תושבי המדינה, אך טרם סיימה את דיוניה. הממשלה מציעה איפוא להאריך                                 |                 |
|את תקופת כהונתן של המועצות הדתיות היהודיות הקיימות לשנה נוספת.                                               |                 |
