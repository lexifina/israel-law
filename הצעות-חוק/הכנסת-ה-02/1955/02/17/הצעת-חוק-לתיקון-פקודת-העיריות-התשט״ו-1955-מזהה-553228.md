חוק לתיקון פקודת העיריות, תשט"ו-1955

|1. פקודת העיריות 1 תתוקן כך:                                                                                |תיקון פקודת        |
|(1) במקום פרט (12) לסעיף 96 יבוא פרט זה:                                                                    |העיריות            |
|"(12) (א) אשר לחזירים: להתקין סדרים בדבר גידולם או לאסור את גידולם ;                                        |                   |
|האיסור יוכל להיינתן גם בהתחשב בטעמים דתיים או לאומיים ;                                                     |                   |
|(ב) אשר לשאר בעלי-חיים: להתקין סדרים בדבר גידולם באופן שלא                                                  |                   |
|יהוו בגידולם מפגע או קלקלה לבריאות ולהסדיר או למנוע את רעייתם או                                            |                   |
|מעברם."                                                                                                     |                   |
|(2) בפרט (8) לסעיף 98 אחרי המלה "אחר" יבוא פסיק ואחריו המלים: "וכן לאסור                                    |                   |
|מכירת בשר חזיר או כל מוצר מבשר זה ; איסור מכירת בשר חזיר או כל מוצר כאמור יוכל                              |                   |
|להינתן גם בהתחשב בטעמים דתיים או לאומיים."                                                                  |                   |
|דברי הסבר                                                                                                   |                   |
|הצעת חוק זו באה לתקן את פקודת העיריות, 1934, בנוגע לסמכויות העיריות להגבלת                                  |                   |
|גידול החזיר ומכירתו.                                                                                        |                   |
|גידול החזירים והפצתם מהווה, כדברי שר המשפטים ("דברי הכנסת" מושב ד' עמ'                                      |                   |
|456), "דאגה קשה לחלק ניכר של הציבור". הרצון למנוע גידולם והפצתם בא לידי ביטוי                               |                   |
|על ידי חקיקת חוקי עזר במספר ניכר של רשויות מקומיות במדינה. שר הפנים סירב לאשר                               |                   |
|את רובם הגדול של חוקי עזר אלה שהוגשו על ידי הרשויות המקומיות "מאחר שכללו                                    |                   |
|הוראות, שחרגו מסמכויות ؀ࠂࠎࠐࠒהרשויות המקומיות" ("דברי הכנסת" מושב רביעי, עמ' 466).                           |                   |
|ואף לגבי חוק עזר של תל אביב, אשר אושר על ידו, הובע החשש שהוא לא יעמוד במבחן                                 |                   |
|הבקורת המשפטית (עיין דברי שר המשפטים ב"דברי הכנסת", מושב רביעי, עמ' 7-456),                                 |                   |
|הצעת חוק זו באה לתקן את החוק המנדטורי ולתת סמכות לעיריות לאסור גידול                                        |                   |
|חזירים ומכירתם, גם מטעמים דתיים או לאומיים, כדי שאי אפשר יהיה לערער על כך                                   |                   |
|מבחינה משפטית.                                                                                              |                   |

חבר הכנסת : ק. כתנא
