חוק "נצר-סרני", תשט"ו-1955

|1, הישוב "נצר" ייקרא מעתה על מפת ארץ ישראל ; נצר-סרני.                                                      |קביעת שם        |
|                                                                                                            |לישוב           |
|דברי הסבר                                                                                                   |                |
|חברי קיבוץ נצר (בוכנוולד) החליטו לשאת את שמו של השליח-הצנחן חייט אנצו                                       |                |
|סרני' אשר נרצח במחנה ההסגר בדבאו ב-18.11.44, ובחרו לקרוא לישובם; נצר-סרני.                                  |                |
|ועדת השמות שעל יד משרד ראש הממשלה, מתוך התנגדות עקרונית לצליל של                                            |                |
|שם זר על מפת הארץ, לא אישרה את החלטת חברי נצר והחליטה על השם ; "נצר-חיים".                                  |                |
|מציעי החוק "נצר-סרני" סבורים, כי מרובים הישובים הנושאים את השם "חיים"                                       |                |
|וביניהם ישובים על שמם של חיים נחמן ביאליק, חיים וייצמן, חיים ארלוזורוב וחיים                                |                |
|שטורמן (מעוז-חיים, גבעת חיים, כפר-חיים, קרית חיים וכו' וכו'), ומתוך כך אין בטבע                             |                |
|השם שקבעה הועדה הנ"ל משום מתן זכרון של ממש לצנחן, אשר מסר את נפשו על                                        |                |
|אהבת ישראל וכבוד האדם בבית המוות הנאצי במלחמת העולם השניה. צורה זו של שם                                    |                |
|אינה מעלה כל גוון חי לדיוקן האישי של אנצו סרני וייחוד שליחותו בלב האומה וילדיה.                             |                |
|ונמצא אנצו סרני סמוי ללא בת-קול בשם של ישוב במרכז הארץ, ואינו זוכה להשארת                                   |                |
|הנפש על מפת ישראל.                                                                                          |                |
|לנימוקים העקרוניים הנ"ל מצטרף טעם אנושי של חברות קרובה לאיש' אשר                                            |                |
|במעגל גורלו באסון "מעגן" נלקח ממנו בנו יחידו' היחיד אשר נשא  את שם המשפחה                                   |                |
|היהודית העתיקה מאיטליה - דניאל סרני,                                                                        |                |
|ומרובים הם בין אזרחי ישראל הסבורים, כי אין הצליל "סרני" פוגם באוזן העברית'                                  |                |
|וכי שורש היסטורי לו באחת התנועות המשיחיות בישראל.                                                           |                |
|ולו גם החלטנו למחוק כל צליל שם זר ؀ࠂࠌࠎלבל ייזכר על מפת הארץ (כגון כפר מא-                                   |                |
|סאריק, בלום, רופין, ברנדים, סולד, תל-מונד וכו' וכר וכפר טרומן, הר. הרצל בבירת                               |                |
|ישראל - שמות אשר מקיימים אותם גם לאחר קום המדינה)' הרי גילוי קידוש השם                                      |                |
|בימינו ראוי להנחלת מורשת-שם על פני מפת ארץ ישראל - במעשה חקיקה מיוחד.                                       |                |
|מתוך כל האמור לעיל, משוכנעים מציעי החוק, כי על הבית לאשר את רצונם של                                        |                |
|חברי קיבוץ נצר ולקיים את השם "נצר-סרני" על מפת הארץ, אשר ממנה' בשליחותה'                                    |                |
|ומתוך בחירה שבלב הלך החלוץ הראשון מאיטליה סרני בשביל-העקידה עד סופו בדכאו.                                  |                |
