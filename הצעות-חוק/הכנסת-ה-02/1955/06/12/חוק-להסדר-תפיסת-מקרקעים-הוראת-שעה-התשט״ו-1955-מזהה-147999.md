חוק להסדר תפיסת מקרקעים (הוראת שעה), תשט"ו-1955,

|1, בחוק זה תהא לכל מונח המשמעות שיש לו בחוק להסדר תפיסת מקרקעים בשעת                                        |פרשנות         |
|חירום, תש"י-1949  1(להלן - החוק העיקרי).                                                                    |               |
|2, מקרקעים שערב תחילתו של חוק זה היו תפוסים, על פי צו תפיסת מקרקעים והרשות                                  |די! מקרקעים    |
|, המוסמכת החזיקה בהם באמצעות צבא-הגנה לישראל או העידה עליהם בכתב שהם דרושים                                 |תפוסים לצרכי   |
|להגנת המדינה - מותר להחזיק בהם עד ט"ו באב תשי"ח (1 באוגוסט 1958), אף אם                                     |בטחת           |
|התקופה האמורה בסעיף 6 (א) לחוק העיקרי תמה לפני כן.                                                          |               |
|דברי הסבר                                                                                                   |               |
|לפי סעיף 6 לחוק להסדר תפיסת מקרקעים בשעת-חירום, תש"י-1949, כפי שתוקן                                        |               |
|על ידי חוק מס' 61 משנת תשי"ב, מקרקעים שנתפסו על פי צו תפיסת מקרקעים לא                                      |               |
|יוחזקו, בין בתוקף צו אחד ובין בתוקף צווים אחדים, תקופה העולה על שלוש שנים, ואם                              |               |
|נתפסו המקרקעים לפני ה-1 באוגוסט 1952 - תקופה העולה על שש שנים.                                              |               |
|כל השטח השייך לבעלים פרטיים והמוחזק לפי חוק זה- על ידי מוסדות הממשלה                                        |               |
|ומוסדות אחרים הוא כ-89,300 דונם המתחלק בין משרד הבטהון, בעיקר הצבא; מוסדות                                  |               |
|. ממשלתיים אחרים, בעיקר משרד הדואר; ובין מוסדות לאומיים ומוניציפליים, בעיקר                                 |               |
|לצרכי מעבדות. נוסף לכך תפוסים؀ࠂࠌࠎ לפי חוק זה על ידי מוסדות הממשלה כ-580 חדרים                               |               |
|בעיקר בירושלים, תל אביב וחיפה.                                                                              |               |
|מקרקעין שאינם מוחזקים לשם הגנה על המדינה, ושהסמכות להחזיקם עומדת לפקוע                                      |               |
|לפי סע יף 6 האמור, מן הראוי שהמדינה תשחרר אותם או תרכוש אותם מאת הבעלים על פי                               |               |
|הסכם או בדרך שימוש בפקודת הקרקעות (רכישה לצרכי ציבור); 1943. אך לגבי מקרקעים                                |               |
|הדרושים להגנת המדינה אי אפשר ללכת בדרך המוצעת, כי השטח התפוס למטרה זו שאפשר                                 |               |
|יהיה לשחררו בזמן הקרוב ביותר מגיע סך הכל ל-3,800 דונם, וביטול צווי התפיסה לגבי                              |               |
|יתרת השטח ידרוש שנים אחדות להכנת התחליפים או האמצעים הכספיים לרכישתו. לכן                                   |               |
|בא החוק המוצע. לתת אפשרות לממשלה להחזיק במקרקעים התפוסים לצרכי בטחון, ובהם                                  |               |
|בלבד, תקופה נוספת עד לט"ו באב תשי"ח (1 באוגוסט 1958).                                                       |               |

1 ס"ח 27 תש"י עמ' 1.
