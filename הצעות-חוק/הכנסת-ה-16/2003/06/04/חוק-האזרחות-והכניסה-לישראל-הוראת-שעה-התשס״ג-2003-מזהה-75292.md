|"תושב אזור" - לרבות מי שמתגורר באזור אף שאינו רשום במרשם האוכלוסין של האזור,                            |                    |
|ולמעט תושב יישוב ישראלי באזור.                                                                          |                    |
|2. בתקופת תוקפו של חוק זה, על אף האמור בכל דין לרבות סעיף 7 לחוק האזרחות, שר                            |הגבלת אזרחות        |
|הפנים לא יעניק לתושב אזור אזרחות לפי חוק האזרחות ולא ייתן לו רישיון לישיבה בישראל                       |וישיבה בישראל       |
|לפי חוק הכניסה לישראל, ומפקד האזור לא ייתן לתושב כאמור היתר לשהייה בישראל לפי                           |                    |

|בישראל על ידי מפקד האזור ובהמשך ניחן על ידי שר                  |יהודה והשומרון וחבל עזה (להלן -                             |

|לתקופות קצובות של שנה כל אחת, כאשר בכל אחד                      |1952 (להלן - חוק האזרחות), הקובע לאמור:                     |
|משלבי ההליך נעשית בחינה מחדש של המשך קיומו של                   |"התאזרחות של בעל ואישה                                      |

|ביטחונית למתן מעמד בישראל לתושב האזור.                          |מהם ביקש להתאזרח ונתקיימו בו התנאים שבסעיף 5(א)             |

|התאבדות בשטח ישראל, מסתמנת מעורבות גוברת                        |שבסעיף 5(א)."                                               |
|והולכת בעימות זה של פלסטינים שהם במקור תושבי                    |גם רישיונות לישיבת קבע בישראל ניתנים כיום                   |
|האזור, אשר נושאים תעודות זהות ישראליות בעקבות                   |לתושבי האזור שבני זוגם הם תושבי קבע בישראל,                 |
|הליכי איחוד משפחות עם בעלי אזרחות או תושבות                     |לצורך איחוד משפחות, וזאת על פי סמכותו הכללית של             |
|ישראלית, תוך ניצול מעמדם בישראל המאפשר להם                      |שר הפנים, לפי סעיף 2 לחוק הכניסה לישראל,                    |
|תנועה חופשית בין שטחי הרשות לישראל.                             |התשי"ב-1952 (להלן - חוק הכניסה לישראל), לתת                 |
|לפיכך, ובהתאם להחלטת הממשלה מס' ג181 מיום                       |אשרה ורישיון לישיבת קבע בישראל.                             |
|12.5.2002 (להלן - החלטת הממשלה), מוצע להגביל את                 |גורם נוסף המוסמך לתת היתר לשהייה בישראל                     |
|האפשרות להעניק לתושבי האזור אזרחות לפי חוק                      |הוא מפקד כוחות צה"ל באזור, מכוח תחיקת הביטחון               |

|סייגים        |3. על אף הוראות סעיף 2 -                                                                                |
|              |(1) רשאי שר הפנים או מפקד האזור, לפי הענין, לתת לתושב אזור רישיון לישיבה                                |
|              |בישראל או היתר לשהייה בישראל, למטרת ؀ࠂࠆࠈࠌࠒࠔ࠘עבודה או לשם טיפול רפואי, לתקופה                            |
|              |קצובה, וכן למטרה זמנית אחרת - לתקופה מצטברת שלא תעלה על שלושה                                           |
|              |חודשים;                                                                                                 |
|              |(2) רשאי שר הפנים להעניק אזרחות או לתת רישיון לישיבה בישראל, לתושב אזור,                                |
|              |אם שוכנע  כי הוא מזדהה עם, מדינת ישראל ויעדיה וכי הוא או בן משפחתו פעלו                                 |
|              |פעולה של ממש לקידום הביטחון, הכלכלה או ענין חשוב אחר של המדינה, או                                      |
|              |שהענקת האזרחות או מתן הרישיון לישיבה בישראל, הם מענינה המיוחד של                                        |
|              |המדינה; בפסקה זו, "בן משפחה" - בן זוג, הורה, ילד.                                                       |
|הוראות מעבר   |4. על אף הוראות חוק זה -                                                                                |
|              |(1) רשאי שר הפנים או, מפקד האזור, לפי הענין, להאריך את תוקפו של רישיון                                  |
|              |? לישיבה בישראל או של היתר לשהייה בישראל, שהיו בידי תושב אזור ערב תחילתו                                |
|              |של חוק זה;                                                                                              |
|              |(2) רשאי מפקד האזור לתת היתר לשהייה זמנית בישראל לתושב אזור שהגיש                                       |
|              |בקשה להתאזרחות לפי חוק האזרחות או בקשה לרישיון לישיבה בישראל לפי חוק                                    |
|              |הכניסה לישראל, לפני יום א' בסיון התשס''ב (12 במאי 2002) ואשר ביום תחילתו של                             |
|              |חוק זה טרם ניתנה החלטה בענינו, ובלבד שלא תוענק לתושב באמור, לפי הוראות                                  |
|              |פסקה זו, אזרחות לפי חוק האזרחות ולא יינתן לו רישיון לישיבת ארעי או לישיבת                               |
|              |קבע, לפי חוק הכניסה לישראל.                                                                             |
|תוקף          |5. חוק זה יעמוד בתוקפו עד תום שנה מיום פרסומו, ואולם רשאית הממשלה, באישור                               |
|              |ועדת הפנים ואיכות הסביבה של הכנסת, להאריך בצו את תוקפו, מעת לעת, לתקופה שלא                             |
|              |תעלה בכל פעם על שנה אחת.                                                                                |
