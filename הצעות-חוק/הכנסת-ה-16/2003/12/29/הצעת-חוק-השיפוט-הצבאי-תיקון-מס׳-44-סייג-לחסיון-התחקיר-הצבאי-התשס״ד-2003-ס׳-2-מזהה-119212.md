|(1) בפסקה (2), בסופה יבוא:                                                                           |                    |
|"הוראות פסקה זו לא יחולו על חומר ארכיוני שזכות העיון בו הוגבלה בחוק                                  |                    |
|הארכיונים, התשט"ו-21955, או לפיו, אך התקיימו כל התנאים לחשיפתו לעיון                                 |                    |
|הקהל אשר נקבע לפי החוק האמור."                                                                       |                    |
|(2) בפסקה (5) -                                                                                      |                    |
|(א) אחרי המילים "לאדם הנוגע בדבר" יבוא "ואם יש באירוע ענין ציבורי                                    |                    |
|רשאי הוא לאשר פרסום סיכום ממצאי התחקיר ברבים";                                                       |                    |
|(ב) בסיפה, אחרי המילים "ואולם לא יועבר" יבוא "או יפורסם" ובמקום                                      |                    |
|המילים "העברתו תפגע" יבוא "העברתו או פרסומו יפגעו".                                                  |                    |

|דברי הסבר                                                                                                               |
|התשכ"ז-1966 (ק"ת התשכ"ז, עמ' 468), המאפשרות                 |סעיף 539א לחוק השיפוט הצבאי, התשט"ו-1955                   |
|חשיפת חומר מוגבל של צבא הגנה לישראל לאחר                    |(להלן - החש"צ) אשר הוסף לחש"צ בתיקון מס' 33 (ס"ח           |
|שחלפו 50 שנים והחומר נבדק בהיבטי ביטחון שדה                 |התשנ"ח, עמ' 6), קובע את חיסיונם של תחקירים צבאיים          |
|("סריקה"), וזאת כדי לאפשר גם למגזר האזרחי להפיק             |הקשורים לאימונים ולפעילות מבצעית; מטרת החיסיון             |
|לקחים מתחקירים צבאיים וללמוד מהם.                           |לשרת את תרבות התחקיר והפקת הלקחים בצה"ל כך                 |
|(ב) התרת פרסום המידע העולה מתחקיר צבאי                      |שחיילים יוכלו למסור באופן חופשי למפקדיהם מידע              |
|במקרה שבו הרמטכ"ל רואה חשיבות ציבורית בפרסום                |מלא בדבר שגיאות וטעויות שביצעו, הם וחבריהם,                |
|הפקת הלקחים מאירוע שיש בו ענין ציבורי, וזאת כדי             |במהלך אימונים ופעילות מבצעית, בלא חשש שדבריהם              |
|למנוע פגיעה באמון הציבור במערכת הצבאית                      |יהיו להם לרועץ במסגרת הליכים פליליים בהמשך.                |
|וביכולתה לחקור אירועים שהתרחשו 'בקרבה, ולהפיק               |בסעיף 539א(ב) מפורטים כמה מקרים שבהם ניתן                  |
|את הלקחים המתבקשים למניעת הישנות מקרים מעין                 |להעביר את חומר התחקיר או את סיכום ממצאיו,                  |
|אלה בעתיד; במקרה כזה מוצע, כי הרמטכ"ל יוכל לאשר             |בהתאם לגורם שלו נמסר המידע.                                |
|רק פרסום מוגבל בהיקפו שיכלול את סיכום ממצאי                 |התיקון המוצע מבקש להתיר באופן מפורש פרסום                  |
|התחקיר ולא את שאר חומר התחקיר הכולל למשל                    |המידע העולה מן התחקיר בשני מקרים נוספים לאלה               |
|דברים שהושמעו בתחקיר ופרוטוקול ؀ࠂࠈהתחקיר.                   |המפורטים בסעיף 539א(ב) הקיים:                              |
