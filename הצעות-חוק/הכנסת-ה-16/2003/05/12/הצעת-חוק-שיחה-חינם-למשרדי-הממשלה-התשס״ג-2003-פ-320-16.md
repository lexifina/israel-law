הצעת חוק שיחה חינם למשרדי הממשלה, התשס”ה - 2005

|קו טלפון חינם   |1.     |לכל משרד ממשלתי יהיה קו טלפון להתקשרות חינם (להלן – קו טלפון חינם); מספרו של הקו האמור יפורסם מידי |
|                |       |תקופה שתקבע על ידי המשרד בשני עיתונים יומיים וכן בכל פרסום רשמי של המשרד שמיועד לציבור.            |
|                |       |                                                                                                   |
|מידע לציבור     |       |בקו טלפון חינם יינתן מידע לציבור על המשרד ועל אופן הגשת בקשה או פניה לבעלי תפקידים באותו משרד.     |
|                |2.     |                                                                                                   |
|                |       |                                                                                                   |
|ביצוע           |3.     |שר אחראי לביצוע הוראות חוק זה לגבי המשרד שבתחום אחריותו.                                           |

דברי - הסבר

מוצע, כי לכל משרד ממשלתי יהיה שירות של שיחה חינם (800-1) כך שגם אזרחים מעוטי יכולת יוכלו להתקשר מבלי לחשוש שהזמן הרב בו הם ממתינים ועד אשר הם מוצאים את מבוקשם יעלה להם כסף רב.

השירות יכיל גם מידע אינפורמטיבי על המשרד ועל היחידות השונות ואופן הפניה אליהן.

הצעת חוק זהה הונחה על שולחן הכנסת השש-עשרה על ידי חבר הכנסת אמנון כהן ומספרה פ/320.
