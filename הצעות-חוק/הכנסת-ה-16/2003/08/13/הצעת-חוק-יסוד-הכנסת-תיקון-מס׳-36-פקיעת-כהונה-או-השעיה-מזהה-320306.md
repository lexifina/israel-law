|מתפרסמת בזה הצעת חוק מטעם הממשלה;                                                                                            |
|הצעת חוק-יסוד: הכנסת (תיקון מס' 36) (פקיעת בהונה או השעיה)                                                                   |
|1. בחוק-יסוד: הכנסתי (להלן - חוק היסוד), בסעיף 42, במקום "לענין זה" יבוא "לענין                         |תיקון סעיף 42        |
|סעיף זה וסעיפים 42א ו-42ב".                                                                             |                     |
|2. בסעיף 42א לחוק היסוד -                                                                               |תיקון סעיף 42א       |
|(1) אחרי סעיף קטן (א) יבוא:                                                                             |                     |
|"(או) הורשע חבר הכנסת בפסק דין סופי בעבירה פלילית וקבע בית המשפט,                                       |                     |
|ביזמתו או לבקשת היועץ המשפטי לממשלה, שהוא היה למועמד לכנסת או                                           |                     |
|לחבר הכנסת כתוצאה מהעבירה, או אישר בית המשפט קביעה כאמור של בית                                         |                     |
|משפט קמא, יראו את קביעת בית המשפט או את אישורו כקביעה שיש עם                                            |                     |
|העבירה קלון לפי סעיף קטן (א).";                                                                         |                     |
|(2) בסעיף קטן (ב), בכל מקום, במקום "סעיף קטן (א)" יבוא "סעיפים קטנים (א)                                |                     |
|ו-(או)".                                                                                                |                     |
|3. בסעיף 42ב לחוק היסוד -                                                                               |תיקון סעיף 42ב       |
|(1) אחרי סעיף קטן (א) יבוא-.                                                                            |                     |
|"(א1) חבר הכנסת שהורשע בעבירה פלילית וקבע בית המשפט, ביזמתו או                                          |                     |
|לבקשת היועץ המשפטי לממשלה, שהוא היה למועמד לכנסת או לחבר הכנסת                                          |                     |
|כתוצאה מהעבירה, תושעה חברותו בכנסת מיום מתן פסק הדין למשך הזמן                                          |                     |
|שפסק הדין אינו סופי.";                                                                                  |                     |
|(2) בסעיף קטן (ב1), במקום "(א) או (ב)" יבוא "(א), (או) או (ב)".                                         |                     |

|דברי הסבר                                                                                                                |
|או לחבר הכנסת בתוצאה מעבירה פלילית שהוא הורשע                |כללי הצעת חוק זו מטרתה למנוע מחבר הכנסת                    |
|בביצועה, יראו אותה כקביעה שיש עם העבירה קלון                 |שהיה למועמד לכנסת או לחבר הכנסת                            |
|לפי סעיף 42א(א) לחוק היסוד, אף בלי שבית המשפט                |כתוצאה מביצוע עבירה פלילית לצאת נשכר מדבר                  |
|יידרש בנפרד לשאלת הקלון.                                     |העבירה.                                                    |
|סעיף 3 סעיף 42ב לחוק היסוד שענינו השעיה,                     |סעיף 2 סעיף 42א לחוק-יסוד: הכנסת (להלן - חוק               |
|קובע בסעיף קטן (א) כי השעיית חבר                             |היסוד) שענינו חבר הכנסת שהורשע, קובע                       |
|הכנסת שהורשע בעבירה ؀ࠂࠈפלילית למשך הזמן שפסק                 |בסעיף קטן (א) כי אם הורשע חבר הכנסת בעבירה                 |
|הדין אינו סופי נתונה לשיקול דעתה. של ועדת                    |פלילית ובית המשפט קבע שיש עם העבירה קלון, תיפסק            |
|הכנסת.                                                       |חברותו בכנסת ביום שפסק הדין נעשה סופי.                     |
|מוצע להוסיף הוראה בסעיף 42ב לחוק היסוד,                      |הואיל וחברות בכנסת או ברשימת מועמדים                       |
|ולקבוע כי במקרים שבהם קבע בית המשפט כי חבר                   |לכנסת כתוצאה מביצוע עבירה פלילית היא, מטבע                 |
|הכנסת שהורשע כאמור היה למועמד לכנסת או לחבר                  |הדברים, עבירה שיש עמה קלון לגבי חבר הכנסת, מוצע            |
|הכנסת כתוצאה מהעבירה הפלילית, תושעה חברותו                   |להוסיף הוראה בסעיף 42א לחוק היסוד ולקבוע כי                |
|בכנסת מיום מתן פסק הדין למשך הזמן שפסק הדין אינו             |קביעת בית המשפט שחבר הכנסת היה למועמד לכנסת                |
|סופי.                                                        |                                                           |
