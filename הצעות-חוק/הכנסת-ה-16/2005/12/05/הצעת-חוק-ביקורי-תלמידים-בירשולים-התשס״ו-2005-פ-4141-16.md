הצעת חוק ביקורי תלמידים בירושלים, התשס"ו-2005

|                |1.     |במהלך שהותו במערכת החינוך החובה יבקר כל תלמיד בירושלים, בירת ישראל; לענין זה, "תלמיד" - ילד או נער |
|                |       |בגיל לימוד חובה כמשמעותם בחוק לימוד חובה, התש"ט-1949[1].                                           |

|                |       |אופן הביקור ויקבע הוראות באשר לגיל התלמידים המבקרים בכל אתר, וכן הוראות באשר למוסדות חינוך במגזרי  |
|                |       |המיעוטים.                                                                                          |

דברי - הסבר
מערכת החינוך אינה מחייבת כיום את בתי הספר להגיע לביקורים  בירושלים בירת ישראל. מנתוני צה"ל עולה כי קרוב לשליש מהחיילים לא ביקרו בירושלים טרם גיוסם. לבני נוער  רבים אין את היכולת והאפשרות להגיע לירושלים שלא במסגרת המאורגנת של מערכת החינוך. ראוי שהמדינה תקבע, במסגרת עיצוב דור העתיד, חובת ביקורי תלמידים בירושלים, כאשר הביקורים יכללו, בין היתר, את האתרים המוגדרים בהצעה שהם הכותל המערבי, מוזיאון יד ושם ומוזיאון הרצל שהינם בעלי משמעות לעיצוב זהותו היהודית והציונית של הנוער בישראל.
