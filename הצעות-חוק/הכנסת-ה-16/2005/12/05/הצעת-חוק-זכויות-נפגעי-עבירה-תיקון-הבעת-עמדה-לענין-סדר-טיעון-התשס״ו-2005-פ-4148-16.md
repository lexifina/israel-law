|תיקון סעיף 17   |1.     |בחוק זכויות נפגעי עבירה, התשס"א-2001[1], בסעיף 17  -                                               |
|                |       |(1)    |אחרי "לפני התובע" יבוא "או בכתב לפני בית משפט";                                            |
|                |       |(2)    |האמור בו יסומן "(א)" ואחריו יבוא:                                                          |
|                |       |       |"(ב)   |הביע נפגע עבירת מין או אלימות חמורה כאמור בסעיף קטן (א), את עמדתו בפני תובע, זכאי  |
|                |       |       |       |הוא שהתובע יביא את עמדתו לפני בית המשפט.".                                         |

דברי - הסבר

מעמדו של הנפגע מעבירת מין או אלימות בהסדר טיעון שנערך בין התביעה לנאשם מעוגן היום בסעיף 17 לחוק זכויות נפגעי עבירה אשר קובע כי נפגע עבירת מין או אלימות חמורה שקיבל הודעה לפי סעיף 8(ג)(2) על האפשרות שהתביעה תגיע להסדר טיעון עם הנאשם, זכאי שתינתן לו הזדמנות להביע את עמדתו בענין זה לפני התובע, לפני קבלת החלטה בענין. ביסודה, מבקשה הוראת חוק זו להקטין את החשש מפגיעה נוספת בנפגע העבירה ומהנזק הנפשי העלול להיגרם לו מעצם עריכת הסדר הטיעון. הזכות העומדת לנפגע עבירות מין או אלימות להביע עמדתו בפני התובע בטרם קבלת ההחלטה בעניין הסדר הטיעון, אף מוסיפה מימד חשוב לשיקולי התביעה בהבטחת האינטרס הציבורי בעת עריכת הסדרי טיעון, ומחזקת אף היא את מעמדם.

מוצע לאפשר לנפגע עבירת מין או אלימות חמורה להביע את עמדתו בנוגע לאפשרות שהתביעה תגיע להסדר טיעון עם הנאשם גם בפני בית המשפט הדן בעניינו של הנאשם. בדרך זו, יתאפשר לנפגע עבירת המין או האלימות החמורה להביע דעתו בנושא הסדר הטיעון בצורה בלתי אמצעית וישירה בפני בית המשפט אשר צפוי להחליט בסופו של יום האם לאשר את הסדר הטיעון עם הנאשם – אם לאו.

עוד מוצע לקבוע כי מקום שבו בחר נפגע עבירת המין או האלימות החמורה להביע דעתו בפני התובע, זכאי הוא שהתובע יביא את עמדתו בענין זה בפני בית המשפט. בכך, מובטח כי בפני בית המשפט תעמוד עמדת נפגע העבירה בענין הסדר הטיעון עם הנאשם, אפילו מקום שבו עמדת נפגע העבירה לא התקבלה על ידי התובע.
