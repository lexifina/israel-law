|תיקון סעיף 11  |1.     |בחוק הרשויות המקומיות (מימון בחירות), התשנ"ג-1993  (להלן - החוק העיקרי), בסעיף 11(א), ברישה, במקום "שתוך שבעה ימים  |
|               |       |לאחר היום הקובע" יבוא  "שבתוך התקופה שמהיום השביעי שאחרי היום הקובע ועד היום החמישי שאחרי יום הבחירות".             |
|תיקון סעיף     |2.     |בסעיף 12(א)(1) לחוק העיקרי, במקום "לא יאוחר מהיום ה-21 שלפני יום הבחירות" יבוא "בתקופה  שמהיום השביעי שאחרי היום    |
|12א            |       |הקובע ועד היום החמישי שאחרי יום הבחירות".                                                                           |
|תיקון סעיף 12א |3.     |בסעיף 12א(א) לחוק העיקרי, במקום "לא יאוחר מהיום ה-21 שלפני יום הבחירות" יבוא "בתקופה שמהיום השביעי שאחרי היום הקובע |
|               |       |ועד היום החמישי שאחרי יום הבחירות ".                                                                                |
|החלפת סעיף 29  |4.     |במקום סעיף 29 לחוק העיקרי יבוא:                                                                                     |
|                        |"המצאת הודעות    |29.     |השר ימציא במרוכז למבקר המדינה, לא יאוחר מהיום                                             |
|                        |                 |        |ה-10 שאחרי יום הבחירות, העתקים מההודעות שקיבל לפי סעיפים 11(א), 12(א), 12א(א) ו-26(ג), וכן|
|                        |                 |        |רשימה מפורטת של סכומי המקדמות ששולמו לפי סעיפים 10 ו-26(ב) לסיעות אם, לסיעות, לרשימות,    |
|                        |                 |        |למועמדים לראש מועצה אזורית ולמועמדים בבחירות מיוחדות לראש רשות."                          |
|הוראת שעה     |5.      |הוראות הסעיפים 1, 2 ו-3 לחוק זה, יחולו על כל סיעה ורשימה שמסרו הודעות לשר הפנים, בתוך המועדים הנקובים בסעיפים        |
|              |        |האמורים, בבחירות שהתקיימו בשנת התשס"ה.                                                                               |

דברי הסבר

|1.    |על פי הוראת החוק העיקרי יש להגיש בקשות מימון לפני יום הבחירות. סיעה הרוצה לקבל מימון חייבת להגיש את בקשתה לשר, בצירוף  |
|      |כל המסמכים הנדרשים, 59 יום לפני יום הבחירות ואילו רשימה ומועמד לראש מועצה אזורית חייבים להגיש את הבקשה 21 יום לפני יום |
|      |הבחירות.                                                                                                               |
|      |אין כל סיבה שלא לאפשר להגיש בקשות למימון הוצאות הבחירות גם לאחר יום הבחירות כאשר תוצאות הבחירות כבר ידועות למגיש הבקשה |
|      |והוא יכול לכלכל מעשיו בהתאם לכך;  זאת בכפוף לכך שמבקש המימון הקפיד לנהל בתקופת הבחירות, את חשבון הוצאותיו והכנסותיו    |
|      |בקשר לבחירות בהתאם להנחיות מבקר המדינה וההוצאות וההכנסות הללו היו בגבולות המותרים.                                     |
|      |מוצע לפיכך לקבוע כי ניתן יהיה להגיש בקשות  למימון בתקופה שבין היום השביעי אחרי היום הקובע (59 יום לפני יום הבחירות) עד |
|      |היום החמישי שאחרי יום הבחירות.                                                                                         |
|2.    |מוצע כי בהתאם להוראות שלעיל – ידחה גם המועד להעברת החומר משר הפנים למבקר המדינה.                                       |
|3.    |מוצע כי ההוראות האמורות יחולו על כל סיעה ורשימה שאיחרה בהגשת בקשה למימון, בבחירות שהתקיימו בשנת תשס"ה, אולם הבקשות     |
|      |הוגשו לפני תום 5 ימים מיום הבחירות באותה רשות.                                                                         |
