|סוב. (א) בסעיף זה -                                                                 |גישור                  |
|"גישור" - הליך שבו נועד מגשר עם בעלי הרין, כדי להביאם לידי הסכמה                    |                       |
|ליישוב הסכסוך, בלי שיש בידו סמכות להכריע בו;                                        |                       |
|"מגשר" - מי שתפקידו לסייע בידי בעלי הרין להגיע להסדר של גישור                       |                       |
|בדרך של ניהול משא ומתן חופשי ואין בידו הסמכות להכריע                                |                       |
|בסכסוך;                                                                             |                       |
|"הסדר גישור" - הסכם בין בעלי הדין על יישוב סכסוך ביניהם שהושג                       |                       |
|בסיומו של הליך גישור.                                                               |                       |
|(ב) בית דין רבני הדן בענין שבסמכותו, רשאי, בהסכמת בעלי הרין,                        |                       |
|להעבירו לגישור.                                                                     |                       |
|(ג) בהליך הגישור רשאי מגשר להיוועד עם בעלי הדין, יחד או                             |                       |
|לחור, ועם כל מי שקשור לסכסוך; ורשאי הוא להיפגש עם בעל דין,                          |                       |
|בהסכמתו, בלי עורך דינו.                                                             |                       |
|(ר) דברים ؀ࠂࠆࠈࠌࠒשנמסרו במסגרת הליך גישור לא ישמשו ראיה בהליך                        |                       |
|בפני בית דין רבני ובהליך משפטי אחר.                                                 |                       |
|(ה) העביר בית דין רבני ענין לגישור, יעכב את ההליכים שלפניו                          |                       |
|לתקופה שיקבע, ורשאי הוא להאריך את התקופה בהסכמת בעלי הדין.                          |                       |
|(ו) לא הגיעו בעלי הרין להסדר גישור עד תום התקופה, כאמור                             |                       |
|בסעיף קטן (ה), יחודשו ההליכים בבית הרין הרבני; אולם, רשאי בית הרין,                 |                       |
|על פי בקשה של המגשר או של בעל דין, לחדשם בבל עת לפני תום                            |                       |
|התקופה האמורה.                                                                      |                       |
|(ז) הגיעו בעלי הדין להסדר גישור, יודיע על כך המגשר לבית הדין                        |                       |
|הרבני ובית הדין יהיה רשאי ליתן להסדר תוקף של פסק דין.                               |                       |
