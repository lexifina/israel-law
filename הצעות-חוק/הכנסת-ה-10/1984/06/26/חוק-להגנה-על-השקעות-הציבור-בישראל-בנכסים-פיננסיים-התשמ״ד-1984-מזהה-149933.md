|חוק להגנה על השקעות הציבור בישראל בנכסים פיננסיים, התשמ"ד-1984                                                              |

|הגדרה                |1. בחוק זה, "השקעות ציבור" - הנכסים הפיננסיים המנויים בתוספת.                                                  |
|הגנה על              |2. (א) הממשלה לא תפקיע השקעות ציבור שנוצרו לפני תחילתו של חוק זה ולא                                           |
|השקעות ציבור         |תשנה לרעה את התנאים שנקבעו להן לפני תחילתו.                                                                    |

|דברי הסבר                    |

|מטרת החוק המוצע להעניק הגנה נוספת ומיוחדת                         |
|לנכסים הפיננסיים של הציבור בישראל. באמצעות                        |
|הגנה זו יוגבר אמון הציבור במכשירי החסכון ויינתן                   |
|עידוד להמשיך ולהחזיק בהשקעות הקיימות וליצור                       |
|חסכונות חדשים.                                                    |
|לגבי השקעות קיימות, ההגנה הניתנת מתייחסת                          |
|לתנאיהן כפי שהם קיימים ביום תחילת החוק. לגבי                      |
|השקעות שייעשו בעתיד, ההגנה מתייחסת לתנאים כפי                     |
|שיהיו בתוקף במועד שבו ייעשו.                                      |

|לפי המצב המשפטי הקיים רשאית הממשלה מפעם                         |
|לפעם לקבוע תנאים להשקעות, בהתאם למדיניותה                       |
|הכלכלית, אולם אין לשנות לרעה באופן רטרואקטיבי                   |
|תנאים שנקבעו להשקעות אלא בדרך של חקיקה,                         |
|וחקיקה כזו לא נעשתה בעבר. החוק המוצע בא                         |
|להבטיח כי לא יתקבל חוק המשנה לרעה תנאים של                      |
|השקעה לעומת התנאים שהיו קיימים בעת שההשקעה                      |
|בוצעה, אלא ברוב של חברי הכנסת, דהיינו בקולותיהם                 |
|של 61 חברי כנסת לפחות.                                          |

|(ב) הממשלה לא תפקיע השקעות ציבור שייווצרו לאחר תחילתו של חוק זה                                                       |                 |
|ולא תשנה לרעה את תנאיהן, הכל כפי שיהיו קבועים להן בעת שייווצרו, בין שיהיו זהים                                        |                 |
|לתנאים הקבועים להשקעות ציבור מאותו סוג ערב תחילתו של חוק זה ובין שיהיו שונים.                                         |                 |
|(ג) בסעיף זה, "תנאים" -                                                                                               |                 |
|(1) סכום הפרעון או הפדיון;                                                                                            |                 |
|(2) מועד הפרעון או הפדיון ;                                                                                           |                 |
|(3) שיעור הריבית ומועד תשלומה;                                                                                        |                 |
|(4) בסיס ההצמדה ושיעורה;                                                                                              |                 |
|(5) שיעור המס החל;                                                                                                    |                 |
|הכל לפי הענין.                                                                                                        |                 |
|3. אין לשנות חוק זה ואין לגרוע מהתוספת אלא ברוב של חברי הכנסת.                                                        |נוקשות החוק      |
|4. שר האוצר, באישור ועדת הכספים של הכנסת,؀ࠂࠌࠎࠒࠞࠠࠢࠤ רשאי להוסיף על התוספת.                                             |הוספה על         |
|                                                                                                                      |התוספת           |
|תוספת                                                                                                                 |                 |
|(סעיף 1)                                                                                                              |                 |
|1. פקדון שחל עליו צו לפי סעיף 5(א)(2) לחוק עידוד החסכון, הנחות ממס                                                    |                 |
|הכנסה וערבות למילוות, התשט"ז-1950  1(להלן - חוק עידוד החסכון);                                                        |                 |
|2. איגרות חוב סחירות שאינן ניתנות להמרה במניות, שחל עליהן צו לפי סעיף                                                 |                 |
|5(א)(3) לחוק עידוד החסכון;                                                                                            |                 |
|3. איגרות חוב או תעודות מילווה של המדינה, שהוצאו על פי חוק;                                                           |                 |
|4. ניידות ערך שחלה עליהם הודעה בדבר הסדרים לרכישת ניירות ערך בנק-                                                     |                 |
|איים2;                                                                                                                |                 |
|5. פקדון תושב או פקדון תושב (פיצויים) כמשמעותם בהיתר הפיקוח על המטבע,                                                 |                 |
|התשל"ח-1978  3;                                                                                                       |                 |
|6. זכויות עמית בקופת גמל כמשמעותה בסעיף 47 לפקודת מס הכנסה 4 ;                                                        |                 |
|7. פוליסת ביטוח חיים שהוצאה בישראל.                                                                                   |                 |

|דברי הסבר                   |

|חוב סחירות, שלגבי הריבית עליהן ניתן פטור או                   |
|הנחה ממס הכנסה, איגרות חוב ממשלתיות ומילוות                   |
