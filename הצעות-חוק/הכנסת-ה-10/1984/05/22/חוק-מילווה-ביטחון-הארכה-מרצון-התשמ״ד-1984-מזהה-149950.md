|1. בחוק זה -                                                                                                      |הגדרות             |
|י'מילווה בטחון" - מילווה לפי חוק מילווה בטחון, התשל"א-1971  1(להלן - החוק);                                       |                   |
|"מועד הפרעון המקורי" - מועד הפרעון שנקבע לפי החוק;                                                                |                   |
|"מועד הפרעון של המילווה החדש" - ה-1 בחודש החל לאחר תום התקופה הקבועה                                              |                   |
|בסעיפים 2(1) או 2(2), לפי הענין.                                                                                  |                   |
|2. מי ששילם מילווה בטחון ונמנע מלדרוש את פרעונו עד תום התקופה הנקובה                                              |מילווה חדש         |
|להלן ממועד הפרעון המקורי, יראוהו כמי שהמילווה נפרע לו והוא חזר והלווה את                                          |                   |
|הסכומים הצפויים מפרעון תעודת המילווה שבידו (להלן - סכום המילווה החדש) לתקופה                                      |                   |
|כאמור ויראו את תעודת המילווה שבידו כאילו ניתנה בשל המילווה החדש:                                                  |                   |
|(1) מילווה שמועד פרעונו המקורי חל בין 1 באפריל 1984 לבין 1                                                        |                   |
|בספטמבר 1984 - שלוש שנים;                                                                                         |                   |
|(2) מילווה שמועד פרעונו- המקורי חל בין 1 באוקטובר 1984 לבין 1                                                     |                   |
|במרס 1985 -שש שנים.                                                                                               |                   |
|3. (א) סכום המילווה החדש ישא ריבית בשיעור 4% לשנה מ-1 באפריל 1984                                                 |ריבית              |
|עד מועד הפרעון של המילווה החדש.                                                                                   |                   |
|(ב) הריבית תהיה פטורה ממס הכנסה-                                                                                  |                   |
|4. (א) סכום המילווה החדש והריבית עליו יהיו צמודים למדד המחירים לצרכן;                                             |הצמדה למדד         |
|התברר בעת פרעונו של המילווה החדש כי המדד החדש עולה על המדד היסודי, תיפרע                                          |                   |
|קרן המילווה החדש והריבית עליו כשהן מוגדלות בשיעור עליית המדד החדש לעומת                                           |                   |
|המדד היסודי.                                                                                                      |                   |
