|1. אחרי סעיף 55 לחוק ניירות ערך, התשכ"ח-1968  1(להלן - החוק העיקרי), יבוא:                                        |הוספת סעיפים         |
|                                                                                                                  |55א ו-55ב            |
|55א. (א) שר האוצר, בהתייעצות עם הרשות ובאישור ועדת הכספים                                        |"אגרות           |                     |
|של הכנסת, רשאי לקבוע בתקנות אגרות אלה שישולמו לרשות:                                             |                 |                     |
|(1) אגרה שישלם מציע;                                                                             |                 |                     |
|(2) אגרה שנתית שישלם תאגיד שהוראות פרק ו' חלות                                                   |                 |                     |
|עליו;                                                                                            |                 |                     |
|(3) אגרה בעד עיון במסמכים והעתקתם.                                                               |                 |                     |
|(ב) בתקנות כאמור ייקבע המועד לתשלום האגרות (להלן -                                               |                 |                     |
|מועד התשלום).                                                                                    |                 |                     |
|(ג) לא שולמה אגרה במועד התשלום, ייווספו עליה הפרשי הצמדה                                         |                 |                     |
|לפי שיעור עליית המדד מן המדד שפורסם לאחרונה לפני מועד התשלום                                     |                 |                     |
|עד המדד שפורסם לאחרונה לפני המועד שבו שולמה האגרה בפועל,                                         |                 |                     |
|וכן קנס בשיעור של 1.5% מסכום האגרה לכל שבוע של פיגור או חלק                                      |                 |                     |
|ממנו.                                                                                            |                 |                     |
|(ד) בסעיף זה, "מדד" - מדד המחירים לצרכן שמפרסמת הלשכה                                            |                 |                     |
|המרכזית לסטטיסטיקה.                                                                              |                 |                     |
|55ב. על גביית אגרות, הפרשי הצמדה וקנס לפי סעיף 55א תחול                                          |גבייה            |                     |
|פקודת המסים (גביה)2 כאילו היו מס כמשמעותו בפקודה האמורה."                                        |                 |                     |
|2. בסעיף 56(א) לחוק העיקרי, הסיפה המתחילה במלים "בתקנות אלה רשאי" -                                               |תיקון סעיף 56        |
|תימחק.                                                                                                            |                     |

|דברי הסבר؀ࠂࠒࠔࠖࠤ               |

|האגרה היחידה המשולמת כיום לרשות - והמיו-                       |
|עדת לכסות את כל הוצאותיה - היא האגרה המשולמת                   |
|בעת הגשת הבקשה להתיר פרסומו של תשקיף. תאגיד                    |
|אשר ניירות הערך שלו נסחרים בבורסה חייב בדיווח                  |
|שנתי ובדיווחים מידיים ועל הרשות לבדוק דו"חות                   |
|אלה, וזאת נוסף לבדיקות אחרות וחקירות שהצורך                    |

|בהן עשוי להתעורר לגבי תאגידים אשר ניירות הערך                      |
|שלהם נסחרים כאמור.                                                 |
|לפיכך מוצע להסמיך את שר האוצר לקבוע אגרה                           |
|שנתית שתשולם לרשות בידי התאגידים שעליהם מטיל                       |
|החוק חובת דיווח, וזאת נוסף לאגרה שמשולמת לרשות                     |
|בעת הגשת הבקשה להתיר פרסומו של תשקיף.                              |
