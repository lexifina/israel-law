|מתפרסמת בזה הצעת חוק מטעם ועדת החוקה, חוק ומשפט של הכנסת :                          |

|חוק איסור לשון הרע (תיקון מס' 3), התשמ"ד-1984                                         |

|1. במקום סעיף 11 לחוק איסור לשון הרע, התשכ"ה-1965  1(להלן - החוק העיקרי)                                          |החיפת                |
|יבוא:                                                                                                             |סעיף 11              |
|11. (א) פורסמה לשון הרע באמצעי התקשורת, ישאו באחריות                                         |"אחריות בשל         |                     |
|פלילית ואזרחית, בשל לשון הרע, האדם שהביא את דבר לשן הרע                                      |פרסום באמצעי        |                     |
|לאמצעי התקשורת, וגרם בכך לפרסומו, עורך אמצעי התקשורת ומי                                     |התקשורת -           |                     |
|שהחליט בפועל על הפרסום, ובאחריות אזרחית ישא גם האחראי לאמצעי                                 |                    |                     |
|התקשורת.                                                                                     |                    |                     |
|(ב) באישום פלילי לפי סעיף זה תהא זו הגנה טובה לעורך                                          |                    |                     |
|שנקט אמצעים סבירים כדי למנוע פרסום אותה לשון הרע ושלא ידע                                    |                    |                     |
|על פרסומה.                                                                                   |                    |                     |
|(ג) בחוק זה -                                                                                |                    |                     |
|"אמצעי תקשורת" - עתון כמשמעותו בפקודת העתונות 2 והשידורים                                    |                    |                     |
|כהגדרתם בחוק רשות השידור, התשכ"ה-1965 3;                                                     |                    |                     |
|"עורך אמצעי תקשורתי", בעתון - לרבות עורך בפועל, ובשידור -                                    |                    |                     |
|לרבות עורך התכנית שבה נעשה הפרסום;                                                           |                    |                     |
|"אחראי לאמצעי תקשורת", בעתון - מוציאו לאור, ובשידור -                                        |                    |                     |
|רשות השידור."                                                                                |                    |                     |
|2. בסעיף 15 לחוק העיקרי, במקום פסקה (11) יבוא:                                                                    |תיקון סעיף 15        |
|"(11) הפרסום לא יהא אלא במסירת ידיעה לעורך אמצעי תקשורת או לנציגו                                                 |                     |
|כדי שיבחן שאלת פרסומה באותו אמצעי תקשורת."                                                                        |                     |
|3. בסעיף 17 לחוק העיקרי -                                                                                         |תיקון סעיף 17        |
|(1) בסעיף קטן (א), במקום הרישה עד המלים "מקבלת הדרישה" יבוא:                                                      |                     |
|"פורסמה לשון הרע באמצעי תקשורת לא תעמוד הגנת תום לב לעורכו,                                                       |                     |
|למי שהחליט בפועל על הפרסום או לאחראי על אותו אמצעי תקשורת                                                         |                     |
|אם נדרש על ידי הנפגע؀ࠂࠒࠔࠖࠤ, או אחד הנפגעים, לפרסם תיקון או הכחשה מצד                                              |                     |
|הנפגע ולא פרסם את התיקון או ההכחשה במקום, במידה ובדרך שבה פורסמה                                                  |                     |
|אותה לשון הרע, ותוך זמן סביר מקבלת הדרישה; "                                                                      |                     |
|(2) בסעיף קטן (ב), במקום "הופיע העתון" יבוא "היה הפרסום בעתון המופיע".                                            |                     |

|דברי הסבר                |

|הצעת החוק באה להרחיב את תחולת ההוראות                         |
|בדבר פרסום הכחשה או תיקון גם על הרדיו והטלויזיה,              |
|שלגביהם לא היו עד כה הוראות בענין זה והיא באה                 |

|להבהיר כי פרסום הכחשה מגזעם עתון ואמצעי תקשורת                     |
|אחר, לבקשת הנפגע, צריכה להיעשות באותה הבלטה                        |
|שבה פורסמה לשון הרע על הנפגע.                                      |
