|חוק הבזק (העברת עובדים), התשמ"א-1981                                |

|1. נחתם בין המדינה לבין בעל הרשיון הכללי כמשמעותו בחוק הבזק, התשמ"א-                                        |הסכם להעברת        |
|1981ג (להלן - חוק הבזק), לבין ארגון עובדים יציג הסכם בדבר העברת עובדים                                      |עובדים             |
|משירות המדינה לשירות בעל הרשיון הכללי (להלן - הסכם ההעברה), יחולו הוראות                                    |                   |
|אלה מיום תחילתו של הסכם ההעברה:                                                                             |                   |
|(1) עובד המדינה שייקבע בהסכם ההעברה יהיה עובד של בעל הרשיון                                                 |                   |
|הכללי החל מן היום שקבע שר התקשורת;                                                                          |                   |
|(2) על אף האמור בכל דין, עובד המדינה שהפך להיות עובד של בעל                                                 |                   |
|הרשיון הכללי כאמור בפסקה (1) לא יהיה זכאי להטבות פרישה כל שהן                                               |                   |
|בשל ההעברה;                                                                                                 |                   |
|(3) עובד שהפך להיות עובד של בעל הרשיון הכללי כאמור בפסקה (1),                                               |                   |
|ובתנאים ובתקופה שנקבעו בהסכם ההעברה לא הסתגל לעבודה אצל בעל                                                 |                   |
|הרשיון הכללי - הוראות פסקה (2) לא יחולו עליו וזכויותיו יהיו כפי                                             |                   |
|שנקבע בהסכם ההעברה;                                                                                         |                   |
|(4) זכויותיו של עובד שהועבר כאמור כלפי המדינה מכוח יחסי עובד                                                |                   |
|ומעביד שהיו ביניהם, בשל תקופת היותו עובד המדינה, שבעל רשיון קיבל                                            |                   |
|על עצמו לקיימן בהסכם ההעברה - לא יהיה העובד רשאי לתבוע קיומן                                                |                   |
|מן המדינה.                                                                                                  |                   |
|2. תנאי הסכם עבודה בין בעלי הרשיון הכללי לבין ארגון יציג של עובדיו, שענינם                                  |הסכם עבודה         |
|תנאי עבודה, שינויי תקן, שכר והטבות אחרות, טעונים אישור שר האוצר, וזאת לתקופה                                |                   |
|של שנה מיום העברת רוב עובדי משרד התקשורת לבעל הרשיון הכללי.                                                 |                   |
|3 . הוראות חוק שירות הציבור (הגבלות לאחר פרישה), התשכ"ט-1969 2, לא יחולו                                    |אי תחולת           |
|על מי שהיה עובד משרד התקשורת ביום כ؀ࠂࠐࠒࠔ"ה בטבת התשמ"א (1 בינואר 1981)                                      |הוראות חוק         |
|והיה לעובדו של בעל הרשיון הכללי עד תום שנה מיום תחילתו של חוק הבזק.                                         |שירות הציבור       |
|                                                                                                            |(הגבלות לאחר       |
|                                                                                                            |פרישה)             |

|דברי הסבר              |

|עובד המדינה המועבר לשירותו של בעל              |סעיף 1       |
|הרשיון הכללי על פי קביעת השר, לאחר             |             |
|חתימת הסכם להעברת עובדים, לא יהיה זכאי להטבות               |
|פרישה בשל ההעברה, ולא יהיה זכאי לתבוע מהמדינה               |
|קיום זכויות שהועברו לבעל הרשיון על פי ההסכם                 |
|שבין המדינה, בעל הרשיון וארגון עובדים יציג.                 |
|קביעת תנאי השכר ותנאי העבודה של                |סעיף 2       |
|העובדים המועברים על פי סעיף 1, בתקו-           |             |
|פה הראשונה של פעילותו של בעל הרשיון הכללי,                  |
|תהיה טעונה אישור שר האוצר.                                  |

|הוראות חוק שירות הציבור (הגבלות לא-           |מעיף 3      |
|חר פרישה), התשכ"ט-1969, מטילות הגב-           |            |
|לות שונות על מי שעזב את שירות המדינה ומעסיק                |
|אותו גוף שבענינו הוא עסק בהיותו עובד המדינה.               |
|מאחר שעובדים במשרד התקשורת עוסקים בהקמת גוף                |
|עסקי - בעל הרשיון הכללי - למתן שירותי בזק                  |
|במקום המדינה, מוצע לפטור עובדים אלה מתחולת                 |
|הוראות החוק, בשנה הראשונה לפעילותו של בעל                  |
|הרשיון, אף אם נתקבלו לעבודה אצל בעל הרשיון                 |
|שלא בדרך האמורה בסעיף 1 לחוק.                              |
