|                  |מתפרסמת בזה מטעם ועדת החינוך והתרבות הצעת חוק של חבר הכנסת :                                              |
|                  |חוק מורשת העדות, התשמ"א-1981                                                                              |
|הקמת הרשות        |1. מוקמת בזאת רשות ממלכתית לחקר מורשת עדות ישראל ושמירתה.                                                 |
|המטרות            |2. מטרות הרשות הן:                                                                                        |
|                  |(1) לחקור את מורשת עדות ישראל;                                                                            |
|                  |(2) לאסוף ולתעד את החומר הקיים בנוגע למורשת עדות ישראל;                                                   |
|                  |(3) להקים גנזך לאומי שבו תישמר ותוצג המורשת הרוחנית והתרבותית                                             |
|                  |של עדות ישראל.                                                                                            |
|מועצה             |3. לרשות תהיה מועצה שמספר חבריה 15 ובהם שני חברי הכנסת שתבחר ועדת                                         |
|                  |החינוך והתרבות של הכנסת ונציגי גופים אלה:                                                                 |
|                  |(1) משרד החינוך והתרבות;                                                                                  |
|                  |(2) האוניברסיטה העברית בירושלים;.                                                                         |
|                  |(3) אוניברסיטת תל-אביב;                                                                                   |
|                  |(4) אוניברסיטת בר-אילן;                                                                                   |
|                  |(5) אוניברסיטת בן-גוריון בנגב;                                                                            |
|                  |(6) אוניברסיטת חיפה;                                                                                      |
|                  |(7) מכללת בית ברל;                                                                                        |
|                  |(8) יד יצחק בן-צבי.                                                                                       |
|מינויים ראשונים   |4. (א) שר החינוך והתרבות ימנה את המועצה הראשונה.                                                          |
|                  |(ב) המועצה הראשונה תכהן שנתיים מיום מינויה.                                                               |
|התקנון            |5. (א) המועצה הראשונה תתקין תקנון תוך שנה מיום הקמתה; התקנון יובא לאישור                                  |
|                  |הממשלה ולאישור ועדת החינוך והתרבות של הכנסת.                                                              |
|                  |(ב) בתקנון יהיו, בין השאר, הוראות בדבר פעילות הרשות, הרכב המוסדות,                                        |
|                  |תקופת כהונתם, סמכויות המוסדות וחובותיהם, סדרי؀ࠂࠌࠎ עבודה, צורת קביעת התקציב ודרך                           |
|                  |הבאת שינויים ותיקונים בתקנון.                                                                             |
|                  |(ג) יובטח מימון מאוצר המדינה כפי שתאשר ועדת הכספים של הכנסת.                                              |
|ביצוע ותקנות      |6. שר החינוך והתרבות ממונה על ביצוע חוק זה והוא רשאי להתקין תקנות לביצועו.                                |

|דברי הסבר         |

|המציאות היום בישראל מראה כי תרבויות שלמות                   |
|שהתפתחו בעדות ישראל השונות במקום גלויותיהן,                 |
|הולכות ונכחדות. מטרת חוק זה היא להקים גוף ממל-              |
|כתי שיחקור, ישמור ויאסוף את כל אוצרות התרבות                |

|של העדות השונות ויציגם לעיני כל תושבי המדינה,                |
|על ידי רשות השידור, המוזיאונים, הוצאת ספרי לימוד             |
|וכד', כפי שייקבע בתקנות מפורטות שיתקין שר החינוך             |
|והתרבות.,                                                    |
