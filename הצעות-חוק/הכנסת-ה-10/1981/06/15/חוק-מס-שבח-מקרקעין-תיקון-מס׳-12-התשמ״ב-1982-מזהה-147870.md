|1. בסעיף 47 לחוק מס שבח מקרקעין, התשכ"ג-1963  1(להלן - החוק העיקרי) -                                     |תיקון סעיף 47     |
|(1) אחרי הגדרת "מדד" יבוא:                                                                                |                  |
|""מועד רכישה" ו"מועד מכירה" - לגבי בכס שיום הרכישה שלו או יום                                             |                  |
|המכירה שלו היה במחצית הראשונה של שנת המס - 30 בספטמבר, ולגבי                                              |                  |
|נכס שיום הרכישה שלו או יום המכירה שלו היה במחצית השניה של שנת                                             |                  |
|המס - 31 במרס; לענין זה, "רכישת נכס" - לרבות יצירה והשבחה,                                                |                  |
|ויראו כיום הרכישה של השבחה את יום גמר ההשבחה, ובבנין חדש על                                               |                  |
|קרקע פנויה - את היום שבו תמו שני שלישים מהתקופה המתחילה בתחילת                                            |                  |
|הבניה והמסתיימת בגמר הבניה ;"                                                                             |                  |
|(2) הגדרת "פחת מתואם" - בטלה;                                                                             |                  |
|(3) הגדרת "שווי רכישה מתואם" - בטלה;                                                                      |                  |
|(4) לפני הגדרת "יתרת שווי רכישה" יבוא:                                                                    |                  |
|""הוצאות השבחה" - הסכומים המותרים בניכוי לפי סעיף 39 למעט המסים                                           |                  |
|ותשלומי החובה;"                                                                                           |                  |
|(5) אחרי הגדרת "יתרת שווי רכישה" יבוא:                                                                    |                  |
|""יתרת שווי רכישה מתואם" - יתרת שווי הרכישה, למעט הוצאות השבחה,                                           |                  |
|בתוספת מחצית סכום המסים המותרים בניכוי לפי סעיף 39(8) ששולמו בשל                                          |                  |
|המקרקעין מיום רכישת הזכות בהם ועד לשנת המכירה - למעט המסים                                                |                  |
|ששולמו בשנה שלפני המכירה בשל שנים קודמות - כפול ב-9/1؀ࠂࠐࠒࠖࠚࠜࠞ0 משיעור                                     |                  |
|עליית המדד בתקופה שממועד הרכישה ועד מועד המכירה, ובתוספת הוצאות                                           |                  |
|השבחה כפול ב-9/10 משיעור עליית המדד בתקופה שממועד גמר ההשבחה                                              |                  |
|או ההוצאה, לפי הענין, ועד למועד המכירה ;"                                                                 |                  |
