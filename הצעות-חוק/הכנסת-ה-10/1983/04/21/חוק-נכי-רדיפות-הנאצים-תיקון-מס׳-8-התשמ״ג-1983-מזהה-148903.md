|תיקון סעיף 8      |1. בסעיף 8 לחוק נכי רדיפות הנאצים, התשי"ז-1957 1(להלן - החוק העיקרי),                                           |
|                  |במקום "לענין סעיף 8 לתוספת החמישית לחוק הביטוח הלאומי, התשי"ד-1954                                              |
|                  |(להלן - חוק הביטוח)" יבוא "לפי סעיף 6(א) לחוק נכי המלחמה בנאצים, התשי"ד-                                        |
|                  |.1954 2".                                                                                                       |
|החלפת סעיף 9      |2. במקום סעיף 9 לחוק העיקרי יבוא:                                                                               |
|                  |"עיי 9. הנכה או הרשות המוסמכת רשאים, בתנאים שייקבעו בתקנות,                                                     |
|                  |לערור על החלטה של ועדה רפואית בפני ועדה רפואית עליונה שנת-                                                      |
|                  |מנתה לפי סעיף 12א לחוק נכי המלחמה בנאצים, התשי"ד-1954."                                                         |
|תחולה             |3. חוק זה יחול על מי שביום פרסום חוק זה טרם החל הדיון בבקשתו לקביעת דרגת                                        |
|                  |נכות או שטרם החל הדיון בעררו בקשר לדרגת נכותו, לפי הענין.                                                       |

|דברי הסבר                   |

|המוסמכת, תוך שלושים יום, את כל המסמכים                        |קביעת דרגת נכות של המבקש תגמול לפי חוק                               |
|לועדה רפואית שנתמנתה לענין סעיף 8 לתוספת                      |נכי רדיפות הנאצים מתבצעת בידי הועדות הרפואיות                        |
|החמישית לחוק הביטוח הלאומי, התשי"ד-1953                       |של המוסד לביטוח לאומי לענין נפגעי עבודה.                             |
|(להלן -חוק הביטוח), לשם קביעת דרגת הנכות                      |הלשכה לשיקום נכים של ؀ࠂࠎࠐࠒמשרד האוצר מממנת                           |
|לפי מבחנים ובהתאם לעקרונות שיקבע השר                          |את הבדיקות. לשכה זו מטפלת הן בנכי רדיפות הנא-                        |
|בתקנות.                                                       |צים והן בנכי המלחמה בנאצים.                                          |
|                                                              |מוצע לאחד את הועדות הרפואיות לפי חוק נכי                             |
|                                                              |רדיפות הנאצים וחוק נכי המלחמה בנאצים, באופן                          |
|                                                              |שהועדות הרפואיות הפועלות ליד הלשכה לשיקום נכים                       |
|                                                              |והמוקמות לפי חוק נכי המלחמה בנאצים, יטפלו גם                         |
|                                                              |בנכי רדיפות הנאצים. איחוד הטיפול יביא לכך שמשך                       |
