|מתפרסמות בזה הצעות חוק מטעם הממשלה:                      |

|חוק היטל על נסיעה לחוץ לארץ, התשמ"ג-1983.                                         |

|היטל נסיעה        |1. (א) מי שנוסע לחוץ לארץ ישלם לאוצר המדינה לפני יציאתו מהארץ היטל                                                |
|לחו"ל             |בסכום של 2,100 שקלים (להלן - ההיטל).                                                                              |
|                  |(ב) שר האוצר, באישור ועדת הכספים של הכנסת, רשאי לשנות בתקנות את                                                   |
|                  |סכום ההיטל.                                                                                                       |
|הצמדת סכום        |2. (א) הסכום הנקוב בסעיף 1(א) או הסכום שנקבע לפי סעיף 1(ב) לפי העניו,                                             |
|ההיטל             |ישתנה ב-16 בכל חודש (להלן - יום השינוי) לפי שיעור עליית המדד החדש לעומת                                           |
|                  |המדד היסודי, ויעוגל לסכום הקרוב שהוא מכפלה של 10.                                                                 |
|                  |(ב) שר האוצר רשאי, בין שני ימי שינוי, להעלות בצו את סכום ההיטל כפי                                                |
|                  |שהיה לאחר השינוי האחרון, ובלבד שההעלאה לא תעלה על השיעור שבו עלה שער                                              |
|                  |החליפין החדש לעומת שער החליפין הקודם; העלאה כאמור תופחת מן ההעלאה                                                 |
|                  |שמחושבת ליום השינוי הבא לפי סעיף קטן (א).                                                                         |

|(ג) בסעיף זה -                                                                                                      |גביית ההיטל        |
|"מדד" - מדד המחירים לצרכן שמפרסמת הלשכה המרכזית לסטטיסטיקה; ,                                                       |והעברתו לאוצר      |
|"המדד היסודי" - המדד שפורסם לאחרונה לפני יום קבלתו של חוק זה בכנסת, ואם                                             |                   |
|שונה סכום ההיטל בתקנות לפי סעיף 1(ב) - המדד שפורסם לאחרונה לפני פרסום                                               |                   |
|התקנות;                                                                                                             |                   |
|"שער החליפין" - שער החליפין היציג של דולר של ארצות הברית של אמריקה;                                                 |                   |
|"השער החדש" - שער החליפין שפורסם לאחרונה לפני יום פרסום הצו;                                                        |                   |
|"השער הקודם" - שער החליפין שפורסם לאחרונה לפני יום השינוי הקודם.                                                    |                   |
|3 . (א) ההיטל ישולם לאוצר המדינה באמצעות תאגיד בנקאי או בדרך אחרת                                                   |                   |
|שנקבעה.                                                                                                             |                   |
|(ב) מי שגבה את ההיטל יעבירו לחשב הכללי במשרד האוצר תוך שלושה ימים                                                   |                   |
|מיום גבייתו או במועד אחר שהורה לו שר האוצר.                                                                         |                   |
|(ג) מי שגבה היטל ולא תעבירהו לחשב הכללי במועד יהא חייב בתוספת בשיעור                                                |                   |
|0.5% לכל יממה של פיגור.                                                                                             |                   |
|4. (א) אלה פטורים מתשלום ההיטל:                                                                                     |פטורים             |
|(1) איש צוות של כלי טיס או ؀ࠂࠈࠊࠎࠔכלי שיט, הנוסע בתפקיד;                                                             |                   |
|(2) מי שנמצא בישראל על פי אשרה ורשיון לישיבת מעבר או על פי אשרה                                                     |                   |
|ורשיון לישיבת ביקור;                                                                                                |                   |
|(3) דיפלומט של מדינת חוץ, עובד ארגון האומות המאוחדות או סוכנויותיו                                                  |                   |
|המיוחדות, ארגון הצלב האדום ואנשי הכוח הרב לאומי כהגדרתם בחוק                                                        |                   |
|חסינויות וזכויות (הכוח הרב לאומי), התשמ"ב-1982  1;                                                                  |                   |
|(4) נוסע שיעד נסיעתו הוא מדינה שיש לישראל גבול יבשתי אתה.                                                           |                   |
|(ב) שר האוצר, באישור ועדת הכספים של הכנסת, רשאי לקבוע בצו כי חובת                                                   |                   |
|תשלום ההיטל כולו או מקצתו תחול על נוסעים כאמור בסעיף קטן (א)(4), דרך כלל או                                         |                   |
|לפי יעד הנסיעה.                                                                                                     |                   |
|5. מי שמנהל אגף המכס והבלו הסמיכו לכר רשאי לעכב את יציאתו מן הארץ של                                                |עיכוב יציאה        |
|נוסע שאין בידו אישור על תשלום ההיטל.                                                                                |                   |
|6. על גביית ההיטל והתוספת לפי סעיף 3(ג) תחול פקודת המסים (גביה) 2.                                                  |תחולת פקודת        |
|                                                                                                                    |המסים (גביה)       |
|                                                                                                                    |ביצוע ותקנות       |
|7. שר האוצר ממונה על ביצוע חוק זה והוא רשאי להתקין תקנות בכל הנוגע לביצועו.                                         |                   |
|8. חוק זה יחול על מי שיצא מישראל ביום י"ח בניסן התשמ"ג (1 באפריל 1983)                                              |תחולה              |
