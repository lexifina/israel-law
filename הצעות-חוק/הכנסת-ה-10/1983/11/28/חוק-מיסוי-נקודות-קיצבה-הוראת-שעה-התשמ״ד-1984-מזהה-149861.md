|מס הכנסה בשל       |2 (א) יחיד שביום הקובע זכאי על פי הפקודה לנקודות קיצבה בשל לא יותר                                                   |

|                   |אליה סכום הכנסה ששיעור המס החל עליו הוא 50% או יותר, סכומי נקודות הקיצבה                                             |
|                   |שהוא זכאי להן בשל כל אחד משני ילדיו הראשונים, בשל התקופות המתייחסות ליום                                             |
|                   |הקובע, ייחשבו כהכנסה; הוראה זו תחול על אף האמור בסעיף 116 לחוק הביטוח הלאומי                                         |
|                   |[נוסח משולב], התשכ"ח-1968 2, ובסעיף 9ב לפקודה; הכנסה כאמור לא תובא בחשבון                                            |
|                   |לענין ניכוי כלשהו המחושב כשיעור מהכנסה החייבת.                                                                       |
|                   |(ב) כל המשלם או אחראי לתשלומה של הכנסת עבודה למי שזכאי לנקודות                                                       |
|                   |קיצבה שלפי סעיף קטן (א) רואים אותן כהכנסה, ינכה מהכנסת העבודה שהוא משלם את                                           |
|                   |המס החל על סכומי נקודות הקיצבה כאילו היו הכנסת עבודה שהוא משלם; הוראה זו                                             |
|                   |תחול גם על המדינה.                                                                                                   |
