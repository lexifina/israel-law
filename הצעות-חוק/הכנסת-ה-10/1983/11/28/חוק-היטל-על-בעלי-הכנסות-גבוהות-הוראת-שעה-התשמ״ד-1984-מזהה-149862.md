|חוק היטל על בעלי הכנסות גבוהות (הוראת שעה), התשמ"ד-1983                                          |

|1. בחוק זה -                                                                                                        |פרשנות          |
|(1) תהא לכל מונח המשמעות שיש לו בפקודת מס הכנסה (להלן - הפקודה) 1,                                                  |                |
|זולת אם יש בחוק זה הוראה מפורשת אחרת;                                                                               |                |
|(2) "התקופה הקובעת" - התקופה שמיום 1 בדצמבר 1983 ועד יום 31 במרס                                                    |                |
|1985;                                                                                                               |                |
|(3) "הכנסה חבת היטל" - אותו חלק של ההכנסה החייבת, למעט רווח הון ושבח                                                |                |
|מקרקעין -                                                                                                           |                |
|(א) לגבי שנת המס 1983 - העולה על שלושה מיליון ושלוש מאות אלף                                                        |                |
|שקלים ;                                                                                                             |                |
|(ב) לגבי תקופה שלאחר שנת המס 1983 - העולה על הסכום האמור                                                            |                |
|בפסקת משנה (א), כשהוא מותאם לעליית המדד על פי סעיף 120ב לפקודה                                                      |                |
|החל ב-1 באפריל 1984, כאילו הוא תקרת הכנסה שהותאמה לאחרונה ב-1                                                       |                |
|ביולי 1983;                                                                                                         |                |
|(ג) לגבי חלקי תקופות שומה - העולה על חלק יחסי מסכום ההכנסה                                                          |                |
|האמור בפסקאות משנה (א) ו -(ב), לפי הענין, כיחס מספר החודשים שבחלק                                                   |                |
|תקופת השומה, ל-12.                                                                                                  |                |
|2. (א) יחיד שבתקופה הקובעת היתה לו הכנסה הבת היטל, ישלם היטל בשיעור של                                              |היטל על בעלי    |
|10% ממס ההכנסה שהוא חייב בו על ההכנסה חבת ההיטל.                                                                    |הכנסות גבוהות   |
|(ב) הכנסה שחלים עליה שיעורי מס מיוחדים, יראוה לענין הכללתה בהכנסה                                                   |                |
|חבת היטל בלבד, כאילו היא כלולה בתקרת ההכנסה הגבוהה ביותר של הנישום, כך                                              |                |
|שההכנסות ששיעורי המס עליהם הם הגבוהים ביותר יובאו בחשבון תחילה.                                                     |                |
|(ג) הוראות הפקודה יחולו על ההיטל כאילו היה מס הכנסה.                                                                |                |
|3. שר האוצר ממונה על ביצוע חוק זה והוא רשאי להתקין תקנות לביצועו.                                                   |ביצוע ותקנות    |

|דברי ؀ࠂࠐࠒࠔהסבר            |

|מאות אלף שקלים. הכנסה זו תעודכן מ-1 באפריל 1984                    |הצורך בהקטנת הצריכה הציבורית ובהקטנת הבי-                        |
|ארבע פעמים בשנה, כאילו היתה תקרת הכנסה לענין                       |קושים הפרטיים הגורמים לעודף שימושים מקומיים על                   |
|פקודת מס הכנסה. ההיטל יהיה בשיעור של 10% מהמס                      |המקורות העומדים לרשות המשק חייבו את הממשלה                       |
|החל על אותו חלק מההכנסה העולה על הסכומים                           |בנקיטת צעדי מדיניות שעיקריהן ספיגה מהקבוצות                      |
|האמורים.                                                           |בעלות היכולת הכלכלית שבקרב האוכלוסיה בישראל.                     |
|האוכלוסיה ממנה יגבה ההיטל מצויה במאון העליון                       |אחד הצעדים המוצעים הוא הטלת היטל על בעלי                         |
|של בעלי ההכנסות בישראל, ונכללים בה כ-14,000 איש,                   |ההכנסות הגבוהות לתקופה מוגבלת של 16 חדשים.                       |
|שכמחציתם הם שכירים.                                                |ההיטל המוצע יחול על נישומים שהכנסתם השנתית                       |
