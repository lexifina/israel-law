|ואחריו יבוא:                                                                                                      |                 |
|"(ב) סעיף קטן (א) יחול, בשינויים המחוייבים, על יוצא צבא שנמצא בלתי כשר                                            |                 |
|ארעית לשירות ונקרא להתייצב לבדיקה חוזרת לפי סעיף 5 ולא התייצב, או שהתייצב                                         |                 |
|וסירב להיבדק או להשלים את הבדיקות."                                                                               |                 |

|דברי הסבר                  |

|לפי סעיף 5 לחוק, יוצא צבא שנמצא בלתי כשר                          |סעיף 8 לחוק ؀ࠂࠐࠒࠔשירות בטחון, התשי"ט-1959 [נוסח                  |
|לשירות או בלתי כשר ארעית לשירות, רשאי פוקד                        |משולב], קובע לאמור:                                              |
|לקראו בצו להתייצבות לבדיקה חוזרת לשם קביעת                        |                                                                 |
|כשרו לשירות; הוא הדין לגבי יוצא צבא ששירת                         |                                                                 |
|שירות סדיר או שהיה נמנה עם כוחות המילואים וניתן                   |                                                                 |
|לו פטור משירות מחמת שנמצא בלתי כשד לשירות.                        |                                                                 |
|משנקרא יוצא הצבא לבדיקה חוזרת כאמור ואינו                         |                                                                 |
|מתייצב, אין אפשרות לקבוע אם הוא כשר לשירות                        |                                                                 |
|אפ לאו, ואף אין אפשרות על פי החוק הקיים לקרוא                     |                                                                 |
|לו לשירות בטחון.                                                  |                                                                 |
|כל מה שמאפשר החוק הקיים הוא לפתוח בהליך                           |                                                                 |
|פלילי נגדו.                                                       |                                                                 |
|הועדה לביקורת המדינה של הכנסת העירה על                            |                                                                 |
|ליקוי זה והמליצה לתקן את החוק בהתאם.                              |                                                                 |
|מוצע לאפשר לקתא לשירות בטחון מי שנמצא                             |                                                                 |
|בלתי כשר ארעית ומסרב להתייצב לבדיקה חוזרת.                        |                                                                 |
|                                                                  |"אי התייצבות לבדיקה אינה פוטרת                                   |
|                                                                  |משירות בטחון                                                     |
|                                                                  |8. מיועד לשירות בטחון שנקרא להתייצב                              |
|                                                                  |לבדיקת כשרו לשירות בטחון ולא התייצב,                             |
|                                                                  |או שהתייצב וסירב להיבדק או להשלים את                             |
|                                                                  |הבדיקות, רשאי פוקד לקרוא לו להתייצב לשירות                       |
|                                                                  |בטחון, לפי סעיפים 9 או 19, הכל לפי העניו,                        |
|                                                                  |אם אותה שעה היה יוצא צבא, אף על פי שכשרו                         |
|                                                                  |לשירות בטחון עדיין לא נקבע; אך לא יתחיל                          |
|                                                                  |באימון צבאי כל עוד לא נבדק בדיקה רפואית                          |
|                                                                  |לצורך קביעת כשרו הרפואי לשירות בטחון                             |
|                                                                  |ונמצא כשר לשירות, והוראות הסעיפים 4-7                            |
|                                                                  |יחולו על הבדיקה, בשינויים המחוייבים לפי                          |
|                                                                  |הענין; הבדיקה תהיה תוך חודש ימים לאחר                            |
|                                                                  |התייצבותו, ואם סירב להיבדק, דינו כדין מי                         |
|                                                                  |שהפר את הסעיף 122 לחוק השיפוט הצבאי,                             |
|                                                                  |התשט"ו-1955."                                                    |
