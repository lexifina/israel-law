|הגדרות         |1. (א) בחוק זה -                                                                                                 |
|               |"חייל משוחרר" - חייל ששירת שירות חירום ושירותו זה נסתיים כדין;                                                   |
|               |"שירות חירום" - שירות בתקופה שבין י"ג בסיון התשמ"ב (4 ביוני 1982) לבין י"ג                                       |
|               |באלול התשמ"ב (1 בספטמבר 1982) ששר הבטחון הכריז עליו כשירות חירום, לפי                                            |
|               |סעיף 1 לחוק הארכת מועדים, התשל"ה-1974 1;                                                                         |

|דברי הסבר                  |

|החוק המוצע בא לקבוע הקלות בענין התמחותם                          |
|של חיילים משוחררים ששירתו שירות חירום במבצע                      |
|שלום הגליל. ההצעה תואמת את החלטת לשכת עורכי                      |
|הדין.                                                            |

|"החוק" - חוק לשכת עורכי הדין, התשכ"א-1961 2.                                                                       |קיצור תקופת        |
|(ב) מונחים אחרים בחוק זה יתפרשו כמשמעותם בחוק.                                                                     |התמחות             |
|2. על אף האמור בסעיף 35(א) לחוק, רשאית המועצה הארצית של הלשכה, באישור                                              |                   |
|שר המשפטים, לקבוע בכללים הוראות בדבר קיצור תקופת התמחותו של חייל משוחרר,                                           |                   |
|שהלשכה נוכחה כי עקב שירותו בשירות חירום, נבצר ממנו, בתקופת שירותו, להיות י                                         |                   |
|כשיר להירשם כמתמחה לפי סעיף 26 לחוק, להירשם כמתמחה, להתחיל בהתמחות או                                              |                   |
|להמשיך בה, לפי החוק, וכן לקבוע בכללים תנאים וסייגים לכך, לרבות הקלות מיוחדות                                       |                   |
|לחייל משוחרר שנפצע או שבריאותו נפגעה עקב שירותו כאמור, ובלבד שתקופת התמחות                                         |                   |
|לא תקוצר ביותר מששה חדשים.                                                                                         |                   |
|3. (א) על אף האמור בסעיף 26(1) לחוק, רשאית הלשכה לרשום כמתמחה חייל                                                 |רישום מתמחה        |
|משוחרר שהיה זכאי לעבור לשנת לימודיו האחרונה בפקולטה, גם אם עדיין לא עמד                                            |                   |
|בבחינות בשלושה מקצועות לכל היותר של שנות לימודיו הקודמות.                                                          |                   |
|(ב) אישרה הלשכה בקשתו של מתמחה כאמור בסעיף קטן (א), רשאית היא                                                      |                   |
|לקבוע כיום תחילת התמחותו את התאריך שבו החל להתמחות בפועל על פי הודעת המאמן,                                        |                   |
|ובלבד שלא יקדם מן היום שבו סיים את שירות החירום.                                                                   |                   |
|(ג) מתמחה שנרשם לפי סעיף קטן (א), ובתום؀ࠂࠐࠒࠖࠢࠤࠦࠬ࠮ ששה חדשים מיום כניסת חוק זה                                      |                   |
|לתקפו, עדיין אינו רשאי להירשם כמתמחה לפי סעיף 126(1) לחוק - תיפסק התמחותו                                          |                   |
|עד שיהיה רשאי להירשם כמתמחה לפי סעיף 26(1) לחוק.                                                                   |                   |
|(ד) מי שנרשם כמתמחה לפי סעיף קטן (א), לא יהיה זכאי לקיצור תקופת                                                    |                   |
|ההתמחות כאמור בכללים לפי סעיף 2.                                                                                   |                   |

|דברי הסבר                          |

|הבטחון לפי חוק הארכת מועדים, התשל"ה-1974 (ראה                      |
|ילקוט הפרסומים התשמ"ב, עמ' 2236א ועמי 2502).                       |
|סעיף 35(א) לחוק לשכת עורכי הדין,                   |סעיף 2         |
|התשכ"א-1961, קובע כי "תקופת ההתמחות                |               |
|תהיה שתי שנים". לפי החוק אין לשכת עורכי הדין                       |
|מוסמכת לקצר תקופת התמחות אלא לעורכי דין ולשופ-                     |
|טים מחו"ל (לפי סעיף 35(ב) לחוק), ולמי ששירתו                       |
|שירות מיוחד ליישוב, להקמת המדינה או למדינה לפני                    |
|יום ה' באייר התש"ט (4 במאי 1949) (לפי סעיף 102א                    |
|לחוק).                                                             |
|מוצע להסמיך את הלשכה לקצר את תקופת התמ-                            |
|חותם של מתמחים שהם חיילים משוחררים לפי כללים                       |
|שתקבע באישור שר המשפטים.                                           |

|סעיף 26(1) לחוק מונה בין הרשאים להת-                 |סעיף 3       |
|מחות מי שקיבל בפקולטה "אישור שהוא                    |             |
|זכאי לעבור לשנת לימודיו האחרונה ועמד בכל הבחינות                   |
|של שנות לימודיו הקודמות". כיון שמבצע שלום הגליל                    |
|חל בתקופת הבחינות באוניברסיטאות, קיצור תקופת                       |
|ההתמחות אינו תרופה מספקת לתלמידי שנה ד'. לכן,                      |
|מוצע להרשות את הלשכה לרשום כמתמחים תלמידים                         |
|שלא עמדו בבחינות בשלושה מקצועות לכל היותר                          |
|משנות לימודיהם הקודמות. הרישום יהיה למפרע מת-                      |
|חילת התמחותם בפועל, ובלבד שיסיימו את בחינותיהם                     |
|תוך ששה חדשים. לא סיימו - תיפסק התמחותם, עד                        |
|שיהיו רשאים להירשם כמתמחים לפי סעיף 26(1) לחוק.                    |
|מתמחה כזה לא יהיה זכאי לקיצור התמחות לפי סעיף 2.                   |
