|מתפרסמות בזה הצעות חוק מטעם הממשלה:               |

|חוק הסכמים קיבוציים (תיקון מס' 4), התשמ"ג-1982                                  |

|1. במקום סעיף 28 לחוק הסכמים קיבוציים, התשי"ז-1957 1, יבוא:                                                          |החלפת סעיף 28        |
|28. (א) צו הרחבה יפורסם ברשומות ויפורטו בו ההוראות שהורחבו                                          |"צו הרחבה       |                     |
|וסוגי העובדים והמעבידים שעליהם חל הצו.                                                              |                |                     |
|(ב) בצו הרחבה אפשר לקבוע כי תחילתו תקדם לתאריך פרסומו                                               |                |                     |
|עד שלושה חדשים או עד ליום תחילתן של הוראות ההסכם שהורחבו                                            |                |                     |
|בו, לפי המאוחר -                                                                                    |                |                     |
|(1) לגבי הוראה של הסכם קיבוצי כללי שעניבה אחד מאלה:                                                 |                |                     |
|(א) תוספת יוקר;                                                                                     |                |                     |
|(ב) פיצוי בעד התייקרות;                                                                             |                |                     |
|(ג) שכר מינימום;                                                                                    |                |                     |
|(2) לגבי הוראה של הסכם קיבוצי כללי החל על כמה                                                       |                |                     |
|ענפים, שלדעת שר העבודה והרווחה יש הצדקה לקבוע                                                       |                |                     |
|שתחילתה תהיה למפרע, בשים לב למספר בעלי ההסכם                                                        |                |                     |
|ולאופיה של ההוראה.                                                                                  |                |                     |
|(ג) פורסם צו הרחבה עם תחילה למפרע כאמור בסעיף קטן (ב),                                              |                |                     |
|רשאי המעביד לשלם את ההפרשים הנובעים מהתהילה למפרע של הצו,                                           |                |                     |
|בשיעורים חדשיים שווים ורצופים שמספרם כמספר החדשים שחלפו                                             |                |                     |
|מיום תחילת הצו ועד יום פרסומו, ולענין זה יראו חלק מחודש כחודש                                       |                |                     |
|שלם."                                                                                               |                |                     |

|דברי הסבר             |

|סעיף 28 לחוק הסכמים קיבוציים, התשי"ז-1957,                       |
|כפי שתוקן בשנת התשל"ה, קובע כדלקמן:                              |
|"צו הרחבה                                                        |
|28. (א) צו הרחבה יפורסם ברשומות, יגדיר את                        |
|ההוראות שהורחבו, את סוגי העובדים והמע-                           |
|בידים שעליהם חל הצו ואת תחילת תקפו                               |
|ובלבד שתחילתו לא תקדם לתאריך הפרסום;                             |
|אולם צו הרחבה של הסכם קיבוצי כללי לענין                          |
|תוספת יוקר, פיצוי בעד התייקרות או שכר                            |
|מינימום אפשר לקבוע בו שתחילתו ؀ࠂࠒࠔࠖࠦתקדם לתא-                    |
|ריך פרסומו עד שלושה חדשים או עד לפני                             |
|יום תחילתן של ההוראות שהורחבו בו, הכל לפי                        |
|המאוחר.                                                          |
|(ב) פורסם צו הרחבה עם תחילה למפרע כא-                            |
|מור בסעיף קטן (א), רשאי המעביד לשלם את                           |
|הפרשי השכר שעליו לשלמם על פי הצו בעד                             |

|התקופה שלפני יום פרסומו, בשיעורים חדשיים                          |
|שווים ורצופים במשך תקופה שארכה כאורך                              |
|התקופה שלגביה יש לשלם את הפרשי השכר.                              |
|(ג) ההוראות שהורחבו בצו יפורסמו בדרך                              |
|שיורה שד העבודה."                                                 |
|החוק המוצע נועד לאפשר החלתן למפרע של                              |
|הוראות בהסכמים קיבוציים כלליים החלים על כמה                       |
|ענפים במשק, וחלים על מספר ניכר של עובדים, בנוסף                   |
|להסכמים בדבר תוספת יוקר, פיצוי בעד התייקרות                       |
|ושכר מינימום הניתנים להרחבה למפרע לפי החוק                        |
|הקיים.                                                            |
|כתוצאה מכך יהיו גם עובדים, שאינם נכללים                           |
|באותם הסכמים קיבוציים, זכאים להטבות הנובעות                       |
|מהם התל בתאריך שבו היו זכאים לאותן הטבות                          |
|העובדים שההסכמים הקיבוציים האמורים חלו עליהם                      |
|מלכתחילה, אך לא מעבר לשלושה חדשים.                                |

|נ ס"ח התשי"ז, עמ' 63; התשל"ה, עמ' 223; התשל"ו, עמ' 138, עמ' 264.     |
