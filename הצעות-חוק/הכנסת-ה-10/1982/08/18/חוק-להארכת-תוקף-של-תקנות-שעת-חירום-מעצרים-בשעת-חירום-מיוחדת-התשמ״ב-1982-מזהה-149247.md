|חוק להארכת תקפן של תקנות שעת חירום (מעצרים בשעת                                           |
|חירום מיוחדת), התשמ"ב-1982                                                                |

|הארכת תוקף         |1. תקפן של תקנות שעת חירום (מעצרים בשעת חירום מיוחדת), התשמ"ב-1982 1,                                          |
|                   |בנוסח המובא בתוספת, מוארך בזה עד יום כ"ב באדר התשמ"ג (7 במרס 1983).                                            |
|                   |תוספת                                                                                                          |
|אכרזה על           |1. (א) אם ייראה הדבר לממשלה, בשל שיקולי ביטחון, רשאית היא להכריז על                                            |
|שעת חירום          |שעת חירום מיוחדת.                                                                                              |
|מיוחדת             |(ב) תקפה של הכרזה על שעת חירום מיוהדת יפקע כאשר תכריז על כך הממשלה,                                            |
|                   |או כאשר יפקע תקפן של תקנות אלה, לפי המועד המוקדם.                                                              |
|צו מעצר            |2. (א) בשעת חירום מיוחדת רשאי מפקד בצבא-הגנה לישראל שדרגתו תת-אלוף                                             |
|                   |לפחות (להלן - מפקד), שהיה לו יסוד סביר להניח שטעמי ביטחון המדינה או                                            |
|                   |ביטחון הציבור מחייבים שאדם פלוני, שאינו אזרח ישראלי או תושב ישראל יוחזק                                        |

|1 ק"ת התשמ"ב, עמ' 1182.        |

|במעצר, להורות בצו, בחתימת ידו על מעצרו של אדם זה לתקופה שתצויין בצו                                                 |                    |
|שלא תעלה על שלושה חדשים (להלן - צו מעצר).                                                                           |                    |
|(ב) היה למפקד יסוד סביר להניח ערב פקיעת תקפו של צו לפי תקנת משנה (א)                                                |                    |
|(להלן - צו המעצר המקורי), שטעמי ביטחון המדינה או ביטחון הציבור עדיין                                                |                    |
|מחייבים את החזקתו של העציר במעצר, רשאי הוא, בצו בחתימת ידו, להורות                                                  |                    |
|מפעם לפעם על הארכת תקפו של צו המעצר המקורי לתקופה שלא תעלה על                                                       |                    |
|שלושה חדשים, ודין צו ההארכה לכל דבר כדין צו המעצר המקורי.                                                           |                    |
|(ג) צו מעצר יכול שיינתן שלא במעמד האדם שעל מעצרו הוא חל.                                                            |                    |
|(ד) צו מעצר יבוצע על ידי שוטר או חייל כמשמעותו בסעיף 1 לחוק ؀ࠂࠈࠊࠎࠔהשיפוט                                            |                    |
|הצבאי, התשט"ו-1955 2, וישמש אסמכתה לחבישתו של אותו אדם (להלן - עציר)                                                |                    |
|במקום מעצר שנקבע בצו המעצר או בצל מעצר מאוחר יותר, בתנאים שקבע שר                                                   |                    |
|המשפטים בתקנות לפי סעיף 3 לחוק סמכויות שעת-חירום (מעצרים), התשל"ט-                                                  |                    |
|1979 3.                                                                                                             |                    |
|3. (א) שר המשפטים ימנה ועדת ערר או ועדות ערר לענין תקנות אלה; ועדת ערר                                              |בקורת על            |
|תורכב משלושה חברים ובראשם שופט.                                                                                     |צו מעצר             |
|(ב) עציר רשאי לערור על מעצרו בפני ועדת ערר.                                                                         |                    |
|(ג) האפשרות להגיש ערר והנוהל להגשתו יובאו לידיעת עציר בהקדם האפשרי.                                                 |                    |
|(ד) ועדת ערר תחל לדון בערר תוך שבועיים מיום שהוגש.                                                                  |                    |
|(ה) ועדת ערר תדון לפי סדרי דין ודיני ראיות כפי שנראה לה צודק ומועיל.                                                |                    |
|(ו) ועדת ערר תחליט אם לאשר את המעצר כפי שנקבע בצו המעצר, אם להגבילו                                                 |                    |
|בזמן או להתנותו בתנאים, ואם לבטלו.                                                                                  |                    |
|4. חוק סמכויות שעת-חירום (מעצרים), התשל"ט-1979 (להלן - החוק), לא יחול                                               |אי תחולת            |
|על מעצר לפי תקנות אלה.                                                                                              |החוק                |
|5. פקע תקפה של הכרזה על שעת חירום מיוחדת, ועציר עדיין נמצא במעצר מכוח                                               |המשך מעצר           |
|צו מעצר, יראו אותו כאילו נעצר אותו יום על-פי צו שניתן על ידי ראש המטה                                               |                    |
|הכללי לפי סעיף 2(ג) לחוק, והחוק יחול על המשך מעצרו.                                                                 |                    |
