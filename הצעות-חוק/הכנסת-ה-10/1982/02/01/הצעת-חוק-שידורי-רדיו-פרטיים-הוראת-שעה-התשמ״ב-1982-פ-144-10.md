|חוק שידורי רדיו פרטיים (הוראת שעה), התשמ"ב-1982                                                   |

|הגדרות              |1. בחוק זה -                                                                                                        |
|                    |"התחנה" - התחנה לשידורי רדיו הידועה בשם "קול השלום" והמותקנת בכלי שיט                                               |
|                    |הנושא את השם "שלום";                                                                                                |
|                    |"השר" - שר התקשורת,                                                                                                 |
|רשיון               |2. מי שהיה אחראי באופן אישי לניהולה ולהפעלתה של התחנה עד סמור לתחילתו                                               |
|                    |של חוק זה, יתן לו השר רשיון להפעלת התחנה לצורר שידורי מוסיקה, קטעי קישור                                            |
|                    |ופרסומת מסחרית (להלן - הרשיון); הרשיון הוא אישי ואינו ניתן להעברה.                                                  |
|תנאים ברשיון        |3. (א) השר רשאי לקבוע ברשיון תנאים בכל ענין הנוגע להפעלת התחנה, לרבות                                               |
|                    |בענינים אלה:                                                                                                        |
|                    |(1) מועדי השידורים;                                                                                                 |
|                    |(2) הסדרת שידורי פרסומת, לרבות היקפם, תדירותם ורמתם;                                                                |
|                    |(3) דרכי מימון.                                                                                                     |
|                    |(ב) השר רשאי לשנות את תנאי הרשיון או להוסיף עליהם גם אחרי שניתן                                                     |
|                    |הרשיון.                                                                                                             |

|(ג) תנאים כאמור בסעיפים קטנים (א) ו-(ב) ייקבעו באישור ועדת הכלכלה של                                                |אגרות ותמלוגים       |
|הכנסת.                                                                                                              |                     |
|4. השר, באישור ועדת הכלכלה של הכנסת, רשאי לקבוע אגרות ותמלוגים שישלם                                                |                     |
|בעל הרשיון לאוצר המדינה.                                                                                            |                     |
|5. לא תשדר התחנה דברי תעמולה מפלגתית ופוליטית, בין תעמולה ישירה ובין עקיפה.                                         |איסור שידורי         |
|                                                                                                                    |תעמולה מפלגתית       |
|                                                                                                                    |ופוליטית             |
|6. יראו את הרשיון כאילו ניתן גם לפי הוראות פקודת הטלגרף האלחוטי [נוסח חדש],                                         |תחולת פקודת          |
|התשל"ב-1972 1, ופקודת הדואר [נוסח חדש], התשל"ז-1976 2, והוראות הפקודות                                              |הטלגרף האלחוטי       |
|האמורות יחולו על הרשיון ועל בעל הרשיון, בשינויים המחריבים.                                                          |ופקודת הדואר         |
|7. השר ושר החינוך והתרבות רשאים לקבוע, באישור ועדת הכלכלה של הכנסת,                                                 |כללים וסייגים        |
|כללים וסייגים לשידורים, ולפקח עליהם.                                                                                |                     |
|8. השר רשאי לדרוש מכל אדם דיווח ומסירת מידע בכל הנוגע להפעלת התחנה                                                  |דרישת ידיעות         |
|ולניהולה.                                                                                                           |                     |
|9. השר רשאי לבטל את הרשיון במקרים אלה :                                                                             |ביטול הרשיון         |
|(1) בעל הרשיון חדל להפעיל את התחנה או לנהלה;                                                                        |                     |
|(2) הבעלות על ؀ࠂࠆࠈࠌ࠘ࠚהתחנה או על כלי השיט שעליו היא מותקנת הועברה                                                   |                     |
|ממי שבידיו היתה עד סמוך לתחילתו של חוק זה;                                                                          |                     |
|(3) לא קויימו הוראה מהוראות חוק זה או תנאי מתנאי הרשיון, או הופרו                                                   |                     |
|כללים או סייגים שנקבעו לפי סעיף 7.                                                                                  |                     |
|10. השר יתן את הרשיון לא יאוחר משבועיים מיום תחילת חוק זה.                                                          |מועד מתן             |
|                                                                                                                    |הרשיון               |
|11. תקפם של חוק זה והרשיון שניתן מכוחו יפקע עם תחילתו של חוק המסדיר                                                 |פקיעת החוק           |
|שידורי רדיו מתחנות שידור פרטיות.                                                                                    |והרשיון              |

|דברי הסבר                |

|הצעת החוק באה לאפשר לתחנת השידור "קול                           |
|השלום" לשדר מישראל.                                             |
|שר התקשורת יתן רשיון להפעלת התחנה למפעילה                       |
|הנוכחי.                                                         |
|השר יוסמך לקבוע ברשיון, באישור ועדת הכלכלה                      |
|של הכנסת, את התנאים להפעלת התחנה.                               |

|הרשיון יהיה אישי והוא יינתן תוך שבועיים מיום                        |
|תחילתו של החוק.                                                     |
|תוקפם של החוק ושל הרשיון יפקע עם תחילתו                             |
|של חוק כללי שיסדיר רשיונות לתחנות רדיו פרטיות                       |
|שישררו לציבור.                                                      |
