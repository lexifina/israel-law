|תיקון חוק נכסי       |1. חוק נכסי נפקדים, תש"'-1950 ' 1יתוקן כך:                                                       |
|נפקדים, תש"י-        |בסעיף 12, בסעיף קטן (ג), ייווספו משפטים אלה:                                                     |
|                     |"נקבעו כללים כאלה' רשאי האפוטרופוס לשנות את דמי השכירות שנקבעו                                   |
|                     |בכל חוזה שכירות כדי להתאימם אל אותם הכללים. לצורך. סעיף זה רואים                                 |
|                     |שינוי כזה של דמי השכירות כקביעת דמי השכירות בחוזה השכירות, ואת                                   |
|                     |דמי השכירות ששונו כך כדמי השכירות שנקבעו בחוזה השכירות".                                         |
|                     |דברי הסבר                                                                                        |
|                     |הצעת חוק זו באד. להסיר ספק שנתעורר אגב פירוש הסעיף 12 לחוק נכסי                                  |
|                     |נפקדים, תש"י-1950, הדן ؀ࠂࠊࠌבתחולתן של הפקודות להגבלת דמי שכירות על נכסים                         |
|                     |מוקנים. התיקון המוצע מבהיר כי הכללים ששר האוצר רשאי לקבוע בתקנות לפי                             |
|                     |סעיף 12 (ג) כוחם יפה אף לגבי חוזי שכירות קיימים, ועל כן אפשר להתאים אליהם                        |
|                     |גם את דמי השכירות שנקבעו כבר בחוזי שכירות כאלה.                                                  |
|                     |ספר החוקים 17; מיום ב' בניסן תש"י 20.3.50 ,עמ' 86.                                               |
