חוק להארכת תוקף של תקנות-שעת-חירום (בתי-חולים), תש"י-1950

|הארכת תוקף               |1. תקפן של תקנות שעת חירום (בתי-חולים), תש"ט - 1949, 1 מוארך בזה עד                                 |
|                         |יום כ"ב בטבת תשי"א (31 בדצמבר 1950).                                                                |
|תחילת תוקף               |2. תקפו של חוק זה הוא מיום י"ב באדר תש"י (1 במרס 1950).                                             |
|                         |ד ב ר י - ה ס ב ר                                                                                   |
|                         |לפי תקנות-שעת-חירום (בתי-חולים), תש"ט - 1949, שהותקנו בזמנו על ידי                                  |
|                         |ראש הממשלה, רשאי שר הבריאות ליטול לידיו הנהלת בית-חולים, או להסמיך אדם                              |
|                         |אחר לעשות זאת, אם שר הבריאות סבור שהדבר נחוץ לשם קיום השירותים                                      |
|                         |הרפואיים החיוניים, או אם רמת הטיפול בחולים בבית החולים היא, לדעת שר                                 |
|                         |הבריאות, למטה מן הרמה שהוא רואה אותה כמינימלית.                                                     |
|                         |כן מאפשרות התקנות הנ"ל לשר הבריאות, ולקציני בריאות שנתמנו על ידיו,                                  |
|                         |לתת לבעל בית-חולים הוראות בנוגע להנהלת בית-החולים ולסדריה ככל שיראו                                 |
|                         |לנחוץ או למועיל לשם קיום השירותים הרפואיים החיוניים.                                                |
|                         |תוקף התקנות הוארך על ידי הכנסת עד יום י"ב באדר תש''י (1 במרס 1950).                                 |
|                         |בשעת הדיון האחרון בכנסת בענין הארכת תוקף התקנות הנ''ל, הושמעה הדעה                                  |
|                         |שיש להחליף את התקנות בחוק של קבע. הממשלה שקלה אפשרות זו' והגיעה לכלל                                |
|                         |דעה כי הואיל והתקנות הנ"ל לא נועדו להיות אלא ؀ࠂࠊࠌהוראת שעה, אין להפכן, בצורתן                       |
|                         |זו, לחוק של קבע.                                                                                    |
|                         |הממשלה מכינה הצעת חוק כולל בענין בתי חולים שיובא לפני הכנסת.                                        |
|                         |הסמכויות הנתונות בידי שר הבריאות על פי התקנות הנ"ל ישולבו, במידה שיהיה                              |
|                         |צורך בכך, בהצעת החוק הכולל. הכנת הצעת החוק מצריכה זמן ממושך, ובינתיים                               |
|                         |עומד בעינו הצורך לקיים בידי שר הבריאות את הסמכויות הנתונות בידיו על פי                              |
|                         |התקנות, לפיכך מציעה הממשלה להאריך את תקפן עד סוף שנת 1950.                                          |
|                         |1 ע"ר מס' 41 מיום ו' בטבת תש''ט (7.1.48), תוס' ב', עמ' 107.                                         |
