חוק לתיקון פקודת מס הכנסה, תש"י-1950

|הכנסה, 1947 1, תתוקן על ידי החלפת הסעיף 74א בסעיף הבא:                        |1. פקודת מס ה         |תיקון פקורה             |
|74א. נציב מס הכנסה רשאי לדחות עד יום י"ג בניסן תש"י                           |"דחיית זקיפה          |                        |
|(31 במרס 1950) כל זקיפת מס לפי הסעיפים 32, 33, או 74                          |והחזרה של מס          |                        |
|וכל החזרת מס לסי סעיף 68 לפקודה זו."                                          |                      |                        |
|חוק זה הוא מיום י"ב בטבת תש"י (1 בינואר 1950).                                |2 תקפו של חוק         |תחיית תוקף              |
|ד ב ר י - ה ס ב ר                                                                                    |                        |
|מועצת המדינה הסכימה בשעתו לתת לשלטונות מס ההכנסה את הרשות לדחות                                      |                        |
|עד ליום 31.12.49 כל זקיפת מס וכל החזרת מס על חשבון דיוידנדה שבעלי המניות                             |                        |
|קיבלו מהחברות, ואשר המס עליה שולם לממשלה המנדטורית. הרשאה זו כלולה                                   |                        |
|בסעיף 74א לפקודת מס ההכנסה.                                                                          |                        |
|תיקון זה, שהקשה על בעלי המניות, היה הכרחי, כדי לאפשר במשא ומתן עם                                    |                        |
|ממשלת אנגליה את תביעת הסכומים שהממשלה המנדטורית קיבלה מהחברות ושלפי                                  |                        |
|החוק יש ؀ࠂࠊࠌלהחזירם לבעלי המניות.                                                                    |                        |
|בעת הניסוח של סעיף 74 הניחו, שהמשא ומתן ייגמר לפני סוף שנת 1949. כעת                                 |                        |
|יש להניח, שיימשך עוד זמן-מה.                                                                         |                        |
|הצעת התיקון באה, איפוא, להאריך את תוקף ההרשאה האמורה לשלושה חדשים                                    |                        |
|נוספים.                                                                                              |                        |
|יצויין ששלטונות המס לא השתמשו בסמכותם האמורה לדחייתו החזרתו או                                       |                        |
|זקיפתו של המס בכל אותם המקרים שבהם שולם מס ההכנסה על ידי החברה בתקופת                                |                        |
|המדינה.                                                                                              |                        |
