חוק לתיקון פקודת ועדות חקירה, תשי"א-1950

|פקודת ועדות חקירה1 תתוקן כך:                                                                       |וגילוח הפקירה     |
|בסעיף 5 אחרי פסקה (ט) תיווסף פסקה זו:                                                              |                  |
|"(י) למנות מבין חבריה ועדת-משנה שתהא מורכבת מאדם אחד או יותר,                                      |                  |
|ולהעניק לה את סמכויותיה לפי פסקות (א) עד (ט), כולן או מקצתן."                                      |                  |
|דברי הסבר                                                                                          |                  |
|פקודת ועדות חקירה קובעת כי ועדת חקירה רשאית להשתמש באותן סמכויות,                                  |                  |
|מן המנויות בסעיף 5 לפקודה, שפורשו בצו המנוי ; סמכויות אלה מאפשרות בידי                             |                  |
|הועדה -                                                                                            |                  |
|(א) להשיג ידיעות ולחקור עדים ;                                                                     |                  |
|(ב) לדרוש מעד הבא לפניה, שיישבע או שיצהיר בהן-צדק ;                                                |                  |
|(ג) לדרוש מאדם שיבוא ויעיד לפניה או ימציא לה מסמכים המצויים ברשותו;                                |                  |
|(ד) לקנוס עד שנדרש לבוא לפניה ולא עשה כן, ולחייבו בתשלום ההוצאות                                   |                  |
|שנגרמו עקב אי-הופעתו,                                                                              |                  |
|(ה) לקנוס אדם המסרב להעיד בשבועה או בהן-צדק ;                                                      |                  |
|(ו) להרשות נוכחותו של קהל בישיבותיה או למנוע זאת.                                                  |                  |
|המצב הקיים אינו מאפשר؀ࠂࠌࠎ לועדה להעביר מסמכויותיה לועדה משנה, על מנת                               |                  |
|לבצע את תפקידיה במהירות הדרושה והרצויה ; החוק המוצע בא למלא חסרון זה.                              |                  |

1 חוקי א"י, כרך א', פרק כ"א, עמ' 152.
