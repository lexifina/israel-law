חוק לתיקון פקודת מחלות בעלי-חיים, תש"י-1950

|1. פקודת מחלות בעלי-חיים' 1945;תתוקן כך:                                                        |תיקון פקודה        |
|בסעיף 2. בסעיף קטן (1):                                                                         |                   |
|(א) אחרי המלים "ותרנגולי הודו" שבסוף הגדרת המונח "עופות" ייווספו                                |                   |
|מלים אלו:                                                                                       |                   |
|"וביצי עופות אלה שהושמו במדגרה".                                                                |                   |
|(ב) אחרי הגדרת המונח "פקיד מחוז* תיווסף הגדרה זו:                                               |                   |
|"שחוט, ביחס לביצי עופות, פירושו - השמד".                                                        |                   |
|ד ב ר י - ה ס ב ר                                                                               |                   |
|פקודת מחלות בעלי חיים, 1945' מטילה חובה על בעלו של כל בעל חיים (כולל                            |                   |
|עופות)' הנגוע במחלה' להודיע על הדבר לשלטונות המוסמכים. הפקודה מעניקה                            |                   |
|סמכות לרשויות מסויימות להורות על שחיטת בעל חיים נגוע' ועל חיטוי המקום בו                        |                   |
|הוא מוחזק' ולאסור או להגביל שחיטת בעלי חיים נגועים.                                             |                   |
|הפקודה קובעת כי הממשלה תשלם פיצויים לבעלו של בעל חיים נגוע שנשחט                                |                   |
|לפי הוראות הפקודה' בשיעור מסויים משויו. השווי נקבע על ידי פקיד וטרינרי' אולם                    |                   |
|שר החקלאות רשאי ؀ࠂࠊࠌלקבוע סכומים מכסימליים לשווים של סוגים שונים של בעלי                        |                   |
|חיים.                                                                                           |                   |
|הפקודה מעניקה לרשויות מסויימות סמכות להכריז על שטחים מסויימים כעל                               |                   |
|שטחים נגועים, ומשהוכרז כאמור יחולו לגביהם הוראות זהירות שמטרתן למנוע                            |                   |
|את התפשטות המחלה.                                                                               |                   |
|הגדרת המונח "עופות* שבפקודה אינה כוללת ביצים במדגרה' גם אם התפתח                                |                   |
|בהן העובר. ביצים אלה עלולות להיות נגועות במחלה העוברת בירושה ויש צורר                           |                   |
|להכלילן במונח "עופות" בכדי להתיר את השמדתן בשעת הצורך ותשלום פיצויים                            |                   |
|עבור ביצים שהושמדו.                                                                             |                   |
|החוק המוצע:                                                                                     |                   |
|(1) בא להכליל במונח "עופות" גם ביצי דגירה כאמור.                                                |                   |
|(2) קובע כי המונח "שחוט" אשר בו משתמשים בפקודה כולל גם השמדת                                    |                   |
|ביצי דגירה.                                                                                     |                   |
|1 ע"ר מס' 1437 מיום 2-1.11.45, תוס1, עמ' 155.                                                   |                   |
