|2. כדי להסיר ספק נאמר בזה שמסמך ؀ࠂࠊࠌࠐ࠘ࠚשנעשה לפני שחוק זה נכנס לתקפו -                               |              |

|דברי הסבר                                                                                            |              |
|הסעיפים 17 ו-18 של פקודת העדות דנים בהוכחת כתיבתם וחתימתם של                                         |              |
|מסמכים שנערכו בחוץ לארץ כשהם נועדים לשימוש בישראל בכל ענין משפטי                                     |              |
|אזרחי.                                                                                               |              |
|סעיף 18 קובע שמסמכים אלו יכולים לשמש ראיה בישראל אם נעשו בפני נציג                                   |              |
|דיפלומטי או קונסולרי בריטי או שנעשו בפני נוטריון וחתימת הנוטריון אושרה על                            |              |
|ידי נציג דיפלומטי או קונסולרי בריטי.                                                                 |              |
|סעיף 17 הוציא מכלל זה את המסמכים שמקורם בארצות הקהיליה הבריטי,                                       |              |
|מסמכים אלה די להם שיהיו נעשים בפני נוטריון ציבורי, מושל, זקן שופטים או ראש                           |              |
|עיריה, ואין חתימות הפקידים הנ"ל זקוקות לאישור ע"י נציג דיפלומטי או קונסולרי.                         |              |
|מאחר שהטעמים שגרמו להבדל בתחוקה שוב אינם קיימים, מן הראוי הוא                                        |              |
|להשוות את החוק לגבי כל ארצות חוץ. לכן בא החוק המוצע לבטל את הסעיף 17.                                |              |
|מוצע כמו כן להכניס בסעיף 18 את השינויים הנובעים מביטול סעיף 17, ומהשינוי                             |              |
|בתוארי הנציגים הדיפלומטיים והקונסולריים הישראליים שאינם נופלים בד בבד                                |              |
|עם התוארים המקבילים של הנציגים הבריטיים.                                                             |              |
|השינויים המוצעים בסעיפים 19 ו-21 באים כתוצאה מהתיקונים הנ"ל,                                         |              |
|סעיף 2 של החוק המוצע בא כדי להסיר ספק העלול להתעורר ביחס לכשרם של                                    |              |
|המסמכים שנעשו בארצות הקהיליה הבריטית בלי אישור קונסולרי בתאריך הקודם                                 |              |
|להיכנס החוק המוצע לתקפו.                                                                             |              |
