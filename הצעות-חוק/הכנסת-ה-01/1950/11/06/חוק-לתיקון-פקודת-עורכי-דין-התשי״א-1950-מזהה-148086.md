חוק לתיקון פקודת עורכי-דין, תשי"א-1950

|תיקו! הפקודה    |1. פקודת עורכי-דין, 1938 1, תתוקן כך:                                                           |
|                |בסעיף 20, אחרי סעיף קטן (1), יבוא סעיף קטן זה:                                                  |
|                |,,(1א) המועצה המשפטית רשאית לפרסם, בצורה ובאופן שייראו לה, כל החלטה                             |
|                |שהחליטה בעקבות טענה שחקרה בה או חיוב בדין שעיינה בו על פי סעיף קטן                              |
|                |(1)."                                                                                           |
|                |דברי הסבר                                                                                       |
|                |סעיף 20 לפקודת עורכי-דין, 1938, מעניק למועצה המשפטית את הסמכות                                  |
|                |לחקור בכל טענה שטוענים נגד עורך-דין בדבר התנהגות מחפירה או בלתי הולמת                           |
|                |את מקצועו, וכן לעיין בפסק דין פלילי שניתן נגד עורך-דין על עבירה כל שהיא;                        |
|                |ואם לאחר מכן תמצא זאת המועצה לרצוי, לשם הגנת הציבור או שמו הטוב של                              |
|                |מקצוע עורכי-הדין, רשאית היא להזהיר את עורך-הדין, או לנזוף בו, או להפסיק את                      |
|                |התעסקותו במקצועו לתקופה מסויימת, או לצוות למחוק את שמו מפנקס עורכי-הדין.                        |
|                |לפי החוק הקיים אין המועצה רשאית לפרטם ברבים את ؀ࠂࠈהחלטותיה, אף אם היא                           |
|                |סבורה שטובת הציבור מחייבת זאת.                                                                  |
|                |התיקון המוצע בא להתיר למועצה המשפטית לפרסם ברבים את החלטותיה,                                   |
|                |כשתראה צורך בדבר.                                                                               |
