חוק לתיקון פקודת השותפויות, תש"י-1950

|1. פקודת השותפויות 1 תתוקן כך:                                                                           |תיקון             |
|אחרי סעיף 68 יווסף סעיף זה:                                                                              |הפקודה            |
|68 א(1) נפסד מסמך במשרד הרושט, רשאי הרושם לדרוש מהשותפות                                |"מסמכים         |                  |
|שאותו מסמך  נוגע לה, מכל אחד משותפיה, ממקבל נכסיה או                                    |שנפטרו          |                  |
|ממנהל עסקיה -                                                                           |                |                  |
|(א) להמציא לו, תוך שלושים יום מיום שנמסרה דרישה כאמור,                                  |                |                  |
|העתק מאותו מסמך, מאושר לפי סעיף קטן (6),                                                |                |                  |
|(ב) להראות לו, במועד שיקבע, כל נייר ומסמך של השותפות                                    |                |                  |
|הנוגע לאותו ענין, או לאפשר לאדם, שהורשה לכך על ידיו,                                    |                |                  |
|לעיין בניירות ובמסמכים כאלה,                                                            |                |                  |
|והם חייבים למלא אחרי הדרישה.                                                            |                |                  |
|(2) אישות בכתב של הרושם המעיד שמסמך פלוני נפסד, ישמש                                    |                |                  |
|ראיה חותכת על כך.                                                                       |                |                  |
|(3) העתק מאושר של מסמך שהומצא כאמור ושהרושם הסכים                                       |                |                  |
|לקבלו - ינהג בו הרושם כבמסמך שנפסד, אולם בהעתק ממנו שיוציא                              |                |                  |
|יציק שהוא העתק מהעתק מאושר שנתקבל כאמור.                                                |                |                  |
|(4) בכל פעולה משפטית יראו את ההעתק המאושר שנתקבל על ידי                                 |                |                  |
|הרושם כראיה לכאורה לתכנו של המסמך שנפסד.                                                |                |                  |
|(5) לצורך סעיף זה -                                                                     |                |                  |
|"מסמך" כולל גל כתב הנוגע לשותפות -                                                      |                |                  |
|(א) שהוגש לרושם בקשר עם רישום השותפות, או שהוגש                                         |                |                  |
|לו על ידי השותפות או על ידי אחד משותפיה, או על ידי                                      |                |                  |
|מקבל נכסיה, או מנהל עסקיה, או                                                           |                |                  |
|(ב) שנשלח על ידי ؀ࠂࠊࠌהרושם לשותפות, לאחד משותפיה,                                       |                |                  |
|למקבל נכסיה, או למנהל עסקיה, וכן העתק ממסמך כזה;                                        |                |                  |
|"מסמך נפסד" פירושו - מסמך שאבד או שנשחת עד שאינו ניתן                                   |                |                  |
|לקריאה שלמה.                                                                            |                |                  |
|(6) אישורו של העתק ממסמך יהיה על ידי אדם הרשאי לחתום בשם                                |                |                  |
|השותפות או על ידי מקבל נכסיה או מנהל עסקיה, הכל לפי הענין,                              |                |                  |
|אולם הרושם רשאי לדרוש שההעתק יאושר בדרך אחרת המניחה את                                  |                |                  |
|דעתו."                                                                                  |                |                  |
