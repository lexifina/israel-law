חוק הגנת העולה (שכירות משנה והארחה), תש"י-1949

|פירושים           |1. "עולה" פירושו - אדם שלא מלאו 12 חודש לישיבתו בארץ או 9 חדשים                                    |
|                  |מיציאתו ממחנה עולים בארץ, הכל לפי התאריך המאוחר יותר ;                                             |
|                  |"פקודת הדירות" פירושה - פקודת הגבלת שכר דירה (דירות), 1940 1;                                      |
|                  |"דירה" פירושה - דירה נפרדת כמשמעותה בפקודת הדירות.                                                 |
|היתר השכרה        |2. דייר המחזיק בדירה וחוזה השכירות שבינו ובין המשכיר אוסר עליו השכרת                               |
|                  |משנה או מטיל עליה הגבלות - רשאי להשכיר חלק מדירתו לעולה, על אף                                     |
|                  |האיסור או ההגבלה שבחוזה, ובלבד שנתמלאו תנאים אלה:                                                  |
|                  |(א) ההשכרה לעולה היתה בכתב ולשם מגורים בלבד ;                                                      |
|                  |(ב) הדייר מוסיף להשתמש בחלק מהדירה למטרה שלמענה שכרה;                                              |
|                  |(ג) ניתן היתר להשכרה מאת פקיד השכירות.                                                             |
|בקשה להיתר        |3, בקשה להיתר השכרה תוגש לפקיד השכירות בכתב, כשהיא חתומה בידי                                      |
|השכרה             |הדייר והעולה ומצורף לה החוזה שנחתם ביניהם.                                                         |
|טחן היתר          |4. (א) פקיד השכירות יתן היתר השכרה כאמור -                                                         |
|השכרה             |(1) אם שוכנע שנתמלאו התנאים לפי סעיף 2 (א) ו-(ב) ;                                                 |
|                  |(2) אם מצא ששכר הדירה המשתלם על ידי העולה אינו מביא לדייר                                          |
|                  |רווח בלתי הוגן בהתחשב עם שכר הדירה המשתלם על ידי הדייר ועם                                         |
|                  |הוצאותיו בקשר עם הדירה ;                                                                           |
|                  |(3) אם הצדדים הצהירו בכתב בפניו או בפני אדם שהורשה על ידיו                                         |
|                  |לקבל הצהרה כזו - שהתנאים שבחוזה המצורף לבקשתם, הם תנאי                                             |
|                  |השכירות האמיתיים ולא הותנה שום תנאי שונה או נוסף, ולא ניתנה או                                     |
|                  |הובטחה תמורה שונה או נוספת בכל צורה שהיא, אלא התמורה הקבועה                                        |
|                  |בחוזה בלבד.                                                                                        |
|                  |(ב) היתר השכרה יהיה בכתב ויפרט את הפרטים שהם יסוד למתן ההיתר,                                      |
|                  |כולל תנאי השכירות.                                                                                 |
|שינוי תנאי        |5. כל שינוי בתנאי מתנאי חוזה השכירות שבין הדייר ובין העולה טעון היתר חדש.                          |

|השכרה             |השכירות לפי סעיף 4 (א) (2) לחוק זה הוכחה מכרעת שהתמורה הקבועה בחוזה                                |

|וילדיו, וכן לגבי בגי משפחתו האחרים המנויים בחוזה השכירות שבינו ובין הדייר.                           |                     |
|(ג) העולה שהושכר לו חלק מדירה؀ࠂࠌࠎࠒ࠘ࠚ בהתאם להיתר, יהיה לו מעמד של דייר                               |                     |
|משבה כמשמעותו בפקודת הדירות.                                                                         |                     |
|7. (א) היתר שהושג על יסוד הצהרה כוזבת בנוגע לאחד הפרטים שהיו                                         |ביטול היתר           |
|יסוד למתן ההיתר - בטל מעיקרו.                                                                        |                     |

|המשכיר לו, חוזרים לתקפם.                                                                             |                     |
|8. (א) דייר המחזיק בדירה וחוזה השכירות שבינו ובין המשכיר אוסר עליו                                   |היתר הארחה           |

|ובלבד שניתן היתר הארחה מאת פקיד השכירות.                                                             |                     |
|(ב) פקיד השכירות יתן היתר הארחה על פי הצהרת הצדדים בכתב המפרטת                                       |                     |
|את חלק הדירה המיועד להארחה, את שמות המוארחים והמודיעה שאין בל תמורה                                  |                     |
|ניתנת בעד ההארחה.                                                                                    |                     |
|(ג) פקיד השכירות רשאי להגביל את היתר ההארחה לתקופה שתיראה לו.                                        |                     |
