חוק להארכת תוקף של תקנות-שעת-חירום
(עבירות תנועה - דין חיילים), תש"י - 1949

|הארכת  תוקף    |1. תקפן של תקנות-שעת-חירום (עבירות תנועה - דין חיילים), תש"ט-                                          |
|               |1949 1, מוארך בזה עד יום י"ג בניסן תש"י (31 במרס 1950).                                                |
|תוקף החוק      |2. תקפו של חוק זה הוא מיום י"א בטבת תש"י (31 בדצמבר 1949).                                             |
|               |דברי הסבר                                                                                              |
|               |תקנות-שעת-חירום (עבירות תנועה - דין חיילים) הותקנו בזמנו בקשר עם                                       |
|               |המבצע שפתח בו הצבא למניעת תאונות דרכים ("מבצע מרדכי").                                                 |
|               |תוקף התקנות' בשינויים מספר' הוארך על ידי הכנסת עד יום י"א בטבת                                         |
|               |תש"י (31 בדצמבר 1949).                                                                                 |
|               |הנסיון ؀ࠂࠊࠌהוכיח את תועלתן המרובה של התקנות והצורך בהן בעינו עומד.                                     |
|               |הממשלה מבקשת' איפוא, את הארכת תוקף התקנות לתקופה נוספת של                                              |
|               |שלושה חדשים.                                                                                           |
