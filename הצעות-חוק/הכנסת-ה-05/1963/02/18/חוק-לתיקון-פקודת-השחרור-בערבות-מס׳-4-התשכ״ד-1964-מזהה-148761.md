|מתפרסמת בזה הצעת חוק מטעם הממשלה:                       |

|חוק לתיקון פקודת השחרור בערבות (מס' 4), תשכ"ג-1963                                         |

|1, בסעיף 10 לפקודת השחרור בערבות. 1944 1, במקום סעיף קטן (3) יבוא:                                       |תיקון סעיף 10      |
|"(3) המצווה על שחרור בערבות רשאי להתנותו, בנוסף על התנאי                                                 |                   |
|בדבר הופעת המשוחרר בבית המשפט' גם בהפקדת סכום כסף במקום                                                  |                   |
|הערבות ובתנאים אחרים שימצא לנכון, לרבות הפקדת דרכונו, או תעודת                                           |                   |
|מסע אחרת, של המשוחרר; הותנו תנאים אחרים - יפורטו בשטר הערבות."                                           |                   |
|דברי-הסבר                                                                                                |                   |
|ספק הוא אם פקודת השחרור בערבות מאפשרת להתנות שחרור אדם בערבות בתנאים                                     |                   |
|נוספים על התנאי העיקרי (הופעת המשוחרר בערבות בבית המשפט) (ראה ב"ש 52/58,                                 |                   |
|פד"י, י"ב, 1259); כן נקבע כי שופט המצווה על שחרור אין לו סמכות להתנותו בהפקדת                            |                   |
|מזומנים, אף אם הוא סבור כי הדבר נחוץ, אלא אם הסכים לכך המשוחרר בערבות (ב"ש                               |                   |
|71/59 פד"י יג, 1288). ברוב המקרים לא נהגו؀ࠂࠌࠎ בתי המשפט להתנות תנאים נוספים לשחרור.                      |                   |
|גמישות בתחום זה הוא לטובת הענין. היא תרחיב את האפשרויות לצוות על שחרור                                   |                   |
|גם במקרים שערבות כמקובל היום לא תניח את דעת השופט, אף תבטיח יותר את מילוי                                |                   |
|התנאי העיקרי של צו השחרור.                                                                               |                   |

|1 ע"ר 1944, תוס' 1, מס' 1359, עמ' 57; ס''ח תש"ט, עמ' 294; ס"ח תשכ''ב, עמ' 36; תשכ"ב, עמ' 79.       |
