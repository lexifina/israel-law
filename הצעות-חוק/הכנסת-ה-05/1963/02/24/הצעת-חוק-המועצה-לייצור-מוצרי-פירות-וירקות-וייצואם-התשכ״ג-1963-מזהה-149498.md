|פרק ראשון: פרשנות                                                                                           |                   |
|1. בחוק זה -                                                                                                |הגדרות             |
|"פירות" - גידולים חקלאיים המפורטים בתוספת הראשונה;                                                          |                   |
|"ירקות" - גידולים חקלאיים המפורטים בתוספת השניה;                                                            |                   |
|"מוצרי פירות וירקות" - מוצרים המופקים מפירות או מירקות, ובכלל זה פירות וירקות                               |                   |
|מיובשים ומשומדים, בהוספת חמרים אחרים או בלעדיהם, והם מיועדים לאכילה                                         |                   |
|ולשתיה, למעט משקאות חריפים ומיצי ענבים;                                                                     |                   |
|"יצרן" - אדם שעסקו או חלק מעסקו הוא ייצור של מוצרי פירות או מוצרי ירקות או                                  |                   |
|בשינוי מוצרים אלה מבחינת הצורה, הטיב, האיכות או מכל בחינה אחרת שהיא?                                        |                   |
|"השר" - שר המסחר והתעשיה.                                                                                   |                   |
|פרק שני: המועצה; תפקידיה ומוסדותיה                                                                          |                   |
|2. תוקם מועצה לייצור מוצרי פירות וירקות וייצואם (להלן - המועצה).                                            |הקמת מועצת         |
|3. אלה תפקידי המועצה:                                                                                       |תפקידי המועצה      |
|(1) לתכנן את הייצור של מוצרי פירות וירקות?                                                                  |                   |
|(2) לתכנן, לכוון להסדיר ולרכז בידיה את קניות חמרי הגלם, חמרי עזר                                            |                   |
|והמרי אריזה הנחוצים לייצור מוצרי פירות וירקות ואת הספקתם ליצרנים;                                           |                   |
|(3) לתכנן את היצוא של מוצרי פירות וירקות, לכוונו ולרכזו ולהסדירו,                                           |                   |
|לרבות קביעת מכסות יצוא ליצרנים, סמל למוצרים אלה ודרכים לזיהוי היצרן?                                        |                   |
|(4) לקבוע מיפרטים של חמרי גלם ומוצרים וכן שמות למוצרים שמיפרטיהם                                            |                   |
|נקבעו כאמור;                                                                                                |                   |
|(5) לפקח ולהסדיר את הפיקוח על טיב המוצרים, ובכלל זה פיקוח על איכות                                          |                   |
|המוצרים, צורתם, טיב אריזתם וסימונם, ולקיים לשם כך מוסדות בקורת                                              |                   |
|ומעבדות ומנגנונים אחרים הדרושים לכך;                                                                        |                   |
|(6) לעודד ולסייע פיתוח הייצור של מוצרי פירות וירקות, השבחת שיטות                                            |                   |
|העיבוד, העלאת פריון העבודה, לכוון ולבצע פעולות מחקר בשיטות ייצור,                                           |                   |
|לפתח מוצרים חדשים, לדאוג למחקרי שווקים ולהכשרה מקצועית;                                                     |                   |
|(7) לקיים פרסומת בחוץ לארץ?                                                                                 |                   |
|(8) לייעץ לשר בכל הענינים הנוגעים לביצוע חוק זה;                                                            |                   |
|(9) ליזום ולארגן פעולות להגברת היצוא של מוצרי פירות וירקות וליצור                                           |                   |
|את התנאים הדרושים לכך.                                                                                      |                   |
|4 .המועצה היא תאגיד, כשר לכל זכות והתחייבות ולכל פעולה משפטית.                                              |המועצה תאגיד       |

|החוק המוצע בא להקים גוף ציבורי כאמור בשם המועצה לייצור מוצרי פירות וירקות                                    |
|ויצואם, המורכב ברובו מנציגי היצרנים שינהלו בעצמם את הענינים הנוגעים להם. כדי                                 |
|שהמועצה לא תיהפך לגוף של אינטרסנטים וכדי לשמור על עניני הכלל' מעניק החוק                                     |
|המוצע סמכויות פיקוח לממשלה על ידי -                                                                          |
|(א) מתן ייצוג לממשלה במועצה ובהנהלה' ומינוי היושב ראש וסגנו מכין נציגיה?                                     |

|במשותף עם שר האוצר' לשימוש בסמכויותיה החשובות כגון התקנת כללים להסדר ייצור                                   |
|השימורים או להטלת היטלים, קבלת הלוואות ומתן הלוואות ליצרנים, קביעת התקציב                                    |
