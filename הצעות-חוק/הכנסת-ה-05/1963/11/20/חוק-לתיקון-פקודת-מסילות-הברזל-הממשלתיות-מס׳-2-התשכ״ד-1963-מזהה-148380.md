|חוק לתיקון פקודת מסילות הברזל הממשלתיות (מס' 3), תשכ"ד-1963                                                                    |

|1 . בסעיף 20(2) לפקודת מסילות הברזל הממשלתיות, 1936  1,במקום הקטע המתחיל                                       |תיקון סעיף 20       |
|במלים "ונוסף לכך יהא גם צפוי" ועד סוף הסעיף הקטן יבוא: "ונוסף לכך קנס בשיעור                                   |                    |
|שייקבע על ידי שר התחבורה בתקנות ושלא יעלה על כפל אגרת הנסיעה; בתקנות כאמור                                     |                    |
|רשאי שר התחבורה לקבוע נסיבות בהן יהא אדם פטור מתשלום הקנס".                                                    |                    |
|דברי הסבר                                                                                                      |                    |
|סעיף 20 (2) לפקודת מסילות הברזל הממשלתיות, 1936 , מטיל קנס על כל נוסע ברכבת                                    |                    |
|ללא כרטיס, או המסרב להציגו לפקיד הרכבת שהורשה לכך. הסעיף האמור קובע גם את                                      |                    |
|שיעור הקנס' והוא 15 אגורות לגבי מי שנוסע במחלקה הראשונה' 10 אגורות במחלקה                                      |                    |
|השניה ו-5 אגורות במחלקה השלישית.                                                                               |                    |
|הוראות אלה אינן מתאימות כבר למציאות מכמה בחינות. ראשית אין כבר כיום                                            |                    |
|מחלקות ברכבת ישראל, שנית שיעור הקנס שנקבע בשנת 1936 הפך מזמן למגוחך                                            |                    |
|ואינו נמצא בשום יחס לאגרה המשתלמת תמורת הכרטיס. אגרה זו עצמה לא נקבעה בפקודה                                   |                    |
|בשיעור קבוע' אלא נקבעת מזמן לזמן בחוקי עזר.                                                                    |                    |
|החוק המוצע בא איפוא להעניק לשר התחבורה את הסמכות לקבוע בתקנות את שיעורי                                        |                    |
|הקנס שישתלם על נסיעה ללא כרטיס, ובלבד שהקנס לא יעלה על כפל אגרת הנסיעה.                                        |                    |
|על ידי כך יוכל השר לבסס את שיעורי הקנסות על מחירי הכרטיסים.                                                    |                    |
|מצד שני קורה לעתים, שתנאים אובייקטיביים בתחנה פלונית אינם מאפשרים לקהל                                         |                    |
|לרכוש כרטיסי נסיעה לפני עלותם לרכבת' כגון במקרה של דוחק יוצא מן הכלל על יד                                     |                    |
|הקופות. מוצע איפוא להסמיך את שר ؀ࠂࠊࠌהתחבורה לקבוע בתקנות את הנסיבות בהן יהא אדם                                |                    |
|פטור מתשלום הקנס' על אף שעלה לרכבת בלי לרכוש כרטיס.                                                            |                    |
|להלן נוסח ההוראה בפקודה הקיימת שחוק זה בא לתקנה.                                                               |                    |
|"20. (2) גל הנוסע בלי כרטיס או שאינו מראה או אינו מוסר את כרטיסו כאמור לעיל, יהא                               |                    |
|צפוי לשלם את אגרת הנסיעה בעד המרחק שנסע, או כשיש ספק בנוגע לתחנה או למקום שמשם                                 |                    |
|התחיל את נסיעתו, יהא צפוי לשלם את אגרת הנסיעה בעד המרחק מהתחנה או המקום שמשם                                   |                    |
|יצאו מלכתחילה הרכבת, אניית הקיטור או כל ספינה אחרת, ונוסף על כך יהא צפוי לשלם קנס                              |                    |
|בשיעור של מאה וחמישים פרוטה, אם נסע במחלקה הראשונה, או בשיעור של מאה פרוטה, אם                                 |                    |
|נסע במחלקה השניה, או בשיעור של חמישים פרוטה, אם נסע במחלקת השלישית, בתנאי שלעולם                               |                    |
|לא יעלה הקנס על אגרות הנסיעה גופן."                                                                            |                    |

|1 ע"ר 1936, תוס' 1 מס' 593, עמ' 169; ס"ח תשי"א, עמ' 226; ס"ח תשי"ח, עמ' 114.             |
