|מתפרסמת בזה הצעת חוק מטעם הממשלה:                                                                                             |
|חוק יום הזכרון לגבורי מלחמת הקוממיות וצבא-הגנה-לישראל,                                                                        |
|תשכ"ג-1963                                                                                                                    |

|1. (א) ד' באייר הוא יום זכרון גבורה ללוחמי מלחמת הקוממיות וצבא-הגנה לישראל                                 |ד' באייר           |
|שנפלו במערכה על הקמת מדינת ישראל ועל הבטחת קיומה, להתייחדות עם זכרם ולהעלאת                                |יום הזכרון         |
|מעשי גבורתם.                                                                                               |                   |
|(ב) היה ד' באייר חל בששי בשבוע, יקויים יום הזכרון ביום ב' באייר של אותה שנה;                               |                   |
|היה חל בחמישי בשבוע, יקויים יום הזכרון ביום ג' באייר של אותה שנה.                                          |                   |
|2. תחילתו של יום הזכרון היא משקיעת החמה אור ליום ד' באייר או ג' באייר או ב'                                |תחילתו של יום      |
|באייר, הכל לפי הענין, וסיומו עם צאת הכוכבים למחרתו.                                                        |הזכרון וסיומו      |
|3. ביום הזכרון תהא בכל רחבי המדינה דומיה של שתי דקות כהן תשבות כל עבודה                                    |דרכי קיום של       |
|ותיפסק כל תנועה בדרכים; יקויימו אזכרות, עצרות-עם וטכסי התייחדות במחנות צבא-                                |יום הזכרון         |
|הגנה לישראל ובמוסדות חינוך; הדגלים על הבנינים הציבוריים יורדו לחצי התורן? תכניות                           |                   |
|השידורים ברדיו יביעו אח ייחודו של היום.                                                                    |                   |
|4. (א) בערב יום הזכרון לא יקויימו כל עינוגים ציבוריים.                                                     |איסור עינוגים      |
|(ב) המשתמש בערב יום הזכרון במקום פלוני לעינוג ציבורי - דינו קנס.                                           |ציבוריים           |
|(ג) לענין חוק ؀ࠂࠊࠌזה "עינוג ציבורי" - כמשמעותו של שעשוע ציבורי בפקודת                                      |                   |
|השעשועים הציבוריים - 1935 1.                                                                               |                   |
|5, שר הבטחון, בהתייעצות עם המועצה הציבורית המייעצת שנתמנתה לענין חיק בתי                                   |הוראות לקיום       |
|קברות צבאיים, תש"י- 1959 2, רשאי להתקין הוראות לקיום יום הזכרון בהתאם לחוק זה.                             |יום הזכרון         |
|דברי הסבר                                                                                                  |                   |
|מאז שנת 1952 נהוג להקדיש את היום הקודם ליום העצמאות להתייחדות עם זכר                                       |                   |
|הגבורים שנפלו במערכה על תקומת המדינה ועל הבטחת קיומה.                                                      |                   |
|מוצע בזה לתת לנוהג זה גושפנקה של חוק. הטלת דומיה של שתי דקות שבהן תשבות                                    |                   |
|כל עבודה ותיפסק התנועה בדרכים, וכן הנפת דגלים ועריכת טכסי זכרון - יבטיחו קיום                              |                   |
|יום הזכרון בכל המדינה בצורה הולמת ואחידה.                                                                  |                   |
|בערב יום הזכרון ישבתו גם העינוגים הציבוריים.                                                               |                   |
