|חוק מועצת הרבנות הראשית (בחירות), תשכ"ג-1963                                          |

|1. הבחירות למועצת הרבנות הראשית ייערכו תוך ששה חדשים מיום שחוק זה ייכנס                                    |מועד הבחירות      |
|לתקפו' בתאריך שייקבע על ידי ועדת הבחירות בהתאם לתקנות הקובעות את שיטת הבחירות                              |למועצת הרבנות     |
|של מועצת הרבנות הראשית שיותקנו על ידי שר הדתות.                                                            |הראשית            |
|דברי הסבר                                                                                                  |                  |
|ביום כ"ט בשבט תשכ"א (15 בפברואר 1961) פורסם בספר החוקים 326' חוק מועצת                                     |                  |
|הרבנות הראשית (הוראת שעה)' תשכ"ב-1961' בזה הלשון:                                                          |                  |
|"הבחירות למועצת הרבבות הראשית ייערכו בתוף התקופה המתחילה בתום ששה חדשים מיום                               |                  |
|תחילת חוק זה ؀ࠂࠈוהמסתיימת כתום שנה אחת לאחר אותו יום."                                                     |                  |
|התאריך האחרון 15 בפברואר 1962 עבר' והבחירות לא נערכו' הואיל והגורמים השונים                                |                  |
|לא הגיעו לידי הסכם בקשר לסדרי הבחירות לפיהם תיבחר מועצת הרבנות הראשית.                                     |                  |
|היום סולקו המכשולים, ואופשרה עריכתן של הבחירות תוך התקופה המצויינת בהצעה.                                  |                  |
