|מתפרסמת בזה הצעת חוק מטעם ועדת הכספים של הכנסת:                                                                            |
|חוק מבקר המדינה (הוראת שעה), תשכ"ג-1963                                                                                    |

|1. לגבי הדין וחשבון של מבקר המדינה לשנת הכספים 1961/62 תוארך התקופה הקבועה                                 |הארנת מוקד      |
|בסעיף 16 לחוק מבקר המדינה' תשי"ח-1958 ננוסח משולב] 1, עד ליום כ"ג בניסן תשכ"ג                              |                |
|(17 באפריל 1963).                                                                                          |                |
|דברי הסבר                                                                                                  |                |
|סעיף 16 לחוק מבקר המדינה, תשי"ח-1958 ננוסח משולב], קובע כי שר האוצר יעיר את                                |                |
|הערותיו לדין וחשבון של מבקר המדינה תוך ששה שבועות מהיום שבו קיבל את הדין                                   |                |
|וחשבון, וכי כתום מועד זה יונח הדו"ח על שולחן הכנסת.                                                        |                |
|בשלוש השנים האחרונות האריכה הכנסת מדי שנה - על פי הצעת ועדת הכספים -                                       |                |
|את המועד שניתן לשר האוצר להגשת הערותיו, וכן את המועד להנחת סיכומיה והצעותיה                                |                |
|של הועדה לדין וחשבון על שולחן הכנסת.                                                                       |                |
|אף בחוק זה מציעה ועדת הכספים להאריך את המועד הניתן לשר האוצר להגיש                                         |                |
|הערותיו - הפעם לדין ؀ࠂࠊࠌוחשבון לשנת הכספים 1961/62 - עד ליום כ"ג בניסן תשכ"ג (17                           |                |
|באפריל 1963) במקום יום ו' בניסן תשכ"ג (31 במרס 1963).                                                      |                |
|יש בדעת ועדת הכספים - בהסכמת מבקר המדינה - להגיש לכנסת הצעת תיקון                                          |                |
|לחוק מבקר המדינה, לפיה יוקדם, דרך קבע, המועד להגשת הדין וחשבון של מבקר המדינה                              |                |
|לשר האוצר בארבעה שבועות. במקביל לכך יוארך המועד להערותיו של שר האוצר                                       |                |
|בארבעה שבועות, באופן שהדין וחשבון יונח על שולחן הכנסת לא יאוחר מיום 31 במרס של                             |                |
|כל שנה, שהוא המועד הקבוע בחוק הקיים.                                                                       |                |

|1 ס"ח 248, תשי"ח, עמ' 92.           |
