|מתפרסמת בזה הצעת חוק מטעם הממשלה:                                                                                       |
|חוק המקדמה (פרעון חובות במטבע-חוץ), תשכ"ג-1963                                                                          |

|1. הממשלה מורשית בזה לקבל מבנק ישראל (להלן - הבנק) והבנק מורשה בזה לתת                                       |מילווה לממשלה      |
|לממשלה מילווה בסכום שלא יעלה על 50 מיליון דולר של ארצות הברית של אמריקה                                      |מבנק ישראל         |
|למימון פרעון מוקדם של חובות-חוץ של המדינה.                                                                   |                   |
|2 .תנאי המילווה ומועדי פרעונו ייקבעו בהסכם בין שר האוצר לבין נגיד הבנק באישורה                               |תנאי המילווה       |
|של ועדת הכספים של הכנסת.                                                                                     |                   |
|דברי הסבר                                                                                                    |                   |
|החוק המוצע בא לאפשר למדינה לקבל מילווה במטבע-חוץ מבנק ישראל לשם מימון                                        |                   |
|פרעון מוקדם של חובות חוץ של המדינה ששיעור הריבית עליהם גבוה' ועל ידי כך להביא                                |                   |
|לחסכון בתשלום ריבית במטבע-חוץ.                                                                               |                   |
|לפי סעיף 45 לחוק בנק ישראל, תשי"ד-11954 1,על הממשלה לפרוע מקדמות שניתנו                                      |                   |
|לה על ידי הבנק לפני תום שנת הכספים שבה ניתנו. על פי החוק המוצע תאופשר החזרת                                  |                   |
|המקדמה ؀ࠂࠊࠌבמשך תקופה ארוכה יותר שתיקבע בהסכם בין שר האוצר לבין נגיד בנק ישראל                               |                   |
|באישור ועדת הכספים של הכנסת.                                                                                 |                   |
