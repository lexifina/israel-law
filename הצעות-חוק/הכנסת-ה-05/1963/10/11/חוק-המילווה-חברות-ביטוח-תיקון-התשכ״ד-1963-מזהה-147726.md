|1. בסעיף 2 לחוק המילווה (חברות ביטוח), תשכ"ג-1962 1, במקום "50 מיליון לירות"                               |תיקון סעיף 2       |
|יבוא "100 מיליון לירות".                                                                                   |                   |
|דברי הסבר                                                                                                  |                   |
|חוק המילווה (חברות ביטוח), תשכ"ג-1962, מרשה את הממשלה לקבל מחברות                                          |                   |
|ביטוח' העוסקות בישראל בביטוח חיים צמוד, מילווה בסכום כולל שלא יעלה על 50 מיליון                            |                   |
|לירות, ולשלם בעד המילווה ריבית של 6% לשבה.                                                                 |                   |
|לאחרונה גדלו כהרבה סכומי הפוליסות של ביטוח חיים צמוד, ויש להניח כי בשבת                                    |                   |
|1963 בלבד יערכו פוליסות של ביטוח חיים בסכום העולה על 200 מיליון לירות. הגידול                              |                   |
|בהיקף הביטוח מגדיל גם את קרנות הביטוח שיש להשקיען. מוצע איפוא להגדיל את הסכום                              |                   |
|שהממשלה מורשית ללוותו לפי החוק העיקרי כדי לקלוט השקעות אלה.                                                |                   |
|מאחר שהפרמיות משתלמות לחברות תוך תקופה של 5 עד 40 שנה, לפי תקופת הפו-                                      |                   |
|؀ࠂࠊࠌליסה' והחוק חל על קרנות הנובעות מפוליסות הנקשרות במשך 10 שבים החל בשבת 1962,                           |                   |
|תקבל המדיבה את סכום המילווה במשך תקופה של 50 שבה מתחילת תקפו של החוק העיקרי.                               |                   |
