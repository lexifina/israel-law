|1. על אף האמור בסעיף 6 (ב) לחוק חסכון חובה' תשכ"ב-1962 1, יוחזרו הפרשי                                    |הוראה מיוחדת      |
|הצמדה המגיעים לפי הסעיף האמור עם תשלוט החלק האחרון של החסכון.                                             |                  |
|דברי הסבר                                                                                                 |                  |
|סעיף 6 (ב) לחוק חסכון חובה, תשכ"ב-1962, קובע לאמור:                                                       |                  |
|"החסכון והריבית עליו יהיו צמודים למדד יוקר המחיה ; התברר בעת החזרתו של חלק פלוני                          |                  |
|מהחסכון והריבית עליו כי המדד החדש עולה על המדד היסודי, יוחזרו אותו חלק והריבית עליו                       |                  |
|כשהם מוגדלים באופן יחסי לשיעור העליה של המדד החדש."                                                       |                  |
|סעיף 11 (א) לחוק האמור קובע' כי החסכון יוחזר יחד עם הריבית בארבעה שיעורים                                 |                  |
|שנתיים שווים.                                                                                             |                  |
|מכאן, שעל פי החוק הקיים יש להחזיר מדי שנה לא רק רבע מסכום החסכון                                          |                  |
|והריבית החל עליו, אלא גם את הפרשי ההצמדה החלים לגביו. הוברר שתשלום הפרשי                                  |                  |
|ההצמדה מדי שנה ؀ࠂࠌࠎכרוך בהוצאות ניכרות ומוצע עתה לקבוע כי תשלומי ההצמדה ישולמו                            |                  |
|בבת אחת עם החזרתו של השיעור האחרון של החסכון.                                                             |                  |
