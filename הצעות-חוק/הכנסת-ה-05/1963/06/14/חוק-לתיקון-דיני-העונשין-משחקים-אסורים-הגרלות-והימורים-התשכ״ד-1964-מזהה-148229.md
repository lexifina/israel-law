|                  |"משחק אסור" - משחק שבו עשוי אדם לזכות נכסף או כשווה כסף, לפי תוצאות המשחק,                                |
|                  |והתוצאות תלויות יותר בגורל מאשר בהבנה או ביכולת;                                                          |

|                  |לציבור ובין שהם פתוחים לבני-אדם מסויימים בלבד, ואין נפקא מינה אם הם מוחזקים                               |
|                  |גם למטרה אחרת;                                                                                            |
|                  |"הגרלה" - כל תכנית או תחבולה שלפיהן ניתן לזכות ככספים, בנכסים או בזכויות, כשה-                            |

|                  |זכיה תלויה כניחושו של דבר.                                                                                |

|9.  לענין חוק זה -                                                                                       |חזקות             |
|(1) רואים את הנמצא במקום משחקים אסורים כאילו הוא משחק בו משחק                                            |                  |

|(3) רואים חצרים כמקום שרגילים לערוך בהם משחקים אסורים, אם נערך                                           |                  |
|בהם משחק אסור לפחות שתי פעמים תוך ששה חדשים, כל עוד לא הוכח ההיפך,                                       |                  |
|ואין נפקא מינה אם הנאשם בהחזקתם החזיק בהם כל תקופה זו ואם מקצתה.                                         |                  |
