|1. במקום סעיף 14 לחוק שירות בטחון [נוסח משולב], תשי"ט-1959  1(להלן - החוק                                      |החלפת סעיף 14      |
|העיקרי)' יבוא:                                                                                                 |                   |
|14. אדם שבתקופת שירותו הסדיר היה כלוא בשל עבירה על פי פסק דין                             |''זמן השירות         |                   |
|של בית דין צבאי או של בית משפט אחר' או על פי פסק של קצין שיפוט,                           |לנעדר מן השירות      |                   |
|וכן אדם שנעדר מן השירות שלא כדין או שנעדר ברשות שהושגה                                    |                     |                   |
|בטענות כוזבות, ונענש על כך כדין - אין רואים את תקופת כליאתו                               |                     |                   |
|ולא את תקופת העדרו' לענין חישוב זמן השירות' כתקופה שבה מילא                               |                     |                   |
|חובת שירות סדיר' אלא אם הורה בית הדין הצבאי, בית המשפט או                                 |                     |                   |
|קצין השיפוט הוראה אחרת."                                                                  |                     |                   |
|2. במקום סעיף 23 לחוק העיקרי יבוא:                                                                             |החלפת סעיף 23      |
|23. יוצא-צבא אשר בהיותו בשירות מילואים היה כלוא בשל עבירה                                 |"זמן השירות          |                   |
|על פי פסק דין של בית דין צבאי או של בית משפט אחר, או על פי פסק                            |במילואים לנעדר       |                   |
|של קצין שיפוט' וכן אדם שנעדר מן השירות שלא כדין או שנעדר                                  |מן השירות            |                   |
|ברשות שהושגה על סמך טענות כוזבות, ונענש על כך כדין-אין רואים                              |                     |                   |
|את תקופת כליאתו ולא את תקופת העדרו, לענין חישוב זמן השירות,                               |                     |                   |
|כתקופה שבה מילא חובת שירות מילואים, אלא אם הורה בית הדין                                  |                     |                   |
|הצבאי' בית המשפט או קצין השיפוט הוראה אחרת."                                              |                     |                   |
|דברי הסבר                                                                                                                          |
|החוק המוצע בא להכניס בחוק הקיים שני שינויים לגבי דינה של היעדרות מן השירות                                                         |
|שיש בה כדי עבירה:                                                                                                                  |
|א. לפי סעיפים 14 ו-23 לחוק שירות בטחון, תשי"ט-1959 ננוסח משולב], אין                                                               |
|מביאים בחשבון תקופת השירות הצבאי שחייל חייב בה, כל תקופה שהיה כלוא על פי                                                           |
|פסק דין של בית דין צבאי או של בית משפט. עד ליום 1 בינואר 1956, הוא יום תחילת תקפו                                                  |
|של חוק השיפוט הצבאי, תשט"ו-1955' היה אותו דין חל גם על תקופת מחבוש שנגזרה                                                          |
|על ידי קצין שיפוט؀ࠂࠊࠌࠐࠔࠖࠚ (בג"צ 94/55, פד"י ט', עמ' 1118). אך לפי הבדל נוסח שבין חוק                                               |
|השיפוט הצבאי, תשט"ו-1955, לבין חוקת השיפוט תש"ח, אין דין זה חל על תקופה שחייל                                                      |
|היה חבוש על פי פסק של קצין שיפוט.                                                                                                  |
|מאחר שגם תקופת המחבוש שהוטל על ידי קצין שיפוט מפחיתה את הזמן בו ניתן                                                               |
|לאמן חייל במסגרת יחידתו ואימונו של החייל, בין שהוא בשירות סדיר ובין שהוא                                                           |
|בשירות מילואים נמצא חסר, מוצע כי לענין התקופה שאין רואים אותה כתקופת שירות                                                         |
|יהיה דין המחבוש המוטל על ידי קצין שיפוט כדין המאסר המוטל על ידי בית דין צבאי                                                       |
|או בית משפט.                                                                                                                       |
