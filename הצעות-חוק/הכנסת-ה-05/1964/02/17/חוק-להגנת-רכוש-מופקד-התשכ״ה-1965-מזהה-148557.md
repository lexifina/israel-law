|מתפרסמות בזה הצעות חוק מטעם הממשלה:                                                                                  |
|חוק להגנת רכוש מופקד, תשכ"ד-1964                                                                                     |

|1. בחוק זה -                                                                                                     |הגדרות              |
|"האפוטרופוס הכללי'י - כמשמעותו בפקודת האפוטרופוס הכללי' 1944 1;                                                  |                    |
|"נכס" - מקרקעין ומיטלטלין, וכן זכויות וטובות הנאה מכל סוג שהוא.                                                  |                    |
|2. היה נכס בהנהלתו או בשליטתו של אדם על-פי הרשאה או מינוי או בחזקת נאמן,                                         |חובת הורעה על       |
|ועברו עשר שנים מיום ההרשאה' המינוי או תחילת הנאמנות' ימסור האדם הודעה בכתב על                                    |טיפול בנכס          |
|כך לאפוטרופוס הכללי.                                                                                             |                    |
|3, ההודעה תכלול את תיאור הנכס' שם בעליו ומענו הידוע לאחרונה' וכן פרטים על                                        |תוכן ההודעה         |
|קיום הקשר בין האדם החייב בהודעה ובין בעל הנכס.                                                                   |                    |
|4. ההודעה תימסר תוך שלושה חדשים מיום מלאות עשר שנים כאמור בסעיף 52 אך אם                                         |זמן ההודעה          |
|מלאו עשר השנים לפני תחילתו של חוק זה. תימסר ההודעה תוך שלושה חדשים מיום                                          |                    |
|תחילתו של החוק.                                                                                                  |                    |
|5, העובר על סעיף 2. דינו - קנס 2000 לירות, ו-500 לירות נוספות לכל חודש שבו                                       |דינו של העובר       |
|נמשכת העבירה.                                                                                                    |על סעיף 2           |
|6, (א) לא תירשם בפנקס מקרקעין, או בכל פנקס אחר המתנהל על פי חיקוק, פעולה                                         |פסילת מינוי או,     |
|שתקפה תלוי ברישום, אם צד לפעולה מיוצג על ידי ממונה או על ידי מורשה על פי הרשאה                                   |؀ࠂࠊࠌהרשאה מיושנים   |
|הניתנת לחזרה' ומיום המינוי או ההרשאה עברו עשר שנים, אלא אם הוגשה בכתב הסכמת                                      |                    |
|הממנה או המרשה לפעולה ולא עברה שנה מיום מתן ההסכמה' או אם בית המשפט התיר                                         |                    |
|את הרישום.                                                                                                       |                    |
|(ב) אין הוראות סעיף זה באות להכשיר כל פגם בהרשאה, במינוי או בפעולה המונע                                         |                    |
|את הרישום על פי כל דין אחר.                                                                                      |                    |
|7. הוראות חוק זה לא יחולו על מורשה או ממונה או נאמן הפועלים מכוח חיקוק או                                        |פטורים מתחולת       |
|מטעם בית המשפט.                                                                                                  |החוק                |
|8, שר המשפטים ממונה על ביצוע חוק זה והוא רשאי להתקין תקנות בכל ענין הנוגע                                        |ביצוע ותקנות        |
|לביצועו.                                                                                                         |                    |
|דברי-הסבר                                                                                                        |                    |
|מצוי במדינה רכוש השייך לאנשים שנספו בחוץ-לארץ והוא מוחזק או מתנהל על-ידי                                         |                    |
|אחרים בתוקף הרשאות שקיבלו פעם מהבעלים או עקב יחסי אמון ששררו פעם בין הבעל                                        |                    |
|האמיתי ובין המחזיק. בימי השלטון העותמני ובתקופת המנדט היה אדם נאלץ לפעמים                                        |                    |
|להציג את רכושו כרכוש בעלים מדומים כדי להתגבר על קשיים מדיניים או משפטיים'                                        |                    |
|בארץ ישראל או בארצות חוץ. השואה ותהפוכות מדיניות הביאו לכך, שעקבותיהם של רבים                                    |                    |
|מן הבעלים האמיתיים נעלמו או שחדל כל קשר תקין אתם, ולפעמים ניצלו המורשים את                                       |                    |
|הדבר לרווחם הפרטי. כדי למנוע ניצול כזה מוצע לפסול הרשאות שעבר זמן רב מיום                                        |                    |
|נתינתן ולחייב אנשים המטפלים ברכוש הזולת על-פי הרשאות מסוג זה להודיע על כך                                        |                    |
|לאפוטרופוס הכללי כדי לאפשר לו פיקוח על הרכוש.                                                                    |                    |

|. ע"ר 1944, תוס' 1 מסי 1380 ,עמ' 110,                |
