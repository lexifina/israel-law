|דברי הסבר                                                                                                     |               |
|תקנות ההגנה (כספים)' 1941/ הן הבסיס החוקי לפיקוח על מטבע-חוץ. מאז התקנתן                                      |               |
|הוכנסו בהן מספר שינויים כדי להתאימן לצרכי המדינה. תקפן הוארך מדי פעם בפעם                                     |               |
|ולאחרונה - בחוק לקיום תוקף של תקנות ההגנה (כספים), תשכ"ג-1963 - עד כ"ב באב                                    |               |
|תשכ"ד (31 ביולי 1964). מוצע להאריך תקפן לשלוש שנים נוספות עד כ"ג בתמוז תשכ"ז                                  |               |
|(31 ביולי 1967) (סעיפים 1 ו-3).                                                                               |               |
|תקנה 6 (6) לתקנות האמורות קובעת, כי הכנסה שנתקבלה בישראל רק מחמת החיוב                                        |               |
|להעבירה שבתקנות' תהא פטורה ממס הכנסה אם אינה עולה על 25 לירות. עלתה על 25                                     |               |
|לירות' תהא חייבת במס, אך אם הופקדה בבנק מורשה או הושקעה בניירות ערך רשומים                                    |               |
|בבורסה וניירות ערך אלה הופקדו ؀ࠂࠊࠌבבנק מורשה' רואים את ההכנסה כאילו נתקבלה ביום                               |               |
|שהוצאו הכספים מן הבנק או ביום שהוצאו ניירות הערך. בתקנה זו אין צורך עוד, מאחר                                 |               |
|שלפי סעיף 14 לפקודת מס הכנסה רשאי שר האוצר לתת פטור או הנחה ממס על הכנסה                                      |               |
|של תושב ישראל שמקורה מחוץ לישראל והמס משתלם עליה רק משום שנתקבלה בישראל,                                      |               |
|ובהתאם לסעיף זה ניתן צו בדבר הנחה ממס הכנסה לתושב המעביר הכנסה כאמור                                          |               |
|(קובץ התקנות 1504 ,תשכ"ד, עמ' 151). לכן מוצע לבטל את הוראות תקנה 6(6) האמורה                                  |               |
|(סעיף 2).                                                                                                     |               |
