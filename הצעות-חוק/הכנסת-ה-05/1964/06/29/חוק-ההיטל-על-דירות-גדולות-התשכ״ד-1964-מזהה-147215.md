|מתפרסמות בזה הצעות חוק מטעם הממשלה:                       |

|חוק ההיטל על דירות גדולות, תשכ"ד-1964                                   |

|1. בחוק זה יהא לכל מונח המשמעות שיש לו בפקודת בנין ערים, 1930  1 (להלן -                                    |פרשנות          |
|הפקודה)/ והוא כשאין כוונה אחרת משתמעת.                                                                      |                |
|2. (א) מי שניתן לו לפי הפקודה רשיון לבניית דירה ששטחה ברוטו עולה על מאה                                     |הטלת היטל       |
|עשרים וחמישה מטרים מרובעים, ישלם - יחד עם אגרת הרשיון שעליו לשלם מכוח                                       |                |
|סעיף 4(1) לפקודה-היטל בניה לכל מטר מרובע העודף על מאה עשרים וחמישה מטרים                                    |                |
|מרובעים ברוטו (להלן-היטל בניה); היטל הבניה יהיה לכל אחד מעשרים וחמישה המטרים                                |                |
|המרובעים הראשונים של עודף כאמור - 100 לירות, ולכל מטר מרובע נוסף-150 לירות.                                 |                |
|כספי ההיטל יועברו לקופת הרשות המקומית שבתחומה נמצאת הדירה/ וישמשו קרן מיוחדת                                |                |
|לחיסול מבנים מסוכנים ומשכנות עוני.                                                                          |                |
|(ב) לענין סעיף זה -                                                                                         |                |
|(1) שטח ברוטו - שטח הרצפות כפי שנקבע לענין רשיון הבניה;                                                     |                |
|(2) כל עודף שאינו מגיע למטר מרובע ייחשב כמטר מרובע;                                                         |                |
|(3) דירה - מערכת חדרים שנועדה לפי תכנית בנין עיר' או לפי רשיון                                              |                |
|הבניה' למגוריה של משפחה' יחד עם חדרי השירות שלה' פרוזדוריה ומרפסותיה;                                       |                |
|(4) אין נפקא מינה אם רשיון הבניה ניתן לדירה הנדונה במיוחד או אם ניתן                                        |                |
|למבנה שהדירה הנדונה נועדת להיות חלק ממנו.                                                                   |                |
|3 . בטל רשיון בניה שניתן לפי הפקודה ולא הוקמה הדירה' יוחזר היטל הבניה ששולם                                 |החזרת היטל      |
|בקשר אתו.                                                                                                   |                |
|4. כספי היטל הבניה יוצאו קודם לכל לחיסול מבנים מסוכנים ומשכנות עוני בדרך                                    |יעוד ההיטל      |
|שתיקבע בתקנות, ולשיקום דייריהם, ؀ࠂࠌࠎࠒࠖ࠘בשטח בנין עיר שבו נגבה ההיטל; נשאר עודף                              |                |
|בשנת כספים פלונית - יוצא למטרות אלה במקומות אחרים, בדרך שתיקבע על ידי שר                                    |                |
|הפנים, בהסכמת שר האוצר ושר השיכון.                                                                          |                |
|5. אלה פטורים מתשלום היטל הבניה;                                                                            |פטור            |
|(1) ארגון האומות המאוחדות;                                                                                  |                |
|(2) מדינת חוץ, בדירות המשמשות לצרכי משרדיה או נציגותה בישראל;                                               |                |
|(3) מוסדות ציבור.                                                                                           |                |
|6 . שר הפנים ממונה על ביצוע חוק זה.                                                                         |ביצוע           |

|דברי הסבר                                                                                                    |
|החוק המוצע בא לסייע לפתרון בעיית שיכונם של דיירים במשכנות עוני.                                              |
|מוצע להטיל על מי שידו מגעת לבנות לעצמו דירת מגורים רחבת ידים ומפוארת,                                        |
|חובה לתרום לחיסולן של משכנות העוני. ההיטל יחול על בעלי דירות חדשות ששטחן                                     |
|ברוטו עולה על 125 מ"ר. ככל שהשטח יגדל ממינימום זה - יגדל ההיטל, בשיעור של 100                                |
|לירות לכל מטר מרובע עד 150 מ"ר ובשיעור של 150 לירות לכל מ"ר נוסף. הסכומים שיתקבלו                            |
|מההיטל יעמדו תהילה לרשותה של העיריה או של המועצה המקומית שבתחומה נבנתה                                       |
|הדירה' והעודף - אם יהיה - יועבר לקרן ארצית שתאזן את הצרכים ברשויות מקומיות                                   |
|הזקוקות במיוחד לשיקום.                                                                                       |
