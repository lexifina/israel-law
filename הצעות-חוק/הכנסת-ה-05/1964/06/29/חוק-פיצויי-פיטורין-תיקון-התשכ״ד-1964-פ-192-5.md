|דברי הסבר                                                                                                   |                   |
|סעיף 7 לחוק פיצויי פיטורים, תשכ"ג-1963, קובע, כי עובדת שילדה והתפטרה                                        |                   |
|מעבודתה תוך תשעה חדשים מיום הלידה על מנת לטפל בילד' רואים את התפטרותה כפי-                                  |                   |
|טורים והיא זכאית לפיצויים.                                                                                  |                   |
|בהוראה זו הכיר המחוקק' כי בתשעת החדשים הראשונים לחייו זקוק התינוק במיוחד                                    |                   |
|לטיפולה של האם ויש לאפשר לה את ההתמסרות לשם טיפול זה על ידי הבטחת הפיצויים.                                 |                   |
|מאחר שבשנים האחרונות רב מספרן של הנשים המאמצות ילדים - יש להשוות את מעמדן                                   |                   |
|לנשים יולדות' ולהעניק להן את הזכות לפרוש מן העבודה כדי ؀ࠂࠌࠎלהקדיש עצמן לטיפול                               |                   |
|בתינוק שהוא כילדן לכל דבר.                                                                                  |                   |
