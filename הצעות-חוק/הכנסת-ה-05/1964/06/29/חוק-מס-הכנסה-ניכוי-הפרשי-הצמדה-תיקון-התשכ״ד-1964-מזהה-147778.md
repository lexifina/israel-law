|               |"קרוב לבעל השליטה בו" יבוא "יחיד שהוא אחד מבעלי השליטה בו כאמור בסעיף 76                                   |
|               |לפקודה' או קרוב שלו".                                                                                      |
|               |דברי הסבר                                                                                 |                 |
|               |לפי סעיף 2 של התוספת לחוק הנדון, לא ינוכו מהכנסתו החייבת במס של נישום                                      |
|               |הפרשי הצמדה ששילם על הלוואתו' אם המלווה הוא קרובו או שותפו' ובמקרה שהלווה                                  |
|               |הוא חבר-בני-אדם - אם המלווה הוא קרובו של בעל השליטה באותו חבר-בני-אדם,                                     |
|               |שכמוהו כקרובו של הלווה.                                                                                    |
|               |מטרת הוראות אלה היא למנוע ניכויים של הפרשי הצמדה על הלוואות שיש בהן                                        |
|               |חשש שאינן אלא הלוואת אדם לעצמו.                                                                            |
|               |אולם נשמטו המלים הבאות למנוע ניכויים אלה גם במקרה של הלוואה עצמית ממש'                                     |
|               |כגון שבעל השליטה בחבר-בני-אדם נותן הלוואה לעצמו' כיחיד.                                                    |
|               |החוק המוצע בא למלא את החסר.                                                                                |
|               |וזה לשון החוק והתוספת לענין הנדון:                                                                         |
|               |1. בחוק זה -                                                                              |"הגדרות          |
|               |"הלוואה" - הלוואה שנתקיימו בה כל אלה:                                                     |                 |
|               |(1) נתקבלה ביום הקובע או לפניו ונפרעה, כולה או מקצתה, לאתר אותו יום;                      |                 |
|               |(2) משמשת למקבלה בהשגת הכנסה לפי סעיף 2(1) לפקודת מס הכנסה (להלן -                        |                 |
|               |הפקודה) בתעשיה' בתחבורה' בחקלאות ובכלל זה בתי ؀ࠂࠊࠌאריזה של תוצרת חקלאית'                  |                 |
|               |בבניה או בכית מלון;                                                                       |                 |
|               |(3) נותן ההלוואה אינו נמנה עם המפורטים בתוספת;                                            |                 |

|               |2. יחיד שהוא קרובו של מקבל ההלוואה או שותפו; ואם מקבל ההלוואה הוא חבר בני-אדם -           |                 |
