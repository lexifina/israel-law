|מפקיעים בתשלום     |מהחלקה המקורית מכוח חוק רכישה' תוך שנה אחת לפני שרכש החייב בתשלום פיצויים                                 |

|                   |מסויימים עד ל-25% משטח קרקע רצוף שבבעלות אחת' בלי לשלם פיצויים בעדם. וכן                                  |
|                   |נקבע שהפיצויים בעד כל קרקע שנרכש לצרכים האמורים יוקטנו' אם השטח הכולל שנרכש.                              |

|                   |בע.א. 91/42 (9 פ.ל.ר. עמ' 13) הוחלט כי אם נרכשו' מכוח תכנית בנין עיר, מקרקעין                             |
|                   |ללא תשלום פיצויים ועודף המקרקעין נמכר לאחר מכן, מותר לחזור ולרכוש כאמור ללא                               |
|                   |תשלום פיצויים חלק מאותו עודף עד לשיעור של 25% ממנו. לא נאמר במפורש באותו                                  |
|                   |פסק הדין, אם היה מותר להפקיע שנית ללא תשלום פיצויים גם כשהעודף האמור לא נמכר                              |
|                   |אלא נשאר בידי בעליו המקוריים/ אלא שלמעשה היו הועדות המקומיות לבנין ערים                                   |
|                   |נוהגות לשלם פיצויים במקרים של הפקעות חוזרות מאותם הבעלים כאמור.                                           |
