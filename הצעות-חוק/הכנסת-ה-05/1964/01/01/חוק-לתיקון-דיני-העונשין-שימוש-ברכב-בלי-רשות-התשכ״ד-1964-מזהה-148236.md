|                     |התעבורה 1,ולרבות ספינה או סירה המונעים בכוח מיכני' ועגלה הרתומה לבהמה.                                   |

|                     |בלי רשות), תשכ"ד-1964."                                                                                  |
|                     |דברי הסבר                                                                                                |
|                     |נטילת כלי רכב ללא רשות מבעליהם והחזרתט למקומם לאחר נסיעה או זניחתם                                       |
|                     |במקום אחר דפכו לחזיון- נפוץ בארץ. לפי החוק הפלילי הקיים, אין מעשה כזה כשלעצמו                            |

|                     |לשלול אותו עולמית מאת הבעלים, וכוונה כזו אינה קיימת למעשה. כן ؀ࠂࠊࠌאין היראות חוק                         |
