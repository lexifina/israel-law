|חוק לתיקון פקודת הטבק (מס' 2), תשכ"ד-1964                                                                                      |

|1. בפקודת הטבק 1 (להלן - הפקודה)' בסעיף 21' אחרי סעיף קטן (ב) יבוא:                                        |תיקון סעיף 21       |
|"(ג) שר האוצר או מי שהוסמך על ידיו לענין זה רשאים להורות                                                   |                    |
|על נעילת מחסן שלא בדרך שנקבעה בסעיף קטן (א) וכן רשאים הם                                                   |                    |
|להתיר הכנסתם של דברים למחסן, או הוצאתם ממנו, שלא במעמד רשות                                                |                    |
|הבלו."                                                                                                     |                    |
|2. במקום סעיף 22 לפקודה יבוא:                                                                              |החלפת סעיף 22       |
|22. (א) שר האוצר או מי שהוסמך על ידיו לענין זה רשאים להורות'                           |"תעודות היתר        |                    |
|כי סוחר המוכר טבק לייצור או ליצוא או המעביר טבק למטרות האמורות'                        |הובלה               |                    |
|ימסור לקונה או ליצרן תעודת היתר הובלה על כך בטופס שיורה עליו                           |                    |                    |
|המנהל.                                                                                 |                    |                    |
|(ב) לא ניתנה הוראה כאמור בסעיף קטן (א), תמסור רשות הבלו                                                    |                    |
|לקונה או ליצרן תעודת היתר הובלה כאמור, בטופס שנקבע."                                                       |                    |
|3. בסעיף 33 לפקודה' אחרי סעיף קטן (ב) יבוא:                                                                |תיקון סעיף 33       |
|"(ג) שר האוצר או מי שהוסמך על ידיו לענין זה רשאים להורות                               |                    |                    |
|שמחסן הפקדה יינעל שלא בדרך שנקבע בסעיף קטן (ב)."                                       |                    |                    |
|דברי הסבר                                                                              |                    |                    |
|1. סעיף 21 לפקודה קובע:                                                                                    |                    |
|21. (א) מחסנו של סוחר יינעל בשני מנעולים; מפתח המנעול האחד יהיה בידי הסוחר ומפתח       |"פיקוח רשות הבלו    |                    |
|המנעול האחר- בידי רשות הבלו' ותהיה לה זכות כניסה למחסן בכל שעה לשם בדיקתו ואימותו      |על המחסן            |                    |
|של המצוי בו.                                                                           |                    |                    |
|(ב) אין להכניס למחסן או להוציא ממנו דבר אלא במעמד רשות הבלו."                          |                    |                    |
|הוראה כזו מצויה גם בסעיף 33 לפקודה לענין מחסן הפקדה.                                                       |                    |
|הוראות אלה היו חשובות בשעתו ؀ࠂࠊࠌלביצוע יעיל של הפיקוח על תשלום הבלו' שהוטל                                 |                    |
|על יחידות משקל של טבק שיוצר ונמכר בישראל. כיום, כשעיקר הבלו מוטל על סיגריות,                               |                    |
|באחוזים מהמחיר לצרכן פחתה חשיבותו של הפיקוח הפיסי המתמיד במחסנים של סוחרי                                  |                    |
|הטבק. מוצע' איפוא' להעניק לשר האוצר סמכות להתיר את חומרת הפיקוח הפיסי ולהנהיג                              |                    |
|במקומו פיקוח בדרך אחרת כגון בדיקת ספרים ומסמכים.                                                           |                    |
|2. סעיף 22 לפקודה קובע' וזו לשונו:                                                                         |                    |
|22. כל אימת שהסוחר ימכור או יעביר טבק לייצור או לייצוא' תמסור רשות הבלו לקונה או       |"תעודה על טבק       |                    |
|ליצרן תעודה על כך בטופס שנקבע."                                                        |שנמכר או שהועבר     |                    |
|אף התיקון בסעיף זה בא להעניק סמכות לשר האוצר להתיר במקצת את רצועת                                          |                    |
|הפיקוח הישיר של רשות הבלו על מכירת טבק, ולהסתפק, במקרים שעליהם יורה השר,                                   |                    |
|בתעודת מכירה שתינתן לקונה על ידי המוכר ולאו דוקא על ידי רשות הבלו.                                         |                    |
