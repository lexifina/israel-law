|חוק לתיקון פקודת העיריות (מס' 21), תשכ"ד-1964                                      |

|1. בסעיף 98 לפקודת העיריות, 1934 1, אחרי פסקה (15), יבוא:                                                 |תיקון סעיף 98    |
|(15א) להורות בדבר סיודם, תיקונם ושיפוצם של בנינים                       |"שיפוץ בנינים                    |                 |
|והחזקת חזיתותיהם במצב תקין וכן בכל הנוגע למימון ההו-                    |                                 |                 |
|צאות הכרוכות בכך וחלוקתן."                                              |                                 |                 |
|דברי הסבר                                                                                                 |                 |
|זה שנים מתלבטות העיריות' ובפרט בערים הגדולות והוותיקות יותר' בהבטחת מראה                                  |                 |
|חיצוני נאה ומתוקן לבניני העיר. מצבם המוזנח של הבתים מכער את רחובות ערינו; בתים                            |                 |
|נהרסים מהעדר סיוד, תיקון ושיפוץ; ורכוש רב, שלמשק הלאומי ענין חיוני בו, נפגע קשה.                          |                 |
|לפי המצב החוקי הקיים אין בידי העיריות כלים חוקיים להורות הוראות מחייבות                                   |                 |
|בענינים אלה. בעיית מימון העבודות הללו' וחלוקת הנטל הכספי הכרוך בהן בין הגורמים                            |                 |
|השונים הבאים בחשבון: בעלי הבתים, הדיירים, והציבור (באמצעות השלטון המרכזי                                  |                 |
|והמקומי)' אף היא מן ؀ࠂࠌࠎהבעיות הקשות והמסובכות הטעונות פתרון.                                             |                 |
|קשה להציע פתרון כולל שיהא יפה לכל מקום ומקום, ועל כן אין גם אפשרות לקבוע                                  |                 |
|הוראות מפורטות בענינים אלה בגוף החוק. מוצע' איפוא' שתוקנה סמכות לעיריות' שעל                              |                 |
|פיה תוכל כל עיריה, במידת הצורך, לקבוע בחוקי עזר את פרטי ההסדרים, לרבות עניני                              |                 |
|מימון והקמת קרנות בהשתתפות הגורמים הנ"ל' לפי צרכיה ושיקוליה.                                              |                 |

|חבר הכנסת : ע. דגני           |

|1 ע"ר 1934, תוס' 1 מס' 414, עמ' 1.               |
