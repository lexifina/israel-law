|מתפרסמות בזה הצעות חוק מטעם חברי כנסת:                   |

|חוק לתיקון פקודת החברות, תשכ"ד-1964                                |

|1. (א) בסעיף 220א לפקודת החברות1, במקום סעיף קטן (1), יבוא:                                            |תיקון סעיף 220א         |
|"(1) לחובות המפורטים להלן יהיה בפירוק החברה דין קדימה לכל                                              |                        |
|שאר החובות;                                                                                            |                        |
|(א) שבר עבודה כמשמעותו בחוק הגנת השכר,                                                                 |                        |
|תשי"ח-1958 2, שמגיע לעובד בעד שירותיו לחברה לפני                                                       |                        |
|התאריך המתאים, ובלבד שסך-כל השכר שיש לו דין                                                            |                        |
|קדימה לא יעלה על 2100 לירות;                                                                           |                        |
|(ב) סכום שהחברה ניכתה במקור משכר העבודה על                                                             |                        |
|פי פקודת מס הכנסה 3 ולא שילמה לפקיד השומה;                                                             |                        |
|החובות המפורטים בפסקאות (א) ו-(ב) יהיו שווים זה לזה במעלה                                              |                        |
|וישולמו במלואם, ואם אין בנכסים כדי תשלום מלא לכולם יופחתו התש-                                         |                        |
|לומים בשיעור שווה; אחריהם יבוא חובות אלה:                                                              |                        |
|(ג) תשלומי חובה שמגיעים מאת החברה בתאריך                                                               |                        |
|המתאים והיא נתחייבה בהם, או שזמן פרעונם הגיע'                                                          |                        |
|תוך 12 החדשים שקדמו לאותו תאריך;                                                                       |                        |
|"תשלומי חובה" לענין זה - מסים עירוניים, מסים                                                           |                        |
|של מועצות מקומיות' תרומות שהן בבחינת מסים                                                              |                        |
|המוטלות על פי פקודת העדות הדתיות (ארגונן) 4,                                                           |                        |
|וכן האגרות המשתלמות לרשם על פי פקודה זו;                                                               |                        |
|(ד) מסי הממשלה שנישומו והוטלו על החברה עד 31                                                           |                        |
|במרס האחרון שלפני התאריך המתאים וסך כולם אינו                                                          |                        |
|עולה על ؀ࠂࠌࠎהשומה של שנה אחת' וכן מסי ממשלה אחרים                                                      |                        |
|שהחברה נתחייבה בהם, או שזמן פרעונם הגיע, במשך                                                          |                        |
|12 החדשים שקדמו לאותו תאריך;                                                                           |                        |
|(ה) דמי שכירות של שנה אחת' לכל היותר' שלפני                                                            |                        |
|התאריך המתאים המגיעים למשכיר בעד בתים וקרקעות                                                          |                        |
|ששכרה החברה;                                                                                           |                        |
|החובות המפורטים בפסקאות (ג) עד (ה) יהיו שווים זה לזה במעלה                                             |                        |
|וישולמו במלואם, ואם אין בנכסים כדי תשלום מלא לכולם יופחתו התש-                                         |                        |
|לומים בשיעור שווה."                                                                                    |                        |
|(ב) פסקה (א) שבסעיף קטן (4) - בטלה.                                                                    |                        |
|חבר הכנסת : י. בדר                                                                                     |                        |
