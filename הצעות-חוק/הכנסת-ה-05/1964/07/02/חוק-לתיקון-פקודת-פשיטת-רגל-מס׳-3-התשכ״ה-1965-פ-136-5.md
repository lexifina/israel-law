|חוק לתיקון פקודת פשיטת הרגל, תשכ"ד-1964                                  |

|תיקון סעיף 33   |1, (א) בסעיף 33 לפקודת פשיטת הרגל, 1936 1, במקום סעיף קטן (2), יבוא;                                    |
|                |"(2) לחובות המפורטים להלן יהיה בחלוקת נכסיו של פושט רגל                                                 |
|                |דין קדימה לכל שאר החובות:                                                                               |
|                |(א) שכר עבודה כמשמעותו בחוק הגבת השכר,                                                                  |
|                |תשי"ח-1958 2, שמגיע לעובד בעד שירותיו לפושט                                                             |
|                |הרגל לפני הגשת הבקשה לפשיטת רגל' ובלבד שסך-                                                             |
|                |כל השכר שיש לו דין קדימה לא יעלה על 2100 לירות;                                                         |
|                |(ב) סכום שפושט הרגל ניכה במקור משכר העבודה                                                              |
|                |על פי פקודת מס הכנסה3' ולא שילם לפקיד השומה?                                                            |
|                |החובות המפורטים בפסקאות (א) ו-(ב) יהיו שווים זה לזה במעלה                                               |
|                |וישולמו במלואם, ואם אין בנכסיו של פושט הרגל כדי תשלום מלא                                               |
|                |לכולם יופחתו התשלומים בשיעור שווה? אחריהם יבואו חובות אלה:                                              |
|                |(ג) תשלומי חובה שמגיעים מאת פושט הרגל בתאריך                                                            |
|                |הצו לקבלת נכסים והוא נתחייב בהם, או שזמן פרעונם                                                         |
|                |הגיע' תוך 12 החדשים שקדמו לאותו תאריך;                                                                  |
|                |"תשלומי חובה" לענין זה - מסים עירוניים, מסים של                                                         |
|                |מועצות מקומיות' ותרומות שהן בבחינת מסים                                                                 |
|                |המוטלות על פי פקודת העדות הדתיות (ארגונן) 4;                                                            |
|                |גד) מסי הממשלה שנישומו והוטלו על פושט הרגל עד                                                           |
|                |31 במרס האחרון שלפני תאריך הצו לקבלת הנכסים                                                             |
|                |וסך כולם אינו ؀ࠂࠊࠌעולה על השומה של שנה אחת, וכן                                                         |
|                |מסי ממשלה אחרים שפושט הרגל נתחייב בהם, או שזמן                                                          |
|                |פרעונם הגיע' במשך 12 החדשים שקדמו לאותו תאריך;                                                          |
|                |(ה) דמי שכירות של שנה אחת' לכל היותר' שלפני                                                             |
|                |תאריך ההכרזה המגיעים למשכיר בעד בתים וקרקעות                                                            |
|                |ששכר פושט הרגל;                                                                                         |
|                |(0 כל כסף המגיע בעד פיגורים במילוי צווי מזונות                                                          |
|                |שבית משפט בן-סמך נתנם או מוציאם לפועל;                                                                  |
|                |החובות המפורטים בפסקאות (ג) עד (ו) יהיו שווים זה לזה במעלה                                              |
|                |וישולמו במלואם, ואם אין בנכסיו של פושט הרגל כדי תשלום מלא                                               |
|                |לכולם יופחתו התשלומים בשיעור שווה."                                                                     |
|                |(ב) סעיף קטן (3) - בטל.                                                                                 |
|                |חבר הכנסת : י. בדר                                                                                      |
