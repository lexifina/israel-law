|מתפרסמת בזה הצעת חוק מטעם הממשלה:                                                                                       |
|חוק לתיקון פקודת הנמלים (מס' 6), תשכ"ד-1964                                                                             |

|1, בסעיף 17 לפקודת הנמלים1, אחרי פסקה (טז ד) יבוא :                                                          |תיקון סעיף 17      |
|"(טז ה) הבטיחות של השיט ושל חיי בבי אדם במימי החופין,                                                        |                   |
|באגמים, בנהרות ובשאר מקומות הראויים לשיט, בין שהם                                                            |                   |
|טבעיים ובין שהם מלאכותיים - על ידי הטלת הסדר או                                                              |                   |
|פיקוח על השיט, לרבות איסורו, הגבלתו או התבייתו, אלא                                                          |                   |
|שאיסור כניסתם של כלי שיט' שעיקר עיסוקם דיג לאזור                                                             |                   |
|מסויים, טעון התייעצות עם שר החקלאות."                                                                        |                   |
|דברי הסבר                                                                                                    |                   |
|לאחרונה רבתה תנועת כלי שיט קטנים, בעיקר סירות מירוץ, במים הפנימיים (בכנרת                                    |                   |
|ובנחלים) ובמימי החופין של המדינה, וגדלה הסכנה של פגיעה במתרחצים ושל התנגשות                                  |                   |
|בין כלי השיט.                                                                                                |                   |
|החוק המוצע מעניק לשר התחבורה סמכות להתקין תקנות לפיקוח על תנועת כלי שיט                                      |                   |
|במים פנימיים ובמימי חופין בכל הנוגע לבטיחות השיט ולבטיחות חיי בני אדם.                                       |                   |
