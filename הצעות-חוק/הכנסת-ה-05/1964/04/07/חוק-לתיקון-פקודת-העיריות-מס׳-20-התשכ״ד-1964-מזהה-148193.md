|סעיף 113 לפקודת העיריות' 1934' קובע לאמור:                                                                      |                   |
|113. (א) בחדשים אוקטובר ונובמבר של כל שנה זכאים העיריה או בעל או מחזיק לדרוש               |''בקורת לוח השומה    |                   |
|מועדת השומה בקורת לוח השומה, והועדה תבקר את הלוח. הודעה על זכות דרישה זו תפורסם            |                     |                   |
|בתחום העיריה על ידי יושב ראש ועדת השומה בחודש ספטמבר של כל שנה.                            |                     |                   |
|(ב) הוראות הסעיפים הקטנים (ב) עד (ה) מסעיף 112 יחולו' בשינויים המחוייבים על פי             |                     |                   |
|הענין, על בקורת לוח השומה לפי סעיף זה.                                                     |                     |                   |
|(ג) התיקונים בלוח השומה לפי סעיף זה יקבלו תוקף באחד באפריל שלאחר תאריך                     |                     |                   |
|הדרישה לבקורת הלוח."                                                                       |                     |                   |
|בזמן האחרון התברר כי בגלל עומס הבקשות אין ועדות שומה מספיקות לגמור את                                           |                   |
|בקורת לוחות השומה תוך זמן סביר' ולפעמים חולפות שנים למן הדרישה לבקורת ועד                                       |                   |
|לביצועה. בהתאם להוראות סעיף קטן (ג) של סעיף 113 לפקודת העיריות מקבלות החלטות                                    |                   |
|ועדות השומה תוקף למפרע'؀ࠂࠊࠌ מן האחד באפריל שלאחר תאריך הדרישה לבקורת. במשך                                      |                   |
|תקופה זו אין למשלמי המסים ואף לא לעיריה בטחון בדבר גובה מסי הרכוש העירוניים                                     |                   |
|שיש לשלמם בשל הנכסים ששומתם נמצאת בבקורת.                                                                       |                   |
|מוצע כעת לחייב את ועדות השומה לדון ולהחליט בדרישות לבקורת לוח השומה                                             |                   |
|תוך שנת הכספים שבה הוגשה הדרישה.                                                                                |                   |
|כדי להמריץ את הועדות להקפיד על מועד זה מוצע לשנות את מועד תחילת תקפן                                            |                   |
|של החלטותיהן באופן שאלה ייכנסו לתקפן באחד באפריל שלאחר תאריך ההחלטה. אולם                                       |                   |
|אם החליטה הועדה להקטין את שוויו של נכס' תקבל ההחלטה תוקף באחד באפריל שלאחר                                      |                   |
|הדרישה לבקורת הלוח - וזאת כדי שלא ייפגע משלם המסים במקרה שהועדה התרשלה                                          |                   |
|במילוי תפקידה וקיבלה החלטתה לאחר המועד.                                                                         |                   |
