|מתפרסמות בזה הצעות חוק מטעם הממשלה:                      |

|חוק לתיקון פקודת הרשויות המקומיות (מס עסקים) (מס' 5),                                           |
|תשכ"ה-1964                                                                                      |

|1. בסעיף 3 לפקודת הרשויות המקומיות (מס עסקים), 1945 1, בסעיף קטן(1), אחרי                                   |תיקון סעיף 7.   |
|המלים "בלי שמציאותם של מלאכה או עסק של אותו אדם במקום אחר, בין בתחום הרשות                                  |                |
|המקומית ובין מחוצה לה, תשפיע על קביעת שיעור מס העסקים במקום הנדון" יבוא "והוא,                              |                |
|אף אם המקום הנדון משמש לניהול העסק או המלאכה במקום האחר, בין בתחום הרשות                                    |                |
|המקומית ובין מחוצה לה".                                                                                     |                |
|דברי הסבר                                                                                                   |                |
|ב-31 בדצמבר 1957 קיבלה הכנסת את החוק לתיקון פקודת הרשויות המקומיות (מס                                      |                |
|עסקים), תשי"ח-1957, ובסעיף 1 לאותו חוק הוחלף סעיף 3 (1) לפקודה כך:                                          |                |
|''(1) רשות מקומית רשאית, בחוק עזר, להטיל על כל אדם העוסק בתחומה במלאכה או                                   |                |
|בעסק מן המפורטים בחוק העזר, בין שניהולם בתחום הרשות המקומית ובין שהוא במקום אחר,                            |                |
|מס שייקרא בעיריה "מס עסקים עירוני" ובמועצה מקומית "מס עסקים מקומי", בשיעור שייקבע                           |                |
|בחוק העזר ושלא יעלה על אלפיים לירות לשנה לכל מקום שבו הוא עוסק במלאכה או בעסק                               |                |
|האמורים/ בלי שמציאותם של מלאכה או עסק של אותו אדם במקום אחר/ בין בתחום הרשות                                |                |
|המקומית ובין מחוצה לה/ תשפיע על קביעת שיעור מס העסקים במקום הנדון/ והמס ייקבע לפי                           |                |
|ממדי העסק והמלאכה באותו מקום בלבד, לפי מבחני הדירוג שנקבעו מכוח סעיף קטן (2)."                              |                |
|מגמתה של הכנסת, כפי שבאה לידי ביטוי בדיונים בה, היתה למנוע שכל רשות מקומית                                  |                |
|תטיל מס עסקים על עסק לפי המבחן של ההיקף הארצי של ؀ࠂࠌࠎאותו עסק, להבדיל מההיקף                                |                |
|המקומי בלבד. אולם בית המשפט העליון בע"א 168/59 (פסקי דין י"ג, עמ' 1339) סייג את                             |                |
|המגמה הזאת וקבע הלכה, כפי שנוסחה על ידי בית המשפט המחוזי, תל-אביב בע"א 93/63/6                              |                |
|(פסקים מחוזיים ל"ז, עמ' 61) בזו הלשון:                                                                      |                |
|"(א) היה ''ניהול" העסק בתחום העיריה, לא בא החוק המתקן לשנות כלום מהוראות                                    |                |
|הפקודה, כפי שנתפרשו בע"א 368/54 ('"פסקים עליונים" י"ט, 18); ופשר הדבר                                       |                |
|ששיעור המס ייקבע לפי ממדי העסק שבתחום הניהול/ להבדיל מאשר בתחום (העשוי                                      |                |
|להיות מצומצם יותר) של המקום;                                                                                |                |
|(ב) היה "ביצוע'' לבדו בתחום העיריה, בעוד "ניהול" העסק מחוץ לתחומה, תופסת                                    |                |
|ההגבלה הגיאוגרפית של החוק המתקן/ כלומר שיעור המס יצומצם לפי ממדי העסק                                       |                |
|שבתחום המקום.''                                                                                             |                |
|החוק המוצע בא להשלים ולקבוע בהתאם למגמת הכנסת מאז, שגם אם מקום העסקים                                       |                |
|הוא מקום הניהול המרכזי של עסקים ארציים, אין להשתמש בממדים ארציים של העסק                                    |                |
|כמבחן להטלת המס במקום שבו נמצא מרכז הניהול.                                                                 |                |
