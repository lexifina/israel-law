|מתפרסמות בזה הצעות חוק מטעם הממשלה :                                                                                |
|חוק רציפות הדיון בהצעות חוק, תשכ"ד-1964                                                                             |

|1. הצעת חוק מטעם הממשלה, שועדה מועדות הכנסת היוצאת התחילה לדון בה,                                           |המשך הדיון             |
|והממשלה שנתכוננה בכנסת הנכנסת הודיעה במליאת הכנסת על רצונה שהדיון בהצעה                                      |בועדה                  |
|יימשך - תמשיך בו אותה ועדה של הכנסת הנכנסת מן השלב שאליו הגיעה הועדה של                                      |                       |
|הכנסת היוצאת.                                                                                                |                       |
|2. בהמשך הדיון בהצעת חוק לפי סעיף 1 תתן הועדה לכל חבר הכנסת הנכנסת' שלא                                      |זכותם של חברי          |
|היה חבר הכנסת היוצאת' הזדמנות להשמיע לפניה את דעתו על הצעת החוק' אם יבקש זאת.                                |כנסת חדשים             |
|דברי הסבר                                                                                                    |                       |
|הנסיון מראה' שעם סיום כהונתה של כנסת יוצאת נשארות הצעות חוק מטעם הממשלה                                      |1                      |
|שהדיון בהן התחיל אך לא הסתיים. בכנסת החדשה יש צורך להגיש הצעות אלה מחדש                                      |                       |
|ולחזור על שלבי הדיון שכבר נתקיימו בכנסת היוצאת. במקרים רבים יש בכך משום חזרה                                 |                       |
|מיותרת.                                                                                                      |                       |
|החוק המוצע בא לאפשר ؀ࠂࠈשדיון בהצעות חוק שהתחיל בכנסת יוצאת יימשך בכנסת                                       |                       |
|הנכנסת' אם הממשלה שנתכוננה בכנסת החדשה ביקשה על כך במליאת הכנסת.                                             |                       |
|הסעיף השני של ההצעה בא לשמור על זכויות חברי הכנסת החדשה שלא היו חברים                                        |                       |
|גם בכנסת הקודמת.                                                                                             |                       |
