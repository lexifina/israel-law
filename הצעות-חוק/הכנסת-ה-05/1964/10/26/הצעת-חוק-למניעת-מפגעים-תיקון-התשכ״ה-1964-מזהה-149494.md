|"מאסר ששה חדשים או".                                                                                        |                |
|דברי הסבר                                                                                                   |                |
|בסעיף 11 (א) לחוק למניעת מפגעים, תשכ"א-1961, נקבע עונש מאסר של ששה                                          |                |
|חדשים, או קנס של אלפיים לירות למי שעבר עבירה לפי הוראות החוק או תקנות, חוקי עזר                             |                |
|והוראות שניתנו לפיו. לאחר שיקולים נראה שמן הראוי שלא להעניש במאסר בשל עבירה                                 |                |
|כאמור אלא בקנס בלבד, ולהשתמש בעונש מאסר רק נגד מי שנמנע מלמלא אחר צו בית-                                   |                |
|המשפט, לפי לשון סעיף 11 (ב) לחוק, "להימנע מכל ؀ࠂࠊࠌפעולה שגרמה לעבירה שעליה הורשע",                          |                |
|היינו למנוע את מקור המפגע.                                                                                  |                |
