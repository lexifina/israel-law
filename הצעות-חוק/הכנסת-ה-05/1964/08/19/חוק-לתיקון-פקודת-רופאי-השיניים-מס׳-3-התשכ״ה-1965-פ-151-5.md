|מתפרסמת בזה הצעת חוק מטעם חברי כנסת :                  |

|חוק לתיקון פקודת רופאי שיניים (מס' 3), תשכ"ד-1964                                        |

|תיקון סעיף 7    |1, בסעיף 7 לפקודת רופאי שיניים, 1945 1, אחרי סעיף קטן (ח) יבוא:                                           |
|                |"(ט) מי שעלה לארץ אחרי יום כ"ט באדר תש"ך (28 במרס 1960),                                                  |
|                |ותוך 12 חדשים מיום תחילתו של החוק לתיקון פקודת רופאי שיניים                                               |
|                |(מס' 3)' תשכ"ד-1964' הגיש למנהל בקשה למתן תעודת-היתר לעסוק                                                |
|                |בריפוי שיניים, רשאי המנהל לתת לו תעודת-היתר כאמור, אם נתקיימו                                             |
|                |במבקש תנאים אלה:                                                                                          |
|                |(1) הוא בן ארבעים שנה ומעלה;                                                                              |
|                |(2) הוא בעל תעודת בגרות;                                                                                  |
|                |(3) עסק 20 שנה בריפוי שיניים, להבדיל מטכנאות שיניים;                                                      |
|                |(4) פרנסתו העיקרית כל התקופה האמורה היתה עבודת                                                            |
|                |ריפוי שיניים להבדיל מטכנאות שיניים;                                                                       |
|                |(5) נתקיימו בו התנאים הנקובים בפסקאות (4) - (6) לסעיף                                                     |
|                |קטן (א).                                                                                                  |
|                |(י) הוראות הסעיפים הקטנים (ג) - (ה) יחולו על מבקש תעודת-                                                  |
|                |היתר ועל מי שקבל תעודת-היתר לפי סעיף קטן (ט)' הכל לפי הענין.                                              |
|                |(יא) להוכחת קיומם של התנאים הנקובים בפסקאות (1) - 0:)                                                     |
|                |לסעיף-קטן (ט) לא יזקק המנהל אלא לתעודות ציבוריות כמשמעותן                                                 |
|                |בפקודת העדות 2 , ובהעדרן- לפסק דין הצהרתי של בית משפט שלום."                                              |
|הוראות מעבר     |2. מי שהגיש בקשה למתן תעודת-؀ࠂࠌࠎࠒࠔהיתר לעסוק בריפוי שיניים תוך שלושה חדשים מיום                           |
|                |תחילתו של החוק לתיקון פקודת רופאי שיניים, תשי"ח-1958, וסירבו לבקשתו מחמת שלא                              |
|                |נתקיימו בו התנאים הנקובים בפסקאות (1) - (3) לסעיף 7(א) לפקודת רופאי שיניים, 1945,                         |
|                |רשאי להגיש שנית בקשה תוך ששה חדשים מיום תחילתו של חוק זה' ורשאי המנהל לתת                                 |
|                |לו תעודת-היתר כאמור, אף אם לא נתקיימו בו התנאים האמורים, אם ועדה מייעצת שנת-                              |
|                |מנתה על ידי המנהל המליצה על כך מסיבות יוצאות מן הכלל.                                                     |
|                |חברי הכנסת : נ. ניר, ב. ארדיטי, פ. זוארץ, ו. שם-טוב,                                                      |
|                |ח. מגורי-כהן, י. כץ, י. קורן.                                                                             |
