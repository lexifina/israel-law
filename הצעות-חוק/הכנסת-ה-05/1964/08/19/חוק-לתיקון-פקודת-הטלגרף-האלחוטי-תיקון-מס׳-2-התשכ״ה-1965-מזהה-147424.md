|חוק לתיקון פקודת הטלגרף האלחוטי (תיקון מס' 2), תשכ"ד-1964                                            |

|1. בסעיף 4 לפקודת הטלגרף האלחוטי 1 (להלן - הפקודה), במקום "יהיה מותר לו                                    |תיקון סעיף 4     |
|למנהל הכללי של בתי-הדואר' באישורו של שר הדואר" יבוא "יהיה שר הדואר רשאי".                                  |                 |
|2. בסעיף 7 לפקודה, במקום "באישורו של שר הדואר רשאי המנהל הכללי של בתי-                                     |תיקון סעיף 7     |
|הדואר" יבוא "שר הדואר רשאי",                                                                               |                 |
|דברי הסבר                                                                                                  |                 |
|פקודות ממשלת המנדט העניקו בדרך כלל את מרבית הסמכויות הדרושות לביצוע                                        |                 |
|ההוראות הכלולות בהן - ובכלל זה הסמכות להתקין תקנות - למנהלים שעמדו אז בראש                                 |                 |
|המחלקות השונות של השלטון המנדטורי. בהתאם לכך רוכזו הסמכויות לביצוע פקודת                                   |                 |
|הטלגרף האלחוטי בידי המנהל הכללי של בתי-הדואר Postmaster General(  בלע"ז) אם כי                             |                 |
|בהגבלה אחת והיא שהפעלתן מותנית בהשגת אישור מראש מאת הנציב העליון (היום מסורות                              |                 |
|סמכויות הנציב לשר הדואר). מאז הקמת המדינה הנוהג הוא למסור את הסמכות לבצע                                   |                 |
|חוקים כידי חבר ממשלה.                                                                                      |                 |
|תכליתו של החוק המוצע בזה היא להתאים את האמור בפקודת הטלגרף האלחוטי                                         |                 |
|לנוהל המקובל בחקיקת המדינה על ידי מסירת סמכויותיו של המנהל הכללי של בתי הדואר                              |                 |
|לשר הדואר.                                                                                                 |                 |
|אין החוק המוצע בא לתקן כל תיקון ביחס לסמכויותיו של המנהל הכללי למשרד                                       |                 |
|הדואר ביחס לגביית האגרות בעד חידוש רשיון להחזקת מקלטי רדיו (סעיפים 5א - 5ה                                 |                 |
|לפקודה). על פי הצעת חוק רשות השידור, תשכ"ג-1963 2, שהוגשה על ידי הממשלה לכנסת                              |                 |
|ונמצאת עתה בדיון בועדה של הכנסת' יעברו כל הסמכויות לקביעת האגרות בעד השימוש                                |                 |
|במקלטי רדיו וגבייתן לרשות השידור. עם קבלת חוק רשות השידור על ידי הכנסת יבוטלו                              |                 |
|ההוראות האמורות בפקודה.                                                                                    |                 |
|להלן סעיפי הפקודה שהחוק המוצע בא לתקנם:                                                                    |                 |
|4. היה שר הדואר סבור בזמן מן הזמנים כי השעה שעת חירום ומן הצורך שממשלת ישראל          |"סמכויות נוספות     |                 |
|תעמיד לפיקודה את ענין העברת ידיעות בטלגרף؀ࠂࠊࠌ אלחוטי או אותות על דרך ראיה או השמעת    |בשעת חיפוש          |                 |
|קול' או את ניצול גלי האויר להעברת כוח' יהא מותר לו למנהל הכללי של בתי הדואר' באישורו  |                    |                 |
|של שר הדואר' ליטול מיד לרשותו כל מכשיר המשמש לצורך זה' ובל זמן ששעת החירום נמשכת/     |                    |                 |
|מותר לו להתקין, נוסף לכל תקנה עפ"י סעיף 7, תקנות נוספות, כפי הצורך, בענין החזקת מכשיר |                    |                 |
|המשמש לכך, או חלקיו הבודדים, ובענין מכירתם, קניתם, בניתם והשימוש בהם.                 |                    |                 |
|7. באישורו של שר הדואר רשאי המנהל הכללי של בתי הדואר להתקין תקנות -                   |תקנות               |                 |
|(א) הקובעות אל הטופס והצורה שבהם יש להגיש בקשות עפ"י פקודה זו' את                     |                    |                 |
|התנאים שלפיהם יינתנו רשיונות' ואת האגרות שיש לשלם בעד מתן הרשיון או                   |                    |                 |
|בעד החידוש;                                                                           |                    |                 |
|(ב) הדורשות מאת העובדים ומאת כל העוסקים בניצול טלגרף אלחוטי לקבל                      |                    |                 |
|תעודות, והקובעות הוראות בענין צורת נתינתה של תעודה כזאת, תנאיה וחידושה,               |                    |                 |
|לרבות הבחינות והבדיקות שמקבל התעודה צריך לעסוק בהן;                                   |                    |                 |
|(ג) בענין ניצולו של כל מכשיר טלגרף אלחוטי באניות או באוירונים שלא נרשמו               |                    |                 |
|בישראל כשהאנייה מצויות במימי החוף של ישראל וכשהאוירונים טסים מעל אדמת                 |                    |                 |
|ישראל או מעל מימי החוף שלה;                                                           |                    |                 |
|(ד) הנותנות תוקף להוראות כל אמנה בין-לאומית הדנה בענין הטלגרף האלחוטי                 |                    |                 |
|שממשלת ישראל נצטרפה לה ולכל תקנה שהתקינו על פיה עד כמה שאותה אמנה                     |                    |                 |
|או תקנה דנות בטלגרף אלחוטי."                                                          |                    |                 |
