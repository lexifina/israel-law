|מתפרסמת בזה הצעת חוק מטעם הממשלה:                         |

|חוק המהנדסים והאדריכלים (תיקון), תשכ"ד-1964                                        |

|1, בסעיף 9 לחוק המהנדסים והאדריכלים/ תשי"ח~1958 1-                                                          |תיקון סעיף 9    |
|(1) בפסקה (3), בסופה, יבוא:                                                                                 |                |
|"ובלבד שהחברות או הרישום ניתנת באותה מדינה על סמך פעילות                                                    |                |
|מקצועית באחד מענפי ההנדסה או האדריכלות";                                                                    |                |
|(2) פסקה (4) תסומן פסקה (5);                                                                                |                |
|(3) לאחר פסקה (3) יבוא:                                                                                     |                |
|"(4) בעל תעודת חברות באיגוד של מהנדסים או אדריכלים                                                          |                |
|בישראל, שהחברות בו מותנית במילוי אחרי תנאים הזהים                                                           |                |
|לתנאים האמורים בפסקאות (1), (2), (3) או (5), והאיגוד                                                        |                |
|הוכר על ידי השר לאחר התייעצות במועצה".                                                                      |                |
|דברי הסבר                                                                              |                    |                |
|סעיף 9 לחוק המהנדסים והאדריכלים, תשי"ח-1958, אומר:                                                          |                |
|9. ואלה זכאים להיות רשומים בפנקס המהנדסים והאדריכלים לאחר ששילמו אגרת הרישום           |"רישום בפנקס        |                |
|שנקבעה בתקנות:                                                                         |                    |                |
|(1) בעל תעודת מוסמך למדעי ההנדסה או מוסמך לארכיטקטורה מאת הטכניון-                     |                    |                |
|מכון טכנולוגי לישראל;                                                                  |                    |                |
|(2) בעל תעודה מאת מוסד להשכלה גבוהה באחד מענפי ההנדסה או האדריכלות/                    |                    |                |
|והתעודה והמוסד הוכרו על ידי השר לאחר התייעצות במועצה;                                  |                    |                |
|(3) בעל תעודת חברות באיגוד רשמי של מהנדסים או אדריכלים או בעל תעודת                    |                    |                |
|רישום/ או כיוצא באלה/ במדינה שבה חברות באיגוד רשמי או רישום מסמיכים                    |                    |                |
|לעסוק בענף ההנדסה או האדריכלות, והאיגוד או הרישום הוכרו על ידי השר לאחר                |                    |                |
|התייעצות במועצה;                                                                       |                    |                |
|(4) מי שעבד שתים עשרה שגה לפחות באחד מענפי ההנדסה או האדריכלות/ והוכיח                 |                    |                |
|להנחת דעתו של חבר בוחנים/ אם על ידי העבודות שביצע ואם בדרך אחרת/ הכל כפי               |                    |                |
|שנקבע בתקנות/؀ࠂࠌࠎ שיש לו הכשרה מתאימה/ ובלבד שהגיש בקשה לרישום תוך ששה                 |                    |                |
|חדשים לאחר פרסום הודעה שנפתח בפנקס המהנדסים והאדריכלים מדור לענף                       |                    |                |
|ההנדסה או האדריכלות בו עבד כאמור; חבר הבוחנים יתמנה על ידי השר לאחר                    |                    |                |
|התייעצות במועצה.*                                                                      |                    |                |
|תכליתו של החוק המוצע בזה היא כפולה:                                                                         |                |
|(א) להגביל את זכות הרישום, הניתנת לפי פסקה (3) לסעיף 9 הנ"ל למי שהיה חבר                                    |                |
|באיגוד רשמי במדינת-חוץ, בתנאי שחברותו באותו איגוד ניתנה לו על סמך פעילות מקצועית                            |                |
|בפועל באותה מדינת-חוץ.                                                                                      |                |
|(ב) להסמיך את השר להכיר לצורך הענקת זכות הרישום גם באיגוד מהנדסים או                                        |                |
|אדריכלים ישראלי, ובלבד שהחברות באותו איגוד מותנית במילוי אחרי התנאים המזכים                                 |                |
|כיום לרישום בפנקס, כגון תעודת הסמכה מבית ספר טכנולוגי גבוה מוכר בארץ או בחוץ                                |                |
|לארץ, חברות באיגוד רשמי מוכר בחוץ לארץ וכו'.                                                                |                |

|1 ס'ח תשי''ח, עמ' 61.    |
