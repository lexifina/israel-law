|הצעת חוק זו באה להשלים את הצעת החוק לתיקון פקודת מס הכנסה (מס' 5),                                           |                 |
|תשכ"ד-1964 הדנה במס על רווחי הון.                                                                            |                 |
|הצעת החוק תסייע בקביעת תחום בין מקרקעין שעל הריווח שנבע ממכירתם יוטל                                         |                 |
|מס שבח לפי החוק העיקרי, לבין מקרקעין שעל הריווח כאמור יחול מס רווחי הון על פי                                |                 |
|פקודת מס הכנסה.                                                                                              |                 |
|מוצע לתקן את סעיף 7 לחוק העיקרי, במגמה להטיל לפיו מס על השבח העולה מפעו-                                     |                 |
|לות באיגודי מקרקעין מובהקים (כגון, איגודי בית או מגרש).                                                      |                 |
|ואילו על ריווח הנובע מפעולות באיגודי מקרקעין מעורבים שמרבית רכושם איננו                                      |                 |
|מקרקעין דווקא' וכן ריווח הנובע מפעולות באיגודי מקרקעין מובהקים שעוסקים במקרקעין                              |                 |
|(כגון איגוד העוסק בהשכרת בנינים) ושולטים בהם יותר מ-5؀ࠂࠊࠌࠐࠖ࠘ בני אדם, יוטל מס רווחי הון                      |                 |
|על פי חלק ה' לפקודת מס הכנסה.                                                                                |                 |
|וזו לשון סעיף 7 לחוק העיקרי:                                                                                 |                 |
|7. המט יוטל על פעולה באיגוד מקרקעין אם נתקיים למחות אחד מתנאים אלה:                      |הטלת המס על        |                 |
|(1) איגוד המקרקעין שבו נעשתה הפעולה הוא בשליטתם של חמישה בגי אדם לבל                     |פעולות באיגוד      |                 |
|היותר;                                                                                   |מקרקעין            |                 |
|(2) על מרבית המקרקעין נשוא הזכות במקרקעין שבבעלות איגוד המקרקעין אין                     |                   |                 |
|בנין כמשמעותו בחוק מס רכוש וקרן פיצויים, תשכ"א-1961;                                     |                   |                 |
|(3) מרבית המקרקעין שבהם יש זכות לאיגוד המקרקעין שבו נעשתה הפעולה                         |                   |                 |
|משמשים למגורי יחידים או שהם משמשים רק לייצור הכנסה מן המקורות המפורטים                   |                   |                 |
|בפסקאות (3) ו-(6) של סעיף 2 לפקודת מס הכנסה;                                             |                   |                 |
|(4) באותה פעולה הוקנתה על ידי בעל השליטה באיגוד השליטה לאחר;                             |                   |                 |

|פסקה (4) ואותה פעולה לפי מהותה ולפי נסיבות הענין מהווה שלב נוסף בעסקה בה                 |                   |                 |
|הוקנתה השליטה."                                                                          |                   |                 |
|3. סעיף 58 לחוק העיקרי קובע:                                                                                 |                 |
|58 פעולה באיגוד מקרקעין אשר נציב מס הכנסה או מי שהוסמך על-ידיו אישר כי הריווח            |''איגוד שעיקר      |                 |
|ממכירת מלוא הזכות במקרקעין שיש לו נתון לשומה לפי פקודת מס הכנסה/ תהיה פטורה ממס.*        |עיסוקו במקרקעין    |                 |
|העולה מסעיף זה הוא שהפטור ממס שבח ניתן לאדם לאו דוקא כשהריווח שלו בפעולה                                     |                 |
|באיגוד חייב במס הכנסה, אלא כשהריווח של האיגוד שבו נעשתה הפעולה נתון לשומה                                    |                 |
|לפי פקודת מס הכנסה. נמצא שהפטור ממס שבח על פעולה באיגוד עשוי להינתן גם לאדם                                  |                 |
|שהכנסתו זו אינה חייבת מס הכנסה.                                                                              |                 |
