|""סימן שירות" - סימן המשמש, או מיועד לשמש, לאדם לענין השירות                                             |                      |
|שהוא נותן?                                                                                               |                      |
|"סימן מאשר" - סימן המיועד לשמש בידי אדם, שאינו מנהל עסק,                                                 |                      |
|לאישור מקורה של סחורה פלונית שיש לו ענין בה, מרכיביה, דרכי                                               |                      |
|ייצורה, איכותה או תכונה אחרת מתכונותיה, או לאישור טיבו,                                                  |                      |
