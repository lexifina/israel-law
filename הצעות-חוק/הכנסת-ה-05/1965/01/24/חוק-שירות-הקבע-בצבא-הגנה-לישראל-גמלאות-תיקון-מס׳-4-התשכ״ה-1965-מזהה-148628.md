|יבוא:                                                                                                      |                      |
|31. (א) בסעיף זה -                                                                   |''קצבה ומשכורת      |                      |
|"הכנסה מקופת הציבור" - משכורת מאוצר המדינה או מקופה אחרת                             |מקופת הציבור        |                      |
|שנקבעה על ידי הממשלה כקופה ציבורית לענין סעיף זה;                                    |                    |                      |
|"קצבה רגילה" - קצבה שהיתה מגיעה אלמלא הוראות סעיף זה;                                |                    |                      |
|"הכנסה כוללת" - הכנסה מקופת הציבור בצירוף הקצבה הרגילה,                              |                    |                      |
|(כ) זכאי לקצבה המקבל גם הכנסה מקופת הציבור, יחולו עליו                               |                    |                      |
|הוראות אלה:                                                                          |                    |                      |
|(1) זכאי לקצבת פרישה שהכנסתו מקופת הציבור פחותה                                      |                    |                      |
|מהמשכורת הקובעת, והוא חייל שחזר לשירות קבע או עובד                                   |                    |                      |
|בשירות צבא-הגנה לישראל - תשולם לו קצבה כהפרש                                         |                    |                      |
|שבין הכנסה זו לבין המשכורת הקובעת, ובלבד שלא תעלה                                    |                    |                      |
|על הקצבה הרגילה; עלתה ההכנסה על המשכורת הקובעת,                                      |                    |                      |
|לא תשולם לו כל קצבה;                                                                 |                    |                      |
|(2) זכאי לקצבת פרישה שאינו נמנה עם המפורטים בפסקה                                    |                    |                      |
|(0 והכנסתו הכוללת עולה על המשכורת הקובעת - תשולם                                     |                    |                      |
|לו קצבה בשיעור שני שלישים מהקצבה הרגילה או בשיעור                                    |                    |                      |
|הקצבה הרגילה בניכוי שליש מהסכום שבו עודפת ההכנסה                                     |                    |                      |
|הכוללת על המשכורת הקובעת, הכל לפי הסכום הגבוה יותר;                                  |                    |                      |
|לא עלתה ההכנסה הכוללת על המשכורת הקובעת, לא תופחת                                    |                    |                      |
|קצבתו מכוח מעיף זה;                                                                  |                    |                      |
|(3) זכאי לקצבת שאיר שהכנסתו מקופת הציבור פחותה                                       |                    |                      |
|ממחצית המשכורת הקובעת-תשולם לו קצבה כהפרש שבין                                       |                    |                      |
|הכנסתו זו לבין מחצית המשכורת הקובעת, ובלבד שלא                                       |                    |                      |
|תעלה על הקצבה הרגילה; עלתה אותה הכנסה על המחצית                                      |                    |                      |
|האמורה, לא תשולם לו כל קצבה;                                                         |                    |                      |
|(4) אלמנה הזכאית לקצבת שאיר לפי סעיף 23, תשולם לה,                                   |                    |                      |
|על אף האמור בפסקה (3), קצבה כשיעור הסכום שבו עודפת                                   |                    |                      |
|המשכורת הקובעת על הכנסתה של האלמנה מקופת הציבור,                                     |                    |                      |
|אך לא יותר מהקצבה הרגילה, או בשיעור שני שלישים                                       |                    |                      |
|מהקצבה הרגילה, הכל לפי הסכום הגבוה יותר."                                            |                    |                      |

|סעיף 31 לחוק שירות הקבע בצבא-הגנה לישראל (גימלאות), תשי"ד-1954,                                                  |
|אומר: -                                                                                                          |
|"אדם הזכאי לקיצבה והוא מקבל גם משבורת מאוצר המדינה או מקופה אחרת שנקבעה על ידי                                   |
|הממשלה כקופה ציבורית לענין סעיף זה (בסעיף זה - הכנסה מקופת הציבור), יחולו עליו הוראות                            |
|אלה؀ࠂࠌࠎࠒࠖ࠘:                                                                                                      |
|(1) זכאי לקיצבת פרישה שהכנסתו מקופת הציבור פחותה מהמשכורת הקובעת                                                 |
|שלפיה יש לחשב את קיצבתו-תשולם לו קיצבה כהפרש שבין הכנסה זו לבין המשכורת                                          |
|הקובעת, ובלבד שלא תעלה על הקיצבה שהיתר. מגיעה לו אלמלא הוראת סעיף זה;                                            |
|עלתה ההכנסה על המשכורת הקובעת, לא תשולם לו כל קיצבה;                                                             |
|(2) זכאי לקיצבת שאיר שהכנסתו מקופת הציבור פחותה ממחצית המשכורת הקובעת                                            |
|שלפיה יש לחשב את הקיצבה-תשולם לו קיצבה כהפרש שבין הכנסתו זו לבין מחצית                                           |
|המשכורת הקובעת, ובלבד שאותו שיעור לא יעלה על הקיצבה שהיתה מגיעה לו                                               |
|אלמלא הוראת סעיף זה; עלתה אותה הכנסה על המחצית האמורה, לא תשולם כל                                               |
|קיצבה;                                                                                                           |
|(1:) אלמנה הזכאית לקיצבת שאיר לפי סעיף 2:1 - תשולם לה - על אף האמור                                              |
|בפסקה (2), קיצבה בסכום הגדול שבשני אלה:                                                                          |
|[א] הסכום שבו עודפת המשכורת הקובעת, שלפיה יש לחשב את הקיצבה,                                                     |
|על הכנסתה של האלמנה מקופת הציבור אך לא יותר מהקיצבה שהיתה מגיעה                                                  |
|לאלמנה אלמלא הוראות סעיף זה;                                                                                     |
|[ב] שני שלישים מהקיצבה שהיתה מגיעה לאלמנה אלמלא הוראות סעיף זה.'*                                                |
|זכאי, איפוא, אדם לקבל את מלוא קיצבת הפרישה כל עוד ההכנסה מקופת הציבור אינה                                       |
|עולה על ההפרש בין הקיצבה לבין משכורתו הקובעת-היא המשכורת המשמשת יסוד לחישוב                                      |
|הקיצבה. עלתה ההכנסה על ההפרש כאמור, הרי ככל שההכנסה עולה על אותו הפרש ומת-                                       |
|קרבת למשכורת הקובעת, כן פוחתת קיצבתו של הזכאי לקיצבת פרישה, ובאם ההכנסה                                          |
|עלתה על המשכורת הקובעת, לא תשולם לו קיצבה כלל.                                                                   |
|החוק המוצע בא להבטיח לזכאי לקיצבת פרישה המקבל הכנפה מקופת הציבור חלק                                             |
|מקיצבתו שלא יפחת בשום מקרה משני שלישים ממנה, אף אם ההכנסה מקופת הציבור                                           |
|עולה על המשכורת הקובעת.                                                                                          |
|מטרת החוק המוצע היא לעודד זכאים לקיצבת פרישה משרות קבע בצה"ל להיקלט                                              |
|בשירות מוסדות המדינה ובשירות מוסדות אחרים שנקבעו כקופה ציבורית; כתוצאה מכך                                       |
|יזכו מוסדות כאמור במידה רבה יותר מאשר עד כה, בכוח אדם בעל נסיון ארגוני ומינהלי                                   |
