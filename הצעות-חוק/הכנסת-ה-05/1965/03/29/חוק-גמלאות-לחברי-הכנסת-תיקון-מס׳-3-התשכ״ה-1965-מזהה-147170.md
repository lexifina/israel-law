|מתפרסמת בזה הצעת חוק מטעם ועדת הכנסת:                         |

|חוק גימלאות לחברי הכנסת (תיקון מס' 3), תשכ"ה-1965                                           |

|1, בסעיף 1 לחוק גימלאות לחברי הכנסת, תשי"ח-1958 1 (להלן - החוק העיקרי),                                      |תיקון סעיף 1    |
|בסוף ההגדרה "משכורת חברי הכנסת" יווסף;                                                                       |                |
|"אולם לגבי חבר הכנסת שהיה סגן יושב ראש הכנסת או סגן שר (להלן -                                               |                |
|סגן) תבוא במקום המשכורת האמורה משכורת ממוצעת, והיא סכום                                                      |                |
|המשכורת האמורה כפול במספר החדשים שבהם לא היה סגן בצירוף                                                      |                |
|סכום המשכורת החדשית המשתלמת מזמן לזמן לסגן כפול במספר החדשים                                                 |                |
|שבהם היה סגן, והכל מחולק לסך כל חדשי כהונתו בכנסת".                                                          |                |
|2. תחילתו של סעיף 1 לחוק העיקרי כפי שתוקן בחוק זה היא ביום כ"ח באדר ב' תשכ"ה                                 |תחילה           |
|(1 באפריל 1965) וכוחו יפה גם לגבי חבר הכנסת שחדל לכהן או נפטר לפני תחילתו של חוק                             |                |
|זה.                                                                                                          |                |
|דברי הסבר                                                                                                    |                |
|הקיצבה המשתלמת לחברי הכנסת שחדלו לכהן או לשאיריו של חבר הכנסת שנפטר                                          |                |
|מחושבת, לפי חוק גימלאות לחברי הכנסת, על בסיס המשכורת המשתלמת לרוב חברי                                       |                |
|הכנסת. ואילו לגבי יושב ראש הכנסת נקבע שהוא "זכאי, לגבי תקופת כהונתו כיושב ראש                                |                |
|הכנסת, לגימלאות לפי חוק הגימלאות לשרים, תשי"ז-1957" (סעיף 6).                                                |                |
|היוצא מזה שחבר הכנסת שכיהן כסגן יושב ראש הכנסת או ؀ࠂࠌࠎכסגן שר וקיבל עקב זאת                                  |                |
|משכורת בשיעור של 80% משכר היסוד של שר, לעומת משכורתם של יתר חברי הכנסת                                       |                |
|שהיא כשיעור של 60% משכר היסוד של שר (ראה הודעה על פי סעיף 2 לחוק שכר חברי                                    |                |
|הכנסת, תש"ט-1949 2), אינו זכאי לקיצבה בהתאם לשכרו המוגדל, תוצאה שאין לה הצדקה.                               |                |
|החוק המוצע בא להחיל את הכלל של קיצבה לפי המשכורת גם על סגני יושב ראש הכנסת                                   |                |
|וסגני שרים.                                                                                                  |                |
