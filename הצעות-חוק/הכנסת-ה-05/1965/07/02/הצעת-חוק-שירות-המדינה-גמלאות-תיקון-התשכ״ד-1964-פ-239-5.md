|1, בסעיף 23 לחוק שירות המדינה (גימלאות), תשט"ו-1955 1, בסופו יבוא:                                         |תיקון סעיף 23       |
|"אלמנה המקבלת קיצבה לפי סעיף 20 (1) או לפי סעיף 22 (1) ,והזכאית                                            |                    |
|לפי חוק הביטוח הלאומי, תשי"ד-1953 2, לקיצבת זיקנה וגם לקיצבת                                               |                    |
|שאיר ובחרה באחת מהן לפי סעיף 64 לאותו חוק, לא יחולו עליה הוראות                                            |                    |
|סעיף זה.                                                                                                   |                    |
|2. חוק זה יחול מיום כ"ח באדר ב' תשכ"ה (1 באפריל 1965) ואילך, גם על אלמנה                                   |תחולה               |
|שקיבלה קיצבה כאמור בסעיף 1 לפני פרסום חוק זה ברשומות.                                                      |                    |
|דברי-הסבר                                                                                                  |                    |
|חוק שירות המדינה (גימלאות)/ תשט"ו-1955, בסעיף 23 שבו, קובע כי אם אדם זכאי                                  |                    |
|לקיצבה לפי החוק' כלומר פנסיה של עובד מדינה, והוא זכאי גם לקיצבה לפי חוק הביטוח                             |                    |
|הלאומי, תשי"ד-1953, הרי תנוכה מהפנסיה מחצית קיצבת הביטוח שהוא זכאי לה או שליש                              |                    |
|מסכום הפנסיה, הכל לפי הסכום הקטן יותר. כן נזכרות בסעיף זה הוראות הפחתה נוספות                              |                    |
|ברוח דומה.                                                                                                 |                    |
|החוק מורה כי עובד שנפטר בזמן שירותו תשולם הפנסיה, בין היתר לאלמנתו בשיעור                                  |                    |
|של ארבעים אחוז ממשכורתו הקובעת ואילו עובד שנפטר לאחר צאתו לפנסיה, תהיה אלמנתו                              |                    |
|זכאית לחמישים אחוז מהפנסיה.                                                                                |                    |
|אין؀ࠂࠌࠎ כל הצדקה, שאלמנה המבוטחת מכוח עצמה בביטוח לאומי - וביחוד עקרות בית                                 |                    |
|או נשים עובדות- תופלה לרעה, ומשנפטר בן-זוגה, שהיה עובד מדינה, ינכו מהפנסיה שהיא                            |                    |
|זכאית לה מכוח הנפטר את הסכומים הנ"ל. אילולא נפטר בן-הזוג היה הוא מקבל את הפנסיה                            |                    |
|במלואה, ובת-זוגו היתה מקבלת את קיצבת הזקנה לה היא זכאית. עתה, משנפטר בן-הזוג                               |                    |
|עובד המדינה, מפחיתים סכום זה ללא כל הצדקה סבירה, מה עוד שהאלמנה ממילא אינה                                 |                    |
|מקבלת את מלוא שיעור הפנסיה.                                                                                |                    |
|לפיכך מוצע התיקון לחוק כך, שהוראות הניכוי לא יחולו על המקרה בו מקבלת                                       |                    |
|אלמנה קיצבת זיקנה מכוח עצמה ופנסיה כוח בן-זוגה, שהיה עובד מדינה ונפטר.                                     |                    |
