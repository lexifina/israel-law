|מתפרסמת בזה הצעת חוק מטעם הממשלה:                      |

|חוק-יסוד: נשיא המדינה (תיקון)                          |

|1. בחוק-יסוד 5 נשיא המדינה 1, בסעיף 23, בסופו יבוא:                                                          |תיקון סעיף 23     |
|"(ד) נתפנה מקומו של יושב ראש הכנסת או שיצא יושב ראש                                                          |                  |
|הכנסת את גבולות המדינה או שקבעה ועדת הכנסת ברוב קולות שנבצר                                                  |                  |
|ממנו למלא תפקידו כנשיא המדינה בפועל או כממלא מקום נשיא המדינה'                                               |                  |
|יכהן נשיא בית המשפט העליון כנשיא המדינה בפועל או כממלא מקום                                                  |                  |
|נשיא המדינה, הכל לפי הענין, עד שהכנסת תבחר יושב ראש אחר או                                                   |                  |
|שיושב ראש הכנסת ישוב ארצה או שועדת הכנסת תקבע' כרוב קולות'                                                   |                  |
|כי לא נבצר עוד ממנו למלא תפקידו כאמור.                                                                       |                  |
|(ה) בכהונתו כנשיא המדינה בפועל או כממלא מקום נשיא המדינה                                                     |                  |
|ימלא נשיא בית המשפט העליון את התפקידים המוטלים על נשיא המדינה                                                |                  |
|בחוק וישתמש בסמכויות הנתונות לנשיא המדינה לפי החוק' וכן ימלא                                                 |                  |
|תפקידי יושב ראש הכנסת לפי הסעיפים 5' 6 ו-24 (א) (1) ויפרסם ברשו-                                             |                  |
|؀ࠂࠌࠎמות הודעה על תחילת כהונתו כנשיא המדינה בפועל או כממלא מקום                                               |                  |
|נשיא המדינה' ועל סיום כהונה זו."                                                                             |                  |
|דברי הסבר                                                                                                    |                  |
|חוק-יסוד: נשיא המדינה-קובע שבהתפנות מקומו של נשיא המדינה יכהן יושב ראש                                       |                  |
|הכנסת כנשיא המדינה בפועל ובתקופה שנשיא המדינה הפסיק זמנית למלא תפקידו ולהשתמש                                |                  |
|בסמכויותיו' יכהן יושב ראש הכנסת כממלא מקום נשיא המדינה. אין הוראות בחוק למקרה                                |                  |
|שבאותו זמן יתפנה גם מקומו של יושב ראש הכנסת או שגם ממנו נבצר למלא את תפקידיו.                                |                  |
|התיקון המוצע בא לקבוע הסדר למקרים כאלה.                                                                      |                  |
