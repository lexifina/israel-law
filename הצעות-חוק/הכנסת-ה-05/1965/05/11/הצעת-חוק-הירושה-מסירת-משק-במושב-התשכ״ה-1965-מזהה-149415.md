|מתפרסמות בזה הצעות חוק מטעם הממשלה                    |

|חוק הירושה (מסירת משק במושב), תשכ"ה-1965                                      |

|1. בחוק הירושה, תשכ"ה-1965  1(להלן - החוק העיקרי), אחרי סעיף 114' יבוא;                                  |הוספת סעיף 114א         |
|114א (א) בסעיף זה -                                                                     |"משק במושב      |                        |
|"מושב" - אגודה שיתופית חקלאית שהיא ישוב כפרי נפרד ומטרותיה                              |                |                        |
|העיקריות הן לארגן ולהסדיר את התיישבות חבריה כאיברים עובדים                              |                |                        |
|עבודה עצמית' מחזיקים ברכוש פרטי ומקיימים שיתוף בהספקה'                                  |                |                        |
|בשיווק ובעזרה הדדית' וכן לקבל על עצמה את התפקידים הכרוכים                               |                |                        |
|בניהול שלטון מקומי;                                                                     |                |                        |
|"משק" - משק חקלאי במושב, לרבות הציוד והאינוונטר החי הקשורים                             |                |                        |
|לו וזכויותיו של בעל המשק במושב ובמפעלים שיתופיים שבמושב.                                |                |                        |
|(ב) היה בעזבונו של חבר מושב משק' יימסר המשק' כיחידה                                     |                |                        |
|אחת' ליורש אחד המוכן ומסוגל לקיימו' כחבר באותו מושב ואין לו'                            |                |                        |
|בשעת המסירה' משק נוסף במושב זה או במושב אחר.                                            |                |                        |
|(ג) היו יורשים אחדים כאמור בסעיף קטן (ב) ואין הסכמה ביני-                               |                |                        |
|הם, יימסר המשק לאחד מהם לפי סדר עדיפות זה:                                              |                |                        |
|(1) בן-זוגו של המוריש שגר אתו במשק ערב מותו;                                            |                |                        |
|(2) ילדו של המוריש שעיבד את המשק לבדו או עם המוריש                                      |                |                        |
|ערב מותו' או שעיבד אותו עם המוריש חמש שנים או יותר                                      |                |                        |
|ולא עברו שנתיים מיום שחדל לעבדו עד מות המוריש;                                          |                |                        |
|(3) יורש אחר שנקבע לכך על-ידי המוריש בצוואתו'                                           |                |                        |
|ובאין קביעה כזאת - יורש אחר על פי דין,                                                  |                |                        |
|אולם אם המוריש ירש את המשק מבן-זוגו הקודם ומאותו בן-זוג נשאר                            |                |                        |
|ילד שנתקיימו בו תנאי פסקה (2)' עדיף ילד זה על שאר היורשים.                              |                |                        |
|(ד) היו שני יורשים או יותר בדרגת עדיפות שווה לפי סעיף קטן (ג),                          |                |                        |
|ואין הסכמה ביניהם, יימסר המשק למי שהמוריש קבע לכך בצוואתו,                              |                |                        |
|ובאין קביעה כזאת - למי שיקבע בית המשפט.                                                 |                |                        |
|(ה) בית המשפט' בבואו לקבוע יורש לפי סעיף זה' יתחשב בטובת                                |                |                        |
|המשק' במסגרת המושב ובסיכויי היורשים האחרים להתפרנס מחוץ                                 |                |                        |
|למשק.                                                                                   |                |                        |
|(ו) היה בין היורשים קטין שאפשר לראותו מועמד לקבלת המשק                                  |                |                        |
|לפי סעיף זה' רשאי בית המשפט לדחות את מסירת המשק ולמנות מנהל                             |                |                        |
|עזבון שינהל את המשק עד שיתברר אם יש למסרו לקטין.                                        |                |                        |
|(ז) יורש אשר קיבל את המשק לפי סעיף זה' יפצה את היורשים                                  |                |                        |
|האחרים, במידה ששווי המשק עולה על המגיע לו מן העזבון, ויחולו                             |                |                        |
|עליו' בשינויים המחוייבים, הוראות סעיף 114 (ד).                                          |                |                        |

|1 ס"ח 446, תשכ"ה, עמ' 63.     |
