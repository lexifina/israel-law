|חוק בנינים גבוהים (חובה להתקין מעלית), תשכ"ה-1965                                       |

|1. על אף האמור בכל ודקיק, לא יינתן רשיון לבניית בנין שיש בו ארבע קומות או                                    |חוגה להתקין         |
|יותר' מעל לקומת הקרקע, אלא אם תותקן בבנין מעלית.                                                             |מעלית               |
|2 .שר הפנים, באישור ועדת הפנים של הכנסת, רשאי בצו לפטור סוגים של בניינים                                     |סמכות לפטור         |
|מהוראות סעיף .1                                                                                              |                    |
|3. בנין שיש בו שמונה קומות או יותר, מעל לקומת הקרקע, חייב בעליו להתקין בו                                    |חובה להתקין         |
|גנרטור להפעלת המעלית בשעת הפסקת זרם החשמל בכנין.                                                             |גנרטור              |
|4. שר הפנים ממונה על ביצוע חוק זה והוא רשאי להתקין תקנות לביצועו.                                            |ביצוא ותקגות        |
|דברי הסבר                                                                                                    |                    |
|פקודת בנין ערים, 1936 1, אינה קובעת את התנאים שיש להתנותם לרשיונות בניה                                      |                    |
|והדבר ניתן להסדר על-ידי חקיקת משנה. עם ריבוי הבנינים בני קומות מרובות, מתברר                                 |                    |
|כי לעתים קרובות נגרם לדיירי הקומות הגבוהות סבל רב על-ידי ההכרח לעלות ולחזור                                  |                    |
|ולעלות פעמים רבות מדי יום ביומו, וביחוד כשהמדובר באנשים זקנים או באמהות מטופלות                              |                    |
|בילדים קטנים.                                                                                                |                    |
|החוק המוצע בא לתקן מצב זה בקבעו כי אין לתת רשיון לבנינים שיש בהם ארבע                                        |                    |
|קומות או יותר בנוסף לקומת הקרקע, אלא אם תותקן בהם מעלית. ؀ࠂࠌࠎעם זאת מאפשר החוק                               |                    |
|מתן פטור לסוגים מסויימים של מבנים - הכוונה ביהוד לבנינים שאינם משמשים למגורים                                |                    |
|או שמספר הדיירים בהם או בקומות הגבוהות שבהם הוא מצומצם ביותר.                                                |                    |
|תופעה שלילית אחרת שיש למצוא לה פתרון היא השבתת מעליות על-ידי הפסקת                                           |                    |
|זרם החשמל. הפסקות כאלה קורות לעתים לא רחוקות ובבנינים גבוהים מאוד הן שוללות                                  |                    |
|מדיירי הקומות הגבוהות כל אפשרות מעשית להגיע למקומות מגוריהם. ולכן מוצע, לחייב                                |                    |
|התקנת גנרטור בבנינים בני שמונה קומות או יותר, על מנת להבטיח הפעלתה של המעלית                                 |                    |
|בכל עת ללא תלות באספקת חשמל סדירה.                                                                           |                    |
