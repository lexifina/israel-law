|חוק חופשה שנתית (תיקון מס' 2), תשכ"ה-1965                                 |

|1. בסעיף 3 לחוק חופשה שנתית, תשי"א-1951  1(להלן - החוק העיקרי), בסעיף קטן (א)                                 |תיקון סעיף 3      |
|במקום הפסוק הראשון יבוא:                                                                                      |                  |
|"אורך החופשה לכל שנת עבודה אצל מעביד אחד או במקום עבודה                                                       |                  |
|אחד הוא:                                                                                                      |                  |
|(1) בעד 4 השנים הראשונות - 14 יום;                                                                            |                  |
|(2) בעד השנה החמישית - 16 יום;                                                                                |                  |
|(3) בעד השנה השישית - 18 יום;                                                                                 |                  |
|(4) בעד השנה השביעית - 21 יום;                                                                                |                  |
|(5) בעד השנה השמינית ואילך - יום נוסף לכל שנת                                                                 |                  |
|עבודה עד לחופשה של 4 שבועות;".                                                                                |                  |
|2. במקום סעיף 15 לחוק העיקרי יבוא:                                                                            |החלפת סעיף 15     |
|15. (א) עובד בשכר העובד אצל מעביד אחד או במקום עבודה אחד                                  |"תשלום תמורת      |                  |
|לפחות יום אחד אך פחות מ-75 ימים רצופים כאמור בסעיף 4' בין בשנת                            |חופשה             |                  |
|עבודה אחת ובין בשתי שנות עבודה רצופות' ואין ביניהם חוזה עבודה                             |                  |                  |
|בכתב לתקופת עבודה רצופה העולה על 74 ימים - ישלם בעדו המעביד                               |                  |                  |
|תמורת חופשה' 4% לפחות משכר העבודה.                                                        |                  |                  |
|(ב) תמורת החופשה תשולם לקרן החופשה של ענף העבודה שבו                                      |                  |                  |
|עבד העובד או בכל דרך אחרת שנקבעה בתקנות.                                                  |                  |                  |
|(ג) היתה תמורת החופשה משתלמת לקרן החופשה' חייב המעביד                                     |                  |                  |
|לשלמה בתחילת החודש שלאחר חודש העבודה' לפי שכר העבודה                                      |                  |                  |
|המשתלם בחודש שלפניו לעובדים כאמור בסעיף קטן (א); המשיך העובד                              |                  |                  |
|לעבוד אצל אותו מעביד או באותו מקום עבודה מעל ל-74 ימים רצופים                             |                  |                  |
|ישלם לו המעביד את דמי החופשה, או פדיון חופשה, הכל לפי הענין,                              |                  |                  |
|וקרן החופשה תחזיר למעביד' לפי בקשתו' את הסכומים שהעביר לה                                 |                  |                  |
|בשל אותו עובד.                                                                            |                  |                  |
|(ד) קרן החופשה רשאית - בהסכמת העובדים שתינתן בהסכם                                        |                  |                  |
|קיבוצי' בחוזה עבודה או בדרך אחרת שתיקבע - לבוא לידי הסכם עם                               |                  |                  |
|המעביד בדבר תשלום דמי החופשה לקרן גם בעד עובדים שעבדו אצלו                                |                  |                  |
|מעל ל-75 ימים.                                                                            |                  |                  |
|(ה) שר העבודה רשאי לקבוע בתקנות את המועדים והסדרים                                        |                  |                  |
|להחזרת הסכומים על ידי קרן החופשה' כאמור."                                                 |                  |                  |

|1 ס"ח תשי"א, עמ' 234; תשי"ז, עמ' 134.      |

|דברי הסבר                                                                                                   |
|התיקון המוצע בא לקבוע תקופות חופשה ؀ࠂࠌࠎࠒࠖ࠘מודרגות על יסוד ותק של העובד במקום                                |
|העבודה' עד למקסימום של 4 שבועות חופשה לשנה* במקום החופשה השבתית האחידה של                                   |
|שבועיים עד כה (סעיף 1).                                                                                     |
|מוצע עוד' שהתשלום לקרן החופשה בעד עובדים המועבדים פחות מ-75 ימים ישולם                                      |
|באופן רגיל בתחילת כל חודש ולא לאחר סיום כל תקופות עבודתם כפי שהיה עד כה,                                    |
|תיקון זה יבטיח שהמעבידים אמנם יעבירו את תשלומי תמורת החופשה לקרן החופשה                                     |
|כסדרם. כן ניתנת לפי החוק המוצע אפשרות לבצע תשלומי חופשה באמצעות קרן החופשה                                  |
|גם לגבי עובדים המועבדים מעל 75 ימים, לפי הסכם עמ הקרן ובהסכמת העובדים הנוגעים                               |
|לענין, אפשרות שלא היתה קיימת ער כה (סעיף 2).                                                                |
|ואלה סעיפי החוק העיקרי שהחוק המוצע בא לתקנם:                                                                |
|3. (א) אורך החופשה הוא 14 יום לבל שבת עבודה אצל מעביד אחד או במקום עבודה אחד;            |"אורך החופשה      |
|אך שר העבודה רשאי לקבוע, בתקנות, לעבודה מסויימת חופשה ארוכה מזו, אם ראה צורך בכך         |                  |
|מטעמים שבבריאות העובד או שבנסיבות העבודה.*                                               |                  |
|15. (א) עובד בשכר שעבד אצל מעביד אחד, או במקום עבודה אחד, לפחות יום אחד אך               |"תשלום חמורת      |
|פחות מ-75 ימים רצופים כאמור בסעיף 4, בין בשנת עבודה אחת ובין בשתי שנות עבודה             |חופשה             |
|רצופות, ישלם בעדו המעביד תמורת חופשה 4% לפחות משכר העבודה.                               |                  |
|(ב) תמורת החופשה תשולם לקרן החופשה של ענף העבודה שבו עבד העובר או בכל                    |                  |
|דרך אחרת שתיקבע בתקנות; תמורת חופשה המשתלמת לקרן חופשה, חייב המעביד לשלמה לכל            |                  |
|המאוחר תוך תשעה ימים מיום שבו חדל העובד לעבוד.                                           |                  |
|(ג) חמורת החופשה ששולמה לקרן חופשה תימסר לעובד לפי הוראות תקנון הקרן,                    |                  |
|ותמורת החופשה ששולמה בדרך אחרת תימסר לעובד בדרך שתיקבע בתקנות.*                          |                  |
