|חוק פיצויי פיטורים (תיקון מס' 2), תשכ"ה-1965                                |

|1. האמור בסעיף 12 לחוק פיצויי פיטורים, תשכ"ג~1963  1,יסומן "12 (א)" ואחריו יבוא:                          |תיקון סעיף 12       |
|"(ב) שר העבודה רשאי' לאחר התייעצות בשר האוצר ובאישור                                                      |                    |
|ועדת העבודה של הכנסת' להגדיל בתקנות את שיעור פיצויי הפיטורים                                              |                    |
|לעובד בשכר; תקנות כאמור יכול שיהיו כלליות או לפי ענפי עבודה."                                             |                    |
|דברי הסבר                                                                                                 |                    |
|סעיף 12 לחוק פיצויי פיטורים, תשכ"ג-1963,מעמיד את שיעור פיצויי הפיטורים                                    |                    |
|המגיעים לעובד לפי החוק האמור על שכר חודש לכל שנת עבודה לעובד במשכורת (היינו                               |                    |
|עובד ששכרו משתלם על בסיס של חודש או תקופה ארוכה יותר), ושכר שבועיים לעובד                                 |                    |
|בשכר (היינו' למעשה' עובד יומי).                                                                           |                    |
|ההבדל בין עובד חדשי לעובד יומי נובע מתנאי עבודה שהיו קיימים בעבר' ושאין                                   |                    |
|להם הצדקה ביחסי העבודה בהווה.                                                                             |                    |
|מוצע איפוא להעניק לשר העבודה את הסמכות להעלות בתקנות שיותקנו לאחר                                         |                    |
|התייעצות؀ࠂࠊࠌ עם שר האוצר ובאישור ועדת העבודה של הכנסת' את שיעור הפיצויים המגיעים                          |                    |
|לעובד בשכר במגמה להשוותם למשתלמים לעובד כמשכורת.                                                          |                    |

|1 ס''ח תשכ''ג, עמ' 136; ס"ח תשכ"ד, עמ' 167.                 |
