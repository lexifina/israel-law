|1. (א) לא יותקן קו טלפון מרכזי ישיר נפרד או קו טלפון מרכזי ישיר משותף (להלן -                             |הלוואה למדינה      |

|קו הטלפון או את העברתו הלוואה למדינה על פי חוק זה בסכום של 400 לירות (להלן -                              |                   |
|הלוואה).                                                                                                  |                   |

|העברתו לאחר על פי פקודת בתי הדואר 1.                                                                      |                   |
|2. ההלוואה תיפרע בשלמותה בתום 5 שנים מיום נתינתה בתוספת ריבית בסכום של                                    |פרעון הלוואה       |
|106.64 לירות, כשהקרן והריבית צמודות למדד יוקר המחיה.                                                      |                   |
|3, (א) נתן אדם הלוואה בשל קו טלפון ולפני תום 5 שנים מיום נתינתה חדל להיות                                 |פרעון מוקדם        |
|מנוי על אותו קו' תוחזר ההלוואה בשלמותה תוך שלושים יום מיום שחדל להיות מנוי                                |                   |
|בתוספת ריבית בסכומים המפורטים בסעיף קטן (ב), כשהקרן והריבית צמודות למדד יוקר                              |                   |
|המחיה.                                                                                                    |                   |
|(ב) ואלה סכומי הריבית:                                                                                    |                   |

|19.36 לירות?                                                                                              |                   |
|(2) הוחזרה ההלוואה לאחר תום 24 חדשים ולפני תום 36 חדשים מיום נתינתה-                                      |                   |
|39.65 לירות:                                                                                              |                   |
|(3) הוחזרה ההלוואה לאחר תום 36 חדשים ולפני תום 48 חדשים מיום נתינתה-                                      |                   |
|60.92 לירות:                                                                                              |                   |
|(4) הוחזרה ההלוואה לאחר תום 48 חדשים ולפני תום 60 חדשים מיום נתינתה-                                      |                   |
|83.25 לירות.                                                                                              |                   |
|4. אם ביום פרעונה של הלוואה יהיה המדד החדש גבוה מן המדד היסודי, ישולמו ההלוואה                            |תנאי הצמדה         |

|5. לענין הסעיפים 2 עד 4 -                                                                                 |הגדרה              |
|"מדד יוקר המחיה" או "מדד" - מדד המחירים, המתפרסם על ידי הלשכה המרכזית לסט-                                |                   |
|טיסטיקה ולמחקר כלכלי, ולרבות אותו מדד אף אם יתפרסם על ידי מוסד ממשלתי אחר                                 |                   |
|וכן כל מדד רשמי שיבוא במקומו, בין אם יהיה בנוי על אותם נתונים שעליהם בנוי                                 |                   |
|המדד הקיים ובין אם לאו; אם יבוא מדד אחר תקבע הלשכה המרכזית לסטטיסטיקה                                     |                   |
|ולמחקר כלכלי את היחס שבינו לבין המדד המוחלף;                                                              |                   |
|"המדד היסודי" - לענין מילווה שניתן בין ה-1 בינואר וה-30 ביוני של כל שנה - המדד                            |                   |
|שנתפרסם בחודש דצמבר של השנה הקודמת, ולענין מילווה שניתן בין ה-1 ביולי וה-31                               |                   |
|בדצמבר של כל שנה - המדד שנתפרסם בחודש יוני של אותה שנה;                                                   |                   |
