|מתפרסמת בזה הצעת חוק מטעם הממשלה :                    |

|חוק הגנת הדייר (שכירות בדמי מפתח), תשכ"ב-1962                                         |

|1. (א) דייר שנתן בעד מושכר דמי מפתח כמשמעותם בחוק דמי מפתח, תשי"ח-                                                 |הפחתה למשלמי       |
|1958 1, לפני תחילתו של חוק זה, יופחת בחמישים אחוזים הסכום הנוסף שעליו לשלם לפי                                     |דמי מפתח           |
|התקנות בדבר שיעורי דמי השכירות בדירות ובבתי עסק שנתפרסמו ביום כ"ז בניסן                                            |                   |
|תשכ"כ (1 במאי 1962) ושיכנסו לתקפן ביום ב' באלול תשכ"ב (1 בספטמבר 1962), ובלבד                                      |                   |
|שדמי השכירות שעליו לשלם לא יפחתו מדמי השכירות שהדייר שילם למעשה לפני תחילתו                                        |                   |
|של חוק זה.                                                                                                         |                   |
|(ב) ההפחתה תתחיל מיום תחילתן של התקנות האמורות ותסתיים כתום עשר שנים                                               |                   |
|מיום שהדייר שכר לראשונה את המושכר בהסכם שכירות שבקשר אליו ניתנו דמי המפתח.                                         |                   |
|דברי הסבר                                                                                                          |                   |
|ביום כ"ז בניסן תשכ"ב (1 במאי 1962) פרסמה הממשלה/ על פי סעיפים 11 ו-18 לחוק                                         |                   |
|הגנת הדייר, תשי"ד-1954 2, תקנות בדבר؀ࠂࠌࠎ שיעורי דמי השכירות בדירות ובבתי עסק,                                      |                   |
|שלפיהן הועלו דמי השכירות במושכרים השונים. החוק המוצע בא לקבוע שלגבי דייר                                           |                   |
|ששילם דמי מפתח תופחת התוספת שעליו להוסיף לדמי השכירות כדי מחצית מן ההעלאה                                          |                   |
|שלפי התקנות האמורות. הפחתה זו תסתיים בתום עשר שנים מיום שהוסכם על השכירות                                          |                   |
|בדמי מפתח.                                                                                                         |                   |
|כדי להסיר ספק בדבר חוקיותן של ההבחנות שנוספו בתקנות האמורות על ההבחנות                                             |                   |
|הקיימות בחוק הגנת הדייר, תשי"ד-1954, נאמר במפורש שהתקנות כפי שנוסחו יהיו בנות                                      |                   |
|תוקף ביום שיקבע לפי החוק.                                                                                          |                   |
