|1. במקום סעיף 9 לחוק המעבר. תש"ט-1949 1, יבוא:                                                                          |החלפת סעיף 9       |
|9. (א) לאחר התייעצות עם נציגי סיעות בכנסת יטיל נשיא המדינה                                       |"התפקיד               |                   |
|על אחד מחברי הכנסת את התפקיד להרכיב את הממשלה.                                                   |להרכיב ממשלה          |                   |
|(ב) הודיע חבר הכנסת לנשיא המדינה, תוך שלושה ימים מהיום                                           |                      |                   |
|שהתפקיד הוטל עליו, שאינו מוכן לקבלו, יטיל הנשיא את התפקיד על                                     |                      |                   |
|חבר כנסת אחר.                                                                                    |                      |                   |
|(ג) חבר הכנסת שנשיא המדינה הטיל עליו את התפקיד להרכיב                                            |                      |                   |
|ממשלה, והוא לא הודיע לנשיא כאמור בסעיף קטן (ב), נתונה לו תקופה                                   |                      |                   |
|של 28 יום למילוי תפקידו.                                                                         |                      |                   |
|(ד) נשיא המדינה רשאי להאריך את התקופה של 28 ימים עד 14                                           |                      |                   |
|ימים נוספים ולהאריכה בשביה עד 7 ימים נוספים, אם ייראה לו הדבר                                    |                      |                   |
|מוצדק על פי דין וחשבון שמסר לו אותו חבר הכנסת לפני עבור התקופות                                  |                      |                   |
|האמורות.                                                                                         |                      |                   |
|(ה) לא הודיע חבר הכנסת לנשיא המדינה עד תום התקופות שניתנו                                        |                      |                   |
|לו לפי הסעיפים הקטנים (ג) או (ד) שהרכיב ממשלה, או שהודיע לנשיא                                   |                      |                   |
|המדינה לפני כן שאין בידו להרכיב ממשלה, יעשה נשיא המדינה שנית                                     |                      |                   |
|כאמור בסעיפים הקטנים (א) ו--(ב); לחבר הכנסת שעליו הוטל התפקיד                                    |                      |                   |
|לפי סעיף קטן זה נתונה תקופה של 28 ימים למילוי תפקידו ולא יחולו؀ࠂࠌࠎ לגביו                         |                      |                   |
|הוראות סעיף קטן (ד).                                                                             |                      |                   |
|(ו) עברה גם התקופה של 28 ימים הנתונה לחבר הכנסת שעליי                                            |                      |                   |
|הוטל התפקיד בהתאם לסעיף קטן (ה), וחבר הכנסת לא הודיע לנשיא                                       |                      |                   |
|המדינה כי הרכיב ממשלה, אך שהודיע לנשיא לפני כן שאין בידו להרכיב                                  |                      |                   |
|ממשלה, רשאי נשיא המדינה להמשיך ולהטיל את התפקיד; זולת אם                                         |                      |                   |
|נציגי סיעות שחבריהן מהווים רוב חברי הכנסת המליצו לפניו להטיל את                                  |                      |                   |
|התפקיד על חבר כנסת פלוני. יטילו על אותו חבר הכנסת.                                               |                      |                   |
|(ז) הטיל נשיא המדינה על חבר הכנסת את התפקיד להרכיב את                                            |                      |                   |
|הממשלה, יודיע על כך מיד ליושב ראש הכנסת.                                                         |                      |                   |
|(ח) הרכיב חבר הכנסת ממשלה, יודיע על כך מיד לנשיא המדינה                                          |                      |                   |
|וליושב ראש הכנסת,                                                                                |                      |                   |
