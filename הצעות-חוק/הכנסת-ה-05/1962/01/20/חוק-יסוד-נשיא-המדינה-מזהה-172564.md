|מתפרסמת בזה הצעת חוק מטעם הממשלה:                                                                                     |
|חוק-יסוד: נשיא המדינה                                                                                                 |

|1. הנשיא עומד בראש המדינה.                                                                                 |מעמד               |
|2. נשיא המדינה נבחר על ידי הכנסת.                                                                          |בחירה              |
|3. כל אזרח ישראלי שהוא תושב ישראל, בן ארבעים שנה ומעלה, כשיר להיבחר נשיא                                   |כשירות             |
|המדינה.                                                                                                    |                   |
|4. בחירת נשיא המדינה תיערך לא יותר מתשעים יום ולא פחות משלושים יום לפני תום                                |מועד הבחירה        |
|תקופת כהונתו של נשיא המדינה הקודם; נתפנה מקומו של נשיא המדינה לפני תום תקופת                               |                   |
|כהונתו' תיערך הבחירה תוך ארבעים וחמישה ימים מיום שנתפנה מקומו; יום הבחירה בתוך                             |                   |
|המועד לפי סעיף זה' ייקבע על ידי יושב ראש הכנסת והוא יודיע על כך ככתב לכל חברי                              |                   |
|הכנסת לפחות עשרים יום מראש.                                                                                |                   |
|5. (א) נקבע יום הבחירה, רשאים עשרים, לפחות, מחברי הכנסת להציע מועמד; ההצעה                                 |הצעת מועמדים       |
|תהיה בכתב ותימסר ליושב ראש הכנסת' בצירוף הסכמת המועמד בכתב או במברק' לא                                    |                   |
|יאוחר מעשרה ימים לפני יום הבחירה. לא ישתף עצמו חבר הכנסת ביותר מהצעת מועמד                                 |                   |
|אחת.                                                                                                       |                   |
|(ב) יושב ראש הכנסת יודיע לכל חברי הכנסת בכתב' לא יאוחר משבעה ימים לפני                                     |                   |
|יום הבחירה, על כל מועמד שהוצע ועל שמות חברי הכנסת שהציעוהו, ויכריז על המועמדים                             |                   |
|בפתיחת ישיבת הבחירה.                                                                                       |                   |
|6. בחירת נשיא המדינה תהיה בהצבעה חשאית בישיבת הכנסת שנועדה לענין זה בלבד.                                  |הצבעה              |
|7, המועמד שקיבל רוב קולות של כל חברי הכנסת - הוא הנבחר; לא קיבל אף מועמד                                   |בחירה ברוב         |
|אחד רוב כאמור מצביעים שנית' ואם היה כך גם בהצבעה השניה' חוזרים ומצביעים והמועמד                            |קולות              |
|שקיבל באחת ההצבעות הנוספות קולותיהם של רוב המשתתפים בהצבעה - הוא הנבחר.                                    |                   |
|8. סמוך לבחירתו ככל האפשר יצהיר הנשיא הנבחר בפני הכנסת הצהרת אמונים זו:                                    |הצהרת אמונים       |
|"אני מתחייב לשמור אמונים למדינת ישראל ולחוקיה ולמלא באמונה                                                 |                   |
|את תפקידי כנשיא המדינה".                                                                                   |                   |
|9. הנשיא הנבחר, לאחר שהצהיר את הצהרת האמונים, ייכנס לתפקידו בתום תקופת                                     |תחילת הכהונה       |
|כהונתו של נשיא המדינה הקודם; נתפנה מקומו של נשיא המדינה לפני שהנבחר הצהיר את                               |                   |
|הצהרת האמונים, ייכנס הנשיא הנבחר לתפקידו עם הצהרת האמונים.                                                 |                   |
|10, תקופת כהונתו של נשיא המדינה היא חמש שנים מיום שנכנס לתפקידו.                                           |תקופת הכהונה       |
|11, נשיא המדינה -                                                                                          |תפקידי הנשיא       |
|(1) יאמין נציגים דיפלומטיים של המדינה' יקבל האמנתם של נציגים דיפלו-                                        |                   |
|מטיים שמדינות-חוץ שיגרו לישראל, יסמיך נציגים קונסולריים של המדינה                                          |                   |
|ויקיים מינוים של נציגים קונסולריים שמדינות-חוץ שיגרו לישראל;                                               |                   |
|(2) ימלא כל תפקיד שיוחד לו בחוק בקשר להרכבת הממשלה, למינוים של                                             |                   |
|נושאי משרות ולכל דבר אחה                                                                                   |                   |

|ותשלומים אחרים  |לרבות אלה שישולמו לשאיריו' ייקבעו על-ידי החלטת הכנסת והיא רשאית להסמיך לכך את                               |
|                |ועדת הכספים.                                                                                                |

|21. (א) כמקרים המנויים להלן יכהן יושב ראש הכנסת, בתקופה המפורשת לגבי אותו                                     |ממלא מקום של      |
