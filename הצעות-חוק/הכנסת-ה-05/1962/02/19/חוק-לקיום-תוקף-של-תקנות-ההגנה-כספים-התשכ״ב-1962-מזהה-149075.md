|בתוספת, יעמדו בתקפן עד יום כ"ז באדר ב' תשכ"ה (31 במרס 1965).                                                         |                   |
|2. הרשאה, היתר או פטור שמותר לתיתם לאחר מעשה על פי תקנה 2 (3) לתקנות                                                 |הכשר               |
|העיקריות, מותר לתיתם בין אם המעשה נעשה לפני תחילת חוק זה ובין אם נעשה לאחר                                           |פעולות             |
|תחילתו.                                                                                                              |                   |
|3. תחילתו של חוק זה ביום כ''ו באדר ב' תשכ"ב (1 באפריל 1962).                                                         |תחילה              |
|תוספת                                                                                                                |                   |
|(סעיף 1)                                                                                                             |                   |
|בתקנה 2 לתקנות העיקריות, אחרי תקנת משנה (2) יבוא -                                                                   |                   |
|,,(3) הרשאה, היתר או פטור ששר האוצר או מי שמונה על ידיו רשאים לתת                                                    |                   |
|לפי תקנות אלה, רשאים הם לתיתם גם לאחר מעשה ומשניתנו כאמור, רואים                                                     |                   |
|אותם כאילו ניתנו לפני המעשה."                                                                                        |                   |
|דברי הסבר                                                                                                            |                   |
|תקנות ההגנה (כספים), 1941' מהוות את הבסיס החוקי לפיקוח על מטבע-חוץ. מאז                                              |                   |
|התקנתן הוכנסו בהן מספר שינויים, ובשנים האחרונות הותאמו לצרכיה המיוחדים של                                            |                   |
|המדינה. תקפן הוארך מדי פעם בפעם ולאחרונה בחוק לקיום תוקף של תקנות ההגנה                                              |                   |
|(כספים), תשכ"א-1961, עד יום כ"ה באדר ב' תשכ"ב (31 במרס 1962). מוצע להאריך את                                         |                   |
|תוקף התקנות ؀ࠂࠊࠌלמשך שלוש שנים, עד ליום כ"ז באדר ב' תשכ"ה (31 במרס 1965) (סעיף 1).                                   |                   |
|תוך כדי הפעלת התקנות נתברר כי אנשים שביצעו עסקאות הנתונות לפיקוח על פי                                               |                   |
|התקנות' לא ביקשו בתום-לב הרשאה, היתר או פטור הדרושים לפי התקנות. עסקאות אלה,                                         |                   |
|שלגביהן לא ניתנו ההרשאה, ההיתר או הפטור אינן חוקיות ואינן ניתנות לאכיפה בבתי                                         |                   |
|המשפט.                                                                                                               |                   |
|בעסקאות עם תושבי-חוץ נתברר כי במספר פעמים לא הופנתה תשומת-לבם לתקנות                                                 |                   |
|ההגנה (כספים) ולכן לא הגישו את הבקשה למתן ההיתר הדרוש. על מנת להסיר מכשול                                            |                   |
|מלפני עיוור מוצע להסמיך את שר האוצר או מי שמונה על ידיו לתת את ההרשאה, ההיתר                                         |                   |
|או הפטור לאחר מעשה (סעיף 3).                                                                                         |                   |
