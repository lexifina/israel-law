|מתפרסמות בזה הצעות חוק מטעם הממשלה:                     |

|חוק לתיקון פקודת האגודות השיתופיות (מס' 2), תשכ"ב-1962                                               |

|1 . בסעיף 65 לפקודת האגודות השיתופיות1' בסעיף קטן (2)' אתרי פסקה (כה) יבוא:                                       |תיקון סעיף 66      |
|"(כו) לקבוע אגרות בעד רישום איגרת-חוב, משכנתה, שעבוד,                                                             |                   |
|או מסמך אחר אשר הפקודה דורשת או מרשה את רישומו                                                                    |                   |
|וכל עובדה שהרשם נדרש או מורשה בפקודה לרשמה."                                                                      |                   |
|2. אגרות בשיעור שנקבע בצו החברות (אגרות), תשי"ג-1953 2, שבגבו בין יום ב' בטבת                                     |הבשר פעולות        |
|תשי"ד (8 בדצמבר 1953) לבין תחילת חוק זה' בעד רישום פעולות האמורות בסעיף 1 רואים                                   |                   |
|אותן כאילו נגבו כדין.                                                                                             |                   |
|דברי הסבר                                                                                                         |                   |
|בשעתו היה רישום איגרות חוב' משכנתאות ושעבודים של אגודות שיתופיות חייב                                             |                   |
|באותן אגרות שהוטלו על רישומם לגבי חברות' וזאת על פי הוראה בסעיף 59 לפקודת                                         |                   |
|האגודות השיתופיות' המפנה לפקודת החברות בענין זה. וזו לשון ההוראה:                                                 |                   |
|"59. (1) פרט למותנה בסעיף 9(2) מפקודה זו, לא תחולנה הוראות                                                        |                   |
|פקודת החברות על אגודות רשומות אלא בכל הנרגע -                                                                     |                   |
|(א) לאיגרות חוב, משכנתאות ושעבודים.                                                                               |                   |
|האגרות בעד רישום כאמור נקבעו לפי פקודת החברות בצו' וכאמור חלו אותם צווים                                          |                   |
|גם על עניני האגודות השיתופיות.                                                                                    |                   |
|בשנת תשי"ד תוקנה פקודת؀ࠂࠌࠎ החברות על ידי חוק לתיקון פקודת החברות (הוראות                                          |                   |
|שונות), תשי"ד-1953, שהטיל על חברות אגרות שנתיות קבועות וביטל משום כך את תשלום                                     |                   |
|האגרות בעד הרישום כאמור. לגבי אגודות שיתופיות לא נעשה הסדר דומה, ואף אין כוונה                                    |                   |
|להטיל עליהן אגרות קבועות. גביית האגרות בעד פעולות הרישום האמורות לגבי אגודות                                      |                   |
|שיתופיות נמשכה על פי צווים שהיו קיימים ערב התיקון האמור' אף על פי שלאחר ביטול                                     |                   |
|האגרות האלה בפקודת החברות ניטל מן הצווים לענין זה הבסיס החוקי.                                                    |                   |
|החוק המוצע בא לתת בסיס חוקי לגביית אותן אגרות בעתיד ולהכשיר את הגביה                                              |                   |
|שנעשתה מיום ביטול האגרות לגבי החברות עד יום תחילת תקפו של חוק זה.                                                 |                   |
