|חוק המעבר (תיקון מס' 6), תשכ"ב-1961                                    |

|1, בסעיף 11 לחוק המעבר' תש"ט-1949 1, סעיף קטן (ז) יסומן כסעיף קטן (ח) ולפניו                                          |תיקון מעיף 11       |
|יבוא:                                                                                                                 |                    |
|"(ז) (1) חבר ממשלה ישא בפני הממשלה באחריות להצבעתו                                                                    |                    |
|במליאת הכנסת וכן להצבעת הסיעה שעליה הוא נמנה, במליאת                                                                  |                    |
|הכנסת;                                                                                                                |                    |
|(2) חבר ממשלה שהצביע במליאת הכנסת נגד הצעת הממ-                                                                       |                    |
|שלה או נמנע מן ההצבעה' שלא בהסכמתה המוקדמת של                                                                         |                    |
|הממשלה' דינו כדין מי שהתפטר מהממשלה מן היום שהממש-                                                                    |                    |
|לה תמסור על כך הודעה לפני הכנסת' ובלבד שההודעה                                                                        |                    |
|נמסרה תוך שבועיים מאותה הצבעה;                                                                                        |                    |
|(3) הצביעה הסיעה שעליה נמנה חבר ממשלה כעד הצעה                                                                        |                    |
|להביע לממשלה אי אמון, או נמנעה מן ההצבעה על הצעה                                                                      |                    |
|כזאת' או הצביעה במליאת הכנסת נגד הצעת הממשלה או                                                                       |                    |
|נמנעה מן ההצבעה' שלא בהסכמתה המוקדמת של הממשלה'                                                                       |                    |
|באחד הענינים הבאים:                                                                                                   |                    |
|(א) הצעת תקציב המדינה' חלק מחלקיו או פרט                                                                              |                    |
|מפרטיו;                                                                                                               |                    |
|(ב) הצעת חוקים והוראות חוק המקטינים את הכנסות                                                                         |                    |
|המדינה או מגדילים הוצאותיה - במישרין או בעקיפין-,                                                                     |                    |
|(ג) הצעות חוקים והוראות חוק והצעות אחרות                                                                              |                    |
|בענינים בטחוניים ומדיניים ובעניבים אחרים שהממשלה                                                                      |                    |
|החליטה עליהם מראש שתחול אחריות לפי סעיף קטן                                                                           |                    |
|זה'                                                                                                                   |                    |
|והחליטה הממשלה' תוך שבעה ימים מאותה הצבעה' שהיה                                                                       |                    |
|בכך משום הפרת האחריות לפי סעיף קטן זה, דינו של אותו                                                                   |                    |
|חבר ממשלה כדין מי שהתפטר מהממשלה מן היום שהממשלה                                                                      |                    |
|תמסור על כך הודעה לפני הכנסת. ההודעה תימסר תוך                                                                        |                    |
|שבועיים מהחלטת הממשלה האמורה;                                                                                         |                    |
|(4) הוראות פסקאות (2) ו-(3) לא יחולו על ענינים אשר                                                                    |                    |
|؀ࠂࠌࠎࠒࠖ࠘הממשלה החליטה לגביהם על חופש ההצבעה או זכות ההימנ-                                                             |                    |
|עות' הכל בסייגים שתקבע הממשלה בהחלטתה.                                                                                |                    |

|דברי הסבר                                                                                                              |
|אחריות הממשלה בפני הכנסת קבועה בסעיף 11 (1) לחוק המעבר, תש"ט-1949, בזו                                                 |
|הלשון:                                                                                                                 |
|"(1) הממשלה תשא באחריות משותפת לפעולותיה בפני                                                                          |
|הכנסת. תמסור לה דין וחשבון עליהן ותכהן כל עוד תיהנה                                                                    |
|מאמון הכנסת".                                                                                                          |
|החוק המוצע בא להוסיף הוראות בדבר אחריות חברי הממשלה לפני הממשלה, לפי                                                   |
|ההצעה יהיה כל חבר ממשלה אחראי לפני הממשלה להצבעתו הוא ולהצבעת סיעתו במליאת                                             |
|הכנסת; הפרת אחריות זו תיחשב כהתפטרות מהממשלה; והכל בתנאים ובסייגים המפורטים                                            |
|בהצעה.                                                                                                                 |
