|"תושב", "תעודת זהות", "משרד הרישום" - כאמור בפקודת מרשם התושבים, תש"ט-1949 2;                  |                        |

|לצורך תקנות אלה.                                                                               |                        |
|2. (א) תושב גבר שמלאו לו 17 שנה חייב לקבל במשרד הרישום תעודת זהות.                             |החזקת תעודת             |
|(ב) תושב כאמור חייב לשאת עמו תמיד תעודת זהות ולהציגה בפני קצין משטרה גבוה/                     |זהות והצגתה             |

|(ג) אדם יצא ידי חובתו לפי תקנות אלה, אם במקום תעודת-זהות ישא עמו ויציג כאמור -                 |                        |
|(1) כשהוא חבר ממשלה - תעודת חבר ממשלה;                                                         |                        |
|(2) כשהוא חבר כנסת - תעודת חבר כנסת;                                                           |                        |
|(3) כשהוא שופט - תעודה שופט הנושאת את חתימת שר המשפטים ואת תצלומו                              |                        |
|של השופט;                                                                                      |                        |
|(4) כשהוא דיין - תעודת דיין הנושאת את חתימת שר הדתות ואת תצלומו של                             |                        |
|הדיין;                                                                                         |                        |
|(5) כשהוא שוטר או קצין משטרה - תעודה המעידה שהוא שוטר או קצין כאמור,                           |                        |
|הנושאת את תצלומו ושהוצאה לו בהתאם להוראות המחייבות בחיל ؀ࠂࠌࠎהמשטרה;                            |                        |
|(6) כשהוא יוצא-צבא כמשמעותו בחוק שירות בטחון, תשי"ט-1959 [נוסח                                 |                        |
|משולב] 4, או שהתייצב לרישום לפי החוק האמור - תעודת חייל או תעודת התייצבות                      |                        |
|המכילות את תצלומו ושהוצאו לו בהתאם להוראות המחייבות בצבא-הגנה לישראל;                          |                        |
|(7) כשהוא נמצא בישראל מכוח רשיון לישיבת ביקור כמשמעותו בחוק הכניסה                             |                        |
|לישראל, תשי"ב-1952  5- רשיון כאמור רכן דרכון או תעודת מסע רשמית אחרת                           |                        |
|המכילה את תצלומו.                                                                              |                        |
