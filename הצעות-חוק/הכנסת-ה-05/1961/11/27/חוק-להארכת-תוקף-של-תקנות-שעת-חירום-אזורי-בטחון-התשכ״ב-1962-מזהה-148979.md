|וזה הנוסח של תקנות-שעת-חירום (אזורי בטחון), תש"ט-1949:                                                                 |                    |
|1. (א) רצועת אדמה בתוך שטח ישראל ברוחב הניתן להלן מכל נקודה שעל קו גבול שטח                   |"שטח מוגן               |                    |

|(2) דרומה מקו הרוחב של ???31 - רצועה ברוחב של עשרים וחמישה קילומטר.                           |                        |                    |
|(ב) "שטח ישראל" - 3תלנה זו פירושו השטח שבו חל משפט מדינת ישראל.                               |                        |                    |
|2. (א) שר הבטחון רשאי, מזמן לזמן, בצו בחתימת ידו שיפורסם ברשומות, להכריז שהשטח                |אזורי בטחון             |                    |
|המוגן/ או כל חלק ממנו, יהיה אזור בטחון לצורך תקנות אלה.                                       |                        |                    |
|(ב) צו לפי תקנת משנה (א) שניתן אחר שנכנס לתקפו חוק להארכת תוקף של תקנות-                      |                        |                    |
|שעת-חירום (אזורי בטחון), תש"י-1950 2, יובא בפני הועדה לעניני חוץ ובטחון של הכנסת              |                        |                    |
|תוך עשרה ימים מיום פרסומו ברשומות; והועדה רשאית, על ידי החלטה שתפורסם ברשומות,                |                        |                    |
|לבטל בכל עת צו כאמור.                                                                         |                        |                    |
|3. תושב קבוע של אזור בטחון הוא, לצורך תקנות אלה, אדם אשר ביום שבו היה אזור מסויים             |תושבים קבועים           |                    |
|לאזור הבטחון, בתוקף אכרזה לפי תקנה 2, ישב באותו אזור ישיבת קבע.                               |                        |                    |
|4. שר הבטחון רשאי למנות כל קצין צבא-הגנה לישראל בדרגת סגן-אלוף או בדרגה גבוהה                 |רשויות מוסמכות          |                    |
|מזו להיות, לצורך תקנות אלה, רשות מוסמכת לאזור בטחון שיפרש במינוי.                             |                        |                    |
|5. (א) שר הבטחון ימנה לגבי כל אזור בטחון ועדה מייעצת של שלושה חברים או יותר,                  |ועדה מייעצת             |                    |
|שתייעץ לרשות המוסמכת בנוגע לשימוש בסמכויותיה לפי תקנה 8.                                      |                        |                    |
|(ב) חברי הועדה המייעצת יתמנו מתוך באי כוח הרשויות המקומיות שתחום שיפוטן הוא                   |                        |                    |
|באזור הבטחון ובסביבתו ומתוך התושבים הקבועים של אזור הבטחון ותושבי סביבתו; ואם אין             |                        |                    |
|רשויות מקומיות כאמור, או שאיין פעילות למעשה - יתמנו חברי הועדה המייעצת מתוך התו-              |                        |                    |
|שבים הקבועים של אזור הבטחון ומתוך תושבי סביבתו.                                               |                        |                    |
|6. (א) אסור לאדם, שאינו תושב קבוע, להימצא באזור בטחון או להיכנס אליו, אלא אם                  |איסורים                 |                    |
|הוא חייל או שוטר במילוי תפקידו, או אם הורשה לכך על פי רשיון בכתב מאת רשות מוסמכת              |                        |                    |
|ובהתאם לתנאי הרשיון; אך שר הבטחון רשאי, בצו על פי תקנה 2 או בצו נפרד בחתימת ידו               |                        |                    |
|שיפורסם ברשומות, להוציא מכלל האיסור האמור, לגבי אזור הבטחון כולו או לגבי חלק ממנו,            |                        |                    |
|סוג מסויים של בני אדם, בין ללא תנאי ובין בתנאינו.                                             |                        |                    |
