|חוק הסכמים קיבוציים (הוראת שעה), תשל"ו-1976                                  |

|הסכם קיבוצי   |1. הוראות ההסכם הקיבוצי האמור בתוספת עדיפות - לגבי הצדדים להסכם ולגבי                                      |
|עדיף          |העובדים הנזכרים בו - על כל הוראה בהסכם קיבוצי, חוזה עבודה או הסדר אחר; או                                  |
|              |בפסק דין או בפסק בוררות, שנעשו או ניתנו לפני תחילתו של חוק זה, וכוחן יפה -                                 |
|              |על אף האמור בכל דין - לכל דבר וענין.                                                                       |
|              |וו                                                                                                         |
|תחילה         |2. תחילתו של חוק זה מיום א' בניסן תשל"ו (1 באפריל 1976).                                                   |
|              |תוספת                                                                                                      |
|              |(סעיף 1)                                                                                                   |
|              |ההסכם הקיבוצי שנחתם ביום כ"ה בניסן תשל"ו (25-באפריל 1976) בין ממשלת                                        |
|              |ישראל בשם מדינת ישראל לבין ؀ࠂࠎࠐࠒהמוסד לביטוח לאומי ולבין ההסתדרות הכללית של                                |
|              |העובדים בארץ-ישראל, ושמספרו המזהה אצל הממונה הראשי על יחסי העבודה במשרד                                    |
|              |העבודה הוא 112/76.                                                                                         |

|דברי הסבר          |

|החוקי המוצע נועד להסיר כל ספק לגבי כוחן                   |
|של הוראות ההסכם הקיבוצי בענין שכר עובדי                   |

|המדינה והביטוח הלאומי וביטול התוספות הייחודיות,           |
|כמפורט בהסכם האמור בתוספת לחוק.                           |
