|תיקון סעיף 37א     |1. בסעיף 37א לחוק יישוב סכסוכי עבודה, תשי"ז-1957 1(להלן - החוק העיקרי),                               |
|                   |אחרי הגדרת "שביתה או השבתה בלתי מוגנת", במקום "לענין הגדרה זו רואים כשביתה"                           |
|                   |יבוא "לענין פרק זה רואים כשביתה".                                                                     |
|הוספת סעיף         |2. סעיפים 37ג ו-37ד לחוק העיקרי יסומנו כסדרם "37ד" ו-"37ה", ואחרי סעיף 37ב                            |
|                   |יבוא:                                                                                                 |
|                   |37ג. (א) לענין סעיף זה -                                                              |''דין שביתה    |
|                   |"מקום עבודה" - לרבות חלק ממפעל;                                                       |חלקית          |
|                   |"שכר רגיל" - שכרו של העובד בעד שעות העבודה הרגילות להוציא                             |               |
|                   |פרמיות או תוספת אחרת בעד מאמץ בעבודה.                                                 |               |
|                   |(ב) בית הדין אזורי כמשמעותו בחוק בית הדין לעבודה, תשכ"ט-                              |               |
|                   |1969 2, שבתחום שיפוטו נמצא מקום עבודתם של עובדים המקיימים                             |               |
|                   |שביתה חלקית בלתי מוגנת, יהא מוסמך לקבוע שהעובדים במקום עבודה                          |               |
|                   |פלוני או כמה מהם מקיימים שביתה חלקית בלתי מוגנת, ומשקבע בית                           |               |
|                   |הדין כך לא יהיה עובד המועסק באותו מקום עבודה או שהוא אחד מאותם                        |               |
|                   |עובדים, כפי שיקבע בית הדין, זכאי אלא לשכר חלקי בעד עבודה שעשה                         |               |
|                   |בפועל, בשיעור שקבע בית הדין לפי נסיבות הענין; לענין זה, "שביתה                        |               |
|                   |חלקית" - לרבות שביתת האטה והפרעה מאורגנת אחרת של מהלך                                 |               |
|                   |העבודה.                                                                               |               |
|                   |(ג) עובד הזכאי לשכר חלקי בלבד כאמור בסעיף קטן (ב), רואים                              |               |
|                   |סכום השווה למחצית שכרו הרגיל כשכר החלקי המגיע לו כל עוד לא                            |               |
|                   |קבע בית הדין את שיעור שכרו החלקי כאמור.                                               |               |
|                   |(ד) הפרשי שכר שמעביד חב לעובד או עובד חב למעביד מכוח                                  |               |
|                   |הוראות סעיף זה ישולמו תוך 30 יום מיום קביעת בית הדין האזורי בדבר                      |               |
|                   |שיעור השכר החלקי כאמור בסעיף קטן (ב), זולת אם קבע בית הדין                            |               |
|                   |מועד אחר לתשלום, ולענין סעיף 25 לחוק הגנת השכר, תשי"ח-1958 3,                         |               |
|                   |רואים סכום עודף ששולם כאמור לעובד כמקדמה.                                             |               |

|דברי הסבר                  |

|לפי המצב המשפטי הקיים כיום, ספק אם ניתן                        |
|להפחית את שכרו של עובד המשתתף בשביתה חלקית,                    |
|שביתת האטה או "סנקציות" למיניהן (כל אלה הוגדרו                 |
|כ-"שביתה חלקית") כדי להתאים את שכרו לעבודה                     |
|שעשה בפועל. החוק המוצע בזה נועד לאפשר הפחתה                    |
|זו, לאחר שבית הדין לעבודה יקבע שאכן מתקיימת                    |
|שביתה חלקית כאמור.                                             |

|יש להדגיש כי המדובר הוא רק בשביתה ؀ࠂࠐࠒࠖࠠࠢࠤࠪחלקית בלתי        |
|מוגנת, היינו, המהווה "שביתה בלתי מוגנת" כמשמעותה             |
|בסעיף 37א לחוק כפי שתוקן בתיקון מס' 2 בשנת 1972.             |
|שיעור השכר החלקי המגיע לעובד המשתתף בשביתה                   |
|חלקית ייקבע בבית הדין לעבודה, אולם עד לקביעה זו,             |
|מוצע להעמיד זמנית את שיעור השכר החלקי על 50%                 |
|משכרו הרגיל של העובד.                                        |

|דברי הסבר                         |

|אם יתברר לאחר פסק דינו של בית הדין לעבודה כי                |
|שיעור השכר החלקי המגיע לעובד פלוני עולה על 50%              |
|משכרו הרגיל, יהיה המעביד חייב לשלם לו את ההפרש              |
|תוך 30 יום, ואם יתברר כי שיעור השכר החלקי, לפי              |

|קביעת בית הדין, קטן מ-50 האחוזים האמורים, יהיה               |
|העובד חייב להחזיר למעביד את ההפרש תוך 30 יום                 |
|והמעביד רשאי גם לנכות הפרש זה משכרו של העובד                 |
|בדרך שבה מנכים מקדמה ששולמה על חשבון השכר.                   |
