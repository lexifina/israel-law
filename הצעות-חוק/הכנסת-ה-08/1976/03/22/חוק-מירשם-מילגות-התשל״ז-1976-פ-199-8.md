|                |הוא תלמיד במוסד חינוך, בין בדרך מענק ובין בדרך הלוואה, בין לצורך מימון שכר                                   |
|                |לימודיו ובין לצורך קיומו בתקופת לימודיו, לרבות הקלה כתשלום שכר לימוד ולמעט                                   |
|                |אלה:                                                                                                         |

|                |בעיסוק פלוני;                                                                                                |

|                |המקבל או עם בן משפחתו של המקבל;                                                                              |
|                |"מרכז הקרנות" - מרכז הקרנות במשרד החינוך והתרבות;                                                            |
|                |"קרן" -                                                                                                      |
|                |(1) מוסד חינוך;                                                                                              |
|                |(2) תאגיד שעיקר מטרתו מתן מילגות;                                                                            |
|                |(3) מי שהעמיד כספים, שלא באורח חד-פעמי, לצורך מתן מילגות בסכום                                               |
|                |שנתי כולל העולה על סכום שנקבע בתקנות לענין זה;                                                               |
|                |"קרן רשומה" - קרן ששר החינוך והתרבות הורה על רישומה במרכז הקרנות לפי סעיף 2.                                 |
