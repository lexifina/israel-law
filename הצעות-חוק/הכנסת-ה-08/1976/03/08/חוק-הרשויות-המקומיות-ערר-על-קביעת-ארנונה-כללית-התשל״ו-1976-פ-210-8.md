|חוק הרשויות המקומיות (ערר על קביעת ארנונה כללית), תשל"ו-1976                                             |

|הגדרות           |1. בחוק זה -                                                                                             |
|                 |"רשות מקומית" - עיריה או מועצה מקומית;                                                                   |
|                 |"המועצה" - מועצה של רשות מקומית.                                                                         |
|מנהל הארנונה     |2. המועצה תמנה אחד מעובדיה להיות מנהל הארנונה.                                                           |
|השגה             |3. מי שחוייב בתשלום ארנונה כללית רשאי להשיג עליה לפני מנהל הארנונה על יסוד                               |
|                 |טענה מטענות אלה:                                                                                         |
|                 |(1) הנכס שבשלו נדרש התשלום אינו מצוי באזור. כפי שנקבע בהודעת                                             |
|                 |התשלום;                                                                                                  |
|                 |(2) נפלה טעות בציון סוג הנכס או גדלו.                                                                    |
|תשובת מנהל       | 4. (א) מנהל הארנונה ישיב למשיג תוך ששים יום מיום קבלת ההשגה.                                            |
|הארנונה          |(ב) לא השיב מנהל הארנונה תוך ששים יום - ייחשב הדבר כאילו החליט לקבל                                      |
|                 |את ההשגה.                                                                                                |
|ועדת ערר         |5. המועצה תמנה ועדת ערר אחת או יותר, בהרכב של שלושה חברים מבין בעלי הזכות                                |
|                 |להיבחר כחברי המועצה, ואת היושב ראש שלהן.                                                                 |
|ערר              |6, (א) הרואה עצמו מקופח בהחלטה לפי סעיף 4 רשאי, ؀ࠂࠈתוך שלושים יום מיום-שנמ-                              |
|                 |סרה לו ההחלטה, לערור לפני ועדת הערר.                                                                     |
|                 |(ב) עברו ששים יום כאמור בסעיף 4 (ב) והיתה למנהל הארנונה סיבה טובה להעדר                                  |
|                 |תשובה, רשאי הוא לפנות לועדת הערר בבקשה לבטל את טבלת ההשגה.                                               |
|                 |(ג) החלטת ועדת הערר היא סופית ואין עליה ערעור לבית-משפט.                                                 |
|ביצוע            |7. שר הפנים ממונה על ביצוע חוק זה.                                                                       |
|                 |חבר הכנסת מ. ידיד                                                                                        |
