|"אתר לאומי" - מבנה או חלק ממנו, לרבות סביבת המבנה, שהוא בעל                                                   |                |

|שר הפנים יש ערך לשמירתו;                                                                                      |                |

|הכרזה על אתר 42ג. ראה שר הפנים כי מן הראוי לשמור על אתר לאומי מפני פגיעה                                      |                |
|לאומי    בו, רשאי הוא להכריז עליו ברשומות בהתייעצות עם המועצה, שהוא                                           |                |
|אתר לאומי, ואם ראה צורך בכך לקבוע גבולותיו,                                                                   |                |
|תקנות לאתרים 42ד. שר הפנים רשאי, לאחר התייעצות במועצה, להתקין תקנות לאיסור                                    |                |
|לאומיים       פגיעה באתר לאומי ולהסדרת השמירה עליו, החזקתו, הגנתו והטיפול                                     |                |
|בו, בין דרך כלל ובין לאתר לאומי פלוני,                                                                        |                |
|הטלת תפקידים 42ה. (א) שר הפנים רשאי להטיל בצו, בהתייעצות עם ראש הממשלה -                                      |                |
|על רשות הגנים, או בהתייעצות עם שר החקלאות - על רשות שמורות                                                    |                |
