|חוק תגמולי ביטוח לצד שלישי, תשל"ג-1973                                   |

|1. בפקודת פשיטת הרגל, 1936 1, אחרי סעיף 38 יבוא:                                                             |תיקון פקודת        |
|                                                                                                             |פשיטת רגל          |
|38א. מקום שניתן צו לקבלת נכסים נגד חייב שהוא מבוטח בביטוח                              |''תגמולי ביטוח      |                   |
|אחריות כלפי צד שלישי ולפני או אחרי מתן הצו חב החייב כלפי צד                            |                    |                   |
|שלישי בשל מאורע המכוסה על ידי הביטוח, זכויותיו של המבוטח כלפי                          |                    |                   |
|המבטח על פי חוזה הביטוח לא יהיו חלק מנכסיו והם יעמדו לזכות הצד                         |                    |                   |
|השלישי, על אף האמור בכל דין."                                                          |                    |                   |
|2. בפקודת החברות 2, אחרי סעיף 220ג יבוא:                                                                     |תיקון פקודת        |
|                                                                                                             |החברות             |
|220ד. מקום שחברה היתה מבוטחת בביטוח אחריות כלפי צד שלישי,                              |''תגמולי ביטוח      |                   |
|וניתן נגדה צו פירוק או שנתקבלה בה החלטה על פירוק מרצון או                              |                    |                   |
|שנתמנה לה כדין כונס נכסים או מנהל לעסקיה או למפעלה, ולפני אחד                          |                    |                   |
|המקרים האמורים או לאחריו חבה החברה כלפי צד שלישי בשל מאורע                             |                    |                   |
|המכוסה על ידי הביטוח, זכויותיה של החברה כלפי חברת הביטוח؀ࠂࠐࠒࠔ על פי                    |                    |                   |
|חוזה הביטוח לא יהיו חלק מנכסיה והם יעמדו לזכות הצד השלישי, על                          |                    |                   |
|אף האמור בכל דין."                                                                     |                    |                   |

|דברי הסבר                  |

|מוצע לקבוע כי במקרה של פשיטת רגל של אדם                     |
|או פירוק חברה לא ייפגעו זכויות צד שלישי שלטובתו             |
|נעשה ביטוח, בין אם החבות טעונה ביטוח לפי החוק               |
|כמו במקרה של ביטוח רכב מנועי לענין סיכוני צד שלישי          |
|ובין אם הביטוח מרצון, כגון ביטוח אחריות מעבידים:            |

|העובד הנפגע יוכל לקבל פיצוי מהחברה המבטחת                         |
|באופן ישיר, ולחברה המבטחת לא תהיה זכות קיזוז                      |
|כלפי צד שלישי בשל חובות כל שהן של המבוטח כלפי                     |
|המבטח.                                                            |
