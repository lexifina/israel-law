|מתפרסמות בזה הצעות חוק מטעם הממשלה:                           |

|מבוא                                                                                                          |
|חומרתם של נזקי הבריאות הבאים מעישון סיגריות איבה מוטלת עוד בספק. רשימת                                        |
|המחלות שמקורן כעישון ארוכה (סרטן הריאות, ברונכיט כרוני, נפחת הריאות, מחלות                                    |
|הלב וכלי הדם ועוד), וככל שהמחקר נמשך - הרשימה מתארכת.                                                         |
|ארגון הבריאות העולמי, בועידתו ה-23 (אפריל 1970), המליץ לפני כל המדינות                                        |
|החברות להגביר מאמצים במלחמה נגד העישון, תוך הדגשה כי במאבק צריך לשלב אמצעים                                   |
|חינוכיים-חברתיים ותחיקתיים.                                                                                   |
|כל המומחים בעולם העוסקים במניעת עישון סיגריות מאוחדים בדעה שאחד הגורמים                                       |
|החשובים בתחום עידוד העישון היא הפרסומת. מאז היו הסיגריות למוצר המוני, ובמיוחד                                 |
|מאז מלחמת העולם השניה, מושקעים מדי שנה בפרסומת לעידוד העישון מאות מיליונים                                    |
|(בארה"ב מוציאים על כך כ-300 מיליון דולר בשנה). יש להניח שחברות הסיגריות לא                                    |
|היו משקיעות סכומים כאלה אילו לא היתה הפרסומת מגבירה את השימוש בטבק.                                           |
|החוק המוצע הוא חיוני במאבק לריסון העישון בכלל ובקרב הנוער בפרט. חשיבותו                                       |
|רבה גם מנקודת ראות חינוכית.                                                                                   |

|חוק הגבלת הפרסום של חמרי עישון, תשל"ג-1973                                                    |

|הגדרות               |1. בחוק זה -                                                                                              |
|                     |"מוצרי טבק" - סיגריות מכל סוג, סיגרים, סיגרלות וטבק, לרבות חמרים אחרים המשמ-                              |
|                     |שים לעישון או שהם אבזרי עישון;                                                                            |
|                     |"פרסום" - בעל פה, בכתב, בדפוס, בהקרנה על מסך, בציור, בדמות, בתנועה, בצליל                                 |
|                     |או בכל דרך אחרת;                                                                                          |
|                     |"רשות הרבים" - לרבות הצרים הפתוחים לציבור והצרים פרטיים שפרסום בהם מיועד                                  |
|                     |לציבור או בא לידיעתו, למעט בית מסחר שבו נמכרים מוצרי טבק.                                                 |
|איסור פרסומת         |2, (א) לא ייעשה פרסום בענין מוצרי טבק ברדיו, בטלוויזיה ובכלי תקשורת ממלכ-                                 |
|בדבר מוצרי טבק       |תיים אחרים.                                                                                               |
|                     |(ב) לא יפרסם אדם ברשות הרבים כל פרסום בדבר מוצרי טבק, תכונותיהם, טיבם,                                    |
|                     |שמם המסחרי או סימן המסחר שלהם או פרסום בשבח העישון; היה הפרסום קיים - חייב                                |
|                     |המפרסם להסירו.                                                                                            |
|איסור פרסומת על      |3, לא יפרסם אדם ברשות הרבים את השם, הכינוי או סימן המסחר של יצרן מוצרי טבק                                |
|יצרן מוצרי טבק       |אלא על בית עסקו של אותו יצרן או של סוחר במוצרי טבק, או במודעה שאין ענינה פרסום                            |
|                     |מוצרי טבק.                                                                                                |
|פרסומת בעתונות       |4. (א) על אף האמור בסעיפים 2 ו-3, רשאי יצרן טבק לפרסם בעתון מודעה על מוצרי                                |
|                     |טבק שלו, והוא רשאי לכלול בה את שם מוצר הטבק, סימן המסחר שבו הוא מצויץ, שם                                 |
|                     |היצרן וסימן המסחר שלו, דמות חפיסת המוצר ומקום מכירתו; המודעה תכלול אזהרה לפי                              |
|                     |סעיף 5, באותיות שאינן קטנות מיתר אותיות המודעה פרט לשם המוצר,                                             |
|                     |(ב) שר הבריאות, בהתייעצות עם שר המסחר והתעשיה ושר החקלאות, רשאי                                           |
|                     |להתקין תקנות ؀ࠂࠈࠊࠎࠚࠜࠠࠪࠬ࠮࠾המפרטות ענינים אחרים שמותר או אסור לכוללם במודעה והוראות משלימות                 |
|                     |לענין זה.                                                                                                 |
|אזהרה                |5, כל עטיפה או אריזה שיש בה מוצרי טבק תישא עליה אזהרה באותיות ברורות "העי-                                |
|                     |שון מזיק לבריאות", בעברית ובשפה אחת נוספת הרווחת בישראל.                                                  |
