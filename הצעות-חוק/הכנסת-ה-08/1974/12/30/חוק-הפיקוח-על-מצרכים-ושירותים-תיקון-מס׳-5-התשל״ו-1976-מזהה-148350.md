|הוספת פרק שני 2     |1. בחוק הפיקוח על מצרכים ושירותים, תשי"ח-1957 1, אחרי סעיף 16ט יבוא:                                          |
|                    |"פרק שני 2: הפסקת בניה                                                                    |                   |
|                    |16י. (א) ראה בית משפט שלום כי מתבצעת פעולת בניה בהפרת צו                                  |צו הפסקה זמני      |
|                    |לפי חוק זה, רשאי הוא לצוות, על פי בקשתו של מי שרשאי להגיש                                 |                   |
|                    |תביעה כאמור בסעיף 41 ובמעמדו בלבד, כי פעולת הבניה תיפסק.                                  |                   |
|                    |(ב) כצו לפי סעיף קטן (א) (להלן - צו הפסקה זמני) ייאסר על                                  |                   |
|                    |כל מי שבראה לבית המשפט אחראי לביצוע הבניה, ועל כל מי שעובד                                |                   |
|                    |בשירותו, להמשיך בפעולת הבניה, אף אם יש כידו היתר לכך לפי חוק                              |                   |
|                    |התכנון והבניה, תשכ"ה-1965 2.                                                              |                   |
|                    |(ג) תקפו של צו הפסקה זמני יפקע שלושים יום לאחר נתינתו                                     |                   |
|                    |אם לא הוגש כתב אישום על הבניה.                                                            |                   |
|                    |(ד) הוגש כתב אישום, רשאי בית המשפט שלפניו הוגש לבטל                                       |                   |
|                    |את צו ההפסקה הזמני או להאריך את תקפו, בתנאים או בלי תנאים;                                |                   |
|                    |ועם נתינת פסק הדין רשאי בית המשפט לעשות את הצו לסופי, בשינוי                              |                   |
|                    |או בלי שינוי, להאריך את תקפו לתקופה הנראית לו, או לבטלו.                                  |                   |
|                    |16יא. מי שלא קיים צו הפסקה שניתן לפי סעיף זה, דינו, בלי לגרוע                             |עונשין             |
|                    |מדין מאסר החל עליו לפי סעיף 39 - קנס 50,000 לירות וקנס 1,000                              |                   |
|                    |לירות או מאסר שבעה ימים לכל יום שבו נמשכה העבירה."                                        |                   |

|דברי הקובר                |

|חוק הפיקוח על מצרכים ושירותים, תשי"ח-1957,                    |
|מעניק סמכות להוציא צו כללי או אישי האוסר על התח-              |
|לת בניה או המשכה, אולם במקרה של אי קיום הצו,                  |
|אין לרשות מנהלית או לבית המשפט סמכות להוציא צו                |
|הפסקת בניה בדומה לצו מינהלי או שיפוטי לפי חוק                 |
|התכנון והבניה, תשכ"ה-1965. כדי ליצור כלי יעיל                 |
|למנוע באופן מידי פעולות בניה בניגוד לצו לפי החוק/             |
|מוצע לקבוע אפשרות של הוצאת צורם מאת בית המשפט                 |
|להפסקה זמנית של בניה, להארכת ההפסקה הזמנית                    |
|ולעשייתה לסופית.                                              |
|תביעה לפי ؀ࠂࠐࠒࠖࠚࠜࠞסעיף 41 לחוק, הנזכרת בסעיף 16י(א)           |
|המוצע, יכולה להיות מוגשת בידי היועץ המשפטי לממ-               |
|שלה או בא כוחו או בהסכמתו בכתב של היועץ המשפטי                |
|לממשלה. מוצע כי על פי בקשתו של מי שמוסמך להגיש                |
|תביעה יוכל בית משפט השלום ליתן צו זמני להפסקת                 |

|בניה, במעמד המבקש בלבד. כמובן, יתר ההליכים לפי                    |
|הפרק המוצע יהיו במעמד כל הצדדים.                                  |
