|מתפרסמת בזה הצעת חוק מטעם הממשלה:                                              |

|חוק למניעת הונאה בכשרות, תשל"ד-1974                                 |

|1. בחוק זה -                                                                                               |הגדרות             |
|"כשר" - כשר לפי דין תורה;                                                                                  |                   |
|"תעודה" - תעודה מאת מועצת הרבנות הראשית או מאת רב המכהן כרב במקום                                          |                   |
|שבו נמצא בית האוכל או האטליז או בית המטבחיים או- במקום שבו מיוצר                                           |                   |
|המצרך, הכל לפי הענין, ויש בידו אישור מאת מועצת הרבנות הראשית שהוא                                          |                   |
|כשיר לשמש רב בישראל; אם אין באותו מקום רב כאמור המוכן לטפל                                                 |                   |
|בנתינת תעודות, יהיה רב לצרכי סעיף זה רב כשיר כאמור המכהן כרב במקום                                         |                   |
|אחר;                                                                                                       |                   |
|"ייצור של מצרך" - לרבות אריזתו וכל פעולה הנותנת לו את הצורה שבה נמכר                                       |                   |
|המצרך לצרכן.                                                                                               |                   |
|2 . (א) מי שמנהל בית אוכל או אטליז והוא הציג בו מודעה או סימן המציינים את                                  |בתי אופי           |
|בית האוכל או האטליז ככשרים, בלי שהיתה בידו תעודה המאשרת כשרותם,                                            |ואטליזים           |
|אשם בעבירה.                                                                                                |                   |
|(ב) מי שמנהל בית אוכל או אטליז ויש בידו תעודה כאמור בסעיף קטן (א), והוא                                    |                   |
|הציג מודעה או סימן המציינים את בית האוכל או האטליז ככשרים, והוא הגיש                                       |                   |
|בו ללקוחותיו או מכר בו מצרכים שאינם כשרים, אשם בעבירה.                                                     |                   |
|(ג) בסעיף זה -                                                                                             |                   |
|"בית אוכל" - מקום שבו עוסקים במכירת מאכלים או משקאות לציבור לשם                                            |                   |
|אכילה או שתיה בו במקום;                                                                                    |                   |
|"מצרך" - לענין בית אוכל - מאכלים ומשקאות, ולענין אטליז - בשר                                               |                   |
|ומוצרי בשר.                                                                                                |                   |
|3, (א) מי שעוסק בייצור מצרכים והוא מציין מצרך שייצר כמצרף כשר בלי שהיתה                                    |מצרכים             |
|בידו תעודה המאשרת כשרותו של המצרך, אשם בעבירה.                                                             |                   |
|(ב) מי שעוסק בייצור של מצרך שניתנה עליו תעודה כאמור בסעיף קטן (א),                                         |                   |
|והמצרך שהוא ייצר אינו כשר, אשם בעבירה.                                                                     |                   |
|(ג) מי שעוסק במכירת מצרכים ומכר מצרך שאינו כשר בתארו כאילו הוא כשר,                                        |                   |
|אשם בעבירה; באישום לפי הוראה זו תהא זאת הגנה שהמצרך יוצר בידי                                              |                   |
|יצרן מוכר ונשא ציון המעיד על כשרותו.                                                                       |                   |
|4. (א) מי שעוסק בשחיטה בבית מטבחיים ציבורי והכריז על שחיטה כשרה בלי                                        |בתי                |
|שהיתה בידו תעודה המאשרת שהוא מורשה לשחיטה כשרה, אשם בעבירה.                                                |מטבחיים            |
|(ב) מי שעוסק בשחיטה בבית מטבחיים ציבורי ויש בידו תעודה כאמור בסעיף                                         |                   |
|קטן (א) ושחיטתו אינה כשרה, אשם בעבירה.                                                                     |                   |

|דברי הסבר            |

|יש מקרים שבעלי מסעדה, בעלי אטליז, שוחטים                    |
|וסוחרים מציינים את בתי עסקיהם, שחיטתם או סחורתם             |
|בציון "כשר" בלי שציון זה יהלום את המציאות.                  |
|מעשים כאלה יש בהם משום הונאת הציבור.                        |
|ענין הכשרות שונה מתכונות אחרות של מצרכים                    |
|באשר אין לו ביטוי מטריאלי בגוף המצרך וקשה                   |

|לקבוע את כשרותו של מצרך על-ידי בדיקת מעבדה                 |
|או תהליך דומה. לפיכך אין די בחוקים הקיימים                 |
|בדבר הונאה או זיוף מצרכים כדי להילחם בצורה                 |
|מיוחדת זו של הונאה, ויש צורך להוסיף את הערובה              |
|הניתנת על-ידי החוק המוצע.                                  |
