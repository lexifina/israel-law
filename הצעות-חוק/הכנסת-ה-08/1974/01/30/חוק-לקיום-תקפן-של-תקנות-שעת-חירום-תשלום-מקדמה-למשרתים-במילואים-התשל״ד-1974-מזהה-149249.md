|חוק להארכת תקפן של תקנות-שעת-חירום                                                   |
|(תשלום מקדמה למשרתים במילואים), תשל"ד-1974                                           |

|הארכת תוקף          |1. תקפן של תקנות-שעת-חירום (תשלום מקדמה למשרתים במילואים), תשל"ד-                                        |
|                    |1973 1, בנוסח הניתן בתוספת, מוארך בזה עד יום ח' בניסן תשל"ד (31 במרס 1974),                              |
|ממכות ביטול         |2, שר העבודה רשאי בכל עת, בצו שיפורסם ברשומות, לבטל את התקנות האמורות,                                   |
|                    |כולן או מקצתן.                                                                                           |
|תחילה               |3. תחילתו של חוק זה ביום כ"ו בשבט תשל"ד (18 בפברואר 1974).                                               |

|דברי הסבר             |

|אחרי פרוץ הקרבות בחודש אוקטובר 1973 הותקנו                    |
|תקנות-שעת-חירום (תשלום מקדמה למשרתים במילו-                   |
|אים), תשל"ד-1973, שמטרתן היתה להנהיג הסדרים                   |
|דחופים מיוחדים בקשר לתשלום מקדמות למשפחות                     |
|המגוייסים. אלה הן התקנות המפורטות בנוסח מעודכן                |
|בתוספת לחוק המוצע.                                            |
|לפי סעיף 9(ג) לפקודת סדרי השלטון והמשפט,                      |
|תש"ח-1948,פוקע תקפן של תקנות-שעת-חירום בתום                   |

|שלושה חודשים מיום התקנתן זולת אם הכנסת האריכה                 |
|את תקפן למועד מאוחר יותר.                                     |
|לאור סעיף 9(0 האמור יפקע תקפן של תקנות-שעת-                   |
|חירום האמורות ביום כ"ו בשבט תשל"ד (18 בפברואר                 |
|974 0, ובנסיבות הקיימות מוצע להאריך את תקפן עד                |
|סוף חודש מרס .1974                                            |
|עם זאת מוצע כי שר העבודה, שהתקין את התקנות                    |
|האמורות, יהיה מוסמך לבטלן, כולן או מקצתן, אם                  |
|יתברך שלא יהיה עוד צורך בהן.                                  |

|1 ק"ת תשל"ד, עמ' 332, עמ' 456, עמ' 582.    |

|תוספת                                                                                                        |                    |
|(סעיף 1)                                                                                                     |                    |
|1. (א) אוצר המדינה ישלם למי שזכאי לתגמול לפי חוק שירות מילואים (תגמולים),                                    |מקדמה על            |
|תשי"ט-1959 [נוסח משולב] 2 (להלן - החוק), מקדמה על חשבון התגמול המגיע לו לפי                                  |חשבון התגמול        |
|החוק בעד שירותו במילואים בשיעורים אלה:                                                                       |                    |
|(1) לנשוי עם שני ילדים או יותר - 850 לירות לחודש;                                                            |                    |
|(2) לנשוי עם ילד אחד - 725 לירות לחודש;                                                                      |                    |
|(3) לכל אדם אחר - 600 לירות לחודש;                                                                           |                    |
|(להלן - המקדמה).                                                                                             |                    |
|(ב) בעד תקופת שירות קצרה מחודש תשולם מקדמה בסכום השווה לחלק ה-30 של                                          |                    |
|המקדמה החדשית המגיעה לפי תקנת משנה (א) כפול במספר ימי השירות במילואים.                                       |                    |
|(ג) לענין תקנה זו, "ילד" - ילדו של המשרת במילואים שטרם מלאו לו 18 שנה,                                       |                    |
|לרבות ילד מאומץ וילד חורג.                                                                                   |                    |
|2. מי שחייב לפי החוק בתשלום תגמול ؀ࠂࠎࠐࠔࠚࠜࠞבעד תקופת שירותו של אדם במילואים יפחית                             |ניכוי המקדמה        |
|מסכום התגמול שעליו לשלם את סכום המקדמה בעד אותה תקופת שירות.                                                 |                    |
|3. (א) עלה סכום המקדמה שקיבל אדם פלוני על סכום התגמול שיש לשלם לו לפי                                        |אין חובה להחזיר     |
|החוק, לא יהיה חייב להחזיר את ההפרש.                                                                          |                    |
|(ב) הוראות תקנה זו לא יגרעו מחובתו של מקבל המקדמה להחזיר סכום ששולם                                          |                    |
|לו בטעות או שלא כדין,                                                                                        |                    |
|4. (א) לענין סעיף 13 (א) לחוק דין מקדמה ששולמה לעובד פלוני שהסעיף האמור חל                                   |דין המקדמה          |
|עליו כדין תגמול ששילם לו מעבידו.                                                                             |                    |
|(ב) הוראות סעיף 25(א) לחוק לא יחולו על המקדמה.                                                               |                    |
|5. אוצר המדינה ישלם למי שאינו זכאי לתגמול על פי החוק ושירת במילואים, סכום                                    |חשלום למי           |
|השווה למקדמה שהיתה משתלמת לו לפי תקנה 1 אילו היה זכאי לתגמול לפי החוק.                                       |שאינו זכאי          |
|                                                                                                             |על-פי החוק          |
|6. אוצר המדינה יכסה את תשלומי קרן ההשוואה שהוקמה לפי החוק, בעד תגמולים                                       |מימון מאוצר         |
|למשרתים במילואים בתקופה שמיום י' בתשרי תשל"ד (6 באוקטובר 1973) ואילך, וקרן                                   |המדינה              |
|ההשוואה תחזיר לאוצר המדינה, מתוך הרזרבה שהצטברה בקרן ליום ההחזרה, סכום שיקבעו                                |                    |
|שרי העבודה והאוצר לאחר התייעצות עם ארגון העובדים שעם חבריו נמנים רוב העובדים                                 |                    |
|במדינה ועם ארגוני מעבידים של דעת השרים הם יציגים ונוגעים בדבר, ובהתחשב בסכום                                 |                    |
|הכולל של תשלומי הקרן בעד תגמולים למשרתים במילואים בשלושת החדשים הרצופים                                      |                    |
|שלאחר תום תקפן של תקנות אלה.                                                                                 |                    |
|7. הוראות החוק יחולו בכפוף להוראות תקנות אלה.                                                                |תחולה               |
|8. לתקנות אלה ייקרא "תקנות-שעת-חירום (תשלום מקדמה למשרתים במילואים),                                         |השם                 |
|תשל"ד-1973".                                                                                                 |                    |
