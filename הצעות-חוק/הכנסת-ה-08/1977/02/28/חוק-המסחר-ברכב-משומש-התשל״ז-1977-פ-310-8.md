|חוק המסחר ההוגן ברכב משומש, תשל"ז-1977                                       |

|1. בחוק זה -                                                                                                |הגדרות            |
|"רכב משומש" - רכב או רכב מנועי שנתקיים בו אחד מאלה:                                                         |                  |
|(1) נעשה בו שימוש בתקופה של שלושה חדשים לפחות לאחר רישומו לפי                                               |                  |
|פקודת התעבורה 1;                                                                                            |                  |
|(2) הוא מוצע למכירה לצרכן אחרי שנמכר לפחות פעם אחת כך;                                                      |                  |
|(3) הוא הופעל כנסיעה לפחות 2000 ק"מ;                                                                        |                  |
|"עוסק" - מי שעיסוקו מכירת רכב משומש, בין כעיסוק יחיד ובין כאחד מעיסוקיו, לרבות                              |                  |
|מי שעוסק כאמור כשכיר, כעמיל או כמתווך או בכל דרך כיוצאת באלה;                                               |                  |
|"השר" - שר התחבורה ;                                                                                        |                  |
|לכל מונח אחר תהיה המשמעות בפקודת התעבורה אם אין כוונה אחרת משתמעת.                                          |                  |
|2, (א) עוסק יציג במובלט על רכב משומש שהוא מציע למכירה או המוצע למכירה                                       |מסירת פרטים       |
|באמצעותו, במקום שבו מוצע הרכב, מודעה בכתב, שתכלול, בין היתר -                                               |על רכב משומש      |
|(1) תוצרו של הרכב המשומש, שם המפעל שבו יוצר וארץ הייצור;                                                    |                  |
|(2) הדגם ושנת הייצור;                                                                                       |                  |
|(3) בעליו הקודמים של הרכב המשומש, לפי הרשום כרשיון הרכב;                                                    |                  |
|(4) הגבלות על שימוש ברכב המשומש או על העברת הבעלות בו מחמת אי                                               |                  |
|תשלום מכס, מסים, היטלים או אגרות החלים על הרכב, או מחמת משכון,                                              |                  |
|שעבוד או עיקול;                                                                                             |                  |
|(5) השימושים שנעשו ברכב המשומש כעבר;                                                                        |                  |
|(6) התיקונים שבוצעו בעבר במכלולים בטיחותיים של הרכב, המשומש;                                                |                  |
|(7) מספר הקילומטרים שבהם הופעל הרבב המשומש;                                                                 |                  |
|(8) מידת אחריותו של העוסק לתיקונים שידרוש הקונה ברכב המשומש.                                                |                  |

|דברי הסבר              |

|מטרת החוק המוצע להביא לידיעתו של קונה רכב                 |
|משומש את הפרטים החשובים הרלבנטיים לגבי הרכב               |
|שהוא עומד לרכוש. הצורך בחוק נובע מהעובדה שלא              |
|כל קונה ער לכל הפרטים שעליו לדרוש מן המוכר, ולא           |
|כל מוכר נוהג למסור מיוזמתו את מלוא הפרטים המדו-           |
|ייקים. הבעיה הפכה לאקטואלית במיוחד בתקופה                 |
|האחרונה לאור ההעלאה הניכרת של מחירי כלי רכב.              |
|מוצע להטיל את חובת מסירת הפרטים המנויים                   |
|בסעיף 2 על העוסק במכירת רכב משומש. כדי להבטיח             |

|את מסירת הפרטים, ולשם מניעת קשיי הוכחה בדבר                       |
|מסירתם, מוצע שהסכם לרכישת רכב משומש ייעשה                         |
|בכתב.                                                             |
|המפר את הוראות החוק צפוי לעונש חמור בתחום                         |
|הפלילי, ולביטול החוזה מצד הקונה בתחום האזרחי,                     |
|אם יתגלה שאחד הפרטים המרכזיים לא נמסר או היה                      |
|כוזב. במקרה שהקונה סבל נזק כתוצאה מעבירה על                       |
|החוק, הוא יהיה זכאי גם לפיצויים.                                  |
