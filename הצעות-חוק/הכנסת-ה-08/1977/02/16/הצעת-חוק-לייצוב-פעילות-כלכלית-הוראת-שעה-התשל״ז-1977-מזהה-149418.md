|1. בפרק זה -                                                                                                |                   |
|"חוק הפיקוח" - חוק הפיקוה על מצרכים ושירותים, תשי"ח-1957 י;                                                 |                   |
|"המועד הקובע" -ערב תחילתו של חוק זה;                                                                        |                   |
|"מחיר יציב" - של מצרך או שירות -                                                                            |                   |
|(1) אם נקבע למצרך או לשירות מחיר מכסימלי לפי כל חיקוק - המחיר                                               |                   |
|המכסימלי במועד הקובע;                                                                                       |                   |
|(2) אם לא נקבע מחיר מכסימלי כאמור בפסקה (1) - המחיר שבו היה                                                 |                   |
|על פלוני למכור את המצרך או לעשות את השירות במועד הקובע, לפי כל                                              |                   |
|חיקוק שהיה בתוקף במועד הקובע;                                                                               |                   |
|(3) אם לא נקבע מחיר מכסימלי כאמור בפסקה (1) ולא היה כל חיקוק                                                |                   |
|בתוקף במועד הקובע לגבי מחירו של המצרך או השירות - המחיר שבו                                                 |                   |
|מכר פלוני את המצרך או עשה את השירות במועד הקובע;                                                            |                   |
|''מחיר", "מחיר העולה על מחיר יציב" - כמשמעותם בסעיף 16א לחוק הפיקוח;                                        |                   |
|"מצרך" - כל נכס למעט ניירות ערך.                                                                            |                   |
|2. (א) לא ימכור אדם מצרך ולא יציעו למכירה, ולא יעשה שירות ולא יציע לעשותו,                                  |איסור העלאת        |
|במחיר העולה על המחיר היציב.                                                                                 |מחיר               |
|(ב) היה מקובל במועד הקובע מתן הנחה ממחיר המצרך או השירות, דרך כלל                                           |                   |
|או בתנאים מסויימים, לא ימכור אדם מצרך ולא יעשה שירות, במקרים דומים, במחיר                                   |                   |
|העולה על המחיר לאחר מתן ההנחה כאמור.                                                                        |                   |
|3. (א) סעיפים 1516, 30, 31, 32, 39 ו-41 לחוק הפיקוח יחולו, בשינויים המחריבים,                               |תחולת הוראות       |

|דברי הסבר                |

|החוק המוצע בא בעקבות הסדר בין הממשלה והס-                  |
|תדרות העובדים הכללית בדבר, היציבות של מחירים,              |
|שכר, מסים ודיבידנדים, בתקופה שבין קבלת החוק                |
|ועד יום 30 ביוני 1977.                                     |
|החוק בא לאסור העלאה של מחירי מצרכים ושירו-                 |
|תים, הכרזה ותשלום של דיבידנדים בשיעור העולה על             |

|השיעור ששולם בתקופה המקבילה בשנת 1976, והעלאת                 |
|מסים ממשלתיים ועירוניים, וכן לדחות את התשלום                  |
|של תוספות שכר שנקבעו בתקופת תקפו של החוק.                     |
|עוד בא החוק לקבוע כי ההסכם הקיבוצי הנזכר                      |
|בתוספת, המקים מוסד לבוררות מוסכמת, יחול על כלל                |
|העובדים והמעבידים בשירות הציבורי.                             |
