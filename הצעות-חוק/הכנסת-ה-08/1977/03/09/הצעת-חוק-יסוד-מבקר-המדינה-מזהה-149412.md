|מתפרסמות בזה הצעות חוק מטעם ועדת החוקה חוק ומשפט של הכנסת:                             |

|חוק-יסוד: מבקר המדינה                               |

|1. גרסה א':                                                                                                  |הבקורת והמבקר   |
|(א) תקויים בקורת על המינהל והמשק של המדינה כדי להבטיח ניהול תקין, יעילות,                                    |                |
|חסכון וטוהר המידות וכדי למנוע הפרת חוק, חריגה מסמכות, שרירות ורשלנות במילוי                                  |                |
|תפקידי הממשל.                                                                                                |                |
|גרסה בי:                                                                                                     |                |
|(א) תקויים בקורת על המינהל והמשק של המדינה לשם שמירה על החוק, ניהול                                          |                |
|תקין, יעילות, חסכון וטוהר המידות במילוי תפקידי הממשל,                                                        |                |
|(ב) הבקורת תחול על משרדי הממשלה, על מוסדות המדינה ומפעליה, על הרשויות                                        |                |
|המקומיות ועל איגודים וגופים אחרים שייקבעו בחוק או על פיו.                                                    |                |
|(ג) הבקורת תיעשה בידי מבקר המדינה; במילוי תפקידיו יהיה מבקר המדינה אחראי                                     |                |
|לפני הכנסת בלבד ולא יהיה כפוף לממשלה.                                                                        |                |
|(ד) מבקר המדינה גם יברר תלונות הבאות אליו מקרב הציבור, וכפי שייקבע בחוק                                      |                |
|- יתן חוות דעת בענינים שבתחום תפקידיו וימלא תפקידי בקורת בקשר למימון                                         |                |
|מפלגות ותפקידים אחרים.                                                                                       |                |
|2, גרסה א':                                                                                                  |؀ࠂࠊࠌࠐࠔמינוי     |
|(א) כל אזרח ישראלי שהוא תושב ישראל כשיר להיות מועמד לכהונת מבקר המדינה.                                      |(בחירה)         |
|גרסה ב': להוסיף לגרסה א':                                                                                    |ותקופת כהונה    |
|מי שכיהן כמבקר המדינה שתי תקופות בזו אחר זו לא יהיה מועמד. לתקופה הסמוכה                                     |                |
|לאחריהן.                                                                                                     |                |
|גרסה א':                                                                                                     |                |
|(ב) נשיא המדינה ימנה את מבקר המדינה לפי המלצת ועדה שקבעה לכך הכנסת                                           |                |
|מתוך ועדותיה.                                                                                                |                |
|גרסה ב':                                                                                                     |                |
|(ב) הכנסת תבחר את מבקר המדינה.                                                                               |                |
|(ג) תקופת כהונתו של מבקר המדינה תהיה חמש שנים לפי הלוח העברי.                                                |                |
|(ד) כהונת מבקר המדינה תפקע בתום תקופתה, בהתפטרותו של מבקר המדינה, או                                         |                |
|על פי החלטת הכנסת ברוב חבריה להעבירו מכהונתו לאחר שניתנה לו הזדמנות להשמיע                                   |                |
|דברו לפני ועדה שקבעה לכך הכנסת מתוך ועדותיה.                                                                 |                |
|(ה) נבצר ממבקר המדינה דרך ארעי למלא תפקידיו, רשאית ועדה שקבעה לכך                                            |                |
|הכנסת מתוך ועדותיה למנות לו ממלא מקום לתקופה שלא תעלה על ששה חדשים.                                          |                |

|הצהרת אמונים      |3. סמוך ככל אפשר לאחר מינויו (היבחרו) יצהיר ויחתום מבקר המדינה בפני נשיא                                     |
|                  |המדינה (בפני הכנסת) הצהרת אמונים זו:                                                                         |
|                  |"אני מתחייב לשמור אמונים למדינת ישראל ולחוקיה ולמלא באמונה                                                   |
|                  |את תפקידי כמבקר המדינה."                                                                                     |
|סמכויות הבקורת    |4. (א) למבקר המדינה יהיו כל הסמכויות הדרושות למילוי תפקידיו; פרטי הסמכויות,                                  |
|וסדריה            |סדרי הבקורת והסייגים למבחני הבקורת או הוספת מבחני בקורת ייקבעו בחוק או על פיו;                               |
|                  |כן ייקבעו חובת הדיווח על פעולות מבקר המדינה וסדרי הדיווח.                                                    |
|                  |(ב) הדינים וחשבונות של מבקר המדינה יפורסמו ברבים; סדרי הפרסום והסייגים                                       |
|                  |לפרסום ייקבעו בחוק או על פיו.                                                                                |
|בירור תלונות      |5.  (א) בבירור תלונות הציבור יכהן מבקר המדינה כנציב תלונות הציבור.                                           |
|                  |(ב) כל אדם רשאי להגיש תלונה אל נציב תלונות הציבור.                                                           |
|                  |(ג) הגופים והאנשים שעליהם ניתן להגיש תלונה, הליקויים שעליהם ניתן להתלונן,                                    |
|                  |דרכי בירור התלונות ותוצאות הבירור ייקבעו בחוק או על פיו.                                                     |
|                  |(ד) לא ייזקק שום בית משפט לבקשת סעד נגד מבקר המדינה בענין תלונה.                                             |
|תקציב             |6. תקציב מבקר המדינה ייקבע לפי הצעת מבקר המדינה בידי ועדה שקבעה לכך הכנסת                                    |
|                  |מתוך ועדותיה, וייכלל בתקציב המדינה.                                                                          |
