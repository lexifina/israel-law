|ניות טלוויזיה וכיוצא באלה;                                                                                      |                     |
|"ספריה ציבורית" - ספריה של רשות מקומית, שהיא פתוחה לכל והוקמה לפי צו, או הוכרה,                                 |                     |
|לפי סעיף 2.                                                                                                     |                     |
|2. י (א) השר רשאי, בהתייעצות עם שר האוצר ושר הפנים, להטיל בצו על רשות מקומית                                    |הקמת ספריה           |
|או על רשויות מקומיות אחדות במשותף, להקים, להחזיק ולנהל ספריה בתחום שיפוטן.                                      |ציבורית              |
|(ב) השר רשאי להכיר בספריה של רשות מקומית כספריה ציבורית, ומשעשה כן                                              |והכרה בה             |
|יחול עליה האמור בחוק זה.                                                                                        |                     |
|3. ספריה ציבורית תהא נתונה לפיקוחו של השר.                                                                      |פיקוח                |
|4. בהקמתה של ספריה ציבורית, בתחזוקתה ובניהולה רשאית רשות מקומית לשתף מוס-                                       |שיתוף גופים          |
|דות וגופים אחרים.                                                                                               |אחרים                |
|5, השר יקבע מדי שנה בשנה, בהתייעצות עם שר האוצר ושר הפנים, את שיעור השתתפותו                                    |שיעור השתתפות        |
|של אוצר המדינה בהקמת ספריות ציבוריות, בתחזוקתן ובניהולן.                                                        |המדינה               |
|6, (א) ספריה ציבורית תספק בתחום השיפוט של הרשות המקומית או הרשויות המקו-                                        |שירותים              |
|מיות את השירותים הבאים, כולם או מקצתם, כפי שקבע השר:                                                            |                     |
|(1) השאלת ספרים, והשימוש בהם בכתלי הספריה הציבורית, למבוגרים,                                                   |                     |
|לבני נוער ולילדים;                                                                                              |                     |
|(2) מתן - ייעוץ והדרכה בכל הנוגע לשימוש בספרים, לרבות שירות                                                     |                     |
|ביבליוגרפי;                                                                                                     |                     |
|(3) קיום חוגי לימוד, הרצאות, תערוכות וכיוצא באלה.                                                               |                     |
