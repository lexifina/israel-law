|מתפרסמת בזה הצעת חוק מטעם חבר הכנסת:                         |

|חוק המועצה לייצור ושיווק של ירקות                             |
|(תיקון מס' 2), תשל"ה-1975                                     |

|1. אחרי סעיף 28 לחוק המועצה לייצור ושיווק של ירקות' תשי''ט-1959 1, יבוא:                                   |הוספת סעיף 28א      |
|28א. (א) לא יושמדו עדפי ירקות בכמויות בלתי סבירות אלא בהיתר                             |''איסור השמדת    |                    |
|מאת שר החקלאות או המנהל הכללי של משרד החקלאות, והיתר כזה                                |עדפי ירקות       |                    |
|לא יינתן אלא אם שוכנע נותנו כי לא נמצא להם שימוש לכל מטרה                               |                 |                    |
|מועילה; ראה השר או המנהל הכללי כי בנסיבות הקיימות אותה עת ניתן                          |                 |                    |
|להשתמש בעדפי הירקות למטרת חסד, רשאי הוא לא לתת היתר כאמור.                              |                 |                    |
|(ב) שר החקלאות רשאי לאצול סמכותו לפי סעיף קטן (א) לסגן                                  |                 |                    |
|מנהל כללי או למנהל אזורי של משרד החקלאות.                                               |                 |                    |
|(ג) לא נתן שר החקלאות או המנהל הכללי של משרד החקלאות                                    |                 |                    |
|היתר לפי סעיף קטן (א) מחמת שראה שניתן להשתמש בעדפי הירקות                               |                 |                    |
|למטרת חסד, יקבע שר הסעד בתיאום עם שר החקלאות את סדרי החלוקה                             |                 |                    |
|של עדפי הירקות.                                                                         |                 |                    |
|(ד) שר החקלאות ושר הסעד ידווחו לועדת הכלכלה של הכנסת                                    |                 |                    |
|אחת לששה חדשים בדבר ביצוע הוראות סעיף זה."                                              |                 |                    |

|דברי הסבר               |

|ביולי 1973 אישרה הכנסת את חוק מועצת חפירות                  |
|(ייצור ושיווק), חשל"ג"1973. סעיף 60 לאותו חוק קבע           |
|כי "לא ؀ࠂࠒࠔࠖࠤיושמדו עדפי סירות אלא בהיתר מאת השר או         |
|המנהל הכללי של משרד החקלאות, והיתר כזה לא יינתן             |
|אלא אם שוכנע נותנו כי לא נמצא להם שימוש לכל מטרה            |
|מועילה, לרבות מטרת חסד". סמכות זו לא ניתנה                  |
|לאצילה.                                                     |

|סעיף דומה אינו כלול בחוק שמוצע לתקנו. המעיף                      |
|המוצע בא להשלים את החוק לענין זה, אך הוא יאפשר                   |
|לשר לאצול מסמכותו.                                               |
|כדי להבטיח שימוש מועיל בעדפי הירקות לצרכי                        |
|חסד, מוצע לקבוע כי חלוקת העדפים תיעשה בתיאום                     |
|עם שר הסעד.                                                      |
|חבר-הכנסת : אברהם שכטרמן                                         |

|1 ס"ח תשי"ט, עמ' 222', תשכ''ב, עמ' 130.       |
