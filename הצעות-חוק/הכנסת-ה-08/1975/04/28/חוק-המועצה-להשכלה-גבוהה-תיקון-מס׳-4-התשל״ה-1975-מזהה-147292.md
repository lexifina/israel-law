|מתפרסמות בזה הצעות חוק מטעם הממשלה:                    |

|מבוא                                                                                                           |
|למועצה להשכלה גבוהה סמכויות בקשר להכרה במוסדות להשכלה גבוהה, למתן                                              |
|היתרים למוסדות השכלה גבוהה, ולהענקת תארים אקדמאים מוכרים.                                                      |
|כדי שהמועצה תהא מקובלת כבעלת סמכות כגוף אובייקטיבי ונייטרלי, ומנגנונו                                          |
|יהיה עצמאי ובלתי תלוי, יש צורך בארגון המועצה כתאגיד עצמאי. במסגרת זו תוכל                                      |
|המועצה לבצע פעולות משקיות מסויימות ובעיקר לקיים סגל עובדים נפרד.                                               |
|היום מבוצעות כל פעולות המועצה באמצעות משרד החינוך והתרבות.                                                     |
|עם הפיכת המועצה לתאגיד עצמאי יש צורך בקביעת הוראות בדבר הביקורת עליו,                                          |
|בדבר זכויות העובדים, העברתם ומעמדם, בדבר הגבלתו בהעברת נכסים וכן כדבר תקציבו.                                  |

|חוק המועצה להשכלה גבוהה (תיקון מס' 4), תשל"ה-1975                                                |

|1. אחרי סעיף 3 לחוק המועצה להשכלה גבוהה, תשי"ח-1958 1, יבוא:                                                |הוספת סעיפים         |
|                                                                                                            |3א-3ה                |
|3א. המועצה תהא תאגיד, כשר לכל חיוב, זכות ופעולה משפטית.                               |''המועצה תאגיד      |                     |
|3ב. המועצה תהא גוף מבוקר, כמשמעותו בסעיף 9(6) לחוק מבקר                               |המועצה גוף          |                     |
|המדינה, תשי"ח-1958 [נוסח משולב] 2.                                                    |מבוקר               |                     |
|3ג. קבלת עובדי המועצה ומינוים ייעשו בידי המועצה ויהיו כשל                             |קבלת עובדים         |                     |
|עובדי המדינה, בתיאומים שייקבעו בתקנות; תנאי העבודה ושכרם של                           |ותנאי עבודתם        |                     |
|עובדי המועצה יהיו כשל עובדי המדינה.                                                   |                    |                     |
|3ד. המועצה לא תהא רשאית למכור או להעביר בדרך אחרת נכס                                 |איסור העברת         |                     |
|שבבעלותה, למשכנו או להשכירו לתקופה העולה על עשר שנים, אלא                             |נכסים               |                     |
|באישור שר החינוך והתרבות; שכירות המקנה זכות לחדשה או להאריכה,                         |                    |                     |
|וכן שכירות לתקופה נוספת שבצירופה לקודמות הן עולות על עיטר                             |                    |                     |
|שנים, טעונה אישור כאמור.                                                              |                    |                     |
|3ה. הכנת התקציב, מסירותו לממשלה לאישור יהיו בדרכים שייקבעו                            |התקציב              |                     |
|בתקנות."                                                                              |                    |                     |
|2. (א) עובדי המדינה המועסקים במועצה ערב תחילתו של חוק זה, ימשיכו בשירותם                                    |העברת עובדים         |
|כעובדי ؀ࠂࠆࠈࠌࠚࠜࠞהמועצה, בתנאי שירות שלא יהיו גרועים מתנאי שירותם ערב תחילת חוק זה.                           |                     |
|(ב) זכויות עובדי המועצה שהועברו לשירותה והנובעות מעבודתם כעובדי המדינה                                      |                     |
|כאמור בסעיף קטן (א), ייחשבו כזכויות הנובעות מעבודתם בשירות המועצה.                                          |                     |
|(ג) ההסדרים לגבי זיכוי המועצה בסכומי התשלומים שהעובדים העוברים לשירותה                                      |                     |
|יהיו זכאים להם ייקבעו, במידת הצורך, בהסכם בין, המועצה ובין המדינה.                                          |                     |
|3. כל הסכומים שהוקצבו למועצה כחוק התקציב לשנת הכספים שבה חל יום תחילת                                       |כספים שהוקצבו        |
|חוק זה, ולא הוצאו ער לאותו יום, יעמדו לרשות המועצה.                                                         |בתקציב               |
