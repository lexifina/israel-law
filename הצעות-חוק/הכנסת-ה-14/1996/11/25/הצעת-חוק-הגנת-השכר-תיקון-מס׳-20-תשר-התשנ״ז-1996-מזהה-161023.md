|ו. בחוק הגנת השכר, התשי"ח-1958 1( להלן - החוק העיקרי), אחרי סעיף 3 יבוא:                                 |הוספת סעיף 5א       |
|3א. (א) בסעיף זה -                                                                       |-תשר אינו       |                    |
|"תשר" - מענק כספי שנתן לעובד מי שקיבל או שקנה שירות ממעבידו,                             |שכר עבודה       |                    |
|באמצעות אותו עובד, באשר המענק לא נכלל בתמורה שדרש המעביד                                 |                |                    |
|ממקבל או מקונה השירות;                                                                   |                |                    |
|"עובד" - עובד בענף עבודה המנוי בתוספת, בחלק א'.                                          |                |                    |
|(ב) לענין חוק זה ולענין החוקים המנויים בתוספת בחלק בי. תשר                               |                |                    |
|אינו שכר עבודה.                                                                          |                |                    |
|(ג) שר העבודה והרווחה, באישור ועדת העבודה והרווחה של                                     |                |                    |
|הכנסת, רשאי בצו לשנות את חלק א' של התוספת."                                              |                |                    |

|דברי הסבר                |

|ועדה ציבורית לבדיקת יחסי העבודה בענף                         |
|המלצרות, בראשותו של הפרופ' אברהם פרידמן, ואשר                |
|נציגי ארגוני העובדים והמעבידים הנוגעים בדבר היו              |
|חברים בה, מצאה כי במקרים רבים אין העובדים בענף               |
|זה משתכרים שכר מינימום כחוק. זאת, משום                       |
|התייחסותם של מעבידים מסוימים להשתכרותו של                    |
|העובד ככזו הכוללת גם סכומי תשר (טיפ) המשולמים                |
|להם מתוך נוהג על ידי הלקוחות, במישרין. כתוצאה                |
|מכך גם אין עובדים אלה זוכים לתשלומים עבור זכויות             |
|סוציאליות, הנובעים מן השכר.                                  |
|מאחר שסכומי התשר האמורים משולמים                             |
|בסכומים העשויים להשתנות על פי רוחב ידו ורצונו                |
|הטוב, או להיפך, של מקבל השירות, ובעיקר משום שאין             |
|הם משולמים על ידי המעביד או באמצעותו, מצאה                   |

|הועדה כי יש צורך לקבוע בחיקוק, במפורש, שמענק                    |
|כספי המשולם לעובד ישירות על ידי מקבל השירות, לא                 |
|יבוא בגדר שכר עבודה לענין חיקוקים הנוגעים לזכויות               |
|עובדים.                                                         |
|לפיכך מוצע כי תשר יוצא מגדר שכר ؀ࠂ࠘ࠚࠞࠤࠦࠨ࠶࠸עבודה לענין           |
|חוקי מגן לעובד המפורטים בחלק ב' של התוספת לחוק.                 |
|כן מוצע כי קביעה זו תחול לא רק בענף המלצרות כעולה               |
|מממצאי הועדה הציבורית אלא גם בענפי עבודה                        |
|אחרים שבהם נהוג לשלם תשר לעובדים, המפורטים אף                   |
|הם בתוספת לחוק, בחלק א'.                                        |
|עוד מוצע, לנוכח התנאים המשתנים במשק,                            |
|להקנות סמכות לשר העבודה והרווחה לשנות, באישור                   |
|ועדת העבודה והרווחה של הכנסת, את החלק הראשון                    |
|של התוספת.                                                      |
