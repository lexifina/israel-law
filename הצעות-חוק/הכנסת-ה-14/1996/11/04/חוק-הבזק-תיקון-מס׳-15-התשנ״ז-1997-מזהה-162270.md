|דברי הסבר              |

|סעיף 6לד לחוק הבזק, התשמ"ב-1982 (להלן -                      |
|החוק), קובע כלהלן:                                           |
|"השימוש באפיקים                                              |
|6לד. (א) השר רשאי, לאחר התייעצות במועצה,                     |
|להורות לבעל זכיון לאפשר לאחר שימוש, בתשלום,                  |
|באפיקי רשת הכבלים שלו, ובלבד שקיבולת האפיקים                 |
|שתיוותר לבעל הזכיון לא תפחת מחמש שישיות.                     |
|(ב) בעד שימוש כאמור בסעיף קטן (א), רשאי בעל                  |
|זכיון לדרוש מן המשתמש מחיר סביר, ובאין הסכמה                 |
|ביניהם - תקבע המועצה את המחיר על בסיס העלות                  |
|הכוללת של השימוש בתוספת רווח סביר.                           |
|(ג) בעל זכיון יקצה, ללא תמורה, אפיק מאפיקי                   |
|רשת הכבלים שלו לשידורי הטלויזיה הלימודית-, את                |
|דרכי השימוש באפיק כאמור תקבע המועצה."                        |
|הסעיף מעניק סמכות לשר התקשורת להורות לבעל                    |
|זכיון לשידורי כבלים לאפשר לאחר (להלן - בעל זכות              |
|שימוש) שימוש בשישית מאפיקי הכבלים העומדים                    |
|לרשותו של בעל הזכיון.                                        |
|הוראת סעיף 6לד (בסעיפים קטנים (א) ו-(ב))                     |
|מצומצמת; סמכות השר למתן ההוראות לבעל הזכיון                  |
|(סעיף קטן (א)), זכותו של בעל זכיון לדרוש תשלום סביר          |
|מבעל זכות השימוש וקביעת גובה דמי השימוש בידי                 |
|המועצה אם הצדדים לא הסכימו ביניהם; הסעיף הקיים               |

|אינו מגדיר את אופי השימוש שרשאי לעשות בעל זכות                  |
|שימוש ולא צוין באילו דרכים רשאי בעל זכות שימוש                  |
|לממן שידור מישדרים באפיק זה; כן לא נאמר בסעיף מי                |
|רשאי להיות בעל רשיון ומהן דרכי הענקת הרשיון.                    |
|מטרתו של התיקון היא איפוא להסיר ספקות                           |
|ולהבהיר את הסמכויות בכל הקשור בשימוש באפיק                      |
|שיועמד לרשותו של בעל זכות שימוש.                                |
|לפסקה (ו): בסעיף 6לד(א) לחוק אין הבחנה            |סעיף 2       |
|בין סוגי הפעילויות באפיק שיועמד לבעל              |             |
|זכות שימוש, מי יקבע את יעוד האפיק ומהם סדרי                     |
|העדיפות בענין זה; התיקון בסעיף קטן (א) בא לפתור את              |
|התהיות והשאלות האמורות; הסמכות ניתנת בידי השר,                  |
|יכול שהשימוש באפיק יינתן לידי "משדר ערוץ" שישדר                 |
|שידורים לציבור ויכול שהשימוש ייועד גם לשירותים                  |
|אחרים שניתן לתת באמצעות האפיק.                                  |
|לפסקה (2): בסעיף 6לד(ב) לחוק נקבע שבאין הסכמה בין               |
|בעל הזכיון לבין בעל זכות השימוש בדבר גובה דמי                   |
|השימוש בעד האפיק שמשתמש בו בעל זכות השימוש,                     |
|תקבע מועצת הכבלים את המחיר.                                     |
|הנסיון שנרכש בענין זה מלמד, שמועצה ציבורית                      |
|כמועצת הכבלים אינה הגוף המקצועי לקבוע עלויות                    |
|כניסה לרשתות תקשורת, באשר בדיקת סבירותו של                      |
|מחיר אינה ענין למועצה שבה מחליטים בהצבעה. מן                    |

|הוספת סעיף        |3. אחרי סעיף 6לד לחוק העיקרי יבוא:                                                                        |
|6לד1              |                                                                                                          |
|                  |6לד1. (א) השר רשאי להעניק רשיון שידור למשדר ערוץ למי שבחרה                           |"רשיון לשידורים      |
|                  |המועצה במכרז שפירסמה.                                                                |ולשירותים אחרים      |
|                  |(ב) במכרז לפי סעיף קטן (א) רשאית המועצה לקבוע תנאים ؀ࠂࠒࠔ࠘ࠢࠤࠨ࠲࠴࠶ࡄࡆࡌלענין              |                     |
|                  |חובותיו של בעל הרשיון בכל הנוגע לשידוריו; ומתוך מגמה להביא לריבוי                    |                     |
|                  |הגורמים המעורבים בשידור מישדרים לציבור, רשאית המועצה לקבוע                           |                     |
|                  |במכרז -                                                                              |                     |
|                  |(ו) תנאים והגבלות בדבר החזקה, העברה או רכישה של                                      |                     |
|                  |זכויות בבעל הרשיון, לרבות בידי מי שמשדר שידורים לציבור                               |                     |

|                  |במישרין או בעקיפין;                                                                  |                     |
|                  |(2) כי בעל הרשיון יהיה רשאי לממן את שידוריו באמצעות                                  |                     |

|                  |סעיף 6כד לא יחולו על שידוריו.                                                        |                     |
|                  |(ג) השר רשאי, בהתאם לסמכותו לפי סעיף 4, להעניק רשיון                                 |                     |
|                  |לשירותים אחרים באפיק על פי מכרז שיפרסם לענין זה.                                     |                     |
|                  |(ד) השר רשאי לקבוע תקנות לענין ההליכים לעריכת מכרז                                   |                     |
|                  |לבחירת בעל רשיון שידור למשדר ערוץ לפי סעיף קטן (א), דרכי הגשתן של                    |                     |

|דברי הסבר           |

|הראוי איפוא שהסמכות לקביעת המחיר תהיה בידי גוף,                |
|האמון על כך והעוסק בכך בהקשר אחר, והוא: השר,                   |
|ולמעשה הגורם המקצועי במשרד העוסק בכך, הקובע                    |
|לפי סעיף 5 לחוק את המחיר שישלם בעל רשיון אחד                   |
|למשנהו בער השימוש בתשתית שלו.                                  |
|לסעיף קטן (א): מוצע להסמיך את השר               |סעיף 3        |
|להעניק רשיון למשדר ערוץ שנבחר על פי             |              |
|מכרז שפרסמה המועצה.                                            |
|לסעיף קטן (ב): מוצע להסמיך את המועצה לקבוע את                  |
|תנאי המכרז, לרבות חובות בעל הרשיון, תנאים והגבלות              |
|של זכויות בבעל הרשיון והרשאה לממן את השידורים                  |
|באמצעות פרסומת.                                                |

|לסעיף קטן (ג): מוצע להסמיך את השר להעניק רשיון               |
|באפיק לשירותים אחרים על פי סמכותו שבסעיף 4 לחוק              |
|(רשיון מיוחד לשירותי בזק) על פי מכרז שיפרסם.                 |
|לסעיף קטן (ד): מוצע להסמיך את השר להתקין תקנות               |
|בדבר הליכי המכרז לבחירת בעל רשיון שידור למשדר                |
|ערוץ וההליך להענקת רשיון.                                    |
|לסעיף קטן (ה): מוצע להסמיך את השר לקבוע את                   |
|שיעורי התמלוגים שישלם מי שקיבל רשיון לפי סעיף                |
|זה.                                                          |
|לסעיף קטן (ו): מוצע להסמיך את המועצה להחיל את                |
|הכללים הקיימים על משדר ערוץ או לקבוע כללים                   |
|מיוחדים לגביו.                                               |
