|אחרי סעיף קטן (א) יבוא:                                                                                      |                    |
|"(א1) יוצא צבא הנמנה עם כוחות המילואים, אשר לא שירת שירות סדיר, או שירת                                      |                    |
|שירות סדיר שאינו עולה על שלושה ימים, חייב, בנוסף לאמור בסעיף קטן (א),                                        |                    |
|בשירות מילואים במקום שירות סדיר."                                                                            |                    |
|2. בסעיף 28 לחוק העיקרי, אחרי פסקה (2) יבוא:                                                                 |תיקון סעיף 28       |
|"(3) שסך כל ימי שירות המילואים החודשי בשנה לא יעלה על ששה."                                                  |                    |
|5. במקום סעיף 29 לחוק העיקרי יבוא:                                                                           |החלפת סעיף 29       |
|(א) תקופת שירות המילואים השנתי לא תעלה על עשרים וארבעה ימים                                |"שירות שנתי      |                    |
|בשנה, ותקופת שירות המילואים לצורכי אימונים, לא תעלה על ששה                                 |                 |                    |
|ימים נוספים.                                                                               |                 |                    |
|(ב) שירות מילואים שנתי יהיה רצוף, אולם פוקד או מפקד כאמור                                  |                 |                    |
|בסעיף 27(ג), רשאי להורות, כי תקופת שירות המילואים השנתי של יוצא                            |                 |                    |
|צבא בשנה מסוימת תחולק לשתיים או לשלוש ואולם אם הסכים לכך                                   |                 |                    |
|יוצא הצבא בכתב, ניתן לחלקה אף לארבע או יותר.                                               |                 |                    |
|(ג) במנין תקופת שירות המילואים השנתי יבואו ימי המנוחה                                      |                 |                    |
|כמשמעותם בפקודת סדרי השלטון והמשפט, התש"ח-1948 2, ובן ימים                                 |                 |                    |
|אחרים שעל פי פקודות הצבא אין לשחרר בהם יוצאי צבא משירות                                    |                 |                    |
|מילואים, ואולם לא יבוא במנין תקופת השירות יום באמור אם הוא היום                            |                 |                    |
|האחרון של תקופת שירות המילואים המירבית.                                                    |                 |                    |
|(ד) שר הבטחון רשאי להסמיך פוקד או מפקד לקרוא ליוצא צבא                                     |                 |                    |
|לשירות מילואים שנתי שמשכו ארוך מהקבוע בסעיף זה, בתנאים שיקבע                               |                 |                    |
|השר בתקנות."                                                                               |                 |                    |

|דברי הסבר                |

|הצעת החוק נועדה להסדיר את הקריאה לשירות                    |
|מילואים שנעשתה עד כה מכוח סעיפים 27 ו-54 לחוק              |
|שירות בטחון [נוסח משולב], התשמ"ו-1986.                     |
|לפי המוצע, לא יעלה ؀ࠂࠒࠔ࠘ࠜࠞࠠשירות המילואים השנתי על         |
|עשרים וארבעה ימים ותקופת שירות המילואים לצורכי             |
|אימונים לא תעלה על שישה ימים נוספים.                       |

|עם זאת יורשה שר הבטחון לקבוע תנאים בתקנות                     |
|שלפיהם יורשה פוקד או מפקד לקרוא לשירות מילואים                |
|ארוך יותר.                                                    |
