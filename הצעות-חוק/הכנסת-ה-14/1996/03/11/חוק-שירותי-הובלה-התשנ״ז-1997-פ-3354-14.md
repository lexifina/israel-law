|הגדרות        |1. בחוק זה -                                                                                             |
|              |"גרור" - במשמעותו בתקנות התעבורה, אשר משקלו הכולל הוא 10 טון או יותר;                                    |
|              |"הובלה" - הובלה במשאית של מטענים" נוזליים או מוצקים, לרבות בתפזורת, בין בשכר                             |
|              |ובין בקשר עם עסקו או מסחרו של מוביל;                                                                     |

|דברי הסבר        |

|מטרתה של הצעת חוק זו הוא לחייב רשיון לענף                    |
|ההפעלה של הובלה במשאית במדינת ישראל. נושא זה                 |
|חייב להיות מוסדר בחקיקה ראשית, בדי להבטיח                    |
|התאמתו לחוק-יסוד: חופש העיסוק.                               |
|כיום, נושא המשאיות ונהגיהן, חברות ההובלה                     |
|וההסעה וקציני הבטיחות פרוץ, וכל בעל עסק של                   |
|משאיות עושה כרצונו, כך שבפועל ניתן לראות משאיות              |
|כבדות הנהוגות בידי נהגים אשר נמצאים ליד ההגה                 |
|26-16 שעות רצופות, העמסת יתר של המשאיות, נסיעה               |

|ללא טסטים במשאית שאינה מתוחזקת כראוי ונסיעה                   |
|עם רשיונות לא בתוקף הן של הנהג והן של המשאית.                 |
|מוצע להסדיר את כל נושא המשאיות,                               |
|האוטובוסים ונהגיהם, על מנת לשים קץ למצב הבלתי                 |
|נסבל הקיים היום בתחום זה בכבישים.                             |
|טרק ראשון                                                     |
|ענינו של הפרק 'הגדרות''. מוצע לקבוע הגדרות                    |
|ברורות לגבי רשיון הובלה ורשיון מפעיל.                         |

|"הובלה בשכר-  הובלה במשאית בשכר או בתמורה אחרת;                                                               |                  |
|"הובלה עצמית" - הובלה במשאית הנמצאת בבעלות המוביל או בשליטתו, לצרכי עסקיו                                     |                  |
|העצמיים של המוביל, ללא קבלת שכר או תמורה אחרת;                                                                |                  |
|"השכרה" - השכרת גרורים, השאלתם, מתן רשות השימוש בהם והעמדתם לרשות אדם                                         |                  |
|אחר ככל צורה שהיא, כשהם נעשים או ניתנים בשכר או בתמורה אחרת;                                                  |                  |
|"מוביל" - אדם שלו הבעלות או השליטה במשאית, לרבות המחזיק במשאית מכוח הסכם                                      |                  |
|של מקח-אגב-שכירות;                                                                                            |                  |
|"מזמין הובלה" - אדם שהזמין ממוביל ביצוע הובלה בשבר או בתמורה אחרת;                                            |                  |
|"מפקח" - מפקח על התעבורה במשרד התחבורה או מי שהמפקח הסמיכו לענין חוק זה,                                      |                  |
|ובמידה שהסמיכו;                                                                                               |                  |
|"משאית" - רכב מנועי מסחרי כמשמעותו בפקודת התעבורה1, שמשקלו הכולל המותר                                        |                  |
|עולה על 10,000 ק"ג;                                                                                           |                  |
|"משרד הובלה" - מקום שבו מתנהל מפעל, עסק, מיזם או מוסד של הובלה, בשכר או                                       |                  |
|בתמורה אחרת, ברכב מסחרי או במשאית;                                                                            |                  |
|"רשיון הובלה בינלאומי" - רשיון להובלה בשכר הן בשטח מדינת ישראל והן מחוץ                                       |                  |
|לישראל;                                                                                                       |                  |
|"רשיון הובלה במדינת ישראל" - רשיון להובלה בשכר בשטח מדינת ישראל בלבד;                                         |                  |
|"רשיון להובלה עצמית" - רשיון להובלה שלא בשכר, לצרכים עצמיים בלבד, הן בשטח                                     |                  |
|מדינת ישראל והן מחוץ לישראל, כפי שייקבע בתנאי הרשיון;                                                         |                  |
|"רשיון מפעיל" - רשיון להובלה עצמית אשר ניתן על פי חוק זה ואשר הוא מסוג רשיון                                  |                  |
|הובלה במדינת ישראל או רשיון הובלה בינלאומי;                                                                   |                  |
|"שטר מטען" - הסכם הובלה בשכר במשאית, שהצדדים לו הם מוביל ומזמין הובלה;                                        |                  |
|"תקנות התעבורה" - תקנות התעבורה, התשכ"א-1961 2.                                                               |                  |
