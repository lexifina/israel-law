|הצעת חוק איסור נהיגה ברכב בחוף הים, התשנ"ו-1996*                                     |

|הגדרות          |ו. בחוק זה -                                                                                             |
|                |"רכב" - כמשמעותו בפקודת התעבורה, התשכ"א-1961 1 (להלן - פקודת התעבורה), ובכלל                             |
|                |זה - טרקטורון, רכב שדה, אופנוע, רכב המשמש לרוכלות וביוצא באלה, ולמעט                                     |
|                |אופניים;                                                                                                 |

|דברי הסבר                  |

|החוק המוצע בא לתת פתרון מיידי לבעיה של                     |
|סיכון חיי אדם ושלמות גופם של הבאים לחופי הארץ              |
|לצורך נופש, הנובעת מנהיגת כלי רכב מסוגים שונים             |
|בחופים, וכן לשמירה על ערכי החי, הצומח והסביבה              |

|הטבעית בחופי הארץ, הניזוקים באופן קשה - ולעתים                |
|בלתי הפיך - כתוצאה מתופעה זו. מוצע לאסור נהיגה                |
|ברכב בחוף הים, למעט בסייגים המפורטים בו.                      |

|* הצעת חוק ג'כ''א; הועברה לועדה ביום כ"ה בטבת התשנ"ו (17 לינואר 1996).            |
|1 דיני מדינת ישראל, נוסח חדש 7, עמ' 173.                                          |

|"חוף הים" - רצועת החוף, חולית או סלעית, ברוחב של 100 מטר מקו המים, באזור חוף                              |איסור נהיגה          |
|מוכרז - בל תחום החוף המוכרז, למעט דרכים שהוסדרו על פי דין וחניונים, ולמעט                                 |בחוף הים             |
|תחומים שהוכרזו כנמל לפי פקודת הנמלים [נוסח חדש], התשל"א-1971 2;                                           |                     |
|"השר" - שר הפנים.                                                                                         |                     |
|2. לא ינהג אדם ברכב בחוף הים.                                                                             |                     |
|5. מבלי לגרוע מהוראות סעיף 2, רשאי אדם לנהוג ברכב בחוף הים -                                              |סייגים ؀ࠂࠎࠐࠔࠚࠜࠞלנהיגה|
|(ו) למטרות שמירה על בטחון הציבור, ביצוע משימות שיטור, פיקוח והצלה;                                        |בחוף הים             |
|(2) למטרות מתן שירותים - כשהנהג הורשה לכך במפורש על ידי הרשות                                             |                     |
|המקומית הנוגעת בדבר, ומחוץ לתחום הרשות המקומית - באישור הממונה על                                         |                     |
|המחוז;                                                                                                    |                     |
|(3) למטרה אחרת שאישר השר בצו.                                                                             |                     |
|4. (א) השר רשאי להסמיך מפקחים לענין חוק זה מקרב עובדי משרדו, ומתוך רשימות                                 |הסמכת מפקחים         |
|פקחים ומפקחים שהגישו לו איגודי ערים ורשויות מקומיות.                                                      |                     |
|(ב) השר לאיכות הסביבה רשאי להסמיך מפקחים לענין חוק זה מקרב עובדי משרדו                                    |                     |
|ומתוך רשימת פקחים ומפקחים שהגישו לו רשות הגנים הלאומיים, רשות שמורות הטבע,                                |                     |
|רשות העתיקות, רשות נחלים ומעיינות, מינהל מקרקעי ישראל והקרן הקיימת לישראל.                                |                     |
|5. היה לשוטר יסוד סביר להניח כי ארם נהג ברכב בניגוד להוראות חוק זה ובאופן שיש                             |פסילת רשיון          |
|בו כדי לסכן חיי בני אדם או לגרום פגיעה ניכרת בסביבה, יודיע על כך לקצין משטרה                              |נהיגה                |
|בדרגה שאינה פחותה מדרגת מפקח, והקצין רשאי לפסול אותו אדם, בצו, מלהחזיק ברשיון                             |                     |
|נהיגה לתקופה של 30 ימים מיום שנמסר לו הצו, והוראות סעיף 47, 48, 49 ו-50 לפקודת                            |                     |
|התעבורה יחולו בהתאם.                                                                                      |                     |
|6. השר ממונה על ביצוע חוק זה והוא רשאי להתקין תקנות בבל הנוגע לביצועו, ובלבד                              |ביצוע ותקנות         |
|שתקנות בענינים שהשר לאיכות הסביבה, השר לבטחון הפנים ושר תחבורה ממונים עליהם                               |                     |
