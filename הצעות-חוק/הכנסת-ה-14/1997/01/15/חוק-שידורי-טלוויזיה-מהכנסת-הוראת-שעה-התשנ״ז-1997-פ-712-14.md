|הצעת חוק הכנסת (תיקון מס' 3) (שידורי טלוויזיה מהכנסת),                                          |
|התשנ"ז-1997*                                                                                    |

|הוספת סעיף 4       |ו. בחוק הכנסת, התשנ"ד-1994 1, אחרי סעיף 3 יבוא:                                                            |
|                   |4. (א) בסעיף זה -                                                                     |"שידורי טלוויזיה   |
|                   |"גורם משדר'' - מי שעל פי כל דין רשאי לשדר שידורי טלוויזיה לציבור                      |מהכנסת             |
|                   |בכל הארץ;                                                                             |                   |
|                   |"שידורים מהכנסת'' - שידורי טלוויזיה מהכנסת של ישיבות מליאת                            |                   |
|                   |הכנסת ושל ועדותיה, ושידורים אחרים מהכנסת בהתאם לסעיף זה.                              |                   |
|                   |(ב) ישיבותיה של מליאת הכנסת וכן חלק מישיבותיהן של ועדות                               |                   |
|                   |הכנסת, יועברו בטלוויזיה בשידור ישיר ורצוף על ידי גורם משדר.                           |                   |
|                   |(ג) הגורם המשדר לא יבטל, יקטע או יפסיק את השידורים                                    |                   |
|                   |מהכנסת, אלא בהתאם לכללים שנקבעו בתקנות, לפי סעיף קטן (ה).                             |                   |

|* הצעת חוק מס' פ/2ו7; הועברה לועדה ביום א' בטבת התשנ''ז (וו בדצמבר 1996).                     |
|1 ס"ח התשנ''ד, עמ' 140; התשנ''ו, עמ'  234 ועמ' 372.                                           |

|(ד) הכנסת תממן את ההוצאות שנגרמו לגורם המשדר כתוצאה                                                           |                  |
|מביצוע השידורים מהכנסת; סכום המימון ייקבע בהסכם שייחתם בין                                                    |                  |
|הכנסת לבין הגורם המשדר.                                                                                       |                  |
|(ה) יושב ראש הכנסת, באישור ועדת הכנסת, יקבע בתקנות כללים,                                                     |                  |
|הוראות ותנאים לקיום השידורים מהכנסת, בין היתר בענינים אלה:                                                    |                  |
|(1) בחירת הגורם המשדר, בין בדרך של מכרז ובין בדרך                                                             |                  |
|אחרת, לרבות הדרישות שעל הגורם המשדר לעמוד בהן כתנאי                                                           |                  |
|לבחירתו ולביצוע השידורים מהכנסת;                                                                              |                  |
|(2) התקופה שבה יבצע הגורם המשדר את השידורים                                                                   |                  |
|מהכנסת;                                                                                                       |                  |
|(ג) הדרך לקביעת הישיבות של ועדות הכנסת, שדיוניהן                                                              |                  |
|יועברו בשידור ישיר;                                                                                           |                  |
|(4) חיוב הגורם המשדר להעביר בשידור ישיר אירועים                                                               |                  |
|מיוחדים המתקיימים בכנסת;                                                                                      |                  |
|(5) חיוב הגורם המשדר לשדר או להגיש תכניות הכוללות                                                             |                  |
|סיקור הליכים בכנסת, או תכניות אחרות על עניני הכנסת                                                            |                  |
|ועבודתה;                                                                                                      |                  |
|(6) נסיבות שבהן יהיה הגורם המשדר רשאי לקטוע או                                                                |                  |
|להפסיק את רצף השידורים מהכנסת.''                                                                              |                  |
|2. (א) על אף האמור בסעיף؀ࠂࠈࠊࠎࠚࠜࠞ ו, במהלך השנים 997ו ו-998ו יבוצעו השידורים מהכנסת                            |הוראת שעה         |
|על ידי הרשות, כמשמעותה בחוק רשות השידור, התשכ"ה-1965 2.                                                       |                  |
|(ב) ביצוע השידורים מהכנסת על ידי הרשות יהיה בהתאם להסכם שייחתם בין                                            |                  |
|הכנסת לבין הרשות.                                                                                             |                  |

|דברי הסבר                  |

|מזה שנים אחדות מופעלים שידורי הטלוויזיה מן                    |
|הכנסת. הציבור בישראל זוכה באמצעות שידורים אלה                 |
|לאפשרות לעקוב אחר הנעשה בבית המחוקקים ואף                     |
|להכיר מקרוב יותר את חברי הכנסת ואת עמדותיהם                   |
|האישיות וכן את המפלגות על מצעיהן ותפיסת עולמן                 |
|בתחומי החיים השונים.                                          |
|השידורים המופעלים מהכנסת נעשים באמצעות                        |
|ערוץ ממלכתי. השידורים וכן עלותם מתבצעים על פי                 |
|הסכם בין הכנסת לרשות השידור.                                  |

|מן הראוי לקבוע בנורמה חוקית את השידור מן                        |
|הכנסת ואת המשכתו בכלים ממלכתיים כדי למנוע את                    |
|האפשרות ששלטון כלשהו יחליט כי אין הוא חפץ                       |
|בשידורים מן הכנסת ויפסיק אותם בהחלטה ממשלתית                    |
|חד צדדית. הואיל ומדובר במכשיר שיש לו תרומה                      |
|ייחודית לדמוקרטיה בישראל - מוצע לעגן אותו                       |
|בחקיקה.                                                         |
