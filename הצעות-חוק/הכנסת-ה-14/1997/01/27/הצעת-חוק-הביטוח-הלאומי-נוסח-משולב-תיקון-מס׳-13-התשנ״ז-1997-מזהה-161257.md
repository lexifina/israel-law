|(1) כותרת השוליים תהיה "שלושה ימים ראשונים";                                                                |                      |
|(2) במקום סעיפים קטנים (א), (או), (א2) ו-(א3) יבוא:                                                         |                      |

|שכר אותו יום."                                                                                              |                      |

|94. (א) בסעיף זה -                                                                     |"תקופת הזכאות      |                      |

|הנפגע לדמי פגיעה לפי פרק זה.                                                           |                   |                      |

|דברי הסבר             |

|סימן ד' לפרק ה' שבחוק הביטוח הלאומי [נוסח                   |
|משולב], התשנ"ה- 1995(להלן - החוק), דן בדמי פגיעה            |
|המשתלמים למי שאירעה לו פגיעה בעבודה, בעד פרק                |
|הזמן שאינו מסוגל לעבוד.                                     |
|בחוק ההסדרים במשק המדינה (תיקוני חקיקה                      |
|להשגת יעדי התקציב לשנת 1997), התשנ"ז- 1997(להלן             |
|- חוק ההסדרים), תוקן סעיף 95 שבפרק האמור ונקבע בו           |
|שהמוסד לא ישלם דמי פגיעה למי שאירעה לו פגיעה                |
|בעבודה (להלן - הנפגע), בעד תשעת הימים הראשונים              |
|שבעדם הוא זכאי לדמי פגיעה. ואולם התיקון האמור               |
|לסעיף 93 קובע כי על המעביד לשלם לעובדו דמי פגיעה            |
|בעד תשעת הימים האמורים.                                     |
|הוראות אלה נכנסו מיד לתוקף, החל ביום כ"ב                    |
|בטבת התשנ'ז (1 בינואר 1997), ולפיהן הוטל על                 |
|המעסיקים, נוסף על הנטל הכספי, גם נטל מנהלי הכרוך            |
|בחישוב ובתשלום דמי הפגיעה במועד, לרבות תשלום                |
|פיצויי הלנה במקרה של איחור בתשלום דמי הפגיעה.               |

|זאת ועוד, קיים חשש כי זכויותיהם של עובדים                    |
|לדמי פגיעה ייפגעו.                                           |
|נוכח הקושי הכרוך בביצוע תשלום דמי הפגיעה                     |
|על ידי המעסיקים ובמטרה למנוע פגיעה אפשרית                    |
|בזכויותיהם של עובדים הזכאים לדמי פגיעה, מוצע כי              |
|חוק הביטוח הלאומי יתוקן וייקבע בו כדלקמן:                    |
|(א) המוסד ישלם לעובד שנפגע את דמי הפגיעה ויגבה               |
|את הסכום שישלם ממעבידו-,                                     |
|(ב) הכלל האמור, לפיו מעביד יהיה חייב להחזיר                  |
|למוסד את דמי הפגיעה ששילם, לא יחול על עובד                   |
|؀ࠂࠒࠔ࠘ࠜࠞࠠבמשק בית שלא לצורך עסקו של המעביד.                   |
|מוצע כי התיקון המוצע לחוק יחול ממועד תחילתו                  |
|של התיקון לסעיף 93 לחוק כפי שתוקן בחוק ההסדרים,              |
|כך שהשינוי לענין תשעת ימי הזכאות הראשונים יופעל              |
|ממועד תחילתו של התיקון האמור, בהתאם להסדרים                  |
|הקבועים בתיקון החוק המוצע.                                   |

|תחילה ותחולה      |(1) היה הנפגע עובד -                                                                                        |
|                  |(א) המעביד יחזיר למוסד את סכום דמי הפגיעה                                                                   |
|                  |שהמוסד שילם לנפגע בעד תקופת הזכאות הראשונה;                                                                 |
|                  |הרשה המוסד למעביד לשלם בשמו דמי פגיעה לעובדיו -                                                             |
|                  |יהיה אותו מעביד חייב לשלם לעובד גם את רמי הפגיעה                                                            |
|                  |בעד תקופת הזכאות הראשונה, ולא יהיה זכאי להחזר                                                               |
|                  |הסכומים ששילם בעד תקופת הזכאות הראשונה;                                                                     |
|                  |(ב) (1) היה הנפגע עובד אצל מעבידים שונים, יחזיר                                                             |
|                  |כל אחד מהם למוסד, חלק יחסי מסכום דמי הפגיעה                                                                 |
|                  |ששילם המוסד לנפגע בעד תקופת הזכאות                                                                          |
|                  |הראשונה;                                                                                                    |
|                  |(2) המוסד יקבע את החלק היחסי האמור בפסקה                                                                    |
|                  |(0, בהתאם לחלקו היחסי של סכום שכר העבודה                                                                    |
|                  |הרגיל של העובד אצל אותו מעביד לעומת הסכום                                                                   |
|                  |הכולל של שכר העבודה הרגיל של העובד אצל כל                                                                   |
|                  |מעבידיו;                                                                                                    |
|                  |(ג) מועד תשלום ההחזר למוסד כאמור בפסקאות משנה                                                               |
|                  |(א) ו-(ב) יהיה היום ה-15 בחודש שחל בתכוף לאחר                                                               |
|                  |החודש שבו הודיע המוסד למעביד על סכום דמי הפגיעה                                                             |
|                  |שעליו להחזיר למוסד;                                                                                         |
|                  |(ד) דין סכום ההחזר לפי סעיף זה כדין דמי ביטוח                                                               |
|                  |והוראות פרק ט''ו והתקנות שהותקנו לפיו, יחולו לענין                                                          |
|                  |החזר הסכום האמור, בשינויים המחויבים, כאילו היו דמי                                                          |
|                  |ביטוח;                                                                                                      |
|                  |(ה) השר רשאי לקבוע כללים והוראות בדבר דרכי                                                                  |
|                  |חישוב סכום דמי הפגיעה שעל מעביד להחזיר למוסר לפי                                                            |
|                  |סעיף זה.                                                                                                    |
|                  |(2) היה הנפגע עובד עצמאי, לא ישולמו לו דמי פגיעה בעד                                                        |
