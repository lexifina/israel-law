|מתפרסמת בזה הצעת חוק של חבר הכנסת מטעם ועדת הכספים של הכנסת:                                  |

|הצעת חוק הלוואות לדיור (תיקון מס' 2) (הלוואה נוספת - הוראת שעה),                                            |
|התשנ"ז-1997*                                                                                                |

|1. בחוק הלוואות לדיור, התשנ"ב-1992 1 (להלן - החוק העיקרי), אחרי סעיף 6 יבוא:                            |הוספת סעיף 6א -        |
|                                                                                                        |הוראת שעה              |
|6א. בתקופה שמיום כ"ו בסיון התשנ''ז (1 ביולי 1997) ועד יום ט''ו בניסן                |"הלוואה נוספת -   |                       |
|התשנ"ט (1 באפריל 1999), יחולו הוראות אלה:                                           |הוראת שעה         |                       |
|(ו) בסעיף זה -                                                                      |                  |                       |
|"חוק המכר (דירות)" - חוק המכר (דירות) (הבטחת השקעות של                              |                  |                       |
|רוכשי דירות), התשל"ה-1974 2;                                                        |                  |                       |
|"מוכר" - כמשמעותו בחוק המכר (דירות);                                                |                  |                       |
|(2) מי שניתנה לו הלוואה לדיור לפי חוק זה (להלן - הלוואה                             |                  |                       |
|ראשונה), זכאי להלוואה נוספת לפי סעיף זה (להלן - הלוואה נוספת)                       |                  |                       |
|אם נתקיימו לגביו כל אלה:                                                            |                  |                       |
|(א) ההלוואה הראשונה שולמה על ידו למוכר שהוכרז כפושט                                 |                  |                       |
|רגל, ואם המוכר תאגיד - שניתן לגביו צו כינוס נכסים או צו                             |                  |                       |
|פירוק קבוע;                                                                         |                  |                       |
|(ב) השקעתו לא הובטחה כנדרש לפי חוק המכר (דירות), ואם                                |                  |                       |
|הובטחה - לא היה בהבטחת כספו כדי למנוע ממנו הפסד                                     |                  |                       |
|בסכום שקבע השר, ובלבד שהסכום כאמור מהווה 50% לפחות                                  |                  |                       |
|מן הסכום ששולם למוכר;                                                               |                  |                       |
|(ג) הוא הפסיד בפועל את הסכום האמור בפסקת משנה (ב);                                  |                  |                       |
|(ד) במועד הגשת הבקשה להלוואה הנוספת מתקיימים בו בל                                  |                  |                       |
|התנאים המזכים אותו לקבלת הלוואת דיור לפי חוק זה                                     |                  |                       |
|והכללים לפיו; ויראו אותו, לענין ההגדרה ''זכאי'' כמחוסר דיור                         |                  |                       |
|אף על פי שהשתמש בכספי ההלוואה הראשונה לשם רכישת                                     |                  |                       |
|דירה או בנייתה או למטרה של רכישת זכויות בדירה;                                      |                  |                       |
|(ג) אין בהוראות סעיף זה כדי ؀ࠂࠒࠔࠖࠤלשחרר את מי שקיבל הלוואה                          |                  |                       |
|ראשונה מחובתו להחזירה;                                                              |                  |                       |
|(4) השר רשאי לקבוע כללים למתן הלוואה נוספת.''                                       |                  |                       |
|2. השר, באישור ועדת הכספים של הכנסת, רשאי להאריך את תחולתו של סעיף 6א                                   |הארכת תחולה            |
|לחוק העיקרי כנוסחו בסעיף 1 לחוק זה, עד ליום ח' בניסן התשס''א (1 באפריל 2001).                           |                       |

|דברי הסבר              |

|החוק המוצע נועד להסדיר מצבים שבהם קונים                     |
|רכשו דירות מחברות שהתפרקו, או מקבלנים אשר פשטו              |
|את הרגל ונותרו, שלא באשמתם, ללא קורת גג. על פי              |
|חוק הלוואות לדיור, התשנ"ב-1992 (להלן - החוק),               |
|כנוסחו היום, נחשבים קונים אלה כבעלי דיור ועל כן             |
|אינם זכאים לקבלת משכנתה או השתתפות בשכר דירה,               |

|בעודם נאלצים לשלם משכנתה על דירה שלא יקבלו.                   |
|החוק המוצע יאפשר לקונים אלה להיחשב כמחוסרי                    |
|דיור לצורך החוק, כפי שהם במציאות, ולקבל הלוואה                |
|נוספת מכוח החוק, לשם רכישת דירה אחרת                          |
|למגוריהם.                                                     |
|חבר הכנסת משח גפני                                            |
