|מתפרסמת בזה הצעת חוק מטעם הממשלה:                                  |

|הצעת חוק יישום מזכר ההבנה בין מדינת ישראל לבין הממלכה הירדנית                                                         |
|ההאשמית (שימוש משותף בשדה התעופה עקבה) (הוראת שעה),                                                                   |
|התשנ"ח-1997                                                                                                           |

|1. חוק זה מטרתו ליישם את מזכר ההבנה בדבר שימוש משותף בשדה התעופה עקבה,                                         |מטרת החוק            |
|אשר נחתם בין ישראל לבין הממלכה הירדנית ההאשמית ביום כ"ח באב התשנ"ז                                             |                     |
|(31 באוגוסט 1997).                                                                                             |                     |
|2. בחוק זה -                                                                                                   |הגדרות               |
|"מזכר ההבנה" - מזכר ההבנה האמור בסעיף 1 על נספחיו1;                                                            |                     |
|"שדה התעופה" - שדה התעופה בעקבה, לרבות כביש הגישה ממנו עד תחנת הגבול מעבר                                      |                     |
|ערבה;                                                                                                          |                     |
|"נוסע נכנס" - נוסע שהגיע לשדה התעופה בטיסה שיעדה אילת, לרבות אדם הנמנה עם                                      |                     |
|צוות המטוס;                                                                                                    |                     |
|"נוסע יוצא" - נוסע שהגיע לשדה התעופה על מנת לצאת בטיסה שמוצאה אילת, לרבות                                      |                     |
|אדם הנמנה עם צוות המטוס;                                                                                       |                     |
|"עובד" - אדם הפועל בשטח שדה התעופה מטעם רשות ישראלית או מטעם גוף הפועל                                         |                     |
|במסגרת יישום מזכר ההבנה;                                                                                       |                     |
|"רשות שדות התעופה" - כמשמעותה בחוק רשות שדות התעופה, התשל"ז-1977 2.                                            |                     |
|3. (א) רשות שדות התעופה מוסמכת לבצע בשדה התעופה כל פעולה שהיא מוסמכת                                           |הפעלת סמכויות        |
|לעשות על פי כל דין כבל שהדבר דרוש לשם ביצוע מזכר ההבנה.                                                        |                     |
|(ב) איש בטחון במשמעותו בחוק הטיס (בטחון בתעופה האזרחית), התשל"ז-1977 3,                                        |                     |
|מוסמך לבצע בשדה התעופה כל פעולה שהוא מוסמך לעשותה על פי חוק הטיס (בטחון                                        |                     |
|בתעופה האזרחית), התשל"ז-1977, או על פי חוק רשות שדות התעופה, התשל"ז-1977, או                                   |                     |
|לפי כל דין אחה ככל שהדבר דרוש לשם ביצוע מזכר ההבנה.                                                            |                     |
