|1 מתפרסמת בזה הצעת חוק מטעם הממשלה:                               |

|הצעת חוק שירותי הדת היהודיים (תיקון מס' 9), התשנ"ח-1997                                                      |

|1. בחוק שירותי הדת היהודיים [נוסח משולב], התשל''א-1971 1(להלן - החוק העיקרי),                                        |؀ࠂࠒࠔࠖࠚתיקון סעיף 6  |
|בסעיף 6, בסופו יבוא:                                                                                                 |                    |
|"(ג) חבר המועצה יצהיר אמונים; ואלה דברי ההצהרה: "אני מתחייב לשמור                                                    |                    |
|אמונים למדינת ישראל, למלא באמונה את תפקידי כחבר המועצה הדתית לפי                                                     |                    |
|הוראות חוק זה, ולקיים את החלטות המועצה הדתית".                                                                       |                    |
|(ד) ראש המועצה היוצא יכנס את המועצה לישיבתה הראשונה, ואם לא נכלל                                                     |                    |
|ראש המועצה היוצא בהרכבה החדש או אם נבצר ממנו לכנס את המועצה, יכנס את                                                 |                    |
|המועצה מי שהשר מינה לכך (להלן - היושב ראש).                                                                          |                    |
|(ה) משפתח היושב ראש את הישיבה הראשונה יצהיר את הצהרת האמונים של                                                      |                    |
|חברי המועצה הדתית, וישוב ויקרא את הצהרת האמונים באזני חברי המועצה                                                    |                    |
|הדתית וכל אחד מחברי המועצה הדתית יקום, בזה אחר זה, ויצהיר: "מתחייב                                                   |                    |
|אני"."                                                                                                               |                    |
|2. אחרי סעיף 7 לחוק העיקרי יבוא:                                                                                     |הוספת סעיף 7א       |
|"החלטות המועצה 7א. המועצה הדתית וחבריה יפעלו לפי פסיקת הרבנות                                                        |                    |
|המקומית והרבנות הראשית לישראל בכל ענין שבהלכה,                                                                       |                    |
|שבתחום תפקידיה וסמכויותיה."                                                                                          |                    |

|דברי הסבר                       |

|מוצע שחברי המועצה הדתית יצהירו                      |סעיף ו       |
|אמונים, בדומה לחברי הכנסת.                          |             |
|סעיף זה בא לתת ביטוי לזיקה ולכפיפות                 |סעיף 2       |
|של המועצה הדתית כגוף מינהלי לסמכות                  |             |

|של הרבנות המקומית והרבנות הראשית בנושאים                         |
|ההלכתיים שבמסגרת מתן השירותים הדתיים                             |
|היהודיים.                                                        |
