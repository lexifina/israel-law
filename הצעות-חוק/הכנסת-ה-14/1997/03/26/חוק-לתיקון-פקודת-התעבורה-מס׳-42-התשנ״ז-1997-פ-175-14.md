|מתפרסמת בזה הצעת חוק שלי חברי הכנסת מטעם ועדת הכלכלה של הכנסת:                                    |

|הצעת חוק לתיקון פקודת התעבורה (מס' 44) (איסור נהיגה ברכב מסחרי עם                                                 |
|עומס יתר), התשנ"ז-1997*                                                                                           |

|ו. בפקודת התעבורה1 (להלן - הפקודה), בכותרת הפרק החמישי, במקום "ובדירות קנס"                             |תיקון כותרת      |
|יבוא "ברירות קנס והשבתת רכב".                                                                           |הפרק החמישי      |
|2. אחרי סעיף 30 לפקודה יבוא:                                                                            |הוספת סעיף ו3    |
|31. (א) היה לשוטר יסוד סביר להניח, כי אדם הוביל מטען ברכב                            |"סמכות להשבית    |                 |
|מסחרי כשמשקלו הכולל של הרכב עלה באותה עת, ב - 15% או יותר על                         |רכב מסחרי        |                 |
|המשקל הכולל המותר, יודיע על כך לקצין משטרה בדרגה שאינה פחותה                         |                 |                 |
|מדרגת מפקח ( להלן - קצין משטרה).                                                     |                 |                 |
|(ב) קיבל קצין משטרה הודעה כאמור בסעיף קטן (א), רשאי הוא                              |                 |                 |
|להורות, בצו, על השבתת הרכב לתקופה שלהלן, ובן על החסנת הרכב                           |                 |                 |
|במקום שעליו יורה בצו -                                                               |                 |                 |
|(1) לתקופה של 30 ימים ממועד מתן הצו - כשמשקלו הכולל                                  |                 |                 |
|של הרכב עלה ב-0/0 15  עד 25% על המשקל הכולל המותר;                                   |                 |                 |
|(2) לתקופה של 60 ימים ממועד מתן הצו - כשמשקלו הכולל                                  |                 |                 |
|של הרכב עלה ביותר מ-25% על המשקל הכולל המותר.                                        |                 |                 |
|(ג) בעל הרכב ישא בהוצאות ההחסנה של הרכב לפי סעיף זה.                                 |                 |                 |
|(ד) הוכיח בעליו של רכב שהושבת בצו לפי סעיף זה, כי מי שנהג                            |                 |                 |
|ברכב פעל בניגוד להוראותיו, וכי הוא נקט את כל האמצעים הסבירים                         |                 |                 |
|למנוע נהיגה כאמור, רשאי קצין המשטרה שנתן את הצו לבטלו.                               |                 |                 |
|(ה) הוראות סעיף 48 יחולו על צו להשבתת רכב לפי סעיף זה כאילו                          |                 |                 |
|היה צו לפסילת אדם מהחזיק ברשיון נהיגה."                                              |                 |                 |

|דברי הסבר           |

|מוצע לקבוע מנגנון חדש בפקודת התעבורה,                      |
|ולאפשר השבתת רכב מסחרי בצו מנהלי, כאשר הרכב                |
|המסחרי הוביל מטען עודף בשיעור של 15% ויותר, מעל            |
|המשקל הכולל המותר לו. (סעיף קטן (א) המוצע). מטרת           |
|החוק המוצע להפחית את מספר תאונות הדרכים שבהן               |
|מעורבים כלי רכב מסחריים הנושאים מטען עודף וזאת             |
|؀ࠂࠒࠔࠖࠤלנוכח ריבוי תאונות הדרכים שבהן מעורבים כלי רכב       |
|אלה והתוצאות החמורות הנגרמות מהן.                          |
|מוצע, כי רכב כאמור יושבת על פי צו של קצין                  |
|משטרה בדרגה שאינה פחותה מדרגת מפקח, בדומה                  |
|לפסילת רשיון מנהלית, וכי השבתת הרכב תהיה                   |
|לתקופה של 30 ימים או 60 ימים, בהתאם לאחוז המטען            |
|העודף. עוד מוצע כי קצין המשטרה יהא רשאי להורות             |

|על החסנת רכב שהושבת כאמור ועל מקום החסנתו                      |
|בתקופת ההשבתה וכי הוצאות ההחסנה יוטלו על בעליו                 |
|של הרכב. (סעיפים קטנים (ב) ו-(ג) המוצעים).                     |
|כמו כן מוצע כי במקרים שבהם יוכיח בעל הרכב,                     |
|כי מי שנהג ברכב עם מטען עודף, פעל בניגוד                       |
|להוראותיו, וכי הוא נקט את כל האמצעים הסבירים                   |
|למנוע נהיגה כאמור, יבטל קצין המשטרה את השבתת                   |
|הרכב. (סעיף קטן (ד) המוצע).                                    |
|יחד עם זאת, מוצע כי בדומה לפסילת רשיון                         |
|מנהלית, תהיה אפשרות לפנות לבית המשפט המוסמך,                   |
|בבקשה לבטל את הצו להשבתת הרכב, וזאת בהתאם                      |
|להוראות סעיף 48 לפקודת התעבורה (סעיף קטן (ה)                   |
|המוצע).                                                        |
|חבר הכנסת אלי גולדשמידט                                        |
