|הצעת חוק שירות המדינה (גימלאות) (תיקון מס' 40) (עובדים חדשים),                                                 |
|התשנ"ז-1997                                                                                                    |

|תיקון סעיף ו     |1. בחוק שירות המדינה (גימלאות) [נוסח משולב], התש"ל-1970 1 (להלן - החוק                                        |
|                 |העיקרי), בסעיף ו -                                                                                            |
|                 |(1) אחרי ההגדרה ''הטבות פרישה" יבוא:                                                                          |
|                 |""היום הקובע" - היום שיקבע שר האוצר לפי הוראות סעיף 107א(ג)";                                                 |
|                 |(2) בהגדרה ""עובד המדינה" או "עובד"", אחרי "מי שנתמנה" יבוא "לפני היום                                        |
|                 |הקובע החל לגביו",                                                                                             |

|דברי הסבר                    |

|בחודש ספטמבר 1992 החליטה הממשלה לפעול                          |
|לשם הפסקת צבירת התחייבויות בפנסיה תקציבית לגבי                 |
|עובדי מדינה חדשים ובמקביל לאפשר להם להבטיח את                  |
|זכויותיהם הסוציאליות על ידי הצטרפות לתכניות                    |
|צוברות.                                                        |
|מדיניות זו נקבעה בשל חסרונותיה של שיטת                         |
|הפנסיה התקציבית, שאלה העיקריים שבהם:                           |

|(0 יצירת ההוצאה התקציבית בעת מימוש                            |
|זכויות הפנסיה ולא במהלך צבירת ההתחייבות מעוותת                |
|את התקציב ויוצרת התחייבות עתידית גדולה, ללא                   |
|ביטוי מתאים בתקציב השוטף;                                     |
|(2) כתוצאה מכך יש חשש שקבלת החלטות                            |
|ועריכת הסכמים (כגון: הסדרי פרישה מוקדמת, הענקת                |
|הטבות מוגדלות לפני הפרישה, ועוד) נעשים ללא                    |

|1 ס"ח התש''ל, עמ' 65; ה"ח התשנ''ו, עמ' 486.      |

|2. אחרי סעיף 071 לחוק העיקרי יבוא:                                                                      |הוספת סעיף 107א       |
|071א. (א) הוראות חוק זה לא יחולו על מי שהתמנה לפי חוק המינויים                              |-עובד חדש  |                      |
|החל ביום הקובע החל לגביו, למעט על עובד שירותי הבטחון בהגדרתו                                |           |                      |
|בסעיף 63א (להלן - עובד חדש);                                                                |           |                      |
|(ב) על אף הוראות סעיף קטן (א), עובד חדש יהיה מבוטח בפנסיית                                  |           |                      |
|זיקנה, נכות ושאירים בקופת גמל לקיצבה בהגדרתה בתקנות מס הכנסה                                |           |                      |
|(כללים לאישור ולניהול קופות גמל), התשכ"ד-1964 2 (להלן - קופת גמל),                          |           |                      |
|בתנאים שייקבעו בהסכם הקיבוצי או בחוזה העבודה החל עליו, לפי                                  |           |                      |
|הענין, ובלבד שלעובד תהיה הרשות לבחור את קופת הגמל שבה יבוטח,                                |           |                      |
|לפי ההסכם או החוזה כאמור; לא חל עליו הסכם או חוזה כאמור, או לא                              |           |                      |
|בחר העובד בקופת גמל מסוימת, יבוטח העובד בקופת הגמל שבה                                      |           |                      |
|מבוטחים רוב העובדים החדשים ובאותם תנאים.                                                    |           |                      |
|(ג) (ו) שר האוצר יקבע את היום הקובע בהודעה ברשומות                                          |           |                      |
|ובלבד שיום זה לא יהא לפני יום *                                                             |           |                      |
|(2) שר האוצר רשאי לקבוע ימים שונים לסוגי ؀ࠂࠎࠐࠔࠠࠢࠤࠬעובדים                                    |           |                      |
|שונים.                                                                                      |           |                      |
|(3) הוראות סעיף זה יחולו גם על עובדים שתנאי עבודתם הם,                                      |           |                      |
|על פי כל דין או הסכם קיבוצי, כתנאי עבודתם של עובדי                                          |           |                      |
|המדינה."                                                                                    |           |                      |

|דברי הסבר                 |

|התחשבות בשיקולים אמיתיים וללא בקרה תקציבית.                |
|מצד שני מוטלות הגבלות בלתי סבירות לגבי תגמול               |
|עובדים פעילים, עקב הצורך להתחשב בשיקולים                   |
|פנסיוניים;                                                 |
|(3) אי צבירת הכספים על ידי המעביד והעובד                   |
|מקטינה את החסכון במשק ואת פוטנציאל ההשקעות.                |
|חסרונותיה של שיטת הפנסיה התקציבית נדונו                    |
|רבות בדו"חות ביקורת ובהצעות לרפורמה במערכת                 |
|השכר הציבורית (ראה דו''ח מבקר המדינה מס' 40 וכן            |
|דו"ח ועדת זוסמן).                                          |
|בהתאם להחלטת הממשלה האמורה, ניהל                           |
|הממונה על השכר והסכמי עבודה במשרד האוצר משא                |
|ומתן על שינוי הסדרי הפנסיה במסגרת הסכמי השכר               |

|בשירות המדינה לשנים 1996-1993. במשא ומתן האמור                 |
|הושגה הסכמתם העקרונית של ההסתדרות הכללית                       |
|החדשה והאיגודים המקצועיים, להעברתם של עובדים                   |
|חדשים וארעיים לתכניות פנסיה צוברת.                             |
|על מנת לממש הסכמה עקרונית זו, ובעקבות                          |
|החלטת הממשלה האמורה, פורסמה בחודש פברואר                       |
|אשתקד הצעת חוק שירות המדינה (גימלאות) [נוסח                    |
|משולב] (תיקון מס' 39) (עובדים חדשים), התשנ"ו-1996              |
|(הצעת חוק, התשנ''ו, עמ' 486).                                  |
|החוק המוצע בזה חוזר בעיקריו על הצעת החוק                       |
|האמורה, ומוצע בו להנהיג את ההסדר הפנסיוני החרש                 |
|על כלל המגזרים שבהם חל כיום ההסדר של פנסיה                     |
|תקציבית, בכפוף להסכמי העבודה הקיבוציים והאחרים                 |
|שייחתמו בכל מגזר.                                              |

|2 ק''ת התשכ"ד, עמ' 1302.            |
|. טרם נקבע מועד.                    |
