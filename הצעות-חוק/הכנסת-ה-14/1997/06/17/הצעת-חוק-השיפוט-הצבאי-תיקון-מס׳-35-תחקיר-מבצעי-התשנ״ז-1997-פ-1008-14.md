|מתפרסמת בזה הצעת חוק של חברי הכנסת מטעם ועדת החוץ והבטחון של הכנסת:                                |

|ו. בחוק השיפוט הצבאי, התשט'ו-1955 1 (להלן - החוק העיקרי), בסופו יבוא:                                    |תיקון סעיף 558       |
|"לענין סעיף זה, ''משפט' - הליך המתקיים בפני בית משפט או בפני בית דין.''                                  |                     |
|2. אחרי סעיף 539 לחוק העיקרי יבוא:                                                                       |הוספת סעיף 539א      |
|539א. (א) לענין סעיף זה -                                                                |'קבילות תחקיר  |                     |
|(ו) ''תחקיר'' - בירור פנימי המבוצע בצבא ההגנה                                            |               |                     |
|לישראל, בהתאם לפקודות הצבא;                                                              |               |                     |
|(2) ''משפט" - כמשמעותו בסעיף 538.                                                        |               |                     |
|(ב) תוכן הדברים שהושמעו בתחקיר, פרוטוקול התחקיר, כל חומר                                 |               |                     |
|אחר שהוכן במהלכו, סיכומיו, ממצאיו ומסקנותיו (להלן - חומר התחקיר),                        |               |                     |
|לא יתקבלו כראיה במשפט, למעט במשפט פלילי בשל מסירת עדות שקר                               |               |                     |
|בתחקיר.                                                                                  |               |                     |
|(ג) לא יימסר חומר התחקיר אלא בהתאם לפקודות הצבא                                          |               |                     |
|ולגורמים שנקבעו בהן.''                                                                   |               |                     |

|דברי הסבר                  |

|בפסק הדין במשפט צאלים כ' העיר בית הדין                     |
|הצבאי כי אין הדעת סובלת כי לקחים אשר היה, אולי,            |
|בכוחם, למנוע אובדן חיים, לא הופקו בשל אי קיום              |
|תחקיר מבצעי -פיקודי של האירוע. הסיבה לכך, מציין            |
|בית הדין, היא אפשרות ההשפעה של תחקיר כזה על                |
|חקירה משפטית ואפשרות פגיעה בזכות השתיקה של                 |
|המעורבים.                                                  |
|הניסיון מלמד כי תחקירים משמשים לא פעם את                   |
|רשויות החקירה, ועדויות, כמו גם מסקנות התחקירים,            |
|מוגשות כראיה בבתי המשפט ובבתי הרין ועומדים                 |
|לחובתם של הנידונים. מצב זה יכול להרתיע את                  |
|המעורבים בתחקיר מלמסור עדות, ומקשה על ؀ࠂࠒࠔࠖࠤהגופים         |
|השונים להגיע לחקר האמת, לשפר ולתקן את הטעון                |
|תיקון. מתעורר, אם כן, הצורך לסייג את קבילותו של            |
|חומר שהוכן ונמסר במסגרתו של תחקיר צבאי, בבתי               |

|משפט ובבתי דין. מוצע להבהיר כי התחקיר הנו קודם             |
|כל כלי בידי רשויות הצבא. לפיכך, ככלל, לא יימסר תוכן        |
|הדברים שהושמעו בתחקיר, ממצאיו ומסקנותיו.                   |
|למען הסר ספק מוצע גם לתקן את סעיף 538 לחוק                 |
|השיפוט הצבאי, התשט'ו-1955, באופן שיבהיר כי                 |
|ההוראה בדבר אי קבילות דבר שהושמע בועדת חקירה               |
|כראיה במשפט, חלה על הליך המתקיים בפני בית                  |
|המשפט או בית דין בלבד.                                     |
|חברי הכנסת: עוזי לנדאו, אורי אור, רחבעמ                    |
|זאבי, יוסי שריד, יורי שטרן, בנימין בן-אליעזר,              |
|אהוד ברק, גדעון עזרא, דוד צוקר, פיני בדש,                  |
|חנן פורת, יהודה לנקרי, חיים דמון, עוזי ברעם,               |
|מיכאל איתן, שלמה בן-עמי, שאול יהלום,                       |
|מאיר שטרית                                                 |
