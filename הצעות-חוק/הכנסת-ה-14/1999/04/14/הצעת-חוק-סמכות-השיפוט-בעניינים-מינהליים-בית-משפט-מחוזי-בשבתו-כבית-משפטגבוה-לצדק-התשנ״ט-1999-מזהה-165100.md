|מטרה               |1. חוק זה מטרתו לשנות בהדרגה את סדרי השיפוט בענינים מינהליים, באופן שענינים                                      |
|                   |אלו יידונו בפני בית משפט מחוזי בשבתו כבית משפט גבוה לצדק כערכאה ראשונה, על ידי                                   |
|                   |שופטים של בית המשפט המחוזי שיוסמכו לענין חוק זה, ולפי סדרי דין מיוחדים שייקבעו,                                  |
|                   |למעט ענינים מינהליים בעלי חשיבות, רגישות או דחיפות מיוחדת אשר ימשיכו להידון                                      |
|                   |בפני בית המשפט העליון בשבתו כבית משפט גבוה לצדק כערכאה ראשונה.                                                   |
|הגדרות             |2. בחוק זה -                                                                                                     |
|                   |"ענינים מינהליים" - ענינים הנוגעים לסכסוכים שבין אדם לרשות;                                                      |
|                   |"רשות" - רשות מרשויות המדינה, רשות מקומית, וכן גופים ואנשים אחרים הממלאים                                        |
|                   |תפקידים ציבוריים על פי דין;                                                                                      |
