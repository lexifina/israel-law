|1. מטרתו של חוק זה לעודד את ההתנדבות בתחום הסיעוד והשיקום הביתי של חולים,                                          |מטרת החוק         |
|נכים וקשישים, לשם שיפור איכות חייהם, תוך חיסכון במשאבים מתקציב המדינה מחד                                          |                  |
|גיסא ושילוב תושבי ישראל בפעילות למען הציבור מאידך גיסא.                                                            |                  |
|פרק בי: פרשנות                                                                                                     |                  |
|2, בחוק זה -                                                                                                       |הגדרות            |
|"עמותה לסיעוד ולשיקום ביתי" או "העמותה" - עמותה כמשמעותה בחוק                                                      |                  |
|העמותות, התש"ם-1980 1, שאישר השר, הפועלת ברציפות במשך עשר שנים                                                     |                  |
|לפחות, בעיקר באמצעות מתנדבים, לצורך מתן שירותי סיעוד ושיקום ביתי,                                                  |                  |
|מפעילה לפחות 50,000 ימי התנדבות בשנה ב-20 ישובים לפחות-,                                                           |                  |
|"יום התנדבות" - יום שבו בוצעה פעולת התנדבות על ידי מתנדב, על פי הפניה                                              |                  |
|מוקדמת מאת העמותה;                                                                                                 |                  |
|"מתנדב" - מי שפעל בהתנדבות, שלא בשבר, לביצוע שירותי סיעוד ושיקום ביתי,                                             |                  |
|ובלבד ששמו, תעודת הזהות שלו וכתובתו רשומים בעמותה;                                                                 |                  |
|"שירותי סיעוד ושיקום ביתי" או "השירותים" - שירותים המיועדים לסייע לנזקקים                                          |                  |
|להם בביצוע פעולות יום-יום, לרבות השירותים המפורטים בתוספת;                                                         |                  |
|"השר" - שר הבריאות;                                                                                                |                  |
|"הפקודה" - פקודת מס הכנסה2;                                                                                        |                  |

|דברי הסבר                 |

|מטרתה של הצעת חוק זו היא לעודד את                |סעיף 1      |
|ההתנדבות בתחום הסיעוד והשיקום                    |            |
|הביתי של חולים, נכים וקשישים, ולאפשר להם להישאר              |
|בביתם, בחיק המשפחה ובסביבתם הטבעית, על אף                    |
|מוגבלותם הפיזית. מטרה זו חשובה לא רק לנזקקים                 |
|עצמם אלא לקהילה ולחברה בכללותה.                              |
|כיום פועלים כמה גופים המפעילים מתנדבים                       |
|למטרות האמורות והם עושים פעילות ברוכה החוסכת                 |
|סכומים נכבדים ביותר מתקציב המדינה, ולנוכח מצבם               |
|של בתי החולים ושל קופות החולים מן הראוי לעודד                |
|פעילות זו.                                                   |

|ארגון "יד שרה" למשל, מצליח לחסוך מדי שנה                           |
|למעלה מ-200 מיליון דולר למשק הישראלי, בעזרת                        |
|מערבת שירותים מקיפה הכוללת שירותי בית ובכלל זה                     |
|משדרי מצוקה, שירותי כביסה והשאלת ציור רפואי,                       |
|ושירותי קהילה ובכלל זה שירותי הסעות למוגבלי                        |
|תנועה, מרפאות שיניים גריאטריות ומרכזי יום לקשישים                  |
|ולמוגבלים. שירותים אלה, הניתנים בהיקף רחב ביותר,                   |
|ולבל נזקק, מהווים חלופה לאשפוז ממושך בבתי חולים                    |
|ובמוסדות סיעודיים שונים.                                           |
|מוצע להחיל את החוק רק על גופים בעלי               |סעיף 2          |
|יכולת מוכחת בתחום ההתנדבות כמפורט                                  |
|בסעיף.                                                             |
