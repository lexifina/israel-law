|7. (א) לכנסת יהיה יועץ משפטי.                                                                       |"יועץ משפטי                |
|(ב) היועץ המשפטי לכנסת -                                                                            |לכנסת ותפקידיו             |
|(1) יעניק ייעוץ משפטי לכנסת ולמוסדותיה בבל ענין הנוגע                                               |                           |
|לסמכויותיהם ולתפקידיהם;                                                                             |                           |
|(2) יסייע לחבר הכנסת בכל ענין הנוגע לכנסת והנובע                                                    |                           |
|מחברותו בה, לרבות בניסוח הצעות חוק ומסמכים אחרים                                                    |                           |
|הקשורים לפעולתו של חבר הכנסת במילוי תפקידיו בכנסת,                                                  |                           |

|ראש הכנסת;                                                                                          |                           |
|(3) ייעץ בכל ענין הנוגע להליכי החקיקה בכנסת;                                                        |                           |
|(4) ייצג את הכנסת בערכאות והוא רשאי, בהסכמת היועץ                                                   |                           |
|המשפטי לממשלה, להסתייע לשם כך בפרקליטות המדינה-,                                                    |                           |

|הוראות סעיף 2(1) ו-(2) לחוק בתי המשפט [נוסח משולב], התשמ"ד-,21984                                   |                           |

|דברי הסבר             |

|ההצעה באה להסדיר בחוק את מעמדו, את                             |
|תפקידיו ואת סמכויותיו של היועץ המשפטי לכנסת,                   |
|תפקיר אשר אינו מעוגן כיום בחיקוק כלשהו.                        |
|ההצעה קובעת את הכישורים הנדרשים למילוי                         |
|תפקיר זה, דרכי המינוי לתפקיד, תקופת הכהונה ודרכי               |

|תום הכהונה, והכל כדי להבטיח בחירה ראויה                        |
|ועצמאיות במילוי התפקיד.                                        |
|על פי ההצעה תוקם ועדת בחירה של שבעה                            |
|בראשות יושב ראש הכנסת והיא שתבחר את היועץ                      |
|המשפטי לכנסת לתקופת כהונה של 5 שנים עם אפשרות                  |
|לתקופת כהונה אחת נוספת.                                        |
