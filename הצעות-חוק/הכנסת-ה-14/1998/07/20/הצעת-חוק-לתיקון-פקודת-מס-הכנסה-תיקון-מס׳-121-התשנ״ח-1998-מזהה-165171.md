|הצעת חוק לתיקון פקודת מס הכנסה (תיקון מס 121), התשנ"ח-1998                                                      |                   |
|1. בפקודת מס הכנסה 1 (להלן - הפקודה), בסעיף 9, אחרי פסקה (2) יבוא:                                              |תיקון סעיף 9       |
|"(2א)(א) הכנסתו של ארגון מקצועי לרבות הכנסה מדמי חבר, ובלבד שלא                                                 |                   |
|הושגה מעסק שהוא עוסק בו, או מכל הכנסה מחבר בני אדם שבשליטתו,                                                    |                   |
|העוסק בעסק, לרבות מדיבידנד, מריבית או מהפרשי הצמדה;                                                             |                   |
|(ב) (1) על אף האמור בפסקת משנה (א), יתרת ההכנסה של הארגון                                                       |                   |
|המקצועי העולה על שיעור של 25% מהוצאותיו, לא תהיה פטורה                                                          |                   |
|ממס;                                                                                                            |                   |
|(2) סכום הוצאות העולה על סכום הכנסות בשנת מס מסוימת יראו                                                        |                   |
|כאילו היה סכום הוצאות שהוצא בשנת המס הבאה אחריה, כשהוא                                                          |                   |
|מתואם לפי שיעור עליית המדד בשנת המס הבאה כאמור;                                                                 |                   |
|(3) לענין זה -                                                                                                  |                   |
|"יתרת ההכנסה" - ההכנסות הפטורות לפי פסקת משנה (א) לאחר                                                          |                   |
|שהופחתו מהן ההוצאות שהוצאו בייצור אותן הכנסות;                                                                  |                   |
|"הוצאות" - הוצאות המותרות לניכוי, למעט פחת וכן הוצאות                                                           |                   |
|לרכישת נכס בר-פחת המשמש למטרות הארגון או ליצירת נכס                                                             |                   |
|כאמור;                                                                                                          |                   |
|"נכס בר-פחת" - כהגדרתו בסעיף 88 לרבות זכות במקרקעין,                                                            |                   |
|כמשמעותה בחוק מס שבח מקרקעין.                                                                                   |                   |
|(ג) בפסקה זו, "ארגון מקצועי" - חבר בני-אדם שאושר על ידי הנציב                                                   |                   |
|ושהתקיימו בו כל אלה:                                                                                            |                   |
|(א) חברים בו שבעים חברים לפחות-,                                                                                |                   |
|(ב) כל מטרתו קידום ענינים מקצועיים משותפים, השתלמות                                                             |                   |
|מקצועית או ייצוג ציבורי של ציבור בעלי משלח יד מסוים או של                                                       |                   |
|* עוסקים בענף או במגזר כלכלי מסוים וכל נכסיו והכנסותיו משמשים                                                   |                   |
|לקידום מטרות אלה;                                                                                               |                   |
|(ג) פעילותו אינה לשם הגדלת רווחיהם של חברים מסוימים בו;                                                         |                   |
|(ד) הוא מגיש דו"ח שנתי לגבי נכסיו, הכנסותיו והוצאותיו, להנחת                                                    |                   |
|דעתו של פקיד השומה על פי תקנות שהתקין שר האוצר;".                                                               |                   |

|דברי הסבר              |

|מוצע לקבוע פטור ממס הכנסה לגבי                    |סעיף 1       |
|הכנסתו של ארגון המייצג בעלי מקצוע                 |             |
|מסוים או בעלי משלח יד מסוים (להלן - ארגון                       |
|מקצועי).                                                        |
|הפטור המוצע יינתן לארגון המקצועי בתנאי                          |
|שפעילותו אינה לשם הגדלה במישרין של רווחי החברים                 |
|בו ורק לגבי הכנסתו שלא הושגה מעסק.                              |

ההצעה לפטור הכנסות מסוג זה נובעת מהעובדה
שהן לא הושגו באמצעות פעילות שכוונתה השגת
רווחים, אלא מפעילות שנועדה לקדם עניינים ؀ࠂࠎࠐࠔࠠࠢࠤࠬמקצועיים
משותפים של קבוצת אגשים בעלי מקצוע מסוים או
בעלי משלח יד מסוים, פעילות שיש לה חשיבות
ציבורית. מוצע לקבוע מגבלת תקרה להכנסה כך שיתרת
ההכנסה של הארגון המקצועי העולה על שיעור של
25% מהוצאותיו לא תהיה פטורה. קביעה זו אמורה
להוות תמריץ בידי הארגון להשתמש בעודפי הכנסותיו
למטרות הארגון.
