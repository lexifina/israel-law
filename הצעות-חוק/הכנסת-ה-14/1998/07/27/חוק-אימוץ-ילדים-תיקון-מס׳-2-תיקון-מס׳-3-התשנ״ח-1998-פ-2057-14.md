|הצעת חוק אימוץ ילדים (תיקון מס' 2) (תיקון מס' 4), התשנ"ח-1998*                                                |

|1. בחוק אימוץ ילדים (תיקון מס' 2), התשנ"ו-1996 1, אחרי סעיף ו1(ב) יבוא:                                        |תיקון סעיף וו        |
|"(ג) על אף הוראות סעיף קטן (ב), אישרה רשות מוסמכת של מדינת חוץ למבקש                                           |                     |
|מסירת ילד לאימוץ לפני תום התקופה האמורה בסעיף קטן (ב), והילד נמסר למבקש                                        |                     |
|לפני תום תשעה חודשים מיום תחילתם של הסעיפים המנויים בסעיף קטן (או),                                            |                     |
|רשאית הרשות המרכזית לאשר את אימוץ הילד בידי המבקש אם מצאה כי התקיימו                                           |                     |
|כל אלה -                                                                                                       |                     |
|(ו) הליכי האימוץ החלו בפועל במדינת החוץ לפני יום ג' בטבת התשנ"ח                                                |                     |
|(1 בינואר 1998);                                                                                               |                     |
|(2) המבקש נמצא כשיר ומתאים לאמץ ילד באימוץ בין-ארצי לאחר עריכת                                                 |                     |
|בדיקה ובירור כאמור בסעיף 28ח.                                                                                  |                     |
|(ד) הרשות המרכזית רשאית לקבוע תנאים לאישור האימוץ לפי סעיף קטן (ג),                                            |                     |
|לרבות מסירת מידע ומסמכים הנוגעים לאימוץ ולנסיבותיו."                                                           |                     |

|דברי הסבר                  |

|מטרתו של חוק אימוץ ילדים (תיקון מס' 2),                        |
|התשנ"ו-1996 , היא להעביר את כל נושא האימוץ הבין-               |
|ארצי לטיפולן של עמותות שיאושרו בידי שר העבודה                  |
|והרווחה ושר המשפטים; עד היום לא אישרו השרים ולו                |
|גם ؀ࠂࠔࠖ࠘ࠦעמותה אחת.                                            |
|אי אישור עמותות יוצר מצב בלתי נסבל שבו                         |
|אנשים אשר החלו בהליכי אימוץ בין-ארצי או מבקשים                 |

|להתחיל בהליכים אלה, אינם יכולים לעשות זאת לפי                    |
|הדין הקודם ואינם יכולים לעשות זאת לפי הדין                       |
|הנוהג.                                                           |
|מוצע לדחות את תחילת החוק עד לאחר שיאושרו                         |
|שתי עמותות לפחות, ולקבוע הוראות מעבר במוצע                       |
|בסעיף ו להצעת חוק זו שתאפשר את פתרונה של בעיה                    |
|אנושית וחברתית חמורה ביותר שנתעוררה בתקופה זו.                   |
