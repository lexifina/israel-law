|1. בפקודת העיריות 1, אחרי סעיף 149ד יבוא:                                                                     |הוספת סעיף 149ה         |
|                                                                                                              |לפקודת העיריות          |
|491ה. (א) המועצה תבחר ועדה לבטיחות בדרכים שתפקידה ליזום                                    |"ועדת בטיחות      |                        |
|ולתכנן פעילות בתחומים הנוגעים לבטיחות בדרכים; הוועדה תגיש                                  |בדרכים            |                        |
|לאישור המועצה את תכניותיה ותפקח על ביצוע התכניות המאושרות. .                               |                  |                        |
|(ב) חברי הוועדה יהיו -                                                                     |                  |                        |
|(ו) ראש העיריה או חבר מועצה אחר שנבחר מבין חבריה,                                          |                  |                        |
|והוא יהיה היושב ראש;                                                                       |                  |                        |
|(2) מהנדס העיר ומנהל אגף החינוך, או מי שכל אחד מהם                                         |                  |                        |
|הסמיכו, מבין עובדי העיריה, לענין זה;                                                       |                  |                        |
|(3) חברים אחרים שתבחר המועצה, ובמספד שתקבע, מבין                                           |                  |                        |
|חברי המועצה או מבין בעלי תפקידים אחרים בעיריה;                                             |                  |                        |
|(4) נציג שד התחבורה, שימנה שר התחבורה;                                                     |                  |                        |
|(5) 1ציגי גופים העוסקים בבטיחות בדרכים, כפי שתחליט                                         |                  |                        |
|המועצה;                                                                                    |                  |                        |
|(6) נציג השר לבטחון הפנים שימנה מפקד המרחב שבתחום                                          |                  |                        |
|סמכותו נמצאת העיר."                                                                        |                  |                        |

|דברי הסבר                 |

|תאונות הדרכים בתחום העירוני מהוות ביום ב-                     |
|80% מכלל תאונות הדרכים בישראל.                                |
|במספר לא קטן של עיריות קיים מטה בטיחות                        |
|הפועל לקידום הבטיחות בדרכים בתחומי אותן עיריות.               |
|מטות אלה פועלים בהתנדבות ؀ࠂࠒࠔࠖࠤועוסקים בהם בנושאים            |
|שונים בתחום הבטיחות בדרכים, כגון: חינוך, הקמה                 |
|ואחזקה של תשתית בטיחותית, ותיאום פעולות                       |

|להגברת -הבטיחות בדרכים עם הרשות הלאומית                           |
|לבטיחות בדרכים שבמשרד התחבורה.                                    |
|מוצע לעגן את הנושא בחקיקה ולקבוע כי בכל                           |
|עיריה תוקם ועדה לבטיחות בדרכים באחת מהועדות                       |
|הקבועות שעיריה -מקימה.                                            |
|בן מוצע לקבוע בחוק את הרבבה ואת סמכויותיה                         |
|של הוועדה.                                                        |

|דיני מדינת ישראל, נוסח חדש 8, עמ' 197; התשנ"ח, עמ' 109; ה''ח התשנ''ח, עמ' 196.             |
