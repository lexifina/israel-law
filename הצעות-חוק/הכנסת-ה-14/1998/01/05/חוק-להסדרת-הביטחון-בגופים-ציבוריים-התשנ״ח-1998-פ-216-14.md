|הצעת חוק להסדרת הבטחון בגופים ציבוריים, התשנ"ח-1998*                                           |

|הגדרות                |1. בחוק זה -                                                                                                        |
|                      |"מוסד" - מכון, גוף, מפעל או ארגון הנותנים שירות בעל אופי ציבורי או פרטי;                                            |
|                      |"קצין בטחון מוסדי" - מי שעמד בתנאי ההכשרה המפורטים בחוק זה;                                                         |
|                      |"איש בטחון מוסדי" - מי שעמד בתנאי ההכשרה המפורטים בחוק זה ומועסק במחלקת                                             |
|                      |הבטחון במוסד;                                                                                                       |
|                      |"ועדה בוחנת" - ועדת הרישוי כמשמעותה בסעיף 5 בתפקידה כעורכת הבחינות על פי חוק                                        |
|                      |זה, המפקחת עליהן והבודקת אותן.                                                                                      |
|ייחוד העיסוק          |2. לא יעסוק אדם כממונה על בטחון במוסד שתפקידו אבטחת המוסד, עובדיו רכושו                                             |
|                      |והמידע העסקי המצוי בו, אלא אם כן הוא קצין בטחון מוסדי לפי הוראות חוק זה.                                            |

|* הצעת חוק מס' פ/216; הועברה לוועדה ביום כ''ו באדר א' התשנ'ז (5 במרס 1997).               |

|5. אדם כשיר להיות קצין בטחון מוסדי אם נתקיימו בו כל אלה:                                                                 |כשירות למקצוע           |
|(1) הוא אזרח ישראלי או תושב ישראל;                                                                                       |                        |
|(2) מלאו לו 23 שנים;                                                                                                     |                        |
|(3) הוא בוגר קורס פיקודי בצבא הגנה לישראל או במערכת הבטחון;                                                              |                        |
|(4) הוא עבר הכשרה מקצועית בתחום הבטחון וקיבל הכשרתו במוסד מוכר;                                                          |                        |
|(5) הוא עבר תקופת אימון במחלקת בטחון, בתקופה ולפי סדרים שייקבעו                                                          |                        |
|בתקנות;                                                                                                                  |                        |
|(6) הוא לא הורשע בעבירה שמפאת חומרתה או נסיבותיה אין הוא ראוי לעסוק                                                      |                        |
|כקצין בטחון מוסדי.                                                                                                       |                        |
|(7) הוא עמד בבחינות מקצועיות שערכה הועדה הבוחנת שנושאיהן וסדריהן                                                         |                        |
|נקבעו בתקנות.                                                                                                            |                        |
|4. אלה בעלי הכשרה מקצועית לעניין סעיף 2(4):                                                                              |הכשרה מקצועית           |
|(ו) אדם שכיהן כאיש בטחון מוסדי במשך 3 שנים ויותר;                                                                        |                        |
|(2) בעל מקצוע המוכר על-ידי ועדת הרישוי, ואשר רכש נסיון של 5 שנים באותו                                                   |                        |
|מקצוע. /                                                                                                                 |                        |
|5. לשם מתן הברה במקצועות המקנים הכשרה לעסוק כקצין בטחון מוסדי ימנה השר                                                   |ועדה הרישוי             |
|לבטחון הפנים ועדה בת 5 חברים (להלן - ועדת הרישוי) ובהם לפחות:                                                            |                        |
|(ו) קצין משטרה שדרגתו ניצב ומעלה והוא יהיה היושב ראש;                                                                    |                        |
|(2) נציג הארגון היציג של קציני הבטחון המוסדיים;                                                                          |                        |
|(3) נציג משרד הפנים.                                                                                                     |                        |
|6. תפקידי ועדת הרישוי הם:                                                                                                |תפקידי ועדת             |
|(ו) לבחון כל פניה של מועמד לתפקיד קצין בטחון מוסדי ולקבוע אם להכיר                                                       |הרישוי                  |
|במקצועו כמקצוע שהקנה הכשרה מקצועית המאפשרת עיסוק כקצין בטחון                                                             |                        |
|מוסדי;                                                                                                                   |                        |
|(2) לבדוק את ؀ࠂࠈࠊࠎ࠘ࠚࠞࠢࠤעברו הפלילי של כל מועמד על פי נתוני משטרת ישראל ולקבוע האם                                        |                        |
|הוא מסכן את בטחון הציבור;                                                                                                |                        |
|(3) לכהן בועדה בוחנת;                                                                                                    |                        |
|(4) למלא את כל התפקידים המוטלים עליה לפי חוק זה.                                                                         |                        |
|7. (א) מועמד הרוצה לעבור אימון לתפקיד קצין בטחון מוסדי, כאמור בסעיף 2(5) יגיש                                            |אימון                   |
|בקשה בכתב לוועדת הרישוי.                                                                                                 |                        |

|דברי הסבר              |

|הצעת החוק להסדרת הבטחון בגופים ציבוריים,                       |
|התשנ"ח-1998, נועדה לתת מענה למצב שבו אחד                       |
|התחומים החשובים הנוגעים לפעילות יומיומית של                    |
|אזרחי המדינה פרוץ ואינו מוסדר בחקיקה.                          |

|הצעת החוק באה לקבוע אמות מידה להכשרתם                            |
|המתאימה ולהעסקתם של קציני בטחון מוסדיים                          |
|שיופקדו על בטחונם של עובדי המוסדות, על אבטחת                     |
|הרכוש, הציוד והכספים, והמידע האישי והכלכלי.                      |
