|2. אחרי סעיף 19 לפקודה יבוא:                                                                                   |הוספת סעיף 19א       |
|19א. (א) מצא רופא מחוזי כי קיימת סכנה מיידית להתפשטות מחלה                                |"מניעת התפשטות      |                     |
|מידבקת במקום כמשמעותו בסעיף 53(טו) (בסעיף זה - מוסד), בשל תנאי                            |מחלות               |                     |
|התברואה בו כאמור באותו סעיף, או כי מחלה מידבקת פשטה במוסד                                 |                    |                     |
|כאמור, או כי לא מכבר היתה קיימת בו מחלה מידבקת, רשאי הוא להורות                           |                    |                     |
|לבעל המוסד, למנהלו או למחזיק בו (להלן - בעל המוסד), על נקיטת                              |                    |                     |
|האמצעים הדרושים למניעת התפשטות המחלה או הישנותה, לרבות                                    |                    |                     |
|סגירת המוסד או חלק ממנו, לתקופה שיקבע.                                                    |                    |                     |
|(ב) לא יתן רופא מחוזי הוראה כאמור בסעיף קטן (א) אלא לאחר                                  |                    |                     |
|שנתן לבעל המוסד הזדמנות להשמיע את טענותיו; ואולם אם מצא הרופא                             |                    |                     |
|המחוזי בי השהיית מתן ההוראה עלולה לסכן את בריאותם של השוהים                               |                    |                     |
|או של המבקרים במוסד, רשאי הוא לתת לאלתר הוראה כאמור, ובלבד                                |                    |                     |
|שיתן לבעל המוסד הזדמנות להשמיע את טענותיו בהזדמנות הראשונה                                |                    |                     |
|לאחר מכן.                                                                                 |                    |                     |
|(ג) בעל המוסד רשאי, בתוך שבעה ימים מהיום שבו קיבל את                                      |                    |                     |
|ההוראה כאמור בסעיף קטן (א), לערור עליה לפני המנהל; אין בהגשת ערר                          |                    |                     |
|לפי סעיף קטן זה כדי לעכב את ביצוע ההוראה.                                                 |                    |                     |
|(ד) הוראת סגירה של מעון המשמש מקום מגורים לחסרי ישע                                       |                    |                     |
|תינתן בתיאום עם פקיד הסעד הראשי הנוגע בדבר; מצא רופא מחוזי בי                             |                    |                     |
|השהיית מתן הוראה כאמור עלולה לסכן את בריאותם של השוהים                                    |                    |                     |
|במוסד, יתן הוראת סגירה לאלתר וימסור על בך הודעה לפקיד הסעד                                |                    |                     |
|הראשי הנוגע בדבר; העתק הודעה לפי סעיף קטן זה יימסר למנהל הכללי                            |                    |                     |
|של משרד העבודה והרווחה.                                                                   |                    |                     |
