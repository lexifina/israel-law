|מתפרסמת בזה הצעת חוק של חברי הכנסת מטעם ועדת הכלכלה:                                  |

|הצעת חוק מלנהל מקרקעי ישראל (תיקון מס' 2) (מכרזים להענקת זכויות                                                   |
|במקרקעין לבניה ולמגורים), התשנ"ח-1998* .                                                                          |

|1. בחוק מינהל מקרקעי ישראל, התש"ך-1960 1, אחרי סעיף 4יד יבוא:                                                   |הוספת סעיף 4טו        |
|4טו. (א) במכרז להענקת זכויות במקרקעין המיועדים לבניה למגורים,                               |"מכרז להענקת       |                      |
|לא יפרסם המינהל הערכה או קביעה לגבי שווי המקרקעין (בסעיף זה -                               |זכויות במקרקעין    |                      |
|הערכת השווי).                                                                               |לבניה למגורים      |                      |
|(ב) לא יבטל המינהל מכרז כאמור בסעיף קטן (א), בשל כך                                         |                   |                      |
|שההפרש בין ההצעה הגבוהה ביותר שהוגשה לבין הערכת השווי היה                                   |                   |                      |
|נמוך מ-25%.                                                                                 |                   |                      |
|(ג) השה באישור ועדת הכלכלה של הכנסת, רשאי לשנות את                                          |                   |                      |
|האחוז הנקוב בסעיף קטן (ב).                                                                  |                   |                      |
|(ד) הוראות סעיף זה יחולו על מקרקעין של המדינה בלבד."                                        |                   |                      |

|דברי הסבר               |

|פסילת מכרזים להענקת זכויות במקרקעין                              |
|המיוערים למגורים, כאשר קיים פער בין הערכה או                     |
|קביעה של שמאי מטעם המינהל לגבי שווי המקרקעין,                    |
|לבין ההצעה הגבוהה ביותר שהוגשה במכרז, גורמת                      |
|לכך, שמחירי הקרקעות והדיור נשארים ברמה גבוהה                     |
|ולא ניתן להוזילם. תוצאה זו היא בלתי סבירה, בעיקר                 |
|בהתחשב בכך, שהמינהל הוא הבעלים, או המנהל, של                     |
|כ-93% ؀ࠂࠔࠖ࠘ࠦמהמקרקעין במדינה, ולפיכך הוא משמש                    |
|למעשה כמונופול בתחום הקרקעות.                                    |
|בהתחשב במדיניות השואפת להגדלת היצע                               |
|הקרקעות והוזלת מחיר הדיור, מוצע לקבוע בחוק,                      |

|שהמינהל לא יפרסם, עם המכרז, גם את הערכת השווי                   |
|שבידיו, וזאת כדי לאפשר לשוק לקבוע את המחירים                    |
|בלא שתהיה הטיה שלהם בהתאם להערכת השווי. כן                      |
|מוצע לקבוע שהמינהל לא יהיה רשאי לפסול מכרז                      |
|כאמור, כאשר הפער בין הערכת השווי של המינהל לבין                 |
|ההצעה הגבוהה ביותר שהוגשה במכרז, נמוך מ-25.                     |

|חברי הכנסת: אמנון רובינשטיין, פיני בדש,               |
|בנימין בן אליעזר, אופיר פינס-פז, יורי                 |
|שטרן, סילבן שלום, מיכאל נודלמן                        |
