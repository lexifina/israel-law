|מתפרסמת בזה הצעת חוק של חברי הכנסת מטעם ועדת החינוך והתרבות של הכנסת:                                                                        |
|הצעת חוק הקולנוע, התשנ"ט-1998*                                                                                                               |
|1. בחוק זה -                                                                                                          |הגדרות               |
|"סרט" - יצירה אורקולית, המורכבת מסדרה של תמונות נעות, בליווי פס-קול או בלעדיו,                                        |                     |
|שניתן להקרינה על מרקע, לרבות מרקע טלוויזיה, וליצור עותקים ממנה;                                                       |                     |
|"סרט ישראלי" - סרט שהוכר על פי כללים שנקבעו לפי סעיף 13;                                                              |                     |
|"קולנוע" - עשיית סרט, לרבות כל פעולה לגבי סרט או הקשורה בו;                                                           |                     |
|"חוק יסודות התקציב" - חוק יסודות התקציב, התשמ"ה-11985;                                                                |                     |
|?'השר" - שר החינוך התרבות והספורט.                                                                                    |                     |
|2. (א) השר ימנה מועצה לקולנוע (להלן - המועצה).                                                                        |מינוי מועצה          |
|(ב) המועצה תפעל לשם עידוד ותמיכה בקולנוע הישראלי תוך הבטחת חופש                                                       |לקולנוע ומטרותיה     |
|היצירה ומהן ביטוי למגוון התרבותי של החברה בישראל, להשקפות השונות הרווחות בה                                           |                     |
|ולערכיה.                                                                                                              |                     |
|3. אלה תפקידי המועצה -                                                                                                |הפקיד- המועצה        |
|(ו) לייעץ לשר בכל נושא הנוגע למדיניות בתחום הקולנוע ובכל ענין הנוגע                                                   |                     |
|לביצוע חוק זה;                                                                                                        |                     |
|(2) לייעץ לממונה על סעיף תקציב בהגדרתו בסעיף ו לחוק יסודות התקציב                                                     |                     |
|(להלן - הממונה), לענין קביעת מבחנים לתמיכה במוסדות ציבור כאמור בסעיף 3א                                               |                     |
|לחוק יסודות התקציב, לשם המטרות הבאות:                                                                                 |                     |
|(א) קידום ועידוד יצירה, הפקה והפצה של סרטים ישראליים, לרבות דרמות                                                     |                     |
|וסרטי תעודה;                                                                                                          |                     |
|(ב) עידוד שיתוף פעולה בין-לאומי בתחום הקולנוע;                                                                        |                     |

|דברי הסבר                   |

|סרטי הקולנוע משתייכים לתחום התרבות                              |
|הפופולרי ביותר בעולם המודרני והם בעלי משקל                      |
|בגיבוש אופיה התרבותי של כל חברה מודרנית בעשרות                  |
|השנים האחרונות. בגלל היקפו וחשיבותו של תחום זה                  |
|חייבת המדינה להתייחס להיבט התרבותי של פעילותו                   |
|ולהיבט התעשייתי. החוק המוצע הוא נסיון להתאים את                 |
|החקיקה למציאות זו.                                              |
|מוצע לפתח כיוונים, מגמות והתחייבויות חדשות                      |
|בהתפתחות הקולנוע הישראלי, תוך התחייבות                          |

|להשתתפות דמוקרטית ורב תחומית של במאים,                             |
|תסריטאים, מפיקים ומעורבים אחרים בעשיית הקולנוע                     |
|המקומי, ללא חשש לאבדן זהות תרבותית ישראלית.                        |
|כן מוצע להקים מועצה לעידור הקולנוע הישראלי,                        |
|שתייעץ בבל תחום הנוגע לקולנוע.                                     |
|תחום הקולנוע מתוקצב כיום באמצעות משרד                              |
|החינוך התרבות והספורט בסכום של כ-20 מיליון שקלים                   |
|חדשים; החוק המוצע יביא להעלאת התקציב לתחום                         |
|הקולנוע בשיעור ניכר.                                               |
