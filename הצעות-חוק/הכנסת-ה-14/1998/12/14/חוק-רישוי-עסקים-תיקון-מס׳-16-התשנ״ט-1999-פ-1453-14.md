|מתפרסמת בזה הצעת חוק של חבר הכנסת מטעם ועדת החוקה חוק ומשפט של הכנסת:                                        |

|הצעת חוק רישוי עסקים (תיקון מס' 16) (עסק של אבזרי מין),                                         |
|התשנ"ט-1998*                                                                                    |

|ו. בחוק רישוי עסקים, התשכ"ח- 1968 1,  אחרי סעיף 2ד יבוא:                                                         |הוספת סעיף 2ה      |
|2ה. (א) בעסק של אבזרי מין, תהא רשות הרישוי שלו לפי חוק זה,                                      |"עסק של         |                   |
|רשאית להשתמש בסמכותה, לשם הגנה על שלומם של קטינים ומניעת                                        |אבזרי מין       |                   |
|פגיעה ממשית בסדר הציבורי, גם לענינים אלה:                                                       |                |                   |
|(ו) מניעת רשיונות לפתיחת עסק של אבזרי מין במקום שיש                                             |                |                   |
|בו משום פגיעה ממשית בקטינים או בדיירי המקום;                                                    |                |                   |
|(2) איסור כניסה לעסק האמור לקטינים מתחת לגיל 17;                                                |                |                   |
|(3) הגבלת צורת הפרסומות לעסק האמור בחזית הפונה                                                  |                |                   |
|לרשות הרבים.                                                                                    |                |                   |
|(ב) לענין סעיף זר -                                                                             |                |                   |
|"אבזר מין'' - מכשיר המשמש לגירוי או לסיפוק מיני, למעט מכשיר                                     |                |                   |
|כאמור הנמכר בבית מרקחת;                                                                         |                |                   |
|"עסק של אבזרי מין" - לרבות כל אחר מאלה:                                                         |                |                   |
|(ו) עסק למכירה או להשכרה של חומר שיש בו כדי לגרות יצר                                           |                |                   |
|מיני (חומר פורנוגרפי), ובלבד שעיסוקו העיקרי הוא אבזרי                                           |                |                   |
|מין;                                                                                            |                |                   |
|(2) עסק שמאפשר הצצה על ארם העושה מעשה מיני או                                                   |                |                   |
|הנותן שיעשו בו מעשה כאמור."                                                                     |                |                   |

|דברי הסבר             |

|עסקים המוכרים אבזרי מין מהווים מקור משיכה                     |
|לקטינים. מכיוון שאין כל ؀ࠂࠒࠔࠖࠤבקרה חינוכית ופסיכולוגית על     |
|החומר שיש בחנויות אלה, עלולים האבזרים לגרום                   |
|לעיוותים ולנזקים נפשיים וגופניים, ויש בהם משום                |
|פגיעה בציבורים רחבים ובצביון האזור.                           |
|עד עתה לא קבע המחוקק חובת רישוי לעסקים                        |
|אלו, כשם שעשה לגבי מספרות, מכוני כושר, אטליזים                |
|ועסקים רבים אחרים.                                            |

|רשות מקומית שברצונה להגביל פתיחת עסקים                         |
|אלה סמוך למוסדות חינוך, או במקומות שפוגעים                     |
|בדיירים, אינה מסוגלת לעשות זאת.                                |
|השופט אלון ביקש בפס"ד בבגי'צ 146/88 בני קורן נ'                |
|עיריית רחובות (מב(4) עמ' 72) "שמן הראוי כי יבוא תיקון          |
|מתאים לחוק רישוי העסקים בדומה לתיקון שהתקבל                    |
|בשנת 1983 לענין משחקי הימור גם לענין מסוג זה"                  |
|(הכוונה לעסקים למכירת אבזרי מין).                              |
|על בן מוצע לקבוע זאת בחוק.                                     |
|להצעת חוק זו לא צפויות עלויות.                                 |
|חבר הכנסת חנן פורת                                             |
