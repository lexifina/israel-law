|מתפרסמת בזה הצעת חוק של חבר הכנסת מטעם ועדת החוץ והבטחון של הכנסת:                                       |

|הצעת חוק שירות בטחון (תיקון מס' 8) (מתן טיפול רפואי לחייל שנמצא                                               |
|בלתי בשר לשירות), התשנ"ח-1998*                                                                                |

|1. בחוק שירות בטחון [נוסח משולב], התשמ"ו- 1986 1, אחרי סעיף 17 יבוא:                                         |הוספת סעיף 17א        |
|17א. (א) חייל בשירות סדיר אשר נמצא בלתי כשר לשירות או בלתי                                |"התנדבות לצורך     |                      |
|כשר ארעית לשירות, יראו אותו כמי שהתנדב להמשך שירות סדיר, למשך                             |קבלת טיפול         |                      |
|כל תקופת היותו בלתי כשר כאמור, או עד לתום 180 ימים מיום שנמצא                             |רפואי              |                      |
|בלתי כשר כאמור, לפי המוקדם מביניהם, וזאת לצורך קבלת טיפול רפואי                           |                   |                      |
|בלבד, אלא אם כן הודיע החייל בכתב, במהלך התקופה האמורה, כי הוא                             |                   |                      |
|מבקש שלא להתנדב.                                                                          |                   |                      |
|(ב) חייל שנמצא בלתי כשר לשירות, כאמור בסעיף קטן (א), יקבל                                 |                   |                      |
|הסבר על זכותו שלא להתנדב בהתאם להוראות סעיף זה."                                          |                   |                      |

|דברי הסבר                 |

|לפי המצב החוקי הקיים היום חיילים שנמצאו                          |
|בלתי כשרים מבחינה רפואית לשירות בטחון, בין ארעית                 |
|ובין לצמיתות, לפי חוק שירות בטחון [נוסח משולב],                  |
|התשמ"ו-1986, משוחררים משירותם הצבאי, דבר                         |
|המעורר אצלם ואצל בני משפחותיהם תחושה קשה,                        |
|באילו בעשותו כך מסיר צה"ל מעצמו את האחריות                       |
|כלפיהם.                                                          |

|؀ࠂࠔࠖ࠘ࠦמוצע על כן מטעמים חברתיים, מוסריים וערכיים,              |
|ועל מנת להקל על החייל ועל משפחתו את המעבר                      |
|לטיפול רפואי אזרחי, לראות בחייל, כמי שמשרת בצה"ל               |
|בהתנדבות, לתקופה שלא תעלה על  180 ימים. הדבר                   |
|יאפשר לחייל להמשיך את הטיפול הרפואי במסגרת                     |
|הצבא, אם הוא מעוניין בכך.                                      |
