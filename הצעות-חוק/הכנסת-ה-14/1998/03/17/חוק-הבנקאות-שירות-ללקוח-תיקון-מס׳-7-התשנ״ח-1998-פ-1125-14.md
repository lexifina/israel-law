|מתפרסמת בזה הצעת חוק של חבר הכנסת מטעם ועדת הכלכלה של הכנסת:                                    |

|הצעת חוק הבנקאות (שירות ללקוח) (תיקון מס' 7) (מסירת מידע על עמלות),                                            |
|התשנ"ח-1998*                                                                                                   |

|1. בחוק הבנקאות (שירות ללקוח), התשמ"א-1981 1, אחרי סעיף 5 יבוא:                                                |הוספת סעיף 5א       |
|5א. (א) מבלי לגרוע מהוראות סעיף 5, תאגיד בנקאי ימסור ללקוחותיו                              |"מסירת מידע       |                    |
|מידע בכתב על סכומי העמלות או על שיעור העמלות שהוא גובה בשל                                  |על עמלות          |                    |
|שירות שנקבע בכללים לפי סעיף 5.                                                              |                  |                    |
|(ב) המידע באמור בסעיף קטן (א) יוצג או יימסר כלהלן:                                          |                  |                    |
|(ו) אם המידע אינו מתייחס ללקוח מסוים - במקום בולט לעין                                      |                  |                    |
|בכל סניפיו, של התאגיד הבנקאי וכן, אם התאגיד הבנקאי                                          |                  |                    |
|מאפשר ללקוחותיו לקבל הודעות באמצעות מחשב - גם                                               |                  |                    |
|באמצעות המחשב;                                                                              |                  |                    |
|(2) אם המידע הוא מידע מרוכז לגבי כל סכומי העמלות                                            |                  |                    |
|שנגבו מלקוח מסוים במהלך רבעון - על ידי משלוח הודעה                                          |                  |                    |
|ללקוח בתום כל רבעון; ואולם, אם הלקוח קיבל את המידע                                          |                  |                    |
|האמור בפסקה זו באמצעות מחשב, יהיה התאגיד הבנקאי פטור                                        |                  |                    |
|ממשלוח ההודעה ללקוח."                                                                       |                  |                    |

|דברי הסבר                 |

|סקרים שנערכו הוכיחו, כי לרוב לקוחות הבנקים                      |
|אץ מידע בדבר העמלות שהם אמורים לשלם עבור                        |
|פעולות בנקאיות שונות.                                           |
|יתרה מכך לפי המצב החוקי כיום אין בידי                           |
|؀ࠂࠔࠖ࠘ࠦהלקוחות בלי ברור ונוח, כדי לקבל מידע מרוכז בדבר סך        |
|בל העמלות שנגבו מהם בפועל.                                      |

|מוצע לקבוע בחוק הבנקאות (שירות ללקוח),                           |
|התשמ"א-1981, את חובתו של תאגיד בנקאי למסור                       |
|ללקוחותיו מידע על העמלות שהוא גובה, לרבות החובה                  |
|לדאוג לכך, שלקוח יקבל בפועל, בתום כל רבעון, מידע                 |
|מרוכז על העמלות שנגבו ממנו במהלך אותו רבעון.                     |

|חבר הכנסת אברהם יחזקאל                |
