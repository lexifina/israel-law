|מתפרסמת בזה הצעת חוק של חבר הכנסת מטעם ועדת הכלכלה של הכנסת:                                       |

|הצעת חוק הגנת הצרכן (תיקון מס' 6) (שיווק ישיר), התשנ"ח-1998                                            |

|1. בחוק הגנת הצרכן, התשמ"א-1981 1 (להלן - החוק העיקרי), בסעיף 8, בסופו יבוא:                                   |תיקון סעיף 8         |
|""שיווק ישיר" - התקשרות בין עוסק לצרכן לרכישת טובין, כשהעסקה מבוצעת לא                                         |                     |
|בבית העסק של העוסק או המפרסם, והטובין נשלחים ישירות לצרכן."                                                    |                     |
|2. אחרי סעיף 14 לחוק העיקרי יבוא:                                                                              |הוספת סעיף 14א       |
|4וא. (א) בעסקאות של שיווק ישיר, יצרף העוסק לטובין הנשלחים אל                                 |"שיווק ישיר      |                     |
|הצרכן הוראות מפורטות בכתב; הוראות אלה יכללו פירוט של כל אחד                                  |                 |                     |
|מאלה:                                                                                        |                 |                     |
|(ו) הדרך שבה רשאי הצרכן לבטל את העסקה בהתאם                                                  |                 |                     |
|להוראות סעיף קטן (ב);                                                                        |                 |                     |
|(2) הכתובת המלאה של העוסק שעל הצרכן למען אליה את                                             |                 |                     |
|הודעתו במקרה של ביטול העסקה;                                                                 |                 |                     |
|(3) מידע על סוג השירות שיקבל הצרכן לאחר הרכישה;                                              |                 |                     |
|(4) הכתובת המלאה שאליה רשאי הצרכן להעביר תלונה על                                            |                 |                     |
|טיב הטובין;                                                                                  |                 |                     |
|(5) תעודת אחריות.                                                                            |                 |                     |
|(ב) צרכן רשאי לבטל עסקה של שיווק ישיר, ללא מסירת הסבר,                                       |                 |                     |
|בהודעה בכתב לעוסק תוך 4ו ימים מקבלת הטובין לרשותו.                                           |                 |                     |
|(ג) בוטלה עסקה בהתאם להוראות סעיף קטן (ב), יחזיר העוסק                                       |                 |                     |
|לצרכן את התשלום שקיבל, תוך פרק זמן שלא יעלה על 4ו ימים מיום                                  |                 |                     |
|קבלת הטובין חזרה לרשותו, או מיום קבלת הודעת הביטול של הצרכן, לפי                             |                 |                     |
|המאוחר מביניהם."                                                                             |                 |                     |

|דברי הסבר                |

|בנוהל עסקים רגיל נפגשים צרכן ועוסק בבית                          |
|העסק, והצרכן יכול לראות, להתרשם ולקבל מידע נוסף                  |
|על השירות ועל מחיר המצרך טרם רכישתו.                             |
|בשיווק ישיר ؀ࠂࠔࠖ࠘ࠦנעשית העסקה ממרחק, ללא קשר                     |
|ישיר עם העוסק, או עם בית העסק והמוצר, ויש צורך                   |
|בגילוי מרבי ומפורש של פרטי העסקה והמצרך על ידי                   |
|העוסק, כדי לאפשר לצרכן לשקול ולהחליט אם לרכוש                    |
|את הטובין או את השירות.                                          |
|במדינות מערביות רבות קיימת חקיקה ענפה בכל                        |
|הקשור לשיווק ישיר. בחקיקה האירופית מודגשים                       |

|הסעיפים שענינם זכות הצרכן לבטל עסקה תוך 7 ימים                    |
|לפחות מקבלת המצרך, גילוי נאות של פרטים על ידי                     |
|העוסק ועוד.                                                       |
|החקיקה בארץ לא עוסקת בהגנת הצרכן בעסקאות                          |
|מסוג זה.                                                          |
|מטרתה של הצעת חוק זו לקבוע הסדר מתאים                             |
|בנוגע לשיווק ישיר. נושא זה הוא בעל מאפיינים                       |
|ייחודיים המצדיקים התייחסות נפרדת בחוק הגנת                        |
|הצרכן.                                                            |

|חבר הכנסת: אברהם יחזקאל                |
