|מתפרסמת בזה הצעת חוק מטעם הממשלה:                         |

|הצעת חוק בנק ישראל (תיקון  17), התשנ"ה-1994                                                        |[929]               |

|1. במקום סעיף 66 לחוק בנק ישראל, התשי"ד-1954 1, יבוא:                                                          |החלפת סעיף 66         |
|66. מי שפרש משירותו בבנק יחולו עליו הוראות חוק שירות הציבור                                  |'הגבלות לאחר     |                      |
|(הגבלות לאחר פרישה), התשכ"ט-1969 2 (להלן - חוק שירות הציבור),                                |פרישה            |                      |
|בשינויים המחוייבים לפי הענין וכן בשינויים הבאים:                                             |                 |                      |
|(ו) סעיף 3 לחוק שירות הציבור יחול על הנגיד, על משנה לנגיד, על                                |                 |                      |
|עובד שהנגיד מינה לחבר הנהלת הבנק ועל עובד שהיה מדורג ערב                                     |                 |                      |
|פרישתו באחת מחמש הדרגות העליונות בדירוג עובדי הבנק;                                          |                 |                      |
|(2) מי שפרש משירותו בבנק לא יהיה דירקטור בתאגיד בנקאי, לא                                    |                 |                      |
|יהיה עובד של תאגיד בנקאי ולא יועסק על ידי תאגיד בנקאי, אם                                    |                 |                      |
|במסגרת תפקידו בבנק הגיע לידיו מידע מתאגיד בנקאי אחר, אשר                                     |                 |                      |
|הימצאותו בידי התאגיד הבנקאי שבו הוא מבקש לקבל תפקיד                                          |                 |                      |
|כאמור, עלול לפגוע פגיעה של ממש בעסקי התאגיד האחר, והבל                                       |                 |                      |
|אלא אם כן עברה שנה מיום שהמידע הגיע לידי אותו אדם או אם                                      |                 |                      |
|ניתן לו היתר לפי חוק שירות הציבור, לקבלת אותו תפקיד."                                        |                 |                      |

|דברי הסבר                       |

|סעיף 66 לחוק בנק ישראל, התשי''ד-1954, כנוסחו                 |
|היום, קובע לאמור:                                            |
|הגבלות על עובד הבנק                                          |
|66.؀ࠂࠒࠔࠖࠤ (א) עובד הבנק לא יהיה אותה שעה גם מנהל,            |
|פקיר או עובד, או בעל מניות, במישרין או בעקיפין,              |
|בתאגיד בנקאי ומשתדל להיות עובד הבנק לא יועסק על              |
|ידי תאגיד בנקאי בכל תפקיד עד תום שנתיים מיום                 |
|שחדל, אלא אם קיבל היתר בכתב מאת הנגיד.                       |

|(ב) עובד ארעי בבנק שהיה בעל מניות בתאגיד                           |
|בנקאי לפני שהיה לעובד כאמור, רשאי להמשיך להחזיק                    |
|בהן ער תום שנת עבודתו הראשונה בבנק או ער היותו                     |
|לעובד קבוע של הבנק, לפי המוקדם."                                   |
|מוצע להשוות את ההגבלות המוטלות על עובר                             |
|בנק ישראל שפרש, להגבלות החלות על עוברי ציבור                       |
|אחרים לפי חוק שירות הציבור (הגבלות לאחר פרישה),                    |
|התשכ''ט-1969, אשר חל על עובדי שירות המדינה,                        |
|רשויות מקומיות וגופים ציבוריים אחרים, בהתאמות                      |
|ובשינויים הדרושים לפי הענין.                                       |
