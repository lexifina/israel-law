|מתפרסמות בזה הצעת חוק של חבר הכנסת מטעם ועדת הפנים ואיכות הסביבה של הכנסת:                               |

|הצעת חוק התכנון והבניה (תיקון מס' 42) (מעונות למטופלים),                                        |[921]                |
|התשנ"ה-1994*                                                                                    |                     |

|1. בחוק התכנון והבניה, התשכ"ה-1965 1, אחרי סעיף 64 יבוא:                                                  |הוספת סעיף 64א      |
|64א. נקבעו בתכנית מיתאר או בתכנית מפורטת שטחים שנועדו למטרות                                 |"מעונות     |                    |
|מגורים, יראו ייעוד כזה ככולל גם היתר למגורי מטופלים שנקבעו על ידי משרד                       |למטופלים    |                    |
|העבודה והרווחה כמתאימים למגורים במעון פתוח, ובלבד שמספרם בבנין                               |            |                    |
|מגורים אחד לא יעלה על 25; אין בהוראות סעיף זה כדי לגרוע מסמכותה של                           |            |                    |
|ועדה מקומית לכלול בתכנית מיתאר או בתכנית מפורטת שטחים שיועדו                                 |            |                    |
|בתכניות כאמור למטרות מוסדות לטיפול בנזקקים למיניהם, בכל מספר                                 |            |                    |
|שהוא."                                                                                       |            |                    |

|דברי הסבר            |

|הגישה הטפולית לגבי אוכלוסיות שונות הזקוקות                 |
|לטפול והשגחה היא לשלבם עד כמה שניתן באוכלוסיה              |
|רגילה בחיי הקהילה, במסגרות של עבודה, לימודים וכוי.         |
|לצורך זה הוקמו הוסטלים ובתי טפול רבים אשר מספר             |
|המטופלים בהם אינו עולה על 25. שילובם בחיי הקהילה           |
|מותנה בכך שגם מגוריהם יהיו בתוך הקהילה.                    |
|לצערנו, פעמים רבות נתקלים אנו באוכלוסיה                    |
|המתנגדת שבשכנותם יוקם הוסטל או מעון מעין ؀ࠂࠒࠔࠖࠦזה.         |

|הצעת חוק זו באה לקבוע שמעון אשר מספר המטופלים                  |
|בו אינו עולה על 25 ייחשב בחוק כבית מגורים לכל                  |
|דבר.                                                           |
|הצעה זו תסייע לאוכלוסיות חלשות אלו להשתלב                      |
|בחיי הקהילה ולתפקד תפקוד רגיל עד כמה שהם יכולים                |
|ותוסר מהם הרגשת החרם והנדוי החברתי.                            |
|חבר הכנסת: יצחק לוי                                            |
