|מתפרסמת בזה הצעת חוק של חבר הכנסת מטעם ועדת החוקה חוק ומשפט של הכנסת:                               |

|הצעת חוק איסור פרסומים של גופים ציבוריים, התשנ"ה-1994*                                             |[918]               |

|1. בחוק זה -                                                                                                 |הגדרות              |
|"פרסום" - פרסום בתמורה באמצעי תקשורת לרבות פרסום מודעה תמורת תשלום;                                          |                    |
|"אמצעי תקשורת" - עתון, לרבות עתון יומי, שבועון או ירחון, בין אם הם מופצים באופן ארצי או                      |                    |
|מקומי, ולרבות פרסום חוצות, בין על לוחות מודעות ובין בכל דרך אחרת;                                            |                    |
|"איגרת ברכה" - לרבות מכתב, גלויה, או כרטיס ברכה לחג או למועד;                                                |                    |
|"גוף ציבורי" - משרד ממשלתי ומוסד ממוסדות המדינה, לרבות רשות מקומית, חברה ממשלתית,                            |                    |
|תאגיד שהוקם בחוק או גוף ציבורי הממלא תפקיד על פי דין וכן גוף נתמך כמשמעותו בסעיף                             |                    |
|32 לחוק יסודות התקציב, התשמ"ה- 11985;                                                                        |                    |
|"בעל תפקיד ציבורי" - מי שממלא תפקיד בגוף ציבורי לרבות מי שנבחר לכהונה בגוף ציבורי                            |                    |
|לפי דין, וכן חבר הכנסת או שר-,                                                                               |                    |
|"בן משפחה" - בן זוג, הורה, צאצא, אח או אחות.                                                                 |                    |
|2. (א) גוף ציבורי לא יממן פרסום או משלוח איגרות ברכה לבעל תפקיד ציבורי או לבן                                |איסור פרסום         |
|משפחתה ולא ישתתף במימון פרסום או משלוח כאמור, במישרין או בעקיפין.                                            |                    |
|(ב) לענין סעיף זה יראו פרסום של גוף ציבורי או משלוח איגרת ברכה על ידיו, גם                                   |                    |
|פרסום או משלוח של המנהל של אותו גוף או של עובד בו, ופרסום או משלוח איגרת ברכה שבו                            |                    |
|יצוין שמו של הגוף הציבורי, והכל אם אותם גורמים הם המברכים את בעל התפקיד                                      |                    |
|הציבורי.                                                                                                     |                    |

|דברי הסבר             |

|גופים ציבוריים רבים מפרסמים מודעות ברכה                          |
|לעמיתיהם או לנבחרים לכנסת, לממשלה או לרשויות                     |
|מקומיות שונות.                                                   |
|פרסום זה אשר עולה ממון רב, ממומן הלכה למעשה                      |
|מכספי הציבור אשר אינו צד לחילופי הברכות ההדדיות                  |
|ואינו מעונין בהן. תופעה זו בולטת במיוחד ערב החגים, בהם           |

|נשלחות איגרות ברכה מטעם העובדים בגופים ציבוריים                 |
|לכל עמיתיהם בשירות הציבורי או לבני משפחותיהם.                   |
|סעיף 2 מוצע לאסור בחוק פרסום מיותר ויקר זה                      |
|ולקבוע כי גוף הממומן מכספי ציבור לא                             |
|יעשה שימוש בכספים אלה אלא למטרות שלשמן הוא פועל,                |
|ולא למטרות אישיות של המנהלים או של העובדים בו.                  |

|                    |את הפרסום או המשלוח כאמור וכן יראו את מי ששמו או תוארו מופיעים כמברך או כחתום על                           |

|עונשין              |5. המפר הוראת חוק זה, דינו - קנס 10,000 שקלים חדשים.                                                       |

|                    |בדבר -                                                                                                     |
