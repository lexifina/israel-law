|                |(א) בפסקה (ו), בסופה יבוא ''לרבות תוצרת אזור כמשמעותו בתקנות שעת חירום                                    |
|                |(יהודה והשומרון וחבל עזה - שיפוט בעבירות ועזרה משפטית), התשכ"ז-1967 2                                     |

|דברי הסבר          |

|מבוא                                                         |
|הצעה זו גובשה בעיקרה בידי צוות בינמשרדי אשר                  |
|הכין את נוסח תקנות הממשלה לפי סעיף 3א לחוק חובת              |
|המכרזים, התשנ"ב-1992 (להלן - התקנות). הסעיף מסמיך            |
|את הממשלה לקבוע, באישור ועדת החוקה חוק ומשפט של              |
|הכנסת, תקנות בענין העדפת תוצרת הארץ, חובת שיתוף              |
|פעולה עסקי ורכש גומלין בינלאומי והעדפת תוצרת של              |
|אזור עדיפות לאומית. ענינים מסוימים, אשר בעיקרם נהגו          |

|לפיהם בהתאם להחלטות ממשלה קודמות, אינם ניתנים                |
|לקביעה בתקנות לפי החוק הקיים, ויש צורך בתיקון החוק           |
|לגביהם.                                                      |
|מוצע שהממשלה תהיה רשאית לקבוע                |סעיף ו        |
|בתקנות -                                     |              |
|(1) העדפה גם לענין תוצרת מאזורי יהודה, שומרון                |
|וחבל עזה, אשר יוצרה בידי אזרח ישראלי, תושב קבע               |
|בישראל או בידי תאגיד הרשום בישראל; (פסקה ו(א)                |
|המוצעת):                                                     |

|1 ס"ח התשנ"ב, עמ' 144 ועמ' 250 ; התשנ"ד, עמ' 244.    |
|2 ס"ח התשכ"ח, עמ' 20; ק''ת התשנ"ד, 1444.             |

|(בחוק זה - אזור), והבל אם יוצרה בידי אזרח ישראלי או תושב קבע בישראל, או                                     |                    |
|בידי תאגיד הרשום בישראל";                                                                                   |                    |
|(ב) בפסקה (2), בסופה יבוא 'לרבות קביעת התחייבות לשיתוף פעולה עסקי                                           |                    |
|בינלאומי או רכש גומלין בינלאומי כתנאי להשתתפות במכרז, ולרבות קביעת                                          |                    |
|דרישה כאמור בהתקשרויות המבוצעות שלא באמצעות מכרז";                                                          |                    |
|(ג) בפסקה (3), אחרי "מאזורי עדיפות לאומית'' יבוא "לרבות קביעת הוראות ברבר                                   |                    |
|חיוב מי שמתקשר עם מערכת הבטחון לרכוש תוצרת מאזורי עדיפות לאומית,                                            |                    |
|וקביעת הוראות לענין עריבת מברזים בירי מערכת הבטחון למציעים מאזורי                                           |                    |
|עדיפות לאומית";                                                                                             |                    |
|(2) אחרי סעיף קטן (ב) יבוא:                                                                                 |                    |
|"(ג) לענין סעיף זה, "העדפה" - לרבות בדרך של פיצול ההתקשרות נושא המכרז,                                      |                    |
|בין מציעים של תוצרת הארץ לבין מציעים של תוצרת שאינה תוצרת הארץ, או בין                                      |                    |
|מציעים של תוצרת מאזורי עדיפות לאומית לבין מציעים של תוצרת שלא מאזורים                                       |                    |
|כאמור, לפי הענין, והכל בתנאים, בשיעורים, ועל פי כללים שייקבעו בתקנות.'                                      |                    |
|2. אחרי סעיף 3א לחוק העיקרי יבוא:                                                                           |הוספת סעיף 3ב       |
|3ב. הממשלה רשאית להורות כי המדינה או תאגיד ממשלתי לא יתקשרו                              |"סייג להתקשרות     |                    |
|בחוזה לביצוע ؀ࠂࠎࠐࠔࠞࠠࠢࠬעסקה כאמור בסעיף 2 עם מדינת חוץ או עם ספק חוץ, מטעמים              |חוץ                |                    |
|שבמדיניות חוץ; הוראה כאמור אינה טעונה פרסום ברשומות, והממשלה                             |                   |                    |
|תביא אותה לידיעת מוסדות המרינה והתאגידים הממשלתיים בדרך שתמצא                            |                   |                    |
|לנכון; ניתנה הוראה כאמור לחברה ממשלתית או לחברת בת ממשלתית, יחולו                        |                   |                    |
|הוראות סעיף 3א(ב).'                                                                      |                   |                    |

|דברי הסבר              |

|(2) שהדרישה לשיתוף פעולה עסקי תהווה תנאי סף                  |
|במכרז, ולא רק מרכיב במסגרת אמות המידה לבחירת הזוכה           |
|במכרז. עוד מוצע כי הממשלה תוסמך במפורש לקבוע                 |
|בתקנות דרישות כאמור גם לענין התקשרויות המבוצעות              |
|שלא באמצעות מכרז; (פסקה ו(ב) המוצעת);                        |
|(5) הוראות לענין דרישה ממי שמתקשר עם מערכת                   |
|הבטחון לרכוש תוצרת מאזור עדיפות לאומית, והוראות              |
|לענין עריכת מכרזים בירי מערכת הבטחון בין מציעים              |
|מאזור עדיפות לאומית, בינם לבין עצמם, וזאת בדומה              |
|לנהוג במערכת הבטחון כיום; (פסקה ו(ג) המוצעת);                |
|עוד מוצע לקבוע שההעדפה אשר הממשלה תוסמך                      |
|לקבוע בתקנות לא תהיה רק לענין אמת המידה של המחיר             |
|במסגרת יתר אמות המירה לבחירת הזוכה במכרז, אלא גם,            |
|בדרך של הוראות בדבר פיצול התקשרויות במכרזים                  |

|מסוימים, באופן שחלק מהיקף המכרז יובטח להצעה של              |
|טובין מתוצרת הארץ, או של טובין מאזור עדיפות לאומית,         |
|לפי הענין. (פסקה (2) המוצעת).                               |
|מוצע להסמיך את הממשלה להורות כי              |סעיף 2        |
|מוסדות המדינה והתאגידים הממשלתיים            |              |
|לא יתקשרו עם מדינת חוץ מסוימת או עם ספק זר מטעמים           |
|של מדיניות חוץ; הכוונה בעיקר לנימוקים של שיתוף פעולה        |
|עם החרם הערבי.                                              |
