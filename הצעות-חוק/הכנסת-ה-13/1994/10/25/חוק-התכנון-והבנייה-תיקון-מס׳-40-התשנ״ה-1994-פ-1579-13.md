|"תוספת חמישית                                                                                                 |                   |
|(סעיף 58וא2(א))                                                                                               |                   |
|"בנין ציבורי'' - בנין או חלק מבנין המשמש למטרות הבאות להוציא בנין או חלק מבנין                                |                   |
|שאינו נועד להיות פתוח לקהל;                                                                                   |                   |
|(1) משרדי ממשלה, משרדי רשויות מקומיות וכל בנין אחר הנועד למתן שירות                                           |                   |
|ציבורי;                                                                                                       |                   |
|(2) בית קולנוע, לקונצרטים ולתיאטרון;                                                                          |                   |
|(ג) מוזיאון או בנין המשמש באופן קבוע לתערוכות, שהם ברשות מוסד ממשלתי,                                         |                   |
|לאומי או עירוני, וכל מקום כיוצא באלה;                                                                         |                   |
|(4) בנין המשמש מגרש ספורט או מקום למיתקני ספורט;                                                              |                   |
|(5) בית ספר למבוגרים ומוסד להשכלה גבוהה מוכר לפי סעיף 9 לחוק המועצה                                           |                   |
|להשכלה גבוהה, התשי"ח-1958 2;                                                                                  |                   |
|(6) מוסד חינוך כמשמעותו בחוק לימוד חובה, התש"ט-949ו3;                                                         |                   |
|(7) מוסד ציבורי לילדים-,                                                                                      |                   |
|(8) אולם לשמחות;                                                                                              |                   |
|(9) בית לאסיפות ובית לעצרות עם במשמעות "אסיפה'' ו"עצרת עם" בסעיף ו                                            |                   |
