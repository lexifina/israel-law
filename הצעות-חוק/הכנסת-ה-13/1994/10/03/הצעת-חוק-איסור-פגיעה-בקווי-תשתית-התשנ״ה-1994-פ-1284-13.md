|1. בחוק זה -                                                                                               |הגדרות              |
|"קווי תשתית" - קווי צינורות תת-קרקעיים ועל-קרקעיים המשמשים להולכת שמן דלק לסוגיו,                          |                    |
|נפט גלמי או מעובד, מוצרי נפט או גז דליק;                                                                   |                    |
|"מיתקני חיבור" - תיבות, ארגזים, גובים תת-קרקעיים, מגופים, חדרי מגופים וחשמל, שוחות,                        |                    |
|מסגרות סעף, תיבות הסתעפות, מערבת הגנה קטודית, שרוולים ואבזרים אחרים שאליהם                                 |                    |
|מחוברים קווי תשתית;                                                                                        |                    |
|"ציוד הנדסי" - כמשמעות "ציוד" בסעיף 1 לחוק רישום ציוד הנדסי, התשי"ז-1957 1;                                |                    |
|"עבודות חפירה" - עבודות חפירה, בכל מקום בארץ, באמצעות ציוד הנדסי לעומק העולה על                            |                    |
|1.5 מטר מפני הקרקע בתחום רצועות קווים ו-4 מטרים מכל צד של קו תשתית;                                        |                    |
|"בעלי קווים" - חברות או גופים אשר בבעלותם קווי תשתית;                                                      |                    |
|"רצועות קווים" - רצועות קרקע לאורך קווי התשתית שבהן יש לבעלי הקווים זכויות, בין בדרך                       |                    |
|הפקעה ובין בדרך אחרת, לרבות זכות מעבר.                                                                     |                    |
|2. לא יבצע אדם עבודות חפירה, אלא אם כן קיבל לכך אישור מהרשות המקומית שהוא                                  |תנאים לביצוע        |
|עומד לחפור בתחומה; לפני מתן אישור כאמור -                                                                  |עבודות חפירה        |
|(1). תברר הרשות המקומית, על פי תכנית מיתאר מחוזית, תכנית מיתאר מקומית, תכנית                               |                    |
|מפורטת או סימונים, אם עוברים קווי תשתית או מיתקני חיבור בשטח שבו הוא מתעתד                                 |                    |
|לבצע עבודות חפירה או בסמוך לו;                                                                             |                    |
|(2) תפנה הרשות המקומית במכתב רשום לבעלי הקווים, תוך צירוף תכנית של המקום                                   |                    |
|שבי יש כוונה לבצע עבודות חפירה, בשאלה האם בשטח התכנית מצויים קווי תשתית                                    |                    |
|ומיתקני חיבור ומה מיקומם המדוייק, ותמתין 45 ימים לקבלת תשובה מהם במכתב                                     |                    |
|רשום.                                                                                                      |                    |
|3. נודע למי שמתכוון לבצע עבודות חפירה, תוך ביצוע אחת הפעולות הנזכרות בפסקאות                               |אישור מבעלי         |
|(ו) ו-(2) של סעיף 2 או בדרך אחרת, כי ברדיוס של 0ו מטרים ממקום שבו הוא מתכוון לבצע                          |קווי תשתית          |
|עבודות חפירה עוברים קווי תשתית או מיתקני חיבור, לא יהיה רשאי לבצע עבודות חפירה אלא                         |                    |
|אם כן קיבל לכך אישור מראש ובכתב מאת בעלי התשתית ובתנאים שקבעו.                                             |                    |
|4. הנחת צנרת דלק או גז תהיה מותנית בתנאים הבאים:                                                           |צנרת דלק וגז        |
|(1) סימון קו הצנרת במפות השייכות לענין;                                                                    |                    |
|(2) הנחת הצינור בעומק העמוק ב-2 מטרים לפחות מצנרת אחרת;                                                    |                    |
|(3) סימון תת-קרקעי, בגובה 3 מטרים מעל הצנרת, אשר יאפשר זיהויה; אם צינור עובר                               |                    |
|מעל צנרת אחרת יונח סימון מתאים 1.5 מטר מתחת לפני הקרקע;                                                    |                    |
|(4) סימון תוואי הצנרת מעל פני הקרקע, בגובה קו העין;                                                        |                    |
