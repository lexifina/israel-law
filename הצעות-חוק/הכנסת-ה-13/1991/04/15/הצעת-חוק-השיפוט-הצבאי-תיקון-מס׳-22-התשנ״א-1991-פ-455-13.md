|[413]         |חוק השיפוט הצבאי (תיקון מס' 22), התשנ"א-1991                                      |

|1. במקום סעיף 65 לחוק השיפוט הצבאי, התשט"- 1955 1,  יבוא:                                              |החלפת סעיף 65       |
|65. (א) חייל שהיכה אדם הנמצא במשמורת שהחייל מופקד עליה, או                                |"התעללות    |                    |
|שהיכה חייל הנמוך ממנו בדרגה, או שהתעלל בהם בדרך אחרת, דינו - מאסר                         |            |                    |
|שלש שנים.                                                                                 |            |                    |
|(ב) חייל שהתעלל בחייל אחר, דינו - מאסר שנתיים.                                            |            |                    |
|(ג) נעברה העבירה בנסיבות מחמירות, דין המתעלל - מאסר שבע                                   |            |                    |
|שנים."                                                                                    |            |                    |

|דברי הסבר        |

|לאמור:                                                       |
|"התעללות                                                     |
|65. חייל שהיכה אדם הנמצא במשמורת שהחייל מופקד                |
|עליה, או שהיכה חייל הנמוך ממנו בדרגה, או שהתעלל בהם          |
|בדרך אחרת, דינו - מאסר שלוש שנים".                           |
