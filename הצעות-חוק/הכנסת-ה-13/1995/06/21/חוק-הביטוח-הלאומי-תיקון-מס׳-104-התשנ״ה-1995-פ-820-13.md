|התשנ"ה-1995*                                                                                               |

|החלפת סעיף 103ה        |1. במקום סעיף 103ה לחוק הביטוח הלאומי [נוסח משולב], התשכ"ח-1968 1, יבוא:                                  |
|                       |103ה. גימלה לשמירת הריון, לכל יום, היא בסכום השווה לשכר העבודה                      |"שיעור הגימלה        |
|                       |הרגיל של המבוטחת המחושב לפי סעיף וסו ולא יותר מ-70% מהשכר                           |                     |
|                       |הממוצע מחולק ב-30; לעניין שכר העבודה הרגיל - היום הקובע הוא                         |                     |
|                       |היום הראשון לשמירת ההריון; חל פיצוי לאחר תום התקופה ששימשה                          |                     |
|                       |בסיס לחישוב שכר העבודה הרגיל יוגדל סכום שכר העבודה הרגיל                            |                     |
|                       |שחושב כאמור בשיעור הפיצוי מיום תחילת הפיצוי."                                       |                     |
|תיקון סעיף 60          |2. נוסחו של סעיף 60 לחוק הביטוח הלאומי [נוסח משולב], התשנ"ה-1995 2, יהיה                                  |
|בנוסח משולב            |כנוסחו של סעיף 03וה המובא בסעיף ו לחוק זה.                                                                |
|התשנ'ה                 |                                                                                                          |

|דברי הסבר              |

|אשה עובדת הזכאית לגימלה לשמירת הריון,                         |
|זכאית, לפי המצב החוקי הקיים ؀ࠂࠐࠒࠔהיום, לקבל מהמוסד            |
|לביטוח לאומי את שכר עבודתה הרגיל או סכום השווה                |
|ל-25% מהשכר הממוצע לפי הנמוך מביניהם. לפי זה                  |
|אשה לא תקבל יותר מ-1,000 ש''ח לחודש שהם 60%                   |
|משכר המינימום.                                                |

|מוצע לתקן את החוק באופן שהגימלה לשמירת                      |
|הריון תהיה בגובה שבר עבודתה הרגיל של העובדת                 |
|אולם לא יותר מ-70% מהשכר הממוצע במשק, דהיינו                |
|לא יותר מכ-2,800 ש''ח לחודש.                                |
|חברי הכנסת: תמר גוז'נסקי, ענת מאור,                         |
|אסתר סלמוביץ, נעמי חזן                                      |
