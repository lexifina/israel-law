|מתפרסמות בזה הצעות חוק של חברי הכנסת מטעם ועדת הפנים ואיכות הסביבה של הכנסת:                              |

|הצעת חוק הרשויות המקומיות (סייג לעסק או לעיסוק נוסף),                                     |
|התשנ"ו-1995*                                                                              |

|1. בהצעת חוק זו -                                                                                            |הגדרות             |
|"הכנסה" - כהגדרתה בפקודת מס הכנסה [נוסח חדש]1 לרבות הכנסה עקיפה;                                             |                   |
|"עסק או עיסוק נוסף" - בין בעצמו ובין בשיתוף עם אחר לרבות עובד או שליח ולמעט ניהול                            |                   |
|הנכסים שלו או של בני משפחתו;                                                                                 |                   |
|"רשות מקומית או רשות" - עיריה או מועצה מקומית;                                                               |                   |
|"שופט" - שופט בדימוס של בית המשפט העליון או בית המשפט המחוזי שקבע נשיא בית                                   |                   |
|המשפט העליון;                                                                                                |                   |
|"תמורה חומרית" - לרבות העמדת רכב, משרד, שירותי משרד ושירותי טלפון לראש הרשות                                 |                   |
|לצרכיו הפרטיים.                                                                                              |                   |
|2. יא) ראש רשות מקומית לא יעסוק בכל עסק או בכל עיסוק נוסף אם יש בעסק או                                      |סייגים לעיסוק      |
|בעיסוק אחד מאלה:                                                                                             |                   |
|(ו) פגיעה בחובותיו כראש רשות;                                                                                |                   |
|(2) אפשרות של ניגוד ענינים בין העסק או העיסוק הנוסף לבין תפקידו כראש                                         |                   |
|רשות.                                                                                                        |                   |
|(ב) (1) ראש רשות רשאי לעסוק בכל עסק או עיסוק נוסף שאינם אסורים על פי                                         |                   |
|סעיף קטן (א) ובלבד שהכנסתו השנתית של ראש רשות מעסק או עיסוק נוסף                                             |                   |
|כאמור לא תעלה על מחצית הכנסתו בראש רשות, בין בתמורה כספית ובין                                               |                   |
|בתמורה חומרית אחרת.                                                                                          |                   |
|(2) בתום כל שנה, יגיש ראש רשות לשופט, במועד ובדרך שייקבעו בתקנות,                                            |                   |
|הצהרה הכוללת את פרטי הכנסתו מעסק או מעיסוק נוסף בשנה שקדמה                                                   |                   |
|להגשת ההצהרה.                                                                                                |                   |
|(3) שר הפנים יקבע הוראות בענין מועד ודרך הגשת הצהרה הכוללת את                                                |                   |
|פרטי הכנסתו של ראש רשות מעסק או מעיסוק נוסף.                                                                 |                   |

|דברי הסבר              |

|؀ࠂࠒࠔࠖࠦבשנת 1975 חוקק חוק הרשויות המקומיות (בחירת           |
|ראש הרשות סגניו וכהונתם), התשל"ה-1975, ונקבעה              |
|בו בחירה ישירה של ראש רשות מקומית.                         |
|בחירה ישירה מחייבת את הנבחר לראש רשות                      |
|להקדיש את רוב זמנו לעבודתו ברשות. מוצע על-כן               |
|להטיל סייגים על עסק או עיסוק נוסף שיבחר ראש רשות           |
|לעסוק בו בנוסף לתפקידו כראש רשות ושיש בו משום              |

|פגיעה בחובותיו כראש רשות או שקיימת אפשרות                     |
|שיהיה ניגוד ענינים בין העסק או העיסוק הנוסף לבין              |
|תפקידו כראש עיר (סעיף 2). עוד מוצע כי בתום כל שנה,            |
|יגיש ראש רשות הצהרה שתוגש לשופט הכוללת את                     |
|פרטי הכנסתו של ראש רשות מכל עסק או עיסוק נוסף                 |
|(סעיף 2(ב)(2)).                                               |
