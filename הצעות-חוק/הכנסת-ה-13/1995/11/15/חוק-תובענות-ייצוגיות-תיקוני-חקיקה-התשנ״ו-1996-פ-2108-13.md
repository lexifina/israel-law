|46א. (א) אדם או ארגון צרכנים (להלן - התובע) רשאי לתבוע בשם                                |תובענה ייצוגית      |
|קבוצת אנשים בשל כל עילה אשר בשלה יכול על פי חוק זה התובע                                  |                    |
|לתבוע בשמו נגד כל נתבע אשר התובע יבול לתבוע בשמו (להלן -                                  |                    |
|תובענה ייצוגית).                                                                          |                    |
|(ב) פסק דין בתובענה ייצוגית יהווה מעשה בית דין לגבי כל                                    |                    |
|הנמנים עם הקבוצה, בכפוף להוראות סעיף 46ג(ב).                                              |                    |
|46ב. הגשת תובענה ייצוגית טעונה אישור בית המשפט או בית הדין,                               |אישור בית           |
|לפי הענין (להלן בפרק זה - בית המשפט), והוא לא יאשרה אלא אם כן                             |המשפט               |

|(1) גודלה של הקבוצה מצדיק הגשת התובענה בתובענה                                          |                    |
|ייצוגית;                                                                                |                    |
|(2) קיימת אפשרות סבירה ששאלות מהותיות של עובדה                                          |                    |
|ומשפט המשותפות לקבוצה יוכרעו בתובענה הייצוגית לטובת                                     |                    |
|הקבוצה;                                                                                 |                    |
|(3) הגשת התובענה הייצוגית היא דרך עדיפה על הגשת                                         |                    |
|תביעות אישיות והוגנת להכרעה במחלוקת בנסיבות הענין;                                      |                    |
|(4) קיים יסוד סביר להניח כי התובע מייצג בדרך הולמת את                                   |                    |
|עניינם של כל הנמנים עם הקבוצה.                                                          |                    |
|46ג. (א) אישר בית המשפט את הגשת התובענה כתובענה ייצוגית,                                |הגדרת הקבוצה        |
|יגדיר את הקבוצה שבשמה תוגש התובענה הייצוגית ויורה על אופן                               |                    |
|פרסום החלטתו,                                                                           |                    |
|(ב) יראו מי שנמנה עם הקבוצה שהגדיר בית המשפט כמי                                        |                    |
|שהסכים להגשת התובענה כתובענה ייצוגית, אלא אם כן הודיע לבית                              |                    |
|המשפט על רצונו שלא להימנות עם הקבוצה, וזאת תוך ארבעים וחמישה                            |                    |
|ימים מיום פרסומה של החלטת בית המשפט; בית המשפט רשאי לפי                                 |                    |
|בקשה של אדם פלוני להאריך לגביו את התקופה האמורה, אם ראה טעם                             |                    |
|מיוחד לבך.                                                                              |                    |
|46ד. תובע לא יסתלק מתובענה ייצוגית, ולא יעשה הסדר או פשרה עם                            |הסדר או פשרה        |
|נתבע, אלא באישור בית המשפט.                                                             |                    |
|46ה. (א) שר המשפטים יקבע סדרי דין לענין הגשת תובענה ייצוגית                             |תקנות               |
|וניהולה.                                                                                |                    |
|(ב) שר המשפטים רשאי לקבוע הוראות בדבר דרכי הוכחת הנזק                                   |                    |
|שנגרם לכל אחד מהנמנים עם הקבוצה.                                                        |                    |
|46ו. תובע המגיש תובענה ייצוגית יודיע על כך בכתב ליועץ המשפטי                            |הודעה               |
|לממשלה ולממונה.                                                                         |                    |
|46ז. הגשת תובענה ייצוגית תהיה פטורה מתשלום אגרת בית                                     |פטור מאגרה          |
|המשפט.                                                                                  |                    |
