|מתפרסמת בזה הצעת חוק של חבר הכנסת מטעם ועדת הכלכלה של הכנסת:                           |

|הצעת חוק קליטת חיילים משוחררים (תיקון מס' 2) (הקצאת קרקעות),                                       |
|התשנ"ו-1995*                                                                                       |

|1. בסעיף 1 לחוק קליטת חיילים משוחררים, התשנ"ד-1994 1 (להלן - החוק העיקרי),                              |תיקון סעיף ו          |
|בסופו יבוא:                                                                                             |                      |
|""אזור עדיפות לאומית א'" ו"אזור עדיפות לאומית ב'" - האזורים שנקבעו לפי סעיף                             |                      |
|40ד לחוק לעידוד השקעות הון, התשי"ט- 1959 2."                                                            |                      |
|2. אחרי סעיף 17 לחוק העיקרי יבוא:                                                                       |הוספת סעיף 17א        |
|17א. (א) בני זוג שנישאו זכאים לקרקע לבניה אחרי פיתוח, שיקצה                           |"הקצאת קרקעות     |                      |
|להם מינהל מקרקעי ישראל, ובלבד שלפחות אחד מבני הזוג הוא חייל                           |                  |                      |
|משוחרר, ובני הזוג יתגוררו בבית שנבנה על הקרקע שהוקצתה להם                             |                  |                      |
|לפחות חמש שנים.                                                                       |                  |                      |
|(ב) הקצאת הקרקע תיעשה:                                                                |                  |                      |
|(ו) באזור עדיפות לאומית א' - ללא כל תשלום;                                            |                  |                      |
|(2) באזור עדיפות לאומית ב' - תמורת תשלום של 20 אחוזים                                 |                  |                      |
|מערך הקרקע;                                                                           |                  |                      |
|(3) ביתר האזורים - תמורת תשלום של 40 אחוזים מערך                                      |                  |                      |
|הקרקע.                                                                                |                  |                      |
|(ג) הוקצתה קרקע ולא התמלאו בל תנאי הזכאות לפי סעיף קטן                                |                  |                      |
|(א), יחזירו בני הזוג כסף לאוצר המדינה, או למינהל מקרקעי ישראל,                        |                  |                      |
|בהתאם להוראות וכללים שיקבע השר."                                                      |                  |                      |

|דברי הסבר            |

|בנושא הדיור קיימת מצוקה רבה לזוגות ؀ࠂࠒࠔࠖࠤצעירים.            |
|מוצע להקצות קרקע לבניה ללא תשלום, או                        |
|בתשלום נמוך, לפי מקום הקרקע, לבני זוג שנישאו                |
|ולפחות אחד מבני הזוג הוא חייל משוחרר.                       |

|עלות הצעת החוק לפי הערכת המציע, כ-0ו מיליון                 |
|שקלים חדשים, ואותם מוצע לממן מהרזרבות שבתקציב               |
|המדינה. להערכת משרד האוצר העלות תהיה כ-800                  |
|מיליון עד 1.2 מיליארד שקלים חדשים.                          |
|חבר הכנסת עובדיה עלי                                        |
