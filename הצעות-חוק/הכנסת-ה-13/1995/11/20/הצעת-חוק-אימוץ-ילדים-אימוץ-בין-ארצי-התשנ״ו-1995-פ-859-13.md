|הצעת חוק אימוץ ילדים (אימוץ בין-ארצי), התשנ"ו-1995*                                         |

|אימוץ בין-ארצי  |1. אימוץ בין-ארצי של ילד שאינו תושב ישראל על-ידי תושב ישראל יתבצע על פי                                  |
|                |הוראות חוק זה על-ידי עמותה מאושרת לפי הוראות סעיף 3 במסגרת אמנה שישראל צד לה                             |
|                |ולאחר שהרשויות המוסמכות של מדינת המוצא -                                                                 |
|                |(ו) קבעו שהילד הוא בר-אימוץ;                                                                             |
|                |(2) קבעו, לאחר שיקול של אפשרויות השמה של הילד בתוך מדינת המוצא,                                          |
|                |שאימוץ בין-ארצי הוא לטובת הילד;                                                                          |
|                |(3) אישרו כי ההורים, האפוטרופסים או כל אדם, מוסד או רשות שהסכמתם                                         |
|                |נדרשת לאימוץ, התייעצו במידה הנדרשת וקיבלו מידע לגבי תוצאות הסכמתם                                        |
|                |לאימוץ;                                                                                                  |

|דברי הסבר             |

|מוצע להסדיר את התנאים המאפשרים לאזרחים                     |
|ישראלים לאמץ בחוץ לארץ.                                    |
|הבעייתיות בתחום זה נובעת מהעובדה, שבשל                     |
|המסורת היהודית המשפחתית העמוקה, ישנם בכל שנה               |
|בישראל יחסית מעט ילדים מועמדים לאימוץ ומאידך,              |
|מעוניינים רבים באימוץ.                                     |

|פער זה יצר אפיקים של הליכי אימוץ לא חוקיים,                 |
|ולפעמים יקרים, בחוץ לארץ שהסתיימו לא אחת בסבל               |
|למאמצים ולילדים. אחרים נרתעו מלהיכנס לתהליכי                |
|האימוץ, ונמנעה מהם חוויית ההורות.                           |

|. הצעת חוק מס' תתכ"ט; הועברה לועדה ביום י"ד בסיון התשנ''ה (24 במאי 1994); הצעת חוק מס' א'תרס;            |
|הועברה לועדה ביום י"ד בסיון התשנ''ה (24 במאי 1994).                                                      |
|ס''ח התשמ''א, עמ' 295.                                                                                   |

|(4) אישרו כי ההורים, האפוטרופסים או כל אדם, מוסד או רשות שהסכמתם                                             |                   |
|נדרשת לאימוץ נתנו הסכמה בלתי מותנית על פי דיני מדינת המוצא, והסכמתם לא                                       |                   |
|נבעה מתשלום תמורה מכל סוג שהוא.                                                                              |                   |
|2. בנוסף להוראות סעיף ו, אימוץ בין-ארצי יתבצע לאחר שהרשויות המוסמכות של                                      |תנאים לאימוץ       |
|מדינת ישראל קבעו כי -                                                                                        |בין-ארצי           |
|(ו) ההורים העתידים לאמץ ראויים ומתאימים לאימוץ;                                                              |                   |
|(2) הילד יורשה להיכנס ולגור בקביעות בישראל.                                                                  |                   |
|3. שר המשפטים רשאי ליתן רשיון לעמותה, למטרת טיפול וביצוע אימוץ בין-ארצי,                                     |עמותה מאושרת       |
|לאחר שהוכח להנחת דעתו כי העמותה עמדה בדרישות שקבע וכי היא תוכל לטפל ולבצע                                    |                   |
|את הליך ؀ࠂࠐࠒࠖࠜࠞࠠהאימוץ כראוי על כל היבטיו (להלן - עמותה מאושרת).                                             |                   |
|4. עמותה מאושרת תנקוט את כל הצעדים הנדרשים כדי -                                                             |תפקיד עמותה        |
|(1) לאסוף, לשמור ולהחליף מידע לגבי מצבו של הילד ומצב ההורים העתידים                                          |מאושרת             |
|לאמץ;                                                                                                        |                   |
|(2) לסייע ולזרז את ההליכים להשגת האימוץ ולעקוב אחריהם, בהתאם לנדרש:                                          |                   |
|(3) למנוע. כל רווח כספי או אחר שאינו הולם את תהליך האימוץ, או נוהג שאינו                                     |                   |
|הולם את תקינות האימוץ;                                                                                       |                   |
|(4) לפתח שירותי ייעוץ לאימוץ בישראל ובמדינות המוצא.                                                          |                   |
|5. תוקם רשות מרכזית לאימוץ בין-ארצי במשרד העבודה והרווחה (להלן - הרשות).                                     |רשות מרכזית        |
|6. הרשות או עמותה מאושרת יכינו תסקיר לגבי ההורים העתידים לאמץ; התסקיר                                        |תסקיר              |
|יכלול מידע לגבי זהותם, כשירותם, התאמתם לאימוץ, רקעם, ההיסטוריה המשפחתית                                      |                   |
|והרפואית שלהם, סביבתם החברתית, מניעיהם לאימוץ ויכולתם לעמוד באימוץ בין-ארצי;                                 |                   |
|התסקיר יועבר לרשויות המוסמכות של מדינת המוצא.                                                                |                   |
|7. עמותה מאושרת או הרשות יאשרו את התאמת ההורים העתידים לאמץ.                                                 |אישור התאמה        |
|8. ילד שאומץ לפי חוק זה - דינו כדין מי שאומץ לפי חוק אימוץ ילדים,                                            |תוצאי אימוץ        |
|התשמ"א-1981 1.                                                                                               |                   |
|9. שר המשפטים, בהתייעצות עם שר העבודה והרווחה ובאישור ועדת החוקה, חוק                                        |רשויות מוסמכות     |
|ומשפט של הכנסת, ימנה רשויות מוסמכות לענין חוק זה ככל הנחוץ לטיפול ולביצוע אמנה                               |                   |
|דו-צדדית או רב-צדדית שענינה אימוץ בין-ארצי, שישראל צד לה.                                                    |                   |
|10. שר המשפטים ממונה על ביצוע חוק זה והוא רשאי, בהתייעצות עם שר העבודה                                       |ביצוע ותקנות       |
|והרווחה ובאישור ועדת החוקה, חוק ומשפט של הכנסת, להתקין תקנות לביצועו ולביצוע                                 |                   |
|אמנה שישראל צד לה.                                                                                           |                   |
