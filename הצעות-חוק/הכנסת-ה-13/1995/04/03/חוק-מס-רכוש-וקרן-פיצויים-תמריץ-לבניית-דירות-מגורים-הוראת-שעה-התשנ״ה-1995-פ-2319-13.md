|                 |(2) ''דירות מגורים" - דירות שאינן מהוות מלאי עסקי בידי בעליהן;                                           |
|                 |(3) "קרקע" - כהגדרתה בחוק מס רכוש, למעט קרקע המהווה מלאי עסקי בידי                                       |
|                 |בעליה;                                                                                                   |

|                 |(5) "מס" - מס רכוש.                                                                                      |
|פטור ממס         |2. (א) על אף הוראות חוק מס רכוש, לא ישולם מס על ידי בעל קרקע שאינו עוסק                                  |
|רכוש             |במקרקעין, על קרקע שעליה ייבנו דירות מגורים, במשך תקופה של שלושים חודשים שקדמו                            |
|                 |לגמר הבניה של דירות המגורים, ובלבד שהבניה החלה בתוך שלוש שנים מיום תחילתו של                             |
|                 |חוק זה; לענין זה, "תחילת הבניה" - התחלת עבודות הבניה בקרקע לאחר קבלת רשיון בניה                          |
|                 |בחוק.                                                                                                    |
|                 |(ב) על אף הוראות סעיף קטן (א) -                                                                          |
|                 |(ו) הפטור ממס רכוש יחול רק על אותו חלק מהקרקע הדרוש לבניית                                               |
|                 |הדירה;                                                                                                   |
|                 |(2) במכירת קרקע או חלק ממנה שתמורתה היא זכויות במקרקעין בבנין                                            |
|                 |שייבנה על הקרקע, יקבל בעל הקרקע פטור ממס על חלק הקרקע הדרוש לבניית                                       |
|                 |דירת מגורים אחת בלבד.                                                                                    |
|חיוב במס         |3. קיבל בעל קרקע פטור ממס רכוש על פי חוק זה אף שלא היה זכאי לקבלו, יהא חייב                              |
|למקבל פטור       |בתשלום המס כאילו לא ניתן הפטור, בצירוף הפרשי הצמדה וריבית באמור בסעיף 33 לחוק                            |
|שלא היה          |מס רכוש וקנס על פי חוק המסים (קנס פיגורים), התשמ"א-1980 3.                                               |
|זכאי לקבלו       |                                                                                                         |
|ביצוע ותקנות     |4. שר האוצר ממונה על ביצוע חוק זה והוא רשאי להתקין תקנות בכל ענין הנוגע                                  |
|                 |לביצועו, לרבות בדבר התנית מתן הפטור בתנאים, ולרבות הקפאת גביית מס רכוש בעת                               |
|                 |הצהרה על התחלת בניה, והתאמת תקופת הפטור למועד סיום הבניה.                                                |
