|1. בפקודת מס הכנסה [נוסח חדש] 1, אחרי סעיף 27 יבוא:                                                   |הוספת סעיף 27א       |
|27א, (א) בסעיף זה, "ציוד נלווה'' - לרבות תוכנות מחשב.                                 |"פחת בגין      |                     |
|(ב) על אף האמור בסימן זה, אדם העוסק בעסק או במשלח יד                                  |מחשבים וציוד   |                     |
|המצריכים שימוש במחשבים וציוד נלווה למחשבים, יהיה זכאי לנכות,                          |נלווה          |                     |
|אחת לשנה, פחת של חמישים אחוזים ממחיר רכישתם.                                          |               |                     |
|(ג) שר האוצר רשאי להתקין תקנות לענין שיעורי פחת העולים על                             |               |                     |
|שיעור הפחת הקבוע בסעיף קטן (ב)."                                                      |               |                     |

|דברי הסבר           |

|הפחת הנהוג ביום על מחשבים הוא 20% לשנה.                   |
|פחת זה מקשה על עסקים לחדש את ציוד המחשוב                  |
|שלהם ולשכלל את עסקיהם.                                    |
