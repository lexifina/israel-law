|מתפרסמת בזה הצעת חוק מטעם ועדת החוקה, חוק ומשפט של הכנסת:                        |

|הצעת חוק שירות המדינה (מינויים) (תיקון מס' 7) (ייצוג הולם),                                      |
|התשנ"ה-1995                                                                                      |

|1. בחוק שירות המרינה (מינויים), התשי"ט-1959 1, אחרי סעיף 15 יבוא:                                        |הוספת סעיף 5וא       |
|5וא. (א) בקרב העובדים בשירות המדינה יינתן ביטוי הולם, בנסיבות                          |"ייצוג הולם      |                     |
|הענין, לייצוגם של בני שני המינים (להלן - ייצוג הולם).                                  |לבני שני המינים  |                     |
|(ב) ראה נציב שירות המדינה כי בקרב העובדים במשרד או                                     |                 |                     |
|ביחידה במשרד, או בסוג משרות אין ייצוג הולם כאמור, יפעל לקידום                          |                 |                     |
|הייצוג ההולם, ככל שניתן בנסיבות הענין.                                                 |                 |                     |
|(ג) פעולות הנציב יכול שייעשו בתכנית אשר תכלול הוראות בדבר                              |                 |                     |
|העדפה במכרז למשרה או לקבוצת משרות, או לדרגה או לקבוצת דרגות                            |                 |                     |
|שיפורטו בתכנית ולתקופה שתיקבע בה. התכנית טעונה אישור ועדת                              |                 |                     |
|השירות;                                                                                |                 |                     |
|בסעיף קטן זה, "העדפה" - מתן עדיפות במכרז לבן המין שאינו                                |                 |                     |
|מיוצג באופן חולם, מקום שמועמדים בני שני המינים הינם בעלי כישורים                       |                 |                     |
|דומים."                                                                                |                 |                     |

|דברי הסבר                   |

|חוק החברות הממשלתיות (תיקון מס' 6), התשנ"ג-                    |
|1993, קבע תקדים עקרוני בחקיקה הישראלית כשקבע                   |
|את עיקרון ההעדפה המתקנת במפורש וכחובה בחוק.                    |
|הימנעות ממינוי נשים הביאה לקביעה מפורשת                        |
|של בית המשפט העליון בבג"צ 454/49 שדולת הנשים                   |
|בישראל נ' ממשלת ישראל ואח' (טרם פורסם). בפסק דינו              |
|של כב' השופט מצא נאמר, כי רעיון ""ההעדפה                       |
|המתקנת" (או "המקדמת", AFFIRMATIVE ACTION)                      |
|נגזר מעקרון השוויון, ועיקרו הוא בהעמדת אמצעי של                |
|מדיניות משפטית להגשמת ؀ࠂࠒࠔࠖࠤהשוויון בנורמה חברתית              |
|תוצאתית", ובהמשך: ''... קיומו לאורך זמן של שוויון              |
|פורמלי בלבד מעלה את החשש שבשל דרכו של עולם                     |
|ומנהגי הבריות, תונצחנה תוצאותיה של ההפליה. תיקון               |
|עוולות העבר והשגת שוויון מעשי יכולים, לכן,                     |
|להיעשות רק בהענקת יחס מועדף לבני הקבוצה                        |
|החלשה." (פסקה 16 לפסק דינו של השופט מצא).                      |

|בעקבות פסק דין זה, שדן במינוי נשים                             |
|כדירקטוריות בחברות ממשלתיות, מוצע להרחיב את                    |
|יישום העיקרון של העדפה מתקנת גם בשירות המדינה                  |
|ולשם כך לקבוע במפורש בסעיף 21א(א), את העיקרון                  |
|הכללי בדבר מתן ביטוי הולם, בנסיבות הענין, לייצוגם              |
|של בני שני המינים בשירות המדינה. לאור ייחודו של                |
|שירות המדינה הבנוי ממשרדים ומתפקידים שונים,                    |
|מוצע, בסעיף קטן (ב), להסמיך את נציב שירות המדינה               |
|לוודא אם אכן קיים יצוג הולם כאמור במשרד ממשלתי,                |
|ביחידה או בסוג משרות, ולפעול לקידומו.                          |
|בסעיף קטן (ג) מוצע להקנות לנציב שירות המדינה                   |
|סמכות לקבוע תכנית אשר תכלול גם הוראות בדבר                     |
|העדפה במכרז לשם יישום ההעדפה המתקנת, עוד                       |
|מוצע שתכנית זו תהא טעונה אישור ועדת השירות                     |
|על-מנת להבטיח סדרי מנהל תקינים.                                |

|1 ס"ח התשי"ט עמ' 86; התשנ"ד עמ' 66.              |
