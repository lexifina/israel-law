|התשנ"ה-1995*                                                                                             |

|1. במקום סעיף 19 לחוק התכנון והבניה, התשכ"ה-1965 1, יבוא:                                                |תיקון סעיף 19     |
|19. (א) במרחב תכנון מקומי שבתחומו נמצאות יותר מרשות מקומית                             |"ועדה של         |                  |
|אחת (להלן - רשות מרחבית), יקבע שר הפנים את מספר חברי הועדה                             |במה רשויות       |                  |
|המקומית שיבואו מקרב חברי המועצות של הרשויות המקומיות שבאותו                            |                 |                  |
|מרחב תכנון.                                                                            |                 |                  |
|(ב) השר יקבע את מספר הנציגים של כל רשות מקומית בועדה                                   |                 |                  |
|המקומית באופן שישקף, ככל האפשר, את היחס המספרי של התושבים                              |                 |                  |
|בכל אחת מהרשויות.                                                                      |                 |                  |
|(ג) על ועדה מקומית לפי סעיף זה יחולו הוראות סעיף 18 בשינויים                           |                 |                  |
|המתחייבים."                                                                            |                 |                  |

|דברי הסבר           |

|בהתאם לחוק התכנון והבניה, התשכ"ה-1965,                       |
|רשאי שר הפנים למנות ועדה מקומית הכוללת יותר                  |
|מרשות מקומית אחת. בדרך כלל מאוחדים, בדרך זו,                 |
|ישובים קטנים למרחב תכנון מקומי אחד.                          |
|במצב זה, לא חל סעיף 18 לחוק התכנון והבניה,                   |
|התשכ"ה-1965, הקובע כי מועצת הרשות המקומית                    |
|תהיה גם הועדה המקומית של אותו מרחב תכנון. סעיף               |
|18 נועד לתת ביטוי בועדה המקומית לכל הסיעות                   |
|המיוצגות במועצת הרשות המקומית. ועדה הממונה על                |

|ידי שר הפנים כאמור מתמנית, לעתים, תוך סטיה؀ࠂࠐࠒࠔ מיחסי      |
|הכוחות שנקבעו בהליך דמוקרטי.                               |
|לכן מוצע, שכאשר מדובר במספר רשויות מקומיות                 |
|יהיו נציגי הרשויות והם בלבד, הועדה המקומית. שר             |
|הפנים יקבע את ייצוג הרשויות בועדה המקומית באופן            |
|יחסי למספר התושבים שבבל רשות.                              |
|מן הראוי שגם ועדות מקומיות ''מרחביות" יהיו                 |
|כמו ועדות מקומיות "רגילות", דהיינו, מאויישות על-ידי        |
|נציגי השלטון המקומי.                                       |
|חברי הכנסת: גדליה גל, אברהם פורז                           |
