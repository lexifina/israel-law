|מתפרסמת בזה הצעת חוק מטעם הממשלה:                      |

|הצעת חוק יישום חוזה השלום בין מדינת ישראל לבין הממלכה                                            |[944]                  |
|הירדנית ההאשמית, התשנ"ה-1995                                                                     |                       |

|ו. חוק זה מטרתו ליישם את חוזה השלום, שנחתם בין מדינת ישראל לבין הממלכה                                       |מטרת החוק            |
|הירדנית ההאשמית ביום כ"א בחשון התשנ"ה (26 באוקטובר 1994) והמסמכים שנלוו אליוי                                |                     |
|(להלן - חוזה השלום).                                                                                         |                     |
|2. רואים את חוזה השלום כבר-תוקף לכל מטרותיו.                                                                 |תוקפו של             |
|                                                                                                             |חוזה השלום           |
|3. (א) באזורים שתחום הממלכה הירדנית ההאשמית (להלן - ירדן) המתוארים                                           |הרין באזורים         |
|בתוספת IV ובתוספת V לנספח 1 לחוזה השלום (להלן - האזורים), ואשר נקבע לגביהם                                   |שבתחום ירדן          |
|משטר מיוחד, כמפורט בסעיף 3 ובנספחים 1(ב) ו-1(ג) לחוזה השלום, יחולו דיני ישראל על                             |שהוחל עליהם          |
|מעשה, מחדל או פעולה אחרת, שעשה תושב ישראל, לרבות תאגיד, או אדם אחר שנכנס                                     |משטר מיוחד           |
|לאזורים מתחום ישראל, והבל בהתאם לאמור בחוזה השלום.                                                           |                     |
|(ב) למשטרת ישראל יהיו באזורים, לגבי מי שנזכר בסעיף קטן (א), כל הסמכויות                                      |                     |
|הנתונות לה על פי דין, לרבות לצורך עריכת פעולות חקירה או מעצר.                                                |                     |
|(ג) כל רשות המוסמכת על פי דין בישראל, רשאית להפעיל באזורים את סמכותה                                         |                     |
|לגבי מי שנזכר בסעיף קטן (א).                                                                                 |                     |
|(ד) על אף האמור בכל דין, רשאי שר הפנים לקבוע הוראות בכל הנוגע ליציאה                                         |                     |
|מישראל לאזורים ולכניסה מהאזורים לישראל.                                                                      |                     |
|(ה) על אף האמור בסעיף קטן (א), לא יעביר אדם זכות במקרקעין באזורים למי                                        |                     |
|שאינו אזרח או תושב ישראל, אלא אם כן קיבל היתר לכך מהרשויות המוסמכות בירדן,                                   |                     |
|ובדרך שתיקבע.                                                                                                |                     |
|(ו) הוראותיהם של כל חוק של מסים, כמשמעותו בחוק לתיקון דיני מסים (חילופי                                      |                     |
|ידיעות בין רשויות המס), התשכ"ז-1967 2, ושל החוקים המפורטים בתוספת, יחולו על                                  |                     |
|פעילות באזורים לגבי מי שנזכר בסעיף קטן (א), כאילו נעשתה בישראל; שר האוצר רשאי,                               |                     |
|באישור ועדת הכספים של הכנסת, לקבוע סוגי פעולות, עוסקים, נישומים או הכנסות,                                   |                     |
|שלגביהם לא יחולו ההוראות האמורות, כולן או מקצתן, או שיחולו בסייגים ובתיאומים; שר                             |                     |
|האוצר רשאי בצו באישור כאמור, לשנות את התוספת.                                                                |                     |

|הצעה זו באה למלא אחר אותה התחייבות.                           |
