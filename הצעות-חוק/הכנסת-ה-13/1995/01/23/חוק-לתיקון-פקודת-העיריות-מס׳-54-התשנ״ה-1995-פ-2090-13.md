|(1) בסעיף קטן (ב), במקום "בהחלטה ברוב חבריה'' יבוא ''בהחלטת שני שלישים                                    |                       |
|מחבריה", והסיפה המתחילה במלים "היה מספר התושבים'' - תימחק;                                                |                       |
|(2) אחרי סעיף קטן (ב) יבוא:                                                                               |                       |
|"(ג) לא ימונה ולא יכהן אדם במבקר עיריה אלא אם כן נתקיימו בו כל                                            |                       |
|אלה:                                                                                                      |                       |
|(ו) הוא יחיד;                                                                                             |                       |
|(2) הוא תושב ישראל;                                                                                       |                       |
|(3) הוא לא הורשע בעבירה שיש עמה קלון;                                                                     |                       |
|(4) הוא בעל תואר אקדמי מאת מוסד להשכלה גבוהה בישראל או מוסד                                               |                       |
|להשכלה גבוהה בחוץ-לארץ שהכיר בו לענין זה מוסד להשכלה גבוהה                                                |                       |
|בישראל, או שהוא עורך דין או רואה חשבון."                                                                  |                       |
|2. אחרי סעיף 167 לפקודה יבוא:                                                                             |הוספת סעיף 167 א       |
|167א. (א) נראה לממונה כי המועצה אינה ממנה מבקר, רשאי הוא                                  |"מועצה שלא     |                       |
|לדרוש ממנה בצו כי תמנה מבקר, באמור בסעיף 167, תוך הזמן הנקוב                              |מינתה מבקר     |                       |
|בצו.                                                                                      |               |                       |

|דברי הסבר           |

|סעיף 167(ב) לפקודת העיריות (להלן -              |סעיף ו       |
|הפקודה), קובע לאמור:                            |             |
|"מינוי פקידים                                                  |
|167. (א) ...                                                   |
|(ב) המועצה, בהחלטה ברוב חבריה, תמנה                            |
|לעיריה מבקר במשרה מלאה; היה מספר התושבים פחות                  |
|מ-30,000, רשאי שר הפנים לאשר שמבקר העיריה יכהן                 |
|במשרה חלקית שלא תפחת ממחצית המשרה, בתנאי                       |
|שהשלמת משרתו לא תהיה אלא בעבודת ביקורת                         |
|ברשות מקומית אחרת, ואף זאת באישור שר הפנים.''                  |
|מוצע לקבוע שהרוב הדרוש למינוי יהיה שני                         |
|שלישים מחברי המועצה.                                           |

|כמו כן מינוי מבקר לעיריה בהיקף של חצי משרה,                   |
|אין בו כדי להבטיח ישום הביקורת כנדרש בחוק. מוצע               |
|איפוא למחוק את ההוראה המאפשרת מינוי כזה. תנאי                 |
|הכשירות באים להבטיח שימונה אדם שיש לו השכלה                   |
|המתאימה לתפקיד המבקר. כאשר ההצעה מבוססת על                    |
|חלק מדרישות הכשירות המנויות בסעיף 3 לחוק                      |
|הביקורת הפנימית, התשנ"ב-,1992, בשינויים                       |
|המתאימים.                                                     |
|מטרת התיקון המוצע בסעיף 2 להצעת                  |סעיף 2      |
|החוק היא למנוע מצב שבו אין מבקר                  |            |
|לעיריה כיון שמועצת העיריה לא מינתה מבקר מסיבה                 |
|כלשהי. במקרה כזה מוצע להקנות לממונה על המחוז                  |
|את הסמכות למנות מבקר.                                         |
