|9411]      |הצעת חוק הרשויות המקומיות (יועץ לעניני מעמד האשה),                                                 |
|           |התשנ"ה-1995*                                                                                       |

|הגדרות          |1. בחוק זה -                                                                                             |
|                |"השר" - שר הפנים;                                                                                        |
|                |"רשות מקומית'' - עיריה או מועצה מקומית;                                                                  |
|                |"יועץ לעניני מעמד האשה" - מי שנתמנה לפי חוק זה להיות יועץ לעניני מעמד האשה.                              |
|מינוי יועץ      |2. (א) ראש רשות מקומית חייב למנות יועץ לעניני מעמד האשה, שיפעל לתפקוד                                    |
|                |נאות ופונקציונלי של הרשות בתחומים הקשורים לנשים בקהילה.                                                  |
|                |(ב) היועץ לעניני מעמד האשה יהיה עובד הרשות המקומית ויחולו על מינויו                                      |
|                |ועבודתו ההוראות החלות על עובדי אותה רשות ככל שאינן סותרות הוראות חוק זה; שכרו                            |
|                |ישולם מקופת הרשות המקומית בלבד.                                                                          |

|דברי הסבר                 |

|בפקודת העיריות ובפקודת המועצות המקומיות                     |
|נקבעו כמה משרות שחובה על הרשויות המקומיות                   |
|לקיימן. מוצע לחייב את הרשויות המקומיות לקבוע גם             |
|משרת יועץ ראש הרשות לעניני מעמד חאשה, שתפקידו               |
|לפעול לתפקוד נאות של הרשות בתחומים הקשורים                  |
|לנשים בקהילה.                                               |

|תחומים רבים ברשות המקומית נוגעים לנשים                           |
|ובדרך כלל דווקא קולן לא נשמע. היועץ לעניני נשים                  |
|ישמש פה לנשים ברשות המקומית. הוא יקח חלק                         |
|בישיבות מועצת הרשות וועדותיה ויחווה דעתו בכל                     |
|ענין הנוגע למעמד האשה. התפקיד חיוני במיוחד לנוכח                 |
|התרבות מקרי האלימות והאפליה כלפי נשים.                           |

|* הצעת חוק מס' אתע'ז; הועברה לועדה ביום ו' בחשון התשנ"ה (11 באוקטובר 1994).              |

|(ג) על אף האמור בכל דין, תנאי העסקתו של היועץ לעניני מעמד האשה ייקבעו                                         |תנאי כשירות        |
|בחוזה מיוחד עמו, כפי שיאושר בידי מי שהשר מינה כראש מינהל שירות העובדים                                        |                   |
|ברשויות המקומיות.                                                                                             |                   |
|(ד) נתפנתה משרת היועץ לעניני מעמד האשה, וראש הרשות המקומית לא מינה                                            |                   |
|יועץ לעניני מעמד האשה תוך שלושה חודשים, ימנה השר יועץ לעניני מעמד האשה                                        |                   |
|לרשות המקומית.                                                                                                |                   |
|3. כשיר להיות יועץ לעניני מעמד האשה מי שנתמלאו בו התנאים שהשר קבע                                             |                   |
|בתקנות.                                                                                                       |                   |
|4. (א) היועץ לעניני מעמד האשה כפוף במישרין לראש הרשות המקומית ולו                                             |כפיפות וסמכות      |
|בלבד.                                                                                                         |                   |
|(ב) בתחום הסמכויות שהוענקו ליועץ לעניני מעמד האשה על פי דין, יפעל היועץ                                       |                   |
|אך ורק על פי הוראות הדין.                                                                                     |                   |
|5. (א) היועץ לעניני מעמד האשה יוזמן לכל ישיבה של מועצת ؀ࠂࠎࠐࠔࠚࠜࠞהרשות המקומית ושל                              |הזמנות חובה        |
|כל ועדה מועדותיה.                                                                                             |                   |
|(ב) נכח היועץ לעניני מעמד האשה בישיבה שהוזמן אליה לפי סעיף זה, תינתן לו                                       |                   |
|הזדמנות להשמיע חוות דעתו לפני קבלת כל החלטה שיש לה נגיעה לענינו.                                              |                   |
|(ג) היועץ לעניני מעמד האשה יהיה רשאי להיות מיוצג בישיבות כאמור בסעיף זה                                       |                   |
|על ידי עובד הרשות המקומית שהוא קבע לענין זה.                                                                  |                   |
|6. (א) לא יפוטר יועץ לעניני מעמד האשה אלא על פי החלטת מועצת הרשות                                             |פיטורי יועץ        |
|המקומית ברוב של שני שלישים מחבריה, ולאחר שההחלטה אושרה בידי ועדה מקצועית                                      |                   |
|שהשר ימנה לצורך סעיף זה, הועדה תהיה מורכבת מנציג שר הפנים, שר העבודה והרווחה                                  |                   |
|ושר המשפטים.                                                                                                  |                   |
|(ב) החלטת המועצה בדבר פיטורי יועץ לעניני מעמד האשה לא תתקבל אלא                                               |                   |
|בישיבת מועצה שזומנה במיוחד לענין זה, ולאחר שניתנה הודעה כדין לכל חברי המועצה                                  |                   |
|שדבר הפיטורים יידון באותה ישיבה וניתנה ליועץ לעניני מעמד האשה הזדמנות להשמיע                                  |                   |
|לפני המועצה את טענותיו בענין הפיטורים.                                                                        |                   |
|(ג) הוראות סעיף זה לא יחולו על היועץ לעניני מעמד האשה בתקופת שנת עבודתו                                       |                   |
|הראשונה ברשות המקומית, בתקופה זאת רשאי ראש הרשות המקומית לפטר את היועץ                                        |                   |
|לעניני מעמד האשה בהודעה מוקדמת של שלושים ימים.                                                                |                   |
|(ד) האמור בסעיפים קטנים (א) עד (ג) אינו בא לגרוע מסמכותו של בית הדין                                          |                   |
|למשמעת לפי חוק הרשויות המקומיות (משמעת), התשל"ח-,1978 1 לפסוק בדבר פיטורים של                                 |                   |
|יועץ לעניני מעמד האשה בשל עבירת משמעת כמשמעותה בחוק האמור.                                                    |                   |
|7. שר הפנים ממונה על ביצוע חוק זה והוא רשאי להתקין תקנות בכל ענין הנוגע                                       |ביצוע ותקנות       |
|לביצועו.                                                                                                      |                   |
|8. 30 ימים מיום תחילתו של חוק זה ימנה ראש הרשות המקומית יועץ לעניני מעמד                                      |תחילה              |
|האשה; לא ימנה יועץ לעניני מעמד האשה כאמור, יחולו הוראות סעיף 2(ד).                                            |                   |
