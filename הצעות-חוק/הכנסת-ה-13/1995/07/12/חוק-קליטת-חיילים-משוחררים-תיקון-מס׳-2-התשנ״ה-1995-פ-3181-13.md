|מתפרסמת בזה הצעת חוק של חבר הכנסת מטעם ועדת העבודה והרווחה של הכנסת:                             |

|הצעת חוק קליטת חיילים משוחררים (תיקון) (שינוי סכום הפקדון                                           |
|וסכום המענק), התשנ"ה-995 1                                                                          |

|ו. בסעיף 9(א) לחוק קליטת חיילים משוחררים, התשנ"ד-1994 1(להלן - החוק העיקרי),                                  |תיקון סעיף 9     |
|במקום "290 שקלים חרשים" יבוא "270 שקלים חדשים", ובמקום "340 שקלים חדשים" יבוא                                 |                 |
|"320 שקלים חדשים",                                                                                            |                 |
|2. בסעיף 10 לחוק העיקרי, במקום "50 שקלים חדשים" יבוא '70 שקלים חדשים"                                         |תיקון סעיף 0ו    |
|3. בסעיף 22(ג) לחוק העיקרי, במקום פסקה (2) יבוא:                                                              |תיקון סעיף 22    |
|"(2) אם תקופת שירותו הסדיר, החל ביום הקובע, היתה יותר מ-12 חודשים, יהיה                                       |                 |
|זכאי להטבות לפי חוק זה בשינוי הבא:                                                                            |                 |
|על אף הוראות סעיף 9(א), תוך חודש מיום שסיים את שירותו הסדיר תזקוף                                             |                 |
|הקרן לזכות הפיקדון סכום השווה ל-340 שקלים חרשים כפול מספר החודשים                                             |                 |
|השלמים ששירת החייל בשירות סדיר, החל ביום הקובע. פחות סכום המענק                                               |                 |
|שלו הוא זכאי על פי סעיף זה.                                                                                   |                 |
|(3) על אף הוראות סעיף 0ו, תוך חודשיים מיום סיום השירות הסדיר תשלם הקרן                                        |                 |
|לחייל משוחרר סכום השווה ל-70 שקלים חדשים בפול מספר החודשים השלמים                                             |                 |
|ששירת בשירות סדיר לרבות לפני היום הקובע."                                                                     |                 |
|4. הוראות החוק העיקרי, בפי שתוקנו בחוק זה, יחולו לגבי חייל משוחרר שסיים את                                    |תחולה            |
|שירותו הסדיר ביום כ"ט בטבת התשנ"ה (ו בינואר 1995) או לאחריו, ובלבד שהתוספת                                    |                 |
|למענק השחרור על פי חוק זה לא תהא גבוהה מיתרת זכות פקדונו.                                                     |                 |
