|מתפרסמת בזה הצעת חוק של חבר הכנסת מטעם וערת הפנים ואיכות הסביבה של הכנסת:                                  |

|הצעת חוק הרשויות המקומיות (בחירת ראש הרשות וסגניו וכהונתם)                                          |
|(תיקון מס' 14) (פטירה או התפטרות), התשנ"ה-1995*                                                     |

|1. בסעיף 6 לחוק הרשויות המקומיות (בחירת ראש הרשות וסגניו וכהונתם),                                         |תיקון סעיף 6          |
|התשל"ה-1975 1 (להלן - החוק העיקרי) -                                                                       |                      |
|(1) בסעיף קטן (א), המילים "נפטר או'' - יימחקו;                                                             |                      |
|(2) בסעיפים קטנים (ב) ו-(ג), במקום "לפי סעיף זה" יבוא "לפי סעיף קטן (א)";                                  |                      |
|(3) אחרי סעיף קטן (ג) יבוא:                                                                                |                      |
|"(ד) נפטר מועמד לראש הרשות, רשאי מי שהציע את מועמדותו, בכפוף                                               |                      |
|להוראות סעיף קטן (ה), לא יאוחר מהיום העשירי שלאחר פטירת המועמד,                                            |                      |
|להציע מועמד אחר במקומו (להלן - הצעת מועמד).                                                                |                      |
|(ה) הוגשה הצעת מועמד בידי קבוצת בוחרים, רשאים כל יתר המועמדים                                              |                      |
|הכלולים ברשימת המועמדים למועצה שבראשה עמד המועמד שנפטר להציע                                               |                      |
|מועמד כאמור בסעיפים קטנים (ד) ו-(ו).                                                                       |                      |
|(ו) מועמד שהוצע לפי סעיף קטן (ד) יהיה אזרח ישראלי הזכאי להיבחר כחבר                                        |                      |
|המועצה, ואינו חייב להיות כלול ברשימת מועמדים כלשהי למועצה.                                                 |                      |
|(ז) חובת ההודעה לפי סעיפים 41 ו-42 לחוק הבחירות לא תחול על מועמד                                           |                      |
|שהוצע לפי סעיפים קטנים (ד) או (ה), אם מועמד זה כלול ברשימת מועמדים                                         |                      |
|שאושרה.                                                                                                    |                      |
|(ח) מועמד שהוצע לפי סעיפים קטנים (ד) או (ה) רואים אותו לכל דבר כראשון                                      |                      |
|ברשימת המועמדים שבה היה כלול המועמד שנפטר, על אף האמור בסעיף                                               |                      |
|ו4א(ב) לחוק הבחירות.                                                                                       |                      |
|(ט) הוצע מועמד במועד האמור בסעיפים קטנים (ד) או (ה) יתקיימו הבחירות                                        |                      |
|למועצה ולראש ؀ࠂࠒࠔࠖࠤהרשות ביום ג' הראשון שלאחר היום ה-ג3 שלאחר הגשת                                         |                      |
|הצעת המועמד; לא הוצע מועמד במועד האמור בסעיף קטן (ד) לא יידחו                                              |                      |
|הבחירות.                                                                                                   |                      |
|(י) שר הפנים יקבע בתקנות טפסים להגשת הצעת מועמד לפי סעיף זה.                                               |                      |
|2. סעיף 10א לחוק העיקרי - יימחק.                                                                           |ביטול סעיף 010        |

|דברי הסבר             |

|מוצע למנוע אפשרות שמועמד יזכה ליתרון                         |
|משמעותי ומכריע בבחירות לראש הרשות על רקע                     |
|פטירת מתחרהו היחיד והעיקרי. במקרה כזה, צריך                  |
|להעניק שהות מספקת למתחרים אפשריים להתארגן                    |

|מחדש ולהעמיד מועמד אחר כנגד מי שעלול היה                    |
|להיוותר כמועמד יחיד ולהיבחר בלי התמודדות                    |
|ממשית.                                                      |
|חבר הכנסת דוד מגן                                           |
