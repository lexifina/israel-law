|מתפרסמת בזה הצעת חוק של חברי הכנסת מטעם ועדת הפנים ואיכות הסביבה של הכנסת:                                  |

|הצעת חוק לתיקון פקודת העיריות (מס' 56) (ועדת הנחות),                                |
|התשנ"ה-1995*                                                                        |

|1. אחרי סעיף 49וג לפקודת העיריות [נוסח חדש]1, יבוא:                                                           |הוספת סעיף 149ד      |
|149ד. (א) המועצה תבחר מבין חבריה ועדת הנחות שתפקידה לדון                                      |'ועדת הנחות    |                     |
|במתן הנחות למחזיקים בנכס שהם מבקשים נזקקים ולמחזיקים שהם                                      |               |                     |
|הבעל הראשון של בנין חדש ריק, שמיום שהסתיימה בנייתו והוא ראוי                                  |               |                     |
|לשימוש, אין משתמשים בו במשך תקופה מסויימת, הכל כפי שייקבע                                     |               |                     |
|בתקנות.                                                                                       |               |                     |
|(ב) חברי ועדת ההנחות יהיו -                                                                   |               |                     |
|(1) שלושה חברי המועצה אשר אחד מהם לפחות חבר בסיעה                                             |               |                     |
|שאינה מיוצגת בועדת הנהלה;                                                                     |               |                     |
|(2) עובדי העיריה הבאים - הגזבר, היועץ המשפטי, מנהל                                            |               |                     |
|מחלקת הרווחה ומנהל מחלקת הגביה.                                                               |               |                     |
|(ג) המועצה תמנה מבין חבריה שמונו לועדה, את יושב ראש                                           |               |                     |
|הועדה וממלא מקומו.                                                                            |               |                     |
|(ד) מנין חוקי בישיבות הועדה יהיה יושב ראש הועדה או ממלא                                       |               |                     |
|מקומו, היועץ המשפטי והגזבר."                                                                  |               |                     |

|דברי הסבר                  |

|מבקרת המרינה, מצביעה בדו"ח על הביקורת                           |
|בשלטון המקומי, התשנ"ג-1992, על אי סדרים בנהלי                   |
|הענקת הנחות לארנונה. כל רשות קבעה הנחות, על פי                  |
|ראות עיניה. כתוצאה מכך נקלעו רשויות מקומיות רבות                |
|؀ࠂࠒࠔࠖࠤלגרעונות כספיים כבדים. מוצע שההנחות יינתנו                |
|לנזקקים ולמחזיקים שהם בעלי נכס שנבנה אך אינו                    |
|מאוכלס ומשום כך אינו מניב הכנסה.                                |
|בתקנות הסדרים במשק המדינה (הנחה מארנונה),                       |
|התשנ"ג-1993 (ק"ת התשנ"ג, עמ' 540), קבע שר הפנים                 |
|את הרכב ועדת ההנחות. תקנה 6(א)(1) קובעת כי בועדה                |

|יכהנו: "שלושה חברי מועצה שאחד לפחות אינו חבר                 |
|ועדת ההנהלה." אולם סיעתו יכלה להיות מיוצגת                   |
|בהנהלה.                                                      |
|מוצע לעגן בחוק את פעילות ועדת ההנחות                         |
|ולקבוע בו גם את הרכב חבריה ובכך להבטיח את יצוגה              |
|של האופוזיציה בועדה חשובה זאת.                               |
|חברי הכנסת: דוד מגן, יהושע מצא, אברהם                        |
|הירשזון, שאול עמוד, חיים דיין                                |
