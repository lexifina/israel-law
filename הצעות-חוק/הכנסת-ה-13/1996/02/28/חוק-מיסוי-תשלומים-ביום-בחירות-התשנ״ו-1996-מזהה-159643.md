|(ו) מפלגה כהגדרתה בסעיף ו לחוק המפלגות;                                                                   |                     |
|(2) ישות שעל פי דין ממונה על ביצוע בחירות;                                                                |                     |

|?'תשלום" - תמורה, בכסף או בשווה כסף, שאדם מקבל (להלן - המקבל), מאת המשלם או                               |                     |
|מטעמו, בער עבודה או שירות בשל הבחירות שנעשו ביום הבחירות, בעד הסעת נוסעים                                 |                     |
|או הובלה, או החזר הוצאות בשל הבחירות, שבוצעו או הוצאו, לפי הענין, ביום                                    |                     |

|נותן לו שירות, לפי הענין, ביום הבחירות בלבד.                                                              |                     |
