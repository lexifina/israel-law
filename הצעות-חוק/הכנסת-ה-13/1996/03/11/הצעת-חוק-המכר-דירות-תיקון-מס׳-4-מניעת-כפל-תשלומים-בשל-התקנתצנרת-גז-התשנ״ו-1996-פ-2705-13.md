|מתפרסמת בזה הצעת חוק של חבר הכנסת מטעם ועדת הכלכלה של הכנסת:                         |

|הצעת חוק המכר (דירות) (תיקון מס' 4) (מניעת כפל תשלומים בשל התקנת                                         |
|צנרת גז), התשנ"ו-1996*                                                                                   |

|1. בחוק המכר (דירות), התשל"ג-1973 1, אחרי סעיף 6 יבוא:                                                    |הוספת סעיף 6א       |
|6א. (א) בסעיף זה -                                                                       |התקנת צנרת      |                    |
|"חברת הגז'' - החברה המתקינה את צנרת הגז;                                                 |ג! - מניעת      |                    |
|"ציוד מושאל'' - ציוד שעל פי חוזה בין חברת הגז לבין הקונה מצוי                            |כפל תשלומים     |                    |
|בבעלות חברת הגז ומושאל לו לצורך אספקת הגז או לצורך השימוש                                |                |                    |
|בו, לרבות מכל הגז;                                                                       |                |                    |
|"צנרת גז'' - צנרת על אבזריה ולמעט ציוד מושאל.                                            |                |                    |
|(ב) חברת הגז אינה רשאית לגבות מן הקונה תשלום נוסף בשל                                    |                |                    |
|התקנת צנרת גז כאשר מחיר ההתקנה כלול במחיר הדירה.                                         |                |                    |
|(ג) לא נבלל מחיר התקנת צנרת גז במחיר הדירה, ישלם הקונה את                                |                |                    |
|דמי התקנתה לחברת הגז בלבד.''                                                             |                |                    |
