|מתפרסמת בזה הצעת חוק של חברי הכנסת מטעם ועדת העבודה והרווחה של הכנסת:                          |

|הצעת חוק הגנה על עובדים (חשיפת עבירות על החוק ופגיעה בטוהר המידות                                       |
|ובמינהל התקין), התשנ"ו-1996*                                                                            |

|ו. בחוק זה -                                                                                                |הגדרות              |
|''גוף ציבורי'' -                                                                                            |                    |
|(1) גוף מבוקר כמשמעותו בסעיף 9 לחוק מבקר המדינה, התשי"ח-1958 [נוסח                                          |                    |
|משולב]1;                                                                                                    |                    |
|(2) תאגיד שהוקם בחוק;                                                                                       |                    |
|(5) תאגיד שניהול עסקיו נתון לפיקוח או לביקורת על פי חוק שנתייחד לעסקים                                      |                    |
|מהסוג שהוא מנהל;                                                                                            |                    |
|(4) תאגיד המספק שירות לציבור.                                                                               |                    |
|''תלונה'' - תלונה בכתב של עובד נגד מעבידו או נגד עובד אחר שהוגשה לרשות מוסמכת                               |                    |
|על אחת מאלה:                                                                                                |                    |
|(ו) הפרת חיקוק בקשר לעבודה;                                                                                 |                    |
|(2) פגיעה בטוהר המידות או במינהל התקין, בגוף ציבורי, בקשר לעבודה.                                           |                    |
|2. לא יפגע מעביד בתנאי עבודתו של עובד ולא יפטרו בשל כך בלבד שהגיש תלונה או                                  |הגנה על             |
|שסייע לעובד אחר בקשר להגשת תלונה; לענין זה, יראו פגיעה שנעשתה בידי הממונה על                                |מתלונן              |
|העובד כפגיעה שנעשתה בידי המעביד.                                                                            |                    |
|3. לבית הדין לעבודה, תהא סמכות ייחודית לדון בהליך בשל הפרת חוק זה והוא                                      |סמכות שיפוט         |
|רשאי -                                                                                                      |ותרופות             |
|(ו) לפסוק פיצויים, אף אם לא נגרם נזק של ממון, בשיעור שייראה לו בנסיבות                                      |                    |
|הענין;                                                                                                      |                    |
|(2) לתת צו מניעה או צו עשה, לרבות צו המבטל פיטורין, אם ראה שמתן פיצויים                                     |                    |
|בלבד לא יהא צודק; בבואו לתת צו כאמור יביא בית הדין בחשבון, בין היתר, את                                     |                    |

|דברי הסבר             |

|לא אחת קורה שעובדים שהגישו תלונה על                           |
|מעשים בלתי תקינים במקום העבודה מוצאים את                      |
|עצמם חשופים להתנכלות ורדיפה מצד המעבידים؀ࠂࠒࠔ࠘ࠜࠞࠠ,             |
|הממונים והחברים לעבודה. לעתים אף מפטרים אותם                  |
|מעבודתם.                                                      |

|מוצע על כן להגן בחוק על עובדים במצבים                       |
|האמורים, בדרך של הקניית סמכות מיוחדת לבית הדין              |
|לעבודה, לפסוק פיצויים או לתת צו מניעה או אף צו              |
|עשה כנגד פגיעה בתנאי עבודה או פיטורין.                      |
