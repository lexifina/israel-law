|הצעת חוק זכויות יוצרים ומבצעים - קלטות (תיקוני חקיקה),                              |
|התשנ"ו-1996*                                                                        |

|תיקון פקודת     |1. בפקודת זכות יוצרים 1, אחרי סעיף 3א יבוא:                                                               |
|זכות יוצרים     |                                                                                                          |
|                |3ב. בסעיפים 3ג עד גו -                                                                |'הגדרות            |
|                |"טביעה" - שימור של יצירה בכל אמצעי המאפשר לראות, לשמוע                                |                   |
|                |או לשעתק את היצירה;                                                                   |                   |
|                |"קלטת'' - התקן שאין עליו טביעה ושניתן לטבוע בו טביעה קולית או                         |                   |
|                |טביעה ויזואלית, למעט התקן המיועד לשימוש במחשב;                                        |                   |
|                |"שיעתוק" - העתק של טביעה או של חלקה המהותי;                                           |                   |
|                |"חברת התמלוגים" - תאגיד, שאישר לענין זה שר החינוך התרבות                              |                   |
|                |והספורט, המייצג את המספר הגדול ביותר של בעלי זכויות                                   |                   |
|                |יוצרים או בעלי זכויות מבצעים, שהינם אזרחים ישראלים                                    |                   |
|                |ותושבי ישראל;                                                                         |                   |
|                |"זכות יוצרים'' - כמשמעותה בסעיף 1(2) לחוק זכות יוצרים, 1911 2;                        |                   |

|דברי הסבר           |

|זה מכבר הוכרו זכויותיהם של יוצרים ומבצעים                  |
|כתורמים לערכה הרוחני והחומרי של יצירה ספרותית              |
|או אמנותית.                                                |
|עם התפתחות הטכנולוגיה ומגוון האפשרויות                     |
|להטבעה, להקלטה, לשכפול, ולשיעתוק של יצירות אף              |
|באמצעים ביתיים פשוטים, נפגעות זכויותיהם של                 |
|היוצרים והמבצעים.                                          |
|חוק זה בא לפצות את היוצרים והמבצעים על                     |
|פגיעה זו, ולאפשר הגנה ראויה על זכויותיהם, תוך              |
|ראייה של חשיבות תרומתם לתוצר האמנותי.                      |
|לכן, מוצע להכניס בפקודת זכות יוצרים (להלן -                |
|הפקודה), הגדרות של ''טביעה", "קלטת" ו"שיעתוק''. עוד        |
|הוגדרה ''חברת התמלוגים" אשר תוקם על מנת לייצג              |

|את בעלי זכויות היוצרים והמבצעים (סעיף 3ב המוצע               |
|לפקודה).                                                     |
|עוד מוצע שלא יראו טביעה ושיעתוק לשיטה*                       |
|פרטי או ביתי כהפרת זכויות יוצרים ומבצעים (סעיף גג            |
|המוצע לפקודה).                                               |
|אשר על בן, מוצע לפצות את בעלי זכויות אלה.                    |
|בדרך של פיצוי מאת הממשלה לחברת התמלוגים אשר                  |
|תחלק את התמלוגים לבעלי הזכויות.                              |
|נקבעה תקרה של 3 מליון שקלים חדשים בשנה                       |
|עבור פיצוי זה (סעיף 3ד(ג) המוצע לפקודה).                     |
|עוד מוצע להסמיך את בית המשפט המחוזי לספל                     |
|בחילוקי דעות שיתעוררו ואת שר החינוך התרבות                   |
|והספורט להתקין תקנות.                                        |

|3ג. לא תהיה זו הפרה של ؀ࠂࠐࠒࠖࠜࠞࠠזכויות יוצרים ומבצעים לטבוע או לשעתק                        |שימוש פרטי          |
|יצירה על גבי קלטת לשם שימוש פרטי או ביתי בלבד.                                             |וביתי               |
|3ד. (א) הממשלה תפצה את בעלי זכויות היוצרים ואת בעלי זכויות                                 |תשלום לבעלי         |
|המבצעים על אובדן הכנסה ופגיעה בזכויות, הנגרמת להם בשל העתקת                                |זכויות יוצרים       |
|קלטות, לשם שימוש פרטי וביתי, שהותרה מכוח סעיף 3ג.                                          |ומבצעים             |
|(ב) הממשלה תעביר לחברת התמלוגים, מדי שנה, סכום כאמור                                       |                    |
|בסעיף קטן (ג); חברת התמלוגים תעביר את הסכום לבעלי זכויות היוצרים                           |                    |
|ולבעלי זכויות המבצעים החברים בה, לפי קריטריונים שיקבע שר החינוך                            |                    |
|התרבות והספורט, בהתייעצות עם שר המשפטים.                                                   |                    |
|(ג) הסכום הכולל שישולם כאמור בסעיף קטן (ב) יהיה בשיעור של                                  |                    |
|5% מהמחיר לצרכן, ללא תשלום מס ערך מוסף של סך כל הקלטות הריקות                              |                    |
|שנמכרו בישראל לשימוש פרטי או ביתי בשנה שקדמה לשנה הנדונה, אך                               |                    |
|לא יותר מ-3 מליון שקלים חדשים בשנה.                                                        |                    |
|(ד) ועדה שתכלול את נציג שר האוצר, נציג שר המשפטים ונציג                                    |                    |
|שר החינוך התרבות והספורט, תקבע את הנתונים הדרושים לצורך סעיף                               |                    |
|קטן (ג).                                                                                   |                    |
|(ה) התקרה הקבועה בסעיף קטן (ג) תתואם מדי שנה בהתאם                                         |                    |
|לשיעור עליית המדד בשנה שחלפה.                                                              |                    |
|3ה. (א) חברת התמלוגים תחלק, בין בל היוצרים והמבצעים הזכאים                                 |חלוקת הגמול         |
|לגמול, את הגמול שקיבלה מהממשלה, לאחר ניכוי הוצאות מינהלה                                   |                    |
|וגבייה.                                                                                    |                    |
|(ב) התעוררו חילוקי דעות לגבי יחס חלוקת הגמול, יכריע בענין                                  |                    |
|בית המשפט המחוזי; לדיון בבית המשפט המחוזי, יוזמנו, בדרך שתיקבע                             |                    |
|בתקנות, חברות תמלוגים, נציג משרד החינוך התרבות והספורט והיוצר או                           |                    |
|המבצע שלגבי גמולו התעוררו חילוקי הדעות, לפי הענין; החלטת בית                               |                    |
|המשפט תחייב את כל חברות התמלוגים ואת כל בעלי זכויות היוצרים                                |                    |
|והמבצעים, אף אם לא היו צד להליך בפני בית המשפט.                                            |                    |
|3ו. שר החינוך התרבות והספורט, בהתייעצות עם שר המשפטים, רשאי                                |תקנות               |
