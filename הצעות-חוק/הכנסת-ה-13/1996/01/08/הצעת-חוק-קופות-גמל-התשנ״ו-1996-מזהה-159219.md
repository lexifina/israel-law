|"קופת גמל" או "קופה" - קרן לתגמולים, לפיצויים או להשתלמות, שאושרה כקופת גמל לפי                                      |             |
|סעיף 6, והמתנהלת בידי חברה מנהלת שאושרה לפי סעיף 4;                                                                  |             |
|"עמית" - מי שרשומים על שמו או עומדים לזכותו כספים בקופת גמל;                                                         |             |
|"תגמולים" - סכום הון שמשלמת קופת גמל לפי תקנותיה, לעמית- שכיר, לעמית-עצמאי או                                        |             |
|לעמית-שיתופי, או לזכאים לבך לאחר מותו של העמית מכספים שהצטברו לזכותו;                                                |             |
|"פיצויים" - סכום הון שמשלם מעביד או שמשלמת קופת גמל לפיצויים כמענק עקב פרישה                                         |             |
|או מוות, לעובד או לשאיריו לאחר מותו;                                                                                 |             |
|"קופת גמל לתגמולים" - קופת גמל שנועדה לצבירת כספים והשקעתם לצורך תשלום                                               |             |
|תגמולים;                                                                                                             |             |
|"קופת גמל המבטיחה תשואה" - כל אחת מקופות הגמל המנויות בתוספת;                                                        |             |
|"קרן השתלמות" - קופת גמל שנועדה לצבירת כספים והשקעתם לצורך חסכון והשתלמות,                                           |             |
|ושהמעביד והעובד מפקידים בה בספים במקביל, למעט קרן השתלמות למורים שצבירת                                              |             |
|הכספים בה מיועדת למימון שנת שבתון;                                                                                   |             |
|"קופת גמל אישית לפיצויים" - קופת גמל שנועדה לצבירת כספים והשקעתם לצורך                                               |             |
|תשלום פיצויים, המתנהלת בחשבונות אישיים על שם העובדים;                                                                |             |
|"קופת גמל מרכזית לפיצויים" - קופת גמל שנועדה לצבירת כספים והשקעתם לצורך                                              |             |
|תשלום פיצויים, שעמיתיה הם מעבידים בלבד;                                                                              |             |
|"קופת גמל לפיצויים" - קופת גמל אישית לפיצויים או קופת גמל מרכזית לפיצויים-,                                          |             |
|"קופה ייעודית" - קופת גמל לתגמולים, לפיצויים או להשתלמות, שההצטרפות אליה                                             |             |
|מוגבלת לפי תקנונה לציבור מסויים בלבד, המתנהלת בידי חברה מנהלת שאושרה לפי                                             |             |
|סעיף 4(ב), ואשר מספר עמיתיה אינו קטן מהמספר שקבע שר האוצר בתקנות; קביעה                                              |             |

|אחרת, אחת או יותר, באופן ששווי נכסי קופות הגמל שבניהול החברה ושבניהול בל אחת                                       |

|(2) ההגבלות על העסקת עובדים, ובין השאר -                      |
