|הצעת חוק לגילוי נגיפי איידס בקטינים, התשנ"ו-1996                              |

|בדיקת איידס            |1. (א) על אף הוראות כל דין, בדיקה לגילוי נגיפי איידס בקטין תיערך לפי בקשת קטין,                             |
|בקטין                  |אף ללא אישור הורהו או אפוטרופסו (להלן - נציגו), ובלבד שהבדיקה תיערך במוסד רפואי                             |
|                       |ששר הבריאות הכיר בצו לצורך זה, ושרופא באותו מוסד אישר בכתב את עריכתה, לאחר                                  |
|                       |שהתקיימו כל אלה:                                                                                            |
|                       |(1) הרופא נתן לקטין הסבר מלא על אופי הבדיקה ומשמעותה, על דרכי                                               |
|                       |ההידבקות בנגיפי איידס ועל הדרכים למנוע הידבקות, ונוכח כי הקטין הבין את                                      |
|                       |ההסבר שנתן לו;                                                                                              |
|                       |(2) הרופא שוחח עם הקטין בדבר האפשרות לקבל את הסכמת נציגו, אך                                                |
|                       |הקטין התנגד לכך;                                                                                            |
|                       |(3) הרופא שוכנע בי, בהתחשב בגיל הקטין, בבגרותו הנפשית וביכולתו לגבש                                         |
|                       |רצון עצמי, מחייבת טובתו את הבדיקה ללא קבלת אישור נציגו.                                                     |
|                       |(ב) לענין אישור רופא לפי סעיף קטן (א), רשאי הרופא להיוועץ במי שהוא כשיר                                     |
|                       |לעבודה סוציאלית, כמשמעותו בסעיף ו לחוק שירותי הסעד, התשי"ח-1958 1 (להלן - כשיר                              |
|                       |לעבודה סוציאלית).                                                                                           |
|                       |(ג) האישור יהיה מנומק.                                                                                      |
|                       |(ד) על אף הוראות סעיף קטן (א), לא תיערך בדיקה לגילוי נגיפי איידס בקטין שטרם                                 |
|                       |מלאו לו ארבע עשרה שנים ללא אישור נציגו, זולת אם הבדיקה אושרה בידי צוות, הבולל                               |
|                       |כשיר לעבודה סוציאלית ורופא (להלן - צוות).                                                                   |
|הודעת תוצאות           |2. (א) תוצאה שלילית של בדיקה לגילוי נגיפי איידס תימסר לקטין בידי אחד מאלה:                                  |
|הבדיקה                 |רופא, אדם הכשיר לעבודה סוציאלית, אח או אחות, ובלבד שעברו הכשרה לענין זה.                                    |

|דברי הסבר          |

|את הבדיקה לבדם או עם בן/בת זוג, מתוך צעד אחראי               |

|בדיקות כאלה אם הורי הקטין או אפוטרופסו לא                    |
