|1. בפקודת בריאות העם, 1940 1, אחרי סעיף 10 יבוא:                                                           |הוספת חלק ג'1      |
|"חלק ג1: איסור קבלת תשלומים                                                               |                 |                   |
|0וא. בחלק זה -                                                                            |הגדרות           |                   |
|"מוסד רפואי ציבורי" - כל אחך מאלה:                                                        |                 |                   |
|(1) מוסד רפואי של המדינה או של רשות מקומית;                                               |                 |                   |
|(2)" מוסד רפואי שהממשלה משתתפת בהנהלתו או שהוא                                            |                 |                   |
|נתמך בידי הממשלה או מוסד אחר של המדינה, במישרין או                                        |                 |                   |
|בעקיפין, בדרך הקצבה, ערבות וכיוצא באלה;                                                   |                 |                   |
|"עובד מוסר רפואי ציבורי" -רופא, אחות, עובר פארה-רפואי, עובד                               |                 |                   |
|מינהלה או עובד אחר, החייבים לתת טיפול רפואי בתוקף תפקידם, וכן                             |                 |                   |
|כל עובד אחר שבתוקף תפקידו קובע או מאשר מועד למתן טיפול                                    |                 |                   |
|רפואי או שקובע או מאשר את נותן הטיפול הרפואי; לענין זה, "טיפול                            |                 |                   |
|רפואי" - לרבות כל שירות אחר שהמוסר נותן למטופלים בו.                                      |                 |                   |
|סוב. עובד מוסד רפואי ציבורי לא ידרוש ולא יקבל, במישרין או בעקיפין,                        |איסור קבלת       |                   |
|תשלום כלשהו, שלא באמצעות המוסד הרפואי הציבורי שבו הוא עובד,                               |תשלומים          |                   |
|או בהסכמתו, בער מתן טיפול רפואי או בעד פעולה כלשהי אחרת                                   |                 |                   |
|שהעובד חייב לעשותם על פי תפקידו; לענין סעיף זה, "תשלום" - כסף,                            |                 |                   |
|שווה כסף, שירות או טובת הנאה אחרת.                                                        |                 |                   |
|סוג. עובד מוסד רפואי ציבורי לא יעדיף, במסגרת עבודתו במוסד                                 |איסור העדפת      |                   |
|הרפואי הציבורי, אדם שהיה או שהוא עדיין בטיפולו בזמן כלשהו                                 |חולים פרטיים     |                   |
|במסגרת פרטית באותו מוסד או בנוסף לעבודתו באותו מוסד.                                      |                 |                   |
|סור. (א) תרומה למוסד רפואי ציבורי תינתן אך ורק באמצעות מנהל                               |תרומות           |                   |
|המוסד או מי שהמנהל הסמיך לכך, בהתאם לנהלים שקבע המנהל;                                    |                 |                   |
|(ב) עובד מוסד רפואי ציבורי לא יבקש ולא יקבל ממטופל, שבו הוא                               |                 |                   |
|מטפל באופן ישיר, תרומה כלשהי עבור המוסד.                                                  |                 |                   |
|(ג) מתן תרומה לפי סעיף ؀ࠂࠒࠔ࠘ࠠࠢࠤ࠲סוד, אין בו כדי להתיר לעובד מוסד                          |                 |                   |
|רפואי לפעול בניגוד להוראות סעיף סוג.                                                      |                 |                   |

|דברי הסבר                 |

|שירות רפואי מועדף לחולה במוסד רפואי ציבורי                    |
|תמורת תשלום לכיסו של העובד במערכת הציבורית                    |
|כרוך בביצוע שורה של עבירות, כגון: העלמת הכנסות,               |
|קבלת שוחד, עושק, מרמה וניצול מיתקני הציבור לטובת              |
|הפרט.                                                         |

|למתן שירות רפואי כאמור גם פן אתי-מוסרי. חולים                 |
|הנזקקים לסעד רפואי מוכנים להשקיע כל שהתבקש                    |
|מהם למען שביב של תקווה או הבטחה להצלת חיים.                   |
|לכן מוצע לקבוע לענין זה עונשים מיוחדים.                       |
