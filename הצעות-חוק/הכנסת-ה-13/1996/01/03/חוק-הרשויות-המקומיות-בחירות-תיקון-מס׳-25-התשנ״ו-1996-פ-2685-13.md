|מתפרסמת בזה הצעת חוק מטעם ועדת הפנים ואיכות הסביבה של הכנסת:                          |

|הצעת חוק הרשויות המקומיות (תיקון מס' 23) (בחירות), התשנ"ו-1996*                                         |

|1. בחוק הרשויות המקומיות (בחירות), התשכ"ה-1965 1 (להלן - החוק העיקרי), בסעיף                             |תיקון סעיף 72        |
|72(א), אחרי פסקה (3) יבוא:                                                                               |                     |
|"(4) שבוחרים שינו מענם לצורך הבחירות לפי הוראות סעיף 85א וכמות בוחרים                                    |                     |
|אלה, שהצביעו, היתה עלולה להשפיע על חלוקת המנדטים או על בחירת ראש                                         |                     |
|הרשות המקומית באותן בחירות.*                                                                             |                     |
|2. בסעיף 73 לחוק העיקרי, אחרי סעיף קטן (א) יבוא:                                                         |תיקון סעיף 73        |
|''(או) היו בכתב הערעור טענות על מעשים שנעשו בניגוד להוראות בסעיפים 85א                                   |                     |
|או 88 וראה בית המשפט כי הוגשה למשטרה קובלנה בשל אותם מעשים ובי נבצר                                      |                     |
|ממנו לפסוק במועד האמור בשל הצורך לשמוע ראיות בטענות לפי הסעיפים                                          |                     |
|האמורים, רשאי בית המשפט לפסוק בערעור תוך שנה מיום הגשתו.'                                                |                     |
|3. אחרי סעיף 85 לחוק העיקרי יבוא:                                                                        |תוספת סעיף 85א       |
|85א. (א) הגורם לשינוי מענו במרשם האוכלוסין מישוב שבו הוא                                   |"שינוי מען   |                     |
|רשום לישוב אחר שבו הוא אינו תושב, ביודעו שהודעת השינוי אינה                                |             |                     |
|נכונה וכתוצאה מהודעה זו הוצא שמו מרשימת בוחרים שבה היה כלול                                |             |                     |
|ונכלל ברשימת בוחרים של אזור קלפי שבתחום הישוב האחר שאיננו                                  |             |                     |
|תושב בו, ובבחירות הסמוכות לאחר שינוי המען, הצביע בישוב שאינו                               |             |                     |
|תושב בו, דינו - מאסר 3 שנים או קנס.                                                        |             |                     |
|(ב) לענין סעיף זה, אין נפקה מינה אם שינוי המען נגרם על דרך                                 |             |                     |
|הודעה, בקשה או ערר לפי סעיפים 40 או 41 לחוק הבחירות לכנסת [נוסח                            |             |                     |
|משולב], התשכ"ט-1969 2, או؀ࠂࠒࠔࠖࠤ לפי סעיף 17 לחוק מרשם האוכלוסין,                           |             |                     |
|התשכ"ה-1965 5."                                                                            |             |                     |

|דברי הסבר                |

|מבוא                                                       |
|בבחירות הכלליות האחרונות לרשויות המקומיות,                 |
|התעוררו בבתי המשפט שתי בעיות. האחת קשורה                   |
|לערעור בחירות בטענות זיוף. התברר כי ברוב המקרים,           |
|לא ניתן יהיה להוכיח טענות אלה במסגרת ערעור על              |
|בחירות בו בית המשפט חייב ליתן פסק דינו תוך 30 יום          |
|מיום הגשתו. הבעיה השניה קשורה לרישום שלא כדין              |
|של בוחרים בישוב שבו אינם תושבים, לצורך הצבעה               |
|בבחירות, במטרה להשפיע על חלוקת המנדטים או על               |
|בחירת ראש הרשות.                                           |

|סעיף 1 מוצע כי שינוי מען כמפורט בפסקה יחיה                   |
|עילת ערעור לבית המשפט המחוזי.                                |
|סעיף 2 מוצע כי פסק דין בעילות זיוף ושינוי מען                |
|יינתן תוך שנח במקום 30 ימים ובלבד                            |
|שהוגשה קובלנה למשטרה בשל המעשים.                             |
|סעיף 3 הסעיף המוצע קובע כי שינוי מען והצבעה                  |
|בבחירות, הוא עבירה פלילית חמורה.                             |
|חבר הכנסת אבנר חי שאקי                                       |
