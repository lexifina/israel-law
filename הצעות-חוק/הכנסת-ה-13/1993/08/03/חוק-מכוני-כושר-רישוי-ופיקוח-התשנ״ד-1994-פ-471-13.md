|הצעת חוק מכוני כושר (רישוי ופיקוח), התשנ"ג-1993 *   [690]                                                   |

|הגדרות            |1. בחוק זה -                                                                                            |
|                  |''מכון כושר" - מקום שבו מתאמנים במכשירים והוא אינו מופעל על ידי אגודת ספורט;                            |
|                  |''מכשיר" " מכשיר המפעיל את השרירים בתנאים של מאמץ גופני;                                                |
|                  |''בעלים" - הבעלים הרשום של מכון הכושר;                                                                  |
|                  |''מדריך'' - בוגר קורס מוכר למדריכי חדר כושר;                                                            |
|                  |''רשיון'' - רשיון הפעלה למכון כושר פרטי;                                                                |
|                  |''מתאמן'' - מי שעושה שימוש במכשירים של מכון הכושר;                                                      |
|                  |''קטין'' - מי שטרם מלאו לו 18 שנה.                                                                      |
|תנאי הפעלה        |2. לא יקבל בעלים רשיון, אלא אם כן התקיימו התנאים הבאים;                                                 |
|                  |(1) מכון הכושר ממוקם באולם מאוורר ונקי;                                                                 |
|                  |(2) המכשירים מוצבים במרחק סביר זה מזה;                                                                  |
|                  |(3) לכל מכשיר מוצמדות, במקום בולט, הוראות היצרן בשפה הידועה למתאמנים,                                   |
|                  |לגבי צורת ההפעלה והמיגבלות לגבי הפעלה בידי קטין;                                                        |
|                  |(4) בידי הבעלים מצויה פוליסת ביטוח בת תוקף, המכסה כל נזק שייגרם למתאמן                                  |
|                  |עקב שימוש במכשירים.                                                                                     |
|חובת נוכחות       |3. בכל העת שמכון הכושר פתוח, יהיה נוכח במקום מדריך, המלמד את דרכי הפעלת המכשירים                        |
|                  |ומשגיח על המתאמנים בהם.                                                                                 |
|חובת בדיקה        |4. מכון כושר יקבל מתאמן רק לאחר שימציא תעודה חתומה בידי רופא המאשרת את כשירותו                          |
|רפואית            |להתאמן במכון כושר.                                                                                      |
|הסכמת הורי        |5. קטין יוכל להתאמן רק לאחר שימציא, נוסף לתעודה הרפואית, גם הסכמה בכתב של הוריו או                      |
|קטין              |אפוטרופסו.                                                                                              |
|סייג              |6. ילד שטרם מלאו לו 14 שנים לא יתאמן במכון כושר.                                                        |
|שטירת הוראות      |7. חוק זה בא להוסיף על הוראת חוק אחרת ולא לגרוע ממנה,                                                   |
|ביצוע             |8 .שר החינוך, ממונה על ביצוע חוק זה ובהתייעצות עם שר הבריאות, יתקין תקנות                               |
|ותקנות؀ࠂࠐࠒࠖࠚࠜࠞ    |לביצועו.                                                                                                |

|דברי הסבר                      |

|הפעלת מכוני הכושר אינה מוסדרת כיום בחוק. לאור                 |
|העובדה שמתאמנים נפגעו מהפעלה לא נכונה של מכשירים              |

|וביניהם בני נוער, מוצע לקבוע בחוק תנאים להפעלת מכון         |
|כושר.                                                       |
