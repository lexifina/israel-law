|מתפרסמת בזה הצעות חוק מטעם הממשלה :                           |

|חוק להארכת תוקף של תקנות-שעת-חירום (אזורי בטחון),                                                         |
|תש''ך-1959                                                                                                |

|1. תקפן של תקנות-שעת-חירום (אזורי בטחון), תש"ט-1919ד, מוארך בזה עד יום י"ב                                          |הארכת תוקף            |
|בטבת תשכ"א (31 בדצמבר 1960).                                                                                        |                      |
|2. שר הבטחון רשאי, בכל עת, לבטל את התקנות האמורות על ידי צו שיפורסם ברשומות.                                        |זבות ביטול            |
|3. תחילתו של חוק זה היא כתום שלושת החדשים הראשונים לתקופת כהונתה של הכנסת                                           |תחילה                 |
|הרביעית.                                                                                                            |                      |

|דברי הסבר                                                                                                         |
|תקנות-שעת-חירום (אזורי בטחון)' תש"ט-1919, שהותקנו על ידי שר הבטחון -                                              |
|תקפן הוארך על ידי הכנסת, אגב שינויים מסויימים בנוסה התקנות עד יום לי בכסלו תש"ך                                   |
|(31 בדצמבר 1959); אולם מכוח סעיף 38 לחוק-יסוד: הכנסת2, מוארך התוקף מעבר למועד זה                                  |
|עד תום שלושת החדשים הראשונים לתקופת כהונתה של הכנסת הרביעית.                                                      |
|הצורך בתקנות הנ"ל בעינו עומד. הממשלה מציעה להאריך את תוקף התקנות עד                                               |
|תום שנת 1900.                                                                                                     |
|וזהו הנוסח של תקנות-שעת-חירום (אזורי בטחון), תש"ט-1949:                                                           |

|1. (א) רצועת אדמה בתוך שטח ישראל ברוחב הניתן להלן מכל נקידה שעל קי גבול שטח                 |"שטח מוגן           |
|ישראל, ולכל אורך קו הגבול, היא שטת מוגן לצורך תקנות אלה:                                    |                    |
|(1) צפונה מקו הרוחכ של 310 - רצועה ברוחב של עשרה קילומטרים;                                 |                    |
|(2) דרומה מקו הרוחב של 310 - רצועה ברוחב של עשרים וחמישה קילומטר.                           |                    |
|(ב) 'ישטח ישראל", בתקנה זו, פירושו השטח שבו חל משפט מדינת ישראל.                            |                    |
|2. (א) שר הבטחון רשאי, מזמן לזמן, בצו בחתימת ידו שיפורסם ברשומות, להכריז שהשטח              |אזורי בטחון         |
|המוגן, או כל הלק ממנו, יהיה אזור בטחון לצורך תקנות אלה,                                     |                    |
|(ב) צו לפי תקנת משנה (א) שניתן אהרי שנכנס לתקפו חוק להארכת תוקף של תקנות-                   |                    |
|שעת-חירום (אזורי בטחון), תש"י-1950 6, יובא בפני הועדה לעניני חוץ ובטחון של הכנסת            |                    |
|תוך עשרה ימים מיום פרסומו ברשומות; והועדה רשאית, על-ידי החלטה שתפורסם ברשומות/              |                    |
|לבטל בכל עת צו כאמור.                                                                       |                    |
|3. תושב קבוע של אזור בטחון הוא, לצורך תקנות אלה, אדם אשר ביום שבו היה אזור                  |תושבים קבועים       |
|מסויים לאזור הבטחון, בתוקף אכרזה לפי תקנה 2, ישב באותו אזור ישיבת קבע.                      |                    |
|4. שר הבטחון רשאי למנות כל קצין צבא-הגנה לישראל בדרגת סגן-אלוף או בדרגה                     |רשויות מוסמכות      |
|גבוהה מזו להיות רשות מוסמכת לצורך תקנות אלה.                                                |                    |
|5. (א) שר הבטחון ימנה לגבי כל אזור בטחון ועדה מייעצת של שלושה חברים או יותר/                |ועדה מייעצת         |
|שתייעץ לרשות המוסמכת בנוגע לשימוש בסמכויותיה לפי תקנה 8.                                    |                    |
|(ב) חברי הועדה המייעצת יתמנו מתוך באי כוח הרשויות המקומיות שתחום שיפוטן הוא                 |                    |
|באזור הבטחון ובסביבתו ומתוך התושבים הקבועים של אזור הבטחון ותושבי סביבתו; ואם אין           |                    |
|רשויות מקומיות כאמור, או שאינן פעילות למעשה - יתמנו חברי הועדה המייעצת מתוך                 |                    |
|התושבים הקבועים של אזור הבטחון ומתוך תושבי סביבתו.                                          |                    |
|6. (א) אסור לאדם, שאינו תושב קבוע, להימצא באזור בטחון או להיכנס אליו, אלא אם                |איסורים             |
|הוא חייל או שוטר במילוי תפקידו, או אם הורשה לכך על כי רעיון בכתב מאת רשות מוסמכת            |                    |
|ובהתאם לתנאי הרשיון; אך שר הבטחון רשאי, בצו על פי תקנה 2 או בצו נפרד בחתימת ידו             |                    |
|שיפורסם ברשומות, להוציא מכלל האיסור האמור, לי.בי אזור הבטחון כולו או לגבי חלק ממנו/         |                    |
|סוג מסויים של בני אדם, בין ללא תנאי ובין בתנאים.                                            |                    |

|(ב) אדם הנמצא באזור בטחון בנייוד לתקנה זו, רשאי כל חייל וכל שוטר, שהורשו לכך                       |עבירות               |
|על ידי רשות מוסמכת, להוציאו מאזור הבטחון במועד שנקבע על ידי הרשות המוסמכת/ עם                      |                     |
|מטלטליו או בלעדיהם, ולהשתמש לצורך זה במידת הכוח הדרושה.                                            |                     |
|(ג) הוצאת אדם מאזור בטחון על פי תקנח משנה (ב) לא תגרע מאחריותו של אותו אדם                         |                     |
|על פי תקנה 7,                                                                                      |                     |
|7. אדם העובר על תקנה 6 (א), או על תנאי של רשיון שניתן על פיה, דינו - מאסר עד שנה                   |                     |
|אחת או ؀ࠂࠐࠒࠖࠜࠞࠠקנס עד שלוש מאות לירות או שני הענשים באחד.                                          |                     |
|8. (א) רשות מוסמכת רשאית לצוות על תושב קבוע של אזור בטחון לצאת את אזור הבטחון.                     |צווי יציאה           |
|צו כזה נקרא בתקנות אלה "צו יציאה".                                                                 |                     |
|(ב) תושב קבוע שנצטווה לצאת את אזור הבטחון, כאמור, חייב לצאת את אזור הבטחון                         |                     |
|תוך ארבעה עשר יום מהיום שבו נמסר לו צו היציאה.                                                     |                     |
|(ג) חלפו ארבעה עשר יום האמורים, דינו של התושב הקבוע כדין אדם שאינו תושב                            |                     |
|קבוע, ותקנות 7-6 יחולו עליו בהתאם לכך.                                                             |                     |
|9. (א) שר הבטחון ימנה ועדת ערעור או ועדות ערעור לצורך תקנות אלה.                                   |ועדות ערעור          |
|(ב) ועדת ערעור תהיה של שלושה חברים. יושב ראש הועדה יהיה שופט או 'שופט שלום                         |                     |
|שיתמנה לפי המלצת שר המשפטים.                                                                       |                     |
|(ג) הודעה על מינוי ועדת ערעור ועל כתובת הועדה תפורסם ברשומות.                                      |                     |
|10. (א) תושב קבוע שניהן עליו צו יציאה, רשאי, תוך ארבעה ימיט מהיום שבו נמסר לו                      |ערעור                |
|הצו/ לערער עליו בפני ועדת ערעור.                                                                   |                     |
|(ב) הערעור יוגש בכתב לידי הרשות המוסמכת שנתנה את צו היציאה. הרשות המוסמכת                          |                     |
|תעביר מיד אח הערעור לועדת הערעור.                                                                  |                     |
|(ג) ועדת הערעור תדון ותפסוק בערעור תוך ארבעה עשר יום מהיום שבו נמסר צו                             |                     |
|היציאה למערער.                                                                                     |                     |
|(ד) ועדת הערעור רשאית לאשר את צו היציאה, או לאשרו בתנאים מסוימים, או לרטלו.                        |                     |
|החלטת הועדה תהיה סופית.                                                                            |                     |
|11. (א) היתה רשות מוסמכת סבורה שאדם מסויים הנמצא באזור בטחון אינו תושב קבוע                        |טענת תושב קבוע       |
|ואותו אדם טוען שהוא תושב קבוע, רשאי הוא להביא את טענתו בפני ועדת ערעור.                            |                     |
|(ב) הטענה תוגש בכתב לידי הרשות המוסמכת שתעבירה מיד לועדת הערעור.                                   |                     |
|(ג) הועדה תפסוק/ תוך ארבעה עשר יום מיום הגשת הטענה/ אם אותו אדם הוא תושב                           |                     |
|קבוע או לא. החלטת הועדה תהיה סופית.                                                                |                     |
|(ד) פסקה הועדה שאותו אדם הוא תושב קבוע, יראו אותו כאילו ביום הגשת הטענה                            |                     |
|ניתן עליו צו יציאה והוא ערער על הצו לפי תקנה 10; והועדה תחליט, באותו מעמד, אם לאשר                 |                     |
|את צו היציאה, או לאשרו בתנאים מסויימים או לבטלו. החלטת הועדה תהיה סופית.                           |                     |
|(ה) הגשת טענה לכי תקנה זו לא תמנע את הרשות המוסמכת מלנהוג בטוען כבמי שאינו                         |                     |
|תושב קבוע; והחלטת ועדת הערעור שהטוען הוא הושב קבוע לא תפגע בתקפה של כל פעולה                       |                     |
|שנעשתה לגבי הטיען לפני יום ההחלטה, אם הפעולה היתה בה תוקף אילי הטוען לא היה הושב                   |                     |
|קבוע.                                                                                              |                     |
