|מתפרסמת בזה הצעת חוק מטעם הממשלה :                      |

|חוק המעבר (תיקון), תש"ך-1959                            |

|1. בסעיף 11 לחוק המעבר, תש"ט -1949 1, סעיף-קטן (ז) יסומן כסעיף-קטן (ח) ויווסף                                      |תיקון סעיף 11       |
|סעיף-קטן זה:                                                                                                       |                    |
|"(ז) האחריות המשותפת מחייבת את חברי הממשלה על סיעותיהם.                                                            |                    |
|הצבעת הבר הממשלה או חברי סיעתו בגד הצעת הממשלה בכנסת' או                                                           |                    |
|הימנעות חבר הממשלה או חברי סיעתו מן ההצבעה בכנסת על הצעת                                                           |                    |
|הממשלה' בלי הסכמתה' דינם כדין התפטרות אותו חבר הממשלה. התפטרות                                                     |                    |
|זו נכנסת לתקפה עם מסירת הודעה עליה על ידי ראש הממשלה בכנסת.                                                        |                    |
|הודעה זו אינה טעונה אישור הכנסת."                                                                                  |                    |
|דברי הסבר                                                                                                          |                    |
|האחריות המשותפת של הממשלה בפני הכנסת קבועה בסעיף 11 (ו) לחוק המעבר                                                 |                    |
|תש"ט-1949, שזו לשונו:                                                                                              |                    |
|"הממשלה תשא באחריות משותפת לפעולותיה בפני הכנסת' תמסור לה דין וחשבון עליהן, ותכהן                                  |                    |
|כל עוד תיהנה מאמון הכנסת".                                                                                         |                    |
|אחריות משותפת זאת תחייב' לפי קווי היסוד של הממשלה הנוכחית' לא את؀ࠂࠌࠎ הממשלה                                        |                    |
|על חבריה בלבד' אלא גם את כל הסיעות המשתתפות בקואליציה הממשלתית.                                                    |                    |
|החוק המוצע בא להביא בחוק המעבר, תש"ט-1949,  את התיקון הדרוש לביצוע                                                 |                    |
|האמור בקווי היסוד.                                                                                                 |                    |
