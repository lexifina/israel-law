|חוק לתיקון פקודת הטבק, תשכ"א-1960                                                            |

|1. אחרי סעיף 50 לפקודת הטבק 1, יווסף סעיף זה:                                                                       |הוספת סעיף 50א     |
|50א. על אף האמור בסעיפים 48 ו-50, רשאי- שר האוצר לפטור, דרך                                  |"מכירת טבק            |                   |
|כלל או לסוגים, ובתנאים שיראה לקבוע, מקבלת רשיון למכירת טבק או                                |ללא רשיון             |                   |
|להחזקתו או לרוכלות בה                                                                        |                      |                   |
|2. תחילתו של חוק זה היא מיום י"ג בטבת תשכ"א (1 בינואר 1961).                                                        |תחילה              |

|דברי הסבר                                                                                                              |
|סעיפים 48 ו-50 לפקודת הטבק אוסרים מכירת טבק או החזקתו למכירה ללא רשיון.                                                |
|וזו לשון הסעיפים.                                                                                                      |

|48. (א) לא ימכור אדם טבק מיוצר ולא יחזיקנו לשם מכירה/ אלא לפי רשיון בטופס שנקבע.             |"רשיון חנווני          |
|(ב) הרשיון יקנה לבעליו רשות למכור טבק מיוצר בחצרים המפורטים ברשיון או להחזיק                 |                       |
|בהם טבק למכירה.                                                                              |                       |
|(ג) חצרים נפרדים שמוכרים בהם טבק או שמחזיקים בהם טבק לשם מכירה, טעונים                       |                       |
|רשיון כל אחד לחוד.                                                                           |                       |
|(ד) מותר לסרב ליתן רשיון בלי לפרש נימוקים.                                                   |                       |
|(ה) בעד כל רשיון תשולם אגרה בשיעורים שנקבעו בתוספת.                                          |                       |
|(ו) אין רשיון ניתן להעברה אלא באישור המנהל; הרשיון יהא מוצג במקום נראה לעין                  |                       |
|שבחצרים הנקובים בו.                                                                          |                       |
|(ז) הרשיון יפקע באחד בינואר של כל שנה.                                                       |                       |
|50. (א) לא ירכול אדם בטבק ؀ࠂࠒࠔࠖࠤלא-מיוצר.                                                    |רוכלות בטבק            |
|(ב) לא ירכול אדם בטבק מיוצר אלא לפי רשיון בטופס שנקבע.                                       |                       |
|(ג) בעד רשיון רוכלים תשולם אגרה בשיעור שנקבע בתוספת.                                         |                       |
|(ד) בעל רשיון רוכלים יציג את רשיונו לפני פקיד בלו או שוטר למי דרישתם."                       |                       |

|מוצע להעניק לשר האוצר סמכות לפטור מקבלת רשיון למכירת טבק בקמעונות או                                                  |
|לרוכלות בו, לאחר שנתברר כי ניתן לקיים פיקוח נאות על מכירת טבק כאמור לאו דוקא                                          |
|בדרך חיוב בקבלת רשיון לכך.                                                                                            |
|יש בתיקון משום הקלה רבה לעוסקים במכירת טבק בקמעונות או ברוכלות/ שכיום                                                 |
|הם חייבים ברשיון הן מרשות המכס והן מהרשות המקומית שבה הם מקיימים את עסקם.                                             |
|ביטול הפיקוח על קבלת רשיונות יחסוך גם למדינה כוח אדם שיופנה למשימות חשובות                                            |
|יותר.                                                                                                                 |
