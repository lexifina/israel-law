|תיקון סעיף 10    |1. בחוק רשות חקלאית בפתח-תקוה, תשי"ט-1959 1, בסעיף 10, במקום "י"ד בניסן תשכ"א                                    |
|                 |(31 במרס 1961)" יבוא "ו' בניסן תשכ"ג (31 במרס 1963)".                                                            |
|                 |דברי הסבר                                                                                                        |
|                 |באוגוסט 1959 חוקקה הכנסת חוק רשות חקלאית בפתח-תקוה, תשי"ט-1959. מטרתו                                            |
|                 |של החוק היתה למצוא הסדר ביניים בשביל שטח של כ-12/000 דונם בערך של אדמה חקלאית                                    |
|                 |שהיווה בזמנו את תחום שיפוטה של המועצה הכפרית בפתח-תקוה. עם ביטולה של המועצה                                      |
|                 |נוצר הכרח למצוא פתרון לבעיית הספקת השירותים החקלאיים החיוניים לשטח זה בדרך                                       |
|                 |שתאפשר מניעת האורבניזציה של האזור ושמירה על אפיו החקלאי, מאחר ולא היה כבר                                        |
|                 |סיפק בידי הכנסת השלישית למצוא פתרון קבע לבעיה, נקבע בחוק העיקרי הסדר ביניים                                      |
|                 |שתקפו הוגבל עד יום י"ד בניסן תשכ"א (31 במרס 1961). ואולם נתברר שהבעיה דורשת                                      |
|                 |מחקר ומשא ומתן ממושכים יותר؀ࠂࠊࠌ ולא תהיה כל אפשרות למצוא את הפתרון המתאים עד                                     |
|                 |לתאריך שנקבע. לפיכך בא החוק המוצע להאריך את תקפו של הסדר הביניים לשנתיים                                         |
|                 |נוספות.                                                                                                          |
