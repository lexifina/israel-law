|חוק לתיקון פקודת הפרשנות, תשכ"א-1960                                        |

|1. בסעיף 16 לפקודת הפרשנות 1, בפסקה (2), במקום "חמישים לירות" יבוא "חמש                                             |תיקון סעיף 16      |
|מאות לירות'/                                                                                                        |                   |
|דברי הסבר                                                                                                           |                   |
|סעיף 16 (2) לפקודת הפרשנות קובע:                                                                                    |                   |
|"16. מקום שהחוק מעניק לרשות את הסמכות להתקין תקנות, יהיו ההוראות הבאות חלות לגבי                                    |                   |
|התקנתן וכוח פעולתן של תקנות אלו, אם אין כוונה אחרת משתמעת -                                                         |                   |
|(1)                                                                                                                 |                   |
|(2) מותר לקבוע בתקנות/ כי כל העובר על הוראה מהוראותיהן/ יהא צפוי לקנס                                               |                   |
|שנקבע בתקנות, או לתקופת מאסר שנקבעה בהן או לשני הענשים כאחד, ובלבד                                                  |                   |
|שהקנס לא יעלה על חמישים לירות ותקופת המאסר לא תעלה על ששה חדשים;                                                    |                   |
|והוא כשאין באותו חוק הוראה אחרת."                                                                                   |                   |
|כשנחקקה הוראה זו' בשנת 1945/ היה לקנס של 50 לירות כוח מרתיע מפני עבירות                                             |                   |
|על הוראות תקנות, היינו חקיקת-משנה לסוגיה. לא כן עתה. את השינוי שחל מבחינה זו                                        |                   |
|כבר הביא המחוקק בחשבון, בראשונה כשקבע בסעיף 5 לחוק לתיקון דיני העונשין (דרכי                                        |                   |
|ענישה), תשי"ד-1954, (ס"ח 166, עמ' 234) שכל קנס הקבוע בחוק שהיה קיים ערב הקמת                                        |                   |
|המדינה יוכפל פי חמישה עשר, ובאחרונה כאשר תיקן בשנת תשי"ז (ס"ח 234) את פקודת                                         |                   |
|העיריות, 4934 ופקודת המועצות המקומיות, 1941, והעלה את הגבול המקסימלי של ؀ࠂࠊࠌקנסות                                   |                   |
|בעבירות על חוקי עזר מעשרים לירות לחמש מאות לירות. העלאה אחרונה זו חלה על חוקי                                       |                   |
|עזר המותקנים מכוח שתי הפקודות האמורות אך לא על צווים המוצאים על פיהן. היא אינה                                      |                   |
|חלה גם על הקנסות לפי תקנות שלא נקבע להם שיעור בחוק המסמיך את התקנתן, כגון                                           |                   |
|תקנות לפי פקודת הנמלים (חוקי א"י, כרך ב', פרק קי"ד), לפי חוק הטיס, 1927 (חוקי                                       |                   |
|א"י, כרך ב' עמ' 2551) ועוד.                                                                                         |                   |
|מטרת החוק המוצע היא להתאים גם את שיעור הקנסות, שאפשר להטיל בתקנות,                                                  |                   |
|לשינויי הזמן.                                                                                                       |                   |
