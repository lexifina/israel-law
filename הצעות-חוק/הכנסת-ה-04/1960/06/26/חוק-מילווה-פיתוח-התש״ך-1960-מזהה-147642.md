|מתפרסמות בזה הצעות חוק מטעם הממשלה:                            |

|חוק מילווה פיתוח, תש"ך-1960                            |

|1 . הממשלה מורשית בזה לקבל, בשם המדינה, מילווה למטרות פיתוח בסכום כולל שלא                                      |הרשאה ללוות             |
|יעלה על 40 מיליון לירות ולהוציא למטרה זו איגרות חוב.                                                            |                        |
|2. איגרות החוב יוצאו בסדרות ויהיו למוכ"ז או רשומות על שם או מקצתן למוכ"ז                                        |הוצאה בסדרות            |
|ומקצתן רשומות על שם, הכל כפי שיקבע שר האוצר בתקנות לגבי כל סדרה.                                                |                        |
|3. הסכומים המשתלמים לפי איגרות החוב וכל ההוצאות הכרוכות בביצוע חוק זה ישולמו                                    |תשלום וערובה            |
|מתוך הכנסותיה הכלליות ומתוך נכסיה של המדינה.                                                                    |                        |
|4 . הנהלת עניני המילווה (להלן - המינהלה) תהיה כידי בנק ישראל.                                                   |הנהלת המילווה           |
|5, שר האוצר יקבע בתקנות לגבי כל סדרה ענינים אלה:                                                                |תנאי המילווה            |
|(1) סך כל שוויה הנקוב;                                                                                          |                        |
|(2) יום הוצאתה;                                                                                                 |                        |
|(3) שיעור הריבית שתשולם על איגרות החוב, דרכי תשלומה ומועדיה, ובלבד                                              |                        |
|שלא יעלה על 6% לשנה;                                                                                            |                        |
|(4) דרכי פדיונן של איגרות החוב ומועדי הפדיון, ובלבד שאיגרות החוב של                                             |                        |
|כל סדרה ייפדו לא יאוחר מ-15 שנים מיום הוצאתה של הסדרה;                                                          |                        |
|(5) שווין הנקוב של איגרות החוב;                                                                                 |                        |
|(6) נוסחן של איגרות החוב.                                                                                       |                        |
|6. שר האוצר רשאי לקבוע בתקנות לגבי כל סדרה -                                                                    |תנאים מיוחדים           |
|(1) שהקרן והריבית של איגרות החוב יהיו צמודות, הצמדה מלאה או חלקית,                                              |                        |
|לדולר של ארצות הברית של אמריקה או למדד יוקר המחיה או מקצתן לזה                                                  |                        |
|ומקצתן לזה, ולפי התנאים שיקבע;                                                                                  |                        |
|(2) שהריבית לא תהא חייבת בשום מס המוטל על הכנסה, חוץ מן המס שיש                                                 |                        |
|לנכותו מאותה ריבית לפי סעיף 31(7) לפקודת מס הכנסה, 1947 1, ושלא יעלה                                            |                        |
|על 25%;                                                                                                         |                        |
|(3) שאיגרות החוב יימכרו רק לתושבי-חוץ תמורת מטבע-חוץ.                                                           |                        |
|7. (א) המינהלה תנהל פנקס שבו יירשמו שמותיהם ומעניהם של בעלי איגרות החוב                                         |פנקס האיגרות            |
|על שם ושווין הנקוב של האיגרות.                                                                                  |על שם                   |
|(ב) הפנקס ישמש ראיה לכאורה לכל ענין הרשום בו כדין.                                                              |                        |
|8. (א) איגרות חוב למוכ"ז ניתנות להעברה במסירה.                                                                  |העברת איגרות חוב        |
|(ב) איגרות חוב על שם ניתנות להעברה בכתב-העברה חתום על ידי המעביר                                                |                        |
|והנעבר; כתב ההעברה יימסר למינהלה והיא תרשום את ההעברה.                                                          |                        |
|9. שר האוצר רשאי לבוא לידי הסכם עם אדם שיקבל על עצמו ؀ࠂࠌࠎࠒࠚࠜࠞהפצת איגרות החוב או                                |הסכם להפצת              |
|שיערוב להפצתן, כולן או מקצתן, ולשלם לו עמלה כפי שיקבע שר האוצר בתקנות, דרך                                      |איגרות חוב              |
|כלל או לסדרה פלונית.                                                                                            |                        |

|חתימה                |11. איגרות החוב ישאו את דמות חתימותיהם של שר האוצר ושל החשב הכללי.                                               |
|רכישת איגרות         |12. שר האוצר רשאי לקבוע בתקנות כללים שלפיהם רשאית המינהלה, על אף האמור                                           |

|                     |איגרות החוב שנרכשו או הועברו כאמור; לענין סעיף זה דין חבר הבורסה לניירות ערך                                     |

|                     |לביצועו' ובלבד שתקנות לפי הסעיפים 5 ו-6 יותקנו לפני הוצאתה של כל סדרה ומשהותקנו                                  |
|                     |לא יהיו נתונות לשינוי זולת דרכי תשלום הריבית ודרכי פדיון הקרן.                                                   |

|דברי-הסבר                                                                                                        |
|החוק המוצע מרשה לממשלה לקבל מילווה בסכום של 40 מיליון לירות ולהוציא                                              |
|למטרה זו סדרות של איגרות חוב. המילווה מיועד למטרות פיתוח.                                                        |
|החוק אינו קובע את הפרטים של תנאי המילווה אלא רק מסגרת שבתוכה יקבע שר                                             |
|האוצר פרטים כמפורש בחוק, כגון ריבית, פדיון וכוי* ורשאי לקבוע תנאים מיוחדים לענין                                 |
|הצמדה, פטור הריבית ממס הכנסה והגבלת המכירה לתושבי-חוץ בלבד. תנאי המלווה                                          |
|ייקבעו לפני הוצאת כל סדרה, ומשנקבעו אין לשנותם עוד.                                                              |
