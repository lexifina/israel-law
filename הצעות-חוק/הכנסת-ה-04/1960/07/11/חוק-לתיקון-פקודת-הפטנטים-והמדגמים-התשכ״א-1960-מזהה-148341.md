|חוק לתיקון פקודת הפטנטים והמדגמים, תש"ך-1960                                               |

|תיקון סעיף 21     |1, בסעיף 21 (5) לפקודת הפטנטים והמדגמים 1, אחרי פסקה (ב), תיווסף פסקה זו:                                        |
|                  |"(ג) אם בעל הפטנט אינו מייצר בישראל את המוצר, שעליו                                                              |
|                  |או על התהליכים לייצורו ניתן לו הפטנט' והוא מסרב ליתן                                                             |
|                  |ליצרן מקומי רשיון להשתמש במוצר או בתהליך."                                                                       |
|תחולה             |2. חוק זה יחול גם על אמצאות שניתן עליהן פטנט לפני תחילתו של החוק.                                                |
|                  |דברי-הסבר                                                                                                        |
|                  |פקודת הפטנטים והמדגמים מעניקה לבעל פטנט מונופולין על אמצאתו, למשך תקופה                                          |
|                  |מוגבלת, והוא היחיד הרשאי להשתמש באותה אמצאה, לנצלה, לספקה ולמכרה או ליתן                                         |
|                  |רשיונות לאחרים לעשות כן.                                                                                         |
|                  |אם בעל המונופולין מנצל לרעה זכותו זו, רשאית המדינה להתערב ולנקוט צעדים                                           |
|                  |אשר ימנעו שימוש לרעה בזכות היהודית שמעניק הפטנט. אחד המקרים הבולטים הוא                                          |
|                  |אי-ניצולה של האמצאה בתחומי המדינה שנתנה את הפטנט עליה. לפיכך מצויות בכל                                          |
|                  |חוק פטנטים הוראות המאפשרות למדינה נקיטת אמצעים כאמור; והן מצויות גם בסעיף 21                                     |
|                  |לפקודת הפטנטים והמדגמים, וזו לשובו:                                                                              |
|                  |"21, (ו) רשאי כל אדם הנוגע בדבר להגיש בקשה לרשם ובה יטען שלא סופק,- דרישותיו                                     |
|                  |הסבירות של הציבור בקשר לאמצאה שניהן עליה פטנט ויבקש שיתנו רשיון חובה, ולא - לבטל                                 |
|                  |את הפטנט.                                                                                                        |
|                  |(2) על הרשם לעיין כבקשה. ואם לא יבואו הצדדים לכלל הסכם ביניהם לבין עצמם,                                         |
|                  |ונתברר לו שיש לה לבקשה על מה שתסמוך, יהא זה מחובתו להביא את הבקשה לפני בית המשפט                                 |
|                  |המחוזי.                                                                                                          |
|                  |(3) הובאה בקשה כזאת ע"י הרשם לפני בית המשפט והוכח כדי הנחת דעתו של בית                                           |
|                  |המשפט שלא סופקו דרישותיו הסבירות של הציבור בקשר עם האמצאה שניתן עליה פטנט,                                       |
|                  |רשאי בית המשפט לצוות על בעל הפטנט לתת רשיונות באותם התנאים שיצדקו בעיני בית                                      |
|                  |המשפט, ואם סבור בית המשפט שלא יהא במתן רשיונות סיפוק דרישותיו הסבירות של הציבור,                                 |
|                  |רשאי הוא לתת צו לבטל את הפטנט;                                                                                   |
|                  |בתנאי שלא יתן בית המשפט צו עפ"י סעיף זה אלא אם עברו שלוש שנים מיום מתן                                           |
|                  |הפטנט, וכן לא יינתן צו כזה אם נתן בעל הפטנט נימוקים המניחים את הדעת לאי סיפוק דרישות                             |
|                  |הציבור ההוגנות.                                                                                                  |
|                  |(0 כשדנים בבקשה עפ"י סעיף זה ייעשו רעל הפטנט וכל איש התובע זכויות בפטנט                                          |
|                  |בין؀ࠂࠊࠌࠐࠔ כבעל רשיון יחידי ובין באופן אתר, צדדים במשפט, וליועץ המשפטי לממשלה תהיה הזכות                          |
|                  |להשמיע את טענותיו.                                                                                               |
|                  |(י.) לצורך סעיף זה תיחשבנה דרישותיו הסבירות של הציבור כדרישות שלא סופקו -                                        |
|                  |(א) אם אין בעל הפטנט מעבד די הצורך חפץ שיש לו פטנט עליו, ואינו מספק,                                             |
|                  |במידה הדרושה ובתנאים סבירים ומחמת כך סובלת שלא כדין אחת המלאכות אי                                               |
|                  |אחת התעשיות בישראל, או שנוצרה תקלה על דרך ביסוס מלאכה הדשה או חרושת                                              |
|                  |חדשה בישראל או שאין מספיקים די הצורך את הביקוש לחפץ שיש עליו פטנט או                                             |
|                  |לחפץ דמיוצר ע"י התהליך שניתן לו פטנט.                                                                            |
|                  |(ב) אם סובלת אחת המלאכות או התעשיות בישראל שלא כדין מחמת התנאים                                                  |
|                  |שהעמיד בעל הפטנט לקניית החפץ שיש לו פטנט עליו או לשימוש בו או לניצולו                                            |
|                  |של תהליך בפטנט.                                                                                                  |
|                  |(6) צו בית המשפט המצווה לתה רשיון עפ"י סעיף זה יהא כוחו יפה כאלו נכלל ברשיון                                     |
|                  |שנערך כהלכה בין הצדדים שבמשפט."                                                                                  |

|1 חוקי א"י, כרך ב, פרק כ"ה, עמ' 1053.               |

|אין הפקודה קובעת במפורש, כי גם סירוב של בצל פטנט ליתן רשיון לתעשיה                                                   |
|המקומית להשתמש באמצאתו, במקום שהוא עצמו אינו מייצר בישראל את המוצר שעליו                                             |
|ניתן הפטנט - מהווה ניצול לרעה של המונופולין.                                                                         |
|קביעה זו המצויה בתחיקה הבריטית הסרה בפקודה הישראלית, אולי משום שהמחוקק                                               |
|של הזמן ההוא לא היה מעונין במיוחד בעידוד התעשיה המקומית, עם פיתוחה של התעשיה                                         |
|הישראלית' התרחבותה וקידומה, מורגש חסרונה של הוראה כזו, ומוצע להוסיפה.                                                |
