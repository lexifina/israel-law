|                |"(3) על אף האמור בסעיף קטן (1), רשאי שר המשפטים אם הדבר                                                         |
|                |נראה לו דרוש למען עשיית צדק, להתיר, לאחר התייעצות עם המועצה                                                     |
|                |המשפטית, לאדם שאינו אזרח ישראלי והוא נאשם בעבירה שדינה מיתה,                                                    |
|                |או שמתנהלת נגדו חקירה בשל עבירה כזאת, למנות לעצמו סניגור שאינו                                                  |
|                |עורך דין כמשמעותו בפקודה זו. סניגור שנתמנה כך, דינו, לענין זה, כדין                                             |
|                |עורך דין כאמור המורשה לעסוק במקצועו."                                                                           |
|                |דברי הסבר                                                                               |                       |
|                |בקשר למשפט אייכמן התעורר הצורך לאפשר לו מינוי סניגור שאינו עורך דין                                             |
|                |הרשום בפנקס עורכי הדין בישראל. מוצע בזה לתקן את פקודת עורכי הדין, 1938, באופן                                   |
|                |שתינתן לשר המשפטים סמכות להתיר מינוי סניגור כזה לנאשם בעבירה שדינה מיתה                                         |
|                |והוא אינו אזרח ישראלי. עיקר הכוונה לאפשר לזר הנאשם בעבירה כזאת לבקש לו גם                                       |
|                |הגנתו של סניגור מארץ זרה. סעיף 4 לפקודה כנוסחו כיום אינו מאפשר זאת. וזו לשונו:                                  |
|                |''4. (1) לשום אדם לא ההא הזכות לטעון מטעם אדם אחר בכל בירור משפטי בפני בית משפט         |                       |
|                |אזרחי או בכל הליך משפטי בישראל/ אלא אם כן הוא רשום בפנקס ؀ࠂࠈעורכי הדין והוא בעל רשיון   |                       |
|                |לעסוק במקצוע עפ"י סעיף קטן (1) של סעיף 10 לפקודה זו או שהוא זכאי לעסוק במקצוע בלא       |                       |
|                |רשיון כזה במותנה באותו סעיף קטן, או שהוא היועץ המשפטי לממשלה או נציגו של היועץ          |                       |
|                |המשפטי לממשלה.                                                                          |                       |
|                |. (2) כל אדם רשאי, ברשות בית המשפט, לטעון בפני בית המשפט כידיד מטעם צד שאינו            |                       |
|                |מיוצג על ידי אדם הרשאי לעסוק כעורך דין, אבל בשום אופן לא תהיה לאותו אדם תביעה,          |                       |
|                |הניתנת לאכיפה בתוקף החוק, לקבלת שכר בעד שירותו. רשות על פי הוראה זו לא תינתן לאדם       |                       |
|                |שלדעת בית המשפט או השופט, עושה לו מנהג לעסוק כידיד לבעלי דין."                          |                       |
