|חוק אכסון במלון, תש"ך-1960                                    |

|1. בחוק זה -                                                                                                     |הגדרות                    |
|"מלול" - לרבות בית לינה' פנסיון, אכסניה' ביית אירוח וכל מוסד כיוצא באלה;                                         |                          |
|"בעל מלון" - לרברת מי שבידיו הנהלת המלון;                                                                        |                          |
|"צו-אכסון" - צו לפי סעיף 3.                                                                                      |                          |
|2. (א) ראש הממשלה רשאי למנות פקידי אכסון לענין חוק זה.                                                           |פקידי אכסון               |
|(ב) מינוי על פי סעיף זה יכול להיות כללי או מסוייג.                                                               |                          |
|(ג) כל מינוי על פי סעיף זה יפורסם ברשומות.                                                                       |                          |
|3. מלון שיש עליו אישור לפי צו ההגנה (זיהוי עסקים למכירת טובין ומתן שירותים                                       |צו-אכסון                  |
|לתיירים), תשי"ז-1957 1, רשאי פקיד האכסון, בצו בחתימת ידו, לחייב את בעל המלון                                     |                          |
|לאכסן בו אדם הנקרב בצו, במשך תקופה המפורשת בצו ובתנאי לינה' כלכלה ושירות                                         |                          |
|הנהוגים באותו מלון, אם נוכח פקיד האכסון, כי הדבר דרוש לאכסון תיירים בשים לב                                      |                          |
|לאפשרויות האשפוז במלונות' או לשם מתן אכסון חלוף למי שמפנה הדר מכוח צו-אכסון;                                     |                          |
|בצו-האכסון תפורש הזכות לערור עליו לפי הוראות החוק, המועד לערר ומען ועדת                                          |                          |
|הערר.                                                                                                            |                          |
|4. לא יינתן צו-אכסון על חדר התפוס בידי אדם השוהה בישראל על פי אשרה ורשיון                                        |חדר התפוס                 |
|לישיבת מעבר או לישיבת ביקור, כמשמעותם בחוק הכניסה לישראל, תשי"ב-1952 2, אלא                                      |בידי תייר                 |
|אם תמה התקופה שבה הוא רשאי לתפוס את החדר על פי חוזה או על פי הזמנה שאושרה על                                     |                          |
|ידי בעל המלון או מטעמו, והחדר דרוש למען אדם אחר השוהה כאמור והזמין את החדר                                       |                          |
|לתקופה המתחילה כתום תקופת אכסונו של האדם שקדם לו.                                                                |                          |
|5. ניתן צו-אכסון המחייב בעל מלון לאכסן אדם בחדר מסויים שבמלונו, ואותה שעה                                        |פינוי חדר                 |
|תפוס החדר לתקופה מסויימת בידי אדם אחר על פי חוזה או על פי הזמנה שאושרה בכתב                                      |ואכסון חלוף               |
|על ידי בעל המלון או מטעמו, חייב תופס החדר לפנותו לא יאוחר מ-12 שעות ממסירת                                       |                          |
|צו-האכסון, ופקיד האכסון יתן לו, לפי דרישתו, אכסון חלוף סביר עד לגמר אותה תקופה                                   |                          |
|או עד לגמר תקופת צו-האכסון, הכל לפי המועד הקצר יותר; היה החדר תפוס שלא לפי                                       |                          |
|חוזה או הזמנה כאמור' חייב התופס לפנותו מיד.                                                                      |                          |
|6, התקשר בעל מלון עם אדם בנוגע למלון, ולאחר מכן ניתן צו-אכסון אשר שלל מבעל                                       |פטור מאחריות              |
|המלון את האפשרות לקיים התחייבות שנתחייב בה על פי ההתקשרות, לא ישא בעל המלון                                      |להפרת חוזה                |
|בכל אחריות אזרחית כלפי אותו אדם בשל אי-קיום אותה התחייבות.                                                       |                          |
|7. דמי האכסון על פי צו-אכסון ישולמו על ידי המתאכסן על פיו, או על ידי מי שפקיד                                    |דמי האכסון                |
|האכסון הורה עליו; דין דמי האכסון כדין חוב אזרחי שהמתאכסן או האדם האמור' הכל                                      |                          |
|לפי המקרה, חב לבעל המלון.                                                                                        |                          |
|8. פקיד אכסון שנתן צו-אכסון לגבי מלון או חלק ממנו רשאי, כל עוד לא בוצע הצו,                                      |ביטול צווים               |
|לבטלו או לשנותו, ואין הביטול או השינוי גורע מסמכותו ליתן צו חדש לגבי אותו מלון או                                |ושינוים                   |
|לגבי חלק ממנו.                                                                                                   |                          |
