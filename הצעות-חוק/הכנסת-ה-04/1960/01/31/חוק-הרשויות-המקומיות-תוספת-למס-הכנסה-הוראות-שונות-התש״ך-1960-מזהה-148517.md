|חוק הרשויות המקומיות (תוספת למס הכנסה)                                        |
|(היראות שונות), תש"ך-1960                                                     |

|הגדרות            |1. בחוק זה תהא לכל מונח המשמעות שניתנה לו בחוק הרשויות המקומיות  תוספת למס                                     |
|                  |הכנסה), תשי"ב-1932 1 (להלן - החוק העיקרי).                                                                     |
|רשות לגבית        |2. (א) תוספת מסוכן תוספת מס רווחי חברות לשתיהן יחד ייקרא להלן- התוספת),                                        |
|תוספת מס          |שרשות מקומית היתה רשאית לפי החוק העיקרי להטיל על נישומים לשבות השומה 53 1952,                                  |
|                  |51 19531 ו-55 1951 ולשנות המס 1954, 1955 ו-1935, ייגבו מהם בין שהרשות המקומית החליטה                           |
|                  |להטיל תוספת מס ופרסמה החלטתה כדין ובין שלא עשתה כן.                                                            |
|                  |יב> התוספת תיגבה גם מנישומים שבשנה משנות השומה או משנות המס הנזכרות                                            |
|                  |בסעיף קטן (א) לא השתייכו לרשות מקומית.                                                                         |
|המשך בעיות        |3. סכום שנגבה לפני תחילתו של חוק זה ושגבייתו היתה כדין אילו היה הרק זה בתקפו                                   |
|                  |אותה שעה' רואים אותו באילו נגבה בדין.                                                                          |
|                  |דברי הסבר                                                                                                      |
|                  |הצעת חוק הרשויות המקומיות י תוספת מס הכנסה) (הוראות שונות), תשי"ט-1959 2,                                      |
|                  |הונחה על שולחן הכנסת השלישית ואף נדונה' לאחר קריאה ראשונה' בועדת הכספים                                        |
|                  |של הכנסת; אולם, כהונת הכנסת השלישית נסתיימה לפני תרם הדיון בה.                                                 |
|                  |חוק הרשויות המקומיות (תוספת למס הכנסה), תשי"ב-1952, הסמיך כל؀ࠂࠊࠌ רשות מקומית                                   |
|                  |להטיל על נישום המשתייך לה תשלום של תוספת למס הכנסה בשיעור של 7.5% מהסכום                                       |
|                  |של מס הכנסה שנקבע לנישום. הודעה על החלטתה בדבר הטלת תוספת מס כאמור צריכה                                       |
|                  |להתפרסם ברשומות.                                                                                               |
|                  |לא בכל המקרים פורסמה ההודעה ברשומות והיו גם מקרים שלא נתקבלה החלטת                                             |
|                  |הרשות המקומית במועד שנקבע לכך בחוק.                                                                            |
|                  |בעמ"ה 57 814, פסק בית המשפט המחוזי בתל-אביב-יפו כי בהעדר ההודעה ברשומות                                        |
|                  |אין רשות לגבות את תוספת המס.                                                                                   |
|                  |הכספים שנגבו על פי החוק הנ"ל שמשו לתשלום משכורת המורים במדינה.                                                 |
|                  |למעשה נהגו השלטונות כאילו כל הרשויות המקומיות פרסמו כדין החלטה בדבר                                            |
|                  |הטלת תוספת המס. תכליתו של החוק המוצע להכשיר את הגביה שנעשתה עד כה - בין                                        |
|                  |אם נעשתה לגבי נישומים ברשות מקומית או לגבי נישומים שלא היו בלל תושבי רשות                                      |
|                  |מקומית - ולעשותה חוקית, וכן לאפשר את השלמת הגביה מאלה שטרם שילמו.                                              |
