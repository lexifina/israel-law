|מתפרסמות  בזה הצינות חוק מטעם הממשלה:                       |

|חוק מניעת הפקעת שערים וספסרות (שיפוט) (תיקון מס' 2), תש"ך-1960                                                  |

|ן. בסעיף 4 לחוק מניעת הפקעת שערים וספסרות (שיפוט), תשי"א-1951 1, במקום                                             | תיקון סעיף 1      |
|סעיף קטן (ב) יבוא:                                                                                                 |                   |
|"(ב) למען מנוע ספק נקבע בזה, כי סמכותי של בית הדין לדון                                                            |                   |
|כעבירה נגד המשק אינה גורעת מסמכותו של כל בית משפט המוסמך                                                           |                   |
|לדון באותה עבירה על פי חוק בתי המשפט, תשי"ז- 1937 2, או על פי                                                      |                   |
|כל חוק אחד.                                                                                                        |                   |
|(ג) על אף האמור בחוק בתי המשפט' תשי"ז-1957, מוסמך בית                                                              |                   |
|משפט השלום לדון גם בעבירה נגד המשק שהיא פשע' ובלבד שלא יפסוק                                                       |                   |
|עונש העולה על העונש שהוא מוסמך להטיל בעד עוון."                                                                    |                   |
|דברי הסבר                                                                                                          |                   |
|תכליתו של החוק המוצע היא כפולה:                                                                                    |                   |
|א. סעיף 4 לחוק מניעת הפקעת שערים וספסרות (שיפוט), תשי"א-1931, אומר:                                                |                   |
|"(א) בית דין מוסמך לדון בכל עבירה נגד המשק;                                                                        |                   |
|;ב) כל בית משפט אחר "'ערב תחילת תקפו של חוק זה היה מוסמך לדון בעבירות נגד                                          |                   |
|המשק לולא הוראות פקודת מניעת הפקעת שערים וספסרות (שיפוט), תש''ה-1948 3, יהיה מוסמך                                 |                   |
|לדון באותן עבירות על אף האמור בסעיף קטן (א)."                                                                      |                   |
|נוסח זה השאיר מקום לספק לגבי סמכותם המקבילה של בתי המשפט המחוזיים ושל                                              |                   |
|בתי משפט השלום לדון בעבירות נגד המשק' כפי שפורטו בתוספת לחוק. בעיית הסמכות                                         |                   |
|המקבילה נתעוררה בעיקר אגב דיון בעבירות על חוק הפיקוח על מצרכים ושירותים,                                           |                   |
|תשי"ח-1957 4, שאף הן עבירות נגד המשק. לאחרונה החליט בית המשפט המחוזי בירושלים                                      |                   |
|בערעור פלילי  59 25,כי בית דין בלבד רשאי לדון בעבירות על חוק הפיקוח על ؀ࠂࠌࠎמצרכים                                  |                   |
|ושירותים.                                                                                                          |                   |
|כדי להסיר ספק זה מוצע להחליף סעיף קטן (ב) לסעיף 1-' ולקבוע במפורש כי                                               |                   |
|הסמכות שהוענקה לבתי הדין למניעת הפקעת שערים וספסרות לדון בעבירות נגד והמשק                                         |                   |
|אינה גורעת מסמכות כתי המשפט הרגילים לדון בעבירות אלו.                                                              |                   |
|ב. אם כי רוב עבירות נגד המשק הן פשעים, שהסמכות לדון בהם נתונה לבית המשפט                                           |                   |
|המחוזי הרי במציאות יש בהן גם עבירות קלות יותר למרות שמבחינה פורמלית יש להגדירן                                     |                   |
|כפשעים. לכן מוצע בסעיף קטן (ב) להעניק גם לבתי משפט השלום את הסמכות לדון                                            |                   |
|בעבירות נגד המשק שיובאו לפניו ובלבד שהעונש שיטיל במקרה זה לא יעלה על העונש                                         |                   |
|המקסימלי שהוא מוסמך לפסוק בדרך כלל.                                                                                |                   |
