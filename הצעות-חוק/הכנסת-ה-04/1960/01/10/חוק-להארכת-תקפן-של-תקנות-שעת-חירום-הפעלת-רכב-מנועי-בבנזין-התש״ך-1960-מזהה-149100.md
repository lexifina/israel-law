|מתפרסמת בזה הצעת חוק מטעם הממשלה:                     |

|חוק להארכת תקפן של תקנות-שעת-חירום                                       |
|(הפעלת רכב מנועי בבנזין), תש"ך-1960                                      |

|1. תקפן של תקנות-שעת-חירום (הפעלת רכב מנועי בבנזין), תשי"ח-1957 1, מוארך                                            |הארכת הוקף        |
|בזה עד יום ה' בתמוז תש"ך (30 ביוני 1960).                                                                           |                  |
|2. תחילתו של חוק זה היא כתום שלושת החדשים הראשונים לתקופת כהונתה של                                                 |תחילה             |
|הכנסת הרביעית.                                                                                                      |                  |
|דברי הסבר                                                                                                           |                  |
|ביום י"ח בכסלו תשי"ח (11 בדצמבר 1957) התקינו שר האוצר ושר התחבורה תקנות-                                            |                  |
|שעת-חירום, המאפשרות לאסור את השימוש בסוגי דלק מסויימים להנעת כלי רכב מנועי                                          |                  |
|ולקבוע את סוג הדלק שבו יונעו כלי רכב כאמור. תכליתן של תקנות אלה היתה לאסור                                          |                  |
|הפעלת כלי רכב מנועי בדלק שאינו בנזין, נוכח העובדה שהחלו להשתמש בנפט למטרה                                           |                  |
|זו - שימוש המביא לבלאי במנוע וגורם להוצאות יתר במטבע-חוץ, וזה בנוסף לתוצאות                                         |                  |
|שליליות אחרות כגון זיהום האויר ופגיעה בבריאות הציבור על ידי האדים הנפלטים עקב                                       |                  |
|בעירת הנפט' וכן ירידה ניכרת בהכנסות האוצר ממכס על בנזין. איסור' על פי התקנות                                        |                  |
|הללו' הוטל בצו-שעת-חירום (הפעלת רכב מנועי בבנזין), תשי"ח-1957 2.                                                    |                  |
|ב-19 בינואר 1959 הניחה הממשלה על שולחן הכנסת הצעת חוק בדבר הפעלת רכב                                                |                  |
|מנועי בבנזין, ؀ࠂࠌࠎתשי"ט-1959 3, שמטרתו היתה להפוך את התקנות לחוק קבע. כדברי ההסבר                                   |                  |
|להצעת חוק זו פורסם, בין השאר, גם הנוסח המלא של התקנות.                                                              |                  |
|הכנסת השלישית לא הספיקה לגמור את הדיון בהצעה זו אלא האריכה את תקפן                                                  |                  |
|של התקנות עד סוף שנת 1959; אולם מכוח סעיף 38 לחוק-יסוד: הכנסת 4, מוארך התוקף                                        |                  |
|מעבר למועד זה עד תרם שלושת החדשים הראשונים לתקופת כהונתה של הכנסת הרביעית.                                          |                  |
|הצורך בתקנות אלה בעינו עומד; אולם מאחר שלא יהא סיפק בידי הכנסת לגמור                                                |                  |
|את הדיון בהצעת החוק' שתבוא להחליף את התקנות, עד למועד שבו תם תקפן, מוצע                                             |                  |
|להאריך את תקפן עד יום ה' בתמוז תש"ך (30 ביוני 1960).                                                                |                  |
