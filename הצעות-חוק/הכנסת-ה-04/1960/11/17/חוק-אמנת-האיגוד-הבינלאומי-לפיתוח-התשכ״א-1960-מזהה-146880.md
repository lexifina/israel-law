|מתפרסמות בזה הצעות חוק מטעם הממשלה:                        |

|חוק אמנת האיגוד הבין-לאומי לפיתוח, תשכ"א-1960                                            |

|1. בחוק זה-                                                                                                        |הגדרות               |
|"אמנת האיגוד" - פרקי ההסכם בדבר כינון האיגוד הבין-לאומי לפיתוח (להלן- האיגוד).                                     |                     |
|2. משעה שאמנת האיגוד תהיה חתומה בשם המדינה יהיה שר האוצר רשאי -                                                    |תשלומים לאיגוד       |
|(1) לשלם בשם המדינה לאיגוד את הסכומים שיש לשלמם על פי אמנת האיגוד;                                                 |                     |
|(2) להוציא בשם המדינה, בהתאם לפרק ב', סעיף 2 (ה) של אמנת האיגוד,                                                   |                     |
|שטרי חוב שאינם סחירים, אינם נושאים ריבית ומשתלמים עם הדרישה בערכם                                                  |                     |
|הנקוב.                                                                                                             |                     |
|3. בנק ישראל ייצג את המדינה בכל ענין הנוגע לחברות המדינה באיגוד.                                                   |ייצוג                |
|4. שר האוצר ממונה על ביצוע חוק זה, והוא רשאי להתקין תקנות בכל ענין הנוגע                                           |ביצוע ותקנות         |
|לביצוען של הוראות אמנת האיגוד ולמילוי התחייבויותיה של המדינה על פיהן; ובמיוחד                                      |                     |
|בדבר מעמדם, חסינויותיהם וזכויות היתר של האיגוד ושל נגידיו, מנהליו,؀ࠂࠊࠌ חליפיו, פקידיו,                             |                     |
|ועובדיו.                                                                                                           |                     |
|דברי-הסבר                                                                                                          |                     |
|על הקמת האיגוד הבין-לארמי לפיתוח הוחלט בישיבת מועצת הנגידים של הבנק                                                |                     |
|הבין-לאומי לשיקום ולפיתוח בספטמבר 1959. תפקידיו של האיגוד הם עידוד ההתפתחות                                        |                     |
|הכלכלית הגדלת התפוקה והעלאת רמת החיים במדינות פחות מפותחות שהן חברות באיגוד                                        |                     |
|על ידי מימון מפעלי הפיתוח שלהן בתנאים גמישים יותר מן הנהוגים בהלוואות בנקאיות                                      |                     |
|רגילות, כד* להפחית את הלחץ על מאזן התשלומים של המדינה המקבלת את ההלוואה.                                           |                     |
|תכליתו של החוק המוצע היא לאפשר למדינת ישראל לבצע את הוראות האמנה.                                                  |                     |
