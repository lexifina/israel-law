|שעת-חירום (אזורי בטחון), תש"י-1950 2,יובא בפני הועדה לעניני חוץ ובטחון של הכנסת תוך         |                     |                     |
|עשרה ימים מיום פרסומו ברשומות; והועדה רשאית, על-ידי החלטה שתפורסם ברשומות, לבטל             |                     |                     |

|4. שר הבטחון רשאי למנות כל קצין צבא-ההגנה-לישראל בדרגת סגן-אלוף או בדרגה גבוהה              |רשויות מוסמכות       |                     |

|באזור הבטחון ובסביבתו ומתוך התושבים הקבועים שלאזור הבטחון ותושבי סביבתו; ואם אין            |                     |                     |
