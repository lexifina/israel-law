|הוספת תקנה 8ג     |1. אחרי תקנה 8ב לתקנות ההגנה (כספים), 1941 1, תבוא תקנה זו:                                                     |
|                  |8ג. שר האוצר רשאי' בצו, לפטור סוגי נוסעים מחובת ההצהרה על                                 |"סמכות לפטור         |
|                  |מטבע-חוץ וניירות ערך ומחובת הצגתם כאמור בתקנת 8ב (א)."                                    |מחובת הצהרה          |
|                  |דברי-הסב ר                                                                                                      |
|                  |לפי תקנה 8 ב (א) לתקנות ההגנה (כספים)' 1941 , חובה על כל אדם העומד להיכנס                                       |
|                  |לישראל להצהיר על מטבע-החוץ וניירות הערך שברשותו ולהציגם בפני הפקיד המוסמך.                                      |
|                  |למען עידוד התיירות רצוי לפטור תיירים תושבי חוץ הנכנסים לישראל מהחובה האמורה;                                    |
|                  |ותכליתו של החוק הנ?וצע ה יא להסמיך לכך את שר האוצר.                                                             |
|                  |וזהו נוסחה של תקנה 8ב(א):                                                                                       |
|                  |"כל אדם העומד להיכנס לישראל (הנקרא להלן נוסע") יהא חייב להצהיר בפני הפקיד                                       |
|                  |המוסמך אם יש ברשותו מטבע-חוץ או ניירות-ערך ואם לאו, ולהציג לפקיד המוסמך כל מטבע-                                |
|                  |הוץ או נייר-ערך שברשותו. הפקיד؀ࠂࠊࠌ המוסמך יהא רשאי לערוך חיפוש אצל כל נוסע ובכל כלי                             |
|                  |רכב או אמצעי הובלה בל נכו.ס נוסע לישראל, ולבדוק כל הפץ שניסע נושא עמו או על גופו, כדי                           |
|                  |להיווכח אם יש ברשותו מטבע-חוץ או ניירות ערך; אלא שחיפוש אצל אשה ייעשה על ידי אשה                                |
|                  |בלבד."                                                                                                          |
