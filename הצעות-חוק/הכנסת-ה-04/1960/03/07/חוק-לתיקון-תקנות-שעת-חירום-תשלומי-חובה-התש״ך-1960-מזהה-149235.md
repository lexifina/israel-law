|1. תקנות-שעת-חירום (תשלומי חובה), תשי"ח-1958, מסמיכות להטיל תשלום חובה                                            |                  |
|על טובין, כל אימת שהדבר דרוש לאחת המטרות המפורטות בתקנה 4 (ראה נוסח                                               |                  |
|תקנה 4 להלן).                                                                                                     |                  |
|תקנה 5 קובעת' כי אין להטיל תשלום חובה' אלא אם הודיע השר למחזיק הטובין                                             |                  |
|לפני שסיפק אותם כי הם נתונים לבקורת תחשיבית וכי הוא עשוי להיות חייב עליהם בהיטל'                                  |                  |
|במידה שישיג ריווח עודף.                                                                                           |                  |
|בעסקי יבוא ויצוא הנוהג הוא, כי היבואן הישראלי רוכש בחו"ל את הטובין במזומנים,                                      |                  |
|אך לשם סילוק מחיר הטובין מאפשר לו אוצר המדינה לקבל אשראי במטבע-חוץ מכספי                                          |                  |
|קרן החליפין המתנהלת בבנק ישראל. שיטה זו נהוגה בעיקר כאשר יבוא הטובין הוא לשם                                      |                  |
|יצואם, לאחר תהליך של ייצור בישראל. אם בין יום קבלת האשראי מקרן החליפין כאמור                                      |                  |
|לבין יום פרעונו על ידי היבואן חל במדינה שממנה יובאו הטובין פיחות במטבע של אותה                                    |                  |
|מדינה, הרי מקבל האשראי זוכה בריווח עודף על מטבע-החוץ שניתן לו באשראי מכספי                                        |                  |
|המדינה.                                                                                                           |                  |
|לפי התקנות הקיימות אין על פי רוב האפשרות להטיל תשלום חובה במקרה כגון זה'                                          |                  |
|מאחר שתקנה 5 אינה מאפשרת היטל של תשלום חובה אלא אם הודיע השר למחזיק הטובין                                        |                  |
|לפני שמכר את הטובין על כוונתו להטיל היטל כזה. ואילו במקרים הנדונים הפיחות במטבע-                                  |                  |
|החוץ עלול לחול לאחר שהטובין כבר נמכרו' אך לפני שמקבל האשראי פרע את האשראי                                         |                  |
|במטבע-החוץ המופחת. מקרה דומה קרה שעה שחל פיחות בפרנק הצרפתי בדצמבר 1958.                                          |                  |
|האוצר מתוך הופר אפשרות להטיל תשלום חובה על מקבל אשראי כנ"ל - מאחר שפיחות                                          |                  |
|הפרנק חל לאחר שהטובין יוצאו מישראל - קבע בחוזר מטעם המפקח על מטבע-חוץ אל                                          |                  |
|הסוחרים המוסמכים כי אדם שקיבל באשראי פרנקים לפני הפיחות חייב לשלם בעד פרנקים                                      |                  |
|שהוא רוכש לאחר הפיחות' לשם סילוק אותו אשראי' את מחיר הפרנק שלפני הפיחות.                                          |                  |
