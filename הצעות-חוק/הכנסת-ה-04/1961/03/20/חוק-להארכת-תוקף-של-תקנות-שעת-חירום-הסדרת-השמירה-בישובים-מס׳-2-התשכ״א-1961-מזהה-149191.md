|דברי הסבר                                                                                                           |
|ביום ט"ז באייר תשט"ז (27 באפריל 1956) התקין שר הפנים תקנות-שעת-חירום                                                |
|שמטרתן לאפשר לישובים להטיל את חובת השמירה על תושביהם. תקפן של תקנות אלה                                             |
|הוארך מדי פעם בפעם על ידי הכנסת, ולאחרונה נקבע כי תקפן יפקע ביום ט"ז בסיון                                          |
|תשכ"א (31 במאי 1961). בעקבות משאלתה של הכנסת הוכנה הצעת החוק הבאה להחליף                                            |
|את תקנות-שעת-החירום בחוק של קבע, הצעה זו העברה כבר לדיון ואישור לממשלה ויש                                          |
|לקוות שבזמן הקרוב כיותר תובא בפני הכנסת. מאידך הצורך בתקנות אלה בעינו עומד                                          |
|ולכן מציעה הממשלה להאריך את תקפן לשלושה חדשים נוספים.                                                               |
|וזה הנוסח של תקנות-שעת-חירום (הסדרת השמירה בישובים), תשט"ז-1956:                                                    |

|ו. בתקנות אלה -                                                                              |"הגדרות              |
|"מועצה" - מועצתה של רשות מקומית; ולגבי ישוב הנמצא מחוץ לתחום רשות מקומית, יראו               |                     |
|את הממונה על המחוז בו נמצא הישוב במועצה לענין תקנות אלה;                                     |                     |
|"מפקד אזור (מא"ז)" - אדם שאלוף פיקוד או מי שהוסמך על ידיו, מינהו למפקד אזור (מא"ז)           |                     |
|או לרכז בטחון שוטף (רב"ש) או לרכז בטחון שוטף צבאי (רבש"צ), ובלבד שלמינוי רכז                 |                     |
|בטחון שוטף בפיקוד שבו השמירה נתונה בידי המשטרה יסמיך אלוף הפיקוד את הממונה                   |                     |
|מטעם המשטרה על השמירה באותו פיקוד.                                                           |                     |
|"שמירה" - לרבות פעולה הדרושה, לדעת מפקד אזור (מא"ז), לשמירה על בטחון תושבי ישוב              |                     |
|או רכושם.                                                                                    |                     |
|2. מועצה רשאית, באישור שר הפנים, להסדיר, בחוק עזר שיפורסם ברשומות (להלן -                    |הסדרת השמירה         |
|חוק העזר), את השמירה בתחומה, כולו או מקצתו.                                                  |                     |
|3. בחוק עזר רשאית המועצה להטיל חובת השמירה בתחום ישוב מסויים על תושבי אותו                   |חוקי עזר             |
|ישוב שנמצאו מסוגלים לכך בדרך שתקבע בחוק העזר/ ומשעשתה כן, תקים באותו חוק עזר                 |                     |
|לאזור כולו או לכל חלק ממנו לחוד כפי שתקבע בחוק העזר, ועדת שמירה או רשות שמירה                |                     |
|ובן ועדת ערר ותקבע בו את סמכויותיהן; ובלבד שהסדר השמירה לפי חוק העזר ייעשה בהתאם             |                     |
|להוראת מפקד אזור (מא"ז).                                                                     |                     |
