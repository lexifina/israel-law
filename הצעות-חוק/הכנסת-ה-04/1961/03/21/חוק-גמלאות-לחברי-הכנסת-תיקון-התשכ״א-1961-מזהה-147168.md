|2, במקום סעיף 2 לחוק העיקרי יבוא :                                                                               |החלפת סעיף 2        |
|2. חבר הכנסת שחדל לכהן אחרי שהגיע לגיל ארבעים וחמש וכיהן                                  |"קיצבה לחבר           |                    |
|עשר שנים לפחות, או אחרי שהגיע לגיל חמישים וכיהן שש שנים לפחות,                            |כנסת שחדל לכהן        |                    |
|תשולם לו מהיום שחדל לכהן וכל ימי חייו, קיצבה חדשית שהיא שליש                              |                      |                    |
|האחוז ממשכורת חברי הכנסת כפול במספר חדשי כהונתו בכנסת, ואולם -                            |                      |                    |
|(1) מי שמלאו לו חמישים וחמש שנה כשחדל לכהן תינתן                                          |                      |                    |
|לו תוספת על הקיצבה שני אחוזים ממשכורת חברי הכנסת                                          |                      |                    |
|לכל שנת גילו שלמעלה מחמישים וחמש בשעה שחדל;                                               |                      |                    |
|(2) הקיצבה למי שהיה חבר הכנסת יותר מעשר שנים לא                                           |                      |                    |
|תפחת מ-50% ממשכורת חברי הכנסת;                                                            |                      |                    |
|(3) הקיצבה לא תעלה על 70% ממשכורת חברי הכנסת."                                            |                      |                    |
|3, במקום סעיף 4 לחוק העיקרי יבוא:                                                                                |החלפת סעיף 4        |

|כהונתו כיושב ראש הכנסת, לגימלאות לפי חוק הגימלאות לשרים,                                  |ראש הכנסת             |                    |

|תשי"ז-1957, שנאמר בו "שר" - חוץ מן הביטוי "משכורת שרים" -                                 |                      |                    |
