|1. בסעיף 3 לחוק תקציבי השירותים הדתיים היהודיים, תש"ט-1949 1, במקום סעיף                                             |תיקון סעיף 3     |
|קטן (ה) יבוא:                                                                                                        |                 |
|"(ה) כהונתה של מועצה דתית תתם לא יאוחר מיום כ"ה באדר תשכ"ב                                                           |                 |
|(31 במרס 1962),"                                                                                                     |                 |
|דברי הסבר                                                                                                            |                 |
|חוק תקציבי השירותים הדתיים היהודיים, תש"ט-1949, קובע הסדר בדבר תקציבן                                                |                 |
|של המועצות הדתיות היהודיות הקיימות, המטפלות בסיפוק שירותים דתיים לתושבים                                             |                 |
|היהודיים.                                                                                                            |                 |
|בסעיף 3(ה) של החוק הנ"ל נאמר שמועצה דתית קיימת לא תכהן יותר משנה אחת                                                 |                 |
|מיום פרסום החוק ברשומות. החוק נתפרסם ברשומות ביום כ"ב באב תש"ט (17 באוגוסט                                           |                 |
|1949), וכהונתן של המועצות הדתיות הקיימות עמדה איפוא לתום ביום ג' באלול תש"י                                          |                 |
|(16 באוגוסט 1950).                                                                                                   |                 |
|מאז הוארכה תקופת כהונתן של המועצות הדתיות הקיימות מפעם לפעם 2ולאחרונה                                                |                 |
|נתקבל בכנסת חוק תקציבי השירותים הדתיים היהודיים (תיקון), תש"ך-1960 3, המאריך                                         |                 |
|את תקופת כהונתן של המועצות הקיימות עד יום כ"ח באדר תשכ"א (16 במרס 1961).                                             |                 |
|בזמן הדיונים על ההארכה האחרונה בכנסת הבטיח שר הדתות הרב י. מ. טולידאנו                                               |                 |
|זצ"ל, להביא הצעת חוק המסדירה באורח קבע את עניני ؀ࠂࠌࠎהדת הציבוריים, אך עד להכנתו                                      |                 |
|הסופית של חוק זה יעבור כנראה זמן מה, ולכן מציעה הממשלה להאריך את תקופת כהונתן                                        |                 |
|של המועצות הדתיות היהודיות הקיימות לשנה נוספת.                                                                       |                 |
