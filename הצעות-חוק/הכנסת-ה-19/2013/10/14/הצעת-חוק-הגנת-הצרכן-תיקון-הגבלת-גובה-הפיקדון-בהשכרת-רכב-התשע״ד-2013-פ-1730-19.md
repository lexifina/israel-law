|הוספת סעיף 14א1            |1.      |בחוק הגנת הצרכן, התשמ"א–1981[1], אחרי סעיף 14א יבוא:                                                     |
|                           |        |"עסקה בעניין השכרת רכב     |14א1.   |בעל רישיון להפעלת שירות של השכרת רכב לפי דין לא ידרוש מצרכן המבקש   |
|                           |        |                           |        |לשכור רכב פיקדון בשיעור העולה על סכום ההשתתפות העצמית המרבי בפוליסה |
|                           |        |                           |        |לביטוח הרכב לפי פקודת ביטוח רכב מנועי [נוסח חדש], התש"ל–1970[2]."   |

דברי הסבר

   חברות להשכרת רכב דורשות מלקוחותיהם להפקיד פיקדון על חשבון מסגרת האשראי של הלקוחות בסכומים שונים וגבוהים בהרבה מסכום ההשתתפות העצמית המרבי בפוליסה לביטוח רכב שאותה יידרשו לשלם במידה וייגרם נזק לרכב. בהצעת חוק זו מוצע להגביל את גובה הפיקדון לסכום המרבי של ההשתתפות העצמית כאמור.
