|הגדרות                     |1.      |בחוק זה –                                                                                                 |
|                           |        |"רשות מקומית" - עיריה או מועצה מקומית;                                                                    |
|                           |        |"ראש רשות" - ראש רשות מקומית;                                                                             |
|                           |        |"אמצעי מיגון" - התקנים, מכשירים או חפצים אחרים, המיועדים לשמש להגנה על בטחונו האישי של ראש רשות' הגנה על  |
|                           |        |כלי רכב שבו הוא משתמש, הגנה על לשכתו והגנה על הדירה בה הוא מתגורר דרך קבע;                                |
|                           |        |"פעולות אבטחה" - פעולות הנעשות על ידי אדם, והדרושות לשם שמירה על בטחונו האישי של ראש רשות;                |
|                           |        |"קצין מוסמך" - קצין משטרה בדרגת סגן ניצב ומעלה שמינה המפקח הכללי של המשטרה לענין זה.                      |
|הצבת אבטחה                 |2.      |קצין מוסמך רשאי, באם נוכח כי ראש רשות מאויים עקב פעילותו כראש הרשות, להורות על הצבת שוטר ועל הספקת אמצעי  |
|                           |        |מיגון לשם אבטחתו של ראש הרשות.                                                                            |
|הנחיית ראש הרשות           |3.      |הקצין המוסמך רשאי להנחות  את ראש הרשות בכל הנוגע לפעולות הדרושות לשם אבטחתו.                              |
|ביצוע ותקנות               |4.      |השר לבטחון פנים ממונה על ביצועו של חוק זה והוא רשאי להתקין תקנות לביצועו.                                 |

דברי הסבר

בעקבות מקרים חוזרים ונשנים בתקופה האחרונה של אלימות פיזית חמורה ביותר כלפי ראשי רשויות במקומות שונים בארץ, נדרש הצורך באבטחת נבחרי ציבור אלה המאוימים על ידי גורמים שונים. הצעת חוק זו באה להסדיר את נושא אבטחת ראשי הרשויות.
