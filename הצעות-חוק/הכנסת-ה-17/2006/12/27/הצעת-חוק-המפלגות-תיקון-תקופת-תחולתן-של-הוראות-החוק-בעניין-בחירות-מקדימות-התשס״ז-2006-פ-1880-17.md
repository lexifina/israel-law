הצעת חוק המפלגות (תיקון - תקופת תחולתן של הוראות החוק בעניין בחירות מקדימות), התשס"ז-2006

|תיקון סעיף 28ב         |1.     |בחוק המפלגות, התשנ"ב-1992[1], במקום סעיף 28ב יבוא:                                                               |
|                       |       |תקופת תחולה            |"28ב.    |"ההגבלות שבפרק זה יחולו על התקופה שהחל מהיום שאחרי יום הבחירות המקדימות במפלגה |
|                       |       |                       |         |ועד יום הבחירות המקדימות הבאות".                                               |

דברי הסבר

המצב הקיים, לפיו תרומה למועמד לבחירות מקדימות עומדת בכללי ההגבלה של חוק המפלגות רק בתשעה החודשים שלפני ההתמודדות, או פחות, במקרה של התמודדות בלתי מתוכננת - מאפשרת למועמדים לגייס תרומות ללא כל פיקוח בחודשים ובשנים שלפני ההתמודדות, ולהפחית את קבלת התרומות לתחום המותר רק לקראת ההתמודדות עצמה.
הצעת חוק זו באה לתקן מצב לפיו תרומות בסכומים אדירים מועברות למועמדים בתקופה הקודמת לזו המוגבלת ומפוקחת על פי החוק. על פי ההצעה, ההגבלות החלות כיום רק לקראת ההתמודדות תחולנה בכל התקופה שמאז ההתמודדות הקודמת במפלגה.
