הצעת חוק מס ערך מוסף (תיקון - מס בשיעור אפס על מוצרי בטיחות בדרכים), התשס"ו 2006

|תיקון סעיף 30   |1.     |בחוק מס ערך מוסף, התשל"ו-1975[1], בסעיף 30(א), בסופו יבוא:                                         |
|                |       |"(18)     |מכירת טובין שעיקר תכליתם בטיחות בדרכים; לענין פסקה זו, "טובין שעיקר תכליתם בטיחות       |
|                |       |          |בדרכים" – טובין שיש בהם הפוטנציאל להציל אדם ממוות ולצמצם את הפגיעה הפיזית בו בעודו נמצא |
|                |       |          |ברכב מנועי, ואשר רכישתם מחוייבת לפי פקודת התעבורה[2]."                                  |

דברי – הסבר

לאור המצב העגום בישראל, בו מאות בני אדם נהרגים ואלפים נפצעים מדי שנה כתוצאה מתאונות דרכים, קבע משרד התחבורה רשימת מוצרים ועזרים שונים שמטרתם הצלת אדם ממוות וצמצום הפגיעה הפיזית בו בעודו נמצא ברכב מנועי, בהם מחויבים האזרחים להצטייד.

מוצרים אלו כגון מושבי בטיחות ומושבים מגביהים לילדים מגיל 0 עד 9 שנים, הנם מוצרים אשר חייבים להיות מותאמים לגילו של הילד, גובהו ומשקלו, ולכן יש צורך לקנות מספר מושבים לכל ילד במהלך השנים. מוצרים אלו הנם יקרים ומהווים הוצאה של מאות ואף אלפי שקלים למשפחה בעלת מספר ילדים.

תכליתה של הצעת חוק זו להקטין את העול הכספי הנובע מקניית מוצרים חיוניים אלו, למען כי כל אזרח יוכל לקנות את מוצרי הבטיחות האלו ובכך להציל חיים. על כן מוצע לפטור ממס ערך מוסף את מכירתם של אותם מוצרים.

הצעת חוק זהה הונחה על שולחן הכנסת השש-עשרה על ידי חבר הכנסת ואסל טאהא וקבוצת חברי הכנסת (פ/3408).
