|תיקון סעיף 332             |1.      |בחוק העונשין, התשל"ז-1977[1], בסעיף 332, האמור בו יסומן "(א)" ואחריו יבוא:                                |
|                           |        |"(ב)    |(1) הורשע אדם בעבירה לפי סעיף זה, לא יפחת עונשו מארבע שנות מאסר, אלא אם כן החליט בית המשפט,     |
|                           |        |        |מטעמים מיוחדים שיירשמו, להקל בעונשו;                                                            |
|                           |        |        |(2) עונש מאסר לפי סעיף פסקה (1) לא יהיה, בהעדר טעמים מיוחדים, כולו על-תנאי."                    |

דברי הסבר

בשנת 2007 חלה עליה משמעותית ביותר לעומת השנה הקודמת לה באירועים של ידויי אבנים לעבר כלי רכב ישראליים הנעים בכבישי הארץ. עשרות אירועים של זריקות אבנים נרשמו ברחבי הארץ.
   אירוע זריקת אבנים הוא אירוע חמור העלול להסתיים בהרג, כפי שכבר אירע בעבר. בחלק מן המקרים יש צורך אף בסגירת הכביש בכדי למנוע פגיעה אפשרית בנוסעים בו.
   העונשים המושתים כיום על זורקי אבנים אינם משקפים נכונה את חומרת המעשה, אפילו שזה מסתיים בלי פגיעה משמעותית. לאור התגברות התופעה כאמור, מוצע לחייב את בית המשפט לתת עונש מזערי של 4 שנות מאסר למיידי אבנים.
