פ/3499/17

הצעת חוק האזרחים הוותיקים (תיקון – קצבת זקנה לנכה ותיק אשר לא משתלמת לו גמלת הבטחת הכנסה), התשס"ח–2008

|הוספת סעיף 14א             |1.      |בחוק האזרחים הוותיקים, התש"ן–1989[1], אחרי סעיף 14 יבוא:                                                  |
|                           |        |"זכויות לאזרח ותיק נכה אשר |14א.    |הוראות לפי כל דין או הוראות מכוח הסכם או נוהג בגוף ציבורי, לענין    |

|                           |        |                           |        |אשר הוכיח להנחת דעתו של המוסד לביטוח לאומי כי אלמלא הוראות סעיף 251 |

|                           |        |                           |        |בישראל, התשנ"ד–1994[3] ".                                           |

דברי הסבר

   כיום אזרחים המגיעים לגיל זקנה (אזרח ותיק) ומשתלמת להם גמלת הבטחת הכנסה, זכאים לפי כל דין, הוראות מכוח הסכם או נוהג בגוף ציבורי, להטבות וזכויות שונות. לעומתם נכים המגיעים לגיל זקנה ואלמלא גמלת הנכות, היו זכאים לקבלת גמלת הבטחת הכנסה אינם זכאים לתנאים ולזכויות אלו.
   הצעת חוק זו באה לתקן עיוות זה ובאה להשוות את התנאים והזכויות להם זכאי אזרח ותיק אשר משתלמת לו גמלת הבטחת הכנסה לעומת אזרח ותיק נכה שעקב גמלת הנכות אינו זכאי לגמלת הבטחת הכנסה.
