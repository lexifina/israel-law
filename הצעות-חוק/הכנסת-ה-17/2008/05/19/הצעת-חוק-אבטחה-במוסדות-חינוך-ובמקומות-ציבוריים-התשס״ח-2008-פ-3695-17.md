פ/3695/17

הצעת חוק אבטחה במוסדות חינוך ובמקומות ציבוריים, התשס"ח–2008

|הגדרות                     |1.      |בחוק זה –                                                                                                 |
|                           |        |"מוסד חינוכי" – גן ילדים, בית ספר, פנימייה, ישיבה או מוסד להשכלה גבוהה, וכן יחידת סמך של כל אחד מהם;      |
|                           |        |"מקום הומה אדם" – מקום ציבורי המכיל 200 איש ומעלה;                                                        |
|                           |        |"השר" – השר לביטחון הפנים.                                                                                |
|חובת אבטחה                 |2.      |מוסד חינוכי ומקום הומה אדם חייב באבטחה.                                                                   |
|סמכויות                    |3.      |משטרת ישראל הינה הגורם המוסמך להנחות בכל הקשור למימון ולתכנון האבטחה על פרטיה וסדריה ולהוצאתה לפועל בהתאם |
|                           |        |לתקנות לעניין חוק זה.                                                                                     |
|בקרה ופיקוח                |4.      |השר יגדיר מנגנוני בקרה ופיקוח באמצעות הגופים המופקדים על האבטחה במשטרת ישראל, וכן חובת דיווח עתי.         |
|ביצוע ותקנות               |5.      |השר ממונה על ביצוע חוק זה והוא רשאי, בהסכמת ראש הממשלה ושר הביטחון, ובאישור ועדת הפנים והגנת הסביבה של    |
|                           |        |הכנסת, להתקין תקנות לביצועו.                                                                              |

דברי הסבר

   בעקבות התקפות טרור על מוסדות חינוך, קם הצורך להסדיר בחקיקה ראשית את עניין אבטחתם של מוסדות חינוך ומקומות הומי אדם, אשר תגביר את האבטחה במוסדות החינוך והשוהים במקומות ציבוריים הומי אדם, ותסייע במניעת פגיעה המונית בנפש וברכוש.
