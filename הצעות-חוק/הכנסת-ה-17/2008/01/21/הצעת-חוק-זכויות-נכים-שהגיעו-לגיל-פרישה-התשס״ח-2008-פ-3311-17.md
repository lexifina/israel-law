הצעת חוק זכויות נכים שהגיעו לגיל פרישה, התשס"ח–2008

|המשך החלת זכויות           |1.      |מבוטח ששולמה לו קצבת נכות לפי פרק ט' לחוק הביטוח הלאומי [נוסח משולב], התשנ"ה–1995[1] (להלן – חוק הביטוח   |
|                           |        |הלאומי), בתכוף לפני שנעשה זכאי לקצבת זקנה לפי פרק י"א לחוק הביטוח הלאומי, לא יפסיקו לחול לגביו הוראות     |
|                           |        |החלות לגבי זכאי לקצבת נכות, רק בשל הגיעו לגיל פרישה; לעניין סעיף זה "הוראות" – כל אחד מאלה:               |
|                           |        |(1) הוראות לפי כל דין;                                                                                    |
|                           |        |(2) הוראות מכוח הסכם או נוהג בגוף ציבורי כהגדרתו בחוק אזורים חופשיים לייצור בישראל, התשנ"ד–1994[2].       |

דברי הסבר

   על פי חוק הביטוח הלאומי, נכים הזכאים לקצבת נכות ומגיעים לגיל זקנה חדלים מלהיות נכים והופכים לזקנים הזכאים לקצבת זקנה. מבחינה חוקית-טכנית אין כל אפשרות להיות גם זקן וגם נכה, כך שלא נותר זכר רשמי לנכות עם המעבר לגיל הזקנה. בשל העובדה שקצבת הנכות גבוהה מקצבת הזקנה תוקן החוק כך שאותם "נכים-זקנים", זכאים לתוספת לקצבת הזקנה שלהם כך שתגיע לסכום קצבת הנכות ששולמה להם טרם הגיעו לגיל הזקנה. אך התיקון המוצע לא מטפל בבעיה מהותית נוספת שעולה עם המעבר הטכני ממעמד של נכה למעמד של זקן, הזכאות לקצבת הנכות מקנה זכויות משמעותיות במוסדות שונים, שרובן אינן ניתנות לזכאים לקצבת זקנה. בין השאר ניתן למנות: הנחה ניכרת בארנונה, סיוע בשכר דירה דרך משרד השיכון, הנחות במס רכישה ובמס הכנסה ועוד. עם השנים וההזדקנות גדלים הקשיים וההוצאות הבריאותיות והאחרות, כך שלרוב המצוקה הכלכלית גדלה ולכן אסור לפגוע בזכויות המגיעות לנכים רק בגלל שהפכו "זקנים".
   ולכן מוצע לקבוע כי נכה שהגיע לגיל פרישה, ימשיכו זכויותיו והטבותיו שקיבל בזמן היותו נכה גם לאחר הגיעו לגיל פרישה.
