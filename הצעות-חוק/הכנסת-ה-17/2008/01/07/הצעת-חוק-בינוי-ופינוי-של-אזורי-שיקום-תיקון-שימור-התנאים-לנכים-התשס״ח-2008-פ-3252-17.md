הצעת חוק בינוי ופינוי של אזורי שיקום (תיקון – שימור התנאים לנכים), התשס"ח–2008

|תיקון סעיף 23              |1.      |בחוק בינוי ופינוי של אזורי שיקום, התשכ"ה–1965[1] (להלן – החוק העיקרי), בסעיף 23(א), אחרי פסקה (3) יבוא:   |
|                           |        |"(4) בכללים כאמור בסעיף זה, לא תיאסר בניה באזור שיקום שנועדה למטרות הקמת מרחב מוגן כהגדרתו לפי חוק        |
|                           |        |ההתגוננות האזרחית, התשי"א–1951[2], או שנועדה לביצוע התאמות נגישות לאנשים עם מוגבלות כהגדרתם בחוק שוויון   |
|                           |        |זכויות לאנשים עם מוגבלות, התשס"ה–2005[3] (להלן – חוק שוויון זכויות לאנשים עם מוגבלות)".                   |
|תיקון סעיף 39              |2.      |בסעיף 39(ב) לחוק העיקרי, בסופו יבוא "שימשו המקרקעין למגורים של אדם עם מוגבלות כמשמעותו בחוק שוויון זכויות |
|                           |        |לאנשים עם מוגבלות – יכלול הדיור החלוף את התנאים הדרושים לצרכיו המיוחדים, כפי שהיו קיימים טרם ההפקעה".     |

דברי הסבר

   לפי הצעת חוק זו, יש לאפשר מעבר דירה של אדם נכה, מתוקף חוק בינוי ופינוי של אזורי שיקום, התשכ"ה–1965 (להלן – חוק בינוי פינוי), תוך שמירה על התנאים הדרושים לו לצרכיו המיוחדים. כך למשל, אדם נכה המתגורר בדירת קרקע, לא יועבר לדירה בקומה עליונה, כיוון שמעלית אינה מהווה פיתרון מושלם עבורו.
   מעבר לכך, הצעת חוק זו מאפשרת בנית ממ"דים ובניה לשם התאמת הדירה לצרכים של אדם עם מוגבלות, גם באזור שנועד לשיקום על פי חוק בינוי פינוי.
