הצעת חוק פיצוי לפליטים יהודים מארצות ערב במסגרת תהליך השלום, התשס"ח–2008
|                                                                                                                                             |
|מטרה                                                                                                                                         |
|1.                                                                                                                                           |
|מטרתו של חוק זה לשמור על זכויותיהם של אזרחי מדינת ישראל ווזכויותיהם של יהודים שעלו ארצה מארצות ערב ועזבו את בתיהם ורכושם בעקבות הקמת מדינת   |
|ישראל ומוגדרים כפליטים על פי אמנת הפליטים של האו"ם.                                                                                          |
|                                                                                                                                             |
|הגדרות                                                                                                                                       |
|2.                                                                                                                                           |
|בחוק זה –                                                                                                                                    |
|                                                                                                                                             |
|                                                                                                                                             |
|                                                                                                                                             |
|"פליטים יהודים"– אזרחי ישראל ויהודים שעלו ארצה מארצות ערב שעלו ארצה ועזבו את נכסיהם בעקבות הקמת מדינת ישראל ומוגדרים כפליטים על פי אמנת      |
|הפליטים של האו"ם.                                                                                                                            |
|                                                                                                                                             |
|חתימה על הסכם מדיני                                                                                                                          |
|3.                                                                                                                                           |
|לא תחתום הממשלה או מי מטעמה על אמנה או הסכם עם מדינה, גוף או רשות, שעניינם הסדר מדיני במזרח התיכון מבלי להבטיח את זכויות הפליטים היהודים.    |
|                                                                                                                                             |
|                                                                                                                                             |
|                                                                                                                                             |
|(1)       בכל דיון בנושא הפליטים הפלסטינאים במסגרת משא ומתן לשלום במזרח התיכון, תדאג הממשלה לדון בפיצוי ומעמד שווה לפליטים הערבים שעזבו את   |
|נכסיהם מיום הקמת המדינה וליהודים שנאלצו לעזוב את נכסיהם בארצות ערב בעקבות הקמת המדינה;                                                       |
|(2)  הממשלה תגדיר באופן מדויק את הנכסים שהיו בבעלותם של הפליטים היהודים.                                                                     |
|                                                                                                                                             |
|                                                                                                                                             |
|                                                                                                                                             |
|                                                                                                                                             |
|                                                                                                                                             |
|דברי הסבר                                                                                                                                    |
|                                                                                                                                             |
|על פי הצהרת האו"ם בדבר זכויותיהם של עמים ילידים, למדינה יש חובה לפצות ילידים על אדמות ונכסים תרבותיים, דתיים ורוחניים שאבדו להם בעבר.  על פי |
|עקרון זה המענה היחיד לתביעת הפלסטינאים ל"זכות השיבה" היא פיצוי הולם על פי החלטת האו"ם לזכויות הילידים.                                       |
|                                                                                                                                             |
|מוצע כי במקביל הממשלה תפעל על פי החלטות האו"ם להשבת פליטים בעניין פיצוי הולם למיליון וחצי יהודים שגורשו או ברחו ונאלצו לעזוב את בתיהם ורכושם |
|בארצות ערב מאז קום המדינה.                                                                                                                   |
|הקונגרס האמריקאי קיבל החלטה ( HRES 185 EH) בפברואר 2008 שקבעה כי היהודים  אשר גורשו או ברחו מבתיהם בארצות המזרח התיכון מוגדרים כפליטים על פי |
|ההגדרה המפורשת באמנה הפליטים של האו"ם.  עוד נקבע כי על  ארצות הברית חלה החובה לדרוש בשיחות על תהליך השלום במזרח התיכון שיוענק אותו מעמד      |
|לפליטים בני כל הדתות כולל יהודים ונוצרים כפי שמוענק לפליטים הפלסטינאים, ולמעשה נקבע כי ארה"ב תכיר בעקרון של יחס שוויוני לכל קרבנות הסכסוך    |
|הישראלי- ערבי,                                                                                                                               |
|על כן מוצע כי ממשלת ישראל תדאג למעמד הראוי לפליטים היהודים במזרח התיכון במסגרת תהליך השלום.                                                  |
