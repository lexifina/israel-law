הצעת חוק חובת התקנת מצלמות בגני ילדים, התשס"ח-2007

|הגדרות                     |1.      |בחוק זה –                                                                                                 |
|                           |        |"גן ילדים" – מקום המשמש, או הנועד לשמש, כולו או חלקו, מקום שהיה לילדים כשהם מחוץ למשפחתם, ולרבות מעון,    |
|                           |        |מעון יום ומשפחתון;                                                                                        |
|                           |        |"ילד" – מי שבראשית שנת הלימודים היה מתחת לגיל 6;                                                          |
|                           |        |"מקום שהיה" – מקום בו שוהה ילד לצורך חינוך, השגחה, טיפול או קבלת ארוחות, למעט מוסד רפואי;                 |
|                           |        |"השר" – שר החינוך.                                                                                        |
|חובת התקנת מצלמות          |2.      |בכל גן ילדים יותקנו מצלמות, באופן שיקבע השר, לצורך פיקוח על בטיחותם ורווחתם של הילדים.                    |
|צילום ושידור               |3.      |(א) המצלמות האמורות בסעיף 2 יופעלו, והצילום ישודר באינטרנט באתר מרכזי, הכל כפי שיקבע השר בתקנות.          |
|                           |        |(ב) תקנות לפי סעיף זה יכללו, בין היתר, הוראות בדבר הגורמים, לרבות הורי הילדים, שיהיו מורשים לצפות בשידור  |
|                           |        |כאמור, ודרכי הצפייה בו.                                                                                   |
|ביצוע ותקנות               |4.      |(א) השר ממונה על ביצוע חוק זה.                                                                            |
|                           |        |(ב) תקנות לפי חוק זה יותקנו באישור ועדת החינוך, התרבות והספורט של הכנסת.                                  |

דברי הסבר
   בעקבות החשיפות האחרונות לגבי אלימות בגני ילדים ועקב התגברות האלימות בחברה הישראלית בכלל, הצעת חוק זו נועדה לחייב את גני הילדים או המשפחתונים להציב מצלמות אינטרנט בגן כתנאי לקבלת הרישיון להפעלתו.
   על פי ההצעה, כל גן ילדים – בין אם הוא פועל בפיקוח  משרד החינוך, מועצה מקומית או כל גוף אחר – יחויב להתקין מצלמות אינטרנט בין כתליו במשך כל שעות פעילותו.
   הורי הילדים יוכלו להיכנס בכל עת למערכת צפייה באתר אינטרנט מרכזי.
