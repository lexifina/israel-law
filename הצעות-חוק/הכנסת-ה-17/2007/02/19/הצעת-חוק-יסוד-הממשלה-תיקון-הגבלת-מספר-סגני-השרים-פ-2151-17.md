הצעת חוק-יסוד: הממשלה (תיקון - הגבלת מספר סגני השרים)

|תיקון סעיף 25              |1.      |בחוק-יסוד: הממשלה[1], בסעיף 25(א), בסופו יבוא "מספר סגני השרים לא יעלה על ארבעה".                        |
|תחולה                      |2.      |חוק זה יחול על הממשלה שכוננה לאחר הבחירות לכנסת השבע-עשרה.                                               |
|                           |        |        |        |        |        |        |        |        |                                        |

דברי  הסבר

חוק-יסוד: הממשלה קובע בסעיף 25 כי שר הממונה על משרד רשאי למנות סגן שר אחד. חוק היסוד אינו מגביל את מספרם של סגני השרים.
מוצע לקבוע בחוק-יסוד: הממשלה כי מספר סגני השרים לא יעלה על ארבעה.

הצעת חוק זהה הונחה על שולחן הכנסת השבע-עשרה על ידי חבר הכנסת דני יתום (פ/353/17).
