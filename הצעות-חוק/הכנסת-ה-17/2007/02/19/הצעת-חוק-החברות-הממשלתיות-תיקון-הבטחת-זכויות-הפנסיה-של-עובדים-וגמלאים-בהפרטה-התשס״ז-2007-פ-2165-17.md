הצעת חוק החברות הממשלתיות (תיקון- הבטחת זכויות הפנסיה של עובדים וגמלאים בהפרטה), התשס"ז-2007

|תיקון סעיף 59ב             |1.      |בחוק החברות הממשלתיות, התשל"ה-1975[1] בסעיף 59ב, אחרי סעיף  קטן (ט) יבוא:                                 |
|                           |        |"(י) ועדת השרים תקבע בהחלטת ההפרטה הוראות להבטחת זכויות הפנסיה של העובדים והגמלאים בחברה בהפרטה או בחברה  |
|                           |        |שניתנה לגביה החלטת הפרטה לרבות-                                                                           |
|                           |        |        |(1) חובת החברה בהפרטה להבטחת תשלומי פנסיה תקציבית לגמלאים ולשאירים;                             |
|                           |        |        |(2) חובת החברה בהפרטה להבטחת תשלומי פנסיה תקציבית באמצעות קופת גמל מרכזית לקצבה, לגמלאים        |
|                           |        |        |ולשארים, ללא צורך באישור החברה בהפרטה;                                                          |
|                           |        |        |לענין סעיף זה "קופת גמל לקצבה" כהגדרתה בחוק הפיקוח על שירותים פיננסיים (ביטוח), תשמ"א-1981[2];  |
|                           |        |        |(3) האמור  בסעיפים קטנים (1) ו-(2) יחולו גם על גמלאים שפרשו בפרישה מוקדמת;                      |
|                           |        |        |(4) חובת החברה בהפרטה להבטיח כי יינתן ייצוג הולם לגמלאים ולשאירים בדירקטוריון של קופת גמל מרכזית|
|                           |        |        |לקצבה, בה החברה בהפרטה  היא עמית".                                                              |

דברי הסבר

   בשנים האחרונות דוחף האוצר להקמת קופת גמל מרכזית לקצבה להבטחת זכויות פנסיה של עובדים וגמלאים, בתאגידים ממשלתיים שהופרטו או יופרטו.
   מטרת  הצעת חוק זו להבטיח את זכויותיהם של גמלאים ושל שאירים בחברה העוברת תהליך של הפרטה. כמו כן, מבטיחה ההצעה באופן מיוחד את זכויות הפנסיה של הגמלאים וכן מתן ייצוג הולם לגמלאים ולשאירים בדירקטוריון של קופת גמל מרכזית לקצבה בה החברה בהפרטה היא העמית.
