דברי הסבר

   בחודש יוני 2007 קיבלה הכנסת תיקון לחוק הבנקאות (שירות ללקוח), התשמ"א–1981, באופן שעיגן את עקרונות השקיפות, ההגינות והמובנות במסגרת החובות החלות על תאגיד בנקאי.
   לאור עקרונות אלה, החליטה ועדת הכלכלה לכלול בתיקון גם את החובה ליידע את ארגוני הצרכנים ביחס לבקשתו של תאגיד בנקאי לייקר עמלה. נוסחו של הסעיף היה כדלקמן:

   |                           |        |"בקשה להעלאת סכום עמלה או  |9יד.    |(א) תאגיד בנקאי המבקש לגבות מלקוחותיו, בעד שירות בר-פיקוח שלא נקבעה |
|                           |        |שיעורה                     |        |לגביו הוראה לפי סעיף 9יג, עמלה בסכום או בשיעור העולה על הסכום או    |
|                           |        |                           |        |השיעור שגבה בעד אותו שירות ערב ההכרזה לפי סעיף 9יב, יגיש למפקח בקשה |
|                           |        |                           |        |מנומקת לכך; המפקח רשאי לדרוש מהמבקש פרטים נוספים לבדיקת הבקשה; המפקח|
|                           |        |                           |        |יודיע לארגון צרכנים, כהגדרתו בסעיף 31(ג) לחוק הגנת הצרכן,           |
|                           |        |                           |        |התשמ"א-1981[3], על הגשת בקשה לפי סעיף קטן זה ועל סכום או שיעור      |
|                           |        |                           |        |ההעלאה המבוקשת."                                                    |

   בעקבות הסתייגות שהתקבלה, הושמט הקטע המתייחס לחובת הצרכנים מן הנוסח הסופי שהתקבל, ולפיכך מוגש תיקון זה כהצעת חוק פרטית.
   הצעת החוק באה לקבוע את זכותם של הצרכנים של השירותים הבנקאיים באמצעות נציגיהם המוכרים על-פי חוק, להביע דעתם במסגרת ההליך לאישור ייקורה של עמלה, ולא לאחר מעשה.
   באופן זה יכובדו כללי הצדק הטבעי, המחייבים שיישמע קולו של מי שעלול להיפגע מהחלטה, בטרם תתקבל. התיקון המוצע יאפשר למפקח על הבנקים – כרגולטור – לשקול ולהביא באיזון את מכלול האינטרסים בהם יש להתחשב בעת קבלת ההחלטה.
