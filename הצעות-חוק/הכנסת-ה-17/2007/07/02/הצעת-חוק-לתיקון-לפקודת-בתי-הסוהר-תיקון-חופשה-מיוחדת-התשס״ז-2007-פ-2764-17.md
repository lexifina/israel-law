הצעת חוק לתיקון לפקודת בתי הסוהר (חופשה מיוחדת), התשס"ז-2007

|תיקון סעיף 36              |1.      |בפקודת בתי הסוהר [נוסח חדש], התשל"ב–1971[1], בסעיף 36, אחרי סעיף קטן (א) יבוא:                            |
|                           |        |        |"(א1) הודאתו או כפירתו של אסיר בביצוע העבירה, לא תהווה שיקול במניין השיקולים שיביא השר בחשבון,  |
|                           |        |        |בבואו להחליט האם ליתן חופשה מיוחדת."                                                            |

דברי הסבר

   כיום, אסיר אשר הורשע בביצוע מעשה ואינו מוכן להודות באשמה, אינו זכאי לקבלת חופשות מיוחדות. ייתכן והאסיר הינו חף מפשע, ולכן  לא יתכן כי לא יקבל את אותם התנאים של אסיר אשר הודה בביצוע המעשה, רק מכיוון שהוא מאמין בחפותו. ישנו חשש כי אסיר חף מפשע, יודה בביצוע המעשה רק בעקבות רצונו לזכות בחופשה.
   הצעת חוק זו נועדה למנוע אפליה באפשרות קבלת חופשה בין האסירים, על רקע של כפירה בביצוע העבירה.
