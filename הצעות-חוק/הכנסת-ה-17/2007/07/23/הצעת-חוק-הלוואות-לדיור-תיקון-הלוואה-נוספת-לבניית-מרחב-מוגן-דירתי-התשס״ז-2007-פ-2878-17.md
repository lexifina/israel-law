הצעת חוק הלוואות לדיור (תיקון - הלוואה נוספת לבניית מרחב מוגן דירתי), התשס"ז-2007

|תיקון סעיף 7               |1.      |בחוק הלוואות לדיור, התשנ"ב-1992[1], האמור בסעיף 7 יסומן "(א)" ואחריו יבוא:                                |
|                           |        |"(ב) בנוסף על האמור בסעיף קטן (א), שר הביטחון רשאי להתקין תקנות לענין יישובים בהם תינתן הלוואה נוספת בסכום|
|                           |        |שיקבע, לבניית מרחב מוגן דירתי, כהגדרתו בתקנות ההתגוננות האזרחית (מפרטים לבניית מקלטים), התש"ן-1990[2],    |
|                           |        |והכל לתקופה שתקבע בתקנות כאמור, ובלבד שיתקיימו אלה:                                                       |
|                           |        |        |(1) שיעור הריבית על ההלוואה הנוספת יהיה 2 אחוזים לשנה;                                          |
|                           |        |        |(2) התקופה להחזר ההלוואה הנוספת תהיה עשרים וחמש שנים."                                          |

דברי הסבר

   לאור האיום הביטחוני המתרחב, וכניסתם של יישובים נוספים לטווח הטילים, מוצע להקנות זכאות להלוואה נוספת לבניית מרחב מוגן דירתי (ממ"ד) ליישובים שיקבע שר הביטחון בתקנות.
שיעור הריבית על ההלוואה הנוספת יהיה 2% לשנה, והתקופה להחזר ההלוואה הנוספת תהיה עשרים וחמש שנים.
