|תיקון סעיף 22                    |1.     |בחוק-יסוד: נשיא המדינה[1], בסעיף 22, בסופו יבוא:                                                    |
|                                 |       |"(ג) החליטה ועדת הכנסת לאשר הודעת נשיא המדינה בעניין נבצרות והייתה העילה חקירה פלילית, לא יתגורר    |
|                                 |       |הנשיא, בתקופת הנבצרות, במעונו הרשמי."                                                               |
|                                                                                                                                               |

דברי הסבר

   בהתאם לנוהל הקיים, נשיא אשר מקבל נבצרות זמנית עקב חשדות להרשאה פלילית זכאי להמשיך לשכון במשכן הנשיא. התיקון לחוק בא למנוע זאת כדי למנוע מראית עין ציבורית ולפיה נבחר ציבור אשר הושעה מתפקידו ממשיך לנהל שגרת חיים ציבורית כאילו דבר לא קרה.
