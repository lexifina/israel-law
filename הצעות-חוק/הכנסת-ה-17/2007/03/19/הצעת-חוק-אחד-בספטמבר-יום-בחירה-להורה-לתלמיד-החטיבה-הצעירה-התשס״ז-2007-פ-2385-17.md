הצעת חוק אחד בספטמבר - יום בחירה להורה לתלמיד החטיבה הצעירה, התשס"ז-2007

| הגדרות                    |1.   | |בחוק זה –                                                                                                    |
|                           |     | "תלמיד בחטיבה הצעירה" –תלמיד הלומד לפי חוק לימוד חובה, התש"ט-1949[1], מגיל 5 ועד גיל 10 וכן ילד הלומד בגן   |
|                           |     |ילדים מגיל 3 עד גיל 5;                                                                                       |
|                           |     |"יום בחירה" – יום שהבחירה בידי העובד לצאת לחופשה או לעבוד.                                                   |
|יום אחד בספטמבר כיום בחירה |2.   | |(א) האחד בספטמבר יהיה יום בחירה לעובד שהינו הורה לתלמיד בחטיבה הצעירה.                                       |
|לעובד                      |     | |                                                                                                             |
|                           |     | |(ב) חל יום האחד בספטמבר בשבת, יהיה יום הבחירה ביום הראשון לשנת הלימודים בבתי הספר.                           |
|מניין ימי חופשת העובד      |3.   | |(א) בחר העובד ביום חופשה כאמור בסעיף 2, יובא היום במניין ימי החופשה שלו.                                     |
|                           |     | |(ב) רשאי עובד להגדיר יום זה כחצי יום בחירה ובתנאי שנעדר רק בחלקו הראשון של יום העבודה.                       |
|תחולה                      |4.   | |הוראות חוק זה לא יחולו על מי שהוא עובד משרד החינוך, התרבות והספורט .                                         |

דברי הסבר

   היום הראשון ללימודים הוא אחד הימים המרגשים והחשובים ביותר בימי הלימוד של תלמידי בית הספר, ובפרט תלמידי הגנים והכיתות הצעירות. הורים רבים מבקשים ללוות את ילדיהם ולעמוד לצידם ביום זה. הצעת החוק הזו מבקשת לאפשר להורה לבחור ביום האחד  בספטמבר כיום חופשה- בה יקדיש זמנו להיות עם ילדו ביום החשוב והמיוחד הזה. יום בחירה זה יבוא במניין ימי הבחירה הנהוגים במשק.
