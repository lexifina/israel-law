הצעת חוק מנהל בתי המשפט ומנהל בתי הדין הרבניים (תיקוני חקיקה), התשס"ז-2007

|תיקון חוק בתי המשפט        |1.      |בחוק בתי המשפט [נוסח משולב], התשמ"ד-1984[1], בסעיף 82(א) -                                                |
|                           |        |(1) אחרי "נשיא בית המשפט העליון את" יבוא "אחד השופטים לתפקיד";                                            |
|                           |        |(2) המילים "בין שהוא שופט ובין שאינו שופט" - יימחקו.                                                      |
|תיקון חוק הדיינים          |2.      |בחוק הדיינים, התשט"ו-1955[2], בסעיף 13 -                                                                  |
|                           |        |(1) בסעיף קטן (א), המילים "או אדם הכשיר להיבחר רב עיר" והסיפה המתחילה במילים "מינוי לפי סעיף" – ימחקו;    |
|                           |        |(2) סעיף קטן (ב) – בטל.                                                                                   |
|תחולה                      |3.      |חוק זה לא יחול על מי שמכהן בתפקיד של מנהל בתי המשפט או מנהל בתי הדין הרבניים ערב תחילתו של חוק זה.        |

דברי הסבר

   חוק בתי המשפט [נוסח משולב] מסדיר את מינויו של מנהל בתי המשפט, כך:
|"סדרי מינהל            |82.     |(א)     |שר המשפטים יקבע את סדרי המינהל של בתי המשפט, וימנה בהסכמת נשיא בית המשפט העליון את מנהל בתי     |
|                       |        |        |המשפט, בין שהוא שופט ובין שאינו שופט.                                                           |
|                       |        |(ב)     |מנהל בתי המשפט יהיה אחראי בפני השר על ביצועם של סדרי המינהל."                                   |

   חוק הדיינים, התשט"ו-1955 מסדיר את מינויו של מנהל בתי הדין הרבניים, כך:
|"סדרי מינהל            |13.     |(א)     |השר, בהסכמת נשיא בית הדין הרבני הגדול, יקבע, בתקנות או בהוראות מינהל, לפי הענין, את סדרי המינהל |
|                       |        |        |של בתי הדין הרבניים וימנה על ביצועם את אחד הדיינים או אדם הכשיר להיבחר רב עיר, שיהיה אחראי      |
|                       |        |        |בפניהם; מינוי לפי סעיף קטן זה של מי שכשיר להיבחר רב עיר טעון אישור ועדת המינויים.               |
|                       |        |(ב)     |מנהל בתי הדין הרבניים שאיננו דיין, מינויו אינו טעון מכרז פומבי ודינו, לענין סעיף 17 ולענין חוק  |
|                       |        |        |גימלאות לנושאי משרה ברשויות השלטון, התשכ"ט-1969, כדין דיין."                                    |

   החוק מאפשר למנות לתפקיד מנהל בתי המשפט או מנהל בתי הדין הרבניים אדם המכהן כשופט או כדיין, לפי העניין, אולם מאפשר גם למנות לתפקיד אדם שאינו מכהן כאמור.
   לאור העובדה שמדובר בתפקיד רב חשיבות במערכת השיפוט, יש לעגן את הנוהל הקיים ממילא בבתי המשפט ולחייב כי לתפקיד המנהל ימונה שופט או דיין.
   עוד מוצע כי כדי שלא לפגוע במי שיכהן בתפקיד בעת קבלת החוק, יחול החוק רק על מי שימונה לתפקיד לאחר קבלתו.
