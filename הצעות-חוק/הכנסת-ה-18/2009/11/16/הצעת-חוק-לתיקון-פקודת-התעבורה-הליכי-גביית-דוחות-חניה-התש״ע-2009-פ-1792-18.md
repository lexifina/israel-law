הצעת חוק לתיקון פקודת התעבורה (הליכי גביית דוחות חניה), התש"ע–2009

|תיקון סעיף 77              |1.      |בפקודת התעבורה[1], בסעיף 77, אחרי סעיף קטן (א) יבוא:                                                      |
|                           |        |"(א1)  על אף האמור בסעיפים 229(ב) לחוק סדר הדין הפלילי [נוסח משולב], התשמ"ב–1982[2] ו-70 לחוק העונשין,    |
|                           |        |התשל"ז–1977[3], חלפו שלוש שנים מיום שבוצעה עבירה, שבשלה נשלחה למי שביצע אותה הודעת קנס בהתאם לסעיף קטן    |
|                           |        |(א)(2), תבטל העיריה או המועצה המקומית שבתחומה בוצעה העבירה, לפי העניין, את הקנס, ותפסיק את כל הליכי       |
|                           |        |גבייתו."                                                                                                  |

דברי הסבר

   לא פעם קורה שאזרח מקבל לביתו את דוח החניה שנים לאחר שכבר ביצע את העבירה המיוחסת לו, בתוספת ריבית פיגורים, בין היתר בשל הסחבת בהליכי גביית דוח חניה. הצעת החוק באה למנוע מצב זה, ולחייב עיריה או מועצה מקומית לסיים את כל הליכי גביית קנסות החניה הננקטים נגד אזרח  שביצע עבירות חניה בתחום העיריה או המועצה המקומית, בתוך שלוש שנים מיום ביצוע העבירה. בהתאם להצעת החוק, אם העיריה או המועצה המקומית לא גבו את הקנס בחלוף שלוש שנים ממועד ביצוע העבירה, יהא עליהן לבטלו, ולהפסיק את כל  הליכי הגבייה.
