הצעת חוק בתי הדין הדתיים הדרוזיים (תיקון – ועדת המינויים), התש"ע–2010

|תיקון סעיף 11              |        |בחוק בתי הדין הדתיים הדרוזיים, התשכ"ג–1962[1] בסעיף 11, במקום הקטע החל במילים "חבר כנסת דרוזי" ועד       |
|                           |        |"להוראות חוק הכנסת" יבוא:                                                                                |
|                           |        |"(1) שני חברי כנסת דרוזים שייבחרו על ידי הכנסת בבחירה חשאית ויכהנו כל עוד הינם חברי כנסת, ואם תמה כהונת  |
|                           |        |הכנסת – חברי כנסת אחרים במקומם עד שתיבחר הכנסת החדשה.                                                    |
|                           |        |(2) היו שני חברי כנסת דרוזים בלבד, יכהנו הם כחברי הוועדה ותקופת כהונתם תהא כתקופת כהונתו של חבר כנסת     |
|                           |        |דרוזי שנבחר על ידי הכנסת; ובלבד שאם אחד מהם אינו יכול לכהן כחבר הועדה מפאת הוראות חוק הכנסת, ינהגו כאילו |
|                           |        |אינו חבר כנסת דרוזי לעניין המינוי; והוא הדין אם לא רצה אותו חבר לכהן כחבר הועדה או התפטר מחברותו בה.     |
|                           |        |(3) לא היו שני חברי כנסת דרוזים, ייבחרו נציגים דרוזיים שאינם חברי כנסת לוועדה מקרב העדה הדרוזית, שייבחרו |
|                           |        |על ידי הכנסת בבחירה חשאית ויכהנו כל עוד לא בחרה הכנסת דרוזי אחר במקומם והכול בכפוף להוראות חוק הכנסת     |
|                           |        |התשנ"ד–1994[2] (להלן – חוק הכנסת).                                                                       |
|                           |        |(4) היה חבר כנסת דרוזי אחד, יכהנו הוא ונציג דרוזי נוסף, שאינו חבר כנסת, כחברי הועדה ותקופת כהונתם תהיה   |
|                           |        |כתקופת כהונתו של חבר כנסת דרוזי שנבחר על ידי הכנסת."                                                     |

דברי הסבר
   הצעת החוק המוצעת מבקשת לתקן עיוות בחוק בתי הדין הדרוזים, אשר בניגוד לחוקי בתי הדין השרעיים והרבניים, אינו מחייב שנציגי הכנסת בוועדת המינויים לבחירת הקאדים יהיו חברי כנסת.
   הצעת החוק קובעת כי במידה ויש בכנסת די חברי כנסת דרוזים, הבחירה לנציגיה של הכנסת בוועדת המינויים תיעשה ביניהם בלבד. רק באם אין די חברי כנסת ממוצא דרוזי, תוכל הכנסת לבחור כאחד מנציגיה בוועדה, גם את מי שאיננו חבר כנסת.
