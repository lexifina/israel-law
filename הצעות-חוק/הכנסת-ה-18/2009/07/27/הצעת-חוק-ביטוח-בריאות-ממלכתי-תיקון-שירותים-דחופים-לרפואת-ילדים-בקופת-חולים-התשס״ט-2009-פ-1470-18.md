הצעת חוק ביטוח בריאות ממלכתי (תיקון – שירותים דחופים לרפואת ילדים בקופת חולים), התשס"ט–2009
|הוספת סעיף 21ב             |1.      |בחוק ביטוח בריאות ממלכתי, התשנ"ד–1994[1] (להלן – החוק העיקרי), אחרי סעיף 21א יבוא:                       |
|                           |        |"רפואת ילדים               |21ב.    |קופת חולים תקצה מטעמה שירותים דחופים לרפואת ילדים גם במשך שעות הערב |
|                           |        |                           |        |עד שעת חצות הלילה.".                                                |
|תיקון סעיף 25              |2.      |בסעיף 25 לחוק העיקרי, האמור בו יסומן "(א)" ואחריו יבוא:                                                  |
|                           |        |"(ב) שר הבריאות ישלול הכרה מקופת חולים שאינה מקיימת את הוראת סעיף 21ב.".                                 |

דברי הסבר

   השנתון הסטטיסטי "ילדים בישראל" שפרסמה המועצה לשלום הילד מצביע על עומסים גדולים ביותר עד לכדי אי ספיקה של חדרי מיון הנגרמים מפניית תינוקות וילדים לחדרי המיון בשעות שאין כלל שירותי מרפאה בקופת חולים, ובעיקר בשעות הערב עד חצות הלילה.
   עומסים כבדים אלה גורמים לליקויים רבים ביכולתם של חדרי המיון להתמודד עם עומס הפונים אליהם, אשפוזים מיותרים וטיפול לקוי.
   חיוב קופות החולים לקיים שירותי רפואת ילדים גם בשעות אלו יביא לשיפור השירות, וחיסכון משמעותי בהוצאות קופות החולים.
   הצעת חוק זהה הונחה על שולחן הכנסת השש-עשרה על ידי חבר הכנסת אריה אלדד (פ/3349).
   הצעת חוק זהה הונחה על שולחן הכנסת השבע-עשרה על ידי חבר הכנסת אריה אלדד (פ/610/17).
