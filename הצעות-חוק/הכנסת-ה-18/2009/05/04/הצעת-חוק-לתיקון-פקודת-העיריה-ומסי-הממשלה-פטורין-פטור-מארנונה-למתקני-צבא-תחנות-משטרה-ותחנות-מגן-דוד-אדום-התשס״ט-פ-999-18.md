הכנסת השמונה-עשרה

      הצעת חוק של חבר הכנסת		אריה אלדד

					פ/999/18

הצעת חוק לתיקון פקודת העיריה ומסי הממשלה (פטורין)(פטור מארנונה למתקני צבא, תחנות משטרה ותחנות מגן דוד אדום), התשס"ט–2009
|תיקון סעיף 5               |1.      |בפקודת מסי העיריה ומסי הממשלה (פטורין), 1938[1], בסעיף 5, אחרי פסקה (יא) יבוא:                           |
|                           |        |"(יב) כל מתקן צבאי מבצעי או תחנת משטרה או תחנת מגן דוד אדום.".                                           |
|                           |        |לעניין פסקה זו –                                                                                         |
|                           |        |"מתקן צבאי מבצעי" – מתקן צבאי המשמש לצורכי ביטחון שוטף בגזרתו;                                           |
|                           |        |"תחנת משטרה" – כהגדרתה בסעיף 77ח1 לפקודת המשטרה [נוסח חדש], התשל"א–1971[2];                              |
|                           |        |"תחנת מגן דוד אדום" – תחנה של האגודה "מגן דוד אדום בישראל" שהוקמה לפי חוק מגן דוד אדום, התש"י–1950[3],   |
|                           |        |אשר פועלת לצורך מתן שירותי עזרה ראשונה ושירותי אמבולנסים ואשר מאוישת בעובדים או מתנדבים.".               |

דברי הסבר

   מוצע להבדיל, מחנות מנהלתיים–עורפיים הממוקמים בערים או מועצות אזוריות ומקומיות ועליהם חלים תשלומי ארנונה ככל נכס אחר באותו אזור, ממתקנים מבצעיים צבאיים ומוקדי שירותי חירום והצלה שתפקידם הישיר הוא הגנה על אותו אזור, ולפטור מתקנים אלה מחובת תשלום ארנונה.
   הצעת חוק זהה הונחה על שולחן הכנסת השש-עשרה על ידי חבר הכנסת אריה אלדד (פ/1382). הצעת חוק זהה הונחה על שולחן הכנסת השבע-עשרה על ידי חבר הכנסת אריה אלדד (פ/1508/17).
