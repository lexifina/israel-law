הצעת חוק איסור קבורה בתחומי הר הבית והגבלת קבורה בתחומי העיר העתיקה בירושלים, התשס"ט–2009

|הגדרות                     |1.      |בחוק זה –                                                                                                |
|                           |        |"העיר העתיקה" – אזור בירושלים שגבולותיו מסומנים במפה שבתוספת, שמתוחם על ידי החומות מהמאה השש–עשרה;       |
|                           |        |"הר הבית" – מתחם החצר המקודש שעל הר המוריה בעיר העתיקה, שגבולותיו מסומנים במפה שבתוספת, שמתוחם על ידי    |
|                           |        |חומות ההר ובכללן שערי ההר;                                                                               |
|                           |        |"מצבת זיכרון" – עצם או מבנה הנועד לציין זכר אדם או אירוע;                                                |
|                           |        |"ציוני קבר" – מתחם שמסמל או מציין אדם שנפטר, גם אם אינו קבור בפועל באותו מקום.                           |
|איסור קבורה  בהר הבית      |2.      |בתחומי הר הבית לא תותר קבורה או הקמה של מצבת זיכרון או ציוני קבר.                                        |
|הגבלת קבורה בעיר העתיקה    |3.      |בתחומי העיר העתיקה לא תותר קבורה אלא באישור הממשלה.                                                      |
|ביצוע ותקנות               |4.      |ראש הממשלה ממונה על ביצוע חוק זה והוא רשאי, בהתייעצות עם השר לביטחון הפנים, להתקין תקנות בכל ענין הנוגע  |
|                           |        |לביצועו.                                                                                                 |
|תחילה                      |5.      |תחילתו של חוק זה 90 ימים מיום פרסומו.                                                                    |

דברי הסבר

   בעבר התפרסם כי יאסר ערפאת הביא את בקשתו להיקבר בהר הבית כפי שנקבר בזמנו פייסל חוסייני, וזאת על מנת לחזק את אחיזת הערבים במקום הקדוש ליהודים.
   הצעת החוק מבקשת למנוע קבורה או הקמת מצבת זיכרון או ציוני קבר כדי לשמור על קדושת הר הבית ולמנוע השתלטות ערבית על ההר ואיזור העיר העתיקה.

   מפה ובה סימוני גבולות העיר העתיקה והר הבית תצורף בהמשך.
   הצעת חוק זהה הונחה על שולחן הכנסת השש-עשרה על ידי חבר הכנסת אריה אלדד  (פ/1619).
   הצעת חוק זהה הונחה על שולחן הכנסת השבע-עשרה על ידי חבר הכנסת אריה אלדד  (פ/1398/17).
