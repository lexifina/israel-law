הצעת חוק סיוע לילדים הסובלים ממחלה כרונית במוסדות חינוך, התשע"ב–2012

|                           |        |פרק א': כללי                                                                                             |
|מטרה                       |1.      |חוק זה מטרתו להסדיר מתן סיוע לילדים הסובלים ממחלות כרוניות בעת שהייתם במוסד חינוך.                       |
|הגדרות                     |2.      |בחוק זה –                                                                                                |
|                           |        |"ארגון ציבורי" – ארגון ארצי של מתנדבים העוסק בטיפול בילדים הסובלים ממחלה כרונית או בקידום עניינם, שהשר   |
|                           |        |הכיר בו בצו;                                                                                             |
|                           |        |"הוועדה" – הוועדה שמונתה לפי סעיף 4;                                                                     |
|                           |        |"ילד" – קטין מגיל שלוש ומעלה;                                                                            |
|                           |        |"מוסד חינוך" – כהגדרתו בחוק לימוד חובה, התש"ט–1949[1], שאינו מוסד לחינוך מיוחד;                          |
|                           |        |"מחלה כרונית" – מחלה המנויה בתוספת;                                                                      |
|                           |        |"סיוע" – לרבות השגחה, ליווי וטיפול בצרכים רפואיים הקשורים למחלה הכרונית;                                 |
|                           |        |"סייע מוכר" – אדם שהוכשר להעניק סיוע לילד הסובל ממחלה כרונית בעת שהייתו במוסד חינוך לפי סעיף 9;          |
|                           |        |"עובד סוציאלי" – כהגדרתו בחוק העובדים הסוציאליים, התשנ"ו–1996[2];                                        |
|                           |        |"רשות חינוך מקומית" – כהגדרתה בחוק לימוד חובה, התש"ט–1949;                                               |
|                           |        |"השר" – שר החינוך.                                                                                       |
|                           |        |פרק ב': קביעת זכאות                                                                                      |
|זכאות לסיוע בעת שהייה במוסד|3.      |(א) ילד הסובל ממחלה כרונית וזקוק לסיוע בשל המחלה הכרונית ממנה הוא סובל, יהיה זכאי לסיוע של סייע מוכר     |
|חינוך                      |        |במוסד החינוך בו הוא שוהה, בעת שהייתו בו, לפי החלטת הוועדה.                                               |
|                           |        |(ב) הזכאות לסייע מוכר תהיה לתקופות של שנתיים בכל פעם ולאחר מכן יבוא עניינו של הילד הסובל ממחלה כרונית    |
|                           |        |לדיון חוזר בפני הוועדה.                                                                                  |
|                           |        |(ג)  דיון חוזר יכול שיתקיים גם לאחר תקופה קצרה מזו שנקבעה בסעיף קטן (ב), בין מיזמת מנהל מוסד חינוך כאמור |
|                           |        |ובין לבקשת ארגון ציבורי; הורה רשאי, בכל עת, להביא את עניינו של ילדו בעל הצרכים המיוחדים לדיון חוזר, ובלבד|
|                           |        |שחלפה שנה ממועד ההחלטה הקודמת בעניינו.                                                                   |
|מינוי הוועדה לקביעת זכאות  |4.      |(א) השר, בהתייעצות עם שר הבריאות, ימנה ועדה בת שישה חברים לקביעת זכאות לסיוע לפי חוק זה, ואלה חברי       |
|לסיוע וסדרי דיון           |        |הוועדה:                                                                                                  |
|                           |        |        |(1) המפקח הארצי על הבריאות במשרד החינוך והוא יהיה היושב ראש;                                    |
|                           |        |        |(2) האחראי על תחום החינוך במשרד הבריאות;                                                        |
|                           |        |        |(3) נציג ארגון החולים היציג הגדול ביותר;                                                        |
|                           |        |        |(4) עובד סוציאלי בעל ניסיון בטיפול בילדים, שייבחר מתוך רשימה של עובדים סוציאליים שתיקבע על ידי  |
|                           |        |        |שר הרווחה;                                                                                      |
|                           |        |        |(5) רופא ילדים המומחה בתחום הנדון;                                                              |
|                           |        |        |(6) נציג מרכז השלטון המקומי.                                                                    |
|                           |        |(ב) יושב ראש הוועדה יזמן את הוועדה לפי הצורך ולא פחות מאחת לשלושה חודשים.                                |
|                           |        |(ג) דיוני הוועדה יירשמו בפרוטוקול; הפרוטוקול, המסמכים הרפואיים וכל מסמך אחר שבידי הוועדה הם סודיים, אך   |
|                           |        |מותר להביאם לידיעת אדם אשר הוועדה זקוקה לשירותיו לצורך קביעת זכאות; אדם שהפרוטוקול או מסמך כאמור הובא    |
|                           |        |לידיעתו חייב לשמור על סודיותם.                                                                           |
|                           |        |(ד) החלטה של הוועדה בנוגע לזכאות לסיוע של ילד הסובל ממחלה כרונית, תתקבל בישיבה בה ישתתפו שלושה חברים     |
|                           |        |לפחות, לרבות רופא הילדים כאמור בסעיף קטן (א)(5), ותתקבל ברוב קולות המשתתפים.                             |
|                           |        |(ה) הוועדה תקבע את סדרי עבודתה ונהלי דיוניה, ככל שלא נקבעו בחוק זה.                                      |
|הפניה לוועדה               |5.      |(א) הוועדה תדון בעניינו של ילד הסובל ממחלה כרונית שהופנה אליה בידי הוריו, מוסד חינוך, רשות חינוך מקומית, |
|                           |        |ארגון ציבורי או מי שהשר, שר הבריאות או שר הרווחה והשירותים החברתיים הסמיכו לכך.                          |
|                           |        |(ב) להפניה כאמור בסעיף קטן (א) יצורפו מסמכים אלה:                                                        |
|                           |        |        |(1) חוות דעת בכתב של הרופא המטפל בילד הסובל ממחלה כרונית, שתכלול בין היתר פרטים בנוגע לאופי     |
|                           |        |        |הסיוע הנדרש בהתאם למצבו הרפואי של הילד;                                                         |
|                           |        |        |(2) חוות דעת בכתב של עובד סוציאלי שטיפל בילד הסובל ממחלה כרונית שתכלול בין היתר פרטים בנוגע     |
|                           |        |        |למצבו הרווחתי של הילד, התמודדותו והתמודדות משפחתו עם המחלה ממנה הוא סובל, ומידת עצמאות הילד     |
|                           |        |        |בטיפול.                                                                                         |
|                           |        |        |(3)  בהעדר מסמך לפי פסקה (2), תצורף חוות דעת בכתב של היועץ החינוכי או פסיכולוג מוסד החינוך בו   |
|                           |        |        |שוהה הילד הסובל ממחלה כרונית, שתכלול בין היתר פרטים על צרכיו של הילד במוסד החינוך.              |
|                           |        |(ג) הוועדה רשאית לצוות על כל אדם להמציא לה כל מסמך שברשותו וכן כל חוות דעת רפואית או פסיכולוגית נוספת    |
|                           |        |הנוגעות לילד הסובל ממחלה כרונית, ולהפנות את הילד לבדיקות נוספות, לפי הצורך, והכל כנדרש לצורך החלטתה.     |
|קביעת זכאות                |6.      |(א)  הוועדה תקבע את זכאותו של ילד הסובל ממחלה כרונית לסייע מוכר בעת שהייתו במוסד חינוך, בין היתר בהתחשב  |
|                           |        |באלה:                                                                                                    |
|                           |        |        |(1) מצבו הבריאותי של הילד, המחלה ממנה הוא סובל ואופן הטיפול בה;                                 |
|                           |        |        |(2) גילו של הילד;                                                                               |
|                           |        |        |(3) הצורך הרפואי של הילד מול הצורך ההתפתחותי שלו, תוך שימת דגש על הישגיו הלימודיים והשתלבותו    |
|                           |        |        |הלימודית והחברתית במוסד החינוך.                                                                 |
|                           |        |(ב) הוועדה תזמין את הילד הסובל ממחלה כרונית ואת הוריו ותאפשר להם או למי מטעמם להשמיע את טיעוניהם.        |
|                           |        |(ג) הזכאות לסיוע של ילד הסובל ממחלה כרונית תהיה למשך כל שעות לימודיו במוסד החינוך, אלא אם קבעה הוועדה    |
|                           |        |אחרת מנימוקים שיירשמו.                                                                                   |
|                           |        |(ד)  הוועדה תודיע בכתב להורי הילד בעל הצרכים המיוחדים או למי מטעמם על החלטתה ונימוקיה, אלא אם כן החליטה  |
|                           |        |הוועדה שמטעמים מיוחדים אין להביא את נימוקיה לידיעתם, ואולם פסיכולוג חינוכי, רופא או עובד סוציאלי מטעמם   |
|                           |        |יהיה רשאי, בכל מקרה, לעיין בפרוטוקול כולו.                                                               |
|מינוי ועדת ערר             |7.      |(א) השר ימנה ועדת ערר בת 5 חברים ובהם עובד בכיר במשרד החינוך בעל ניסיון בתחום בריאות התלמיד, והוא יהיה   |
|                           |        |היושב ראש, רופא בכיר המומחה בתחום הנדון ויושב ראש או מנהל כללי של ארגון החולים היציג הגדול ביותר.        |
|                           |        |(ב) יושב ראש ועדת ערר יזמן את הוועדה שתדון בבקשת הערר ותהיה רשאית –                                      |
|                           |        |        |(1) לשנות את החלטת הוועדה;                                                                      |
|                           |        |        |(2) להחזיר את העניין לדיון נוסף של הוועדה בתוספת הנחיות;                                        |
|                           |        |        |(3) לדחות את הבקשה.                                                                             |
|ערר                        |8.      |(א) על החלטת הוועדה רשאי ילד הסובל ממחלה כרונית, הורה או נציג של ארגון ציבורי להגיש ערר לוועדת ערר, תוך  |
|                           |        |עשרים ואחד ימים מיום שקיבל את ההחלטה.                                                                    |
|                           |        |(ב) ועדת ערר תזמין את הילד הסובל ממחלה כרונית ואת הוריו, ותאפשר להם או למי מטעמם, להשמיע את טיעוניהם.    |
|                           |        |(ג) ועדת ערר תיתן החלטתה תוך עשרים ואחד ימים מיום שהוגש הערר, זולת אם האריכה את המועד מטעמים מיוחדים     |
|                           |        |שיירשמו.                                                                                                 |

דברי הסבר
   בעבור ילדים הסובלים ממצבי בריאות מיוחדים ומשפחותיהם, תהליך הכניסה למוסד חינוך והשהיה בו הינו מורכב וקשה ביותר. כדי להקל על משפחות הילדים, בין היתר, מבחינה כלכלית ולאפשר לילדים אלו לממש זכאותם ללמוד במוסדות חינוך, כשאר בני גילם, ובכדי להקל ולהגן עליהם בעת שהייתם במוסד החינוך ולהבטיח להם סביבת לימודים בטוחה ותומכת –  נדרשים להם סיוע, ליווי וטיפול מתאימים וייחודיים, וזאת באמצעות ליווי של אדם אשר הוכשר למתן הסיוע הנדרש לילד כאמור. כיום, משרד החינוך מממן סיוע באופן חלקי ומוגבל, שאינו מוסדר חקיקתית, לילדים אשר עונים על קריטריונים פנימיים שנקבעו בוועדה בין-משרדית (זאת לאחר שנים רבות בהן מימון זה ניתן על ידי משרד הבריאות, אך הופסק בשל בעיה תקציבית). מאחר שמדובר במימון הניתן באופן וולונטרי, הגדיר משרד החינוך כי המימון יינתן רק לילדים עליהם חל חוק חינוך חובה (אשר במקומות רבים חל מגיל 5 ומעלה) הלומדים במסגרת חינוכית של המדינה בלבד, ולפיכך אינו נותן מענה, בין היתר, לילדים בגילאי 3-5 הסובלים מהמחלות כאמור ואשר נמצאים במסגרות חינוך. כתוצאה מכך, אותם ילדים אינם יכולים לקחת חלק במסגרת חינוכית כלשהי יחד עם בני גילם, על כל המשתמע מכך מבחינת התפתחותם השכלית והנפשית התקינה, וכן גם הוריהם נפגעים ולא פעם נאלצים לוותר על פרנסתם בכדי ללוות את ילדם. בנוסף, מעצם היותו של המימון וולונטרי הוא מוגבל ל-30 שעות שבועיות בלבד וזאת גם אם במסגרת החינוכית שבה נמצא הילד, התוכנית הלימודית הינה רחבה יותר והוא זקוק לסיוע במשך כל שעות שהותו במוסד החינוך. כמו כן, הסיוע תלוי בתקציב אשר עלול להיפסק בכל רגע –  ולכך השלכות כבדות.
