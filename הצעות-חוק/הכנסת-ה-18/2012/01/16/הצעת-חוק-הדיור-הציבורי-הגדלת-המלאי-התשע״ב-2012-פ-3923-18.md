|                           |        |"השר" – שר הבינוי והשיכון.                                                                               |

|                           |        |לבעלות המדינה, לשם שימוש לדיור ציבורי.                                                                   |

|                           |        |מהדירות שייבנו על הקרקע המשווקת, במקום העברת 5% מהדירות באותו בניין בהתאם להוראות סעיף 2; הסכום שיקבע    |
|                           |        |השמאי יועבר למשרד הבינוי והשיכון וישמש לרכישת דירות לטובת דיור ציבורי.                                   |

|ביצוע תקנות                |5.      |השר ממונה על חוק זה והוא רשאי להתקין תקנות בכל עניין הנוגע לביצועו; לעניין תקנות לסעיף 3, רשאי השר לשקול |
|                           |        |תשלום תמורה כספית חלף דיור ציבורי במקרים אלה:                                                            |

דברי הסבר

   במדינת ישראל משפחות רבות, אשר זכאיות לדיור ציבורי על פי הקריטריונים המחמירים של משרד הבינוי והשיכון, אך לנוכח החוסר הקיים במלאי הדירות העומד לרשות המדינה, משפחות אלו אינן מקבלות דירה.
   הצעת החוק נועדה לפתור בעיה זאת, ללא צורך בהוצאה כספית מצד המדינה, אלא באמצעות שימוש במשאב הקרקע לטובת אוכלוסייה חלשה זאת.
