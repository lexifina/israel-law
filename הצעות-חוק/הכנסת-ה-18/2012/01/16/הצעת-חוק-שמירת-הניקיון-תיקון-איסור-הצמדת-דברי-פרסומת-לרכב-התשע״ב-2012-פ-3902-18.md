|תיקון סעיף 5א              |1.      |בחוק שמירת הניקיון, התשמ"ד–1984[1], בסעיף 5א, אחרי סעיף קטן (א) יבוא:                                    |
|                           |        |"(א1) עוסק המדביק, תולה או מניח דבר פרסומת על רכבו של אדם, לרבות על חלונותיו או שמשותיו הקדמיות או       |

|                           |        |נכס או נותן שירות דרך עיסוק, כולל יצרן.".                                                                |

דברי הסבר

   נכון להיום אזרחי מדינת ישראל נתקלים יותר ויותר בתופעת פרסומות עלונים על גבי רכביהם במרכזי קניות, מקומות חניה ומגרשים ציבוריים. תופעה זו לא רק שמרגיזה את האזרח אלא גם גורמת לזיהום הסביבה, כאשר דברי הפרסומות מתעופפים ליד הרכבים או מושלכים מהם. מצמידי הפרסומות פוגעים באזרחים, מזיקים לרכושם הפרטי וחודרים לרשות היחיד ללא כל רשות והסכמה לכך.
