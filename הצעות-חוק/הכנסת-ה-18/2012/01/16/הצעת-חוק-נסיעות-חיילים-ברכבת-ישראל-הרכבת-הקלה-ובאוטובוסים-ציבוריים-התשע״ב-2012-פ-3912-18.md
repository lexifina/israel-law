|הגדרות                     |1.      |בחוק זה –                                                                                                |
|                           |        |"אוטובוס ציבורי" – כהגדרתו בפקודת התעבורה[1];                                                            |
|                           |        |"חייל" – כמשמעותו בחוק השיפוט הצבאי, התשט"ו–1955[2], כשהוא לובש מדים ונושא תעודת חייל חוגר או תעודת קצין;|

|נסיעה חינם                 |2.      |חייל זכאי לנסיעה חינם בתחומי המדינה ברכבת, רכבת מקומית ואוטובוס ציבורי.                                  |
|פיצוי                      |3.      |(א) מדינת ישראל תפצה את רכבת ישראל ואת מפעילי הרכבות המקומיות והאוטובוסים הציבוריים בשל אובדן הכנסות,    |

|                           |        |התחבורה והבטיחות בדרכים.                                                                                 |

דברי הסבר
   תכלית הצעת חוק זו היא להקל על חיילי צה"ל ולסייע להם להתנייד ברחבי הארץ שעה שהם משרתים את המולדת. מוצע לקבוע כי חיילים יוכלו לנסוע בחינם בתחבורה הציבורית – באוטובוסים, ברכבת מקומית וברכבת ישראל.
   הצעות חוק דומות בעיקרן הונחו על ידי חברת הכנסת אורית נוקד על שולחן הכנסת השש-עשרה (פ/2386) ועל שולחן הכנסת השבע-עשרה (פ/683/17).
