הצעת חוק דיווח ממשלה לאחר פיגוע טרור, התשע"ב–2012

|דיווח של הממשלה            |        |בישיבת מליאת הכנסת הסמוכה לאחר פיגוע טרור על רקע לאומני (בחוק זה – פיגוע), ולאחר שהתגלה והותר תחקיר      |
|                           |        |הפיגוע לפרסום, תדווח הממשלה על כל אלה:                                                                   |
|                           |        |(1)  מקור הנשק בו השתמש המחבל והאם נמסר כלי נשק זה לידי הרשות הפלסטינית  על ידי ממשלת ישראל ומתי;        |
|                           |        |(2)  האם המחבל שוחרר מבית כלא ישראלי ובאילו נסיבות, עיתוי שחרורו ותמורתו;                                |
|                           |        |(3)  כיצד התאפשרה תנועתו של המחבל למקום הפיגוע, לרבות אם התאפשרה כתוצאה מהחלטה על פתיחת מחסום או הקלת    |
|                           |        |תעבורה אחרת.                                                                                             |
|השלמת דיווח במועד אחר      |2.      |לא היה בידי כוחות הביטחון המידע במועד האמור בסעיף 1, תשלים הממשלה את הדיווח החסר עם קבלת המידע.          |

דברי הסבר

   מאז הסכם אוסלו מסרו ממשלות ישראל אלפי כלי נשק לידי הרשות הפלסטינית. ממשלות ישראל לדורותיהן שיחררו אלפי מחבלים טרם הגיע מועד שחרורם, מסיבות כאלו ואחרות. פעולות אלו נעשו בדרך כלל תוך ויכוח ציבורי נוקב. מחקרים מוסמכים העלו שרבים מאד מאזרחי ישראל שילמו בחייהם כתוצאה מחזרה לפעילות טרור של מחבלים כלואים ("אסירים ביטחוניים"). ברוב המקרים נמנעת מהדיון הציבורי היכולת לקשר בין הסיבה והמסובב. חוק זה נועד להוסיף כובד ראש בעת קבלת החלטות דרמטיות שכאלו ולהגביר את הדיון הציבורי בנושא הקלות כלפי מחבלים כלואים.
   הצעת חוק דומה בעיקרה הונחה על שולחן הכנסת השמונה-עשרה על ידי חבר הכנסת יעקב כץ (פ/1619/18; והוסרה מסדר היום ביום י' בחשוון התש"ע (28 באוקטובר 2009)).
