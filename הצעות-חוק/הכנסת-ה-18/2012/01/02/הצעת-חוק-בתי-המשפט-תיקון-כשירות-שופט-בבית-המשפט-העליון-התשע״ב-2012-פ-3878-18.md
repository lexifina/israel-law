הצעת חוק בתי המשפט (תיקון – כשירות שופט בבית המשפט העליון), התשע"ב–2012

|תיקון סעיף 2               |1.      |בחוק בתי המשפט [נוסח משולב], התשמ"ד–1984[1], בסעיף 2, האמור בו יסומן "(א)" ואחריו יבוא:                  |
|                           |        |"(ב)    |(1) לא יתמנה לשופט בית משפט העליון אלא מי ששירת בצבא ההגנה לישראל או התנדב לשירות לאומי.        |
|                           |        |        |(2) שופט שכבר התמנה לבית המשפט העליון ולא שירת בצבא ההגנה לישראל או התנדב בשירות לאומי, לא ימונה|
|                           |        |        |לנשיא בית המשפט או לתפקיד המשנה לנשיא בטרם ישלים שירות צבאי או יתנדב בשירות לאומי."             |

דברי הסבר
   הצעת חוק זו נולדה בעקבות הויכוח על דמותו של בית המשפט העליון.
    נדמה שלכולי עלמא אין מחלוקת ששופט המבקש להתמנות לבית המשפט העליון צריך להשלים את חובותיו למדינה כמי ששותף לנשיאה בנטל הביטחוני והחברתי.
    מיותר לציין שלא פעם שופט צריך לדון בעניינים הקשורים לביטחון המדינה ומי שלא היה שותף או גרוע יותר, השתמט משירות צבאי או התנדבות אזרחית מסיבות אידיאולוגיות, לא יוכל לכהן כשופט בבית משפט המעצב את דמותה של מדינת ישראל.�
