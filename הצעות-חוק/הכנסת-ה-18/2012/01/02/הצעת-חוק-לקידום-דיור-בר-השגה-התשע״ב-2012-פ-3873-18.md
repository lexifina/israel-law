הצעת חוק לקידום דיור בר השגה, התשע"ב–2012

|הגדרות                     |1.      |בחוק זה –                                                                                                 |

|                           |        |הממוצע במשק ובדירה ששטחה עולה על 55 מטרים רבועים – 30 אחוזים מהשכר הממוצע במשק;                           |
|                           |        |"השכר הממוצע במשק" – השכר החודשי הממוצע למשרת שכיר בישראל, כפי שמפורסם על ידי הלשכה המרכזית לסטטיסטיקה;   |

|                           |        |תכנוניים וכלכליים לעידוד בניה פרטית של דיור בר השגה בהיקף ובאופן שייקבע.                                  |

דברי הסבר
   בשנים האחרונות גוברת מצוקת הדיור באזורים שונים בישראל. בערים רבות נוצר מצב בו קבוצות רחבות באוכלוסייה מתקשות להמשיך ולהתגורר, בשל האמרת מחירי הדיור. רשויות המדינה אינן יכולות להשקיף על בעיה מחריפה זו בשוויון נפש מבלי לנקוט אמצעים כלשהם כדי להתמודד עימה.
   מוצע לתת לשר הבינוי והשיכון סמכות לקבוע אזורים בעודפי ביקוש לדיור ולהציע לממשלה תוכנית לקידום דיור בר השגה באזורים אלה.
   הצעת חוק זהה הונחה על שולחן הכנסת השמונה-עשרה על ידי חבר הכנסת דב חנין וקבוצת חברי הכנסת (פ/2748/18).
