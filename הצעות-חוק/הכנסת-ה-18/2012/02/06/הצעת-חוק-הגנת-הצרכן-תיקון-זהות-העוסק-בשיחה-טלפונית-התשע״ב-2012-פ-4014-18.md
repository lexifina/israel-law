הצעת חוק הגנת הצרכן (תיקון – זהות העוסק בשיחת טלפון), התשע"ב–2012

|תיקון סעיף 4ב              |1.      |בחוק הגנת הצרכן, התשמ''א–1981[1], בסעיף 4ב, האמור בו יסומן "(א)" ואחריו יבוא:                            |
|                           |        |"(ב) עוסק הפונה לצרכן בשיחת טלפון, חייב לעשות זאת ממכשיר טלפון מזוהה; בסעיף זה, "מכשיר טלפון מזוהה" –    |
|                           |        |מכשיר טלפון שממנו מתקשרים ושמספרו אינו חסום וניתן לזהותו על צג מכשיר טלפון או רדיו טלפון נייד שאליו      |
|                           |        |מתקשרים."                                                                                                |

דברי הסבר

   בשנים האחרונות אנו עדים לתופעה חמורה בה נציגי חברות מסחריות כגון חברות הסלולר, הכבלים והלוויין, משרדי הממשלה, רשויות מקומיות, רשות השידור וגופים אחרים הממומנים מכספי הציבור מתקשרים לצרכנים כאשר מספר הטלפון ממנו הם מתקשרים הינו חסוי. בעשותם זאת, הם למעשה מסתתרים מאחורי מספר לא ידוע ולא מאפשרים לציבור לבחור את בחירתו הטבעית והחופשית האם להשיב לשיחה או לא. בכך למעשה, מנצלים ראשי הגופים המסחריים, העירוניים והממשלתיים וגופים אחרים את העובדה שהצרכן ניצב חסר אונים מול שיחת טלפון שאין הוא יודע האם להשיב לשיחה או לאו.
   מן הדין ומן הצדק כי מספר הטלפון של עוסקים, רשויות והגופים האמורים יהיה גלוי בעת שהם מתקשרים לצרכנים. דבר זה יאפשר למקבל השיחה להחליט אם ברצונו להשיב לשיחה זו או לאו.
   הצעת החוק גם תאפשר, במידת הצורך, לצרכן לחזור אל המספר הפונה במידה ואין הוא יכול להשיב לשיחה מסיבה זו או אחרת.
