הצעת חוק ביטוח בריאות ממלכתי (תיקון – פטור מתשלומי השתתפות עצמית לחולה במחלה כרונית), התשע"ב–2012

|תיקון סעיף 8               |1.      |בחוק ביטוח בריאות ממלכתי התשנ"ד–1994[1], בסעיף 8, אחרי סעיף קטן (ז1) יבוא:                               |
|                           |        |"(ז2) חולה במחלה כרונית יהיה פטור מתשלומי השתתפות עצמית בתרופות ובביקור אצל רופא מומחה; לעניין סעיף קטן  |
|                           |        |זה, "חולה במחלה כרונית" – חולה הסובל ממחלה מוגדרת במשך יותר מ-12 חודשים או שמחלתו מוגדרת כמחלה חשוכת     |
|                           |        |מרפא.".                                                                                                  |

דברי הסבר
   רבים מהחולים הכרוניים בדרך כלל אינם יכולים לעבוד בגלל מחלתם ורבים מהם משתייכים לרובד סוציו-אקונומי בינוני ונמוך, כאשר חלקם אף זכאים לקצבאות מהמוסד לביטוח הלאומי. בעבור אותם החולים, תשלום דמי ההשתתפות העצמית לקופות החולים עבור התרופות שהם צורכים וביקורי הרופא מהווים נתח משמעותי מהכנסתם.
   מוצע למנוע עוול ופגיעה קשים ביותר שנוצרו בהדרגה בשנים האחרונות בשל כוונתו של משרד האוצר להקטין את ההוצאה הממשלתית לבריאות על חשבון הגדלת ההוצאה הפרטית.
