הכנסת השמונה-עשרה

      הצעת חוק של  חברת הכנסת		מירי רגב

					פ/2112/18

הצעת חוק חובת המכרזים (תיקון – העדפת תאגידים המעסיקים חיילי מילואים), התש"ע–2010

|תיקון סעיף 3א              |        |בחוק חובת המכרזים, התשנ"ב-1992[1], בסעיף 3א(א), בסופו יבוא:                                              |
|                           |        |"(4) העדפת שירותים ותוצרת של תאגיד המעסיק חיילי מילואים בהתחשב, בין היתר, בשיעור חיילי המילואים בקרב     |
|                           |        |עובדי אותו תאגיד ובמספר ימי המילואים שאותם חיילים משרתים; לעניין פסקה זו, "חייל מילואים" – כהגדרתו בחוק  |
|                           |        |שירות המילואים, התשס"ח–2008[2]".                                                                         |

דברי הסבר

   בהיעדרו של עובד ממקום עבודתו בשל שירות מילואים, נגרמת פגיעה למעסיק, שכן אף ששכרו של העובד משולם בידי המוסד לביטוח לאומי, המעסיק נאלץ לספוג את ההפסד הכרוך באי ביצוע העבודה בעת שירות המילואים, הפסד שאינו נוצר בשל אשמת העובד, כי אם בשל מילוי חובתו בהגנה על מדינת ישראל; במצב דברים זה, עלול להיווצר תמריץ שלילי להעסקת עובדים המשרתים במילואים.
   בהצעת חוק זו מוצע להסמיך את הממשלה להסדיר בתקנות העדפה לתאגידים המעסיקים חיילי מילואים בהתמודדות במכרזים של המדינה ומוסדותיה; באמצעות העדפה זו ייווצר תמריץ חיובי להעסקת עובדים המשרתים במילואים; במציאות בה שיעור המשרתים במילואים הולך ופוחת, יש להוקיר את חיילי המילואים ולטפחם, ובהצעת חוק זו יש צעד נוסף לשם השגת מטרה זו.
