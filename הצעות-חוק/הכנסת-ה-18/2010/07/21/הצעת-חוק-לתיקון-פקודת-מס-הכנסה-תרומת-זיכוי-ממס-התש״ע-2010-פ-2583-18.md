|                           |        |        |אישר המנהל את הבקשה כאמור יועבר סכום בשיעור הזיכוי ממס למוסד הזכאי.                             |
|                           |        |        |(2) הוראות סעיף 46(א) לא יחולו על תרומת זיכוי ממס לפי הוראות פסקה (1).                          |

|                           |        |        |לו לפי כל דין."                                                                                 |

דברי הסבר
   סעיף 46(א) לפקודת מס הכנסה קובע כי אדם שתרם 300 שקלים חדשים בשנה או יותר, לקרן לאומית או למוסד ציבורי – זכאי לקבל זיכוי ממס הכנסה בשיעורים הבאים: אם הוא יחיד – הזיכוי יהיה בשיעור של 35% מסך התרומה, ואם הוא חבר-בני-אדם – יוכל הזיכוי להגיע עד לשיעור מס החברות, העומד כיום על 25% מס; כל זאת, בתנאים האמורים בסעיף.
   כיום קיים קושי רב של ארגונים ציבוריים לגייס תרומות.
   לפיכך מוצע לאפשר לנישום שזכאי לזיכוי במס מכוח סעיף 46(א) לתרום את מלוא הזיכוי למוסד לו תרם את התרומה הגבוהה ביותר.
   להצעה אין עלות תקציבית, מאחר ומלוא הזיכוי ניתן כיום לנישום.
