הצעת חוק לתיקון פקודת בריאות העם (הגבלת כהונה של מנהלי בתי חולים), התשע"א–2010
|הוספת סעיף 28א             |1.      |בפקודת בריאות העם, 1940[1], אחרי סעיף 28 יבוא:                                                           |
|                           |        |"כהונת מנהלי בתי חולים     |28א.    |(א) תקופת כהונה של רופא כמנהל בית חולים לא תעלה על חמש שנים.        |
|                           |        |        |        |        |        |(ב) מינוי רופא כמנהל בית חולים יוגבל לתקופה  של כהונה אחת בלבד ואולם|
|                           |        |        |        |        |        |הנהלת בית החולים תהא רשאית להאריך את המינוי לתקופת כהונה אחת נוספת. |
|                           |        |        |        |        |        |(ג) רופא שכיהן כמנהל בית חולים רשאי לכהן כמנהל בית חולים אחר."      |

דברי  הסבר

   כיום תקופת כהונתם של מנהלי בתי חולים אינה מוגבלת. הדבר פוגם ביעילות ובהתחדשות המערכת, ומונע אפשרות של קליטת רופאים טובים שיש בידיהם לתרום למערכת.
   הצעות חוק דומות בעיקרן הונחו על שולחן הכנסת החמש-עשרה על ידי חבר הכנסת אחמד טיבי וקבוצת חברי הכנסת (פ/1269, פ/2881), ועל ידי חבר הכנסת עוזי לנדאו (פ/1971), ובכנסת השבע-עשרה על ידי חבר הכנסת אחמד טיבי וקבוצת חברי הכנסת (פ/750/17).
