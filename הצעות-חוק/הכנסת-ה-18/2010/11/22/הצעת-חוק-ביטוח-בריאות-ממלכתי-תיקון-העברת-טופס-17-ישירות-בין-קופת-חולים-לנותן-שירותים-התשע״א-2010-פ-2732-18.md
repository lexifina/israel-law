הצעת חוק ביטוח בריאות ממלכתי (תיקון – העברת טופס 17 ישירות בין קופת חולים לנותן שירותים), התשע"א–2010
|הוספת סעיף 21ד             |        |בחוק ביטוח בריאות ממלכתי, התשנ"ד–1994[1], אחרי סעיף 21ג יבוא:                                            |
|                           |        |"העברת טופס 17 בין קופת    |21ד.    |מבוטח שזכאי לשירותי בריאות אצל נותן שירותים לפי הוראות חוק זה,      |
|                           |        |חולים לנותן שירותים        |        |ושירות כאמור מחייב גם מתן טופס 17 מקופת החולים – יועבר טופס 17 כאמור|
|                           |        |                           |        |ישירות ובאופן ממוחשב מקופת החולים לנותן השירותים; שר הבריאות יקבע   |
|                           |        |                           |        |הוראות לעניין סעיף זה."                                             |

דברי הסבר
   במשך שנים רבות נאלצים מבוטחים להציג טופס 17 (טופס התחייבות) בפני בית חולים לצורך קבלת טיפול. הפקת הטופס נעשית היום בצורה ממוחשבת ולמעשה הופכת את האזרח לשליח של הקופה.
   מוצע כי קופות החולים ובתי החולים יפיקו את הטופס בצורה עצמאית ויסגרו את ההתחשבנות בצורה ממוחשבת ללא צורך בטרטור האזרח ממקום למקום.
   בעידן שבו המידע יכול לעבור בצורה חשאית ומהירה במערכות תקשורת מאובטחות ניתן לפטור את האזרח מטרטור זה ושנותני השירות יסדרו ביניהן את הפרוצדורה האדמיניסטרטיבית לרבות הבטחת התשלום.
