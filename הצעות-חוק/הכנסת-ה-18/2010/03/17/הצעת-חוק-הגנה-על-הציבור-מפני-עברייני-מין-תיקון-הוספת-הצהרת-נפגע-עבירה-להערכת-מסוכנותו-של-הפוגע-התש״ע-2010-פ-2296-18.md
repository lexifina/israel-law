הצעת חוק הגנה על הציבור מפני עברייני מין (תיקון – הוספת הצהרת נפגע עבירה להערכת מסוכנותו של הפוגע), התש"ע–2010
|תיקון סעיף 3               |1.      |בחוק הגנה על הציבור מפני עברייני מין, התשס"ו–2006[1], בסעיף 3 –                                          |
|                           |        |(1) בסעיף קטן (א), בסופו יבוא:                                                                           |
|                           |        |        |"(8) הצהרת נפגע העבירה שנמסרה לגוף החוקר או התובע, לפי הוראות סעיף 18(א) לחוק זכויות נפגעי      |
|                           |        |        |עבירה, התשס"א–2001[2].";                                                                        |
|                           |        |(2) בסעיף קטן (ב), אחרי "בסעיף קטן (א)(1) עד (3)" יבוא "ו-(8)".                                          |

דברי הסבר

   מטרתו של תיקון זה היא להפוך את נפגע העבירה לצד בהערכת מסוכנותו של הפוגע. על פי תיקון זה, נפגע העבירה זכאי לכך שהתובע יביא את הצהרתו בפני מעריכי המסוכנות.
   הצעת חוק זו הוכנה בסיוע מרכז נגה למען נפגעי עבירה, הקריה האקדמית אונו.
