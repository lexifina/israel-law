|תיקון סעיף 40ג             |1.      |בפקודת מס הכנסה[1], בסעיף 40ג, אחרי סעיף קטן (ג) יבוא:                                                   |
|                           |        |(ג1) היה היחיד זכאי לקבל נקודת זיכוי אחת בעבור לימודי תואר אקדמי ראשון וכן מחצית נקודת זיכוי בעבור לימודי|
|                           |        |תואר אקדמי שני באותה שנת מס – תובא בחשבון נקודת זיכוי וחצי באותה שנה."                                   |

דברי הסבר
   פקודת מס הכנסה בנוסחה הקיים מעניקה נקודות זיכוי ממס לבוגרי תארים אקדמיים. בוגר תואר ראשון זכאי לקבל נקודת זיכוי במשך שלוש שנים מיום קבלת זכאותו לתואר; בוגר תואר שני זכאי לקבל חצי נקודת זיכוי במשך שנתיים מיום קבלת זכאותו. לאחרונה נודע כי סטודנטים אשר החלו ללמוד תואר שני בתכוף לסיום לימודי תואר ראשון אינם מקבלים את מלוא הזיכוי אותו התכוון המחוקק להעניק להם; בשנה השלישית לקבלת זכאותם לתואר ראשון המהווה גם השנה הראשונה לזכאותם לתואר שני, במקום לקבל זיכוי ממס בגובה נקודה וחצי מקבלים הסטודנטים נקודה אחת בלבד.
   הצעת החוק באה לתמוך באוכלוסיית הסטודנטים ולמנוע מצב שבו סטודנט לתואר שני יפגע כלכלית אך ורק בשל החלטתו להמשיך בלימוד תואר מתקדם בתכוף לסיום לימודיו לתואר ראשון ולא להמתין שנה נוספת.
