הצעת חוק הגנת הצרכן (תיקון – חובת הקלטה של עסקה טלפונית), התש"ע–2010

|תיקון סעיף 14ג             |1.      |בחוק הגנת הצרכן, התשמ"א–1981[1], בסעיף 14ג, אחרי סעיף קטן (ה) יבוא:                                       |
|                           |        |"(ה1)   |(1) בעסקת מכר מרחוק הנעשית באמצעות טלפון, יקליט העוסק את  השיחה שבה נעשית ההתקשרות בין הצדדים;  |
|                           |        |        |עלה מחיר הנכס בעסקה  על סכום שקבע השר, ישמור העוסק  את ההקלטה שישה חודשים לפחות.                |
|                           |        |        |(2) עוסק יעביר לצרכן העתק מההקלטה, אם הצרכן ביקש זאת בתוך התקופה האמורה בפסקה (1)."             |

דברי הסבר

   צרכנים רבים המבצעים עסקאות טלפוניות, מתלוננים על פער בין תנאי העסקה כפי שסוכמו, להבנתם, עם נציגי העוסק בעת ההתקשרות הטלפונית, לבין תנאי העסקה הכלולים במסמך הכתוב המגיע לידיהם לאחר מכן. תלונות רבות מתייחסות לכך שהעוסק, או נציגו, הכחישו את תנאי ההתקשרות, כפי שהוסכמו לטענת הצרכן.
   בכל מקרה, לצרכן אין כל ראייה על מנת להוכיח את טענותיו.
    בהצעת חוק זו מוצע לחייב עוסק, המתקשר עם צרכנים בעסקאות באמצעות הטלפון, להקליט את מלל שיחת ההתקשרות בעסקה, ואם מחיר העסקה איננו זניח, בהתאם לסכום שיקבע השר בתקנות, יהיה עליו לשמור את ההקלטה למשך תקופה שלא תפחת משישה חודשים. במהלך תקופה זו, הצרכן יהיה רשאי לדרוש את קובץ השיחה המוקלטת מן העוסק, והעוסק יהיה חייב להעביר לו את הקובץ. באופן זה, העוסק יהיה מחויב לתוכן הדברים שנאמרו והובטחו על ידיו בעת ההתקשרות הטלפונית.
