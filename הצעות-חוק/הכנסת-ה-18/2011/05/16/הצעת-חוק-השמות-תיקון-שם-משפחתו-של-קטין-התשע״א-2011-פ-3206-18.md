הצעת חוק השמות (תיקון – שם משפחתו של קטין), התשע"א–2011

|תיקון סעיף 3               |        |בחוק השמות, התשט"ז–1956[1], בסעיף 3, במקום "שם משפחת אביו" יבוא "שמות המשפחה של שני ההורים" ובמקום "את שם |
|                           |        |משפחת האם או שמות המשפחה של שני ההורים" יבוא "רק את שם משפחת אחד ההורים.".                                |

דברי הסבר

   בחוק השמות, התשט"ז–1956, במתכונתו הקיימת, הקטין מקבל את שם משפחת אביו, גם במקרה בו מחליטה האם להישאר עם שם נעוריה ולא לאמץ את שם משפחתו של בעלה. בהתאם לכך, הילד יכול לשאת את שמות המשפחה של שני הוריו רק במקרה וישנה הסכמה משותפת לכך.
   במידה ואין הסכמה של האב לכך, או שהוסכם בין ההורים לתת לילד שם משפחה של האב בלבד, הרי שנוצרת קרקע פורייה למצבים בעייתיים עבור האם שילדיה נושאים שם משפחה שונה משלה, אשר באים לידי ביטוי כאשר האם וילדיה מופיעים יחדיו במוסדות רשמיים שונים כמו שדות תעופה, מוסדות חינוך ועוד.
   התיקון המוצע לסעיף 3 בחוק השמות הקיים, אשר מתייחס, כאמור, למקרה בו ההורים בחרו להישאר כל אחד עם שם משפחתו המקורי, מקנה מעמד שוויוני לשני הצדדים מלכתחילה. קרי, הקטין יישא את שמות המשפחה של שני הוריו ולא רק את שם משפחת אביו. יחד עם זאת, באמצעות התיקון השני לסעיף המדובר, בכל זאת ניתנת האפשרות להורים הנושאים שמות משפחה שונים, לבחור בהסכמה שהקטין יישא רק את שם משפחתו של אחד מההורים.
