הצעת חוק לתיקון פקודת בתי הסוהר (איסור שימוש בטלפון ציבורי לביצוע דבר עבירה), התשע"ב–2011

|הוספת סעיף 47ה             |1.      |בפקודת בתי הסוהר [נוסח חדש], התשל"ב–1971[1], אחרי סעיף 47ד יבוא:                                          |
|                           |        |"שימוש בטלפון ציבורי       |47ה.    |(א) הנציב רשאי לקבוע בפקודות הנציבות הוראות בדבר שימוש בטלפון       |
|                           |        |                           |        |ציבורי.                                                             |
|                           |        |        |        |        |        |(ב) ביצע אסיר עבירה באמצעות הטלפון הציבורי, רשאי הנציב להורות כי    |
|                           |        |        |        |        |        |אותו אסיר לא יהיה זכאי להשתמש בטלפון הציבורי לתקופה שיקבע ובלבד ששמע|
|                           |        |        |        |        |        |את טענותיו; הנציב יבחן את החלטתו מחדש לאחר שלושה חודשים."           |

דברי הסבר
   אסירים שנידונו למאסר ומרצים את עונשים בבתי הכלא, רשאים להשתמש בטלפונים הציבוריים שבאגפי הכלא.
   לעתים מבוצעות עבירות פליליות באמצעות טלפונים הציבוריים, כאשר האסירים מפעילים גורמים מטעמם, אשר נמצאים מחוץ לכותלי הכלא לשם ביצוע העבירות.
   הצעת החוק באה למנוע מאסיר שהוכח שכתוצאה מהשימוש בטלפון הציבורי בוצעה עבירה מטעמו, את המשך שימוש בטלפון ציבורי למשך תקופה שיקבע הנציב.
