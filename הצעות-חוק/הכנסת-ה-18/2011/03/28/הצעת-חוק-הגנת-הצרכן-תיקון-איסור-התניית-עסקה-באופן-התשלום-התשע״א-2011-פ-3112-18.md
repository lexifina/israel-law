הצעת חוק הגנת הצרכן (תיקון – איסור התניית עסקה באופן התשלום), התשע"א–2011

|הוספת סעיף 3א              |1.      |בחוק הגנת הצרכן, התשמ"א–1981[1], אחרי סעיף 3 יבוא:                                                        |
|                           |        |"איסור התניית עסקה באופן   |3א.     |עוסק לא יתנה ביצוע עסקה, לרבות עסקה לתקופה קצובה כהגדרתה בסעיף      |
|                           |        |התשלום                     |        |13א(א) ועסקה מתמשכת, בתשלום באמצעות הרשאה לחיוב חשבון או באמצעות    |
|                           |        |                           |        |הרשאה לחיוב כרטיס אשראי כהגדרתו בסעיף 14ב(ב), ויאפשר גם תשלום       |
|                           |        |                           |        |במזומן."                                                            |

   ד ב ר י  ה ס ב ר

   חברות רבות בישראל, ובמיוחד חברות הסלולר והטלוויזיה, מתנות מתן שירותים בתשלום באמצעות הוראת קבע או באמצעות כרטיס אשראי בלבד. חברות אלה מסרבות להתקשר בעסקה עם צרכן אשר מבקש לשלם את התשלום במזומן מידי חודש, כפי שמאפשרות חברות אחרות במשק, כמו חברת החשמל, תאגידי המים וחברות הגז.
   התניית ביצוע העסקה באופן התשלום פוגעת בזכותו של הצרכן לקבל את השירות ולהחליט באשר לאופן התשלום הנוח לו.
   על כן, מוצע לקבוע כי עוסק לא יתנה ביצוע עסקה בתשלום באמצעות הרשאה לחיוב חשבון או לפי הרשאה לחיוב כרטיס אשראי, ויאפשר גם תשלום במזומן.
