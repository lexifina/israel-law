# תוספת ראשונה __NOSUB__
## סעיף 1 - ההגדרות "נתוני הנוסעים" ו"נתוני הצוות" וסעיפים 2(ד), 3(א) ו-(ב), 13(ב), 17(ב)(1) ו-20(ב)(8)
## נתוני הנוסעים ונתוני הצוות
## חלק א': נתונים המופיעים במסמך נסיעה של נוסע או של איש צוות
1. : שם מלא.
2. : אזרחות.
3. : מין.
4. : תאריך הלידה.
5. : המדינה המנפיקה את מסמך הנסיעה.
6. : כל מידע הנוגע לסוג מסמך נסיעה (דרכון, תעודת מעבר, תעודת מסע או מסמך נסיעה אחר שהוכר לפי חוק הכניסה לישראל).
7. : מספר מסמך הנסיעה ומועד פקיעתו.
## חלק ב': נתונים הנוגעים לטיסה
1. : שם חברת התעופה.
2. : מספר הטיסה.
3. : התאריך והשעה של ההמראה.
4. : נמל המוצא שממנו ממריאה הטיסה ונמל היעד שאליו היא טסה.
5. : התאריך והשעה של הנחיתה.
## חלק ג': נתוני ההזמנה של הנוסעים (Passenger Name Record - PNR)
1. : שמות כל הנוסעים הכלולים בהזמנה, מגדרם ומדינת אזרחותם.
2. : קוד PNR.
3. : כל כתובת.
4. : כל מספר טלפון או פקסימיליה המופיע ברשומת ה-PNR.
5. : כל כתובת דואר אלקטרוני המופיעה ברשומת ה-PNR.
6. : כל מידע על הכרטוס, לרבות מספר כרטיס טיסה, מועד הזמנת כרטיס הטיסה ואפיון כרטיס טיסה לכיוון אחד (one-way ticket).
7. : כל מידע על התשלום בעד כרטיס הטיסה, לרבות סכום התשלום, סוג אמצעי התשלום, ארבע הספרות האחרונות של מספר כרטיס האשראי וכתובת למשלוח קבלה.
8. : כל מידע על מסלול הנסיעה המלא בעבור קוד ה-PNR.
9. : כל מידע על מארגן הנסיעה, סוכן הנסיעות או סוכנות הנסיעות.
10. : כל מידע על סטטוס המסע של הנוסע, לרבות אישורי הגעה, סטטוס עלייה למטוס, סטטוס התייצבות או אי-התייצבות לטיסה.
11. : כל מידע בדבר השתייכות למועדון "נוסע מתמיד".
12. : מספר המושב וכל מידע אחר בנוגע למושב.
13. : מידע PNR מפוצל או מחולק.
14. : כל מידע המצוין בשדה "הערות כלליות" ומתייחס לפרט מהפרטים האחרים בתוספת זו, לרבות כל מידע על קטינים בלתי מלווים, ובכלל זה אלה: שם ומין הקטין; גיל הקטין; שפת הקטין; שם האפוטרופוס ופרטי ההתקשרות עימו בנקודת המוצא וזיקתו לקטין; שם האפוטרופוס ופרטי ההתקשרות עימו בנקודת היעד וזיקתו לקטין; סוכן בנקודת המוצא והיעד.
15. : מידע בדבר קוד טיסה-בשיתוף (code-share information).
16. : כל מידע בדבר כבודה נלווית בין שהיא כבודה רשומה ובין שהיא כבודת יד.
