# תוספת
## סעיף 6(ב)(1)
: ואלה בעלי התפקידים במועצת הרשות:
1. : במשרד הבריאות: ראש שירותי בריאות הנפש, המתאם הארצי לנפגעי סמים ואלכוהול, מנהל מרכז שיקום לנפגעי סמים שקבע ראש שירותי בריאות הנפש, מנהל אגף הרוקחות וראש שירותי בריאות הציבור;
2. : במשרד העבודה והרווחה: מנהל האגף לנוער ולצעירים ושירותי תיקון, מנהל האגף לשירותים חברתיים ומפקח האגף להכשרה והשתלמות מקצועית;
3. : במשרד החינוך והתרבות: סגן מנהל המינהל הפדגוגי, מנהל תחום קידום נוער במינהל חברה ונוער, ממונה על חינוך לבריאות ולמניעת סמים ואלכוהול ומנהל מרכז ההסברה;
4. : בעלי תפקידים אחרים: ראש מחלקת מודיעין במשטרת ישראל; ראש מינהל האסיר בשירות בתי־הסוהר; ראש מדור פסיכיאטריה במפקדת קצין רפואה ראשי בצבא הגנה לישראל; פרקליט מחוז בפרקליטות המדינה.
