# סעיף 16: ביטול הוראת תשלום
(א) המשלם רשאי לבטל הוראת תשלום שניתנה שלא במסגרת פעולת תשלום מובטחת, בהודעה לנותן שירותי התשלום למשלם, כל עוד באפשרות נותן שירותי התשלום להפסיק את ביצוע הוראת התשלום בהתאם למגבלות הטכנולוגיות הסבירות החלות עליו או בהתאם למועד הקבוע בחוזה שירותי התשלום ובלבד שהוא סביר.
(ב) קיבל נותן שירותי תשלום למשלם הודעה לפי סעיף קטן (א) ומתקיימים התנאים שבאותו סעיף קטן, יפסיק את ביצוע הוראת התשלום ואת חיוב המשלם מכוחה, מיד עם קבלת ההודעה.
(ג) בחוזה שירותי התשלום יפרט נותן שירותי התשלום למשלם את המועד שעד אליו ניתן להודיע לו על ביטול הוראת תשלום לפי סעיף קטן (א).
