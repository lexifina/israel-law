# סעיף 75: ביטול עונש או הקלה בו
(א) המפקח הכללי רשאי, בנסיבות מיוחדות שיירשמו, לבטל עונש שהוטל בדין משמעתי בפסק דין חלוט או בפסק חלוט, להפחית ממנו או להחליפו בעונש קל ממנו.
(ב) חויב שוטר בדין משמעתי בפסק דין חלוט או בפסק חלוט, בתשלום פיצויים לפי סעיף 70, בשל נזק שנגרם לרכוש המשטרה, רשאי המפקח הכללי, בנסיבות מיוחדות שיירשמו, לבטל את החיוב בפיצויים או להקטין את שיעורם.
