# סעיף 3: בחירת בעל זכיון
(א) בעל הזכיון יהיה חברה הרשומה בישראל, אשר נבחרה מבין המציעים שנמצאו מתאימים במכרז פומבי (להלן - המציעים); שרי התחבורה, האוצר והבינוי והשיכון, באישור הממשלה, יקבעו את מסמכי המכרז שיימסרו למציעים.
(ב) התקופה המרבית של חוזה הזכיון לפי חוק זה וכן סכום האגרה המרבי או הנוסחה לחישוב סכום האגרה המרבי והדרך לעידכונם, לפי הענין, כפי שייכללו במסמכי המכרז האמורים בסעיף קטן (א), טעונים אישור ועדת הכלכלה של הכנסת.
