# סעיף 139: פנייה לבית המשפט או לממונה בידי מי שנפגע מפעולת הנאמן
(א) היחיד הרואה את עצמו נפגע או עלול להיפגע מהחלטה של הנאמן או מפעולה שעשה או שבכוונתו לעשות או ממחדל של הנאמן, רשאי לפנות לממונה בבקשה לבטל או לשנות את ההחלטה או הפעולה או לתת כל הוראה אחרת שיראה לנכון.
(ב) אדם אחר הרואה את עצמו נפגע או עלול להיפגע מהחלטה של הנאמן או מפעולה שעשה או שבכוונתו לעשות או ממחדל של הנאמן, רשאי לפנות לבית המשפט בבקשה לבטל או לשנות את ההחלטה או הפעולה או לתת כל הוראה אחרת שיראה לנכון;
העתק מהבקשה יישלח לממונה וליחיד.
