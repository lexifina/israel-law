# סעיף 11: סכומים מופחתים
(א) המנהל אינו רשאי להטיל עיצום כספי בסכום הנמוך מהסכומים הקבועים בפרק זה, אלא לפי הוראות סעיף קטן (ב).
(ב) שר האוצר, בהסכמת שר המשפטים ובאישור ועדת החוקה, רשאי לקבוע מקרים, נסיבות ושיקולים שבשלהם יהיה ניתן להטיל עיצום כספי בסכום הנמוך מהסכומים הקבועים בפרק זה, ובשיעורים שיקבע.
