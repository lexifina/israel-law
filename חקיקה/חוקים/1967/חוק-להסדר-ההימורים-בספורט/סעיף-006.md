# סעיף 6: עובדים
(א) דרכי קבלת עובדים למועצה ותנאי עבודתם, לרבות תחולת השיפוט המשמעתי, יהיו כשל עובדי המדינה, בתיאומים שיקבעו השרים בתקנות, באישור ועדת העבודה של הכנסת.
(ב) לענין חוק לתיקון דיני העונשין (עובדי הציבור), תשי״ז–1957, פקודת העדות, פקודת הנזיקים האזרחיים, 1944, וחוק שירות המדינה (סיוג פעילות מפלגתית ומגבית כספים), תשי״ט–1959, דין עובדי המועצה כדין עובדי המדינה.
(ג) המועצה, באישור השרים, תמנה מנהל כללי למועצה.
(ד) תקופת כהונתו של המנהל הכללי תהיה חמש שנים, וניתן לשוב ולמנותו, בדרך האמורה בסעיף קטן (ג), לתקופת כהונה נוספת אחת בלבד.
(ה) המועצה תקבע את הכישורים המקצועיים הנדרשים מסגן מנהל כללי לענייני כספים התואמים את פעילות המועצה, ותאשר את מינויו של סגן המנהל הכללי לענייני כספים שימנה המנהל הכללי, בהתאם לכישורים שנקבעו.
