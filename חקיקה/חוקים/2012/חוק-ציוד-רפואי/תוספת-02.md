# תוספת שנייה
## סעיף 2(ב)
## ציוד רפואי שאינו טעון רישום בפנקס
1. : אבזרים המשמשים לבדיקה, כגון מטושים ומקלות עץ לבדיקה לא חודרנית או לבדיקה לחלל הפה;
2. : אגדים אלסטיים;
3. : חוטים דנטליים;
4. : חומרי חבישה לא סטריליים;
5. : חומרי חיטוי לציוד שאינו ציוד רפואי;
6. : קונדומים, למעט קונדומים המכילים תכשירים;
7. : מוצרי הגיינה נשית;
8. : מוצרי צמר גפן;
9. : משקולות לשקילת בני אדם, למעט פגים, או לשקילת חומרים.
