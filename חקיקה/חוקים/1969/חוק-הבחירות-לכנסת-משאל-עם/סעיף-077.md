# סעיף 77: הספקת פתקי הצבעה
(א) הועדה המרכזית תדפיס פתקי הצבעה בהתאם להוראות סעיף 76.
(ב) כמות פתקי ההצבעה מכל סוג תהיה כמספר הבוחרים הרשומים בפנקס הבוחרים בתוספת שלושים אחוזים.
(ג) יושב ראש הועדה המרכזית, בהתייעצות עם סגניו, רשאי לקבוע כמות אחרת מזו הנקובה בסעיף קטן (ב) ואת מספר הפתקים אשר יודפסו בעברית ובערבית.
(ד) הועדה המרכזית תעביר את פתקי ההצבעה לכל ועדות הקלפי לפחות יומיים לפני יום הבחירות.
