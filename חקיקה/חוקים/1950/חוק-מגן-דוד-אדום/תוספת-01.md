# תוספת
## סעיף 8
1. : הארגון הקיים;
2. : "מגן דוד אדום" סניף בנימינה, בבנימינה;
3. : "מגן דוד אדום" אגודה לעזרה מהירה, בבת ים;
4. : "מגן דוד אדום" סניף גוש הגליל העליון, בכפר גלעדי;
5. : "מגן דוד אדום" סניף גדרה, בגדרה;
6. : ארגון ארצי של אגודות "מגן דוד אדום" לעזרה מהירה בארץ ישראל, סניף רמת־גן, בורוכוב, בני־ברק והסביבה, ברמת־גן;
7. : "מגן דוד אדום" סניף הרצליה, בהרצליה;
8. : "מגן דוד אדום" סניף זכרון יעקב, בזכרון יעקב;
9. : "מגן דוד אדום" סניף חדרה, בחדרה;
10. : ארגון ארצי של אגודות "מגן דוד אדום" לעזרה מהירה בארץ ישראל, סניף חולון, בחולון;
11. : "מגן דוד אדום" אגודה לעזרה מהירה, סניף חיפה, בחיפה;
12. : ארגון ארצי של אגודות "מגן דוד אדום" לעזרה מהירה בארץ ישראל, סניף טבריה, בטבריה;
13. : "מגן דוד אדום" אגודה לעזרה ראשונה, בירושלים;
14. : "מגן דוד אדום" סניף השרון הדרומי, בכפר סבא;
15. : אגודת "מגן דוד אדום" בנהריה;
16. : "מגן דוד אדום" סניף הנגב, בניר עם;
17. : "מגן דוד אדום" אגודה לעזרה מהירה, סניף נס ציונה, בנס ציונה;
18. : "מגן דוד אדום" סניף נתניה, בנתניה;
19. : אגודת "מגן דוד אדום" בעמק יזרעאל, בעפולה;
20. : "מגן דוד אדום" סניף עמק הירדן, באפיקים;
21. : "מגן דוד אדום" סניף פרדס־חנה, בפרדס־חנה;
22. : "מגן דוד אדום" אגודה לעזרה מהירה סניף פתח־תקוה, בפתח־תקוה;
23. : "מגן דוד אדום" סניף צפת, בצפת;
24. : "מגן דוד אדום" אגודה לעזרה מהירה סניף ראשון לציון, בראשון לציון;
25. : "מגן דוד אדום" סניף ראש פינה, בראש פינה;
26. : "מגן דוד אדום" אגודה לעזרה מהירה סניף רחובות, ברחובות;
27. : "מגן דוד אדום" תל-אביב, אגודה לעזרה מהירה, בתל־אביב;
28. : "מגן דוד אדום" סניף תל־מונד, בתל־מונד.
