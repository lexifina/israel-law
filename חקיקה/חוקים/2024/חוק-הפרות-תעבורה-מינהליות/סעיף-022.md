# סעיף 22: ביקורת שיפוטית
(א) בית דין לתעבורה מוסמך לאשר את ההחלטה להטיל קנס, לשנותה, לבטלה ולקבל החלטה אחרת במקומה או להחזיר את העניין עם הוראות לגורם שקיבל את ההחלטה.
(ב) בלי לגרוע מהוראות סעיף קטן (א), בית דין לתעבורה אינו רשאי לשנות את שיעור הקנס הקבוע בתוספת הראשונה, אך הוא רשאי לשנות את הפרת התעבורה המיוחסת למפר.
(ג) בית דין לתעבורה רשאי, ביוזמתו או לבקשת העורר, לפרוס את תשלום הקנס.
(ד) החלטת בית דין לתעבורה לשנות את ההחלטה להטיל קנס או לבטלה ולקבל החלטה אחרת במקומה תהיה מנומקת.
