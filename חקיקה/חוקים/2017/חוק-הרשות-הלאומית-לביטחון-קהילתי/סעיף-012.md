# סעיף 12: גמול והחזר הוצאות
חבר הוועדה שאינו עובד המדינה, עובד גוף מתוקצב או עובד גוף נתמך, יהיה זכאי לקבל מהמשרד לביטחון הפנים גמול בעבור השתתפותו בישיבות הוועדה, בהתאם להוראות שקבע החשב הכללי במשרד האוצר לעניין חברי ועדות ציבוריות; בסעיף זה, "עובד המדינה", "עובד גוף מתוקצב" ו"עובד גוף נתמך" - כהגדרתם בסעיף 32 לחוק יסודות התקציב.
