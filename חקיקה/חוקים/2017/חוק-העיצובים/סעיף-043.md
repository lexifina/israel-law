# סעיף 43: החזר תוקפו של עיצוב רשום שפקע בשל אי־תשלום אגרות
(א) בעל עיצוב רשום שפקע תוקפו בשל אי־תשלום אגרות כאמור בסעיף 42, רשאי לבקש מהרשם בתוך שישה חודשים מהמועד שבו נרשם דבר פקיעת תוקפו של העיצוב הרשום לפי הוראות אותו סעיף, בדרך ובצורה שקבע השר, את החזר תוקפו של העיצוב הרשום, ובלבד שיפרט בבקשה את הסיבות לאי־תשלום האגרות (בסימן זה – בקשה להחזר תוקף).
(ב) הוגשה בקשה להחזר תוקף, יחזיר הרשם את תוקפו של העיצוב אם מצא שהאיחור בתשלום האגרות כאמור בסעיף 41 נגרם אף על פי שבעל העיצוב הרשום נקט אמצעים סבירים בנסיבות העניין לתשלום האגרות במועד, ובלבד שהמבקש שילם את האגרות כאמור באותו סעיף; הרשם יפרסם את דבר החזר תוקף העיצוב הרשום באתר האינטרנט של הרשות.
(ג) אין בהחזר תוקפו של עיצוב רשום שפקע לפי הוראות סעיף זה כדי להאריך את תקופת תוקפו של העיצוב מעבר לתקופה האמורה בסעיף 39.
