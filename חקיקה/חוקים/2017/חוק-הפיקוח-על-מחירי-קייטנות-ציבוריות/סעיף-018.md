# סעיף 18: סכומים מופחתים
(א) הממונה אינו רשאי להטיל עיצום כספי בסכום הנמוך מהסכומים הקבועים בפרק זה, אלא לפי הוראות סעיף קטן (ב).
(ב) השר, בהסכמת שר המשפטים ובאישור ועדת הפנים והגנת הסביבה של הכנסת, רשאי לקבוע מקרים, נסיבות ושיקולים שבשלהם יהיה ניתן להטיל עיצום כספי בסכום הנמוך מהסכומים הקבועים בפרק זה, ובשיעורים שיקבע.
