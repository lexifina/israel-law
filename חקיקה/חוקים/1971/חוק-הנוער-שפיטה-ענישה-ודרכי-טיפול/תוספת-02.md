# תוספת שנייה
## סעיף 9כ
: (הוראת שעה ל-5 שנים מיום 29.7.2027):
1. : עבירת טרור כהגדרתה בחוק המאבק בטרור, התשע"ו-2016;
2. : עבירה לפי חוק מאבק בארגוני פשיעה, התשס"ג-2003;
3. : עבירה לפי סימן ב' או סימן ד' בפרק ז' לחוק העונשין ולפי סעיפים 143, 144, 146 ו-147 לחוק האמור וכן לפי סעיפים 413ב, 413ג ו-413ו רישה לחוק האמור, אם החשוד נתפס בתוך הרכב או אם שוטר ראה את החשוד מבצע את העבירה;
4. : עבירה לפי תקנות 58, 59, 62 ו-64 לתקנות ההגנה (שעת חירום), 1945;
5. : עבירה לפי חוק למניעת הסתננות (עבירות ושיפוט), התשי"ד-1954;
6. : עבירה לפי סעיף 12(א)(1) לחוק הכניסה לישראל, התשי"ב-1952;
7. : עבירה לפי סעיפים 428א או 428ב לחוק העונשין;
8. : מי שעצור לפי תקנות שעת חירום (יהודה והשומרון - שיפוט בעבירות ועזרה משפטית), התשכ"ז-1967, כפי שהוארך תוקפן ותוקן נוסחן בחוק מעת לעת, והוא חשוד בעבירה שאילו נעברה בישראל הייתה אחת מהעבירות המנויות בתוספת זו.
